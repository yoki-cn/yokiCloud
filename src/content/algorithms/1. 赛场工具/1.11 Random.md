### RNG 随机数生成器
---
#### 随机数极简版
---
##### 仅随机引擎
```cpp
mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
```
已经可以直接：
```cpp
u64 x = rng();
shuffle(a.begin(), a.end(), rng);
int v = uniform_int_distribution<int>(l, r)(rng); // [l, r]
double y = uniform_real_distribution<double>(l, r)(rng); // [l, r)
```
> [!warning] 异或哈希使用单独的 mt19937 几乎必定能被卡掉，需要添加非线性映射，如开平方或使用 `splitmix64`
##### 常用整数版
如果题目频繁生成区间随机整数，再补一个 `randint()`：
```cpp
mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
template<class T>
T randint(T l, T r) { return uniform_int_distribution<T>(l, r)(rng); }
```
使用：
```cpp
int x = randint(1, n);             // [1, n]
i64 y = randint<i64>(-1E18, 1E18);
```
若主要随机下标，可以额外补：
```cpp
template<class T>
T randrange(T n) { return randint<T>(0, n - 1); }
```

```cpp
int p = randrange(n); // [0, n)
```
##### Xorshift64* 极短高速版
若连 `<random>` 的分布器都不需要，只想获得高速的随机 `u64`，可以使用：
```cpp
u64 rnd() {
    static u64 x = u64(chrono::steady_clock::now().time_since_epoch().count()) | 1;
    x ^= x >> 12;
    x ^= x << 25;
    x ^= x >> 27;
    return x * 2685821657736338717ULL;
}
```
使用：
```cpp
u64 x = rnd();
int p = rnd() % n;
int v = i64(rnd() % (u64(i64(r) - l) + 1)) + l;
```
以上下标示例要求 `n > 0`；区间示例使用 `int l, r` 且 `l <= r`，先提升到宽整数计算区间长度，避免完整 int 区间溢出。整数分布同样要求 `l <= r`，`randrange(n)` 要求 `n > 0`；浮点分布要求有限端点且 `l < r`。
状态必须非零，因此初始化时使用 `| 1`
这个版本状态只有一个 `u64`，代码短、速度快，适合：
- Treap 随机优先级
- 随机选取 pivot / 起点
- 随机化搜索
- Pollard--Rho 等随机化算法中的随机扰动
- 不要求严格均匀分布的随机下标
`rnd() % n` 存在轻微的**模偏差**。竞赛随机化通常不受影响，但数据生成、概率实验或明确要求均匀随机时，应使用前面的 `uniform_int_distribution`
##### 固定种子
需要复现随机结果时，把时间种子直接换为常量：
```cpp
mt19937_64 rng(114514);
```
或：
```cpp
u64 rnd() {
    static u64 x = 114514;
    x ^= x >> 12;
    x ^= x << 25;
    x ^= x >> 27;
    return x * 2685821657736338717ULL;
}
```
#### 随机数完全体
---
```cpp
struct RNG {
    using result_type = mt19937_64::result_type;
    mt19937_64 gen;
    static constexpr result_type min() { return mt19937_64::min(); }
    static constexpr result_type max() { return mt19937_64::max(); }
    static u64 splitmix64(u64 x) {
        x += 0x9e3779b97f4a7c15ULL;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
        x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
        return x ^ (x >> 31);
    }
    static u64 seed_now() {
        u64 x{ u64(chrono::steady_clock::now().time_since_epoch().count()) };
        random_device rd;
        x ^= u64(rd()) << 32;
        x ^= u64(rd());
        x ^= u64(reinterpret_cast<uintptr_t>(&x));
        return splitmix64(x);
    }
    RNG() : gen(seed_now()) {}
    explicit RNG(u64 seed) : gen(splitmix64(seed)) {}
    // ===== 基础随机：随机化算法通常只需保留到 shuffle() =====
    result_type operator()() { return gen(); }
    void seed() { gen.seed(seed_now()); }
    void seed(u64 s) { gen.seed(splitmix64(s)); }
    template<class T>
    T randint(T l, T r) {
        static_assert(is_integral_v<T> && !is_same_v<T, bool>);
        assert(l <= r);
        return uniform_int_distribution<T>(l, r)(gen);
    }
    template<class T>
    T randint(T r) { return randint<T>(T{}, r); }
    template<class T>
    T randrange(T l, T r) { assert(l < r); return randint<T>(l, r - 1); }
    template<class T>
    T randrange(T r) { return randrange<T>(T{}, r); }
    template<class T = double>
    T real(T l = T{}, T r = T{1}) {
        static_assert(is_floating_point_v<T>);
        assert(l < r);
        return uniform_real_distribution<T>(l, r)(gen);
    }
    template<class It>
    void shuffle(It first, It last) { std::shuffle(first, last, gen); }
    // ===== 对拍 / 数据生成扩展 =====
    u32 next_u32() { return u32(gen()); }
    u64 next_u64() { return gen(); }
    bool bit() { return gen() & 1ULL; }
    template<class T = double>
    T normal(T mean = T{}, T stddev = T{1}) {
        static_assert(is_floating_point_v<T>);
        assert(stddev > T{});
        return normal_distribution<T>(mean, stddev)(gen);
    }
    bool bernoulli(double p) { assert(0.0 <= p && p <= 1.0); return bernoulli_distribution(p)(gen); }
    template<class C>
    void shuffle(C &a) { shuffle(begin(a), end(a)); }
    template<class C>
    decltype(auto) choice(C &a) { assert(!a.empty()); return a[randrange<size_t>(a.size())]; }
    template<class C>
    decltype(auto) choice(const C &a) { assert(!a.empty()); return a[randrange<size_t>(a.size())]; }
    template<class C>
    C sample(C a, int k) {
        assert(0 <= k && k <= int(a.size()));
        shuffle(a);
        a.resize(k);
        return a;
    }
    vector<int> perm(int n, int first = 0) {
        assert(n >= 0);
        vector<int> p(n);
        ranges::iota(p, first);
        shuffle(p);
        return p;
    }
    template<class T = int>
    vector<T> vec(int n, T l, T r) {
        assert(n >= 0 && l <= r);
        vector<T> a(n);
        for (T &x : a) x = randint<T>(l, r);
        return a;
    }
};
inline RNG rng;
```
##### 成员变量
- `gen`：底层 `mt19937_64` 随机数引擎
- `rng`：全局随机数生成器，可直接使用
##### 基础接口
- `RNG()`：使用时间、`random_device` 和地址信息生成随机种子
- `RNG(seed)`：指定种子，方便对拍复现
- `seed()`：重新随机播种
- `seed(s)`：使用指定种子重新播种
- `rng()`：返回一个完整的 `mt19937_64::result_type` 随机数
- `randint<T>(l, r)`：均匀生成整数 `[l,r]`
- `randint<T>(r)`：均匀生成整数 `[0,r]`
- `randrange<T>(l, r)`：均匀生成整数 `[l,r)`
- `randrange<T>(r)`：均匀生成整数 `[0,r)`
- `real<T>(l, r)`：均匀生成浮点数 `[l,r)`，默认 `[0,1)`
- `shuffle(first,last)`：随机打乱 `[first,last)`
`RNG` 补全了 `result_type`、`min()`、`max()` 和 `operator()`，因此本身就是一个 **UniformRandomBitGenerator**，可以直接：
```cpp
uniform_int_distribution<int> d(1, 100);
int x = d(rng);
```
##### 对拍 / 数据生成接口
- `next_u32()`：返回随机 `u32`
- `next_u64()`：返回随机 `u64`
- `bit()`：随机返回 `0/1`
- `normal(mean,stddev)`：正态分布
- `bernoulli(p)`：以概率 `p` 返回 `true`
- `shuffle(a)`：随机打乱整个容器
- `choice(a)`：随机选择一个元素，返回引用
- `sample(a,k)`：无放回随机选择 `k` 个元素，原容器按值传入，不修改调用者
- `perm(n,first)`：生成 `[first,first+n)` 的随机排列
- `vec<T>(n,l,r)`：生成长度为 `n`、元素位于 `[l,r]` 的随机数组
##### 注意事项
- `randint(l,r)` 是**闭区间** `[l,r]`；`randrange(l,r)` 是**左闭右开** `[l,r)`。平时涉及下标时优先写 `randrange(n)`，不容易多出一个 `n`
- `uniform_int_distribution` 主要用于标准整数类型；不要直接拿它生成 `i128/u128`
- `real()`、`normal()` 只能使用 `float`、`double`、`long double`
- `choice()` 要求容器非空；`sample(a,k)` 要求 `0 <= k <= a.size()`
- `sample()` 要求容器支持随机访问、`shuffle` 和 `resize`，最常用于 `vector` / `string`
- 固定 `RNG rng(123);` 可以稳定复现**底层 `mt19937_64` 序列**
- 如果比赛环境的 `random_device` 有问题，可以删掉 `random_device rd` 以及两行 `rd()`，仅使用时钟和地址信息
##### 常见用法
###### 随机整数与下标
```cpp
int x = rng.randint(-10, 10); // [-10, 10]
int p = rng.randrange(n);     // [0, n)
```
###### 随机浮点数
```cpp
double x = rng.real();          // [0, 1)
double y = rng.real(-1.0, 1.0); // [-1, 1)
```
###### 随机排列
```cpp
vector<int> p = rng.perm(n);
```
若需要 `1..n`：
```cpp
vector<int> p = rng.perm(n, 1);
```
###### 对拍固定种子
```cpp
RNG rng(114514);
auto a = rng.vec<int>(n, -100, 100);
```
出现错误后保留种子即可复现
##### 复杂度

| 操作                                                                                                   |     时间复杂度 |
| ---------------------------------------------------------------------------------------------------- | --------: |
| `rng()` / `randint()` / `randrange()` / `real()` / `bit()` / `normal()` / `bernoulli()` / `choice()` | 期望 $O(1)$ |
| `shuffle(a)` / `sample(a,k)` / `perm(n)` / `vec(n,l,r)`                                              |    $O(n)$ |
空间复杂度：`RNG` 本身为 `mt19937_64` 的固定状态空间；`sample`、`perm`、`vec` 额外使用 $O(n)$
