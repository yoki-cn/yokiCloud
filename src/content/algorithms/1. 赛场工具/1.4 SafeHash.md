### SafeHash
---
#### 整数哈希
这个是最常用的，适合 `int / i64 / u64`，主要用于防卡 `unordered_*`
```cpp
struct IntHash {
    static u64 splitmix64(u64 x) {
        x += 0x9e3779b97f4a7c15ULL;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
        x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
        return x ^ (x >> 31);
    }
    size_t operator()(u64 x) const {
        static const u64 seed = chrono::steady_clock::now().time_since_epoch().count();
        return splitmix64(x + seed);
    }
};
```
直接：
```cpp
unordered_map<i64, int, IntHash> mp;
unordered_set<u64, IntHash> st;
```
#### `pair<int, int>`
二维坐标、边、状态二元组特别常见。两个 `int` 可以**无冲突地压进一个 `u64`**，所以没必要做两次字段哈希：
```cpp
struct PairIntHash {
    size_t operator()(const pair<int, int> &p) const {
        u64 x = u64(uint32_t(p.first)) << 32 | uint32_t(p.second);
        static const u64 seed = chrono::steady_clock::now().time_since_epoch().count();
        return IntHash::splitmix64(x + seed);
    }
};
```

```cpp
unordered_map<pair<int, int>, int, PairIntHash> mp;
```
这个版本我尤其推荐。`int` 即使是负数也没问题，因为转成 `uint32_t` 后只是保留原来的 32 位比特
如果你的二维点经常写成：
```cpp
array<int, 2>
```
可以准备对应版本：
```cpp
struct Array2Hash {
    size_t operator()(const array<int, 2> &a) const {
        u64 x = u64(uint32_t(a[0])) << 32 | uint32_t(a[1]);
        static const u64 seed = chrono::steady_clock::now().time_since_epoch().count();
        return IntHash::splitmix64(x + seed);
    }
};
```
#### `pair<i64, i64>`
两个 `i64` 已经不能无损塞进一个 `u64`，这时候才需要真正 combine：
```cpp
struct PairI64Hash {
    size_t operator()(const pair<i64, i64> &p) const {
        static const u64 seed = chrono::steady_clock::now().time_since_epoch().count();
        u64 x = IntHash::splitmix64(u64(p.first) + seed);
        u64 y = IntHash::splitmix64(u64(p.second) + seed);
        return IntHash::splitmix64(x ^ (y + 0x9e3779b97f4a7c15ULL + (x << 6) + (x >> 2)));
    }
};
```
适合：
```cpp
unordered_set<pair<i64, i64>, PairI64Hash> st;
```
#### `__int128`
```cpp
struct I128Hash {
    size_t operator()(i128 x) const {
        u128 y = x;
        u64 lo = y;
        u64 hi = y >> 64;
        static const u64 seed = chrono::steady_clock::now().time_since_epoch().count();
        return IntHash::splitmix64(lo ^ IntHash::splitmix64(hi + seed));
    }
};
```

```cpp
unordered_map<i128, int, I128Hash> mp;
```
如果你已经定义了 `u128`，这个只有几行，实战价值挺高
#### 任意定长 `array`
如果偶尔会有三维坐标、状态数组，可以准备这个。它比针对 `array<int, 2>` 的版本稍重，但仍远比完整 `SafeHash` 简单：
```cpp
template<class T, size_t N>
struct ArrayHash {
    size_t operator()(const array<T, N> &a) const {
        static const u64 seed = chrono::steady_clock::now().time_since_epoch().count();
        u64 h = seed;
        for (const T &x : a) {
            u64 y = IntHash::splitmix64(u64(x) + seed);
            h ^= y + 0x9e3779b97f4a7c15ULL + (h << 6) + (h >> 2);
        }
        return IntHash::splitmix64(h);
    }
};
```
主要面向整数数组：
```cpp
unordered_map<array<int, 3>, int, ArrayHash<int, 3>> mp;
```
#### 自定义哈希
```cpp
struct SafeHash {
    static u64 splitmix64(u64 x) {
        x += 0x9e3779b97f4a7c15ULL;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
        x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
        return x ^ (x >> 31);
    }
    static u64 seed() {
        static const u64 s = [] {
            u64 x = chrono::steady_clock::now().time_since_epoch().count();
            x ^= u64(uintptr_t(&x));
            return splitmix64(x);
        }();
        return s;
    }
    // 基础类型：要求 std::hash<T> 可用
    template<class T>
    static u64 get(const T &x) {
        return splitmix64(u64(hash<T>{}(x)) + seed());
    }
    // 组合多个字段；自定义结构体哈希时直接传入各成员
    template<class T>
    static void combine(u64 &h, const T &x) {
        h ^= splitmix64(get(x) + 0x9e3779b97f4a7c15ULL + (h << 6) + (h >> 2));
    }
    // pair / tuple 可直接作为 unordered_* 的键
    template<class T1, class T2>
    static u64 get(const pair<T1, T2> &p) {
        u64 h{ 0 };
        combine(h, p.first);
        combine(h, p.second);
        return h;
    }
    template<class... Ts>
    static u64 get(const tuple<Ts...> &t) {
        u64 h{ 0 };
        apply([&](const auto &...x) { (combine(h, x), ...); }, t);
        return h;
    }
    template<class T>
    size_t operator()(const T &x) const { return size_t(get(x)); }
};
```
#### 接口说明
- `SafeHash`：可直接作为 `unordered_map` / `unordered_set` 的哈希器
- `splitmix64(x)`：对一个 `u64` 做高质量位混合
- `seed()`：返回本次程序运行固定、不同运行之间变化的随机种子
- `get(x)`：计算单个对象的哈希；普通类型要求存在 `std::hash<T>`
- `get(pair)`：按顺序组合两个元素的哈希
- `get(tuple)`：按顺序组合 tuple 中所有元素的哈希
- `combine(h, x)`：把字段 `x` 合并到已有哈希值 `h`，主要用于自定义结构体
- `operator()(x)`：标准哈希器接口，使 `SafeHash` 可以直接传给 `unordered_*`
#### 注意事项
- `SafeHash` 主要用于降低 `unordered_map` / `unordered_set` 被构造大量哈希冲突而退化的风险，不是密码学哈希，也不能保证绝对无碰撞
- 普通类型仍依赖 `std::hash<T>` 得到初始值，再经过随机化的 `splitmix64` 混合
- 已直接支持任意可哈希元素组成的 `pair` 和 `tuple`，包括嵌套结构，例如 `pair<pair<int, int>, i64>`
- `combine()` **传原始成员即可**，不要写成 `combine(h, SafeHash::get(x))`，否则会额外再哈希一次
- `pair` / `tuple` 的组合哈希与元素顺序有关，`{a, b}` 和 `{b, a}` 通常具有不同哈希
- 自定义结构体除哈希器外，还必须提供正确的相等比较，默认即 `operator==`
- 若数据量很大且大致知道元素数量，可以在插入前使用 `reserve()`，减少 `unordered_*` 扩容次数
#### 常见用法
##### 普通整数键
```cpp
unordered_map<i64, int, SafeHash> mp;
unordered_set<i64, SafeHash> s;
mp[x] = 1;
s.insert(x);
```
相比默认的：
```cpp
unordered_map<i64, int> mp;
```
只需要增加第三个模板参数 `SafeHash`
##### `pair` 作为键
无需再单独写 `PairHash`：
```cpp
unordered_map<pair<int, int>, int, SafeHash> mp;
mp[{x, y}] ++;
```
也可以用于集合：
```cpp
unordered_set<pair<int, int>, SafeHash> s;
s.insert({x, y});
if (s.contains({x, y})) {
}
```
若使用 C++17，将 `contains()` 改为：
```cpp
if (s.find({x, y}) != s.end()) {
}
```
##### `tuple` 作为键
```cpp
unordered_map<tuple<int, int, i64>, int, SafeHash> mp;
mp[{x, y, z}] ++;
```
不同类型也可以混用：
```cpp
unordered_set<tuple<int, string, i64>, SafeHash> s;
s.emplace(1, "abc", 10);
```
##### 嵌套组合键
`pair` / `tuple` 可以递归组合：
```cpp
using Key = pair<pair<int, int>, tuple<int, i64>>;
unordered_map<Key, int, SafeHash> mp;
mp[{{x, y}, {z, w}}] ++;
```
##### 自定义结构体
例如：
```cpp
struct Point {
    int x, y;
    bool operator==(const Point &p) const {
        return x == p.x && y == p.y;
    }
};
```
为它写一个极短的哈希器：
```cpp
struct PointHash {
    size_t operator()(const Point &p) const {
        u64 h{ 0 };
        SafeHash::combine(h, p.x);
        SafeHash::combine(h, p.y);
        return h;
    }
};
```
然后：
```cpp
unordered_map<Point, int, PointHash> mp;
mp[{1, 2}] ++;
```
多字段结构体同理：
```cpp
struct NodeHash {
    size_t operator()(const Node &p) const {
        u64 h{ 0 };
        SafeHash::combine(h, p.x);
        SafeHash::combine(h, p.y);
        SafeHash::combine(h, p.id);
        return h;
    }
};
```
##### 大量元素时预留容量
```cpp
unordered_map<i64, int, SafeHash> mp;
mp.max_load_factor(0.7);
mp.reserve(n);
```
可以减少 rehash，一般在预计需要插入大量元素时使用
#### 复杂度
设组合键包含 $k$ 个字段

|操作|时间复杂度|
|---|--:|
|`splitmix64(x)`|$O(1)$|
|`get(x)`|$O(1)$ 加 `std::hash<T>` 的复杂度|
|`get(pair)`|两个成员哈希复杂度之和|
|`get(tuple)`|$O(k)$ 加各成员自身哈希复杂度|
|`combine(h, x)`|$O(1)$ 加 `get(x)` 的复杂度|
`unordered_map` / `unordered_set` 的查找、插入和删除仍为期望 $O(1)$；`SafeHash` 的作用主要是使恶意构造桶冲突更加困难，而不是改变容器本身的理论复杂度
