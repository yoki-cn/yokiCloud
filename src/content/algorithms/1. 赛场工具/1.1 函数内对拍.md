### 函数内随机对拍
---
```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;
using u64 = unsigned long long;

mt19937_64 rng;
int randint(int l, int r) {
    return uniform_int_distribution<int>(l, r)(rng);
}
// ===== 题目相关：按题目修改以下部分 =====
struct Data {};

struct Ans {
    friend bool operator==(const Ans &, const Ans &) = default;
};

Data gen(u64 id) {
    return {};
}

Ans fast(Data a) {
    return {};
}

Ans brute(Data a) {
    return {};
}

// 判断 fast 的答案 x 是否可以接受；y 为暴力 / 标准答案
bool spj(const Data &a, const Ans &x, const Ans &y) {
    return false;
}

// 对拍失败时输出数据、两个答案等调试信息
void print(const Data &a, const Ans &x, const Ans &y) {
}

int main(int argc, char **argv) {
    u64 seed = chrono::steady_clock::now().time_since_epoch().count();
    if (argc >= 2) seed = stoull(argv[1]);
    rng.seed(seed);
    for (u64 id = 1; ; ++ id) {
        Data a = gen(id);
        Ans x = fast(a);
        Ans y = brute(a);
        // ===== 判定方式：二选一 =====
        bool ok = (x == y);          // 严格相等
        // bool ok = spj(a, x, y);   // SPJ

        if (!ok) {
            cout << "\nWA\n";
            cout << "seed = " << seed << "\ncase = " << id << '\n';
            print(a, x, y);
            break;
        }

        if (id % 100000 == 0) {
            cout << "Passed " << id << " cases\r" << flush;
        }
    }
    return 0;
}
```
#### 类型与函数
- `Data`：单组随机数据，按题目填写成员
- `Ans`：答案类型；默认提供逐成员严格相等判定。若答案只是 `i64`、`vector<int>` 等，可以直接改为对应类型
- `randint(l, r)`：生成闭区间 `[l,r]` 内的均匀随机整数
- `gen(id)`：生成第 `id` 组数据；可以利用 `id` 定期构造特殊数据
- `fast(a)`：待验证的正解
- `brute(a)`：暴力 / 标准算法
- `spj(a, x, y)`：特殊判定，返回 `true` 表示正解答案 `x` 可以接受
- `print(a, x, y)`：对拍失败时输出测试数据以及必要的调试信息
#### 判定方式
默认使用严格相等：
```cpp
bool ok = (x == y);
// bool ok = spj(a, x, y);
```
需要 SPJ 时改为：
```cpp
// bool ok = (x == y);
bool ok = spj(a, x, y);
```
#### 注意事项
- `fast()` 与 `brute()` 的参数故意按值传递，因此二者可以独立修改数据，不会互相影响。若 `Data` 很大且算法完全不修改输入，可以改成 `const Data &a`
- `spj()` 默认返回 `false`，避免切换到 SPJ 后忘记实现判定却一直通过
- `Ans` 使用默认 `operator==`，因此结构体成员都支持 `==` 时，可以直接进行严格比较；如果答案类型特殊，可以自己重载 `operator==`
- 对拍失败必须保留打印出的 `seed`。使用相同种子重新运行，可以复现完全相同的随机序列
- `id` 不只是计数器，也可以用于周期性制造边界数据，避免纯随机数据长期覆盖不到特殊情况
- `print()` 最好输出成题目的正常输入格式，再额外输出 `fast`、`brute` 的答案，方便直接复制失败样例调试
#### 常见用法
##### 复现失败数据
假设失败时输出：
```text
seed = 123456789
case = 81724
```
重新运行：
```bash
./a 123456789
```
会重新生成相同的随机序列，并在相同位置复现问题
##### 周期性生成特殊数据
```cpp
Data gen(u64 id) {
    Data a;
    if (id % 10 == 0) {
        // 极小数据
    } else if (id % 10 == 1) {
        // 极大 / 极端数据
    } else {
        // 普通随机数据
    }
    return a;
}
```
##### 浮点答案 SPJ
```cpp
bool spj(const Data &a, const Ans &x, const Ans &y) {
    constexpr long double eps = 1E-12L;
    return abs(x.val - y.val) <= eps * max({1.0L, abs(x.val), abs(y.val)});
}
```
##### 多解构造题 SPJ
`y` 可以提供暴力求出的最优值，`spj()` 负责检查 `x`：
```cpp
bool spj(const Data &a, const Ans &x, const Ans &y) {
    if (!valid(a, x)) return false;
    return x.value == y.value;
}
```
即不要求两份构造完全相同，只要求正解构造合法且目标值正确
