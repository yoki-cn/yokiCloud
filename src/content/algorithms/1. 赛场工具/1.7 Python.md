### Python 算法竞赛回忆手册
---
**用途：** 高精度整数、数论、字符串、组合枚举、模拟及标准库能够简化实现的竞赛题
**环境：** 默认 Python 3.8+，新版本功能单独标注；使用 CPython / PyPy 时以评测机实际版本为准
#### 1. 基础框架与快速 I/O
##### 普通竞赛模板
```python
import sys
input = sys.stdin.buffer.readline
write = sys.stdout.write

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    print(sum(a))

def main():
    t = 1
    # t = int(input())
    for _ in range(t):
        solve()

if __name__ == "__main__":
    main()
```
- `input()` 在本模板中返回 `bytes`，不是通常内置 `input()` 返回的 `str`
- `int(input())`、`map(int, input().split())` 可直接读取整数
- `write(s)` 不自动换行；`print()` 默认自动换行
- 若需要读取 Unicode 文本，使用 `input().decode()` 或改回普通 `input`
##### 快读方法
**按行读取：默认选择**
```python
input = sys.stdin.buffer.readline
n, m = map(int, input().split())
a = list(map(int, input().split()))
s = input().strip().decode()
```
**一次性读入：适合输入不太大且以空白分隔的数据**
```python
a = list(map(int, sys.stdin.buffer.read().split()))
```
**一次性读入并迭代：避免立即创建完整的整数列表**
```python
it = map(int, sys.stdin.buffer.read().split())
n, m = next(it), next(it)
a = [next(it) for _ in range(n)]
```
`read().split()` 仍会建立 `bytes` token 列表并占用内存，特别大的输入优先逐行处理
##### 按字节扫描整数
仅适用于合法的空白分隔整数输入，减少拆分后的 token 对象，但 Python 层逐字节循环不一定比 `map(int, ...)` 快
```python
import sys

def ints():
    x = 0
    neg = has = False
    for c in sys.stdin.buffer.read():
        if 48 <= c <= 57:
            x = x * 10 + c - 48
            has = True
        elif has:
            yield -x if neg else x
            x = 0
            neg = has = False
        else:
            neg = c == 45
    if has:
        yield -x if neg else x

it = ints()
# n = next(it)
```
只在输入保证合法整数 token 时使用；大量输入仍全部保存在读取的 `bytes` 对象中
##### 快速输出
```python
a = [1, 2, 3]
print(*a)                                  # 1 2 3
print("YES" if ok else "NO")              # 按条件输出
sys.stdout.write(" ".join(map(str, a)) + "\n")

out = ["YES", "NO"]
sys.stdout.write("\n".join(out) + "\n")

# 很多行输出时，也可定期分批 write，避免积累过多字符串
```
- `print(*a)` 方便，元素特别多时可改为 `join`
- `join` 需要字符串元素，数字序列通常搭配 `map(str, a)`
- 交互题不可延迟刷新
##### 交互题
```python
print("?", x, y, flush=True)
res = int(input())
if res == -1:
    sys.exit()
print("!", ans, flush=True)
```
如使用 `sys.stdout.write()`，询问后调用 `sys.stdout.flush()`
#### 2. 高精度与数学
##### 任意精度整数
```python
a = 10 ** 100
b = int("9" * 100)

x = a + b
x = a - b
x = a * b
x = a // b
x = a % b
q, r = divmod(a, b)
x = a ** 5
x = pow(a, 5, 998244353)   # 模快速幂
```
Python `int` 可以存储任意精度整数，实际受时间、内存与整数/字符串转换限制约束
##### 超长十进制整数的转换限制
较新的 CPython 默认限制部分十进制整数与字符串互转，常见默认上限为 4300 位；部分旧版本安全更新也引入了限制
```python
import sys
if hasattr(sys, "set_int_max_str_digits"):
    sys.set_int_max_str_digits(0)
```
- `0` 表示取消限制，建议仅在可信的竞赛数据确实需要超长十进制转换时使用
- 不仅 `int(s)`，`str(x)`、`print(x)` 也可能受影响
- 二、八、十六进制等以 2 的幂为底的转换不受该十进制位数限制
##### 基础运算与 C++ 差异
| 运算 | Python | 注意事项 |
|---|---|---|
| 加减乘 | `+`、`-`、`*` | 整数自动扩展精度 |
| 真除法 | `/` | 产生浮点结果，不适合精确大整数除法 |
| 整数整除 | `//` | 向负无穷方向取整 |
| 取余 | `%` | 与向下整除匹配 |
| 商和余数 | `divmod(a, b)` | 返回 `(q, r)` |
| 乘方 | `a ** b` | `^` 是异或，不是乘方 |
| 模快速幂 | `pow(a, b, mod)` | `mod != 0` |
| 向上整除 | `-(-a // b)` | `b != 0`，适用于正负除数 |
```python
-7 // 3         # -3，C++ 的 -7 / 3 为 -2
-7 % 3          # 2，C++ 的 -7 % 3 为 -1
```
##### 数学标准库
```python
from math import gcd, factorial, isqrt, comb, perm, prod

gcd(12, 18)          # 6
factorial(10)        # 10!
isqrt(10**100)       # 精确整数平方根
comb(10, 3)          # 120
perm(10, 3)          # 720
prod([2, 3, 4])      # 24

# Python 3.9+
from math import lcm
lcm(12, 18)          # 36
```
`comb`、`perm`、`isqrt`、`prod` 需要 Python 3.8+，`lcm` 需要 Python 3.9+
##### 模逆元与组合数
```python
mod = 998244353
inv = pow(3, -1, mod)        # Python 3.8+
ans = a * pow(b, -1, mod) % mod
ans = pow(2, 10**18, mod)
ans = comb(100, 30) % mod
```
- `pow(b, -1, mod)` 要求 `gcd(b, mod) == 1`，不要求模数为质数
- 逆元不存在时会抛出 `ValueError`
- 大量组合数模查询仍应考虑阶乘与逆阶乘预处理
##### 精确分数和十进制小数
```python
from fractions import Fraction
from decimal import Decimal, getcontext

a = Fraction(1, 3)
b = Fraction(2, 5)
print(a + b)                  # 11/15

getcontext().prec = 50
x = Decimal("0.1")
y = Decimal("0.2")
print(x + y)                  # 0.3
```
- `Fraction` 适用于精确有理数
- `Decimal` 适用于十进制精度控制，应从字符串创建
- 二者运算通常慢于 `int` 或普通 `float`
#### 3. 基础语法速查
##### 循环、条件、赋值
```python
for i in range(n):                 # [0, n)
    pass
for i in range(l, r):              # [l, r)
    pass
for i in range(n - 1, -1, -1):     # 倒序
    pass
for i, x in enumerate(a):
    pass
for x, y in zip(a, b):
    pass

x, y = y, x                       # 交换
x = a if ok else b                 # 条件表达式
if 0 <= x < n:
    pass
if x in st:
    pass
```
`zip(a, b)` 默认在较短序列结束时停止
##### 推导式与生成器
```python
a = [0] * n
b = [i * i for i in range(n)]
c = [x for x in a if x > 0]
d = [[0] * m for _ in range(n)]

s = sum(x * x for x in a)
ok = all(x >= 0 for x in a)
ok = any(x == 0 for x in a)

b = [x for row in d for x in row]   # 展平二维列表
mp = {x: i for i, x in enumerate(a)}
st = {x % 10 for x in a}
```
**二维列表不要使用** `[[0] * m] * n`，这样会让所有行引用同一个列表
##### 切片、拆包与复制
```python
a = [1, 2, 3, 4, 5]
a[-1]             # 最后一个
a[1:4]            # [2, 3, 4]
a[:3]             # 前三个
a[3:]             # 从下标 3 到末尾
a[::-1]           # 逆序副本
a[::2]            # 步长为 2
a[:]              # 浅拷贝

x, y = y, x
x, *mid, y = [1, 2, 3, 4, 5]

def calc(a, b):
    return a + b, a - b
s, d = calc(10, 3)
```
切片一般会创建新对象，避免在大循环里无意复制大量元素
##### 函数、变量作用域、默认参数
```python
def f(x, y=0):
    return x + y

g = lambda x: x * x

def outer():
    cnt = 0
    def dfs():
        nonlocal cnt
        cnt += 1
    dfs()
    return cnt
```
- `nonlocal` 修改外层函数绑定，`global` 修改模块级绑定
- `lambda` 只能包含一个表达式
- 避免 `def f(a=[])` 等可变默认参数，通常改为 `None` 再初始化
##### 现代语法
```python
# Python 3.8+
if (x := len(a)) > 10:
    print(x)

# Python 3.9+，字典合并
c = a | b

# Python 3.10+
match op:
    case "+":
        pass
    case "-":
        pass
    case _:
        pass
```
#### 4. 容器
##### list：动态数组、栈
```python
a = []
a.append(3)
a.extend([4, 5])
x = a.pop()       # 删除最后一个
a.insert(0, 2)    # O(n)
a.remove(3)      # 删除第一个等于 3 的元素
a.count(4)
a.index(4)
a.reverse()
a.clear()
```
`append()`、尾部 `pop()` 均摊 $O(1)$；中间插入、删除通常 $O(n)$
##### deque：队列与双端队列
```python
from collections import deque
q = deque()
q.append(1)
q.appendleft(2)
x = q.popleft()
y = q.pop()
```
两端操作均摊 $O(1)$，BFS 不要用 `list.pop(0)`
##### set：哈希集合
```python
st = set()
st.add(3)
st.discard(3)       # 不存在也不报错
st.remove(3)        # 不存在抛 KeyError

a = {1, 2, 3}
b = {2, 3, 4}
a | b               # 并
a & b               # 交
a - b               # 差
a ^ b               # 对称差
```
`set` 无键排序保证，也不支持按位置下标访问
##### dict：哈希映射
```python
mp = {}
mp["a"] = 3
mp["b"] = 5
x = mp.get("c", 0)
mp.setdefault("d", 0)
mp.pop("a", None)
for k, v in mp.items():
    pass
```
`dict` 保留插入顺序，但不按键排序
##### Counter / defaultdict
```python
from collections import Counter, defaultdict
cnt = Counter([1, 2, 2, 3, 3, 3])
cnt[3]                 # 3
cnt[10]                # 0
cnt.most_common(2)     # [(3, 3), (2, 2)]

mp = defaultdict(int)
mp[5] += 1
g = defaultdict(list)
g[1].append(2)
st = defaultdict(set)
st[1].add(2)
```
#### 5. 排序、二分与堆
##### 排序
```python
a.sort()                             # 原地升序
a.sort(reverse=True)                 # 原地降序
b = sorted(a)                        # 新列表

p = [(2, 5), (1, 8), (2, 3)]
p.sort()                             # 元组字典序
p.sort(key=lambda x: x[1])           # 按第二项升序
p.sort(key=lambda x: (x[0], -x[1]))  # 第一项升序，第二项降序
```
- 排序是稳定的，一般时间复杂度为 $O(n\log n)$
- `a.sort()` 返回 `None`，不能写 `a = a.sort()`
##### bisect：有序序列二分
```python
from bisect import bisect_left, bisect_right, insort

a = [1, 2, 2, 2, 4, 5]
l = bisect_left(a, 2)     # 1
r = bisect_right(a, 2)    # 4
cnt = r - l               # 等于 2 的个数
insort(a, 3)              # 查找 O(log n)，移动 O(n)
```
- `bisect_left(a, x)`：小于 `x` 的元素个数
- `bisect_right(a, x)`：小于等于 `x` 的元素个数
##### heapq：小根堆
```python
from heapq import heappush, heappop, heapify, heappushpop, heapreplace
h = [5, 2, 8]
heapify(h)              # O(n)
heappush(h, 3)          # O(log n)
x = heappop(h)          # 最小值
x = h[0]                # 查看堆顶
x = heappushpop(h, 4)
x = heapreplace(h, 4)
```
大根堆（通用写法）：
```python
h = []
heappush(h, -10)
heappush(h, -30)
x = -heappop(h)      # 30
```
Python 3.14+ 原生大根堆：
```python
from heapq import heapify_max, heappush_max, heappop_max
h = [5, 2, 8]
heapify_max(h)
heappush_max(h, 10)
x = heappop_max(h)
```
旧版 Python / PyPy 不能假定已支持 3.14 的接口
#### 6. itertools 与记忆化
##### 前缀和、排列、组合、笛卡尔积
```python
from itertools import accumulate, permutations, combinations, product

a = [1, 2, 3, 4]
pre = list(accumulate(a, initial=0))
# [0, 1, 3, 6, 10]，Python 3.8+

for p in permutations([1, 2, 3]):
    pass
for p in combinations([1, 2, 3], 2):
    pass
for p in product(range(2), repeat=3):
    pass
```
##### 合并、分组、相邻元素
```python
from itertools import chain, groupby
b = list(chain([1, 2], [3, 4]))
for x, group in groupby(sorted(a)):
    cnt = sum(1 for _ in group)

# Python 3.10+
from itertools import pairwise
list(pairwise([1, 2, 3]))  # [(1, 2), (2, 3)]

# Python 3.12+
from itertools import batched
list(batched(range(5), 2)) # [(0, 1), (2, 3), (4,)]
```
`groupby()` 只将连续相同值分到同一组，全局计数通常要先排序
##### 记忆化搜索
```python
from functools import lru_cache

@lru_cache(None)
def dfs(x):
    if x <= 1:
        return x
    return dfs(x - 1) + dfs(x - 2)

ans = dfs(30)
dfs.cache_clear()        # 多测时按需清缓存
```
Python 3.9+ 可使用 `from functools import cache` 和 `@cache`
#### 7. 字符串、进制、位运算
##### 字符串方法
```python
s = "  abC,def  "
s.strip()
s.lower()
s.upper()
s.replace("a", "x")
s.find("b")               # 找不到返回 -1
s.count("a")
s.startswith("a")
s.endswith("f")

"1 2 3".split()          # ['1', '2', '3']
"a,b,c".split(",")       # ['a', 'b', 'c']
"-".join(["a", "b"])     # 'a-b'
"abc"[::-1]              # 'cba'
ord("a")                  # 97
chr(97)                   # 'a'
```
`str` 不可原地修改，改动较多时先转为 `list`，完成后再 `"".join(a)`
##### bytes 与 str
```python
s = b"abc"
s[0]                    # 97
s.decode()               # 'abc'
"abc".encode()           # b'abc'
a = list(s)              # [97, 98, 99]
```
`sys.stdin.buffer.readline()` 返回 `bytes`，字符串处理时注意类型差异
##### 进制转换
```python
int("101010", 2)        # 42
int("FF", 16)           # 255
int("777", 8)           # 511
bin(42)                 # '0b101010'
oct(42)                 # '0o52'
hex(255)                # '0xff'
format(42, "b")         # '101010'
format(42, "08b")       # '00101010'
format(255, "X")        # 'FF'
f"{42:08b}"             # '00101010'
```
`int(s, base)` 支持 $2\sim36$ 进制，超过 36 进制需自行处理字符表
##### 位运算与整数 bitset
```python
x & y                   # 与
x | y                   # 或
x ^ y                   # 异或（不是乘方）
~x                      # 按位取反
x << k                  # 左移
x >> k                  # 右移
x & -x                  # lowbit
x & (x - 1)             # 删除最低位的 1
(x >> k) & 1            # 取第 k 位
x | (1 << k)            # 设置第 k 位
x ^ (1 << k)            # 翻转第 k 位
x & ~(1 << k)           # 清除第 k 位
x.bit_length()          # 二进制位数
x.bit_count()           # 1 的数量，Python 3.10+
```
遍历置位：
```python
mask = 0b10110
while mask:
    lb = mask & -mask
    i = lb.bit_length() - 1
    mask ^= lb
```
任意精度整数作为位集（0/1 背包可达性）：
```python
f = 1
for x in a:              # 假设所有 x >= 0
    f |= f << x
ok = bool((f >> target) & 1)
```
移位和按位或的复杂度与位集长度有关，并非严格 $O(1)$
#### 8. 常用算法极简写法
##### 前缀和与差分
```python
from itertools import accumulate
pre = list(accumulate(a, initial=0))
ans = pre[r] - pre[l]          # [l, r)

d = [0] * (n + 1)
d[l] += x
d[r] -= x
a = list(accumulate(d))[:n]
```
##### 去重与离散化
```python
b = sorted(set(a))
mp = {x: i for i, x in enumerate(b)}
c = [mp[x] for x in a]
```
##### BFS
```python
from collections import deque

dis = [-1] * n
dis[s] = 0
q = deque([s])
while q:
    u = q.popleft()
    for v in g[u]:
        if dis[v] != -1:
            continue
        dis[v] = dis[u] + 1
        q.append(v)
```
##### Dijkstra
```python
from heapq import heappush, heappop

inf = 10**30            # 必须大于实际可能的有限最短路长度
dis = [inf] * n
dis[s] = 0
q = [(0, s)]
while q:
    d, u = heappop(q)
    if d != dis[u]:
        continue
    for v, w in g[u]:   # (v, w)，w >= 0
        nd = d + w
        if nd < dis[v]:
            dis[v] = nd
            heappush(q, (nd, v))
```
#### 9. 性能、递归与内存
##### 优化方法速查
| 方法 | 适用情况 | 注意事项 |
|---|---|---|
| `sys.stdin.buffer.readline` | 常规大量按行输入 | 得到 `bytes` |
| `sys.stdin.buffer.read().split()` | 大量空白分隔输入 | 整体内存占用较高 |
| `sys.stdout.write()` + `join()` | 大量输出 | 不自动换行 |
| `sum`、`min`、`max`、`sort` | 标准库能够直接处理 | 通常优于手写 Python 循环 |
| `math` 整数函数 | 高精度数学运算 | 留意版本 |
| `deque` | 队列、单调队列 | 两端操作快 |
| PyPy | 较多 Python 层循环、模拟、DP | 启动和内存开销可能更大 |
| 迭代代替深递归 | 深 DFS / 树形问题 | 减少递归栈风险 |
##### 修改递归深度
```python
import sys
sys.setrecursionlimit(10**6)
```
这只提高解释器递归层数限制，不会扩大操作系统栈，设置过高仍可能导致进程崩溃
##### 减少内存占用
```python
vis = bytearray(n)             # 0/1 标记，单元素 1 字节

from array import array
a = array("i", [0]) * n         # 固定类型整数，位宽依平台

vis = 0                        # int 位集
vis |= 1 << i
```
`list[int]` 的对象开销高于 C++ `vector<int>`；`array` 有类型范围限制，不能保存任意大整数
##### 局部绑定与减少重复工作
```python
a = []
push = a.append
for x in range(n):
    push(x)
```
是否加速依赖 Python 解释器版本，建议在目标环境实测，不要优先追求这类微优化
##### 程序计时
```python
from time import perf_counter
import sys
st = perf_counter()

# 被测代码

print(f"[Time] {(perf_counter() - st) * 1000:.3f} ms", file=sys.stderr)
```
正式测速应关闭大规模调试输出
#### 10. Python 与 C++ 易混淆之处
| 场景 | Python | C++ |
|---|---|---|
| 整数 | `int` 任意精度 | `int` / `i64` 固定宽度 |
| 乘方 | `**` | 快速幂或 `pow` |
| 异或 | `^` | `^` |
| 整数除法 | `//` 向下取整 | `/` 向零截断 |
| 取模 | 与向下整除匹配 | 余数符号通常随被除数 |
| 浮点除法 | `/` | 浮点类型的 `/` |
| 逻辑运算 | `and`、`or`、`not` | `&&`、`||`、`!` |
| 布尔值 | `True`、`False` | `true`、`false` |
| 空值 | `None` | `nullptr` / `nullopt` 等 |
| 自增 | `x += 1` | `++x` |
| 条件表达式 | `a if ok else b` | `ok ? a : b` |
| 哈希容器 | `dict`、`set` | `unordered_map`、`unordered_set` |
##### 易忘记的语言细节
```python
if not a:                 # 空容器为假
    pass

a = [1, 2]
b = a                     # 引用同一列表，不是复制

b = a.copy()              # 浅拷贝

from copy import deepcopy
b = deepcopy(a)           # 深拷贝

s = list("abc")
s[0] = "x"
s = "".join(s)           # 'xbc'

# a = a.sort()            # 错误，sort() 返回 None
x = (5,)                  # 单元素元组必须有逗号
True == 1                 # True
```

##### CPython 与 PyPy 选择
- CPython：标准库兼容性通常更明确，许多内置大整数与字符串操作表现良好
- PyPy：部分 Python 层循环、模拟和 DP 可能更快，内存及启动开销可能更大
- Python 的 `-O` 主要影响 `assert` 和 `__debug__`，不等同于 C++ 的 `-O2` / `-O3`
- 两者速度与内存表现因题而异，优先以题目支持的解释器和实测结果为准
