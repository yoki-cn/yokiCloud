### 1.12 Cmake
---
```cmake
cmake_minimum_required(VERSION 3.20)
project(Contest LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS ON)

# ===== 默认：O2 优化，关闭 Warning =====
add_compile_options(-O2 -w)

# ===== 调试 RE：使用时建议将 -O2 改为 -O0 =====
# add_compile_options(-g3 -fsanitize=address,undefined -fno-omit-frame-pointer -fno-sanitize-recover=all)
# add_link_options(-fsanitize=address,undefined)

# ===== STL 越界、非法迭代器等检查（GCC/libstdc++）=====
# add_compile_options(-D_GLIBCXX_DEBUG)

file(GLOB SOURCES CONFIGURE_DEPENDS "*.cpp")

foreach(source IN LISTS SOURCES)
    get_filename_component(name "${source}" NAME_WE)
    add_executable(${name} "${source}")
endforeach()
```
#### 编译选项速查

|参数|作用|
|---|---|
|`-O2`|开启常用编译优化|
|`-w`|关闭所有编译 Warning|
|`-O0`|关闭优化，方便调试|
|`-g3`|生成调试信息，帮助定位源码行号|
|`-fsanitize=address`|检测越界访问、Use After Free 等内存错误|
|`-fsanitize=undefined`|检测有符号整数溢出、非法移位等未定义行为|
|`-fno-omit-frame-pointer`|提高错误调用栈的可读性|
|`-fno-sanitize-recover=all`|检测到运行时错误后立即终止|
|`-D_GLIBCXX_DEBUG`|检测部分 STL 容器和迭代器的非法操作|

推荐使用方式：
- 出现 RE / WA 且怀疑越界或 UB：启用 Sanitizer 两行，将 `-O2` 改为 `-O0`
- 怀疑 STL 使用错误：额外启用 `_GLIBCXX_DEBUG`，但可能显著降低运行速度

注意 Sanitizer 需要编译器和运行时支持，部分 Windows MinGW 工具链可能不支持 AddressSanitizer
