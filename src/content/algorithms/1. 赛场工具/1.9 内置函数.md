### 标准库与内置函数速查
---
#### IO 与格式化
```cpp
cout << fixed << setprecision(9) << x; // 固定 9 位小数
cout << setprecision(9) << x;          // 9 位有效数字
cout << scientific << x;              // 科学计数法
cout << defaultfloat << x;             // 恢复默认浮点格式
cout << hex << x;                      // 十六进制
cout << oct << x;                      // 八进制
cout << dec << x;                      // 十进制
cout << setw(5) << x;                  // 本次输出宽度至少为 5
cout << setfill('0') << setw(5) << x;  // 不足宽度补 0
cout << boolalpha << b;                 // true / false
```
`setw()` 只影响紧随其后的一次输出，其他格式通常持续生效
整行读入：
```cpp
getline(cin >> ws, s);
```
跳过前导空白后读取整行
#### 查找
传统：
```cpp
auto it = find(a.begin(), a.end(), x);
auto it = find_if(a.begin(), a.end(), pred);
auto it = find_if_not(a.begin(), a.end(), pred);
```
C++20 ranges：
```cpp
auto it = ranges::find(a, x);
auto it = ranges::find_if(a, pred);
auto it = ranges::find_if_not(a, pred);
```
谓词示例：
```cpp
auto it = find_if(a.begin(), a.end(), [](int x) {
    return x < 0;
});
auto it = ranges::find_if(a, [](int x) {
    return x < 0;
});
```
- `find`：第一个等于 `x` 的元素
- `find_if`：第一个满足谓词的元素
- `find_if_not`：第一个不满足谓词的元素
- 找不到时返回 `end()`
复杂度：$O(n)$
#### 计数
传统：
```cpp
int c1 = count(a.begin(), a.end(), x);
int c2 = count_if(a.begin(), a.end(), pred);
```
ranges：
```cpp
int c1 = ranges::count(a, x);
int c2 = ranges::count_if(a, pred);
```
谓词示例：
```cpp
int c = ranges::count_if(a, [](int x) {
    return x % 2 == 0;
});
```
复杂度：$O(n)$
#### 全部 / 任意 / 均不满足
传统：
```cpp
bool a1 = all_of(a.begin(), a.end(), pred);
bool a2 = any_of(a.begin(), a.end(), pred);
bool a3 = none_of(a.begin(), a.end(), pred);
```
ranges：
```cpp
bool a1 = ranges::all_of(a, pred);
bool a2 = ranges::any_of(a, pred);
bool a3 = ranges::none_of(a, pred);
```
示例：
```cpp
bool ok = ranges::all_of(a, [](int x) {
    return x >= 0;
});
```
最坏复杂度：$O(n)$，支持短路
#### 最值位置
传统：
```cpp
auto mn = min_element(a.begin(), a.end());
auto mx = max_element(a.begin(), a.end());
auto [mn, mx] = minmax_element(a.begin(), a.end());
```
ranges：
```cpp
auto mn = ranges::min_element(a);
auto mx = ranges::max_element(a);
auto [mn, mx] = ranges::minmax_element(a);
```
自定义比较：
```cpp
auto cmp = [](int x, int y) {
    return abs(x) < abs(y);
};

auto it1 = min_element(a.begin(), a.end(), cmp);
auto it2 = ranges::min_element(a, cmp);
```
复杂度：$O(n)$
#### 有序范围二分
传统：
```cpp
auto l = lower_bound(a.begin(), a.end(), x); // 第一个 >= x
auto r = upper_bound(a.begin(), a.end(), x); // 第一个 > x
bool ok = binary_search(a.begin(), a.end(), x);
auto [l2, r2] = equal_range(a.begin(), a.end(), x);
```
ranges：
```cpp
auto l = ranges::lower_bound(a, x);
auto r = ranges::upper_bound(a, x);
bool ok = ranges::binary_search(a, x);
auto [l2, r2] = ranges::equal_range(a, x);
```
降序数组：
```cpp
ranges::sort(a, greater{});

auto it1 = lower_bound(a.begin(), a.end(), x, greater{});
auto it2 = ranges::lower_bound(a, x, greater{});
```
必须使用与排序相同的比较规则
复杂度：
- 比较次数 $O(\log n)$
- 非随机访问迭代器可能仍需要 $O(n)$ 次迭代器移动
#### partition_point
对于已经按谓词分成 `true...false` 的范围：
传统：
```cpp
auto it = partition_point(a.begin(), a.end(), pred);
```
ranges：
```cpp
auto it = ranges::partition_point(a, pred);
```
示例：
```cpp
auto it = ranges::partition_point(a, [](int x) {
    return x < 10;
});
```
返回第一个使谓词为 `false` 的位置
复杂度：
- $O(\log n)$ 次谓词判断
- 非随机访问迭代器可能有 $O(n)$ 次移动
#### 排序
传统：
```cpp
sort(a.begin(), a.end());
stable_sort(a.begin(), a.end());
```
ranges：
```cpp
ranges::sort(a);
ranges::stable_sort(a);
```
降序：
```cpp
sort(a.begin(), a.end(), greater{});
ranges::sort(a, greater{});
```
自定义比较：
```cpp
auto cmp = [](const auto &a, const auto &b) {
    if (a.first != b.first) return a.first < b.first;
    return a.second > b.second;
};

sort(a.begin(), a.end(), cmp);
ranges::sort(a, cmp);
```
复杂度：
- `sort`：$O(n\log n)$
- `stable_sort`：通常 $O(n\log n)$，额外内存不足时实现可能退化到 $O(n\log^2 n)$
`stable_sort` 保持等价元素原来的相对顺序
#### ranges 投影
`ranges` 可以直接按成员操作，无需 lambda：
```cpp
struct Node {
    int x, y;
};
ranges::sort(a, {}, &Node::x);
auto it = ranges::lower_bound(a, v, {}, &Node::x);
auto it = ranges::min_element(a, {}, &Node::x);
```
降序：
```cpp
ranges::sort(a, greater{}, &Node::x);
```
传统 STL 没有投影参数，需要 lambda：
```cpp
sort(a.begin(), a.end(), [](const Node &a, const Node &b) {
    return a.x < b.x;
});
```
复杂度与对应算法相同
#### 第 k 小
传统：
```cpp
nth_element(a.begin(), a.begin() + k, a.end());
auto x = a[k];
```
ranges：
```cpp
ranges::nth_element(a, a.begin() + k);
auto x = a[k];
```
自定义比较：
```cpp
nth_element(a.begin(), a.begin() + k, a.end(), greater{});
ranges::nth_element(a, a.begin() + k, greater{});
```
此时 `a[k]` 为第 `k` 大
执行后只保证：
- `a[k]` 是完整排序后的第 `k` 个元素
- 左侧元素不大于它
- 右侧元素不小于它
- 两侧内部不保证有序
平均复杂度：$O(n)$
#### 前 k 小并排序
传统：
```cpp
partial_sort(a.begin(), a.begin() + k, a.end());
```
ranges：
```cpp
ranges::partial_sort(a, a.begin() + k);
```
降序：
```cpp
partial_sort(a.begin(), a.begin() + k, a.end(), greater{});
ranges::partial_sort(a, a.begin() + k, greater{});
```
此时得到前 `k` 大并排序
复杂度：
$$
O(n\log k)
$$
#### next_permutation / prev_permutation
传统：
```cpp
bool ok = next_permutation(a.begin(), a.end());
bool ok = prev_permutation(a.begin(), a.end());
```
ranges：
```cpp
bool ok = ranges::next_permutation(a).found;
bool ok = ranges::prev_permutation(a).found;
```
自定义比较：
```cpp
bool ok1 = next_permutation(a.begin(), a.end(), greater{});
bool ok2 = ranges::next_permutation(a, greater{}).found;
```
`next_permutation`：
- 成功时变为下一个字典序排列并返回 `true`
- 已是最大排列时变回最小排列并返回 `false`
枚举全部不同排列：
```cpp
sort(a.begin(), a.end());
do {
    // a
} while (next_permutation(a.begin(), a.end()));
```
ranges：
```cpp
ranges::sort(a);
do {
    // a
} while (ranges::next_permutation(a).found);
```
即使有重复元素，从最小排列开始也只会枚举不同的值排列
单次复杂度：$O(n)$
#### is_permutation
传统：
```cpp
bool ok = is_permutation(a.begin(), a.end(), b.begin(), b.end());
```
ranges：
```cpp
bool ok = ranges::is_permutation(a, b);
```
自定义等价关系：
```cpp
auto eq = [](int x, int y) {
    return abs(x) == abs(y);
};
bool ok1 = is_permutation(a.begin(), a.end(), b.begin(), b.end(), eq);
bool ok2 = ranges::is_permutation(a, b, eq);
```
最坏复杂度：$O(n^2)$
#### remove / remove_if
传统：
```cpp
a.erase(remove(a.begin(), a.end(), x), a.end());
a.erase(remove_if(a.begin(), a.end(), [](int x) {
    return x < 0;
}), a.end());
```
C++20 可以直接：
```cpp
erase(a, x);

erase_if(a, [](int x) {
    return x < 0;
});
```
`remove / remove_if` 本身只把保留元素移动到前面，并不会真正改变容器大小
对于 `vector/string/deque`，整体复杂度通常为 $O(n)$
#### rotate
传统：
```cpp
rotate(a.begin(), a.begin() + k, a.end());
```
ranges：
```cpp
ranges::rotate(a, a.begin() + k);
```
例如：
```cpp
vector<int> a{1, 2, 3, 4, 5};
ranges::rotate(a, a.begin() + 2);
// 3 4 5 1 2
```
即把 `[0,k)` 搬到末尾
复杂度：$O(n)$
#### shift_left / shift_right
C++20：
```cpp
shift_left(a.begin(), a.end(), k);
shift_right(a.begin(), a.end(), k);
```
移动后空出的元素值不应继续依赖
复杂度：$O(n)$
#### shuffle
传统：
```cpp
shuffle(a.begin(), a.end(), rng);
```
ranges：
```cpp
ranges::shuffle(a, rng);
```
例如：
```cpp
mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
ranges::shuffle(a, rng);
```
复杂度：$O(n)$
#### transform
一元版本：
传统：
```cpp
transform(a.begin(), a.end(), b.begin(), [](int x) {
    return x * x;
});
```
ranges：
```cpp
ranges::transform(a, b.begin(), [](int x) {
    return x * x;
});
```
二元版本：
传统：
```cpp
transform(a.begin(), a.end(), b.begin(), c.begin(),
    [](int x, int y) {
        return x + y;
    }
);
```
ranges：
```cpp
ranges::transform(a, b, c.begin(),
    [](int x, int y) {
        return x + y;
    }
);
```
复杂度：$O(n)$
#### merge
两个输入必须有序
传统：
```cpp
vector<int> c;
merge(a.begin(), a.end(), b.begin(), b.end(), back_inserter(c));
```
ranges：
```cpp
vector<int> c;
ranges::merge(a, b, back_inserter(c));
```
自定义比较：
```cpp
ranges::merge(a, b, back_inserter(c), greater{});
```
此时两个输入也必须已经按降序排列
复杂度：
$$
O(n+m)
$$
#### inplace_merge
若 `[first,mid)` 与 `[mid,last)` 已分别有序：
传统：
```cpp
inplace_merge(a.begin(), a.begin() + k, a.end());
```
ranges：
```cpp
ranges::inplace_merge(a, a.begin() + k);
```
自定义比较：
```cpp
ranges::inplace_merge(a, a.begin() + k, greater{});
```
复杂度：
- 有足够辅助空间时约 $O(n)$
- 否则可达到 $O(n\log n)$
#### 有序集合运算
两个输入都必须按相同比较方式排序
传统：
```cpp
set_union(a.begin(), a.end(), b.begin(), b.end(), back_inserter(c));
set_intersection(a.begin(), a.end(), b.begin(), b.end(), back_inserter(c));
set_difference(a.begin(), a.end(), b.begin(), b.end(), back_inserter(c));
set_symmetric_difference(a.begin(), a.end(), b.begin(), b.end(), back_inserter(c));
```
ranges：
```cpp
ranges::set_union(a, b, back_inserter(c));
ranges::set_intersection(a, b, back_inserter(c));
ranges::set_difference(a, b, back_inserter(c));
ranges::set_symmetric_difference(a, b, back_inserter(c));
```
降序：
```cpp
ranges::set_intersection(a, b, back_inserter(c), greater{});
```
复杂度：$O(n+m)$
这些函数按**有序多重集合**语义处理重复元素
#### includes
判断有序多重集合 `a` 是否包含 `b`
传统：
```cpp
bool ok = includes(a.begin(), a.end(), b.begin(), b.end());
```
ranges：
```cpp
bool ok = ranges::includes(a, b);
```
自定义比较：
```cpp
bool ok = ranges::includes(a, b, greater{});
```
两个范围也必须按 `greater{}` 排序
复杂度：$O(n+m)$
#### partial_sum
```cpp
partial_sum(a.begin(), a.end(), pre.begin());
```
得到：
```text
pre[i] = a[0] + ... + a[i]
```
常见 `pre[0] = 0`：
```cpp
vector<i64> pre(a.size() + 1);
partial_sum(a.begin(), a.end(), pre.begin() + 1);
```
自定义运算：
```cpp
partial_sum(a.begin(), a.end(), pre.begin(), multiplies{});
```
复杂度：$O(n)$
#### inclusive_scan / exclusive_scan
C++17：
```cpp
inclusive_scan(a.begin(), a.end(), pre.begin());
exclusive_scan(a.begin(), a.end(), pre.begin(), 0LL);
```
`inclusive_scan`：
```text
a0
a0+a1
a0+a1+a2
```
`exclusive_scan`：
```text
init
init+a0
init+a0+a1
```
自定义运算：
```cpp
inclusive_scan(a.begin(), a.end(), pre.begin(), multiplies{});
```
复杂度：$O(n)$
#### adjacent_difference
```cpp
adjacent_difference(a.begin(), a.end(), d.begin());
```
得到：
```text
d[0] = a[0]
d[i] = a[i] - a[i - 1]
```
自定义运算：
```cpp
adjacent_difference(a.begin(), a.end(), d.begin(),
    [](i64 x, i64 y) {
        return x ^ y;
    }
);
```
复杂度：$O(n)$
#### inner_product
```cpp
i64 ans = inner_product(
    a.begin(), a.end(),
    b.begin(),
    0LL
);
```
默认计算：
$$
\sum_i a_i b_i
$$
也可以自定义两个运算：
```cpp
auto ans = inner_product(
    a.begin(), a.end(), b.begin(), 0LL,
    plus{}, multiplies{}
);
```
复杂度：$O(n)$
#### midpoint
C++20：
```cpp
auto m = midpoint(l, r);
```
避免 `(l + r) / 2` 的加法溢出
整数不能整除时向第一个参数方向取整
复杂度：$O(1)$
#### lerp
C++20：
```cpp
double x = lerp(a, b, t);
```
表示线性插值：
$$
a+t(b-a)
$$
复杂度：$O(1)$
#### size / ssize / empty / data
```cpp
size(a);
ssize(a); // C++20，有符号
empty(a);
data(a);
```
也适用于普通数组：
```cpp
int a[10];
int n = size(a);
```
通常均为 $O(1)$
#### map / set contains
C++20：
```cpp
if (s.contains(x)) {}
if (mp.contains(key)) {}
```
传统：
```cpp
if (s.find(x) != s.end()) {}
if (mp.find(key) != mp.end()) {}
```
如果还需要迭代器或对应值，直接使用 `find`
复杂度：
- `map/set`：$O(\log n)$
- `unordered_map/unordered_set`：均摊 $O(1)$，最坏 $O(n)$
#### map try_emplace
仅不存在时插入：
```cpp
mp.try_emplace(key, value);
```
不存在则插入，存在则覆盖：
```cpp
mp.insert_or_assign(key, value);
```
`mp[key]`：
```cpp
auto &x = mp[key];
```
若 `key` 不存在会自动插入默认值
复杂度：
- `map`：$O(\log n)$
- `unordered_map`：均摊 $O(1)$
#### 字符判断
```cpp
isdigit(c)
isalpha(c)
isalnum(c)
islower(c)
isupper(c)
isspace(c)
```
转换：
```cpp
tolower(c)
toupper(c)
```
严格写法：
```cpp
isdigit((unsigned char)c);
tolower((unsigned char)c);
```
除 `EOF` 外，不应把负的 `char` 直接传入 `<cctype>` 函数
复杂度：$O(1)$
#### string 查找
```cpp
s.find(t)
s.rfind(t)
s.find_first_of(t)
s.find_last_of(t)
s.find_first_not_of(t)
s.find_last_not_of(t)
```
找不到返回：
```cpp
string::npos
```
例如：
```cpp
if (s.find(t) != string::npos) {}
```
注意：
```cpp
s.find_first_of("abc")
```
查找的是字符 `'a'/'b'/'c'` 中任意一个，不是子串 `"abc"`
单字符查询通常 $O(n)$，子串查找最坏可达到 $O(nm)$
#### string 前后缀
C++20：
```cpp
s.starts_with("abc");
s.ends_with("xyz");
```
C++23：
```cpp
s.contains("abc");
```
C++20 判断包含：
```cpp
s.find("abc") != string::npos
```
`starts_with/ends_with` 复杂度 $O(m)$，其中 `m` 为模式长度
#### 字符串与数字转换
```cpp
int x = stoi(s);
i64 x = stoll(s);
u64 x = stoull(s);
double x = stod(s);

string s = to_string(x);
```
指定进制：
```cpp
int x = stoi(s, nullptr, 16);
i64 x = stoll(s, nullptr, 2);
```
获得停止解析的位置：
```cpp
size_t p;
int x = stoi(s, &p);
```

复杂度：$O(|s|)$
#### stringstream
```cpp
stringstream ss(s);

int x;
while (ss >> x) {
    // x
}
```
混合类型：
```cpp
string name;
int x;
ss >> name >> x;
```
完整解析一遍通常为 $O(|s|)$，常数明显高于直接字符处理
#### 浮点取整
```cpp
floor(x) // 向 -inf
ceil(x)  // 向 +inf
trunc(x) // 向 0
round(x) // 最近整数，正好一半时远离 0
```
例如：
```text
x       floor  ceil  trunc  round
 1.7      1      2      1      2
-1.7     -2     -1     -1     -2
```
均视为 $O(1)$
#### atan2
```cpp
ld ang = atan2(y, x);
```
返回 `(x,y)` 与正 `x` 轴的有向夹角，范围约为：
$$
[-\pi,\pi]
$$
比 `atan(y / x)` 更适合几何，因为可以自动处理象限和 `x = 0`
视为 $O(1)$
#### hypot
```cpp
auto d = hypot(x, y);
```
等价目标：
$$
\sqrt{x^2+y^2}
$$
C++17：
```cpp
hypot(x, y, z);
```
相比直接写 `sqrt(x*x+y*y)` 更不容易产生中间溢出 / 下溢
视为 $O(1)$
#### fmod
```cpp
auto r = fmod(x, y);
```
结果等价于：
$$
x-\operatorname{trunc}(x/y)y
$$
结果符号跟 `x` 一致：
```cpp
fmod(-5.0, 3.0) // -2
```
要求 `[0,y)`：
```cpp
x = fmod(x, y);
if (x < 0) x += y;
```
视为 $O(1)$
#### isnan / isinf / isfinite / signbit
```cpp
isnan(x)
isinf(x)
isfinite(x)
signbit(x)
```
分别判断 NaN、无穷、有限值和符号位
视为 $O(1)$
#### copysign
```cpp
auto x = copysign(a, b);
```
绝对值来自 `a`，符号来自 `b`
视为 $O(1)$
#### fma
```cpp
auto x = fma(a, b, c);
```
计算：
$$
ab+c
$$
在支持融合乘加时只进行一次最终舍入
视为 $O(1)$
#### π
C++20：
```cpp
ld pi = numbers::pi_v<ld>;
```
传统：
```cpp
ld pi = acosl(-1);
```
#### views::iota
C++20：
```cpp
for (int x : views::iota(l, r)) {
    // l <= x < r
}
```
创建视图 $O(1)$，遍历 $O(r-l)$
#### views::reverse
```cpp
for (auto x : a | views::reverse) {
    // ...
}
```
创建视图 $O(1)$，完整遍历 $O(n)$
传统反向遍历：
```cpp
for (auto it = a.rbegin(); it != a.rend(); ++ it) {
```

#### views::filter
```cpp
for (auto x : a | views::filter([](int x) {
    return x % 2 == 0;
})) {
    // 偶数
}
```
完整遍历最坏 $O(n)$ 次谓词判断
传统：
```cpp
for (auto x : a) {
    if (x % 2 == 0) {
        // ...
    }
}
```
#### views::transform
```cpp
for (auto x : a | views::transform([](int x) {
    return x * x;
})) {
    // x 为平方后的值
}
```
惰性计算，创建视图 $O(1)$，完整遍历 $O(n)$ 次转换
传统通常直接：
```cpp
for (auto x : a) {
    auto y = x * x;
}
```
#### pair / tuple 解包
```cpp
auto [x, y] = p;
```
赋值：
```cpp
tie(x, y) = p;
```
忽略部分：
```cpp
tie(x, ignore, z) = t;
```

均为常数级操作，不计成员自身复制 / 移动成本
#### exchange
```cpp
auto old = exchange(x, y);
```
等价于：
```cpp
auto old = x;
x = y;
```
复杂度取决于对象自身复制 / 移动，标量类型为 $O(1)$
