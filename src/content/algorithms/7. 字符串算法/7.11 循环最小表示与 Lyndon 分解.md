### 循环最小表示与 Lyndon 分解
---
#### Booth 最小表示
```cpp
template<class Seg>
int minimum_rotation(const Seg &s) {
    int n = s.size();
    if (!n) return 0;
    int i{ 0 }, j{ 1 }, k{ 0 };
    while (i < n && j < n && k < n) {
        const auto &a{ s[(i + k) % n] };
        const auto &b{ s[(j + k) % n] };
        if (a == b) {
            ++ k;
            continue;
        }
        if (a > b) i += k + 1;
        else j += k + 1;
        if (i == j) ++ j;
        k = 0;
    }
    return min(i, j);
}
template<class Seg>
auto minimum_rotation_sequence(const Seg &s) {
    using T = decay_t<decltype(s[0])>;
    int n = s.size(), p{ minimum_rotation(s) };
    vector<T> res;
    res.reserve(n);
    for (int i = 0; i < n; ++ i) {
        res.push_back(s[(p + i) % n]);
    }
    return res;
}
```
#### 循环同构标准化
```cpp
template<class Seg>
auto canonical_cycle(const Seg &s, bool allow_reverse = false) {
    using T = decay_t<decltype(s[0])>;
    vector<T> a(s.size());
    for (int i = 0; i < s.size(); ++ i) a[i] = s[i];
    vector<T> ans{ minimum_rotation_sequence(a) };
    if (allow_reverse) {
        ranges::reverse(a);
        ans = min(ans, minimum_rotation_sequence(a));
    }
    return ans;
}
```
#### Duval Lyndon 分解
```cpp
template<class Seg>
vector<pair<int, int>> lyndon_factorization(const Seg &s) {
    int n = s.size();
    vector<pair<int, int>> res;
    for (int i = 0; i < n;) {
        int j{ i + 1 }, k{ i };
        while (j < n && s[k] <= s[j]) {
            if (s[k] < s[j]) k = i;
            else ++ k;
            ++ j;
        }
        int len{ j - k };
        while (i <= k) {
            res.push_back({ i, i + len });
            i += len;
        }
    }
    return res;
}
```
#### 接口说明
- `minimum_rotation(s)`：返回字典序最小循环移位的起始下标，$O(n)$
- `minimum_rotation_sequence(s)`：返回字典序最小循环表示，$O(n)$
- `canonical_cycle(s,false)`：返回只允许旋转时的标准表示，$O(n)$
- `canonical_cycle(s,true)`：允许旋转和整体反向时的标准表示，$O(n)$
- `lyndon_factorization(s)`：返回 Duval / Chen–Fox–Lyndon 分解的 `[l,r)` 区间，$O(n)$
`Seg` 只需要：
- `size()`
- `operator[]`
- 元素支持 `==`、`<` / `<=`
可以直接处理：
```cpp
string
vector<int>
vector<pair<int, int>>
```
等可字典序比较的广义字符串
#### 注意事项
- 所有位置和区间均为 `0base`
- 空序列的最小表示起点定义为 `0`
- `minimum_rotation()` 返回的是原序列中的起点，不会实际修改序列
- 当最小循环表示存在多个相同起点时，该实现返回其中最小的下标
- 循环最小表示和“字典序最小后缀”不是同一个问题
- `canonical_cycle(..., true)` 表示允许整个环反向后再任意旋转，适用于无方向环同构
- 若题目只允许旋转，不能错误地开启 `allow_reverse`
- Lyndon 分解和普通“按最小字符切分”没有关系，应直接使用 Duval
- Lyndon 分解的因子区间彼此首尾相接，覆盖整个字符串
- 这里使用的是通常的字典序；若题目字符顺序特殊，应先映射为正确的比较顺序
#### 常见用法
##### 得到最小循环表示
```cpp
int p{ minimum_rotation(s) };
rotate(s.begin(), s.begin() + p, s.end());
```
或者不修改原串：
```cpp
auto t = minimum_rotation_sequence(s);
```
##### 判断两个字符串是否循环同构
```cpp
bool same{ a.size() == b.size() && canonical_cycle(a) == canonical_cycle(b) };
```
这是**确定性**的 $O(n)$ 判定，不需要哈希
##### 无方向环 / 雪花同构
如果一个环正向、反向都视为同一个对象：
```cpp
auto key = canonical_cycle(a, true);
```
然后：
```cpp
set<vector<int>> st;
st.insert(key);
```
即可对环进行标准化去重
典型场景：
- 雪花
- 多边形边标签环
- 环形排列
- 无方向循环序列
##### 周期串的多个最小表示
如果字符串具有周期，则可能有多个位置产生完全相同的最小循环表示
例如：
```text
abab
```
起点 `0` 和 `2` 都得到：
```text
abab
```
`minimum_rotation()` 返回最小起点 `0`
因此：
> “最小表示字符串”唯一，但对应的起点不一定唯一

##### Lyndon 分解
```cpp
auto fac = lyndon_factorization(s);
for (auto [l, r] : fac) {
    // s[l..r) 是一个 Lyndon word
}
```
Chen–Fox–Lyndon 定理给出唯一分解：
$$\boxed{ s=w_1w_2\cdots w_k }$$
其中每个 $w_i$ 都是 Lyndon word，并且：
$$\boxed{ w_1\ge w_2\ge\cdots\ge w_k }$$
按字典序非增排列
##### 判断整个字符串是否为 Lyndon word
对于非空字符串：
```cpp
auto fac = lyndon_factorization(s);
bool is_lyndon{ fac.size() == 1 };
```
##### Lyndon word 的核心性质
非空字符串 $w$ 是 Lyndon word，当且仅当它严格小于自己的任意非平凡循环移位。
因此 Lyndon word 一定是**本原串**，即不存在：
$$w=x^k,\qquad k>1$$
反过来，如果一个字符串是本原串，那么它的字典序最小循环表示一定是一个 Lyndon word
所以 Booth 最小表示与 Lyndon 之间有关系，但解决的问题不同：
- Booth：在一个循环同构类里找最小代表
- Duval：把任意线性字符串唯一分解成 Lyndon words
##### 分解区间恢复
```cpp
for (auto [l, r] : lyndon_factorization(s)) {
    string part{ s.substr(l, r - l) };
}
```
如果只需要边界而不是复制子串，保留 `[l,r)` 会比直接返回 `vector<string>` 更省空间
#### 二级结论
##### 循环同构标准形
定义：
$$C(s)=\min_{0\le i<n}\operatorname{rotate}(s,i)$$
那么：
$$\boxed{ a,b\text{ 循环同构} \iff C(a)=C(b) }$$
因此最小表示可以直接作为循环对象的哈希前标准化、排序键或 `map/set` 键
##### 允许翻转时
定义：
$$D(s)=\min(C(s),C(reverse(s)))$$
则：
$$\boxed{ D(a)=D(b) }$$
当且仅当两者可以通过：
- 任意旋转
- 可选的一次整体反向
互相得到
##### Lyndon 与最小旋转
如果 $s$ 是本原串，则：
$$\boxed{ minimum\_rotation(s) }$$
得到的字符串一定是 Lyndon word
若 $s$ 不是本原串，则其最小表示可能是某个 Lyndon word 的幂
#### 复杂度
设字符串长度为 $n$

|操作|时间复杂度|
|---|--:|
|`minimum_rotation()`|$O(n)$|
|`minimum_rotation_sequence()`|$O(n)$|
|`canonical_cycle()`|$O(n)$|
|`lyndon_factorization()`|$O(n)$|
除输出结果外：
- Booth 额外空间：$O(1)$
- Lyndon 分解保存区间：$O(k)$，其中 `k` 为因子数
- `canonical_cycle()`：$O(n)$
