### Manacher
---
```cpp
struct Manacher {
    int n;
    vector<int> r;
    template<class Seg>
    explicit Manacher(const Seg &s) : n(int(s.size())) {
        int m{ 2 * n + 1 };
        r.assign(m, 0);
        // 虚拟串为 #s[0]#s[1]#...#s[n-1]#：
        // 偶数位置是分隔符，奇数位置是原串字符
        auto equal = [&](int x, int y) {
            if ((x & 1) != (y & 1)) return false;
            return !(x & 1) || s[x / 2] == s[y / 2];
        };
        for (int i = 0, p = 0; i < m; ++ i) {
            if (i < p + r[p]) r[i] = min(r[2 * p - i], p + r[p] - i);
            while (i - r[i] >= 0 && i + r[i] < m && equal(i - r[i], i + r[i])) ++ r[i];
            if (i + r[i] > p + r[p]) p = i;
        }
    }
    // ===== 基础查询：全部只依赖 r，可按需删除 =====
    // 以虚拟位置 c 为中心的最长回文子串长度
    int longest_at(int c) const { return r[c] - 1; }
    // 以虚拟位置 c 为中心的回文子串个数
    int count_at(int c) const { return r[c] / 2; }
    int longest() const { return *max_element(r.begin(), r.end()) - 1; }
    pair<int, int> longest_segment() const {
        int best{ 0 }, l{ 0 };
        for (int c = 0; c < r.size(); ++ c) {
            int len{ longest_at(c) };
            if (len > best) {
                best = len;
                l = (c - len) / 2;
            }
        }
        return { l, l + best };
    }
    i64 count() const {
        i64 ans{ 0 };
        for (int c = 0; c < r.size(); ++ c) ans += count_at(c);
        return ans;
    }
    bool is_pal(int l, int rr) const {
        if (l < 0 || l > rr || rr > n) return false;
        return r[l + rr] > rr - l;
    }
    // ===== 全部枚举：输出规模可能达到 O(n^2)，不需要时可删除 =====
    vector<pair<int, int>> enumerate() const {
        vector<pair<int, int>> res;
        for (int c = 0; c < r.size(); ++ c) {
            for (int len = (c & 1 ? 1 : 2); len < r[c]; len += 2) {
                int l{ (c - len) / 2 };
                res.push_back({ l, l + len });
            }
        }
        return res;
    }
};
```
#### 成员变量
- `n`：原串长度
- `r[c]`：虚拟串中以 `c` 为中心的回文半径
- 虚拟串为 `#s[0]#s[1]#...#s[n-1]#`
- 虚拟位置 `2i + 1` 对应原串字符 `s[i]`
- 虚拟偶数位置对应字符之间的空隙
#### 接口
- `Manacher(s)`：预处理所有回文中心，$O(n)$
- `longest_at(c)`：以虚拟中心 `c` 为中心的最长回文子串长度，$O(1)$
- `count_at(c)`：以虚拟中心 `c` 为中心的回文子串个数，$O(1)$
- `longest()`：最长回文子串长度，$O(n)$
- `longest_segment()`：返回一个最长回文子串区间 `[l,r)`，$O(n)$
- `count()`：回文子串出现次数总和，$O(n)$
- `is_pal(l,r)`：判断 `[l,r)` 是否为回文，$O(1)$
- `enumerate()`：枚举所有回文子串区间 `[l,r)`，$O(K)$，其中 $K$ 为回文子串出现次数
#### 注意事项
- 所有原串区间均为 `0base` 的 `[l,r)
- 实现没有真的向原串插入特殊字符，因此 `Seg` 只要求支持 `size()`、`operator[]` 和元素相等比较
- `r[c]` 是虚拟串半径，不是原串回文长度
- `longest_at(c) = r[c] - 1`
- `count_at(c) = r[c] / 2`
- `count()` 统计的是**回文子串出现次数**，不是本质不同回文串数量；后者应使用 PAM
- `enumerate()` 最坏会产生 $\Theta(n^2)$ 个区间，因此不可能保证线性复杂度
- 空串 `[l,l)` 会被 `is_pal()` 判为回文
#### 常见用法
##### 最长回文子串
```cpp
Manacher man(s);
int len{ man.longest() };
auto [l, r] = man.longest_segment();
cout << s.substr(l, r - l) << '\n';
```
##### $O(1)$ 判断任意区间是否为回文
对于原串区间 `[l,r)`：
$$c=l+r,\quad len=r-l$$
它是回文当且仅当：
$$\boxed{r[c]>len}$$
因此：
```cpp
if (man.is_pal(l, r)) {
    // s[l..r) 是回文串
}
```
这个接口特别适合：
- 区间 DP
- 回文分割
- 枚举切分点后快速判断两侧是否回文
- 与哈希 / DP 配合
##### 一个中心对应哪些回文串
对于虚拟中心 `c`，最长回文长度为：
```cpp
int mx{ man.r[c] - 1 };
```
该中心下所有回文长度依次为：
- `c` 为奇数：`1, 3, 5, ..., mx`
- `c` 为偶数：`2, 4, 6, ..., mx`
所以一个中心贡献的回文子串个数为：
$$\boxed{\left\lfloor\frac{r[c]}2\right\rfloor}$$
进一步：
$$\boxed{ \text{所有回文子串出现次数} = \sum_c\left\lfloor\frac{r[c]}2\right\rfloor }$$
这就是 `count()`
##### 统计长度恰好为 $L$ 的回文子串
长度为 `L` 的区间 `[l,l+L)` 的虚拟中心为：
$$c=2l+L$$
因此长度恰好为 `L` 的回文子串数量，就是满足：
$$c\equiv L\pmod 2,\qquad r[c]>L$$
的中心数量
直接扫描：
```cpp
int ans{ 0 };
for (int c = L & 1; c < man.r.size(); c += 2) {
    ans += man.r[c] > L;
}
```
若要回答大量不同长度的查询，可以进一步离线统计半径
##### 最长回文前缀 / 后缀
预处理后直接枚举端点：
```cpp
int pre{ 0 };
for (int r = 1; r <= s.size(); ++ r) {
    if (man.is_pal(0, r)) pre = r;
}
int suf{ int(s.size()) };
for (int l = s.size(); l >= 0; -- l) {
    if (man.is_pal(l, s.size())) suf = l;
}
```
得到：
- 最长回文前缀：`s[0..pre)`
- 最长回文后缀：`s[suf..n)`
#### 复杂度

| 操作                                                            |  时间复杂度 |
| ------------------------------------------------------------- | -----: |
| `Manacher(s)` / `longest()` / `longest_segment()` / `count()` | $O(n)$ |
| `longest_at(c)` / `count_at(c)` / `is_pal(l,r)`               | $O(1)$ |
| `enumerate()`                                                 | $O(K)$ |
其中 $K$ 为所有回文子串出现次数，最坏为 $\Theta(n^2)$
空间复杂度：$O(n)$
