### 子序列自动机
---
```cpp
template<int A = 26, int offset = 'a'>
struct SubseqAutomaton {
    int n{ 0 };
    vector<array<int, A>> next;
    SubseqAutomaton() = default;
    template<class Seg>
    explicit SubseqAutomaton(const Seg &s) { build(s); }
    template<class T>
    static int id(const T &c) { return int(c) - offset; }
    template<class Seg>
    void build(const Seg &s) {
        n = s.size();
        next.resize(n + 1);
        next[n].fill(n);
        for (int i = n - 1; i >= 0; -- i) {
            next[i] = next[i + 1];
            next[i][id(s[i])] = i;
        }
    }
    // 从原串位置 p 开始，返回字符 c 第一次出现的位置；
    // 不存在时返回 n。
    template<class T>
    int step(int p, const T &c) const { return next[p][id(c)]; }
    // 从原串位置 p 开始匹配 s。
    // 成功返回最后一个匹配位置的后一位，失败返回 -1。
    template<class Seg>
    int match(const Seg &s, int p = 0) const {
        for (const auto &c : s) {
            if (p >= n) return -1;
            int q{ step(p, c) };
            if (q == n) return -1;
            p = q + 1;
        }
        return p;
    }
    template<class Seg>
    bool contains(const Seg &s) const { return match(s) != -1; }
};
```
#### 成员变量
- `n`：原串长度
- `next[p][c]`：原串中下标不小于 `p` 的位置里，字符 `c` 第一次出现的位置；不存在时为 `n`
- 状态 `p` 表示：**下一次允许从原串位置 `p` 开始寻找**
#### 接口
- `SubseqAutomaton(s)`：直接对原串 `s` 建表，$O(nA)$
- `build(s)`：重新对原串 `s` 建表，$O(nA)$
- `step(p,c)`：查询从位置 `p` 开始字符 `c` 的第一次出现位置，$O(1)$
- `match(t,p)`：判断 `t` 能否作为原串后缀区间 `[p,n)` 的子序列；成功返回最后一次匹配位置的后一位，失败返回 `-1`，$O(|t|)$
- `contains(t)`：判断 `t` 是否为整个原串的子序列，$O(|t|)$
#### 注意事项
- 这里最重要的是状态含义：`p` 表示**下一次搜索的起始下标**，不是“当前已经匹配到的位置”
- `step(p,c)` 返回的是字符实际所在下标 `q`；继续匹配时应令 `p = q + 1`
- `n` 同时作为“不存在”的哨兵值
- `p` 合法范围为 `[0,n]`
- 默认小写字母；整数编号序列使用 `SubseqAutomaton<A, 0>`
- 必须保证 `0 <= id(c) < A`
- 构建需要复制长度为 `A` 的整张下一位置表，因此更适合固定小字符集
- 如果字符集非常大而查询很少，更适合为每种字符保存出现位置数组后用 `lower_bound`
#### 常见用法
##### 判断是否为子序列
```cpp
SubseqAutomaton<> sa(s);
if (sa.contains(t)) {
    // t 是 s 的子序列
}
```
##### 求最早匹配结束位置
```cpp
int r{ sa.match(t) };
if (r != -1) {
    // 可以在 s[0..r) 中匹配出 t
    // 且 r 最小
}
```
由于每次都贪心选择当前字符最靠前的位置，因此得到的 `r` 是最早可能结束的位置
##### 从指定位置之后继续匹配
```cpp
int r{ sa.match(t, l) };
if (r != -1) {
    // t 是 s[l..n) 的子序列
    // 匹配实际落在区间 [l, r) 内
}
```
##### 手动逐字符转移
```cpp
int p{ 0 };
for (char c : t) {
    int q{ sa.step(p, c) };
    if (q == sa.n) {
        // 无法继续匹配
        break;
    }
    p = q + 1;
}
```
##### 贪心定理
假设：
```cpp
sa.match(t, l)
```
每个字符都取当前能选到的**最靠左位置**
那么：
$$\boxed{ \text{它得到的是所有 }t\text{ 的匹配方案中，结束位置最早的方案} }$$
这是因为局部把某字符选得更靠左，永远不会损害后续字符的可选空间
##### 可以 $O(|t|)$ 判断区间子序列
要判断：
> `t` 是否是 `s[l,r)` 的子序列

只需要：
```cpp
int p = sa.match(t, l);
if (p != -1 && p <= r) {
    // 是子序列
}
```
原因：
`match()` 已经给出了**最早结束位置**
所以：
$$\boxed{ t\subseteq s[l,r) \iff match(t,l)\le r }$$
##### 正反两个子序列自动机
再对反串建立一个自动机，或者建立：
```cpp
prev[p][c]
```
即可得到：
- 从左向右：最早结束位置
- 从右向左：最晚开始位置

> 某子序列最紧覆盖区间  
> 删除一段后还能否匹配  
> 前后两部分分别匹配

都可以直接做
##### 统计不同子序列数
设状态 `p` 表示：
> 下一次从 `s[p..n)` 中选字符

定义：
$$f[p] = s[p..n)\text{ 的不同子序列数量，包含空串}$$
对于每个字符 `c`：
```cpp
q = next[p][c];
```
若 `q < n`，所有以 `c` 开头的不同子序列，与：
```cpp
s[q+1..]
```
的任意不同子序列一一对应
因此：
$$\boxed{ f[p] = 1+ \sum_{\substack{c\\next[p][c]<n}} f[next[p][c]+1] }$$
边界：
$$f[n]=1$$
最终：
```cpp
f[0] - 1
```
就是不同非空子序列数量
这里不会重复计数，因为不同首字符天然属于不同集合，而同一首字符永远固定选择它的**第一次可用出现位置**
##### 第 k 个字典序不同子序列
有了上面的 `f[p]` 就很自然
对于状态 `p`，按字符：
```cpp
'a', 'b', ...
```
枚举
若：
```cpp
q = next[p][c] < n
```
那么以字符 `c` 开头的不同子序列总数为：
$$f[q+1]$$
于是可以跳过整个字典序块
而选中字符 `c` 后：
```cpp
c
```
本身是这一块里的第一个字符串，然后才是：
```cpp
c + 非空子序列
```
因此可以 $O(AL)$ 求第 `k` 个不同子序列，其中 `L` 是答案长度
##### 最短不存在子序列
定义：
$$g[p] = \text{不是 }s[p..n)\text{ 子序列的最短字符串长度}$$
若存在字符 `c`：
```cpp
next[p][c] == n
```
那么直接：
$$g[p]=1$$
否则：
$$\boxed{ g[p] = 1+\min_c g[next[p][c]+1] }$$
边界：
$$g[n]=1$$
记录最优字符还能恢复答案
如果最小长度相同优先选较小字符，就直接得到：
> **字典序最小的最短不存在子序列**
##### 大字符集时应该换实现
目前：
$$\text{build}=O(nA),\qquad \text{query}=O(m)$$
非常适合：
```cpp
A = 2
A = 26
A = 52
```
但如果字符值域很大，例如整数序列，`A=10^9` 肯定不能这么建
这时应该用：
```cpp
vector<vector<int>> pos;
```
为每种字符保存出现位置，然后每次：
```cpp
lower_bound(pos[c], current)
```
复杂度变成大约：
$$O(n)$$
预处理，以及单次查询：
$$O(m\log n)$$

|场景|方法|
|---|---|
|小固定字符集、大量查询|子序列自动机|
|大字符集、查询不太多|出现位置数组 + `lower_bound`|
|只有一个查询|双指针即可|
#### 复杂度
原串长度为 $n$，查询串长度为 $m$，字符集大小为 $A$

| 操作                         |   时间复杂度 |
| -------------------------- | ------: |
| `build(s)`                 | $O(nA)$ |
| `step(p,c)`                |  $O(1)$ |
| `match(t)` / `contains(t)` |  $O(m)$ |
空间复杂度为 $O(nA)$
