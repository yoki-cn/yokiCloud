### Series PAM（回文系列优化）
---
```cpp
template<int A = 26, int offset = 'a'>
struct SeriesPAM {
    struct Node {
        int len{ 0 }, link{ 0 };
        int diff{ 0 }, slink{ 0 };
        array<int, A> next{};
    };
    vector<Node> t;
    vector<int> s;
    int suff{ 1 };
    explicit SeriesPAM(int m = 0) : t(2), s(1, -1) {
        t.reserve(m + 2);
        s.reserve(m + 1);
        t[0].len = -1;
    }
    template<class Seg>
    explicit SeriesPAM(const Seg &a) : SeriesPAM(int(a.size())) { build(a); }
    // ===== 基础函数：插入依赖，不建议删除 =====
    template<class T>
    static int id(const T &c) { return int(c) - offset; }
    int new_node(int len) {
        t.emplace_back();
        t.back().len = len;
        return int(t.size()) - 1;
    }
    int get_link(int p) const {
        int i{ int(s.size()) - 1 };
        while (s[i - t[p].len - 1] != s[i]) p = t[p].link;
        return p;
    }
    // ===== 在线插入：维护 diff / slink 回文系列 =====
    int add_id(int x) {
        s.push_back(x);
        int p{ get_link(suff) };
        if (!t[p].next[x]) {
            int q{ new_node(t[p].len + 2) };
            if (t[q].len == 1) t[q].link = 1;
            else t[q].link = t[get_link(t[p].link)].next[x];
            t[q].diff = t[q].len - t[t[q].link].len;
            if (t[q].diff == t[t[q].link].diff) t[q].slink = t[t[q].link].slink;
            else t[q].slink = t[q].link;
            t[p].next[x] = q;
        }
        return suff = t[p].next[x];
    }
    template<class T>
    int add(const T &c) { return add_id(id(c)); }
    template<class Seg>
    void build(const Seg &a) { for (const auto &c : a) add(c); }
    int size() const { return int(t.size()); }
    int distinct() const { return int(t.size()) - 2; }
    int longest_suffix() const { return suff; }
    // 枚举当前回文后缀的各个 series 代表节点
    template<class F>
    void series(F f) const {
        for (int p = suff; p > 1; p = t[p].slink) f(p);
    }
};
```
#### 成员变量
除普通 PAM 的 `len / link / next / suff` 外：
- `t[p].diff = len[p] - len[link[p]]`
- `t[p].slink`：回文系列链接
- `s`：字符编号序列，`s[0] = -1` 是哨兵，因此 `get_link()` 不需要额外判断左边界
这里刻意**不维护**普通 PAM 的：
```text
num
occ
```
因为 Series PAM 的职责只是为回文 DP 提供快速后缀分组；需要普通出现次数统计时应使用普通 PAM
#### 接口
- `SeriesPAM(m)`：建立空结构
- `SeriesPAM(s)`：建立整个字符串的回文系列树，$O(n)$
- `add(c)`：在末尾加入字符，返回当前最长回文后缀节点，均摊 $O(1)$
- `build(s)`：依次插入字符串，$O(n)$
- `size()`：节点总数，$O(1)$
- `distinct()`：本质不同回文串数量，$O(1)$
- `longest_suffix()`：当前最长回文后缀节点，$O(1)$
- `series(f)`：沿 `slink` 枚举当前所有回文后缀系列
#### 注意事项
- 只有当 DP 转移需要频繁枚举**所有回文后缀**、普通 `link` 链可能退化为 $O(n^2)$ 时，才需要 Series PAM
- 普通查询、不同回文串计数、出现次数统计应优先使用普通 PAM
- 必须保证所有字符编号位于 `[0,A)`
- `s[0] = -1` 是内部哨兵，因此合法字符编号不能为 `-1`
- `diff / slink` 是结构性字段，不能像普通统计数组那样随意删除
- 回文系列 DP 通常还需要一个按 PAM 节点编号维护的辅助数组 `g`
- `g` 往往需要跨前缀复用，**不要习惯性在每一轮清空**
- 使用 series link 后的具体复杂度取决于 DP 转移；典型回文划分算法通常可做到 $O(n\log n)$，部分专门转移还能进一步优化
#### 常见用法
##### 回文系列的含义
定义：
$$diff[p] = len[p]-len[link[p]]$$
如果：
$$diff[p]=diff[link[p]]$$
说明 `p` 与 `link[p]` 属于同一个系列
这一系列中的回文长度构成等差数列，公差就是：
$$diff[p]$$
`slink[p]` 会一次跳过当前整段相同 `diff` 的回文后缀
因此：
```text
p
slink[p]
slink[slink[p]]
...
```
不是枚举每个回文后缀，而是枚举每个**回文长度等差系列**的代表
##### 普通 PAM 为什么可能慢
若直接枚举：
```cpp
for (int p = pam.longest_suffix(); p > 1; p = pam.t[p].link) {
    // 枚举所有回文后缀
}
```
例如字符串：
```text
aaaaaaa...
```
第 `i` 个前缀可能有 $\Theta(i)$ 个回文后缀
总复杂度可能达到：
$$\Theta(n^2)$$
Series PAM 就是用 `diff / slink` 把大量结构相似的后缀合并处理
##### 枚举当前所有回文系列
```cpp
int last{ pam.add(c) };
for (int p = last; p > 1; p = pam.t[p].slink) {
    int q{ pam.t[p].slink };
    // p 表示当前一个回文后缀系列
    // q 是下一个系列
}
```
也可以：
```cpp
pam.series([&](int p) {
    // 处理系列 p
});
```
##### 回文划分方案数 DP
设：
```cpp
dp[i]
```
表示前缀 `s[0..i)` 划分成若干回文串的方案数
朴素转移需要枚举所有回文后缀：
$$dp[i] = \sum_{\substack{j<i\\s[j..i)\text{ 为回文}}} dp[j]$$
使用 Series PAM：
```cpp
SeriesPAM<> pam(s.size());
vector<i64> dp(s.size() + 1);
vector<i64> g(s.size() + 2);
dp[0] = 1;
for (int i = 1; i <= s.size(); ++ i) {
    int last{ pam.add(s[i - 1]) };
    for (int p = last; p > 1; p = pam.t[p].slink) {
        int q{ pam.t[p].slink };
        int j{ i - (pam.t[q].len + pam.t[p].diff) };
        g[p] = dp[j];
        if (pam.t[p].diff == pam.t[pam.t[p].link].diff) {
            g[p] += g[pam.t[p].link];
        }
        dp[i] += g[p];
    }
}
```
若题目要求取模，把 `i64` 换成取模类型或在加法处取模。
其中：
```cpp
g[p]
```
把同一个等差回文系列中的多个朴素 DP 转移压缩到一起。
##### 最少回文划分 DP
设：
```cpp
dp[i]
```
表示 `s[0..i)` 最少划分成多少个回文串
```cpp
constexpr int INF = 1E9;
SeriesPAM<> pam(s.size());
vector<int> dp(s.size() + 1, INF);
vector<int> g(s.size() + 2, INF);
dp[0] = 0;
for (int i = 1; i <= int(s.size()); ++ i) {
    int last{ pam.add(s[i - 1]) };
    for (int p = last; p > 1; p = pam.t[p].slink) {
        int q{ pam.t[p].slink };
        int j{ i - (pam.t[q].len + pam.t[p].diff) };
        g[p] = dp[j];
        if (pam.t[p].diff == pam.t[pam.t[p].link].diff) {
            g[p] = min(g[p], g[pam.t[p].link]);
        }
        dp[i] = min(dp[i], g[p] + 1);
    }
}
```
最终：
```cpp
dp[s.size()]
```
就是整个字符串的最少回文划分数
##### 核心 DP 下标公式
对于当前前缀长度 `i`、系列代表节点 `p`，令：
```cpp
int q{ pam.t[p].slink };
```
则该系列最短成员对应的前驱位置为：
$$\boxed{ j=i-\bigl(len[q]+diff[p]\bigr) }$$
所以系列 DP 中经常出现：
```cpp
int j{ i - (pam.t[q].len + pam.t[p].diff) };
```

这是 Series PAM 最需要快速回忆的公式
#### 复杂度
PAM 本体仍满足：

|操作|时间复杂度|
|---|--:|
|单次 `add(c)`|均摊 $O(1)$|
|`build(s)`|$O(n)$|
|`distinct()`|$O(1)$|
空间复杂度为 $O(nA)$，固定字符集时为 $O(n)$
Series DP 的复杂度取决于具体转移；典型使用中通过 `slink` 避免逐个枚举全部回文后缀，常见复杂度约为 $O(n\log n)$，某些专门递推可以进一步做到线性
