### 笛卡尔树
---
```cpp
template<class T, class Compare = less<T>>
struct CartesianTree {
    int n, root{ -1 };
    vector<int> parent, left, right;
    explicit CartesianTree(const vector<T> &a, Compare better = Compare())
        : n(int(a.size())), parent(n, -1), left(n, -1), right(n, -1) {
        vector<int> stk;
        stk.reserve(n);
        for (int i = 0; i < n; ++ i) {
            int last{ -1 };
            while (!stk.empty() && better(a[i], a[stk.back()])) {
                last = stk.back();
                stk.pop_back();
            }
            if (!stk.empty()) {
                parent[i] = stk.back();
                right[stk.back()] = i;
            }
            if (last != -1) {
                parent[last] = i;
                left[i] = last;
            }
            stk.push_back(i);
        }
        if (!stk.empty()) root = stk.front();
    }
};
```
#### 成员变量
- `n`：元素个数  
- `root`：根节点下标；空数组时为 `-1`
- `parent[i]`：节点 `i` 的父亲；根节点为 `-1`
- `left[i]` / `right[i]`：节点 `i` 的左右儿子；不存在时为 `-1`
- 节点编号就是原数组下标，因此整棵树的中序遍历固定为 `0,1,...,n-1`
#### 接口
- `CartesianTree(a, better)`：$O(n)$ 构造由 `better` 决定堆序的笛卡尔树
- 默认 `less<T>`：最小笛卡尔树
- 使用 `greater<T>`：最大笛卡尔树
#### 注意事项
- `Compare` 应满足严格弱序；`better(x,y)` 表示 `x` 的优先级严格高于 `y`
- 当前只在新元素**严格更优**时弹栈，因此等价元素不会弹出。默认最小笛卡尔树中，相同最小值会优先选择**更靠左**的位置
- 因此默认最小笛卡尔树中，对任意非空区间 `[l,r)`：$\operatorname{LCA}(l,r-1)$ 就是区间最小值的位置；有多个最小值时返回最靠左的一个。最大笛卡尔树同理对应区间最大值
- 每棵子树在原数组中都对应一个连续区间；节点 `u` 是该区间按 `Compare` 选出的最优元素
- 若节点 `u` 的左右子树大小分别为 `L,R`，则在当前重复值规则下，以 `u` 作为所选极值位置的子数组数量为 $(L+1)(R+1)$
- 笛卡尔树可能完全退化成长度为 `n` 的链；需要遍历整棵树时，大数据不要直接使用递归 DFS
- `root = stk.front()` 是构造后的根：最终单调栈中的第一个元素没有父亲
- 笛卡尔树把 **RMQ 转为 LCA**；而经典的 LCA 欧拉序算法则把 **LCA 转为 RMQ**，两者方向不要混淆
#### 常见用法
##### 最小笛卡尔树
```cpp
CartesianTree<int> ct(a);

int root = ct.root;
int lc = ct.left[root];
int rc = ct.right[root];
```
##### 最大笛卡尔树
```cpp
CartesianTree<int, greater<int>> ct(a);
```
##### RMQ 转 LCA
先在笛卡尔树上建立 LCA 结构：
```cpp
CartesianTree<int> ct(a);

// 在 ct.left / ct.right 构成的树上预处理 LCA。
int pos = lca(l, r - 1);
int minimum = a[pos];
```
##### 自定义比较规则
```cpp
struct CartesianKey {
    i64 value{};
    int id{};
};

struct BetterCartesianKey {
    bool operator()(const CartesianKey &a, const CartesianKey &b) const {
        return tie(a.value, a.id) < tie(b.value, b.id);
    }
};

vector<CartesianKey> a(n);
CartesianTree<CartesianKey, BetterCartesianKey> ct(a);

int id = a[ct.root].id;
```
如果需要显式规定重复值的优先级，最稳妥的方法就是像上面一样把编号一起放入比较键
