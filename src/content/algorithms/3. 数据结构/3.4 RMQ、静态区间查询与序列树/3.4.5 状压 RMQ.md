### 状压 RMQ
---
对静态数组按比较器查询任意非空区间的最优值或最优位置，支持 $O(1)$ 查询，并在存在多个最优值时返回最左位置
```cpp
template<class T, class Cmp = less<T>>
struct RMQ {
private:
    static constexpr int B{ 64 };
    int n;
    Cmp cmp;
    vector<T> a;
    vector<u64> stk;
    vector<vector<int>> st;
    // 返回两个位置中更优的位置；等价时取更靠左的位置
    int better(int x, int y) const {
        if (cmp(a[x], a[y])) return x;
        if (cmp(a[y], a[x])) return y;
        return min(x, y);
    }
    // 查询同一块内 [l,r) 的最优位置
    int small(int l, int r) const {
        u64 s{ stk[r - 1] >> (l % B) };
        return l + __builtin_ctzll(s);
    }
public:
    explicit RMQ(vector<T> a_, Cmp cmp_ = Cmp())
        : n(int(a_.size())), cmp(move(cmp_)), a(move(a_)), stk(n) {
        assert(n > 0);
        int m{ (n + B - 1) / B };
        // 每个前缀维护块内单调栈；第 i 位表示对应位置仍在栈中
        for (int b = 0; b < m; ++ b) {
            int l{ b * B }, r{ min(n, l + B) };
            u64 s{};
            for (int i = l; i < r; ++ i) {
                while (s) {
                    int j{ 63 - __builtin_clzll(s) };
                    if (!cmp(a[i], a[l + j])) break;
                    s ^= 1ULL << j;
                }
                s |= 1ULL << (i - l);
                stk[i] = s;
            }
        }
        // 对完整块的最优位置建立 ST
        int lg{ __lg(m) + 1 };
        st.resize(lg);
        st[0].resize(m);
        for (int b = 0; b < m; ++ b) {
            st[0][b] = small(b * B, min(n, (b + 1) * B));
        }
        for (int k = 1; k < lg; ++ k) {
            int len{ m - (1 << k) + 1 };
            st[k].resize(max(0, len));
            for (int b = 0; b < len; ++ b) {
                st[k][b] = better(st[k - 1][b], st[k - 1][b + (1 << (k - 1))]);
            }
        }
    }
    int query_index(int l, int r) const {
        assert(0 <= l && l < r && r <= n);
        int lb{ l / B }, rb{ (r - 1) / B };
        if (lb == rb) return small(l, r);
        // 左右两个不完整块
        int ans{ better(small(l, (lb + 1) * B), small(rb * B, r)) };
        // 中间所有完整块
        int x{ lb + 1 }, y{ rb };
        if (x < y) {
            int k{ __lg(y - x) };
            ans = better(ans, better(st[k][x], st[k][y - (1 << k)]));
        }
        return ans;
    }
    const T &query(int l, int r) const { return a[query_index(l, r)]; }
};
```
#### 模板参数
- `Cmp`：严格比较器，`cmp(x,y) = true` 表示 `x` 比 `y` 更优
    - 默认 `less<T>`：查询最小值
    - 使用 `greater<T>`：查询最大值
#### 接口
- `RMQ(a, cmp)`：对非空静态数组建立 RMQ
- `query_index(l,r)`：返回 `[l,r)` 中最优元素的原数组下标，$O(1)$
- `query(l,r)`：返回 `[l,r)` 中最优元素的常引用，$O(1)$
当多个元素在 `Cmp` 下等价时，两种查询都选择**最左位置**
#### 注意事项
- 数组下标为 `0base`，所有查询均为左闭右开 `[l,r)`
- 构造数组必须非空，查询必须满足 `0 <= l < r <= n`
- 这是**静态 RMQ**；构造完成后不能修改内部数组
- `Cmp` 必须满足严格弱序，并且其调用运算符应能在 `const` 环境下调用
- 当前弹栈条件为新元素**严格更优**，等价元素不会弹出；结合 `better()` 的下标比较，可以保证相同最优值返回最左位置
- 该结构只支持“根据比较器选出最优元素”，不支持区间和、异或、矩阵乘法等一般结合运算
- `query()` 返回内部 `a` 中元素的引用；RMQ 对象销毁后该引用失效
- 块长固定为 `64`，因此块内单调栈状态可以由一个 `u64` 保存
- `small(l,r)` 只会在 `l`、`r-1` 属于同一个块时调用；不能单独拿它查询跨块区间
- `__builtin_ctzll()` 的参数不会为 `0`：因为 `r-1` 本身一定仍存在于 `stk[r-1]` 中，并且 `l <= r-1`
- 相比普通 ST，这个结构更适合需要大量 RMQ、尤其是还需要返回**极值位置**的场景；普通 ST 的代码更短，应按需求选择
#### 原理简记
每个长度至多为 `64` 的块独立维护单调栈
对于位置 `r-1`，`stk[r-1]` 记录块前缀 `[block_l,r)` 的单调栈状态。删除所有位于 `l` 左侧的位置后：
```cpp
stk[r - 1] >> (l % B)
```
最低的剩余 `1` 所代表的位置，就是 `[l,r)` 的最左最优位置，因此块内 RMQ 可以通过一次 `ctz` 完成
跨块查询拆成：
```text
左侧不完整块 + 中间完整块 + 右侧不完整块
```
左右两部分由块内状态 $O(1)$ 查询，中间完整块由块级 ST $O(1)$ 查询
#### 常见用法
##### 区间最小值及其位置
```cpp
RMQ<int> rmq(a);

int p{ rmq.query_index(l, r) };
int mn{ rmq.query(l, r) };
```
##### 区间最大值
```cpp
RMQ<int, greater<int>> rmq(a);

int p{ rmq.query_index(l, r) };
int mx{ rmq.query(l, r) };
```
##### 相同最小值取最左位置
```cpp
vector<int> a{ 3, 1, 2, 1 };

RMQ<int> rmq(a);
int p{ rmq.query_index(0, 4) }; // 1
```
##### 结构体按字段选择最优元素
```cpp
struct Info {
    i64 key{};
    int id{};
};

struct MinKey {
    bool operator()(const Info &a, const Info &b) const {
        return a.key < b.key;
    }
};

RMQ<Info, MinKey> rmq(a);

int p{ rmq.query_index(l, r) };
const Info &res{ rmq.query(l, r) };
```
这里 `Cmp` 只比较 `key`，因此 `key` 相等时由 RMQ 自动选择原数组中更靠左的位置
如果希望 `id` 本身参与优先级，则改为：
```cpp
struct MinKey {
    bool operator()(const Info &a, const Info &b) const {
        return tie(a.key, a.id) < tie(b.key, b.id);
    }
};
```
### 复杂度

设块长 $B=64$，块数
$$m=\left\lceil\frac nB\right\rceil$$
更严格地写：

| 操作                 |        时间复杂度 |
| ------------------ | -----------: |
| 块内状态预处理            |       $O(n)$ |
| 块级 ST 预处理          | $O(m\log m)$ |
| `query_index(l,r)` |       $O(1)$ |
| `query(l,r)`       |       $O(1)$ |
空间复杂度：
$$O(n+m\log m)$$
代入 $m=\lceil n/64\rceil$：
$$O\left(n+\frac n{64}\log\frac n{64}\right)$$
在固定 64 位机器模型下，$\log m$ 有固定上界，因此该实现通常记作**线性预处理、线性空间、$O(1)$ 查询**
若一次 `Cmp` 比较的复杂度为 $O(k)$，则预处理和查询中的比较开销相应乘上 $O(k)$
