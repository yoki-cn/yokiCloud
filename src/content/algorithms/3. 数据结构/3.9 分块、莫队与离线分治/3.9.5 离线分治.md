### 离线分治
---
离线分治主要保留两类值得独立成板子的算法
- **整体二分**：对一批询问同时二分答案，将事件稳定划分到左右答案区间
- **CDQ 分治**：按时间、下标或某一维分治，只计算左半对右半的贡献
#### 整体二分
---
对所有询问共同维护答案区间 `[vl,vr)`，每层取 `vm`
- 修改值 `< vm` 时加入数据结构
- 查询当前区间中 `< vm` 的元素数 `c`
- 若 `c >= k`，答案进入左半
- 否则进入右半，并令 `k -= c`
事件划分后必须保持原来的时间顺序
#### 动态区间第 k 小
---
支持单点赋值与区间第 `k` 小，所有操作离线后统一计算
```cpp
template<class T = int>
struct PBS {
    struct E {
        int tp, l, r, k, id, d, v;
        T x;
    };
    int n, qn{};
    vector<T> a, val, ans;
    vector<E> e, w, tmp;
    vector<int> bit;
    vector<char> go;
    explicit PBS(vector<T> a_) : n(a_.size()), a(move(a_)), val(a) {
        for (int i = 0; i < n; ++ i) {
            e.push_back({ 0, i, 0, 0, -1, 1, -1, a[i] });
        }
    }
    // ===== 加入操作 =====
    void set(int p, T x) {
        e.push_back({ 0, p, 0, 0, -1, -1, -1, a[p] });
        e.push_back({ 0, p, 0, 0, -1, 1, -1, x });
        a[p] = x;
        val.push_back(x);
    }

    int ask(int l, int r, int k) {
        int id{ qn ++ };
        e.push_back({ 1, l, r, k, id, 0, -1, T{} });
        return id;
    }
    // ===== BIT：统计当前值域左半中的位置 =====
    void add(int p, int x) {
        for (++ p; p <= n; p += p & -p) bit[p] += x;
    }
    int sum(int p) const {
        int s{};
        for (; p; p -= p & -p) s += bit[p];
        return s;
    }
    // ===== 整体二分 =====
    void solve(int l, int r, int vl, int vr) {
        if (l >= r) return;
        if (vr - vl == 1) {
            for (int i = l; i < r; ++ i) {
                if (w[i].tp) ans[w[i].id] = val[vl];
            }
            return;
        }
        int vm{ (vl + vr) / 2 }, nl{};
        for (int i = l; i < r; ++ i) {
            auto &z{ w[i] };
            if (!z.tp) {
                go[i] = z.v < vm;
                if (go[i]) add(z.l, z.d);
            } else {
                int c{ sum(z.r) - sum(z.l) };
                go[i] = c >= z.k;
                if (!go[i]) z.k -= c;
            }
            nl += go[i];
        }
        // 撤销本层 BIT 修改
        for (int i = l; i < r; ++ i) {
            if (!w[i].tp && go[i]) add(w[i].l, -w[i].d);
        }
        // 稳定划分，保持操作的时间顺序
        int x{ l }, y{ l + nl };
        for (int i = l; i < r; ++ i) {
            tmp[go[i] ? x ++ : y ++] = move(w[i]);
        }
        for (int i = l; i < r; ++ i) w[i] = move(tmp[i]);
        solve(l, l + nl, vl, vm);
        solve(l + nl, r, vm, vr);
    }
    vector<T> run() {
        sort(val.begin(), val.end());
        val.erase(unique(val.begin(), val.end()), val.end());
        for (auto &z : e) if (!z.tp) {
            z.v = lower_bound(val.begin(), val.end(), z.x) - val.begin();
        }
        w = e;
        tmp.resize(w.size());
        go.resize(w.size());
        bit.assign(n + 1, 0);
        ans.assign(qn, T{});
        solve(0, w.size(), 0, val.size());
        return ans;
    }
};
```
##### 成员变量
- `e`：按真实时间顺序保存的修改与询问事件
- `tp = 0`：修改事件
- `tp = 1`：询问事件
- `d = 1/-1`：插入 / 删除一个值
- `v`：修改值离散化后的编号
- `k`：当前递归中还需要寻找的排名
- `bit`：维护当前答案左半值域中各位置出现次数
##### 接口
- `PBS(a)`：加入初始数组
- `set(p, x)`：单点赋值 `a[p] = x`
- `ask(l, r, k)`：加入 `[l,r)` 第 `k` 小询问，返回询问编号
- `run()`：离线求出所有询问答案
##### 常见用法
```cpp
PBS<i64> pbs(a);
int x = pbs.ask(l, r, k);
pbs.set(p, v);
int y = pbs.ask(l2, r2, k2);
auto ans = pbs.run();
cout << ans[x] << '\n';
cout << ans[y] << '\n';
```
##### 注意事项
- 下标为 `0base`，区间为 `[l,r)`
- `k` 从 `1` 开始，要求 `1 <= k <= r - l`
- `set()` 和 `ask()` 必须严格按照真实时间顺序加入
- 单点赋值拆成删除旧值和插入新值两个事件
- 所有初始值和修改值统一离散化
- 事件划分必须稳定，否则会破坏修改与询问的时间关系
- 进入右半答案区间时必须执行 `k -= c`
- 每层递归结束前必须撤销该层加入 BIT 的修改
- `run()` 后得到的是最终离线答案，不能在线输出询问
- 若只有静态区间第 `k` 小，主席树、小波矩阵等通常更直接
##### 复杂度
设修改次数为 $u$、询问次数为 $q$、不同值数量为 $V$
事件数量
$$
E=n+2u+q
$$
每个事件经过 $O(\log V)$ 层，每层修改或查询 BIT 为 $O(\log n)$
$$
O(E\log V\log n)
$$
空间复杂度
$$
O(E+n+V)
$$
#### 整体二分的其他常见模型
---
同一套思想还可以处理
- 第一个满足条件的时刻
- 第 `k` 个发生的事件
- 动态排名与第 `k` 小
- 多个询问共享一个具有单调性的判定过程
若答案不是一个离散值，而是“最早时刻”，只需把递归值域改成时间轴，并重新设计每层的 `check`
#### CDQ 分治
---
CDQ 将事件按一个天然有序的维度分成左右两半，只统计
$$
\text{左半}\rightarrow\text{右半}
$$
的跨区间贡献
处理多维偏序时，可以用递归消掉一个维度，再用排序、树状数组等结构处理剩余维度
#### 三维偏序
---
给定点
$$
p_i=(x_i,y_i,z_i)
$$
求每个点满足
$$
x_j\le x_i,\quad y_j\le y_i,\quad z_j\le z_i
$$
的点 `j` 数量，包括自身
经典实现先合并重复点，然后按第二维归并，同时用树状数组维护第三维
```cpp
vector<i64> cdq3(const vector<array<int, 3>> &p) {
    struct P {
        int x, y, z, w{ 1 };
        i64 s{};
        vector<int> id;
    };
    int n{ int(p.size()) };
    if (!n) return {};
    vector<int> o(n);
    iota(o.begin(), o.end(), 0);
    sort(o.begin(), o.end(), [&](int i, int j) {
        return p[i] < p[j];
    });
    // ===== 合并完全相同的点 =====
    vector<P> a;
    for (int i : o) {
        if (!a.empty() &&
            array<int, 3>{ a.back().x, a.back().y, a.back().z } == p[i]) {
            ++ a.back().w;
            a.back().id.push_back(i);
        } else {
            a.push_back({ p[i][0], p[i][1], p[i][2], 1, 0, { i } });
        }
    }
    // ===== 第三维离散化 =====
    vector<int> z;
    z.reserve(a.size());
    for (auto &v : a) z.push_back(v.z);
    sort(z.begin(), z.end());
    z.erase(unique(z.begin(), z.end()), z.end());
    for (auto &v : a) {
        v.z = lower_bound(z.begin(), z.end(), v.z) - z.begin() + 1;
    }
    vector<int> bit(z.size() + 1);
    auto add = [&](int p, int x) {
        for (; p < int(bit.size()); p += p & -p) bit[p] += x;
    };
    auto sum = [&](int p) {
        int s{};
        for (; p; p -= p & -p) s += bit[p];
        return s;
    };
    vector<P> tmp(a.size());
    // ===== 左半贡献给右半，同时按 y 归并 =====
    auto cdq = [&](auto &&self, int l, int r) -> void {
        if (r - l <= 1) return;
        int m{ (l + r) / 2 };
        self(self, l, m);
        self(self, m, r);
        int i{ l }, j{ m }, k{ l };
        while (i < m || j < r) {
            if (j == r || (i < m && a[i].y <= a[j].y)) {
                add(a[i].z, a[i].w);
                tmp[k ++] = a[i ++];
            } else {
                a[j].s += sum(a[j].z);
                tmp[k ++] = a[j ++];
            }
        }
        for (int t = l; t < m; ++ t) add(a[t].z, -a[t].w);
        for (int t = l; t < r; ++ t) a[t] = move(tmp[t]);
    };
    cdq(cdq, 0, a.size());
    vector<i64> ans(n);
    for (auto &v : a) {
        for (int id : v.id) ans[id] = v.s + v.w;
    }
    return ans;
}
```
##### 成员含义
- `x,y,z`：三维坐标
- `w`：完全相同点的出现次数
- `s`：其他坐标组对当前点产生的贡献
- `id`：这一坐标组对应的原输入编号
##### 接口
- `cdq3(p)`：返回每个点三维均不大于它的点数
- 返回值包含点自身以及与其完全相同的其他点
##### 常见用法
###### 每个点的偏序计数
```cpp
auto ans = cdq3(p);
for (i64 x : ans) cout << x << '\n';
```
###### 三维偏序计数直方图
若需要统计“恰有 `k` 个其他点三维均不大于它”的点数
```cpp
auto d = cdq3(p);
vector<int> ans(p.size());
for (i64 x : d) ++ ans[x - 1];
```
##### 注意事项
- 第一维先按 `{x,y,z}` 排序
- 完全相同的点必须先合并，否则相等点之间的贡献容易漏算或重复
- CDQ 返回上一层时，当前区间必须保持按 `y` 有序
- `y` 相等时左半元素必须先加入 BIT，才能统计 `<=`
- 第三维查询使用前缀 `sum(z)`，同样表示 `<=`
- 每层结束后必须撤销加入 BIT 的左半贡献
- 若要求严格 `<`，需要同时调整排序、重复点处理以及归并时的相等关系
- CDQ 不一定处理几何坐标，三个维度也可以分别表示时间、位置、权值
##### 复杂度
初始排序与离散化
$$
O(n\log n)
$$
CDQ 共 $O(\log n)$ 层，每层每个点进行 $O(\log n)$ 的 BIT 操作
$$
O(n\log^2 n)
$$
空间复杂度
$$
O(n)
$$
#### CDQ 的其他常见模型
---
若把第一维换成**操作时间**，CDQ 可以处理很多离线动态问题，例如
```text
时间 t
    ↓ CDQ
只统计过去的修改对未来询问的贡献
    ↓
剩余二维关系交给 BIT / 线段树
```
常见形式包括
- 单点增加 + 二维矩形计数
- 动态二维偏序
- 动态逆序对的部分模型
- 时间维修改 + 区间 / 前缀统计
这类题通常不值得再造一个所谓“万能 CDQ 类”，因为事件含义与贡献方向差异很大，保留三维偏序板子和下面的核心骨架更实用
```cpp
void cdq(int l, int r) {
    if (r - l <= 1) return;
    int m = (l + r) / 2;
    cdq(l, m);
    // 计算 [l,m) 中事件对 [m,r) 的贡献
    // 常用排序 + BIT / 双指针
    // 撤销临时状态
    cdq(m, r);
}
```
#### 选择
| 方法 | 分治对象 | 关键条件 | 常见用途 |
|---|---|---|---|
| 整体二分 | 答案值域 | 判定随答案单调 | 动态第 `k` 小、最早时刻 |
| CDQ | 时间 / 下标 / 偏序维 | 贡献可拆成左半对右半 | 多维偏序、离线动态统计 |
可以直接记成
```text
整体二分：这一批答案分别在哪一半
CDQ：左半事件对右半事件贡献多少
```
