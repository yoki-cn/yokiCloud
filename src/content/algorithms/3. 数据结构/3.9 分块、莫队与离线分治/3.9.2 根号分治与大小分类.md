### 根号分治与大小分类
---
根号分治的核心是找到一个非负规模量 $w_i$，设总量
$$
S=\sum_i w_i
$$
取阈值 $B$，将对象分成
- 轻对象：$w_i<B$，单个对象可在 $O(B)$ 内暴力处理
- 重对象：$w_i\ge B$，数量至多为 $S/B$
- 若总复杂度形如 $O(AB+C/B)$，通常取 $B=\Theta(\sqrt{C/A})$
若操作能转化为“枚举一个轻对象”或“枚举所有重对象”，单次复杂度通常为
$$
O\left(B+\frac SB\right)
$$
取 $B=\Theta(\sqrt S)$ 时得到 $O(\sqrt S)$
#### 通用大小分类
---
```cpp
struct SqrtSplit {
    int B;
    vector<int> id, hi;
    explicit SqrtSplit(const vector<int> &w, int bs = 0) : id(w.size(), -1) {
        i64 s{};
        for (int x : w) s += x;
        B = bs ? bs : max(1, int(sqrt(max<i64>(1, s))));
        for (int i = 0; i < w.size(); ++ i) {
            if (w[i] >= B) id[i] = hi.size(), hi.push_back(i);
        }
    }
    bool high(int x) const { return id[x] != -1; }
};
```
##### 成员变量
- `B`：轻重分类阈值
- `hi`：所有重对象的原编号
- `id[x]`：对象 `x` 在 `hi` 中的编号，轻对象为 `-1`
##### 接口
- `SqrtSplit(w, bs)`：按权值 `w[i]` 分类，`bs = 0` 时取约 $\sqrt{\sum w_i}$，$O(n)$
- `high(x)`：判断 `x` 是否为重对象，$O(1)$
##### 注意事项
- 要求 `w[i]>=0`
- 若阈值为 `B`，重对象数量至多为 $\lfloor S/B\rfloor$
- `w[i]` 不一定是真正的权值，常见含义是出现次数、度数、集合大小、操作次数
- `B` 不一定必须取 $\sqrt S$，应根据轻对象和重对象两侧的真实复杂度平衡
##### 常见用法
###### 高频与低频元素
序列已离散化到 `[0,m)`
```cpp
vector<int> cnt(m);
for (int x : a) ++ cnt[x];

SqrtSplit sp(cnt);
for (int h = 0; h < int(sp.hi.size()); ++ h) {
    int x = sp.hi[h];
    // 对高频值 x 预处理
}
```
高频值数量至多为 $n/B$，低频值出现次数小于 $B$
这种分类常用于：
- 高频值预处理整组答案
- 低频值枚举全部出现位置
- 区间众数与频率相关询问
- 按颜色、种类、标签的出现次数分类
##### 复杂度
设对象数为 $k$，总权值为 $S$

| 操作 | 时间复杂度 |
|---|---|
| 构造 | $O(k)$ |
| `high` | $O(1)$ |
| 枚举全部重对象 | $O(S/B)$ |
空间复杂度 $O(k)$
#### 小参数预处理与大参数暴力
---
另一类常见根号分治不是按对象频率，而是按询问参数 $k$ 分类
若 $k<B$，参数种类只有 $O(B)$ 个，可以预处理
若 $k\ge B$，并且每次暴力处理都会至少前进或消耗 $k$ 个单位，则单次最多处理
$$
O\left(\frac Sk\right)\le O\left(\frac SB\right)
$$
典型结构为
```text
k < B
    对每个小 k 预处理答案

k >= B
    直接按 k 跳跃 / 枚举
    操作次数 <= S / k <= S / B
```
例如每次按照步长 `k` 访问位置：
```cpp
if (k < B) {
    // 读取预处理的 f[k]
} else {
    for (int i = st; i < n; i += k) {
        // 暴力处理
    }
}
```
##### 注意事项
- “大参数暴力更快”必须有类似 $S/k$ 的上界才能成立
- 小参数预处理复杂度需要单独计算，不能机械认为是 $O(SB)$
- 若小参数预处理为 $O(PB)$、大参数单次为 $O(S/B)$，应根据 $P,S,q$ 平衡 $B$
- `B=sqrt(S)` 只是最常见选择，不一定最优
#### 度数分治
---
无向图中令
$$
w_u=\deg(u),\quad S=\sum_u\deg(u)=2m
$$
则
- 轻点满足 $\deg(u)<B$
- 重点数量至多为 $2m/B$
这是根号分治非常典型的应用
下面的板子维护**动态点权**，支持：
- 单点权值增加
- 查询一个点所有邻点的权值和
轻点查询直接枚举邻边，重点查询预处理答案
```cpp
template<class T = i64>
struct DegSum {
    const vector<vector<int>> &g;
    int n, B;
    vector<int> id, hi;
    vector<vector<pair<int, int>>> hs;
    vector<T> a, s;
    explicit DegSum(const vector<vector<int>> &g_, vector<T> a_ = {}, int bs = 0)
        : g(g_), n(g.size()), id(n, -1), hs(n), a(move(a_)) {
        if (a.empty()) a.assign(n, T{});
        i64 d{};
        for (const auto &e : g) d += e.size();
        B = bs ? bs : max(1, int(sqrt(max<i64>(1, d))));
        for (int u = 0; u < n; ++ u) {
            if (g[u].size() >= B) {
                id[u] = hi.size();
                hi.push_back(u);
            }
        }
        s.assign(hi.size(), T{});
        // 统计 u 与每个重点之间的边数，重边只保留一项
        vector<int> cnt(hi.size());
        for (int u = 0; u < n; ++ u) {
            vector<int> used;
            for (int v : g[u]) {
                int h{ id[v] };
                if (h != -1 && cnt[h] ++ == 0) used.push_back(h);
            }
            for (int h : used) {
                hs[u].push_back({ h, cnt[h] });
                cnt[h] = 0;
            }
        }
        for (int h = 0; h < hi.size(); ++ h) {
            for (int v : g[hi[h]]) s[h] += a[v];
        }
    }
    void add(int u, T x) {
        a[u] += x;
        for (auto [h, c] : hs[u]) s[h] += x * c;
    }
    T ask(int u) const {
        if (id[u] != -1) return s[id[u]];
        T res{};
        for (int v : g[u]) res += a[v];
        return res;
    }
};
```
##### 成员变量
- `B`：度数分类阈值
- `id[u]`：重点 `u` 的编号，轻点为 `-1`
- `hi`：所有重点
- `hs[u]`：`{h,c}` 表示 `u` 与重点 `hi[h]` 之间有 `c` 条边
- `a[u]`：点权
- `s[h]`：重点 `hi[h]` 所有邻点的点权和
##### 接口
- `DegSum(g, a, bs)`：预处理轻重点，`a` 为空时初始点权全为 `0`
- `add(u, x)`：令点 `u` 的权值增加 `x`
- `ask(u)`：查询 `u` 所有邻点的点权和
##### 注意事项
- `g` 应为无向图邻接表，每条边双向加入
- `g` 的生命周期必须覆盖 `DegSum`
- 若传入 `a`，要求 `a.size() == g.size()`
- 默认不支持动态加边删边，图结构变化后轻重分类可能失效
- 若存在重边，查询会按邻接表中的边重复计贡献
- `ask(u)` 不包含 `u` 自身，除非图中存在自环
- 单点赋值可以写成 `add(u, x - a[u])`
##### 常见用法
```cpp
DegSum<> d(g, a);

d.add(u, x);
i64 ans = d.ask(u);
```
##### 复杂度
设无向图有 $m$ 条边，阈值为 $B$
重点数量为
$$
O\left(\frac mB\right)
$$
因此

| 操作 | 时间复杂度 |
|---|---|
| 构造 | $O(n+m)$ |
| `add` | $O(m/B)$ |
| 轻点 `ask` | $O(B)$ |
| 重点 `ask` | $O(1)$ |
空间复杂度 $O(n+m)$
取
$$
B=\Theta(\sqrt m)
$$
时单次操作最坏为
$$
O(\sqrt m)
$$
#### 常见分类方式
| 分类对象    | 规模量 `w` | 重对象数量上界               |
| ------- | ------- | --------------------- |
| 数值 / 颜色 | 出现次数    | $O(n/B)$              |
| 图上节点    | 度数      | $O(m/B)$              |
| 集合      | 集合大小    | $O(S/B)$              |
| 参数 `k`  | 参数本身    | 通常用 `k<B` 与 `k>=B` 分类 |
#### 注意事项
- 根号分治本质上不是固定算法，而是利用“轻对象单个便宜、重对象数量少”平衡复杂度
- 在写复杂度前先明确总量 $S$ 是什么，不能看到“大小分类”就直接写 $O(\sqrt n)$
- 高频/低频分类时通常应先离散化，避免值域过大
- 重对象预处理如果需要两两关系，空间可能达到 $O((S/B)^2)$，应提前检查
- 若轻对象处理不是 $O(B)$，或重对象数量不能由 $S/B$ 控制，就需要重新选择阈值或换算法
- 与 3.9.1 的数列分块相比，这一节的“块”通常不是连续下标区间，而是按频率、度数、参数大小进行分类

> [!tip]
> 赛场上判断能不能根号分治，优先找一个总量受限的量 $S$，再问两个问题：小于 $B$ 的对象能否暴力处理，大于等于 $B$ 的对象是否只有 $O(S/B)$ 个  
> 两个条件同时成立，基本就找到了大小分类的切入点
