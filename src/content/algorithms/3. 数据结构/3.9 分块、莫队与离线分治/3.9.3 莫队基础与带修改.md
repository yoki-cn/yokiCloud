### 莫队基础与带修改
---
普通莫队按左端点分块，并让相邻块中的右端点反向排序以减少指针移动，常用块长包括 `n / min(n, sqrt(q))` 与约 $\sqrt n$
带修改莫队在询问中增加时间维，按左端点块、右端点块、时间排序，推荐块长可取 `pow(n, 0.6666)`
#### 普通莫队
---
```cpp
struct Mo {
    struct Q {
        int l, r, id;
    };
    int n, B;
    vector<Q> q;
    explicit Mo(int n_, int bs = 0) : n(n_), B(bs) {}
    void ask(int l, int r, int id) { q.push_back({ l, r, id }); }
    template<class Add, class Del, class Save>
    void run(Add add, Del del, Save save) {
        if (q.empty()) return;
        if (!B) {
            int k{ max(1, min(n, int(sqrt(q.size())))) };
            B = max(1, n / k);
        }
        sort(q.begin(), q.end(), [&](const Q &a, const Q &b) {
            int x{ a.l / B }, y{ b.l / B };
            if (x != y) return x < y;
            return x & 1 ? a.r < b.r : a.r > b.r;
        });
        int l{}, r{};
        for (auto [ql, qr, id] : q) {
            while (l > ql) add(-- l);
            while (r < qr) add(r ++);
            while (l < ql) del(l ++);
            while (r > qr) del(-- r);
            save(id);
        }
    }
};
```
##### 成员变量
- `n`：序列长度
- `B`：块长，传 `0` 时根据询问数自动选择
- `q`：所有离线询问
- `Q::l,r`：询问区间 `[l,r)`
- `Q::id`：询问编号
##### 接口
- `Mo(n, bs)`：构造莫队，`bs = 0` 时自动选择块长
- `ask(l, r, id)`：加入区间 `[l,r)` 的询问，$O(1)$
- `run(add, del, save)`：排序询问并依次处理
- `add(p)`：将位置 `p` 加入当前区间
- `del(p)`：将位置 `p` 移出当前区间
- `save(id)`：当前状态即询问 `id` 的答案，在此保存答案
##### 注意事项
- 下标为 `0base`，区间统一使用 `[l,r)`
- 所有询问必须提前得到，属于离线算法
- `add()`、`del()` 应能快速维护当前答案，通常要求 $O(1)$
- `del()` 必须能够撤销一个元素的贡献，若删除难以维护，应使用后面的回滚莫队
- 莫队本身不处理离散化，值域过大时应提前离散化
- 默认块长参考资料中的 `n / sqrt(q)` 型选择，相比固定 $\sqrt n$ 在询问数较少时通常更合适
- 奇偶块内让 `r` 交替升降不会改变正确性，只用于减少常数
##### 常见用法
###### 区间不同数个数
```cpp
vector<int> cnt(m), ans(qn);
int cur{};
Mo mo(n);
for (int i = 0; i < qn; ++ i) {
    int l, r;
    cin >> l >> r;
    mo.ask(l, r, i);
}
auto add = [&](int p) {
    if (cnt[a[p]] ++ == 0) ++ cur;
};
auto del = [&](int p) {
    if (-- cnt[a[p]] == 0) -- cur;
};
mo.run(add, del, [&](int id) {
    ans[id] = cur;
});
```
##### 复杂度
设有 $q$ 次询问，块长为 $B$，且 `add()`、`del()` 均为 $O(1)$
按上述排序方式估算，总指针移动量为
$$
O\left(qB+\frac{n^2}{B}\right)
$$
取
$$
B\approx\frac n{\sqrt q}
$$
得到
$$
O(n\sqrt q)
$$
再加排序复杂度 $O(q\log q)$
当 $q=\Theta(n)$ 时即常见的
$$
O(n\sqrt n)
$$
空间复杂度 $O(q)$，不计题目自身维护的信息
#### 带修改莫队
---
普通莫队只移动左右端点，带修改莫队额外维护一个时间指针 `t`
每个询问记录
```text
(l, r, t)
```
其中 `t` 表示该询问之前已经发生的修改次数
```cpp
struct MoMod {
    struct Q {
        int l, r, t, id;
    };
    int n, B;
    vector<Q> q;
    explicit MoMod(int n_, int bs = 0) : n(n_), B(bs) {}
    void ask(int l, int r, int t, int id) { q.push_back({ l, r, t, id }); }
    template<class Add, class Del, class Chg, class Save>
    void run(Add add, Del del, Chg chg, Save save) {
        if (q.empty()) return;
        if (!B) B = max(1, int(pow(max(1, n), 2.0 / 3)));
        ranges::sort(q, [&](const Q &a, const Q &b) {
            int x{ a.l / B }, y{ b.l / B };
            if (x != y) return x < y;
            int u{ a.r / B }, v{ b.r / B };
            if (u != v) return x & 1 ? u > v : u < v;
            return u & 1 ? a.t > b.t : a.t < b.t;
        });
        int l{}, r{}, t{};
        for (auto [ql, qr, qt, id] : q) {
            while (l > ql) add(-- l);
            while (r < qr) add(r ++);
            while (l < ql) del(l ++);
            while (r > qr) del(-- r);
            while (t < qt) chg(t ++, l, r);
            while (t > qt) chg(-- t, l, r);
            save(id);
        }
    }
};
```
##### 成员变量
- `n`：序列长度
- `B`：块长
- `Q::l,r`：查询区间 `[l,r)`
- `Q::t`：该询问之前的修改次数
- `Q::id`：询问编号
##### 接口
- `MoMod(n, bs)`：构造，`bs = 0` 时默认取约 $n^{2/3}$ 的块长
- `ask(l, r, t, id)`：加入询问，其中 `t` 为此前修改次数
- `run(add, del, chg, save)`：运行带修改莫队
- `add(p)` / `del(p)`：加入或删除当前版本中位置 `p` 的元素
- `chg(k, l, r)`：切换第 `k` 次修改，要求同一函数既能应用也能撤销
- `save(id)`：保存当前询问答案
##### 可逆修改
```cpp
struct C {
    int p, x;
};
vector<C> c;
auto chg = [&](int k, int l, int r) {
    auto &[p, x] = c[k];
    if (l <= p && p < r) del(p);
    swap(a[p], x);
    if (l <= p && p < r) add(p);
};
```
执行一次后
- `a[p]` 变成修改后的值
- `c[k].x` 保存修改前的值
再次执行同一个 `chg(k)` 就会恢复原状态
##### 常见用法
###### 动态区间不同数个数
假设初始值与所有修改值已经一起离散化
```cpp
struct C {
    int p, x;
};
vector<C> c;
MoMod mo(n);
int qid{};
for (int i = 0; i < q; ++ i) {
    char op;
    cin >> op;
    if (op == 'Q') {
        int l, r;
        cin >> l >> r;
        mo.ask(l, r, c.size(), qid ++);
    } else {
        int p, x;
        cin >> p >> x;
        c.push_back({ p, x });
    }
}
vector<int> cnt(m), ans(qid);
int cur{};
auto add = [&](int p) {
    if (cnt[a[p]] ++ == 0) ++ cur;
};
auto del = [&](int p) {
    if (-- cnt[a[p]] == 0) -- cur;
};
auto chg = [&](int k, int l, int r) {
    auto &[p, x] = c[k];
    if (l <= p && p < r) del(p);
    swap(a[p], x);
    if (l <= p && p < r) add(p);
};
mo.run(add, del, chg, [&](int id) {
    ans[id] = cur;
});
```
##### 注意事项
- 只适用于可以离线的修改与询问
- 这里的修改模型是单点赋值
- `Q::t` 必须等于该询问之前发生的修改数
- 时间移动时若修改位置位于当前 `[l,r)` 内，必须先删除旧贡献，再加入新贡献
- `chg()` 必须可逆，使用 `swap` 是最简写法
- 使用 `swap` 后修改数组 `c` 会随时间移动发生变化，莫队结束后不应再认为 `c[k].x` 是最初读入的新值
- 若需要再次运行同一批数据，应重新复制初始数组与修改数组
- 带修改莫队常数明显大于普通莫队，没有修改时不要使用这一版本
##### 复杂度
带修改莫队的块长取约
$$
B=n^{2/3}
$$
设有 $q$ 次询问、$u$ 次修改，按上述三维排序估算移动量为
$$
O\left(qB+\frac{n^2}{B}+\frac{un^2}{B^2}\right)
$$
当
$$
q,u=O(n)
$$
且
$$
B=\Theta(n^{2/3})
$$
时为
$$
O(n^{5/3})
$$
另有排序复杂度 $O(q\log q)$
空间复杂度 $O(q+u)$，不计题目自身维护的信息
