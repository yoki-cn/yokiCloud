### 回滚、树上与二次离线莫队
---
三类扩展分别解决普通莫队的不同限制

| 方法 | 适用情况 |
|---|---|
| 回滚莫队 | `add` 容易，`del` 很难，但状态可以撤销 |
| 树上莫队 | 查询对象是树上路径 |
| 二次离线莫队 | 移动端点的贡献本身无法 $O(1)$ 计算，但能转成前缀离线统计 |

| 情况 | 优先选择 |
|---|---|
| 加入、删除都容易 | 普通莫队 |
| 有单点修改 | 带修改莫队 |
| 加入容易、删除难，但可回滚 | 回滚莫队 |
| 树上路径询问 | 树上莫队 |
| 树上路径 + 单点修改 | 双欧拉序 + 带修改莫队 |
| 端点贡献较慢，但能转成前缀离线事件 | 二次离线莫队 |
#### 回滚莫队
---
普通莫队要求左右端点能够反复加入和删除
回滚莫队只让跨块询问的右端点单调增加，左端点每次临时加入，求完答案后恢复快照
同一块内部的短询问直接暴力
```cpp
struct RollbackMo {
    struct Q {
        int l, r, id;
    };
    int n, B;
    vector<Q> q;
    explicit RollbackMo(int n_, int bs = 0) : n(n_), B(bs) {}
    void ask(int l, int r, int id) {
        q.push_back({ l, r, id });
    }
    template<class Add, class Snap, class Roll, class Save>
    void run(Add add, Snap snap, Roll roll, Save save) {
        if (q.empty()) return;
        if (!B) {
            int k{ max(1, min(n, int(sqrt(q.size())))) };
            B = max(1, n / k);
        }
        sort(q.begin(), q.end(), [&](const Q &a, const Q &b) {
            int x{ a.l / B }, y{ b.l / B };
            if (x != y) return x < y;
            return a.r < b.r;
        });
        for (int s = 0; s < q.size(); ) {
            int b{ q[s].l / B }, e{ s };
            while (e < int(q.size()) && q[e].l / B == b) ++ e;
            int br{ min(n, (b + 1) * B) };
            auto base{ snap() };
            int k{ s };
            // 同块询问：长度不超过 B，直接暴力
            while (k < e && q[k].r <= br) {
                auto h{ snap() };
                for (int i = q[k].l; i < q[k].r; ++ i) add(i);
                save(q[k].id);
                roll(h);
                ++ k;
            }
            // 跨块询问：右端点单调增加，左端点临时加入
            int r{ br };
            for (; k < e; ++ k) {
                while (r < q[k].r) add(r ++);
                auto h{ snap() };
                for (int i = br - 1; i >= q[k].l; -- i) add(i);
                save(q[k].id);
                roll(h);
            }
            roll(base);
            s = e;
        }
    }
};
```
##### 接口说明
- `RollbackMo(n, bs)`：构造，`bs = 0` 时自动选择块长
- `ask(l, r, id)`：加入 `[l,r)` 的询问
- `add(p)`：将位置 `p` 加入当前状态
- `snap()`：返回当前状态快照
- `roll(s)`：恢复到快照 `s`
- `save(id)`：保存当前答案
##### 常见用法
例如维护
$$
\max_x cnt_x\cdot val_x
$$
以下示例要求 val[x] >= 0，空区间答案为 0。删除某个值后最大值很难恢复，但增加和撤销都很简单
```cpp
vector<int> cnt(m);
vector<pair<int, i64>> his;
i64 cur{};
auto add = [&](int p) {
    int x{ a[p] };
    his.push_back({ x, cur });
    ++ cnt[x];
    cur = max(cur, 1LL * cnt[x] * val[x]);
};
auto snap = [&]() {
    return his.size();
};
auto roll = [&](size_t s) {
    while (his.size() > s) {
        auto [x, old]{ his.back() };
        his.pop_back();
        -- cnt[x];
        cur = old;
    }
};
RollbackMo mo(n);
for (int i = 0; i < q; ++ i) {
    mo.ask(l[i], r[i], i);
}
mo.run(add, snap, roll, [&](int id) {
    ans[id] = cur;
});
```
##### 注意事项
- 下标为 `0base`，区间为 `[l,r)`
- 不需要实现 `del()`
- `add()` 产生的全部状态变化都必须可以被 `roll()` 恢复
- `snapshot()` 通常直接返回历史栈大小
- 跨块询问内部 `r` 必须保持单调，因此不能像普通莫队一样使用奇偶块反转 `r`
- 同块询问不能直接混入跨块状态，否则会破坏右侧永久部分
- 如果 `del()` 本来就能 $O(1)$ 完成，普通莫队更简单
- 典型适用状态是“增加容易，删除后答案难恢复”，例如最大值类统计
##### 复杂度
设块长为 $B$，`add / rollback` 单次修改为 $O(1)$
总修改次数为
$$
O\left(qB+\frac{n^2}{B}\right)
$$
取
$$
B\approx\frac n{\sqrt q}
$$
时为
$$
O(n\sqrt q)
$$
当 $q=\Theta(n)$ 时为
$$
O(n\sqrt n)
$$
另有排序复杂度 $O(q\log q)$
#### 树上莫队
---
树上路径不能直接表示为普通 DFS 序中的一个区间
树上莫队为每个节点记录两次：
- 进入节点时记录一次
- 离开节点时再记录一次
于是节点在当前欧拉区间中出现**奇数次**时，恰好表示它属于当前路径状态
设
$$
p=\operatorname{lca}(u,v)
$$
并调整到 `in[u] <= in[v]`
若 `p = u`
$$
[u,v]\longrightarrow[in_u,in_v]
$$
否则
$$
[u,v]\longrightarrow[out_u,in_v]
$$
并额外加入 `p`
依赖 **3.9.3 普通莫队** 与已有 LCA
```cpp
struct TreeMo {
    struct Q {
        int l, r, p, id;
    };
    int n, B;
    vector<int> in, out, e;
    vector<Q> q;
    explicit TreeMo(int n_, int bs = 0) : n(n_), B(bs), in(n), out(n) {}
    // ===== 双欧拉序 =====
    void build(const vector<vector<int>> &g, int root = 0) {
        e.clear();
        e.reserve(2 * n);
        if (!n) return;
        vector<pair<int, int>> st{{root, -1}};
        while (!st.empty()) {
            auto [u, fa]{ st.back() };
            st.pop_back();
            if (u < 0) {
                u = ~u;
                out[u] = e.size();
                e.push_back(u);
                continue;
            }
            in[u] = e.size();
            e.push_back(u);
            st.push_back({~u, fa});
            for (int v : g[u]) if (v != fa) st.push_back({v, u});
        }
    }
    // ===== 路径转莫队区间 =====
    template<class Lca>
    void ask(int u, int v, int id, Lca lca) {
        if (in[u] > in[v]) swap(u, v);
        int p{ lca(u, v) };
        if (p == u) q.push_back({ in[u], in[v] + 1, -1, id });
        else q.push_back({ out[u], in[v] + 1, p, id });
    }
    // ===== 复用普通莫队 =====
    template<class Tog, class Save>
    void run(Tog tog, Save save) {
        Mo mo(e.size(), B);
        for (int i = 0; i < int(q.size()); ++ i) {
            mo.ask(q[i].l, q[i].r, i);
        }
        auto move = [&](int p) {
            tog(e[p]);
        };
        mo.run(move, move, [&](int i) {
            auto &[l, r, p, id]{ q[i] };
            if (p != -1) tog(p);
            save(id);
            if (p != -1) tog(p);
        });
    }
};
```
##### 接口说明
- `TreeMo(n, bs)`：构造
- `build(g, root)`：生成长度为 `2n` 的双欧拉序
- `ask(u, v, id, lca)`：加入路径询问
- `run(tog, save)`：使用普通莫队处理所有路径
- `tog(u)`：切换节点 `u` 是否属于当前状态
- `save(id)`：保存当前路径答案
##### 常见用法
###### 路径不同颜色数
```cpp
TreeMo tm(n);
tm.build(g, 0);
for (int i = 0; i < q; ++ i) {
    tm.ask(u[i], v[i], i, [&](int x, int y) {
        return hld.lca(x, y);
    });
}
vector<int> on(n), cnt(m), ans(q);
int cur{};
auto tog = [&](int u) {
    int x{ col[u] };
    if (on[u]) {
        if (-- cnt[x] == 0) -- cur;
    } else {
        if (cnt[x] ++ == 0) ++ cur;
    }
    on[u] ^= 1;
};
tm.run(tog, [&](int id) {
    ans[id] = cur;
});
```
##### 注意事项
- 依赖 3.9.3 的 `Mo`
- LCA 直接复用已有板子，不在这里重复实现
- 每个节点在双欧拉序中恰好出现两次
- `tog(u)` 必须是自反操作，执行两次恢复原状态
- 非祖先路径的 LCA 不在对应莫队区间内，因此保存答案前临时加入
- `build()` 不保存 `g`，可以直接复用已有树结构的邻接表
- 当前版本处理**点信息**
- 若处理边信息，通常将边权挂到较深端点，但 LCA 是否需要排除会改变，不能直接照搬点权版
- 使用显式栈生成双欧拉序，避免极深链递归栈溢出
##### 树上带修改莫队
树上带修改不需要再造一套全新思想
路径仍按上面的双欧拉序转换，排序部分换成 **3.9.3 `MoMod`**
修改节点 `u` 时，不应根据欧拉位置判断是否在区间中，而应直接看当前节点开关 `on[u]`
```cpp
struct C {
    int u, x;
};
vector<C> c;
auto chg = [&](int k, int, int) {
    auto &[u, x]{ c[k] };
    bool in{ bool(on[u]) };
    if (in) tog(u);
    swap(col[u], x);
    if (in) tog(u);
};
```
也就是说
```text
树上带修改莫队
=
双欧拉序路径转换
+
节点 toggle
+
3.9.3 带修改莫队的时间维
```
通常不需要再独立维护一份完整模板
##### 复杂度
欧拉序构造为
$$
O(n)
$$
路径转换需要额外的 LCA 复杂度
$$
O(qT_{\rm lca})
$$
随后是在长度 `2n` 的序列上运行普通莫队
若 `tog()` 为 $O(1)$，当 $q=\Theta(n)$ 时通常为
$$
O(n\sqrt n)
$$
#### 二次离线莫队
---
普通莫队要求每移动一次端点，就能立刻算出这一步产生的答案变化
二次离线莫队处理的是：
> 单次端点贡献本身不够快，但这份贡献可以写成某种**前缀状态对一个区间的统计**

于是第一次莫队只负责记录：
```text
在前缀 p 的状态下
查询区间 [l,r]
贡献符号为 +1 / -1
```
第二次统一扫描前缀，再批量处理这些事件
参考资料中的经典模型为：
> 查询 `[l,r]` 内满足 `i < j` 且 `popcount(a[i] xor a[j]) = k` 的数对数量

其实现先记录 `range[p]` 事件，之后重新扫描数组并统一处理
这一技巧高度依赖具体贡献公式，因此不强行封装成万能类
#### XOR 数对二次离线莫队
---
查询 `[l,r)` 内满足
$$
i<j,\quad
\operatorname{popcount}(a_i\oplus a_j)=k
$$
的数对数量
```cpp
vector<i64> mo2_xor(const vector<int> &src, const vector<pair<int, int>> &qs, int k, int W = 14, int bs = 0) {
    struct Q {
        int l, r, id;
        i64 d{};
    };
    struct E {
        int id, l, r, s;
    };
    int n{ int(src.size()) }, m{ int(qs.size()) };
    if (!m) return {};
    if (!n) return vector<i64>(m);
    int S{ 1 << W };
    vector<int> a(n + 2), mask;
    for (int i = 1; i <= n; ++ i) {
        a[i] = src[i - 1];
    }
    for (int x = 0; x < S; ++ x) {
        if (__builtin_popcount(unsigned(x)) == k) {
            mask.push_back(x);
        }
    }
    // f[i]：a[i + 1] 与前缀 a[1..i] 构成的合法数对数
    vector<int> f(n + 1), g(S);
    for (int i = 1; i <= n; ++ i) {
        for (int x : mask) ++ g[a[i] ^ x];
        if (i < n) f[i] = g[a[i + 1]];
    }
    vector<Q> q;
    q.reserve(m);
    for (int i = 0; i < m; ++ i) {
        auto [l, r]{ qs[i] };
        q.push_back({ l + 1, r, i, 0 });
    }
    int B;
    if (bs) B = bs;
    else B = max(1, n / min(n, max(1, int(sqrt(m)))));
    sort(q.begin(), q.end(), [&](const Q &a, const Q &b) {
        int x{ (a.l - 1) / B }, y{ (b.l - 1) / B };
        if (x != y) return x < y;
        return x & 1 ? a.r < b.r : a.r > b.r;
    });
    vector<vector<E>> ev(n + 1);
    int L{ 1 }, R{};
    for (int i = 0; i < m; ++ i) {
        int l{ q[i].l }, r{ q[i].r };
        if (R < r) ev[L - 1].push_back({ i, R + 1, r, -1 });
        while (R < r) q[i].d += f[R ++];
        if (R > r) ev[L - 1].push_back({ i, r + 1, R, 1 });
        while (R > r) q[i].d -= f[-- R];
        if (L < l) ev[R].push_back({ i, L, l - 1, -1 });
        while (L < l) {
            q[i].d += f[L - 1] + (k == 0);
            ++ L;
        }
        if (L > l) ev[R].push_back({ i, l, L - 1, 1 });
        while (L > l) {
            q[i].d -= f[L - 2] + (k == 0);
            -- L;
        }
    }
    // ===== 第二次离线：扫描前缀并处理所有记录事件 =====
    ranges::fill(g, 0);
    for (int i = 1; i <= n; ++ i) {
        for (int x : mask) ++ g[a[i] ^ x];
        for (auto [id, l, r, s] : ev[i]) {
            for (int x = l; x <= r; ++ x) {
                q[id].d += 1LL * g[a[x]] * s;
            }
        }
    }
    // q[i].d 是相邻莫队状态的答案变化量
    for (int i = 1; i < m; ++ i) {
        q[i].d += q[i - 1].d;
    }
    vector<i64> ans(m);
    for (auto [l, r, id, d] : q) {
        ans[id] = d;
    }
    return ans;
}
```
##### 接口说明
- `mo2_xor(a, qs, k, W, bs)`：回答所有 XOR 数对询问
- `a[i]`：要求 `0 <= a[i] < 2^W`
- `qs[i] = {l,r}`：查询 `[l,r)`
- `k`：要求 XOR 后二进制中恰有 `k` 个 `1`
- `W`：值域二进制位数，要求 0 <= W < 31，且计数数组可以放入内存
- `bs = 0`：自动选择莫队块长
- 返回值按原询问顺序排列
##### 核心变量
- `mask`：所有 `popcount(mask) = k` 的掩码
- `f[i]`：`a[i+1]` 与前缀 `[1,i]` 中元素构成的合法数对数
- `q[i].d`：第 `i` 个莫队状态相对前一个状态的答案增量
- `ev[p]`：扫描到前缀 `p` 时需要计算的第二批离线事件
- `s = ±1`：事件贡献符号
##### 常见用法
```cpp
vector<pair<int, int>> qs(q);
for (auto &[l, r] : qs) {
    cin >> l >> r;
    -- l;
}
auto ans = mo2_xor(a, qs, k, 14);
for (i64 x : ans) {
    cout << x << '\n';
}
```
##### 注意事项
- 这是二次离线莫队的**经典具体模型**，不是万能通用类
- 外部接口统一使用 `0base + [l,r)`
- 内部为了方便使用来源中的前缀公式，转换成 `1base`
- 要求 `0 <= k <= W`
- `2^W` 不能过大，否则枚举 `mask` 和计数数组本身不可接受
- 当 `k = 0` 时自身异或满足条件，因此左端点移动公式需要额外的 `(k == 0)`
- `q[i].d` 保存的是莫队排序后相邻状态之间的变化量，最后必须做前缀累加
- 第二次离线的事件不是普通询问，而是第一次莫队移动端点产生的“待计算贡献”
- 奇偶块排序只减少端点移动次数，不改变事件公式
##### 什么时候能二次离线
若移动端点需要计算
$$
\sum_{i=l}^{r-1} F(a_i,x)
$$
而存在可以离线维护的前缀函数
$$
P(p,x)=\sum_{i=0}^{p-1}F(a_i,x)
$$
那么一次端点变化可以改写为若干
```text
(prefix p, interval [l,r), sign)
```
事件
此时就可以考虑二次离线莫队
核心不是“跑两遍莫队”，而是：
```text
第一次莫队
    ↓
把无法快速算出的端点贡献记录下来
    ↓
第二次按某个前缀维统一扫描
    ↓
批量计算这些贡献
```
##### 复杂度
令
$$
C=\binom Wk
$$
即 `mask.size()`
掩码枚举
$$
O(2^W)
$$
前缀预处理与第二次扫描中维护关系计数
$$
O(nC)
$$
莫队产生并处理的区间总长度为
$$
O\left(qB+\frac{n^2}{B}\right)
$$
因此总复杂度为
$$
O\left(
2^W+nC+q\log q+
qB+\frac{n^2}{B}
\right)
$$
取
$$
B\approx\frac n{\sqrt q}
$$
时，莫队部分为
$$
O(n\sqrt q)
$$
当 $q=\Theta(n)$ 时总复杂度为
$$
O(2^W+nC+n\sqrt n)
$$
空间复杂度
$$
O(2^W+n+q)
$$
