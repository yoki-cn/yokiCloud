### 线段树分治动态连通性
---
依赖 [[3.2.6 可撤销 DSU]]
```cpp
struct DynamicConnectivity {
    struct Edge { int u, v; };
    int q, base{ 1 };
    vector<vector<Edge>> seg;
    explicit DynamicConnectivity(int q_) : q(q_) {
        while (base < q) base <<= 1;
        seg.resize(base << 1);
    }
    // 将边 (u, v) 加入整个生效区间 [l, r)
    void add_edge(int l, int r, int u, int v) {
        if (l >= r) return;
        for (l += base, r += base; l < r; l >>= 1, r >>= 1) {
            if (l & 1) seg[l ++].push_back({u, v});
            if (r & 1) seg[-- r].push_back({u, v});
        }
    }
private:
    // DFS 时间线段树：进入节点时加入整段有效边，退出时回滚
    template<class DSU, class F>
    void run(int p, DSU &dsu, F &answer) {
        int snap{ dsu.snapshot() };
        for (auto [u, v] : seg[p]) dsu.unite(u, v);
        if (p >= base) {
            int t{ p - base };
            if (t < q) answer(t, dsu);
        } else {
            run(p << 1, dsu, answer);
            run(p << 1 | 1, dsu, answer);
        }
        dsu.rollback(snap);
    }
public:
    template<class DSU, class F>
    void run(DSU &dsu, F answer) {
        if (q) run(1, dsu, answer);
    }
};
// ===== 边生命周期预处理：若已经知道每条边的生效区间 [l, r)，以下代码可直接删除 =====
struct EdgeIntervals {
    struct Interval { int l, r, u, v; };
    vector<Interval> segs;
private:
    struct State { int cnt{}, l{}; };
    map<pair<int, int>, State> opened;
    static pair<int, int> norm(int u, int v) {
        if (u > v) swap(u, v);
        return {u, v};
    }
public:
    // 边的出现次数从 0 变为 1 时开始一个有效区间
    void add(int t, int u, int v) {
        auto &s{ opened[norm(u, v)] };
        if (s.cnt ++ == 0) s.l = t;
    }
    // 边的出现次数从 1 变为 0 时结束有效区间
    void erase(int t, int u, int v) {
        auto e{ norm(u, v) };
        auto it{ opened.find(e) };
        auto &[cnt, l]{ it->second };
        if (-- cnt) return;
        if (l < t) segs.push_back({l, t, e.first, e.second});
        opened.erase(it);
    }
    // 将操作结束后仍存在的边补成 [l, q)
    void close_all(int q) {
        for (auto [e, s] : opened) {
            if (s.l < q) segs.push_back({s.l, q, e.first, e.second});
        }
        opened.clear();
    }
};
```
#### 接口说明
##### 时间定义
将时间 `t` 定义为**第 `t` 个操作执行后的图**，操作编号为 `0 ... q - 1`
若一条边：
- 在时间 `l` 加入
- 在时间 `r` 删除
并且删除操作执行后立即失效，则它的生效区间为：$[l,r)$]
因此时间 `l` 的状态包含该边，时间 `r` 的状态不包含该边
##### `DynamicConnectivity`
- `DynamicConnectivity(q)`：建立覆盖时间 `0 ... q - 1` 的时间线段树，$O(q)$
- `add_edge(l, r, u, v)`：表示无向边 `(u,v)` 在整个 `[l,r)` 内存在，$O(\log q)$
- `run(dsu, answer)`：遍历所有时间状态；在时间 `t` 调用 `answer(t, dsu)`，其中 `dsu` 恰好包含该时刻所有有效边
传入的 `DSU` 至少需要提供：
```cpp
int snapshot() const;
bool unite(int u, int v);
void rollback(int snap);
```
通常直接使用 [[3.2.6 可撤销 DSU]]
##### `EdgeIntervals`
`EdgeIntervals` 负责把在线形式的增删操作转换为若干边生命周期
- `add(t, u, v)`：时间 `t` 增加一份无向边 `(u,v)`
- `erase(t, u, v)`：时间 `t` 删除一份 `(u,v)`；要求删除前至少存在一份
- `close_all(q)`：全部操作读完后调用，将仍存在的边补成 `[l,q)`
- `segs`：生成的所有 `{l,r,u,v}` 有效区间
对于连通性，多条完全相同的平行边只影响“是否至少存在一条”。因此本实现维护边的**出现次数**：
- `0 -> 1`：开始生命周期
- `1 -> 0`：结束生命周期
- 中间的重复加入 / 删除不会产生额外重叠区间
例如：
```text
+ e
+ e
- e
- e
```
只产生从第一次 `+` 到最后一次 `-` 的一个有效区间
#### 注意事项
- 本算法是**离线算法**：必须先获得所有边的生命周期，才能运行时间线段树
- `DynamicConnectivity` 依赖 [[3.2.6 可撤销 DSU]]，不能替换成使用路径压缩的一般 `DSU`
- `run()` 已经负责每个时间树节点的 `snapshot()` / `rollback()`，回调中不要自行回滚
- 回调中的 DSU 只表示当前时间 `t`；不要保存代表元、父节点或内部引用供之后使用
- 所有时间区间统一使用左闭右开 `[l,r)`
- `0 <= l <= r <= q`
- `q = 0` 时 `run()` 不执行任何回调
- `EdgeIntervals` 将无向边统一规范为 `u <= v`，避免 `(u,v)` 与 `(v,u)` 被视为不同边
- `erase()` 要求对应边当前出现次数大于 `0`；若题目允许删除不存在的边，需要按题意额外处理
- 若题目的边是普通**集合语义**，重复加入已经存在的边应当无效，则必须在预处理阶段忽略这种重复加入；当前 `EdgeIntervals` 按**多重边语义**维护出现次数
- 若初始图已经存在边，可以在预处理开始时把这些边视为在时间 `0` 加入
- 时间端点一定要根据题目的“操作前查询 / 操作后查询”重新确认，不能机械套用 `[add_time, erase_time)`
##### 与动态二分图等问题的关系
时间线段树本身只负责：
```text
进入时间区间
→ 加入这一段始终有效的约束
→ 递归
→ 回滚
```
因此也能用于动态二分图、动态异或约束等问题，但需要对应的 [[3.2.9 可撤销异或关系与二分图 DSU]]
不能简单把普通 `RollbackDSU` 换成非可撤销的 `XorDSU`；冲突状态和关系势能也必须能够随快照一起回滚
如果边还带关系 `w`，则相应扩展 `Edge`：
```cpp
struct Edge {
    int u, v, w;
};
```
并把 DFS 中的：
```cpp
dsu.unite(u, v);
```
改成对应关系 DSU 的约束加入接口即可
#### 常见用法
##### 完整增删边 + 连通性询问
假设：
- `op[t] == '+'`：加入边
- `op[t] == '-'`：删除边
- `op[t] == '?'`：询问两点是否连通
- 所有点已经转换为 `0base`
```cpp
EdgeIntervals life;

for (int t = 0; t < q; ++ t) {
    if (op[t] == '+') life.add(t, u[t], v[t]);
    else if (op[t] == '-') life.erase(t, u[t], v[t]);
}

life.close_all(q);

DynamicConnectivity dc(q);
for (auto [l, r, u, v] : life.segs) {
    dc.add_edge(l, r, u, v);
}

RollbackDSU dsu(n);
vector<bool> ans(q);

dc.run(dsu, [&](int t, RollbackDSU &cur) {
    if (op[t] == '?') {
        ans[t] = cur.same(u[t], v[t]);
    }
});

for (int t = 0; t < q; ++ t) {
    if (op[t] == '?') {
        cout << (ans[t] ? "YES\n" : "NO\n");
    }
}
```
##### 已经知道边的生命周期
如果题目直接给出所有：
```text
[l, r) : 边 (u, v) 存在
```
则完全不需要 `EdgeIntervals`：
```cpp
DynamicConnectivity dc(q);

for (auto [l, r, u, v] : intervals) {
    dc.add_edge(l, r, u, v);
}

RollbackDSU dsu(n);

dc.run(dsu, [&](int t, RollbackDSU &cur) {
    // 查询时间 t 的图
});
```
#### 复杂度
设：
- `q` 为时间点数量
- `m` 为预处理后得到的边有效区间数量
- `k` 为连通性询问数量
每个 `[l,r)` 被拆到 $O(\log q)$ 个时间线段树节点，因此共执行 $O(m\log q)$ 次 DSU 合并
使用按大小合并的 `RollbackDSU` 时，每次 `unite()` / `same()` 最坏为 $O(\log n)$
因此时间线段树部分复杂度为：
$$O(m\log q\log n+k\log n+q)$$
若使用 `EdgeIntervals` 的 `map` 预处理全部 `q` 次增删操作，还需要 $O(q\log q)$ 量级的预处理时间
时间线段树存储 $O(q+m\log q)$ 个节点 / 边记录
加上可撤销 DSU 后，总空间复杂度为：
$$O(n+q+m\log q)$$
