### 二维与扩展域 DSU
---
依赖 [[3.2.1 一般 DSU]]
```cpp
struct GridDSU {
    int n, m;
    DSU dsu;
    GridDSU(int n_, int m_) : n(n_), m(m_), dsu(n * m) {}
    int id(int x, int y) const { return x * m + y; }
    bool unite(int x1, int y1, int x2, int y2) { return dsu.unite(id(x1, y1), id(x2, y2)); }
    bool same(int x1, int y1, int x2, int y2) { return dsu.same(id(x1, y1), id(x2, y2)); }
};
template<int K>
struct DomainDSU {
    int n;
    DSU dsu;
    explicit DomainDSU(int n_) : n(n_), dsu(K * n) {}
    int id(int x, int state) const { return state * n + x; }
    // 加入 state(y) - state(x) ≡ delta (mod K)
    bool add_relation(int x, int y, int delta) {
        delta %= K;
        if (delta < 0) delta += K;
        // 已确定相对关系时先检查，避免冲突后污染并查集
        for (int s = 0; s < K; ++ s) {
            if (dsu.same(id(x, 0), id(y, s))) return s == delta;
        }
        for (int s = 0; s < K; ++ s) {
            dsu.unite(id(x, s), id(y, (s + delta) % K));
        }
        return true;
    }
};
```
#### 接口说明
##### `GridDSU`
将二维坐标 `(x, y)` 映射为：
```cpp
x * m + y
```
再交给普通 `DSU` 维护
- `GridDSU(n, m)`：建立 `n × m` 个位置，$O(nm)$
- `id(x, y)`：返回 `(x, y)` 的一维编号，$O(1)$
- `unite(x1, y1, x2, y2)`：合并两个位置，均摊 $O(\alpha(nm))$
- `same(x1, y1, x2, y2)`：判断两个位置是否连通，均摊 $O(\alpha(nm))$
##### `DomainDSU<K>`
每个对象 `x` 被拆成 `K` 个状态：
$$(x,0),(x,1),\ldots,(x,K-1)$$
`add_relation(x, y, delta)` 加入：
$$state(y)-state(x)\equiv delta\pmod K$$
即对所有 `s` 建立：
$$(x,s)\sim(y,s+delta\bmod K)$$
接口：
- `DomainDSU<K>(n)`：建立 `Kn` 个状态节点，$O(Kn)$
- `id(x, state)`：返回状态节点对应的一维编号，$O(1)$
- `add_relation(x, y, delta)`：加入关系；与已有约束冲突返回 `false`，否则返回 `true`，均摊 $O(K\alpha(Kn))$
#### 注意事项
##### 二维映射
- `GridDSU` 只负责二维编号映射，不会自动合并四邻域
##### 扩展域
- `add_relation()` 的定义固定为 $state(y)-state(x)\equiv delta\pmod K$，关系方向不能写反
- `delta` 会自动归一化到 `[0,K)`
- 新关系冲突时返回 `false`，且不会加入该关系
- 扩展域占用 $K$ 倍节点；若只是维护模 `K` 势能关系，带权并查集通常更省空间
- `K = 2` 常用于两类关系 / 二分约束，`K = 3` 常用于食物链一类三状态关系
#### 常见用法
##### 网格连通
```cpp
GridDSU dsu(n, m);
if (x + 1 < n) dsu.unite(x, y, x + 1, y);
if (y + 1 < m) dsu.unite(x, y, x, y + 1);
```
##### 二扩展域
```cpp
DomainDSU<2> dsu(n);
if (!dsu.add_relation(x, y, delta)) { // 关系冲突
}
```
##### 食物链三扩展域
```cpp
DomainDSU<3> dsu(n);
if (!dsu.add_relation(x, y, delta)) { // 关系冲突
}
```
先按题目定义把关系转换成：
$$state(y)-state(x)\equiv delta\pmod 3$$
再调用接口
#### 复杂度
##### `GridDSU`

|操作|时间复杂度|
|---|---|
|构造|$O(nm)$|
|`id`|$O(1)$|
|`unite` / `same`|均摊 $O(\alpha(nm))$|
空间复杂度：$O(nm)$
##### `DomainDSU<K>`

|操作|时间复杂度|
|---|---|
|构造|$O(Kn)$|
|`id`|$O(1)$|
|`add_relation`|均摊 $O(K\alpha(Kn))$|
空间复杂度：$O(Kn)$
