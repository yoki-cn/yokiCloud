### 带权 DSU（势能并查集）
---
维护约束：
$$val[v]-val[u]=d$$
其中 `dis[x]` 表示 `val[x] - val[pa[x]]`，路径压缩后表示 `val[x] - val[root]`
```cpp
template<class T = i64>
struct WeightedDSU {
    int cc;
    vector<int> pa, siz;
    vector<T> dis;
    explicit WeightedDSU(int n) : cc(n), pa(n), siz(n, 1), dis(n, T{}) { ranges::iota(pa, 0); }
    static bool equal(const T &a, const T &b) {
        if constexpr (is_floating_point_v<T>) return abs(a - b) <= 1e-9;
        else return a == b;
    }
    int find(int x) {
        if (pa[x] == x) return x;
        int p{ pa[x] };
        pa[x] = find(p);
        dis[x] += dis[p];
        return pa[x];
    }
    bool same(int u, int v) { return find(u) == find(v); }
    // 加入 val[v] - val[u] = d；与已有约束冲突时返回 false。
    bool add_relation(int u, int v, const T &d) {
        int ru{ find(u) }, rv{ find(v) };
        T du{ dis[u] }, dv{ dis[v] };
        if (ru == rv) return equal(dv - du, d);
        if (siz[ru] < siz[rv]) {
            pa[ru] = rv;
            dis[ru] = dv - du - d;
            siz[rv] += siz[ru];
        } else {
            pa[rv] = ru;
            dis[rv] = d + du - dv;
            siz[ru] += siz[rv];
        }
        -- cc;
        return true;
    }
    optional<T> diff(int u, int v) {
        int ru{ find(u) }, rv{ find(v) };
        if (ru != rv) return nullopt;
        return dis[v] - dis[u];
    }
    // ===== 以下接口若只需要加入约束和查询两点差值，可以直接删除 =====
    T potential(int x) {
        find(x);
        return dis[x];
    }
    int size(int x) { return siz[find(x)]; }
    int count() const { return cc; }
};
```
#### 接口说明
##### 成员变量
- `pa[x]`：并查集森林中的父节点
- `siz[x]`：当 `x` 为根时表示集合大小
- `dis[x]`：`val[x] - val[pa[x]]`；执行 `find(x)` 后为 `val[x] - val[root]`
- `cc`：当前连通块数量
##### 接口
- `WeightedDSU<T>(n)`：建立 `n` 个独立节点，$O(n)$
- `find(x)`：返回代表元并同步维护势能，均摊 $O(\alpha(n))$
- `same(u, v)`：判断两点是否连通，均摊 $O(\alpha(n))$
- `add_relation(u, v, d)`：加入 $val[v]-val[u]=d$，若与已有约束冲突返回 `false`，否则返回 `true`，均摊 $O(\alpha(n))$
- `diff(u, v)`：连通时返回 $val[v]-val[u]$，否则返回 `nullopt`，均摊 $O(\alpha(n))$
- `potential(x)`：返回 `val[x] - val[root]`，均摊 $O(\alpha(n))$  
- `size(x)`：返回所在集合大小，均摊 $O(\alpha(n))$
- `count()`：返回当前集合数量，$O(1)$
#### 注意事项
- **方向固定为** $val[v]-val[u]=d$，调用 `add_relation(u, v, d)` 时不要把 `u`、`v` 或 `d` 的符号写反
- `add_relation()` 返回的是**约束是否自洽**；重复加入已有且一致的关系返回 `true`
- `dis[x]` 只在 `find(x)` 后表示 `x` 到当前根的完整势能差
- `potential(x)` 依赖当前代表元，不能当成绝对值保存后长期使用
- 使用路径压缩，不能直接用于可撤销 DSU
- `T` 的运算结果必须不会溢出；整数距离、前缀和等应先估计范围
- 浮点类型默认使用绝对误差 `1e-9` 判断冲突，精度要求不同应修改 `equal()`
- 自定义 `T` 时至少需要支持 `T{}`、`+=`、`+`、`-` 和 `==`
- 这一实现按加法形式书写，适用于整数、浮点数、二维偏移量等**可加交换群**
#### 常见用法
##### 区间和约束
设前缀和为 `s[i]`，若已知：
$$a_l+\cdots+a_r=sum$$
则：
$$s[r]-s[l-1]=sum$$
可以直接写：
```cpp
WeightedDSU<i64> dsu(n + 1);
if (!dsu.add_relation(l - 1, r, sum)) {
    cout << "conflict\n";
}
auto ans = dsu.diff(l - 1, r);
if (ans) cout << *ans << '\n';
```
##### 两点坐标差
```cpp
struct Offset2D {
    i64 x{}, y{};
    Offset2D &operator+=(const Offset2D &o) {
        x += o.x;
        y += o.y;
        return *this;
    }
    friend Offset2D operator+(Offset2D a, const Offset2D &b) {
        return a += b;
    }
    friend Offset2D operator-(const Offset2D &a, const Offset2D &b) {
        return {a.x - b.x, a.y - b.y};
    }
    friend bool operator==(const Offset2D &a, const Offset2D &b) {
        return a.x == b.x && a.y == b.y;
    }
};
WeightedDSU<Offset2D> dsu(n);
dsu.add_relation(u, v, {dx, dy});
auto delta = dsu.diff(u, v);
if (delta) {
    cout << delta->x << ' ' << delta->y << '\n';
}
```
此时：
$$pos[v]-pos[u]=(dx,dy)$$
##### 差分约束一致性
```cpp
WeightedDSU<i64> dsu(n);
for (auto [u, v, d] : constraints) {
    if (!dsu.add_relation(u, v, d)) {
        cout << "No\n";
        return;
    }
}
```
