### 异或关系与二分图 DSU
---
维护约束：
$$val[u]\oplus val[v]=w$$
其中 `xr[x]` 表示 `val[x] ^ val[pa[x]]`，路径压缩后表示 `val[x] ^ val[root]`
```cpp
template<class T = int>
struct XorDSU {
    int cc;
    vector<int> pa, siz;
    vector<T> xr;
    explicit XorDSU(int n) : cc(n), pa(n), siz(n, 1), xr(n, T{}) { ranges::iota(pa, 0); }
    int find(int x) {
        if (pa[x] == x) return x;
        int p{ pa[x] };
        pa[x] = find(p);
        xr[x] ^= xr[p];
        return pa[x];
    }
    bool same(int u, int v) { return find(u) == find(v); }
    // 加入 val[u] ^ val[v] = w；与已有约束冲突时返回 false。
    bool add_relation(int u, int v, T w) {
        int ru{ find(u) }, rv{ find(v) };
        T xu{ xr[u] }, xv{ xr[v] };
        if (ru == rv) return (xu ^ xv) == w;
        if (siz[ru] < siz[rv]) {
            swap(ru, rv);
            swap(xu, xv);
        }
        pa[rv] = ru;
        xr[rv] = xu ^ xv ^ w;
        siz[ru] += siz[rv];
        -- cc;
        return true;
    }
    optional<T> relation(int u, int v) {
        int ru{ find(u) }, rv{ find(v) };
        if (ru != rv) return nullopt;
        return xr[u] ^ xr[v];
    }
    // ===== 以下接口若只需要加入约束和判冲突，可以直接删除 =====
    T potential(int x) {
        find(x);
        return xr[x];
    }
    int size(int x) { return siz[find(x)]; }
    int count() const { return cc; }
};
using BipartiteDSU = XorDSU<int>;
```
#### 接口说明
##### 成员变量
- `pa[x]`：并查集森林中的父节点
- `siz[x]`：当 `x` 为根时表示集合大小
- `xr[x]`：`val[x] ^ val[pa[x]]`；执行 `find(x)` 后为 `val[x] ^ val[root]`
- `cc`：当前连通块数量
##### 接口
- `XorDSU<T>(n)`：建立 `n` 个独立节点，$O(n)$
- `find(x)`：返回代表元，同时维护路径上的异或势能，均摊 $O(\alpha(n))$
- `same(u, v)`：判断两点是否已有确定的相对关系，均摊 $O(\alpha(n))$
- `add_relation(u, v, w)`：加入 `val[u] ^ val[v] = w`；若与已有约束矛盾返回 `false`，否则返回 `true`，均摊 $O(\alpha(n))$
- `relation(u, v)`：若两点连通，返回 `val[u] ^ val[v]`；否则返回 `nullopt`，均摊 $O(\alpha(n))$
- `potential(x)`：返回 `val[x] ^ val[root]`，均摊 $O(\alpha(n))$
- `size(x)`：返回所在集合大小，均摊 $O(\alpha(n))$
- `count()`：返回当前集合数量，$O(1)$
#### 注意事项
- `add_relation()` 的返回值表示**约束是否自洽**，不是“是否发生了集合合并”
- 重复加入已经存在且一致的关系仍返回 `true`
- `relation()` 使用 `optional<T>`，不要使用 `-1` 表示“不连通”，因为 `-1` 可能本身就是合法的按位异或结果
- `xr[x]` 会在路径压缩时同步更新；不能只压缩 `pa[x]`
- `potential(x)` 是相对**当前代表元**的势能，不是绝对的 `val[x]`；并查集合并后代表元可能改变
- 使用路径压缩，不能直接用于可撤销并查集
- 默认节点编号为 `0base`
#### 二分图约束
二分图染色可以看作：
$$color[u]\oplus color[v]=1$$
因此：
- 异色：`w = 1`
- 同色：`w = 0`
- 无向图中每加入一条普通边，就加入异色约束 `1`
- 自环会产生 `color[u] ^ color[u] = 1`，立即检测出矛盾
#### 常见用法
##### 维护异或关系
```cpp
XorDSU<int> dsu(n);
if (!dsu.add_relation(u, v, w)) {
    // 与已有关系冲突
}
auto w = dsu.relation(u, v);
if (w) {
    cout << *w << '\n';
}
```
##### 动态判断二分图约束
```cpp
BipartiteDSU dsu(n);
for (auto [u, v] : edges) {
    if (!dsu.add_relation(u, v, 1)) {
        cout << "No\n";
        return;
    }
}
cout << "Yes\n";
```
##### 同色 / 异色混合约束
```cpp
// type = 0：要求同色
// type = 1：要求异色
if (!dsu.add_relation(u, v, type)) {
    // 矛盾
}
```
