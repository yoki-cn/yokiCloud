### 可撤销 DSU
---
```cpp
struct RollbackDSU {
    int cc;
    vector<int> pa, siz, his;
    explicit RollbackDSU(int n) : cc(n), pa(n), siz(n, 1) { ranges::iota(pa, 0); }
    // 不做路径压缩，使一次成功合并只修改一个父指针
    int find(int x) const {
        while (x != pa[x]) x = pa[x];
        return x;
    }
    bool same(int x, int y) const { return find(x) == find(y); }
    bool unite(int x, int y) {
        x = find(x), y = find(y);
        if (x == y) return false;
        if (siz[x] < siz[y]) swap(x, y);
        his.push_back(y);
        pa[y] = x;
        siz[x] += siz[y];
        -- cc;
        return true;
    }
    int size(int x) const { return siz[find(x)]; }
    int count() const { return cc; }
    int snapshot() const { return int(his.size()); }
    void rollback(int snap) {
        while (int(his.size()) > snap) {
            int y{ his.back() };
            his.pop_back();
            int x{ pa[y] };
            siz[x] -= siz[y];
            pa[y] = y;
            ++ cc;
        }
    }
};
```
#### 接口说明
##### 成员变量
- `pa[x]`：并查集森林中的父节点
- `siz[x]`：当 `x` 为根时表示所在集合大小
- `his`：成功合并的历史栈
- `cc`：当前连通块数量
##### 接口
- `RollbackDSU(n)`：建立 `0 ... n - 1` 的单点集合，$O(n)$
- `find(x)`：返回当前代表元，最坏 $O(\log n)$
- `same(x, y)`：判断两点是否连通，最坏 $O(\log n)$
- `unite(x, y)`：按大小合并；成功返回 `true`，原本连通返回 `false`，最坏 $O(\log n)$
- `size(x)`：返回所在连通块大小，最坏 $O(\log n)$
- `count()`：返回当前连通块数量，$O(1)$
- `snapshot()`：返回当前历史位置，用作回滚快照，$O(1)$
- `rollback(snap)`：撤销 `snap` 之后的全部成功合并，每撤销一次合并 $O(1)$
#### 注意事项
- **严禁路径压缩**。按大小合并保证并查集树高为 $O(\log n)$，同时使每次成功合并只需要记录一个修改
- `snapshot()` 返回的是**成功合并记录数**，不是调用 `unite()` 的次数
- `unite()` 发现两点已经连通时不会写入历史栈
- `rollback(snap)` 要求 `0 <= snap <= snapshot()`，通常只传入之前保存的快照
- 快照可以嵌套，但必须按照栈顺序回滚：先离开内层，再离开外层
- 回滚后，以前保存的代表元可能已经失效，需要重新调用 `find()`
- `siz[x]` 只有在 `x` 当前为根时有效
- 默认点编号为 `0base`
#### 常见用法
##### 临时修改后恢复
```cpp
RollbackDSU dsu(n);
int snap = dsu.snapshot();
dsu.unite(u, v);
dsu.unite(x, y);
// 在临时状态上查询
bool connected = dsu.same(a, b);
dsu.rollback(snap);
```
##### 时间线段树 / DFS 分治
```cpp
void dfs(int p, int l, int r) {
    int snap{ dsu.snapshot() };
    for (auto [u, v] : edges[p]) {
        dsu.unite(u, v);
    }
    if (r - l == 1) {
        ans[l] = dsu.same(query_u[l], query_v[l]);
    } else {
        int m{ (l + r) / 2 };
        dfs(p << 1, l, m);
        dfs(p << 1 | 1, m, r);
    }
    dsu.rollback(snap);
}
```
