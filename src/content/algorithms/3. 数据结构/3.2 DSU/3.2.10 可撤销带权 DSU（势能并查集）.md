### 可撤销带权 DSU（势能并查集）
---
维护可撤销约束：
$$val[v]-val[u]=d$$
其中 `dis[x]` 表示：
$$val[x]-val[pa[x]]$$
```cpp
template<class T = i64>
struct RollbackWeightedDSU {
    struct Change {
        int y;
        bool conflict;
    };
    int cc, bad{};
    vector<int> pa, siz;
    vector<T> dis;
    vector<Change> his;
    explicit RollbackWeightedDSU(int n) : cc(n), pa(n), siz(n, 1), dis(n, T{}) { ranges::iota(pa, 0); }
    static bool equal(const T &a, const T &b) {
        if constexpr (is_floating_point_v<T>) return abs(a - b) <= 1e-9;
        else return a == b;
    }
    // 不做路径压缩；返回 {根, val[x] - val[root]}
    pair<int, T> find(int x) const {
        T d{};
        while (x != pa[x]) {
            d += dis[x];
            x = pa[x];
        }
        return {x, d};
    }
    bool same(int u, int v) const { return find(u).first == find(v).first; }
    // 加入 val[v] - val[u] = d；返回该约束是否与当前已有约束一致
    bool add_relation(int u, int v, const T &d) {
        auto [ru, du]{ find(u) };
        auto [rv, dv]{ find(v) };
        if (ru == rv) {
            bool ok{ equal(dv - du, d) };
            his.push_back({-1, !ok});
            bad += !ok;
            return ok;
        }
        if (siz[ru] < siz[rv]) {
            his.push_back({ru, false});
            pa[ru] = rv;
            dis[ru] = dv - du - d;
            siz[rv] += siz[ru];
        } else {
            his.push_back({rv, false});
            pa[rv] = ru;
            dis[rv] = d + du - dv;
            siz[ru] += siz[rv];
        }
        -- cc;
        return true;
    }
    // ===== 回滚接口：线段树分治等算法依赖，不建议删除 =====
    int snapshot() const { return int(his.size()); }
    void rollback(int snap) {
        while (int(his.size()) > snap) {
            auto [y, conflict]{ his.back() };
            his.pop_back();
            if (y == -1) {
                bad -= conflict;
                continue;
            }
            int x{ pa[y] };
            siz[x] -= siz[y];
            pa[y] = y;
            dis[y] = T{};
            ++ cc;
        }
    }
    bool valid() const { return bad == 0; }
    int conflicts() const { return bad; }
    // ===== 扩展查询：若只判断当前约束系统是否合法，以下代码可直接删除 =====
    optional<T> diff(int u, int v) const {
        auto [ru, du]{ find(u) };
        auto [rv, dv]{ find(v) };
        if (ru != rv) return nullopt;
        return dv - du;
    }
    T potential(int x) const { return find(x).second; }
    int size(int x) const { return siz[find(x).first]; }
    int count() const { return cc; }
};
```
#### 接口说明
##### 成员变量
- `pa[x]`：并查集森林中的父节点
- `siz[x]`：当 `x` 为根时表示集合大小
- `dis[x]`：`val[x] - val[pa[x]]`
- `cc`：当前连通块数量
- `bad`：当前活跃约束中的矛盾数量
- `his`：所有加入约束对应的历史记录
##### 接口
- `RollbackWeightedDSU<T>(n)`：建立 `n` 个独立节点，$O(n)$
- `find(x)`：返回 `{root, val[x] - val[root]}`，最坏 $O(\log n)$
- `same(u, v)`：判断两点是否连通，最坏 $O(\log n)$
- `add_relation(u, v, d)`：加入 $val[v]-val[u]=d$，若与已有约束冲突返回 `false`，否则返回 `true`，最坏 $O(\log n)$
- `snapshot()`：保存当前完整约束状态，$O(1)$
- `rollback(snap)`：撤销到指定快照，每撤销一条约束 $O(1)$
- `valid()`：判断当前所有活跃约束是否整体自洽，$O(1)$
- `conflicts()`：返回当前矛盾约束数量，$O(1)$
- `diff(u, v)`：连通时返回 `val[v] - val[u]`，否则返回 `nullopt`，最坏 $O(\log n)$
- `potential(x)`：返回 `val[x] - val[root]`，最坏 $O(\log n)$
- `size(x)`：返回所在集合大小，最坏 $O(\log n)$
- `count()`：返回当前连通块数量，$O(1)$
#### 注意事项
- **不能使用路径压缩**；按大小合并保证并查集父链长度为 $O(\log n)$
- 约束方向始终固定为：$val[v]-val[u]=d$，调用时不能交换 `u/v` 后仍使用原来的 `d`
- `dis[x]` 只保存当前节点到直接父节点的势能差，`find()` 查询时沿父链累积
- 两个不同集合总能通过调整根之间的势能加入一条新关系，因此真正的冲突只会发生在两点已经连通时
- 同根且一致的关系也会写入历史记录，使 `snapshot()` 能准确对应完整约束状态
- 同根但冲突时不改变树结构，只令 `bad ++`
- `rollback()` 必须同时恢复并查集结构和 `bad`
- 即使当前已经存在矛盾，也不能跳过后续 `add_relation()`，否则之后回滚原冲突时会丢失本应存在的状态
- `valid()` 判断的是整个当前约束系统；不维护每个连通块单独的合法性
- 约束系统存在冲突时，`diff()` / `potential()` 返回的是维护森林确定的势能，不保证满足全部活跃约束
- 浮点类型默认使用绝对误差 `1e-9` 判断关系是否一致；精度要求特殊时修改 `equal()`
- 自定义 `T` 至少需要支持 `T{}`、`+=`、`+`、`-` 和 `==`
- 整数势能需要预先估计累加范围，必要时使用 `i64` / `i128`
- 默认点编号为 `0base`
#### 常见用法
##### 临时差分约束
```cpp
RollbackWeightedDSU<i64> dsu(n);

int snap{ dsu.snapshot() };

dsu.add_relation(0, 1, 5);  // val[1] - val[0] = 5
dsu.add_relation(1, 2, -2); // val[2] - val[1] = -2

auto d = dsu.diff(0, 2);
if (d) {
    cout << *d << '\n'; // 3
}

dsu.rollback(snap);
```
##### 判断动态差分约束是否矛盾
时间线段树中的约束需要包含 `d`：
```cpp
struct Edge {
    int u, v;
    i64 d;
};
```
进入时间线段树节点时：
```cpp
int snap{ dsu.snapshot() };

for (auto [u, v, d] : seg[p]) {
    dsu.add_relation(u, v, d);
}
```
叶子查询：
```cpp
ans[t] = dsu.valid();
```
退出节点：
```cpp
dsu.rollback(snap);
```
##### 动态相对坐标
```cpp
struct Offset2D {
    i64 x{}, y{};
    Offset2D &operator+=(const Offset2D &o) {
        x += o.x;
        y += o.y;
        return *this;
    }
    friend Offset2D operator+(Offset2D a, const Offset2D &b) { return a += b; }
    friend Offset2D operator-(const Offset2D &a, const Offset2D &b) { return {a.x - b.x, a.y - b.y}; }
    friend bool operator==(const Offset2D &a, const Offset2D &b) { return a.x == b.x && a.y == b.y; }
};
RollbackWeightedDSU<Offset2D> dsu(n);
dsu.add_relation(u, v, {dx, dy});
auto d = dsu.diff(u, v);
```
表示：
$$pos[v]-pos[u]=(dx,dy)$$
