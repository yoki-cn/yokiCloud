### 连通块信息 DSU
---
```cpp
template<class Info, class Merge>
struct InfoDSU {
    vector<int> pa, siz;
    vector<Info> info;
    Merge merge;
    explicit InfoDSU(vector<Info> init, Merge merge_ = Merge())
        : pa(init.size()), siz(init.size(), 1), info(move(init)), merge(move(merge_)) {
        ranges::iota(pa, 0);
    }
    int find(int x) { return pa[x] == x ? x : pa[x] = find(pa[x]); }
    bool same(int x, int y) { return find(x) == find(y); }
    bool unite(int x, int y) {
        x = find(x), y = find(y);
        if (x == y) return false;
        if (siz[x] < siz[y]) swap(x, y);
        pa[y] = x;
        siz[x] += siz[y];
        info[x] = merge(info[x], info[y]);
        return true;
    }
    int size(int x) { return siz[find(x)]; }
    const Info &get(int x) { return info[find(x)]; }
};
```
#### 接口说明
##### 成员变量
- `pa[x]`：并查集森林中的父节点
- `siz[x]`：当 `x` 为根时，表示集合大小
- `info[x]`：当 `x` 为根时，表示整个集合的聚合信息
- `merge(a, b)`：合并两个连通块的信息
##### 接口
- `InfoDSU(init, merge)`：建立并查集，第 `i` 个单点集合初始信息为 `init[i]`，$O(n)$
- `find(x)`：返回代表元，均摊 $O(\alpha(n))$
- `same(x, y)`：判断是否属于同一集合，均摊 $O(\alpha(n))$
- `unite(x, y)`：合并集合并维护聚合信息，均摊 $O(\alpha(n) + T_{\text{merge}})$
- `size(x)`：返回集合大小，均摊 $O(\alpha(n))$
- `get(x)`：返回所在集合的聚合信息，均摊 $O(\alpha(n))$
#### 注意事项
- `siz[x]`、`info[x]` 仅当 `x` 为根时有效
- 外部查询连通块信息使用 `get(x)`，不要直接访问 `info[x]`
- 由于采用按大小合并，`merge(a, b)` 的左右参数顺序不固定；通常应满足交换律
- 若连通块信息的更新依赖具体连接边、端点或方向，仅有 `merge(info[x], info[y])` 通常不够，应针对题目重新设计合并接口
- 使用路径压缩，不能直接用于回滚
#### 常见用法
#### 连通块最大值
```cpp
struct MergeMax {
    int operator()(int x, int y) const { return max(x, y); }
};
InfoDSU<int, MergeMax> dsu(weight);
dsu.unite(u, v);
cout << dsu.get(u) << '\n';
```
##### 连通块自定义信息
```cpp
struct ComponentInfo {
    i64 sum{};
    int vertices{};
};
struct MergeComponent {
    ComponentInfo operator()(const ComponentInfo &a, const ComponentInfo &b) const {
        return {a.sum + b.sum, a.vertices + b.vertices};
    }
};
vector<ComponentInfo> init(n);
for (int i = 0; i < n; ++ i) {
    init[i] = {weight[i], 1};
}
InfoDSU<ComponentInfo, MergeComponent> dsu(init);
dsu.unite(u, v);
ComponentInfo info = dsu.get(u);
```
#### 复杂度
设一次 `Merge` 的复杂度为 $T_{\text{merge}}$

| 操作                               | 时间复杂度                                |
| -------------------------------- | ------------------------------------ |
| 构造                               | $O(n)$                               |
| `find` / `same` / `size` / `get` | 均摊 $O(\alpha(n))$                    |
| `unite`                          | 均摊 $O(\alpha(n) + T_{\text{merge}})$ |
空间复杂度：$O(n)$ 加 `Info` 的存储
