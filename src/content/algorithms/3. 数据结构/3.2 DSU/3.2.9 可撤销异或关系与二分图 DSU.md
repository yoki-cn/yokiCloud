### 可撤销异或关系与二分图 DSU
---
维护可撤销约束：
$$val[u]\oplus val[v]=w$$
其中 `xr[x]` 表示：
$$val[x]\oplus val[pa[x]]$$
```cpp
template<class T = int>
struct RollbackXorDSU {
    struct Change {
        int y;
        bool conflict;
    };
    int cc, bad{};
    vector<int> pa, siz;
    vector<T> xr;
    vector<Change> his;
    explicit RollbackXorDSU(int n) : cc(n), pa(n), siz(n, 1), xr(n, T{}) { ranges::iota(pa, 0); }
    // 不做路径压缩；返回 {根, val[x] ^ val[root]}
    pair<int, T> find(int x) const {
        T d{};
        while (x != pa[x]) {
            d ^= xr[x];
            x = pa[x];
        }
        return {x, d};
    }
    bool same(int u, int v) const { return find(u).first == find(v).first; }
    // 加入 val[u] ^ val[v] = w；返回该约束是否与当前已有约束一致
    bool add_relation(int u, int v, T w) {
        auto [ru, xu]{ find(u) };
        auto [rv, xv]{ find(v) };
        if (ru == rv) {
            bool ok{ (xu ^ xv) == w };
            his.push_back({-1, !ok});
            bad += !ok;
            return ok;
        }
        if (siz[ru] < siz[rv]) {
            swap(ru, rv);
            swap(xu, xv);
        }
        his.push_back({rv, false});
        pa[rv] = ru;
        xr[rv] = xu ^ xv ^ w;
        siz[ru] += siz[rv];
        -- cc;
        return true;
    }
    // ===== 回滚接口：线段树分治等算法依赖，不建议删除 =====
    int snapshot() const { return int(his.size()); }
    void rollback(int snap) {
        while (int(his.size()) > snap) {
            auto [y, conflict]{ his.back() };
            his.pop_back();
            if (y == -1) {
                bad -= conflict;
                continue;
            }
            int x{ pa[y] };
            siz[x] -= siz[y];
            pa[y] = y;
            xr[y] = T{};
            ++ cc;
        }
    }
    bool valid() const { return bad == 0; }
    int conflicts() const { return bad; }
    // ===== 扩展查询：若只判断当前约束系统是否合法，以下代码可直接删除 =====
    optional<T> relation(int u, int v) const {
        auto [ru, xu]{ find(u) };
        auto [rv, xv]{ find(v) };
        if (ru != rv) return nullopt;
        return xu ^ xv;
    }
    T potential(int x) const { return find(x).second; }
    int size(int x) const { return siz[find(x).first]; }
    int count() const { return cc; }
};
// 二分图专用封装：可直接接入只调用 unite(u, v) 的线段树分治
struct RollbackBipartiteDSU : RollbackXorDSU<int> {
    using RollbackXorDSU<int>::RollbackXorDSU;
    bool unite(int u, int v) { return add_relation(u, v, 1); }
};
```
#### 接口说明
##### 成员变量
- `pa[x]`：并查集森林中的父节点
- `siz[x]`：当 `x` 为根时表示集合大小
- `xr[x]`：`val[x] ^ val[pa[x]]`
- `cc`：当前连通块数量
- `bad`：当前活跃约束中产生的矛盾数量
- `his`：加入约束产生的历史记录
##### 接口
- `RollbackXorDSU<T>(n)`：建立 `n` 个独立节点，$O(n)$
- `find(x)`：返回 `{root, val[x] ^ val[root]}`，最坏 $O(\log n)$
- `same(u, v)`：判断两点是否已有确定的相对关系，最坏 $O(\log n)$
- `add_relation(u, v, w)`：加入 $val[u]\oplus val[v]=w$，若这条约束与当前已有约束冲突返回 `false`，否则返回 `true`，最坏 $O(\log n)$
- `snapshot()`：保存当前完整约束状态，$O(1)$
- `rollback(snap)`：回滚到指定快照，每撤销一条约束 $O(1)$
- `valid()`：判断当前所有活跃约束是否整体自洽，$O(1)$
- `conflicts()`：返回当前矛盾约束数量，$O(1)$
- `relation(u, v)`：连通时返回 `val[u] ^ val[v]`，否则返回 `nullopt`，最坏 $O(\log n)$
- `potential(x)`：返回 `val[x] ^ val[root]`，最坏 $O(\log n)$
- `size(x)`：返回所在集合大小，最坏 $O(\log n)$
- `count()`：返回当前连通块数量，$O(1)$
#### 二分图封装
`RollbackBipartiteDSU` 将每条普通无向边解释为：
$$color[u]\oplus color[v]=1$$
因此：
```cpp
dsu.unite(u, v);
```
等价于：
```cpp
dsu.add_relation(u, v, 1);
```
可以直接替换 [[3.2.8 线段树分治动态连通性]] 使用的普通 `RollbackDSU`
#### 二分图关系
对于染色 `color[x] ∈ {0,1}`：
- 异色：$color[u]\oplus color[v]=1$
- 同色：$color[u]\oplus color[v]=0$
普通无向图要求每条边两端异色，所以动态二分图直接使用 `RollbackBipartiteDSU`
#### 注意事项
- **不能使用路径压缩**；只使用按大小合并，保证树高为 $O(\log n)$
- `xr[x]` 始终只保存 `x` 到直接父节点的异或关系，`find()` 查询过程中累积到根
- `add_relation()` 的返回值表示**这一条新约束是否与当前状态一致**，不是是否真的进行了集合合并
- 两点已经连通且关系一致时仍然会写入一条历史记录，因为 `snapshot()` 维护的是完整的“约束加入状态”
- 两点已经连通但关系矛盾时，不修改并查集结构，而是令 `bad ++`
- 因此 `rollback()` 不仅需要撤销集合合并，还必须撤销冲突状态
- `snapshot()` 等于当前活跃的 `add_relation()` 历史记录数，而不是成功合并次数
- 即使当前 `bad > 0`，后续约束仍然必须正常处理；不能因为当前已经矛盾就提前跳过，否则回滚掉原冲突后状态会不完整
- `valid()` 判断的是**整个约束系统**是否无矛盾；本实现不维护“每个连通块各自是否矛盾”
- 当前约束系统存在矛盾时，`relation()` / `potential()` 仍会返回并查集生成森林确定的关系，但它不一定满足所有活跃约束；通常只在相关约束状态合法时使用
- `T` 需要支持 `T{}`、`^`、`^=` 和 `==`
- 默认点编号为 `0base`
#### 常见用法
##### 可撤销异或约束
```cpp
RollbackXorDSU<int> dsu(n);

int snap{ dsu.snapshot() };

dsu.add_relation(0, 1, 3);
dsu.add_relation(1, 2, 5);

auto w = dsu.relation(0, 2);
if (w) {
    cout << *w << '\n'; // 3 ^ 5
}

dsu.rollback(snap);
```
##### 动态二分图
可以直接与 [[3.2.8 线段树分治动态连通性]] 组合：
```cpp
DynamicConnectivity dc(q);

for (auto [l, r, u, v] : intervals) {
    dc.add_edge(l, r, u, v);
}

RollbackBipartiteDSU dsu(n);
vector<bool> ans(q);

dc.run(dsu, [&](int t, RollbackBipartiteDSU &cur) {
    if (op[t] == '?') {
        ans[t] = cur.valid();
    }
});
```
这里时间线段树仍然调用：
```cpp
dsu.unite(u, v);
```
但对于 `RollbackBipartiteDSU`，其含义已经变为加入异色约束
##### 动态同色 / 异色关系
若边本身带 `w`，不能使用仅保存 `(u,v)` 的普通 `DynamicConnectivity::Edge`，应将时间树中的边扩展为：
```cpp
struct Edge {
    int u, v, w;
};
```
进入节点时：
```cpp
dsu.add_relation(u, v, w);
```
叶子查询：
```cpp
bool ok = dsu.valid();
```
#### 复杂度

|操作|时间复杂度|
|---|---|
|构造|$O(n)$|
|`find` / `same`|最坏 $O(\log n)$|
|`add_relation`|最坏 $O(\log n)$|
|`relation` / `potential` / `size`|最坏 $O(\log n)$|
|`snapshot` / `valid` / `conflicts` / `count`|$O(1)$|
|撤销一条约束记录|$O(1)$|
`rollback(snap)` 若撤销 $k$ 条约束，复杂度为 $O(k)$
空间复杂度：$O(n+h)$，其中 $h$ 为当前历史栈中的约束记录数
