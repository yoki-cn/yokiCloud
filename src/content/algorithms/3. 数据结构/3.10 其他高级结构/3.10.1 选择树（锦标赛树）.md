> [!tip] 在功能上基本可以被线段树替代，常数也可以被 ZKW线段树 逼近，只展示一种思想以及最简洁的实现
### 败者树
内部节点只保存该场比赛的**败者编号**，全局额外保存最终胜者：
```cpp
template<class T, class Compare = less<T>>
struct LoserTree {
    int n, base{ 1 }, win{ -1 };
    Compare better;
    vector<T> val;
    vector<int> tr;
    explicit LoserTree(vector<T> val_, Compare better_ = Compare()) : n(val_.size()), better(better_), val(move(val_)) {
        while (base < n) base *= 2;
        tr.assign(2 * base, -1);
        if (!n) return;
        vector<int> w(2 * base, -1);
        for (int i = 0; i < n; ++ i) w[base + i] = i;
        for (int p = base - 1; p > 0; -- p) {
            int x = w[2 * p], y = w[2 * p + 1];
            if (x == -1 || y == -1) {
                w[p] = x == -1 ? y : x;
            } else {
                w[p] = best(x, y);
                tr[p] = w[p] == x ? y : x;
            }
        }
        win = w[1];
    }
    int best(int x, int y) const {
        if (x == -1) return y;
        if (y == -1) return x;
        if (better(val[x], val[y])) return x;
        if (better(val[y], val[x])) return y;
        return min(x, y);
    }
    int winner() const { return win; }
    const T &top() const { return val[win]; }
    void replace_winner(const T &v) {
        int x = win;
        val[x] = v;
        for (int p = (base + x) / 2; p > 0; p /= 2) {
            int y = tr[p];
            if (y == -1) continue;
            int z = best(x, y);
            if (z == x) tr[p] = y;
            else {
                tr[p] = x;
                x = y;
            }
        }
        win = x;
    }
};
```
这个版本有一个很重要的设计选择：
> [!tip] **只提供 `replace_winner()`，不提供任意 `set(id, v)`**
#### 成员变量
- `val[id]`：编号 `id` 当前对应的值
- `tr[p]`：比赛节点 `p` 中输掉的元素编号
- `win`：当前整个锦标赛的胜者编号
- `base`：不小于 `n` 的最小 $2$ 的幂
- `-1`：空位置 / 轮空
- `better(x, y)`：判断 `x` 是否比 `y` 更优
    - 默认 `less<T>`：较小值获胜
    - `greater<T>`：较大值获胜
若两个元素在 `Compare` 意义下等价，则编号较小者获胜，使结果确定
#### 接口
- `LoserTree(val)`：由初始序列构造败者树，$O(n)$
- `winner()`：返回当前胜者的原编号，要求非空，$O(1)$
- `top()`：返回当前胜者的值，要求非空，$O(1)$
- `replace_winner(v)`：将**当前胜者位置**的值替换为 `v`，并重新比赛，$O(\log n)$
#### 核心思想
胜者树的内部节点记录：*两个儿子谁赢了*
败者树则记录：*当前胜者一路打上来时，每一轮击败了谁*
例如当前胜者为 `x`，沿根路径可能记录：
```
x 击败 a
x 击败 b
x 击败 c
```
当 `x` 被取走并换成新值后，它无需重新和所有叶子比赛，只需要重新依次挑战：
```
a → b → c
```
也就是原来沿途的败者
因此 `replace_winner()` 的核心就是：
```cpp
for (int p = (base + x) / 2; p > 0; p >>= 1) {
    // 当前候选 x 与这一层原败者重新比赛
}
```
这也是“记录败者”比单纯重复记录胜者更有信息含义的地方
#### 注意事项
- `winner()`、`top()`、`replace_winner()` 要求结构非空
- 默认 `less<T>` 表示较小元素获胜，即维护最小值
- 败者树中的叶子位置固定，不支持动态增加或减少路数
- `replace_winner(v)` **只能修改当前胜者对应的位置**
	这一点尤其重要
	不能写：
	```cpp
	tree.val[id] = x;
	tree.replace_winner(...);
	```

	去试图修改任意 `id`
因为内部只记录了每场比赛的败者，没有保存所有子树当前胜者的信息；如果一个原本失败的元素被直接修改得更优，它可能需要从某个内部节点重新向上挑战，而仅靠当前败者信息无法从任意叶子直接恢复。
如果题目需要：
```cpp
任意修改 val[id]
然后查询全局最优
```
应使用前面的 `WinnerTree::set(id, v)`

> [!tip]  
> 因此胜者树和败者树并不是简单的“哪个更高级”：
> 
> - **任意点修改** → 胜者树
> - **反复替换当前最优元素** → 败者树
#### 常见用法
##### 查询最小值及来源
```cpp
LoserTree<int> t(a);
int id{ t.winner() };
int x{ t.top() };
```
其中：`id` 仍然是原数组位置
##### 替换当前最小值
```cpp
int id{ t.winner() };
// 第 id 路取出当前元素，并换成下一个元素
t.replace_winner(next);
```
更新后新的：`t.winner()` 就是新的全局最小值来源
##### 多路有序序列归并
这是败者树最值得放进板子的场景
假设有 $k$ 个已经升序的序列：
```cpp
vector<vector<int>> a(k);
vector<int> pos(k);
```
先取每一路当前元素构造败者树
如果使用一个足够大的哨兵值：
```cpp
vector<int> cur(k, INF);
for (int i = 0; i < k; ++ i) {
    if (!a[i].empty()) cur[i] = a[i][0];
}
LoserTree<int> t(cur);
```
不断取当前胜者：
```cpp
while (t.top() != INF) {
    int id{ t.winner() };
    cout << t.top() << ' ';
    ++ pos[id];
    if (pos[id] < a[id].size()) t.replace_winner(a[id][pos[id]]);
    else t.replace_winner(INF);
}
```
这里每次变化的恰好都是：`winner()`
对应的那一路，所以和败者树的接口完全吻合
##### 大根败者树
```cpp
LoserTree<int, greater<int>> t(a);
```
此时每轮胜者是最大值
#### 与胜者树对比

|特性|胜者树|败者树|
|---|---|---|
|内部节点记录|胜者|败者|
|全局胜者|`tr[1]`|单独保存 `win`|
|查询胜者|$O(1)$|$O(1)$|
|任意位置修改|$O(\log n)$|不适合|
|替换当前胜者|$O(\log n)$|$O(\log n)$|
|多路归并|可以|**更自然**|
|保留原来源编号|是|是|
|每层含义|子树胜者|当前胜者曾击败的对手|
特别是在：
```
k 路归并
外部排序
多个有序流合并
```
这些场景中，优先抄败者树
### 胜者树
胜者树是一棵锦标赛树：叶子表示固定位置的元素，每个内部节点记录两个儿子中更优元素的编号
适合：
- 元素位置固定
- 需要频繁修改某个位置的值
- 每次查询全局最优元素
- 希望同时得到最优元素的**原编号**
```cpp
template<class T, class Compare = less<T>>
struct WinnerTree {
    int n, base{ 1 };
    Compare better;
    vector<T> val;
    vector<int> tr;
    explicit WinnerTree(vector<T> val_, Compare better_ = Compare()) : n(val_.size()), better(better_), val(move(val_)) {
        while (base < n) base *= 2;
        tr.assign(2 * base, -1);
        for (int i = 0; i < n; ++ i) tr[base + i] = i;
        for (int p = base - 1; p > 0; -- p) pull(p);
    }
    int win(int x, int y) const {
        if (x == -1) return y;
        if (y == -1) return x;
        if (better(val[x], val[y])) return x;
        if (better(val[y], val[x])) return y;
        return min(x, y);
    }
    void pull(int p) { tr[p] = win(tr[2 * p], tr[2 * p + 1]); }
    void set(int id, const T &v) {
        val[id] = v;
        for (int p = (base + id) / 2; p > 0; p /= 2) pull(p);
    }
    int winner() const { return tr[1]; }
};
```
#### 成员变量
- `n`：实际元素数量
- `base`：不小于 `n` 的最小 $2$ 的幂
- `val[id]`：编号 `id` 当前对应的值
- `tr[p]`：锦标赛节点 `p` 当前胜者的原编号
- `-1`：不存在的叶子
- `better(x, y)`：判断 `x` 是否优于 `y`
若两个值等价，则：
```cpp
return min(x, y);
```
即编号较小者获胜
#### 接口
- `WinnerTree(val)`：由初始数组建树，$O(n)$
- `win(x, y)`：返回两个编号中的胜者，$O(1)$
- `set(id, v)`：把 `val[id]` 修改为 `v` 并维护到根，$O(\log n)$
- `winner()`：返回当前全局最优元素的编号，$O(1)$
当前最优值：
```cpp
int id{ t.winner() };
auto x = t.val[id];
```
#### 注意事项
- 默认 `less<T>` 表示较小值获胜，因此默认维护最小值
- `set(id, v)` 要求 `0 <= id < n`
- `winner()` 返回的是**元素编号**，不是元素值
- 当 `n = 0` 时，`winner()` 为 `-1`
- 胜者树维护的是固定的 `n` 个位置，没有直接提供动态插入 / 删除接口
- 如果需要“删除”某个位置，可以在具体题目中将其修改为一个永远不会获胜的哨兵值，但泛型板子本身不提供哨兵
- 相同值时按编号较小者优先，因此结果具有确定性
#### 与堆的区别

|需求|更适合|
|---|---|
|动态插入元素、删除堆顶|二叉堆|
|高效合并两个堆|左偏树 / 斜堆|
|固定位置单点修改，查询全局最优编号|胜者树|
例如：
```cpp
100000 个选手
每次修改其中一个选手成绩
询问当前第一名是谁
```
胜者树就非常自然
#### 常见用法
##### 动态维护最小值及其位置
```cpp
WinnerTree<int> t(a);
int id{ t.winner() };
cout << id << ' ' << t.val[id] << '\n';
t.set(3, 10);
id = t.winner();
```
##### 维护最大值
```cpp
WinnerTree<int, greater<int>> t(a);
```
##### 多路归并
胜者树经典用途之一是维护每一路当前候选：
```cpp
int id{ t.winner() };
// 取走第 id 路的当前元素后
t.set(id, next_value);
```
它比只保存值的普通堆更自然地保留“来自哪一路”的编号
