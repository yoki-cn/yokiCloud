### Patricia Trie（压缩位 Trie / crit-bit）
---
**解决问题：** 用压缩后的二进制 Trie 维护整数多重集，只保留真正发生分叉的二进制位，在保持异或最值和异或第 $k$ 小查询的同时，将有效节点数从普通 01 Trie 的最坏 $O(nB)$ 降到 $O(D)$，其中 $D$ 为不同键数量
```cpp
struct PatriciaTrie {
    struct Node {
        int ch[2]{};
        int bit{ -1 }; // -1 表示叶子，否则表示当前分叉位
        u64 value{};
        int cnt{}, siz{};
    };
private:
    vector<Node> tr{ {} };
    vector<int> free_nodes;
    int root{}, distinct{};
    // ===== 节点创建与回收：插入 / 删除依赖，不建议删除 =====
    int new_node(const Node &u) {
        if (!free_nodes.empty()) {
            int p{ free_nodes.back() };
            free_nodes.pop_back();
            tr[p] = u;
            return p;
        }
        tr.push_back(u);
        return int(tr.size()) - 1;
    }
    int new_leaf(u64 x) {
        Node u;
        u.value = x;
        u.cnt = u.siz = 1;
        return new_node(u);
    }
    int new_branch(int bit, int a, int b) {
        Node u;
        u.ch[0] = a;
        u.ch[1] = b;
        u.bit = bit;
        u.siz = tr[a].siz + tr[b].siz;
        return new_node(u);
    }
    void release(int p) { free_nodes.push_back(p); }
    // ===== 基础查找：count / add 依赖，不建议删除 =====
    static int direction(u64 x, int bit) { return x >> bit & 1ULL; }
    int find_leaf(u64 x) const {
        int p{ root };
        while (p && tr[p].bit >= 0) {
            p = tr[p].ch[direction(x, tr[p].bit)];
        }
        return p;
    }
public:
    explicit PatriciaTrie(int want = 0) {
        tr.reserve(1LL + 2LL * want);
        free_nodes.reserve(2LL * want);
    }
    int size() const { return root ? tr[root].siz : 0; }
    int distinct_size() const { return distinct; }
    bool empty() const { return root == 0; }
    // ===== 基础多重集接口：插入 / 查询 / 删除 =====
    int count(u64 x) const {
        int p{ find_leaf(x) };
        return p && tr[p].value == x ? tr[p].cnt : 0;
    }
    void add(u64 x) {
        if (!root) {
            root = new_leaf(x);
            distinct = 1;
            return;
        }
        int same{ find_leaf(x) };
        // 重复元素只增加叶子及祖先的计数，不新增节点
        if (tr[same].value == x) {
            int p{ root };
            while (tr[p].bit >= 0) {
                ++ tr[p].siz;
                p = tr[p].ch[direction(x, tr[p].bit)];
            }
            ++ tr[p].cnt;
            ++ tr[p].siz;
            return;
        }
        // x 与已有叶子最高的不同位就是新的分叉位
        int bit{ 63 - __builtin_clzll(x ^ tr[same].value) };
        // Patricia 要求根到叶子的分叉位严格递减
        int parent{}, side{}, p{ root };
        while (tr[p].bit > bit) {
            ++ tr[p].siz;
            parent = p;
            side = direction(x, tr[p].bit);
            p = tr[p].ch[side];
        }
        int q{ new_leaf(x) }, b{ direction(x, bit) };
        int branch{ b ? new_branch(bit, p, q) : new_branch(bit, q, p) };
        if (!parent) root = branch;
        else tr[parent].ch[side] = branch;
        ++ distinct;
    }
    bool erase(u64 x) {
        if (!root) return false;
        // 一条路径最多经过 64 个分叉位，再加一个叶子
        array<int, 66> path{};
        int len{}, p{ root };
        while (tr[p].bit >= 0) {
            path[len ++] = p;
            p = tr[p].ch[direction(x, tr[p].bit)];
        }
        path[len ++] = p;
        if (tr[p].value != x) return false;
        // 仍有重复元素，只减少路径计数
        if (tr[p].cnt > 1) {
            -- tr[p].cnt;
            for (int i = 0; i < len; ++ i) -- tr[path[i]].siz;
            return true;
        }
        // 整棵树只有这个叶子
        if (len == 1) {
            release(root);
            root = 0;
            distinct = 0;
            return true;
        }
        // 删除叶子后，其父分叉只剩一个儿子，应一起压缩掉
        int parent{ path[len - 2] }, side{ tr[parent].ch[1] == p };
        int sibling{ tr[parent].ch[side ^ 1] };
        for (int i = 0; i + 2 < len; ++ i) -- tr[path[i]].siz;
        if (len == 2) {
            root = sibling;
        } else {
            int grand{ path[len - 3] };
            int parent_side{ tr[grand].ch[1] == parent };
            tr[grand].ch[parent_side] = sibling;
        }
        release(p);
        release(parent);
        -- distinct;
        return true;
    }
    // ===== 异或序统计：若不需要异或查询，以下代码可直接删除 =====
    // 返回第 k 小的 x ^ y，k 为 0base
    optional<u64> kth_xor(u64 x, int k) const {
        if (k < 0 || k >= size()) return nullopt;
        int p{ root };
        while (tr[p].bit >= 0) {
            int b{ direction(x, tr[p].bit) };
            // 当前分叉位异或为 0 的一侧一定更小
            int q{ tr[p].ch[b] };
            if (k < tr[q].siz) {
                p = q;
            } else {
                k -= tr[q].siz;
                p = tr[p].ch[b ^ 1];
            }
        }
        return x ^ tr[p].value;
    }
    optional<u64> min_xor(u64 x) const { return kth_xor(x, 0); }
    optional<u64> max_xor(u64 x) const { return kth_xor(x, size() - 1); }
};
```
#### 成员含义
- `Node::bit`：内部节点的分叉位，范围为 `0..63`；叶子固定为 `-1`
- `Node::value`：叶子保存的完整 `u64` 键值
- `Node::cnt`：该叶子对应值的出现次数
- `Node::siz`：该节点子树中的元素总数，包含重复元素
- `root`：根节点编号，`0` 表示空树
- `distinct`：当前不同键的数量
#### 接口
- `PatriciaTrie(want)`：构造空树，`want` 为预计同时存在的不同键数量，仅用于预留空间
- `size()`：返回元素总数，包含重复元素，$O(1)$
- `distinct_size()`：返回不同元素数量，$O(1)$
- `empty()`：判断是否为空，$O(1)$
- `count(x)`：返回 `x` 的出现次数，$O(B)$
- `add(x)`：插入一个 `x`，允许重复，$O(B)$
- `erase(x)`：删除一个 `x`；不存在时返回 `false`，$O(B)$
- `kth_xor(x,k)`：返回第 `k` 小的 `x ^ y`，`k` 为 `0base`；不存在返回 `nullopt`，$O(B)$
- `min_xor(x)`：返回最小的 `x ^ y`；空集合返回 `nullopt`，$O(B)$
- `max_xor(x)`：返回最大的 `x ^ y`；空集合返回 `nullopt`，$O(B)$
这里的 $B=64$，但实际只访问当前树中存在的分叉位
令 `x = 0` 后：
- `kth_xor(0,k)` 就是集合中的第 `k` 小元素
- `min_xor(0)` 就是集合最小值
- `max_xor(0)` 就是集合最大值
#### 注意事项
- Patricia Trie 不像普通 01 Trie 那样逐位建节点。**内部节点只表示真正产生分叉的最高不同位，完整键只保存在叶子中**
- 根到叶子的 `bit` 必须严格递减，这是 Patricia Trie 最重要的结构不变量
- 若两个不同值为 `x,y`，其新分叉位为：
```cpp
63 - __builtin_clzll(x ^ y)
```
调用时保证 `x != y`，因此不会对 `0` 调用 `__builtin_clzll`
- 一个内部节点的两个儿子在 `bit` 位必然分别为 `0` 和 `1`；该子树内所有键在更高位均相同，因此异或查询仍然可以按照最高分叉位贪心
- `kth_xor()` 的顺序也是按完整 `u64` 异或结果排序。未显式出现的压缩位在当前子树内全部相同，不影响子树内部的大小关系
- `kth_xor()` 的 `k` 为 `0base`
- `min_xor/max_xor/kth_xor` 返回的是 **`x ^ y` 的值**，而不是被选择的原数 `y`；需要原数时可用：
```cpp
u64 y = x ^ result;
```
- 删除最后一个 `x` 时，不仅要删除叶子，还必须把只剩一个儿子的父分叉节点一起压缩掉
- 本实现会把删除掉的叶子和分叉节点加入 `free_nodes`，之后插入时优先复用，避免反复插入删除导致节点池持续增长
- 不要在 `tr.push_back()` 前保存 `Node &` 或指针；`vector` 扩容会使其失效。本实现始终保存节点编号
- 键按 `u64` 处理。如果直接把负的有符号整数转换成 `u64`，其二进制表示仍可用于异或，但普通数值大小关系会变成无符号顺序
- Patricia Trie **不需要像普通 01 Trie 那样选择 `B=31/60/64`**；本版本天然处理完整 `u64`
#### 与普通 01 Trie 的选择
普通 01 Trie 更简单，常数通常也更小：
```text
普通 01 Trie：
每个键最多新增 B 个节点
空间 O(DB)

Patricia Trie：
只为不同键建立叶子和真正的分叉
有效节点恰为 2D-1
空间 O(D)
```
因此：
- `B` 较小、内存足够：优先普通 01 Trie
- `u64` 键很多、公共前缀很长或普通 Trie 节点数过大：考虑 Patricia Trie
- 需要持久化版本：普通可持久化 01 Trie 通常更直接
- 只需要 `set/multiset` 的普通前驱后继，不涉及位结构：优先直接使用平衡树
#### 常见用法
##### 动态多重集
```cpp
PatriciaTrie trie(n);
trie.add(x);
trie.add(x);
cout << trie.count(x) << '\n'; // 2
trie.erase(x);
cout << trie.count(x) << '\n'; // 1
```
##### 最大异或
```cpp
if (auto ans = trie.max_xor(x)) {
    cout << *ans << '\n';
}
```
若还需要取得被选择的原数：
```cpp
if (auto ans = trie.max_xor(x)) {
    u64 y = x ^ *ans;
}
```
##### 第 k 小异或
```cpp
int k; // 0base
cin >> k;
if (auto ans = trie.kth_xor(x, k)) {
    cout << *ans << '\n';
}
```
##### 作为有序多重集查询第 k 小
```cpp
if (auto ans = trie.kth_xor(0, k)) {
    cout << *ans << '\n';
}
```
#### 复杂度
设 $D$ 为当前不同键数量，$B=64$

| 操作                                                            |  时间复杂度 |
| ------------------------------------------------------------- | -----: |
| `size / distinct_size / empty`                                | $O(1)$ |
| `count` / `add` / `erase` / `kth_xor` / `min_xor` / `max_xor` | $O(B)$ |
实际上每次操作只经过存在的分叉节点，路径上的 `bit` 严格递减，因此路径长度同时不超过 $B$ 和 $D$
若当前存在 $D>0$ 个不同键：
- 叶子恰有 $D$ 个
- 内部分叉节点恰有 $D-1$ 个
- 有效节点总数恰为 $2D-1$
节点池支持删除后复用，因此空间复杂度按历史同时存在的最大不同键数 $D_{\max}$ 计为 $O(D_{\max})$
