### FastSet（分层位集）
---
```cpp
struct FastSet {
    using u64 = uint64_t;
    int n;
    vector<vector<u64>> a;
    explicit FastSet(int n_ = 0) : n(n_) {
        assert(n >= 0);
        int m = max(n, 1);
        do {
            m = (m - 1) / 64 + 1;
            a.emplace_back(m, 0);
        } while (m > 1);
    }
    // ===== 基础操作：重复插入 / 删除不存在元素均无影响 =====
    bool empty() const { return a.back()[0] == 0; }
    bool contains(int x) const {
        assert(0 <= x && x < n);
        return (a[0][x >> 6] >> (x & 63)) & 1;
    }
    void insert(int x) {
        assert(0 <= x && x < n);
        for (auto &v : a) {
            u64 &w = v[x >> 6], mask = 1ULL << (x & 63);
            if (w & mask) break;
            w |= mask;
            if (w != mask) break;
            x >>= 6;
        }
    }
    void erase(int x) {
        assert(0 <= x && x < n);
        for (auto &v : a) {
            u64 &w = v[x >> 6], mask = 1ULL << (x & 63);
            if (!(w & mask)) break;
            w &= ~mask;
            if (w) break;
            x >>= 6;
        }
    }
    // ===== 前驱后继：next >= x，prev <= x；不存在返回 n / -1 =====
    int next(int x) const {
        x = max(x, 0);
        if (x >= n) return n;
        for (int d = 0; d < int(a.size()); ++ d) {
            int q = x >> 6;
            if (q >= int(a[d].size())) break;
            u64 w = a[d][q] >> (x & 63);
            if (w) {
                x += countr_zero(w);
                for (int e = d; e -- > 0;) {
                    x = (x << 6) | countr_zero(a[e][x]);
                }
                return x;
            }
            x = q + 1;
        }
        return n;
    }
    int prev(int x) const {
        x = min(x, n - 1);
        for (int d = 0; d < int(a.size()) && x >= 0; ++ d) {
            int q = x >> 6;
            u64 w = a[d][q] << (63 - (x & 63));
            if (w) {
                x -= countl_zero(w);
                for (int e = d; e -- > 0;) {
                    x = (x << 6) | (63 - countl_zero(a[e][x]));
                }
                return x;
            }
            x = q - 1;
        }
        return -1;
    }
    // ===== 批量建集 =====
    explicit FastSet(const string &s) : FastSet(int(s.size())) { build(s); }
    void build(const string &s) {
        assert(int(s.size()) == n);
        fill(a[0].begin(), a[0].end(), 0);
        for (int i = 0; i < n; ++ i) {
            if (s[i] == '1') a[0][i >> 6] |= 1ULL << (i & 63);
        }
        for (int d = 1; d < int(a.size()); ++ d) {
            fill(a[d].begin(), a[d].end(), 0);
            for (int i = 0; i < int(a[d - 1].size()); ++ i) {
                if (a[d - 1][i]) a[d][i >> 6] |= 1ULL << (i & 63);
            }
        }
    }
};
```
#### 成员变量
- `n`：整数全集 `[0, n)` 的大小，**不是**当前元素数量。
- `a[d]`：第 `d` 层的 `uint64_t` 块；`a[0]` 存储实际元素，更高层的第 `i` 位标记下层第 `i` 个块是否非空。
#### 构造与基础操作

| 接口            | 作用                        | 时间复杂度                |
| ------------- | ------------------------- | -------------------- |
| `FastSet(n)`  | 创建全集为 `[0, n)` 的空集合       | $O(1 + n / 64)$      |
| `empty()`     | 集合是否为空                    | $O(1)$               |
| `contains(x)` | 判断 `x` 是否存在               | $O(1)$               |
| `insert(x)`   | 插入 `x`；重复插入无影响            | $O(log_{64}(n + 1))$ |
| `erase(x)`    | 删除 `x`；不存在时无影响            | $O(log_{64}(n + 1))$ |
| `next(x)`     | 最小的 `>= x` 的元素；不存在返回 `n`  | $O(log_{64}(n + 1))$ |
| `prev(x)`     | 最大的 `<= x` 的元素；不存在返回 `-1` | $O(log_{64}(n + 1))$ |
#### 可删除的批量建集接口
- `FastSet(s)`：`s` 为 `0/1` 字符串，令 `n = s.size()`，将 `s[i] == '1'` 的下标加入集合，`O(n)`。
- `build(s)`：用长度为 `n` 的 `0/1` 字符串**覆盖**当前集合，重新构造所有层；`O(n)`。
- 不需要按字符串建集时，可直接删除 `FastSet(const string &)` 与 `build()`，其余代码无需修改。
#### 注意事项
- 集合元素为 **`0base` 的非负整数**，合法范围 `[0, n)`；`insert`、`erase`、`contains` 的参数必须在此范围内。
- `next(x)`、`prev(x)` **都是包含 `x` 的查询**。严格后继用 `next(x + 1)`，严格前驱用 `prev(x - 1)`（这里 `x` 通常在 `[0, n)`）。
- `next(x)` 的无答案标记是 `n`，**不是 `-1`**；`prev(x)` 的无答案标记是 `-1`。
- `next(x)` 支持 `x < 0`，视为从 `0` 开始；`x >= n` 返回 `n`。`prev(x)` 支持 `x >= n`，视为从 `n - 1` 开始；`x < 0` 返回 `-1`。
- `n = 0` 时允许构造空集合，`empty()` 为真，`next(x) == 0`、`prev(x) == -1`；此时不可调用 `contains/insert/erase`。
- 仅支持**集合语义**，不记录重复次数；不提供元素第 `k` 小、集合元素数量或区间统计接口。
- 采用稠密全集预分配，适合 `n` 已知且适中的整数键；对于稀疏的超大 / 64 位键域，改用 `set`、整数 Trie 或先离散化。**离散化后无法无代价地在线加入未预知的新值。**
#### 常见用法
##### 插入、删除和前驱后继
```cpp
FastSet st(100);           // 元素范围 [0, 100)
st.insert(3);
st.insert(10);
st.insert(10);            // 重复插入无影响
st.erase(3);

bool has = st.contains(10); // true
int a = st.next(4);       // 10：最小的 >= 4
int b = st.prev(9);       // -1：没有 <= 9 的元素
int c = st.next(11);      // 100：无答案
```
##### 严格前驱与严格后继
```cpp
int pre = st.prev(x - 1);  // 最大的 < x
int suc = st.next(x + 1);  // 最小的 > x
if (pre == -1) { /* 无严格前驱 */ }
if (suc == st.n) { /* 无严格后继 */ }
```
##### 按顺序枚举元素
```cpp
for (int x = st.next(0); x < st.n; x = st.next(x + 1)) {
    // 访问 x，按从小到大的顺序
}
```
##### 从 01 字符串建集（Library Checker：Predecessor Problem）
```cpp
string s;
cin >> s;
FastSet st(s);                // s[i] == '1' 表示包含 i

int x;
cin >> x;
int ans = st.next(x);
if (ans == st.n) ans = -1;    // 题目输出要求不存在时为 -1
cout << ans << '\n';
```
#### 复杂度
设整数全集大小为 `n`，层数 `L = max(1, ceil(log_64(max(n, 1))))`（仅按数量级理解）

| 操作 | 时间复杂度 |
|---|---|
| 构造空集 | `O(1 + n / 64)` |
| 单点插入、删除 | `O(L)`，遇到非空块可提前终止 |
| 成员查询、判空 | `O(1)` |
| 前驱、后继 | `O(L)` |
| 字符串批量建集 | `O(n)` |
空间复杂度为 `O(1 + n / 64)` 个 `uint64_t` 块，即 `O(n)` bit；上层所需块数逐层按 64 倍缩小。
