# 可持久化队列（Persistent Queue）

## 板子

```cpp
template<class T = i64>
struct PersistentQueue {
    struct Node {
        T val{};
        int dep{}, off{};
    };
    struct Version {
        int tail{}, len{};
    };
    vector<Node> tr{ Node{} };
    vector<int> up;
    vector<Version> ver{ Version{} };

    // ===== 倍增祖先：队首及随机访问依赖本函数，不建议删除 =====
    int ancestor(int p, int k) const {
        assert(0 <= k && k <= tr[p].dep);
        while (k) {
            int b = countr_zero(unsigned(k));
            p = up[tr[p].off + b];
            k &= k - 1;
        }
        return p;
    }

    // ===== 持久化入队 / 出队：版本 0 为空队列，旧版本始终不变 =====
    int push(int v, T x) {
        assert(0 <= v && v < int(ver.size()));
        int p = ver[v].tail, d = tr[p].dep + 1;
        int q = int(tr.size());
        tr.push_back({move(x), d, int(up.size())});
        up.push_back(p);
        for (int j = 1; (1LL << j) <= d; ++ j) {
            int mid = up.back();
            up.push_back(up[tr[mid].off + j - 1]);
        }
        ver.push_back({q, ver[v].len + 1});
        return int(ver.size()) - 1;
    }
    int pop(int v) {
        assert(0 <= v && v < int(ver.size()) && ver[v].len > 0);
        auto [tail, len] = ver[v];
        ver.push_back({len == 1 ? 0 : tail, len - 1});
        return int(ver.size()) - 1;
    }

    // ===== 基础查询：队首 O(log N)，队尾 / 大小 O(1) =====
    int size(int v) const {
        assert(0 <= v && v < int(ver.size()));
        return ver[v].len;
    }
    bool empty(int v) const { return size(v) == 0; }
    T front(int v) const {
        assert(size(v) > 0);
        return tr[ancestor(ver[v].tail, ver[v].len - 1)].val;
    }
    T back(int v) const {
        assert(size(v) > 0);
        return tr[ver[v].tail].val;
    }

    // ===== 可选：按队列顺序随机访问；不用时可直接删除 =====
    T at(int v, int k) const {
        assert(0 <= k && k < size(v));
        return tr[ancestor(ver[v].tail, ver[v].len - 1 - k)].val;
    }

    // ===== 可选：预留空间 / 原样复制版本；不用时可删除 =====
    void reserve(int pushes, int versions) {
        assert(pushes >= 0 && versions >= 0);
        tr.reserve(tr.size() + pushes);
        ver.reserve(ver.size() + versions);
        if (pushes) {
            int lg = bit_width(unsigned(tr.size() + pushes));
            up.reserve(up.size() + size_t(pushes) * lg);
        }
    }
    int copy(int v) {
        assert(0 <= v && v < int(ver.size()));
        ver.push_back(ver[v]);
        return int(ver.size()) - 1;
    }
};
```

## 接口说明

### 成员变量

- `tr[p]`：第 `p` 个历史尾节点；`val` 为入队值，`dep` 为该节点在历史链上的深度，`off` 为其倍增表在 `up` 中的起始下标。
- `up`：**扁平化存储**各节点的 `2^j` 级祖先；无需固定 `LOG` 或为每个节点分配 `vector`。
- `ver[v] = {tail, len}`：版本 `v` 的尾节点和当前队列长度；仅 `len` 个尾部历史节点属于该队列。
- **版本 `0` 是空队列**。每次 `push`、`pop` 或 `copy` 都追加一个版本并返回新版本编号；旧版本永远不变。

### 基础接口

| 接口 | 作用 | 时间复杂度 |
|---|---|---|
| `push(v, x)` | 从版本 `v` 的队尾插入 `x`，返回新版本编号 | `O(log P)` |
| `pop(v)` | 从非空版本 `v` 的队首出队，返回新版本编号 | `O(1)` |
| `front(v)` | 返回版本 `v` 的队首值（**不出队**） | `O(log P)` |
| `back(v)` | 返回版本 `v` 的队尾值 | `O(1)` |
| `size(v)` | 当前队列长度 | `O(1)` |
| `empty(v)` | 当前队列是否为空 | `O(1)` |

`P` 表示执行过的 `push` 总次数。`front(v)` 是对 `ver[v].tail` 跳 `ver[v].len - 1` 级祖先。

### 可选接口

| 接口 | 作用 | 时间复杂度 |
|---|---|---|
| `at(v, k)` | 队首起第 `k` 个值，`k` 为 **0base** | `O(log P)` |
| `copy(v)` | 原样复制版本 `v`，返回新版本编号 | `O(1)` |
| `reserve(pushes, versions)` | 预留额外入队数和版本数的容量 | 预分配成本与预留量成正比 |

裁剪：不需要随机访问可直接删 `at()`；不需要手动容量预留 / 空操作版本可直接删除 `reserve()` / `copy()`。`ancestor()`、`push()`、`pop()` 和基础查询保留。

## 注意事项

- 所有版本编号均为 **0base**，`0` 是初始空队列；修改返回的是**新版本编号**，不是新的队首或队尾下标。
- `pop(v)`、`front(v)`、`back(v)` 要求版本 `v` 非空；`at(v, k)` 要求 `0 <= k < size(v)`。不合法操作由 `assert` 检查。
- **出队不删除历史节点**。例如 `[1,2,3] -> pop -> [2,3] -> push(4) -> [2,3,4]`，新版本仍会共享旧链上曾经出队的节点；通过 `len` 定位有效后缀，功能正确。
- 队列完全出空时，将新版本 `tail` 置为 `0`，之后再次入队会从空链开始，避免历史链无意义地变长。
- 本结构是**完全持久化**：可以反复以任意旧版本为父版本生成分支；同一 `PersistentQueue` 对象内的节点与版本共享内存。
- `T` 默认为已有的 `i64`，也可以改为 `int`；节点 `0` 使用 `T{}`，所以要求 `T` 可默认构造，常用数值类型均满足。`front/back/at` 按值返回。
- `reserve()` 是性能优化，不影响正确性；如果知道最多有多少次入队和一共多少次产生新版本，可以提前调用。
- 这版采用**历史尾链 + 倍增**，优先考虑短代码、无需复杂引用计数，以及分支版本正确性。理论上还存在更复杂的 `O(1)` 持久化实时队列；如果题目对操作量与内存特别敏感，应按约束选择。

## 常见用法

### 从任意历史版本分叉

```cpp
PersistentQueue<int> q;
int v1 = q.push(0, 3);     // v1: [3]
int v2 = q.push(v1, 5);    // v2: [3, 5]
int v3 = q.pop(v2);        // v3: [5]
int v4 = q.push(v3, 7);    // v4: [5, 7]
int v5 = q.push(v1, 11);   // v5: [3, 11]

int x = q.front(v4);       // 5
int y = q.back(v5);        // 11
int z = q.at(v2, 1);       // 5，v2 不会被后续操作修改
```

### 先取队首，再生成出队版本

```cpp
int x = q.front(v2);
int next_version = q.pop(v2);
// x 是旧版本队首；next_version 是删除队首后的新版本
```

### Library Checker：Persistent Queue

题目将**空初始版本标为 `t = -1`**，第 `i` 个询问执行后形成版本 `i`。本结构的版本编号统一加 `1`：题目中的 `t` 映射为 `t + 1`。

```cpp
int Q;
cin >> Q;
PersistentQueue<int> q;
q.reserve(Q, Q);
for (int i = 0; i < Q; ++ i) {
    int op, t;
    cin >> op >> t;
    int v = t + 1;
    if (op == 0) {
        int x;
        cin >> x;
        q.push(v, x);          // 返回的新版本必为 i + 1
    } else {
        cout << q.front(v) << '\n';
        q.pop(v);
    }
}
```

- 测试入口：[Library Checker — Persistent Queue](https://judge.yosupo.jp/problem/persistent_queue)。
- `copy()` 只在“需要生成一个不改变内容的新版本”时才用；若仅保留引用，直接保存原版本编号即可。

## 复杂度

设 `P` 为总入队次数、`V` 为创建的版本总数（含空版本）。

| 操作 | 时间复杂度 |
|---|---|
| `push` | `O(log P)`（新建一个节点和其倍增祖先） |
| `pop`、`back`、`size`、`empty`、`copy` | `O(1)` |
| `front`、`at` | `O(log P)` |

空间复杂度：**`O(P log P + V)`**。

更精确地，每次入队只创建 **1 个 `Node`**，并追加 `floor(log2(dep)) + 1` 个 `int` 祖先索引；每次操作额外创建 1 个 `Version`。没有按版本复制队列元素，也不需要固定最大层数的稠密倍增数组。
