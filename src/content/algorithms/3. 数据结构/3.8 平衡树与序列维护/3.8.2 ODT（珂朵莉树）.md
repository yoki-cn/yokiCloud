### ODT（珂朵莉树）
---
```cpp
template<class T, class Equal = equal_to<T>>
struct ODT {
    using Map = map<int, T>;
    using Iter = typename Map::iterator;
    int n{};
    Map mp;
    Equal equal;
    explicit ODT(const vector<T> &a = {}, Equal equal_ = Equal())
        : n(a.size()), equal(move(equal_)) {
        for (int i = 0; i < n; ++ i) {
            if (i == 0 || !same(a[i - 1], a[i])) {
                mp.emplace(i, a[i]);
            }
        }
    }
private:
    bool same(const T &a, const T &b) const { return equal(a, b); }
    // ===== 相邻等值段合并：所有修改操作依赖，不建议删除 =====
    void normalize(int l, int r) {
        if (mp.empty()) return;
        auto it = mp.lower_bound(l);
        if (it != mp.begin()) -- it;
        while (it != mp.end()) {
            auto nxt = next(it);
            if (nxt == mp.end() || nxt->first > r) break;
            if (same(it->second, nxt->second)) mp.erase(nxt);
            else it = nxt;
        }
    }
public:
    // ===== 核心操作：split / assign / apply =====
    // 保证 x 成为区间左端点；x == n 时返回 end()
    Iter split(int x) {
        assert(0 <= x && x <= n);
        if (x == n) return mp.end();
        auto it = prev(mp.upper_bound(x));
        if (it->first == x) return it;
        return mp.emplace(x, it->second).first;
    }
    void assign(int l, int r, const T &value) {
        assert(0 <= l && l <= r && r <= n);
        if (l == r) return;
        auto last = split(r);
        auto first = split(l);
        mp.erase(first, last);
        mp.emplace(l, value);
        normalize(l, r);
    }
    // f(T &) 必须把一个常值段整体映射为另一个常值
    template<class F>
    void apply(int l, int r, F f) {
        assert(0 <= l && l <= r && r <= n);
        if (l == r) return;
        auto last = split(r);
        auto first = split(l);
        for (auto it = first; it != last; ++ it) f(it->second);
        normalize(l, r);
    }
    // ===== 只读查询：不会 split，不会制造额外断点 =====
    const T &get(int pos) const {
        assert(0 <= pos && pos < n);
        return prev(mp.upper_bound(pos))->second;
    }
    template<class F>
    void for_each(int l, int r, F f) const {
        assert(0 <= l && l <= r && r <= n);
        if (l == r) return;
        auto it = prev(mp.upper_bound(l));
        while (it != mp.end() && it->first < r) {
            auto nxt = next(it);
            int L = max(l, it->first);
            int R = min(r, nxt == mp.end() ? n : nxt->first);
            f(L, R, it->second);
            it = nxt;
        }
    }
    int interval_count() const { return mp.size(); }
};
```
#### 表示方式
若：
```cpp
mp = {
    {0, 2},
    {4, 7},
    {9, 3}
};
```
且 `n = 12`，表示：
```text
[0, 4)  -> 2
[4, 9)  -> 7
[9, 12) -> 3
```
#### 核心接口
- `split(x)`：保证存在以 `x` 为左端点的段；`x == n` 返回 `end()`
- `assign(l,r,value)`：将 `[l,r)` 全部赋为 `value`
- `apply(l,r,f)`：对 `[l,r)` 覆盖到的每个常值段执行一次 `f(T&)`
- `get(pos)`：单点查询
- `for_each(l,r,f)`：枚举 `[l,r)` 内所有常值段，回调参数为 `(L,R,value)`
- `interval_count()`：当前常值段数量
#### `apply()` 的限制
例如：
```cpp
odt.apply(l, r, [&](i64 &x) {
    x += delta;
});
```
是合法的，因为一个原本相等的整段修改后仍然相等
但不能用它表示：
```text
a[i] += i
```
因为同一常值段内部不同位置会得到不同结果，原来的一个 ODT 节点不能继续表示整段
#### 注意事项
- 所有下标为 `0base`，区间统一为 `[l,r)`
- ODT 维护的是**定长数组的等值区间**，不支持像 BlockList 那样插入 / 删除位置
- ODT 的性能核心不是“名字叫珂朵莉树”，而是**当前等值段数量很少**
- `assign()` 会大量删除断点，因此有大量区间赋值时通常表现很好
- 如果只有区间加而没有赋值，原有不同值段通常不会减少，ODT 很可能逐渐失去优势
- 对抗数据可以让段数达到 $\Theta(n)$，一次操作也可能退化到 $\Theta(n)$
- 每次修改后都会尝试合并相邻等值段，以尽量压低段数
- `Equal` 只负责判断两个值是否相等，所以基础 ODT 不要求 `T` 可以排序
- 如果只需要区间赋值和遍历，不需要数值运算，`T` 可以是颜色、状态甚至结构体
#### 常见用法
##### 区间赋值
ODT 最核心、也是最适合它的操作：
```cpp
ODT<int> odt(a);
odt.assign(l, r, color);
```
##### 区间加
区间加只是 `apply()` 的一个特例，没有必要永久写进核心结构：
```cpp
odt.apply(l, r, [&](i64 &x) {
    x += delta;
});
```
如果题目大量使用，可以临时包装：
```cpp
auto add = [&](int l, int r, i64 x) {
    odt.apply(l, r, [&](i64 &v) {
        v += x;
    });
};
```
##### 区间和
无需写进 ODT：
```cpp
i64 sum = 0;
odt.for_each(l, r, [&](int L, int R, i64 value) {
    sum += value * (R - L);
});
```
##### 区间某个值出现次数
```cpp
int cnt = 0;
odt.for_each(l, r, [&](int L, int R, int value) {
    if (value == x) cnt += R - L;
});
```
##### 区间最值
```cpp
i64 mn = INF;
i64 mx = -INF;
odt.for_each(l, r, [&](int L, int R, i64 value) {
    mn = min(mn, value);
    mx = max(mx, value);
});
```
##### 区间第 k 小
这是经典 ODT 题型，但依赖 `T` 可以排序，因此更适合放在常用方法中，而不是让核心 ODT 强制要求 `<`
`k` 为 `0base`：
```cpp
vector<pair<i64, int>> a;
odt.for_each(l, r, [&](int L, int R, i64 value) {
    a.push_back({value, R - L});
});
ranges::sort(a);
for (auto [value, cnt] : a) {
    if (k < cnt) {
        answer = value;
        break;
    }
    k -= cnt;
}
```
如果题目频繁使用，可以包装成：
```cpp
auto kth = [&](int l, int r, int k) {
    vector<pair<i64, int>> a;
    odt.for_each(l, r, [&](int L, int R, i64 value) {
        a.push_back({value, R - L});
    });
    ranges::sort(a);
    for (auto [value, cnt] : a) {
        if (k < cnt) return value;
        k -= cnt;
    }
    assert(false);
    return i64{};
};
```
#### 区间幂次和
经典珂朵莉树题常见：
$$\sum_{i=l}^{r-1} a_i^k \pmod {mod}$$
无需给 ODT 增加特化接口：
```cpp
i64 ans = 0;
odt.for_each(l, r, [&](int L, int R, i64 value) {
    ans = (ans + i64(R - L) * qpow(value, k, mod)) % mod;
});
```
#### 自定义值类型
例如维护颜色和附加信息，只做整体赋值：
```cpp
struct Info {
    int color{};
    i64 value{};
    bool operator==(const Info &) const = default;
};
ODT<Info> odt(a);
odt.assign(l, r, {color, value});
```
甚至不需要定义 `<`
##### 观察是否开始退化
调试时很实用：
```cpp
cerr << odt.interval_count() << '\n';
```
如果本来以为只有几十个段，结果迅速膨胀到接近 `n`，就说明这道题并不适合 ODT
#### 复杂度
设当前共有 $m$ 个等值段，一次操作实际覆盖 $k$ 个段

| 操作                              |         时间复杂度 |
| ------------------------------- | ------------: |
| `split` / `get`                 |   $O(\log m)$ |
| `assign` / `apply` / `for_each` | $O(\log m+k)$ |
| `interval_count`                |        $O(1)$ |
空间复杂度为 $O(m)$，最坏 $m=O(n)$
特化查询则另外计算自身开销。例如区间第 `k` 小若覆盖 $k_s$ 个常值段，需要：
$$O(\log m+k_s\log k_s)$$
