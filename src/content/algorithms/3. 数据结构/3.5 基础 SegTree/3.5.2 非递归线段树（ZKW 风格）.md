### 非递归线段树（ZKW 风格）
---
**解决问题：** 只需单点修改、区间聚合和树上二分时，使用紧凑的非递归线段树；相比递归线段树代码更短、常数更小
```cpp
template<class T, class Merge>
struct IterSegTree {
    int n, base{1};
    T identity;
    Merge merge;
    vector<T> tr;
    IterSegTree(int n_, T identity_, Merge merge_ = Merge())
        : n(n_), identity(move(identity_)), merge(move(merge_)) {
        while (base < n) base <<= 1;
        tr.assign(base << 1, identity);
    }
    IterSegTree(const vector<T> &a, T identity_, Merge merge_ = Merge())
        : IterSegTree(int(a.size()), move(identity_), move(merge_)) {
        for (int i = 0; i < n; ++ i) tr[base + i] = a[i];
        for (int p = base - 1; p; -- p) pull(p);
    }
    void pull(int p) { tr[p] = merge(tr[p << 1], tr[p << 1 | 1]); }
    void set(int x, const T &v) {
        assert(0 <= x && x < n);
        int p{base + x};
        tr[p] = v;
        for (p >>= 1; p; p >>= 1) pull(p);
    }
    const T &get(int x) const { assert(0 <= x && x < n); return tr[base + x]; }
    T query(int l, int r) const {
        assert(0 <= l && l <= r && r <= n);
        T left{identity}, right{identity};
        for (l += base, r += base; l < r; l >>= 1, r >>= 1) {
            if (l & 1) left = merge(left, tr[l ++]);
            if (r & 1) right = merge(tr[-- r], right);
        }
        return merge(left, right);
    }
    const T &all() const { return tr[1]; }
    // ===== 树上二分：若不需要，可直接删除 max_right() / min_left() =====
    // check(identity) 必须为 true，且随着区间扩展只能从 true 变为 false。
    template<class F>
    int max_right(int l, F check) const {
        assert(0 <= l && l <= n && check(identity));
        if (l == n) return n;
        int p{l + base};
        T cur{identity};
        do {
            while (!(p & 1)) p >>= 1;
            T nxt{merge(cur, tr[p])};
            if (!check(nxt)) {
                while (p < base) {
                    p <<= 1;
                    nxt = merge(cur, tr[p]);
                    if (check(nxt)) {
                        cur = nxt;
                        ++ p;
                    }
                }
                return min(n, p - base);
            }
            cur = nxt;
            ++ p;
        } while ((p & -p) != p);
        return n;
    }
    template<class F>
    int min_left(int r, F check) const {
        assert(0 <= r && r <= n && check(identity));
        if (r == 0) return 0;
        int p{r + base};
        T cur{identity};
        do {
            -- p;
            while (p > 1 && (p & 1)) p >>= 1;
            T nxt{merge(tr[p], cur)};
            if (!check(nxt)) {
                while (p < base) {
                    p = p << 1 | 1;
                    nxt = merge(tr[p], cur);
                    if (check(nxt)) {
                        cur = nxt;
                        -- p;
                    }
                }
                return p + 1 - base;
            }
            cur = nxt;
        } while ((p & -p) != p);
        return 0;
    }
};
```
#### 接口说明
- `IterSegTree(n, identity, merge)`：建立长度为 `n`、所有位置均为单位元的线段树，$O(n)$
- `IterSegTree(a, identity, merge)`：由数组建树，$O(n)$
- `set(x,v)`：令 `a[x]=v`，$O(\log n)$
- `get(x)`：返回 `a[x]`，$O(1)$
- `query(l,r)`：按原顺序聚合 `[l,r)`，$O(\log n)$
- `all()`：返回整个 `[0,n)` 的聚合信息，$O(1)$
- `max_right(l,check)`：返回最大的 `r`，使 `check(query(l,r))` 成立，$O(\log n)$
- `min_left(r,check)`：返回最小的 `l`，使 `check(query(l,r))` 成立，$O(\log n)$
#### 注意事项
- 下标为 `0base`，区间统一使用 `[l,r)`
- `merge` 必须满足结合律，`identity` 必须同时满足 `merge(identity,x)=merge(x,identity)=x`
- `merge` 不要求满足交换律；`query()`、`max_right()`、`min_left()` 都保持原数组顺序，因此可以维护矩阵乘积、字符串连接等信息
- `[n,base)` 的补充叶子全部为 `identity`，不会影响实际区间答案
- `max_right/min_left` 要求 `check(identity)=true`
- 树上二分还要求判定具有单调性：区间不断扩展时 `check` 只能从 `true` 变成 `false`
- `max_right(l,check)` 返回的是**最后仍满足条件的右边界**；若加入位置 `p` 后第一次失败，则返回 `p`
- `min_left(r,check)` 对称地返回**最靠左仍满足条件的左边界**
- 若需要区间修改，优先使用懒标记线段树，不建议为了非递归而强行加入传统 ZKW 开区间懒标记技巧
#### 常见用法
##### 区间和
```cpp
struct Add {
    i64 operator()(i64 x, i64 y) const { return x + y; }
};
IterSegTree<i64, Add> seg(a, 0LL);
seg.set(x, v);
i64 sum = seg.query(l, r);
```
##### 区间最大值
```cpp
struct Max {
    i64 operator()(i64 x, i64 y) const { return max(x, y); }
};
IterSegTree<i64, Max> seg(a, i64(-4E18));
i64 mx = seg.query(l, r);
```
##### 区间最大子段和
```cpp
struct MaxSubarrayInfo {
    static constexpr i64 NEG_INF = -4'000'000'000'000'000'000LL;
    i64 sum{0};
    i64 pre{NEG_INF}, suf{NEG_INF}, best{NEG_INF};
    MaxSubarrayInfo() = default;
    MaxSubarrayInfo(i64 x) : sum(x), pre(x), suf(x), best(x) {}
    MaxSubarrayInfo(i64 sum_, i64 pre_, i64 suf_, i64 best_)
        : sum(sum_), pre(pre_), suf(suf_), best(best_) {}
};
struct MergeMaxSubarray {
    MaxSubarrayInfo operator()(const MaxSubarrayInfo &a, const MaxSubarrayInfo &b) const {
        if (a.best == MaxSubarrayInfo::NEG_INF) return b;
        if (b.best == MaxSubarrayInfo::NEG_INF) return a;
        return { a.sum + b.sum, max(a.pre, a.sum + b.pre),
            max(b.suf, b.sum + a.suf), max({a.best, b.best, a.suf + b.pre})
        };
    }
};
```
> 有负数时怎么找第一个前缀和不小于 `x`？

这个 `Info` 里的：`pre` 恰好就是答案
因为对于 `[l,r)`：`info.pre`
表示：
$$\max_{l\le k<r}\sum_{i=l}^{k}a_i$$
随着 `r` 右移，`pre` 只可能不减，所以可以直接：
```cpp
int p = seg.max_right(l, [&](const MaxSubarrayInfo &info) {
    return info.pre < x;
});
```
那么 `p` 就是第一个满足
$$a_l+a_{l+1}+\cdots+a_p\ge x$$
的位置
**哪怕数组中存在负数也成立**
##### 区间加、区间 GCD
设
$$d_i=a_i-a_{i-1}$$
则：
$$\gcd(a_l,a_{l+1},\ldots,a_{r-1}) = \gcd\left( a_l, d_{l+1},\ldots,d_{r-1} \right)$$
而 `[l,r)` 全部加 `v` 只改变：
$$d_l\mathrel{+}=v, \qquad d_r\mathrel{-}=v$$
```cpp
struct Gcd {
    i64 operator()(i64 x, i64 y) const { return gcd(x, y); }
};
```
然后 `IterSegTree<i64, Gcd> seg(diff, 0LL);` 即可维护出差分数组
完整实现：
```cpp
struct Gcd {
    i64 operator()(i64 x, i64 y) const { return gcd(x, y); }
};
struct RangeAddGCD {
    int n;
    BIT<i64> bit;
    vector<i64> diff;
    IterSegTree<i64, Gcd> seg;
    static vector<i64> make_diff(const vector<i64> &a) {
        int n{int(a.size())};
        vector<i64> d(n + 1);
        for (int i = 0; i < n; ++ i) {
            d[i] = a[i] - (i ? a[i - 1] : 0);
        }
        if (n) d[n] = -a[n - 1];
        return d;
    }
    explicit RangeAddGCD(const vector<i64> &a)
        : n(a.size()), bit(n + 1), diff(make_diff(a)), seg(diff, 0LL) {
        for (int i = 0; i <= n; ++ i) bit.add(i, diff[i]);
    }
    void add_diff(int x, i64 v) {
        diff[x] += v;
        bit.add(x, v);
        seg.set(x, diff[x]);
    }
    void add(int l, int r, i64 v) { add_diff(l, v); add_diff(r, -v); }
    i64 get(int x) const { return bit.prefix(x + 1); }
    i64 query(int l, int r) const { assert(l < r); return gcd(abs(get(l)), seg.query(l + 1, r)); }
};
```
##### 找 `[l,n)` 中第一个 `a[i] >= x`
维护区间最大值。对于某段：
```cpp
mx < x
```
表示这一整段都没有答案
```cpp
int p = seg.max_right(l, [&](i64 mx) {
    return mx < x;
});
if (p == n) {
    // 不存在
} else {
    // p 为第一个满足 a[p] >= x 的位置
}
```
同理，找 `[l,r)` 中第一个 `a[i]>=x`：
```cpp
int p = seg.max_right(l, [&](i64 mx) {
    return mx < x;
});
if (p >= r) {
    // [l,r) 中不存在
}
```
##### 找 `[0,n)` 中第一个前缀和不小于 `x`
要求数组元素均非负，使前缀和单调不减
维护区间和，并令：
```cpp
sum < x
```
表示当前前缀还没有达到目标
```cpp
int p;
if (x <= 0) {
    p = 0;
} else {
    p = seg.max_right(0, [&](i64 sum) {
        return sum < x;
    });
}
if (p == n) {
    // 总和仍小于 x，不存在
} else {
    // p 为最小位置，使 a[0] + ... + a[p] >= x
}
```
例如：
```text
a = [2, 4, 1, 5]
前缀和 = [2, 6, 7, 12]
```
当 `x=7` 时：
```cpp
seg.max_right(0, [&](i64 sum) {
    return sum < 7;
});
```
返回 `2`
如果数组允许负数，`sum < x` 不再具有单调性，不能这样二分；此时需要维护最大前缀和等额外信息
##### 找 `[0,r)` 中最后一个 `a[i] >= x`
维护区间最大值，从右向左使用 `min_left()`：
```cpp
int p = seg.min_left(r, [&](i64 mx) {
    return mx < x;
}) - 1;
if (p == -1) {
    // [0,r) 中不存在
} else {
    // p 为最后一个满足 a[p] >= x 的位置
}
```
##### 自定义区间信息
只需令 `T` 表示整个区间的信息，并让 `Merge` 表示左右区间合并
```cpp
struct Info {
    i64 sum{};
    int len{};
};
struct Merge {
    Info operator()(const Info &a, const Info &b) const {
        return {a.sum + b.sum, a.len + b.len};
    }
};
vector<Info> init(n);
for (int i = 0; i < n; ++ i) init[i] = {a[i], 1};
IterSegTree<Info, Merge> seg(init, Info{});
Info info = seg.query(l, r);
```
常见单位元：

|聚合信息|`merge(a,b)`|`identity`|
|---|---|---|
|区间和|`a + b`|`0`|
|区间最大值|`max(a,b)`|`-INF`|
|区间最小值|`min(a,b)`|`INF`|
|GCD|`gcd(a,b)`|`0`|
|XOR|`a ^ b`|`0`|
|矩阵乘积|`a * b`|单位矩阵|
#### 复杂度

| 操作                                                 |       时间复杂度 |
| -------------------------------------------------- | ----------: |
| 建树                                                 |      $O(n)$ |
| `set()` / `query()` / `max_right()` / `min_left()` | $O(\log n)$ |
| `get()` / `all()`                                  |      $O(1)$ |
空间复杂度：$O(n)$
