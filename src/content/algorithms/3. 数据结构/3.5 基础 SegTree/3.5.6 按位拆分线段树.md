### 按位拆分线段树
---
**解决问题：** 区间按位修改难以直接维护整数整体信息时，把每个二进制位独立拆开，维护每一位的 `1` 个数，使区间 XOR、AND、OR 等操作重新变成普通懒标记修改
依赖：
* [[3.5.1 SegTree]] `LazySegTree<Info, Tag>`
* `Info` 支持区间合并
* `Info::apply(tag,l,r)` 表示把标记作用于整个节点
* 以下约定 `Tag::apply(t)` 表示：**当前已有变换之后，再执行 `t`**
若现有 `LazySegTree` 的标记合成方向相反，只需交换 `Tag` 的复合顺序
#### 原理
设某一位在长度为 `len` 的区间中有 `ones` 个 `1`
执行区间 XOR 时，如果掩码这一位为 `1`，所有 `0/1` 翻转，因此：
$$ones\leftarrow len-ones$$
如果这一位没有被 XOR，则保持不变
因此只要对每个二进制位分别维护 `1` 的数量，就能同时恢复：
* 区间算术和
* 区间异或和
* 每一位出现次数
* 其他依赖位计数的信息

#### 区间 XOR
```cpp
template<int B = 61>
struct XorTag {
    u64 mask{0};
    bool empty() const { return mask == 0; }
    void apply(const XorTag &t) { mask ^= t.mask; }
};
template<int B = 61>
struct XorInfo {
    array<int, B> ones{};
    XorInfo() = default;
    explicit XorInfo(u64 x) {
        for (int b = 0; b < B; ++ b) ones[b] = x >> b & 1ULL;
    }
    void apply(const XorTag<B> &t, int l, int r) {
        int len{r - l};
        for (int b = 0; b < B; ++ b) if (t.mask >> b & 1ULL) {
            ones[b] = len - ones[b];
        }
    }
};
template<int B>
XorInfo<B> operator+(const XorInfo<B> &a, const XorInfo<B> &b) {
    XorInfo<B> c;
    for (int bit = 0; bit < B; ++ bit) c.ones[bit] = a.ones[bit] + b.ones[bit];
    return c;
}
```
初始化：
```cpp
using Info = XorInfo<31>;
using Tag = XorTag<31>;
vector<Info> init;
init.reserve(n);
for (u64 x : a) init.emplace_back(x);
// 按已有 LazySegTree 的构造接口建树。
LazySegTree<Info, Tag> seg(init);
```
区间 XOR：
```cpp
seg.apply(l, r, Tag{mask});
```
具体修改接口名按已有 `LazySegTree` 为准

#### 从位计数恢复答案
##### 区间算术和
若第 $b$ 位有 `ones[b]` 个 `1`，贡献为：
$$ones_b\cdot2^b$$
```cpp
template<int B>
__int128_t bit_sum(const XorInfo<B> &info) {
    __int128_t ans{0};
    for (int b = 0; b < B; ++ b) {
        ans += (__int128_t)info.ones[b] << b;
    }
    return ans;
}
```
使用：
```cpp
auto info = seg.query(l, r);
__int128_t sum = bit_sum(info);
```
##### 区间异或和
某一位出现奇数次时，该位的区间异或结果为 `1`：
```cpp
template<int B>
u64 bit_xor(const XorInfo<B> &info) {
    u64 ans{0};
    for (int b = 0; b < B; ++ b) if (info.ones[b] & 1) {
        ans |= 1ULL << b;
    }
    return ans;
}
```

#### 一般 AND / OR / XOR 变换
若只支持 XOR，每一位只有：
```text
保持
翻转
```
两种状态
如果同时需要：
```text
AND
OR
XOR
```
则每一位实际上可能出现四种布尔变换：

| 变换  | $f(0)$ | $f(1)$ |
| --- | -----: | -----: |
| 保持  |      0 |      1 |
| 翻转  |      1 |      0 |
| 赋 0 |      0 |      0 |
| 赋 1 |      1 |      1 |
因此可以使用两个掩码：
```text
to0 = f(0)
to1 = f(1)
```
完整表示每一位的变换

#### 通用按位标记
```cpp
template<int B = 61>
struct BitTag {
    static_assert(1 <= B && B <= 64);
    static constexpr u64 full_mask() {
        if constexpr (B == 64) return ~0ULL;
        else return (1ULL << B) - 1;
    }
    // 当前变换对输入 0 / 1 的输出。
    u64 to0{0};
    u64 to1{full_mask()};
    bool empty() const { return to0 == 0 && to1 == full_mask(); }
    static BitTag bit_and(u64 mask) {
        mask &= full_mask();
        return {0, mask};
    }
    static BitTag bit_or(u64 mask) {
        mask &= full_mask();
        return {mask, full_mask()};
    }
    static BitTag bit_xor(u64 mask) {
        mask &= full_mask();
        return {mask, full_mask() ^ mask};
    }
    // 当前变换为 f，新加入变换为 g，合成为 g(f(x))。
    void apply(const BitTag &g) {
        u64 n0{((~to0 & g.to0) | (to0 & g.to1)) & full_mask()};
        u64 n1{((~to1 & g.to0) | (to1 & g.to1)) & full_mask()};
        to0 = n0;
        to1 = n1;
    }
};
```
对应区间信息：
```cpp
template<int B = 61>
struct BitInfo {
    array<int, B> ones{};
    BitInfo() = default;
    explicit BitInfo(u64 x) {
        for (int b = 0; b < B; ++ b) ones[b] = x >> b & 1ULL;
    }
    void apply(const BitTag<B> &t, int l, int r) {
        int len{ r - l };
        for (int b = 0; b < B; ++ b) {
            int z{int(t.to0 >> b & 1ULL)}, o{int(t.to1 >> b & 1ULL)};
            if (!z && !o) ones[b] = 0;
            else if (z && o) ones[b] = len;
            else if (z && !o) ones[b] = len - ones[b];
        }
    }
};
template<int B>
BitInfo<B> operator+(const BitInfo<B> &a, const BitInfo<B> &b) {
    BitInfo<B> c;
    for (int bit = 0; bit < B; ++ bit) { c.ones[bit] = a.ones[bit] + b.ones[bit]; }
    return c;
}
```
其中：
```cpp
BitTag<B>::bit_and(mask)
BitTag<B>::bit_or(mask)
BitTag<B>::bit_xor(mask)
```
分别表示区间 AND、OR、XOR
因此可以在**同一棵 LazySegTree** 中任意混合这些区间按位修改

#### 原理推广
按位拆分的核心不是 XOR，而是：
> 如果一个整数操作的各二进制位彼此独立，就可以把一个整数状态拆成 $B$ 个小状态分别维护

常见判断方式：
```text
整数整体难以更新
        ↓
操作是否对每一位独立？
        ↓ 是
维护每位 0/1 数量或其他小状态
        ↓
把原修改变成每位上的简单函数
        ↓
使用普通 LazySegTree
```
这种方法与势能线段树、Segment Tree Beats 不同：这里不存在均摊复杂度，修改本身仍是普通的懒标记
#### 接口说明
基础 XOR 版：
* `XorInfo<B>`：维护各二进制位的 `1` 个数
* `XorTag<B>{mask}`：区间 XOR `mask`
* `bit_sum(info)`：从位计数恢复区间算术和
* `bit_xor(info)`：从位计数恢复区间异或和
通用版：
* `BitTag<B>::bit_and(mask)`：区间 AND
* `BitTag<B>::bit_or(mask)`：区间 OR
* `BitTag<B>::bit_xor(mask)`：区间 XOR
* `BitInfo<B>`：同时支持上述三种修改
#### 注意事项
* `B` 必须满足 $1\le B\le64$
* `B=64` 时不能直接计算 `1ULL << 64`，因此 `full_mask()` 必须使用 `if constexpr`
* 若数据只使用较低位，应尽量缩小 `B`，因为时间和空间复杂度都与 `B` 成正比
* `ones[b]` 最大为 $n$，通常 `int` 足够；区间算术和可能超过 `i64`，必要时使用 `__int128_t`
* 通用 `BitTag` 的复合方向必须与现有 `LazySegTree` 的懒标记合成方向一致
* 如果只查询区间 XOR 而不需要区间算术和，通常没必要维护全部位计数，可以使用更简单的区间 XOR 聚合
* 按位拆分适用于各位相互独立的操作；若操作会产生跨位进位，例如普通加法，就不能直接按这种方式拆分
#### 复杂度
设维护 $B$ 个二进制位
建树：
$$O(Bn)$$
一次区间修改或查询：
$$O(B\log n)$$
空间复杂度：
$$O(Bn)$$
当 $B$ 是固定常数时，也可以视为普通线段树的 $O(\log n)$ 操作
