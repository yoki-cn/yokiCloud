### 函数复合线段树
---
**解决问题：** 每个位置表示一个函数或状态转移，支持单点修改，并查询区间内按照下标顺序依次执行这些函数后的复合结果
依赖：
* [[3.5.2 非递归线段树（ZKW 风格）]] 中的 `IterSegTree<T, Merge>`
* `IterSegTree` 必须保持左右区间的合并顺序，即 `merge(left, right)` 表示**左区间后接右区间**
#### 原理
设每个位置维护一个函数：
$$f_0,f_1,\ldots,f_{n-1}$$
查询 `[l,r)` 时，从左到右依次执行：
$$x \xrightarrow{f_l} f_l(x) \xrightarrow{f_{l+1}} f_{l+1}(f_l(x)) \xrightarrow{}\cdots$$
因此整个区间对应的复合函数为：
$$f_{r-1}\circ f_{r-2}\circ\cdots\circ f_l$$
函数复合满足结合律：
$$(h\circ g)\circ f=h\circ(g\circ f)$$
因此可以直接作为普通线段树的区间信息
若：
```text
left  = 左区间对应的复合函数
right = 右区间对应的复合函数
```
那么两个相邻区间合并后，应先执行 `left`，再执行 `right`：
```text
merge(left, right) = right ∘ left
```
函数复合通常不满足交换律，因此左右顺序不能颠倒
#### 仿射函数
最常见的情况是每个位置维护仿射函数：
$$f(x)=ax+b$$
```cpp
struct Affine {
    i64 a{1}, b{0};
    i64 operator()(i64 x) const {
        return a * x + b;
    }
};
struct ComposeAffine {
    Affine operator()(const Affine &left, const Affine &right) const {
        // 返回 right(left(x))
        return { right.a * left.a, right.a * left.b + right.b };
    }
};
```
设：
$$f(x)=a_1x+b_1$$
$$g(x)=a_2x+b_2$$
则：
$$g(f(x))=a_2(a_1x+b_1)+b_2=(a_2a_1)x+(a_2b_1+b_2)$$
所以：
```cpp
compose(f, g) = { g.a * f.a, g.a * f.b + g.b };
```
默认的：
```cpp
Affine{}
```
表示恒等函数：
$$f(x)=x$$
因此正好是函数复合的单位元
#### 使用方法
##### 建树
```cpp
vector<Affine> f(n);
for (int i = 0; i < n; ++ i) {
    f[i] = {a[i], b[i]};
}
IterSegTree<Affine, ComposeAffine> seg(f, Affine{});
```
##### 查询区间复合函数
```cpp
Affine g = seg.query(l, r);
```
此时：
$$g=f_{r-1}\circ f_{r-2}\circ\cdots\circ f_l$$
若要计算初始值 `x` 经过整个区间后的结果：
```cpp
i64 ans = seg.query(l, r)(x);
```
##### 单点修改
将位置 `p` 修改为：
$$f_p(x)=ax+b$$
```cpp
seg.set(p, Affine{a, b});
```
#### 模意义下的仿射函数
实际竞赛中经常维护：
$$f(x)=ax+b\pmod M$$
若已有取模类型 `Z`，直接将 `i64` 改成 `Z`：
```cpp
struct Affine {
    Z a{1}, b{0};
    Z operator()(Z x) const { return a * x + b; }
};
struct ComposeAffine {
    Affine operator()(const Affine &left, const Affine &right) const {
        return { right.a * left.a, right.a * left.b + right.b };
    }
};
```
其余线段树代码与调用方式不变
#### 如何推广
仿射函数只是最简单的一类可复合信息
如果每个位置表示某种**状态转移**，并满足：
1. 单个转移能用固定大小的信息表示
2. 两段连续区间的转移能够快速复合
3. 复合满足结合律
4. 存在“不执行任何操作”的单位转移
那么就可以直接把这种转移作为 `IterSegTree` 的 `T`
常见形式包括：
* 仿射变换
* 矩阵变换
* 置换复合
* 固定状态数的 DP 转移
* 自动机状态转移
* 其他对复合封闭的小型函数
例如状态转移可以表示为：
$$v'=Mv$$
则每个位置存一个矩阵，区间合并维护矩阵乘积即可
核心转换方式为：
```text
单点函数 / 状态转移
        ↓
压缩为固定大小的信息 T
        ↓
定义相邻区间的复合 Merge
        ↓
使用 IterSegTree<T, Merge>
```
#### 注意事项
* `merge(left, right)` 表示左区间后接右区间，因此函数复合应返回 `right(left(x))`
* 函数复合满足结合律，但通常不满足交换律，左右区间不能交换
* `IterSegTree::query()` 必须保持原区间顺序，不能使用只适用于交换运算的简化写法
* 单位元必须表示恒等函数，即对任意 `x` 有 $id(x)=x$
* 函数族必须对复合封闭；若两函数复合后无法继续用相同的固定大小信息表示，就不能直接套本方法
* 若一次 `Merge` 的复杂度为 $O(C)$，线段树操作复杂度也需要额外乘上 $C$
* 模意义下优先直接使用取模类型保存参数，避免在复合过程中漏取模
* 若题目维护的是“若干函数在某点的最优值”，而不是按顺序执行函数复合，通常不属于本方法
#### 复杂度
设一次函数复合 `Merge` 的复杂度为 $O(C)$

| 操作            |                时间复杂度 |
| ------------- | -------------------: |
| 建树            |              $O(Cn)$ |
| 单点修改 / 区间函数复合 |         $O(C\log n)$ |
| 将结果函数作用于一个值   | 取决于函数表示，仿射函数为 $O(1)$ |
空间复杂度：$O(n)$
