### Indexed List（下标双向链表）
```cpp
template<class T>
struct IndexedList {
    static constexpr int NONE{ -1 }, DEAD{ -2 };
    struct Node {
        T val;
        int pre{ NONE }, nxt{ NONE };
    };
    vector<Node> tr;
    int head{ NONE }, tail{ NONE }, cnt{ 0 };
    IndexedList() = default;
    explicit IndexedList(const vector<T> &a) {
        int n = a.size();
        tr.reserve(n);
        for (int i = 0; i < n; ++ i) {
            tr.push_back({ a[i], i - 1, i + 1 < n ? i + 1 : NONE });
        }
        cnt = n;
        if (n) {
            head = 0;
            tail = n - 1;
        }
    }
    bool contains(int p) const { return 0 <= p && p < tr.size() && tr[p].nxt != DEAD; }
    bool empty() const { return cnt == 0; }
    int size() const { return cnt; }
    T &operator[](int p) { return tr[p].val; }
    const T &operator[](int p) const { return tr[p].val; }
    int prev(int p) const { return contains(p) ? tr[p].pre : NONE; }
    int next(int p) const { return contains(p) ? tr[p].nxt : NONE; }
    T &front() { return tr[head].val; }
    const T &front() const { return tr[head].val; }
    T &back() { return tr[tail].val; }
    const T &back() const { return tr[tail].val; }
    int front_id() const { return head; }
    int back_id() const { return tail; }
    int push_back(const T &v) {
        int p = int(tr.size());
        tr.push_back({v, tail, NONE});
        if (tail != NONE) tr[tail].nxt = p;
        else head = p;
        tail = p;
        ++ cnt;
        return p;
    }
    bool erase(int p) {
        if (!contains(p)) return false;
        int l{ tr[p].pre }, r{ tr[p].nxt };
        if (l != NONE) tr[l].nxt = r;
        else head = r;
        if (r != NONE) tr[r].pre = l;
        else tail = l;
        tr[p].pre = tr[p].nxt = DEAD;
        -- cnt;
        return true;
    }
    void reserve(int n) { tr.reserve(n); }
};
```
#### 成员变量
- `tr[p]`：编号 `p` 对应的节点，保存元素值及当前存活的前驱、后继编号
- `head`：当前首节点编号；空表时为 `NONE
- `tail`：当前尾节点编号；空表时为 `NONE
- `cnt`：当前存活节点数
- `NONE = -1`：不存在前驱、后继或首尾节点
- `DEAD = -2`：已删除节点标记
- 节点编号按创建顺序从 `0` 开始，创建后永久不变且不会复用
#### 接口
- `IndexedList()`：构造空链表，$O(1)$
- `IndexedList(a)`：按 `a` 的顺序建表，初始节点编号为 `0..n-1`，$O(n)$
- `contains(p)`：判断编号 `p` 是否合法且仍存活，$O(1)$
- `empty()`：判断当前是否为空，$O(1)$
- `size()`：返回当前存活节点数，$O(1)$
- `operator[](p)`：访问编号 `p` 对应的值，不检查节点是否存活，$O(1)$
- `prev(p)`：返回存活节点 `p` 的前驱编号；不存在、非法或已删除时返回 `NONE`，$O(1)$
- `next(p)`：返回存活节点 `p` 的后继编号；不存在、非法或已删除时返回 `NONE`，$O(1)$
- `front()` / `back()`：访问当前首 / 尾节点的值，要求链表非空，$O(1)$
- `front_id()` / `back_id()`：返回当前首 / 尾节点编号；空表时返回 `NONE`，$O(1)$
- `push_back(v)`：在尾部加入值为 `v` 的新节点，返回新节点编号，均摊 $O(1)$
- `erase(p)`：删除编号 `p` 的节点；成功返回 `true`，非法或已经删除返回 `false`，$O(1)$
- `reserve(n)`：预留至少 `n` 个历史节点的存储空间，要求 `n >= 0`
#### 注意事项
- 节点编号表示**创建时的永久编号**，不是当前链表中的排名；删除节点不会改变其他节点编号
- 删除节点后编号不会复用，因此空间取决于历史创建节点总数，而不是当前 `size()`
- `operator[]` 不检查节点是否存活；即使节点已经删除，其原来的 `val` 仍可通过编号访问
- `prev()` / `next()` 只能查询当前存活节点；对非法或已删除节点统一返回 `NONE`
- `push_back()` 可能导致 `vector` 扩容：**节点编号始终有效**，但此前取得的 `T &`、`Node *` 或迭代器可能失效；需要长期保存引用时应提前 `reserve()`
#### 常见用法
##### 删除元素并取得左右存活节点
```cpp
IndexedList<int> lst(a);
int p = ...;
int l = lst.prev(p);
int r = lst.next(p);
lst.erase(p);
if (l != -1) {
    // l 为删除前最近的左侧存活节点
}
if (r != -1) {
    // r 为删除前最近的右侧存活节点
}
```
##### 从头遍历当前所有存活节点
```cpp
for (int p = lst.front_id(); p != -1; p = lst.next(p)) {
    cout << lst[p] << ' ';
}
```
##### 保存稳定节点编号
```cpp
int p = lst.push_back(x);
lst.push_back(y);
lst.erase(p);
// p 不会被后续新节点复用
```
