### 对顶堆
**动态分界 / 中位数 / Top-k**
> [!tip] 如果需要删除元素，可以使用 `multiset` 或**可删除堆**替代 `priority_queue`
```cpp
template<class T>
struct MedianHeap {
    priority_queue<T> lo;
    priority_queue<T, vector<T>, greater<T>> hi;
    void balance() {
        while (lo.size() > hi.size() + 1) {
            T x = lo.top();
            lo.pop();
            hi.push(x);
        }
        while (lo.size() < hi.size()) {
            T x = hi.top();
            hi.pop();
            lo.push(x);
        }
    }
    void insert(const T &v) {
        if (lo.empty() || v <= lo.top()) lo.push(v);
        else hi.push(v);
        balance();
    }
    int size() const { return lo.size() + hi.size(); }
    bool empty() const { return lo.empty(); }
    const T &lower() const { return lo.top(); }
    pair<T, T> middle() {
        if (lo.size() == hi.size()) return { lo.top(), hi.top() };
        return { lo.top(), lo.top() };
    }
    // 需要删除时
    void erase(const T &v) {
        if (v <= lo.top()) lo.erase(v);
        else hi.erase(v);
        balance();
    }
};
```
#### 成员变量
对顶堆，维护两个堆：
- `lo`：大根堆，保存较小的一半元素
- `hi`：小根堆，保存较大的一半元素
- 始终满足：
    - `lo.size() == hi.size()` 或 `lo.size() == hi.size() + 1`
- 因此奇数个元素时，中位数始终位于 `lo.top()`
#### 接口
- `insert(v)`：插入元素 `v`，均摊 $O(\log n)$
- `size()`：返回当前元素个数，$O(1)$
- `empty()`：判断是否为空，$O(1)$
- `erase(v)`：删除一个值为 `v` 的元素，要求当前结构非空且 `v` 存在，均摊 $O(\log n)$
- `lower()`：返回下中位数，要求非空，均摊 $O(1)$
- `middle()`：返回 `{下中位数, 上中位数}`，要求非空，均摊 $O(1)$
    - 奇数个元素时两个值相同
    - 偶数个元素时分别为两个中间元素
#### 注意事项
- `lower()`、`middle()` 都要求结构非空
- `erase(v)` 要求 `v` 当前确实存在；本结构本身不维护频率表，因此不会检查非法删除
- 如果题目中的删除操作不能保证元素存在，应额外维护 `map<T, int>` / `unordered_map<T, int>` 记录出现次数，删除前自行判断
- `ErasableHeap` 的 `size()` 是**逻辑大小**，而 `a.size()` 可能更大，因为尚未到堆顶的删除元素仍保存在物理堆中
- 因此大量“插入后删除、但被删元素长期不到堆顶”的情况下，实际内存不会立即释放；总空间与历史插入次数有关
#### 删除操作不保证合法
如果输入可能尝试删除不存在的元素，应自行维护频率：
```cpp
MedianHeap<int> med;
map<int, int> cnt;
auto insert = [&](int x) {
    med.insert(x);
    ++ cnt[x];
};
auto erase = [&](int x) {
    if (!cnt[x]) return;
    med.erase(x);
    if (!-- cnt[x]) cnt.erase(x);
};
```
### TopKSum
- Top-k 元素和
- 第 k 大 / 第 k 小
- 动态 Top-k
- 滑动窗口 Top-k
- 固定比例元素和
```cpp
// MAX=true：维护最大的 k 个元素；MAX=false：维护最小的 k 个元素
// 默认依赖 ErasableHeap；若不需要删除，可将 in / out 改为对应 priority_queue，并删除 erase()
template<class T, bool MAX = true, class Sum = T>
struct TopKSum {
    using InCmp = conditional_t<MAX, greater<T>, less<T>>;
    using OutCmp = conditional_t<MAX, less<T>, greater<T>>;
    int k;
    Sum sum{};
    ErasableHeap<T, InCmp> in;   // 被选中的 k 个元素，堆顶为其中最差者
    ErasableHeap<T, OutCmp> out; // 其余元素，堆顶为其中最优者
    explicit TopKSum(int k_ = 0) : k(k_) {}
    // ===== 基础维护：insert() / erase() / set_k() 均依赖，不建议删除 =====
    bool better(const T &x, const T &y) const {
        if constexpr (MAX) return x > y;
        else return x < y;
    }
    int need() const { return min(k, size()); }
    void move_in() {
        T x = out.top();
        out.pop();
        in.push(x);
        sum += Sum(x);
    }
    void move_out() {
        T x = in.top();
        in.pop();
        out.push(x);
        sum -= Sum(x);
    }
    void balance() {
        while (in.size() < need()) move_in();
        while (in.size() > need()) move_out();
    }
    // ===== 基础接口 =====
    int size() const { return in.size() + out.size(); }
    bool empty() const { return size() == 0; }
    Sum query() const { return sum; }
    const T &kth() { return in.top(); }
    void insert(const T &v) {
        if (k > 0 && (in.empty() || !better(in.top(), v))) {
            in.push(v);
            sum += Sum(v);
        } else out.push(v);
        balance();
    }
    // ===== 删除接口：若不需要删除，可删除本函数，并将 in / out 改为 priority_queue =====
    void erase(const T &v) {
        if (!in.empty() && !better(in.top(), v)) {
            in.erase(v);
            sum -= Sum(v);
        } else out.erase(v);
        balance();
    }
    // ===== 动态修改 k：若 k 固定，可直接删除 =====
    void set_k(int k_) {
        k = k_;
        balance();
    }
};
```
如果**完全不需要删除**，只需把：
```cpp
ErasableHeap<T, InCmp> in;
ErasableHeap<T, OutCmp> out;
```
改为：
```cpp
priority_queue<T, vector<T>, InCmp> in;
priority_queue<T, vector<T>, OutCmp> out;
```
然后删除：
```cpp
void erase(const T &v) { ... }
```
#### 成员变量
- `k`：需要维护的元素数量
- `sum`：当前被选中的 `min(k, size())` 个元素之和
- `in`：被选中的 Top-$k$ 集合
    - `MAX = true` 时保存最大的 $k$ 个元素，是小根堆
    - `MAX = false` 时保存最小的 $k$ 个元素，是大根堆
    - 堆顶始终是当前被选中元素中**最差的一个**
- `out`：其余元素
    - 堆顶始终是未被选中元素中**最优的一个**
- `better(x, y)`：判断 `x` 是否比 `y` 更应该进入 Top-$k$
    - `MAX = true`：等价于 `x > y`
    - `MAX = false`：等价于 `x < y`
例如维护最大的 $k$ 个元素时：
```text
out                in
其余元素        最大的 k 个元素
    ...  6 | 7  8  10
         ↑   ↑
     out.top  in.top
     最优落选   最差入选
```
始终保持所有 `in` 中元素不劣于所有 `out` 中元素
#### 接口
- `TopKSum(k)`：构造空结构，维护 Top-$k$，要求 `k >= 0`，$O(1)$
- `size()`：返回当前元素数量，$O(1)$
- `empty()`：判断是否为空，$O(1)$
- `insert(v)`：插入元素 `v`，均摊 $O(\log n)$
- `erase(v)`：删除一个值为 `v` 的元素，要求该元素当前存在，均摊 $O(\log n)$
- `query()`：返回当前最优 `min(k, n)` 个元素之和，$O(1)$
- `kth()`：返回第 $k$ 优元素，要求 `1 <= k <= size()`，均摊 $O(\log n)$
- `set_k(k)`：动态修改需要维护的元素数量，要求 `k >= 0`
其中：
- `TopKSum<i64> q(k);` 维护最大的 $k$ 个元素之和
- `TopKSum<i64, false> q(k);` 维护最小的 $k$ 个元素之和
#### 注意事项
- 当当前元素数小于 `k` 时，`in` 保存全部元素，因此：`q.query()` 返回所有元素之和。也就是说实际维护数量为：`min(k, q.size())`，这样可以从空结构开始直接设置任意 `k`，无需等元素数量达到 `k` 后再修改
- `kth()` 只有在：`1 <= k && k <= size()` 时才表示真正的第 $k$ 优元素。例如维护最大值时：
```text
10 8 7 | 6 3 1
     ↑
   kth()
```
`kth()` 为第 $k$ 大
- `erase(v)` 要求当前至少存在一个 `v`。底层 `ErasableHeap` 不检查非法删除
- 允许重复元素
例如：
```
5 5 5 3
```
维护最大的两个元素时，两个 `5` 都可以位于 `in`
- 删除边界值时，即使相同值同时存在于 `in` 和 `out`，代码优先删除 `in` 中的一个相同值，再由 `balance()` 补回需要的元素；因为相同值不可区分，不影响维护的多重集合与答案
- `Sum` 是求和使用的类型，默认等于 `T`
- 若不需要删除，建议按代码顶部说明改成 `priority_queue` 版本，可以删除懒删除带来的额外空间与常数
- 默认可删除版本的实际空间与**历史插入次数**有关，而不是当前元素数量，因为被懒删除但尚未到堆顶的元素不会立即从物理堆中移除
#### 常见用法
##### 最大的 $k$ 个元素之和
```cpp
TopKSum<i64> q(k);
for (i64 x : a) q.insert(x);
cout << q.query() << '\n';
```
##### 最小的 $k$ 个元素之和
```cpp
TopKSum<i64, false> q(k);
for (i64 x : a) q.insert(x);
cout << q.query() << '\n';
```
##### 动态插入和删除
```cpp
TopKSum<i64> q(k);
q.insert(10);
q.insert(3);
q.insert(7);
cout << q.query() << '\n';
q.erase(7);
```
##### 滑动窗口最大的 $k$ 个元素之和
```cpp
TopKSum<i64> q(k);
for (int i = 0; i < n; ++ i) {
    q.insert(a[i]);
    if (i >= len) q.erase(a[i - len]);
    if (i >= len - 1) {
        cout << q.query() << '\n';
    }
}
```
##### 动态修改 $k$
```cpp
q.set_k(new_k);
cout << q.query() << '\n';
```
例如维护所有元素中最大的前 $10\%$，向上取整：
```cpp
q.set_k((q.size() + 9) / 10);
```
若每次插入 / 删除后比例都要变化，就在操作后重新调用 `set_k()`
##### 查询第 $k$ 大 / 第 $k$ 小
维护最大 $k$ 个：
```cpp
TopKSum<int> q(k);
cout << q.kth() << '\n'; // 第 k 大
```
维护最小 $k$ 个：
```cpp
TopKSum<int, false> q(k);
cout << q.kth() << '\n'; // 第 k 小
```
#### 复杂度
设当前有 $n$ 个元素

| 操作                   | 时间复杂度                          |
| -------------------- | ------------------------------ |
| `size()` / `empty()` | $O(1)$                         |
| `query()`            | $O(1)$                         |
| `insert()`           | 均摊 $O(\log n)$                 |
| `erase()`            | 均摊 $O(\log n)$                 |
| `kth()`              | 均摊 $O(\log n)$                 |
| `set_k(k')`          | $O((\mid k'-k \mid +1)\log n)$ |
固定 `k` 时，单次 `insert()` / `erase()` 后最多只需要跨两个堆移动常数个元素
若 `k` 只改变 $O(1)$，则 `set_k()` 为均摊 $O(\log n)$；最坏一次从 `0` 改为 `n` 等情况需要 $O(n\log n)$
空间复杂度：
- 可删除版：历史插入 $q$ 次后最坏 $O(q)$
- `priority_queue` 无删除版：$O(n)$
### 可删除堆
**支持任意元素懒删除的优先队列**
```cpp
template<class T, class Compare = less<T>>
struct ErasableHeap {
    priority_queue<T, vector<T>, Compare> a, del;
    int cnt{ 0 };
    void normalize() {
        while (!a.empty() && !del.empty() && a.top() == del.top()) {
            a.pop();
            del.pop();
        }
    }
    void push(const T &v) {
        a.push(v);
        ++ cnt;
    }
    void erase(const T &v) {
        del.push(v);
        -- cnt;
        normalize();
    }
    const T &top() {
        normalize();
        return a.top();
    }
    void pop() {
        normalize();
        a.pop();
        -- cnt;
        normalize();
    }
    int size() const { return cnt; }
    bool empty() const { return cnt == 0; }
};
```
#### 成员变量
- `a`：实际插入元素的堆
- `del`：等待删除元素的堆
- `cnt`：当前**逻辑上仍存在**的元素数量
当 `a.top() == del.top()` 时，通过 `normalize()` 同时弹出两个元素完成真正删除
`Compare` 与 `priority_queue` 一致：
```cpp
ErasableHeap<int> mx;                // 大根堆
ErasableHeap<int, greater<int>> mn;  // 小根堆
```
#### 接口
- `push(v)`：插入 `v`，$O(\log n)$
- `erase(v)`：删除一个值为 `v` 的元素，要求该元素当前存在，均摊 $O(\log n)$
- `top()`：返回当前堆顶，要求非空，均摊 $O(\log n)$，通常可视为均摊 $O(1)$ 次查询加懒删除
- `pop()`：删除当前堆顶，要求非空，均摊 $O(\log n)$
- `size()`：返回当前逻辑元素数量，$O(1)$
- `empty()`：判断逻辑上是否为空，$O(1)$

> [!important]  
> `erase(v)` **不能判断 `v` 是否存在**。如果删除不存在的元素，`cnt` 和懒删除队列都会被破坏
> 因此调用方必须保证当前至少存在一个 `v`
### 二叉堆
```cpp
template<class T, class Compare = less<T>>
struct BinaryHeap {
    Compare better;
    vector<T> a;
    explicit BinaryHeap(Compare better_ = Compare()) : better(better_) {}
    BinaryHeap(vector<T> a_, Compare better_ = Compare()) : better(better_), a(move(a_)) {
        for (int i = size() / 2 - 1; i >= 0; -- i) sift_down(i);
    }
    void sift_up(int x) {
        while (x > 0) {
            int p{ x - 1 >> 1 };
            if (!better(a[x], a[p])) break;
            swap(a[x], a[p]);
            x = p;
        }
    }
    void sift_down(int x) {
        while (true) {
            int y{ x }, l{ x << 1 | 1 }, r{ x + 1 << 1 };
            if (l < size() && better(a[l], a[y])) y = l;
            if (r < size() && better(a[r], a[y])) y = r;
            if (y == x) break;
            swap(a[x], a[y]);
            x = y;
        }
    }
    // ===== 基础接口 =====
    bool empty() const { return a.empty(); }
    int size() const { return int(a.size()); }
    const T &top() const { return a[0]; }
    void push(T v) {
        a.push_back(move(v));
        sift_up(size() - 1);
    }
    void pop() {
        swap(a[0], a.back());
        a.pop_back();
        if (!a.empty()) sift_down(0);
    }
};
```
#### 成员变量
- `a`：完全二叉堆的顺序存储，节点 `x`：
    - 父节点为 `(x - 1) / 2`
    - 左儿子为 `2 * x + 1`
    - 右儿子为 `2 * x + 2`
- `better(x, y)`：判断 `x` 是否比 `y` 更优
    - 默认 `less<T>`：较小元素优先，为**小根堆**
    - `greater<T>`：较大元素优先，为**大根堆**

> [!important]  
> `Compare` 的含义是“第一个参数是否应该排在第二个参数前面”，因此与 `priority_queue` 的默认表现相反：
> 
> ```
> BinaryHeap<int> q;                 // 小根堆
> BinaryHeap<int, greater<int>> q;   // 大根堆
> ```
#### 接口
- `BinaryHeap(better)`：构造空堆，可传入比较器，$O(1)$
- `BinaryHeap(a, better)`：由序列 `a` 使用 Floyd 建堆，$O(n)$
- `empty()`：判断堆是否为空，$O(1)$
- `size()`：返回元素数量，$O(1)$
- `top()`：返回当前最优元素，要求堆非空，$O(1)$
- `push(v)`：插入元素 `v`，$O(\log n)$
- `pop()`：删除当前最优元素，要求堆非空，$O(\log n)$
内部维护：
- `sift_up(x)`：从节点 `x` 向上恢复堆序，$O(\log n)$
- `sift_down(x)`：从节点 `x` 向下恢复堆序，$O(\log n)$
#### 注意事项
- `top()` 和 `pop()` 要求堆非空
- 默认 `Compare = less<T>` 得到的是**小根堆**，与 `priority_queue<T>` 默认的大根堆相反
- `Compare` 应满足严格弱序；若：`better(x, y)` 为 `true`，表示 `x` 应比 `y` 更靠近堆顶
- 由整个数组初始化时，应直接使用：`BinaryHeap<int> q(a);` 建堆复杂度为 $O(n)$；逐个 `push()` 是 $O(n\log n)$
- `BinaryHeap(vector<T> a_)` 按值接收数组，因此：
    - 传左值时会复制；
    - 不再需要原数组时可：`BinaryHeap<int> q(move(a));` 避免复制
- 当前普通二叉堆只维护**元素值**，不维护元素身份或位置，因此不适合：
    - 按编号修改元素
    - 删除指定元素
    - `decrease-key / increase-key`
    - 高效合并两个堆
这些需求分别使用 `IndexedHeap`、可删除堆或可并堆
- 若只需要普通优先队列操作，应直接使用 STL `priority_queue`；这份实现主要用于需要手写、修改或扩展二叉堆内部操作的场景
#### 常见用法
- 小根堆：`BinaryHeap<int> q;`
- 大根堆：`BinaryHeap<int, greater<int>> q;`
##### $O(n)$ 建堆
```cpp
vector<int> a{ 5, 2, 7, 1, 3 };
BinaryHeap<int> q(move(a));
```
##### 自定义优先级
```cpp
struct Compare {
    bool operator()(const pair<int, int> &a, const pair<int, int> &b) const {
        return a.second < b.second;
    }
};
BinaryHeap<pair<int, int>, Compare> q;
```
此时 `second` 较小的元素优先
如果需要稳定处理相同优先级，应把次关键字也显式加入比较：
```cpp
struct Compare {
    bool operator()(const pair<int, int> &a, const pair<int, int> &b) const {
        if (a.second != b.second) return a.second < b.second;
        return a.first < b.first;
    }
};
```
#### 复杂度

| 操作                          | 时间复杂度       |
| --------------------------- | ----------- |
| 构造空堆                        | $O(1)$      |
| Floyd 建堆                    | $O(n)$      |
| `empty()` / `size()`        | $O(1)$      |
| `top()`                     | $O(1)$      |
| `push()`                    | $O(\log n)$ |
| `pop()`                     | $O(\log n)$ |
| `sift_up()` / `sift_down()` | $O(\log n)$ |
空间复杂度：$O(n)$
#### 常见用法
##### 小根堆
```cpp
BinaryHeap<int> q;
```
##### 大根堆
```cpp
BinaryHeap<int, greater<int>> q;
```
##### 自定义优先级
```cpp
struct Compare {
    bool operator()(const pair<int, int> &a, const pair<int, int> &b) const {
        return a.second < b.second;
    }
};
BinaryHeap<pair<int, int>, Compare> q;
```
此时 `second` 较小的元素优先

### 索引堆
与普通二叉堆相比，额外维护稳定的元素编号 `id` 与堆位置之间的双向映射，因此可以按 `id` 在 $O(\log n)$ 内修改或删除任意元素
```cpp
template<class T, class Compare = less<T>>
struct IndexHeap {
    int n;
    Compare better;
    vector<int> heap, pos;
    vector<T> val;
    explicit IndexHeap(int n_, Compare better_ = Compare()) : n(n_), better(better_), pos(n, -1), val(n) {}
    IndexHeap(vector<T> val_, Compare better_ = Compare()) : n(val_.size()), better(better_), heap(n), pos(n), val(move(val_)) {
        ranges::iota(heap, 0);
        ranges::iota(pos, 0);
        for (int i = n / 2 - 1; i >= 0; -- i) sift_down(i);
    }
    // ===== 基础维护：所有修改操作依赖，不建议删除 =====
    bool better_id(int x, int y) const {
        if (better(val[x], val[y])) return true;
        if (better(val[y], val[x])) return false;
        return x < y;
    }
    void swap_node(int x, int y) {
        swap(heap[x], heap[y]);
        pos[heap[x]] = x;
        pos[heap[y]] = y;
    }
    void sift_up(int x) {
        while (x > 0) {
            int p{ x - 1 >> 1 };
            if (!better_id(heap[x], heap[p])) break;
            swap_node(x, p);
            x = p;
        }
    }
    void sift_down(int x) {
        while (true) {
            int y{ x }, l{ x << 1 | 1 }, r{ x + 1 << 1 };
            if (l < size() && better_id(heap[l], heap[y])) y = l;
            if (r < size() && better_id(heap[r], heap[y])) y = r;
            if (y == x) break;
            swap_node(x, y);
            x = y;
        }
    }
    void fix(int x) {
        if (x > 0 && better_id(heap[x], heap[x - 1 >> 1])) sift_up(x);
        else sift_down(x);
    }
    // ===== 基础接口 =====
    bool empty() const { return heap.empty(); }
    int size() const { return int(heap.size()); }
    bool contains(int id) const { return pos[id] != -1; }
    int top_id() const { return heap[0]; }
    const T &top() const { return val[heap[0]]; }
    void push(int id, T v) {
        val[id] = move(v);
        pos[id] = size();
        heap.push_back(id);
        sift_up(size() - 1);
    }
    void set(int id, T v) {
        val[id] = move(v);
        fix(pos[id]);
    }
    void erase(int id) {
        int x{ pos[id] };
        swap_node(x, size() - 1);
        heap.pop_back();
        pos[id] = -1;
        if (x < size()) fix(x);
    }
    void pop() { erase(top_id()); }
};
```
#### 成员变量
- `n`：允许使用的 `id` 数量，合法编号为 `[0, n)`
- `heap[p]`：堆中位置 `p` 对应的元素 `id`
- `pos[id]`：编号 `id` 当前在 `heap` 中的位置；不存在时为 `-1`
- `val[id]`：编号 `id` 对应的权值
- `better(x, y)`：判断权值 `x` 是否比 `y` 更优
    - 默认 `less<T>`：较小权值优先，为**小根堆**
    - `greater<T>`：较大权值优先，为**大根堆**
始终维护：
```cpp
heap[pos[id]] == id;
pos[heap[p]] == p;
```
对于当前存在的所有元素成立

> [!important]  
> `id` 是元素的**稳定身份**，而 `pos[id]` 是会随堆调整不断变化的内部位置
> 调用接口时始终传 `id`，不要保存或使用某次操作后的堆位置
#### 比较规则

`better_id(x, y)` 比较的是编号 `x`、`y` 对应的权值：`better(val[x], val[y])`
当两个权值在 `Compare` 意义下等价时，编号较小者优先，因此堆顶结果具有确定性
例如：
```cpp
IndexHeap<int> q(n);                 // 小根堆
IndexHeap<int, greater<int>> q(n);   // 大根堆
```
与普通 `BinaryHeap` 一样，`Compare` 表示“谁更优”，因此默认 `less<T>` 得到小根堆
#### 接口
- `IndexHeap(n, better)`：构造空索引堆，允许 `id` 为 `[0, n)`，$O(n)$
- `IndexHeap(val, better)`：将 `val[i]` 作为编号 `i` 的权值，将全部 `0..n-1` 加入堆并使用 Floyd 建堆，$O(n)$
- `empty()`：判断当前是否为空，$O(1)$
- `size()`：返回当前堆中的元素数量，$O(1)$
- `contains(id)`：判断编号 `id` 当前是否在堆中，要求 `0 <= id < n`，$O(1)$
- `top_id()`：返回当前最优元素的编号，要求非空，$O(1)$
- `top()`：返回当前最优元素的权值，要求非空，$O(1)$
- `push(id, v)`：插入编号 `id`、权值 `v`，要求 `id` 合法且当前不存在，$O(\log n)$
- `set(id, v)`：将已存在的 `id` 的权值修改为 `v`，要求 `id` 当前存在，$O(\log n)$
- `erase(id)`：删除指定 `id`，要求 `id` 当前存在，$O(\log n)$
- `pop()`：删除当前最优元素，要求非空，$O(\log n)$
内部维护：
- `sift_up(p)`：从堆位置 `p` 向上恢复堆序，$O(\log n)$
- `sift_down(p)`：从堆位置 `p` 向下恢复堆序，$O(\log n)$
- `fix(p)`：权值改变或任意位置被替换后，根据实际失衡方向选择上浮或下沉，$O(\log n)$
- `swap_node(x, y)`：交换两个堆位置，并同步维护 `pos`，$O(1)$
#### 注意事项
- 所有 `id` 均为 `0base`，范围固定为 `[0, n)`
- 同一个 `id` 在堆中最多出现一次
- `push(id, v)` 要求 `id` 当前不存在；若已经存在且只是修改权值，应使用：`q.set(id, v);`
- `set(id, v)` 与 `erase(id)` 要求 `id` 当前存在
- `top()`、`top_id()`、`pop()` 要求堆非空
- `erase(id)` 删除后：`q.contains(id) == false`
但 `val[id]` 中仍可能保留旧值；只有 `contains(id)` 能表示该编号当前是否属于堆
- 删除后的 `id` 可以再次插入：
```cpp
q.erase(id);
q.push(id, new_value);
```
- 不要直接修改：`q.val[id] = x;` 这不会恢复堆序。权值变化必须通过：`q.set(id, x);`
- 同样不要直接修改 `heap` 或 `pos`，否则会破坏双向映射
- `IndexHeap(n)` 会直接分配长度为 `n` 的 `pos` 和 `val`，因此构造本身为 $O(n)$，空间也与**编号范围**而不是当前堆大小有关。
- `T` 在空堆构造时需要能够默认构造，因为会创建：`vector<T> val(n);`
- 如果编号非常稀疏且范围极大，不适合直接使用这一实现；此时应改用哈希表维护 `id -> pos`
- 两个索引堆不能像左偏树 / 斜堆一样高效合并；需要频繁合并堆时应使用可并堆

> [!tip]  
> 普通二叉堆中，元素被交换后数组位置就失去了稳定意义；索引堆增加 `pos[id]` 的目的就是让外部始终通过稳定的 `id` 找到元素
> 因此它特别适合 `decrease-key`、`increase-key`、删除指定编号等普通 `priority_queue` 不直接支持的操作
#### 常见用法
##### 小根索引堆
```cpp
IndexHeap<int> q(n);
q.push(3, 10);
q.push(5, 7);
q.push(1, 20);
cout << q.top_id() << ' ' << q.top() << '\n'; // 5 7
```
##### 大根索引堆
```cpp
IndexHeap<int, greater<int>> q(n);
```
##### 修改指定元素
`set()` 同时支持权值变优和变差，无需区分 `decrease-key` / `increase-key`：
```cpp
q.set(id, new_value);
```
例如小根堆中：
```cpp
q.set(id, smaller); // decrease-key，可能向上移动
q.set(id, larger);  // increase-key，可能向下移动
```
`fix()` 会自行判断恢复方向
##### 删除指定元素
```cpp
if (q.contains(id)) q.erase(id);
```
删除时先用堆尾元素填补原位置，再根据新的局部关系决定上浮或下沉
##### $O(n)$ 建堆
若一开始所有编号 `0..n-1` 都存在：
```cpp
vector<i64> a(n);
IndexHeap<i64> q(move(a));
```
此时：
```cpp
q.val[id]
```
对应原数组中的 `a[id]`，全部编号通过 Floyd 方法在 $O(n)$ 内建堆
##### Dijkstra 的 decrease-key
索引堆最典型的用途之一是保证每个未确定节点在堆中至多出现一次。以节点下标作为索引用于 Dijkstra，并给出了 $O(m\log n)$ 的实现
松弛成功时可以写：
```cpp
if (dist[v] > dist[u] + w) {
    dist[v] = dist[u] + w;
    if (q.contains(v)) q.set(v, dist[v]);
    else q.push(v, dist[v]);
}
```
相比常见的：
```cpp
priority_queue<pair<i64, int>, ...>
```
反复插入新距离的懒删除写法，索引堆始终只保存每个 `id` 的当前权值
#### 与普通二叉堆的区别

|能力|`BinaryHeap`|`IndexHeap`|
|---|---|---|
|查询堆顶|✅|✅|
|插入|✅|✅|
|删除堆顶|✅|✅|
|$O(n)$ 建堆|✅|✅|
|保留稳定元素编号|❌|✅|
|判断指定 `id` 是否存在|❌|✅|
|修改指定元素|❌|✅|
|删除指定元素|❌|✅|
|`decrease-key / increase-key`|❌|✅|
|额外 `id -> pos` 空间|❌|✅|
所以两份板子的定位可以非常清楚：
- `BinaryHeap`：标准、极简的数组二叉堆
- `IndexHeap`：需要**稳定编号 + 任意元素修改/删除**时使用
#### 复杂度
设允许的编号范围为 $n$，当前堆中有 $m$ 个元素

|操作|时间复杂度|
|---|---|
|构造空索引堆|$O(n)$|
|全量 Floyd 建堆|$O(n)$|
|`empty()` / `size()`|$O(1)$|
|`contains()`|$O(1)$|
|`top()` / `top_id()`|$O(1)$|
|`push()`|$O(\log m)$|
|`set()`|$O(\log m)$|
|`erase()`|$O(\log m)$|
|`pop()`|$O(\log m)$|
|`sift_up()` / `sift_down()` / `fix()`|$O(\log m)$|
空间复杂度：$O(n)$
### 左偏树与斜堆
用于维护**可以快速合并的堆**
```cpp
// LEFTIST=true：左偏树；LEFTIST=false：斜堆
// 两者只有合并后的维护规则不同，节点池与公开接口共用这一份实现
template<class T, bool LEFTIST = true, class Compare = less<T>>
struct MeldableHeap {
    struct Node {
        T val{};
        int ch[2]{}, dis{};
    };
    Compare better;
    vector<Node> tr{{}};
    // ===== 1. 节点创建：push() 依赖，不使用 push() 时可与 push() 一并删除 =====
    int new_node(const T &v) {
        tr.push_back({ v, {0, 0}, 1 });
        return int(tr.size()) - 1;
    }
    // ===== 2. 可并堆核心：push() / pop() 均依赖，不使用整个结构时才删除 =====
    int merge(int x, int y) {
        if (!x || !y) return x | y;
        if (better(tr[y].val, tr[x].val)) swap(x, y);
        tr[x].ch[1] = merge(tr[x].ch[1], y);
        if constexpr (LEFTIST) {
            if (tr[tr[x].ch[0]].dis < tr[tr[x].ch[1]].dis) {
                swap(tr[x].ch[0], tr[x].ch[1]);
            }
            tr[x].dis = tr[tr[x].ch[1]].dis + 1;
        } else {
            swap(tr[x].ch[0], tr[x].ch[1]);
        }
        return x;
    }
    // ===== 3. 插入扩展：不用时删除 push() 与 new_node() =====
    int push(int root, const T &v) { return merge(root, new_node(v)); }
    // ===== 4. 删除堆顶扩展：不用时只删除 pop() =====
    int pop(int root) { return merge(tr[root].ch[0], tr[root].ch[1]); }
    // ===== 5. 读取堆顶：不用时可单独删除 =====
    const T &top(int root) const { return tr[root].val; }
};
template<class T, class Compare = less<T>>
using LeftistHeap = MeldableHeap<T, true, Compare>;
template<class T, class Compare = less<T>>
using SkewHeap = MeldableHeap<T, false, Compare>;
```
#### 接口说明
通过模板参数选择实现：
```cpp
LeftistHeap<T>   // 左偏树
SkewHeap<T>      // 斜堆
```
两者共用相同的节点池与接口，只在 `merge()` 后的树形维护方式不同
##### 成员变量
- `tr[0]`：空节点
- `tr[p].val`：节点 `p` 的值
- `tr[p].ch[0/1]`：左右儿子
- `tr[p].dis`：左偏树使用的右路径相关信息；斜堆不使用
- `root`：**不存储在结构体内部**，每个堆由一个外部整数根编号表示
- `better(x, y)`：判断 `x` 是否比 `y` 更优
    - 默认 `less<T>`：小根堆
    - `greater<T>`：大根堆
一个 `MeldableHeap` 节点池可以同时维护多个堆：
```cpp
LeftistHeap<int> heap;
int a{ 0 }, b{ 0 };
```
其中 `0` 表示空堆
##### 接口
- `new_node(v)`：创建值为 `v` 的节点并返回编号，$O(1)$
- `merge(x, y)`：合并根为 `x`、`y` 的两个堆，返回新根
- `push(root, v)`：向 `root` 所表示的堆插入 `v`，返回新根
- `pop(root)`：删除堆顶并返回新根，要求 `root != 0`
- `top(root)`：返回堆顶元素，要求 `root != 0`，$O(1)$

> [!important]  
> `push()`、`pop()`、`merge()` 都**返回新的根编号**，必须接住：
> 
> ```cpp
> root = heap.push(root, x);
> root = heap.pop(root);
> root = heap.merge(root, other);
> ```

#### 注意事项
- 默认 `less<T>` 是小根堆
- 空堆根编号为 `0`
- `top(root)` 和 `pop(root)` 要求 `root != 0`
- `merge(x, y)` 是**破坏性合并**：
    - 要求 `x`、`y` 表示两个彼此独立的堆
    - 合并后应使用返回的新根
    - 不要继续把原来的 `x`、`y` 当作两个独立堆使用
- 特别不能执行：
```cpp
root = heap.merge(root, root);
```
否则会破坏树结构
- `pop()` 只把原根从当前堆中移除，节点仍保留在节点池中，不会回收内存
- 因此空间复杂度取决于**历史创建节点数**，而不是当前堆中元素数
- 当前实现没有：
    - 删除任意节点
    - 修改已有节点权值
    - 节点回收
#### 左偏树与斜堆的选择

|结构|特点|
|---|---|
|左偏树|额外维护 `dis`，单次 `merge` 有 $O(\log n)$ 最坏保证|
|斜堆|不维护 `dis`，代码和常数更小，操作为均摊 $O(\log n)$|
|二叉堆|`push/pop` 简单，但两个普通堆不能高效合并|
如果题目核心操作是：*不断把两个集合的堆合并*
应优先考虑左偏树或斜堆，而不是普通二叉堆
#### 常见用法
##### 单个可并堆
```cpp
LeftistHeap<int> heap;
int root{ 0 };
root = heap.push(root, 3);
root = heap.push(root, 1);
root = heap.push(root, 5);
cout << heap.top(root) << '\n'; // 1
root = heap.pop(root);
```
##### 合并两个堆
```cpp
LeftistHeap<int> heap;
int a{ 0 }, b{ 0 };
a = heap.push(a, 1);
a = heap.push(a, 5);
b = heap.push(b, 2);
b = heap.push(b, 3);
a = heap.merge(a, b);
b = 0;
cout << heap.top(a) << '\n';
```
合并后令 `b = 0` 是很好的赛场习惯，可以避免误用旧根
##### 大根可并堆
```cpp
LeftistHeap<int, greater<int>> heap;
```
##### 同时维护很多堆
```cpp
LeftistHeap<int> heap;
vector<int> root(n);
root[u] = heap.push(root[u], x);
root[u] = heap.merge(root[u], root[v]);
root[v] = 0;
```
这种写法很适合并查集合并、树上合并等问题
### Radix Heap
```cpp
// 单调最小堆：要求每次 push(key, val) 满足 key >= last
// Key 必须为不超过 64 位的无符号整数
template<class T = int, class Key = u64>
struct RadixHeap {
    static_assert(is_unsigned_v<Key> && sizeof(Key) <= 8);
    static constexpr int B = numeric_limits<Key>::digits + 1;
    using P = pair<Key, T>;
    array<vector<P>, B> bucket;
    Key last{};
    int cnt{ 0 };
    // ===== 基础维护：push() / top() / pop() 均依赖，不建议删除 =====
    int bit_width(Key x) const {
        if (!x) return 0;
        if constexpr (sizeof(Key) <= 4) return 32 - __builtin_clz((unsigned)x);
        else return 64 - __builtin_clzll((unsigned long long)x);
    }
    int id(Key key) const { return bit_width(key ^ last); }
    void pull() {
        if (!bucket[0].empty()) return;
        int i{ 1 };
        while (bucket[i].empty()) ++ i;
        last = ranges::min_element(bucket[i]), [](const P &a, const P &b) {
            return a.first < b.first;
        })->first;
        vector<P> cur;
        cur.swap(bucket[i]);
        for (auto &e : cur) bucket[id(e.first)].push_back(move(e));
    }
    // ===== 基础接口 =====
    bool empty() const { return cnt == 0; }
    int size() const { return cnt; }
    void push(Key key, T val) {
        bucket[id(key)].push_back({key, move(val)});
        ++ cnt;
    }
    const P &top() {
        pull();
        return bucket[0].back();
    }
    void pop() {
        pull();
        bucket[0].pop_back();
        -- cnt;
    }
};
```
#### 成员变量
- `bucket[i]`：第 `i` 个桶，按照 `key ^ last` 的最高位进行划分
- `last`：最近一次被确定为堆顶的最小 `key`，初始为 `0`
- `cnt`：当前元素数量
- `B`：桶数量，为 `Key` 的二进制位数加 `1`
    - `u32`：`33` 个桶
    - `u64`：`65` 个桶
- `P = pair<Key, T>`：堆中元素，`first` 为排序键，`second` 为附带数据
桶编号为：`id(key) = bit_width(key ^ last);`
因此：
- `bucket[0]`：`key == last`
- `bucket[i]`：`key` 与 `last` 的最高不同位为第 `i - 1` 位

> [!important]  
> Radix Heap 是**单调最小堆**。必须保证每次：`push(key, val);`
> 都满足：`key >= last;`
> 也就是新插入的键不能小于已经弹出的最小键
#### 核心维护
当 `bucket[0]` 为空时，找到编号最小的非空桶 `i`：
1. 找出该桶中最小的 `key` 
2. 将其设为新的 `last`
3. 将整个 `bucket[i]` 按新的 `last` 重新分桶
4. 此时至少一个元素进入 `bucket[0]`
```cpp
last = min key in bucket[i];
```
由于重新分桶后，这些元素所在的桶编号都会严格减小，因此一个元素在整个生命周期中只会被重新分桶有限次
#### 接口
- `RadixHeap<T, Key>()`：构造空 Radix Heap，`last = 0`，$O(1)$
- `empty()`：判断是否为空，$O(1)$
- `size()`：返回当前元素数量，$O(1)$
- `push(key, val)`：插入 `{key, val}`，要求 `key >= last`，$O(1)$
- `top()`：返回当前最小 `key` 对应的 `{key, val}`，要求非空，均摊 $O(W)$
- `pop()`：删除当前堆顶，要求非空，均摊 $O(W)$
其中 $W$ 为 `Key` 的二进制位数，通常：
```text
u32：W = 32
u64：W = 64
```
因此固定整数类型下，桶数量是很小的常数
#### 注意事项
- `Key` 必须是**无符号整数类型**，并且当前实现要求不超过 `64` 位：
```cpp
RadixHeap<int, unsigned> q;
RadixHeap<int, u64> q;
```
- 不要使用：
```cpp
RadixHeap<int, i64>
```
即使实际数据保证非负，也应直接使用 `u64` 作为键类型
- `push(key, val)` 必须满足：`key >= last` 违反该条件后，桶划分不再满足 Radix Heap 的单调性质，结果可能错误
- Radix Heap 不支持普通优先队列意义上的任意键序列，因此不能直接替代 `priority_queue`
适合*弹出的 key 保证单调不减*，不适合：*弹出 100 后，未来仍可能插入 key = 50*
- `top()` 和 `pop()` 要求堆非空
- 相同 `key` 的元素都位于 `bucket[0]`，但这些元素之间**没有稳定顺序**。如果相同键下还要求按照其他字段排序，需要自行把次关键字编码进 `Key`，或者改用其他优先队列
- 当前版本不提供：
    - `erase()`
    - 任意元素修改
    - `decrease-key`
    - 最大堆
Radix Heap 更常见的使用方式是直接插入新状态，并在取出时判断状态是否已经过期
- 与二叉堆不同，`push()` 本身就是 $O(1)$，因此若一开始有 $n$ 个合法初始元素，直接逐个：
```cpp
for (...) q.push(key, val);
```
总插入复杂度已经是 $O(n)$，没有必要再单独提供 `build()`
- `last` 表示最近一次 `pull()` 确定的最小键。调用 `top()` 后即使尚未 `pop()`，`last` 也可能已经更新为当前堆顶键
#### 常见用法
##### 基础使用
```cpp
RadixHeap<int> q;
q.push(3, 0);
q.push(5, 1);
q.push(8, 2);
auto [key, id] = q.top();
q.pop();
```
由于初始：`last == 0`
这些插入都满足单调条件
##### 自定义附带数据
排序只由 `Key` 决定，`T` 可以保存任意状态：
```cpp
struct State {
    int u, from;
};
RadixHeap<State> q;
q.push(dis, {u, from});
```
##### Dijkstra
Radix Heap 最典型的应用是**非负整数边权 Dijkstra**。
```cpp
vector<u64> dis(n, ULLONG_MAX);
RadixHeap<int> q;
dis[s] = 0;
q.push(0, s);
while (!q.empty()) {
    auto [d, u] = q.top();
    q.pop();
    if (d != dis[u]) continue;
    for (auto [v, w] : g[u]) if (d + w < dis[v]) {
        dis[v] = d + w;
        q.push(d + w, v);
    }
}
```
这里要求：`w >= 0`
因此当前有效状态满足：`nd = d + w >= d >= last`
符合 Radix Heap 的插入条件
> [!important]  
> 使用懒删除 Dijkstra 时，应先跳过过期状态：`if (d != dis[u]) continue;` 再进行松弛
> 不应从一个已经过期的状态继续使用较小的 `dis[u]` 松弛，否则新得到的键可能小于当前 `last`，破坏 Radix Heap 的单调条件
#### 与普通二叉堆的区别

|特性|二叉堆|Radix Heap|
|---|--:|--:|
|任意可比较键|✅|❌|
|无符号整数键|✅|✅|
|插入键可任意变化|✅|❌|
|要求 `key >= last`|❌|✅|
|`push()`|$O(\log n)$|$O(1)$|
|`top/pop`|$O(\log n)$|均摊与整数位宽有关|
|自定义 `Compare`|✅|❌|
|Dijkstra|✅|**整数键时适合**|
|支持最大堆|✅|当前版本不支持|
因此选择标准可以直接记为：
```text
普通动态优先队列
→ BinaryHeap / priority_queue
非负整数 key + 弹出值单调不减
→ RadixHeap
```
#### 复杂度
设：
- 当前 / 历史共插入 $q$ 个元素 
- `Key` 的位宽为 $W$
每次重新分桶时，元素所在的桶编号会严格减小，因此每个元素最多被重新分桶 $W$ 次

|操作|时间复杂度|
|---|--:|
|`empty()` / `size()`|$O(1)$|
|`push()`|$O(1)$|
|`top()`|均摊 $O(W)$|
|`pop()`|均摊 $O(W)$|
单次 `top()` / `pop()` 在触发一个大桶重新分配时可能达到 $O(n + W)$，上述为整个操作序列上的均摊复杂度
总重新分桶复杂度为：$O(qW)$
对于固定的 `u32` / `u64`：$W=32\text{ 或 }64$
因此实际实现中可将位宽看作较小常数
空间复杂度：$O(n+W)$
其中 $n$ 为当前堆内元素数量
经典 one-level Radix Heap 用于边权为非负整数且最大边权为 $C$ 的 Dijkstra 时，可得到 $O(m+n\log C)$ 的专门复杂度界；这是该结构最初提出时的主要用途。
