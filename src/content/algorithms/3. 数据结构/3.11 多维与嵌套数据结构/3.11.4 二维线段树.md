### 二维线段树
---
已有二维 BIT 不支持一般最值的单点赋值，因此补充一份短的二维迭代线段树作为动态矩形最值后端。
```cpp
template<class T, class Op>
struct SegTree2D {
    int n, m, sx = 1, sy = 1;
    T e;
    Op op;
    vector<vector<T>> tr;
    SegTree2D(int n_, int m_, T e_, Op op_ = Op())
        : n(n_), m(m_), e(e_), op(op_) {
        while (sx < n) sx <<= 1;
        while (sy < m) sy <<= 1;
        tr.assign(2 * sx, vector<T>(2 * sy, e));
    }
    SegTree2D(const vector<vector<T>> &a, T e_, Op op_ = Op())
        : SegTree2D(int(a.size()), a.empty() ? 0 : int(a[0].size()), e_, op_) {
        for (int i = 0; i < n; ++ i) {
            for (int j = 0; j < m; ++ j) tr[sx + i][sy + j] = a[i][j];
            for (int j = sy - 1; j; -- j) {
                tr[sx + i][j] = op(tr[sx + i][j << 1], tr[sx + i][j << 1 | 1]);
            }
        }
        for (int i = sx - 1; i; -- i) {
            for (int j = 1; j < 2 * sy; ++ j) {
                tr[i][j] = op(tr[i << 1][j], tr[i << 1 | 1][j]);
            }
        }
    }
    void set(int x, int y, const T &v) {
        int p = sx + x, q = sy + y;
        tr[p][q] = v;
        for (int j = q >> 1; j; j >>= 1) {
            tr[p][j] = op(tr[p][j << 1], tr[p][j << 1 | 1]);
        }
        for (p >>= 1; p; p >>= 1) {
            tr[p][q] = op(tr[p << 1][q], tr[p << 1 | 1][q]);
            for (int j = q >> 1; j; j >>= 1) {
                tr[p][j] = op(tr[p][j << 1], tr[p][j << 1 | 1]);
            }
        }
    }
    T query_y(int p, int l, int r) const {
        T left = e, right = e;
        for (l += sy, r += sy; l < r; l >>= 1, r >>= 1) {
            if (l & 1) left = op(left, tr[p][l ++]);
            if (r & 1) right = op(tr[p][-- r], right);
        }
        return op(left, right);
    }
    T query(int x1, int y1, int x2, int y2) const {
        T ans = e;
        for (x1 += sx, x2 += sx; x1 < x2; x1 >>= 1, x2 >>= 1) {
            if (x1 & 1) ans = op(ans, query_y(x1 ++, y1, y2));
            if (x2 & 1) ans = op(ans, query_y(-- x2, y1, y2));
        }
        return ans;
    }
};
```
#### 接口说明
- `SegTree2D(n,m,e,op)`：空矩阵（初始值为单位元 `e`），$O(nm)$；`SegTree2D(a,e,op)`：用矩阵线性建树，$O(nm)$。
- `set(x,y,value)`：单点赋值，$O(\log n\log m)$。
- `query(x1,y1,x2,y2)`：矩形聚合，$O(\log n\log m)$。
- `e`：聚合单位元；`op`：**交换且结合**的二元运算。
#### 注意事项
- 适用范围：二维单点赋值 + 矩形 `min/max/gcd/sum` 等**可交换结合**的聚合。这里不支持一般非交换运算。
- 单点加 + 矩形和请优先使用 `3.3.2 BIT2D`；矩形加 + 矩形和请复用同页的四棵 BIT；静态矩形最值可选 `3.4.2` 二维 ST 表。
- 下标 `0base`，矩形 `[x1,x2) × [y1,y2)`。空间为 $4s_xs_y$ 个 `T`（其中 $s_x,s_y$ 为二次幂扩容维度），大矩阵可能较耗内存。
#### 常见用法
```cpp
struct MinOp { int operator()(int a, int b) const { return min(a, b); } };
SegTree2D<int, MinOp> seg(a, INT_MAX);
seg.set(x, y, v);
int res = seg.query(x1, y1, x2, y2);
```
#### 复杂度
线性初始化 $O(nm)$；单点赋值、矩形查询 $O(\log n\log m)$；空间 $O(nm)$，具体为 $4s_xs_y$ 个元素，介于 $4nm$ 与约 $16nm$ 之间（非空矩阵）。
