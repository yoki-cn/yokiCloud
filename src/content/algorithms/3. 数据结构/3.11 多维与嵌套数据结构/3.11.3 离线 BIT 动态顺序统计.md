### 离线 BIT 动态顺序统计
---
复用 `OfflineBIT2D<int>`：位置为第一维，权值为第二维。适合**提前已知所有修改值**的动态顺序统计。
**依赖**：[[3.3.3 离线二维树状数组]] 中的 `OfflineBIT2D<T>`。
```cpp
struct OfflineKthBIT {
    int n;
    vector<i64> a, xs;
    OfflineBIT2D<int> bit;
    OfflineKthBIT(vector<i64> a_, const vector<pair<int, i64>> &updates)
        : n(a_.size()), a(move(a_)), xs(a), bit(n) {
        for (int i = 0; i < n; ++ i) bit.reserve_point(i, a[i]);
        for (auto [pos, x] : updates) {
            bit.reserve_point(pos, x);
            xs.push_back(x);
        }
        ranges::sort(xs);
        xs.erase(unique(xs.begin(), xs.end()), xs.end());
        bit.build();
        for (int i = 0; i < n; ++ i) bit.add(i, a[i], 1);
    }
    void modify(int pos, i64 x) {
        if (a[pos] == x) return;
        bit.add(pos, a[pos], -1);
        bit.add(pos, x, 1);
        a[pos] = x;
    }
    int count_less(int l, int r, i64 x) const {
        return bit.prefix(r, x) - bit.prefix(l, x);
    }
    int count_range(int l, int r, i64 lo, i64 hi) const {
        return count_less(l, r, hi) - count_less(l, r, lo);
    }
    int rank(int l, int r, i64 x) const { return count_less(l, r, x) + 1; }
    i64 kth(int l, int r, int k) const {
        assert(1 <= k && k <= r - l);
        int low = 0, high = int(xs.size());
        while (low + 1 < high) {
            int mid = (low + high) / 2;
            if (count_less(l, r, xs[mid]) < k) low = mid;
            else high = mid;
        }
        return xs[low];
    }
};
```
#### 接口说明
- `OfflineKthBIT(a, updates)`：建树前预登记所有可能发生的 `(位置, 修改后权值)`；时间 $O((n+q)\log n\log(n+q))$ 量级。
- `modify(pos,x)`：单点赋值，$O(\log^2 n)$（把对数中的内部坐标规模记为 $O(n+q)$ 时）。
- `count_less(l,r,x)` / `count_range(l,r,lo,hi)` / `rank(l,r,x)`：动态区间计数/排名，$O(\log n\log(n+q))$。
- `kth(l,r,k)`：**1base** 第 `k` 小，$O(\log\sigma\log n\log(n+q))$，$\sigma=|xs|$。
- `a`：当前位置的值；`xs`：全部可能权值的升序去重表。
#### 注意事项
- 必须预先收集修改后的 `(pos,new_value)`；每个位置的初始值由构造器自动登记。查询的阈值无需登记。
- `OfflineBIT2D` 的 `add()` 默认**不检查坐标是否登记**；漏登记修改值会悄悄写错，因此须先离线扫描全部操作。
- 与 `3.11.1` 相比，`kth` 多一层二分，通常更慢；但第二维压缩后内存布局连续，在更新坐标稀疏且完全已知时值得选用。
#### 常见用法
```cpp
vector<pair<int, i64>> updates;
for (auto [pos, x] : all_future_modifications) updates.push_back({pos, x});
OfflineKthBIT bit(a, updates);
bit.modify(pos, x);
int rank = bit.rank(l, r, x);
i64 kth = bit.kth(l, r, k);
```
#### 复杂度
设 $M=n+q$ 为初始元素数与预登记操作数，$\sigma$ 为不同权值数量。空间 $O(M\log n)$，初始化 $O(M\log n\log M)$，单点修改和计数 $O(\log n\log M)$，第 k 小 $O(\log\sigma\log n\log M)$。
