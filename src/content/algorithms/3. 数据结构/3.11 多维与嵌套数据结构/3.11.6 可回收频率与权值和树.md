### 可回收频率与权值和树
---
 **计数 `cnt` + 任意附加权重 `sum`** 的独立后端。和 `3.6.4` 的 `sum += x * delta` 变式不同，本结构允许同一权值对应任意附加权重；若只维护频率，可直接复用 `3.6.4`，不复制本结构。
```cpp
struct RecyclableValueTree {
    struct Node {
        int ch[2]{};
        int cnt{ 0 };
        i64 sum{ 0 };
    };
    int vl, vr;
    vector<Node> tr{{}};
    vector<int> bin;
    RecyclableValueTree(int vl_, int vr_) : vl(vl_), vr(vr_) { assert(vl < vr); }
    int new_node() {
        if (bin.empty()) {
            tr.push_back({});
            return int(tr.size()) - 1;
        }
        int p = bin.back();
        bin.pop_back();
        tr[p] = {};
        return p;
    }
    int add(int p, int l, int r, int x, int dc, i64 ds) {
        if (!p) {
            assert(dc > 0);
            p = new_node();
        }
        tr[p].cnt += dc;
        tr[p].sum += ds;
        assert(tr[p].cnt >= 0);
        if (l < r - 1) {
            int m = midpoint(l, r);
            if (x < m) tr[p].ch[0] = add(tr[p].ch[0], l, m, x, dc, ds);
            else tr[p].ch[1] = add(tr[p].ch[1], m, r, x, dc, ds);
        }
        if (tr[p].cnt == 0) {
            assert(!tr[p].ch[0] && !tr[p].ch[1]);
            assert(tr[p].sum == 0);
            tr[p] = {};
            bin.push_back(p);
            return 0;
        }
        return p;
    }
    pair<int, i64> query(int p, int l, int r, int ql, int qr) const {
        if (!p || qr <= l || r <= ql) return {0, 0};
        if (ql <= l && r <= qr) return {tr[p].cnt, tr[p].sum};
        int m = midpoint(l, r);
        auto a = query(tr[p].ch[0], l, m, ql, qr);
        auto b = query(tr[p].ch[1], m, r, ql, qr);
        return {a.first + b.first, a.second + b.second};
    }
    int add(int root, int x, int dc, i64 ds) {
        assert(vl <= x && x < vr);
        return add(root, vl, vr, x, dc, ds);
    }
    pair<int, i64> query(int root, int l, int r) const { return query(root, vl, vr, l, r); }
};
```
#### 接口说明
- `RecyclableValueTree(vl,vr)`：整数权值域 `[vl,vr)`。
- `add(root,x,dc,ds)`：在 `x` 处同时调整频率 `dc` 与附加权重和 `ds`，返回新根，$O(\log V)$。
- `query(root,l,r)`：返回值域 `[l,r)` 的 `{cnt,sum}`，$O(\log V)$。
- `tr`：共享节点池，`bin`：可复用节点编号；一个实例可通过多个根维护多个集合。
#### 注意事项
- 插入元素 `(x,w)` 使用 `add(root,x,+1,+w)`，删除使用 `add(root,x,-1,-w)`。
- 任意时刻每个权值的频率必须非负，删除对象必须真实存在；`cnt==0` 时对应整棵子树必须确实为空且 `sum==0`。
- 更新得到的新根必须写回。后续操作不得再使用已经被回收的旧根。
- 若只做单棵普通区间和，不必引入这份结构，直接复用 `3.6.1 DynamicSegTree<Info>` 即可。
#### 常见用法
```cpp
RecyclableValueTree seg(0, V);
int root = 0;
root = seg.add(root, x, 1, weight);
root = seg.add(root, x, -1, -weight);
auto [cnt, sum] = seg.query(root, lo, hi);
```
#### 复杂度
增删与查询 $O(\log V)$；活跃节点数取决于非空路径，节点池已分配内存保持历史峰值容量。
