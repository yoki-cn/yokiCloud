### 线段树套 FHQ Treap
---
当值域不是方便做权值线段树的整数域，或主要需求为动态区间严格前驱/后继时使用。
**依赖**：[[3.8.3 FHQ Treap 有序多重集]] 中的完整 `FHQTreap<T, Compare>`。
```cpp
template<class T, class Compare = less<T>>
struct SegTreeTreap {
    int n, base = 1;
    vector<T> a;
    vector<int> root;
    FHQTreap<T, Compare> tr;
    explicit SegTreeTreap(const vector<T> &a_) : n(a_.size()), a(a_) {
        while (base < n) base <<= 1;
        root.assign(2 * base, 0);
        for (int i = 0; i < n; ++ i) {
            for (int p = base + i; p; p >>= 1) tr.insert(root[p], a[i]);
        }
    }
    void modify(int pos, const T &value) {
        assert(0 <= pos && pos < n);
        if (!tr.comp(a[pos], value) && !tr.comp(value, a[pos])) {
            a[pos] = value;
            return;
        }
        for (int p = base + pos; p; p >>= 1) {
            bool ok = tr.erase(root[p], a[pos]);
            assert(ok);
            tr.insert(root[p], value);
        }
        a[pos] = value;
    }
    int count_less(int l, int r, const T &value) const {
        int ans = 0;
        for (l += base, r += base; l < r; l >>= 1, r >>= 1) {
            if (l & 1) ans += tr.order_of_key(root[l ++], value);
            if (r & 1) ans += tr.order_of_key(root[-- r], value);
        }
        return ans;
    }
    int count_range(int l, int r, const T &lo, const T &hi) const {
        return count_less(l, r, hi) - count_less(l, r, lo);
    }
    int rank(int l, int r, const T &x) const {
        return count_less(l, r, x) + 1;
    }
    optional<T> predecessor(int l, int r, const T &x) const {
        optional<T> ans;
        auto use = [&](int p) {
            auto v = tr.predecessor(p, x);
            if (v && (!ans || tr.comp(*ans, *v))) ans = v;
        };
        for (l += base, r += base; l < r; l >>= 1, r >>= 1) {
            if (l & 1) use(root[l ++]);
            if (r & 1) use(root[-- r]);
        }
        return ans;
    }
    optional<T> successor(int l, int r, const T &x) const {
        optional<T> ans;
        auto use = [&](int p) {
            auto v = tr.successor(p, x);
            if (v && (!ans || tr.comp(*v, *ans))) ans = v;
        };
        for (l += base, r += base; l < r; l >>= 1, r >>= 1) {
            if (l & 1) use(root[l ++]);
            if (r & 1) use(root[-- r]);
        }
        return ans;
    }
};
```
#### 接口说明
- `SegTreeTreap(a)`：构造，$O(n\log^2 n)$ 期望。
- `modify(pos,x)`：将 `a[pos]` 改为 `x`，内部自动维护原值，$O(\log^2 n)$ 期望。
- `count_less(l,r,x)`：区间内小于 `x` 的数量；`count_range(l,r,lo,hi)`：值域 `[lo,hi)` 的数量，均 $O(\log^2 n)$ 期望。
- `rank(l,r,x)`：严格小于 `x` 的数量加一，$O(\log^2 n)$ 期望。
- `predecessor(l,r,x)` / `successor(l,r,x)`：**严格**前驱/后继，返回 `optional<T>`，$O(\log^2 n)$ 期望。
- `tr`：复用 3.8.3 的节点池；`root[p]`：位置线段树节点 `p` 内的 Treap 根。
#### 注意事项
- **必须先复制 `3.8.3 FHQ Treap 有序多重集` 的 `FHQTreap` 定义**；本页不重复 Treap 代码。
- 所有区间为 `[l,r)`，修改下标为 `0base`；`T` 必须可用 `Compare` 比较且可复制。
- 本版本刻意不提供第 `k` 小：未知连续值域下用 Treap 做第 k 小需额外二分及值域假设；需要它请优先使用 `3.11.1` 或 `3.11.3`。
- Treap 高度为随机期望界；最坏单次不保证 $O(\log^2 n)$。大量不同键时内存约 $O(n\log n)$ 个 Treap 节点。
#### 常见用法
```cpp
SegTreeTreap<i64> seg(a);
seg.modify(pos, x);
int less = seg.count_less(l, r, x);
auto pre = seg.predecessor(l, r, x);
if (pre) cout << *pre << '\n';
```
#### 复杂度
初始化 $O(n\log^2 n)$ 期望；单点修改、计数、前驱和后继均为 $O(\log^2 n)$ 期望；空间 $O(n\log n)$ 个内部 Treap 节点。
