### 离线二维树状数组
---
**解决问题：** 第一维已离散、第二维坐标很大且修改点稀疏时，处理二维点修改、二维前缀和与矩形和
外层对第一维建立 BIT；每个 BIT 节点只离散实际可能被修改的第二维坐标
```cpp
template<class T>
struct OfflineBIT2D {
    int n;
    vector<vector<i64>> ys;
    vector<vector<T>> t;
    explicit OfflineBIT2D(int n_ = 0) : n(n_), ys(n + 1), t(n + 1) {}
    OfflineBIT2D(int n_, const vector<pair<int, i64>> &points) : OfflineBIT2D(n_) {
        for (auto [x, y] : points) reserve_point(x, y);
        build();
    }
    // ===== 离线预处理：所有可能修改的点登记完成后调用 build() =====
    void reserve_point(int x, i64 y) {
        for (++ x; x <= n; x += x & -x) ys[x].push_back(y);
    }
    void build() {
        for (int x = 1; x <= n; ++ x) {
            auto &v{ ys[x] };
            ranges::sort(v.begin(), v.end());
            v.erase(ranges::unique(v).begin(), v.end());
            t[x].assign(v.size() + 1, T{});
        }
    }
    // ===== 修改与查询：build() 后使用 =====
    void add(int x, i64 y, const T &v) {
        for (++ x; x <= n; x += x & -x) {
            int p{ int(ranges::lower_bound(ys[x], y) - ys[x].begin()) + 1 };
            for (; p < int(t[x].size()); p += p & -p) t[x][p] += v;
        }
    }
    T prefix(int x, i64 y) const {
        T res{};
        for (; x > 0; x -= x & -x) {
            int p{ int(ranges::lower_bound(ys[x], y) - ys[x].begin()) };
            for (; p > 0; p -= p & -p) res += t[x][p];
        }
        return res;
    }
    T query(int x1, i64 y1, int x2, i64 y2) const {
        return prefix(x2, y2) - prefix(x1, y2) - prefix(x2, y1) + prefix(x1, y1);
    }
};
```
#### 接口说明
##### 成员变量
- `n`：第一维离散后的长度
- `ys[x]`：外层 BIT 节点 `x` 实际需要维护的第二维坐标
- `t[x]`：节点 `x` 内部的一维 BIT
##### 接口
- `OfflineBIT2D(n)`：建立第一维长度为 `n` 的空结构
- `OfflineBIT2D(n, points)`：登记 `points` 中所有可能修改的点并自动执行 `build()`
- `reserve_point(x, y)`：预登记之后可能调用 `add()` 的坐标，不产生实际修改，$O(\log n)$
- `build()`：对每个外层 BIT 节点分别离散第二维
- `add(x, y, v)`：令点 `(x, y)` 的值增加 `v`
- `prefix(x, y)`：查询 $[0,x)\times(-\infty,y)$ 中的值之和
- `query(x1, y1, x2, y2)`：查询 $[x_1,x_2)\times[y_1,y_2)$ 中的值之和
#### 注意事项
- 第一维必须已经转换为 `0base` 的 `[0, n)` 下标
- 若原始第一维坐标也很大，应先在外部离散化；本结构只自动离散第二维
- 第二维使用 `i64`，可以直接处理很大的正负坐标
- 所有以后可能调用
```cpp
add(x, y, ...)
```
的 `(x, y)` 都必须在 `build()` 前登记
- 查询所使用的 `y` 不需要登记，因为查询通过 `lower_bound()` 找到严格小于 `y` 的已登记坐标
- 同一点可以重复登记，`build()` 会自动去重
- `build()` 后不要继续 `reserve_point()`；新增坐标不会被加入已经建立的内部 BIT
- `add()` 默认传入的点已经登记，不检查坐标是否真实存在
- 所有区间均为半开区间
- `T` 需要支持零初始化、`+=` 和减法
- 若所有二维坐标范围本来就很小，直接使用稠密 `BIT2D` 更简单且常数更低
#### 常见用法
##### 已知全部可能修改点
```cpp
vector<pair<int, i64>> points;

for (auto [x, y] : possible_updates) {
    points.push_back({x, y});
}

OfflineBIT2D<i64> bit(n, points);

bit.add(x, y, delta);
i64 ans = bit.query(x1, y1, x2, y2);
```
##### 扫描操作后统一建树
```cpp
OfflineBIT2D<int> bit(n);

for (auto [x, y] : possible_updates) {
    bit.reserve_point(x, y);
}

bit.build();

for (auto &op : operations) {
    // add / query
}
```
##### 二维偏序计数
按某一维排序后，将另一维作为 BIT 的第一维或第二维：
```cpp
bit.add(x, y, 1);
int cnt = bit.prefix(x, y);
```
具体是否包含当前点，应根据排序和同值处理方式调整。
#### 复杂度
设共登记 $M$ 个点
一次 `reserve_point()` 会进入 $O(\log n)$ 个外层 BIT 节点，因此所有内部离散坐标总数为
$$O(M\log n)$$

|操作|时间复杂度|
|---|--:|
|`reserve_point`|$O(\log n)$|
|全部 `build`|$O(M\log n\log M)$|
|`add`|$O(\log n\log M)$|
|`prefix`|$O(\log n\log M)$|
|`query`|$O(\log n\log M)$|
空间复杂度：
$$O(M\log n)$$
两维规模同阶时，单次修改和查询通常简写为 $O(\log^2 n)$
