### 浮点半平面交
**解决问题：** 求若干有向直线左侧闭半平面的公共区域，用于线性不等式可行域、多边形核、二分答案中的几何可行性判定等问题

![有向边左半平面的公共交区域|385](/algorithm-assets/half-plane-intersection.png)

有向直线由直上一点 $p$ 和非零方向 $d$ 表示，其左侧闭半平面为
$$
H(p,d)=\{x\mid d\times(x-p)\ge0\}.
$$
算法先按方向极角排序并删除同方向的较宽松约束，再维护一个双端队列。若相邻两条有效边界的交点落在新半平面外，就从相应一端删除旧边界
```cpp
struct HalfPlane {
    Point p, dir;
    HalfPlane() = default;
    // 有向直线 a -> b 的左侧为可行区域；要求 a、b 不重合
    HalfPlane(Point a, Point b) : p(a), dir(b - a) {}
    // q 严格位于右侧时返回 true；边界属于可行区域
    bool out(Point q) const { return sgn(cross(dir, q - p)) < 0; }
    Line ln() const { return Line(p, dir); }
};
optional<Point> hp_cross(const HalfPlane &a, const HalfPlane &b) {
    return line_int(a.ln(), b.ln());
}
// 原始值比较用于 sort，不能把 EPS 写进比较器
bool hp_less(const HalfPlane &a, const HalfPlane &b) {
    int ha{ arg_half(a.dir) }, hb{ arg_half(b.dir) };
    if (ha != hb) return ha < hb;
    ld turn{ cross(a.dir, b.dir) };
    if (turn != 0) return turn > 0;
    // 同方向时让更严格的半平面排在前面
    return cross(a.dir, b.p - a.p) < 0;
}
bool same_hp_dir(const HalfPlane &a, const HalfPlane &b) {
    return sgn(cross(a.dir, b.dir)) == 0 && sgn(dot(a.dir, b.dir)) > 0;
}
// 只返回有界且面积非零的交多边形；空、无界、线段或单点均返回空数组
vector<Point> hp_int(vector<HalfPlane> hps) {
    ranges::sort(hps, hp_less);
    vector<HalfPlane> uniq;
    for (const HalfPlane &hp : hps) {
        if (!uniq.empty() && same_hp_dir(uniq.back(), hp)) {
            if (hp.out(uniq.back().p)) uniq.back() = hp;
        } else uniq.push_back(hp);
    }
    deque<HalfPlane> act;
    deque<Point> isecs; // act 中相邻半平面的交点
    for (const HalfPlane &hp : uniq) {
        while (!isecs.empty() && hp.out(isecs.back())) {
            isecs.pop_back();
            act.pop_back();
        }
        while (!isecs.empty() && hp.out(isecs.front())) {
            isecs.pop_front();
            act.pop_front();
        }
        if (!act.empty()) {
            auto p = hp_cross(act.back(), hp);
            // 在“最终交集有界”的前提下，有效相邻边界不应平行。
            if (!p) return {};
            isecs.push_back(*p);
        }
        act.push_back(hp);
    }
    while (!isecs.empty() && act.front().out(isecs.back())) {
        isecs.pop_back();
        act.pop_back();
    }
    while (!isecs.empty() && act.back().out(isecs.front())) {
        isecs.pop_front();
        act.pop_front();
    }
    if (act.size() < 3) return {};
    auto cls = hp_cross(act.back(), act.front());
    if (!cls) return {};
    isecs.push_back(*cls);
    vector<Point> res(isecs.begin(), isecs.end());
    res = norm_conv(move(res));
    if (res.size() < 3 || sgn(poly_area2(res)) == 0) return {};
    return res;
}
// 返回逆时针正方形的四个左半平面，即 [-bound,bound]^2
vector<HalfPlane> box(ld bound) {
    Point a{-bound, -bound}, b{ bound, -bound};
    Point c{ bound,  bound}, d{-bound,  bound};
    return {{a, b}, {b, c}, {c, d}, {d, a}};
}
```
### 线性不等式转换
**解决问题：** 将二维线性约束转成“有向直线左侧”形式
对非退化约束
$$
ax+by\le c
$$
先在边界 $ax+by=c$ 上取一点 $p$，方向应取
$$
d=(-b,a)
$$
因为
$$
d\times(x-p)=c-(ax+by),
$$
所以左侧条件 $d\times(x-p)\ge0$ 恰好等价于 $ax+by\le c$。相反，$ax+by\ge c$ 应使用方向 $(b,-a)$
```cpp
// [浮点版] a、b 不同时为 0
ld a, b, c;
Point p = fabsl(a) > fabsl(b) ? Point(c / a, 0) : Point(0, c / b);
HalfPlane con(p, p + Point(-b, a)); // a*x + b*y <= c
```
当 `a == 0 && b == 0` 时，应在外部单独判断：`0 <= c` 是恒真约束，`0 > c` 表示整体无解，不能构造零方向半平面
### 整数约束与精确性
整数版基础板子的 `pt_side(q, ln)` 已经使用 `i128` 完成精确叉积，因此“某个整数点是否满足半平面”可直接判断：
```cpp
bool ok = pt_side(q, bnd) >= 0; // 有向边界左侧或线上
```
不再额外定义与 `Line` 高度重复的 `IHalfPlane`。但完整半平面交需要构造边界交点，整数直线的交点通常为有理数；若题目要求精确输出或严格比较，应使用统一符号的 `i128` 分子、分母表示有理点，不能做整数除法。
### 多边形核
**解决问题：** 求简单多边形中能够看见整个多边形的所有点
若简单多边形 $P=(p_0,p_1,\dots,p_{n-1})$ 按逆时针排列，并令 $p_n=p_0$，则其核为所有边左侧闭半平面的交：
$$
\operatorname{Kernel}(P)
=\bigcap_{i=0}^{n-1}
\left\{x\mid(p_{i+1}-p_i)\times(x-p_i)\ge0\right\}
$$
多边形方向可直接使用上一篇的 `poly_area2()` 判断，不重复实现面积函数
```cpp
if (sgn(poly_area2(poly)) < 0) ranges::reverse(poly);
vector<HalfPlane> hps;
for (int i = 0, n = poly.size(); i < n; ++ i) {
    hps.emplace_back(poly[i], poly[(i + 1) % n]);
}
vector<Point> ker = hp_int(move(hps));
// ker.empty() 表示没有面积非零的核；本实现不区分空核与退化为线段/单点的核。
```
核本身一定包含在有界多边形内，通常不需要额外加入大框
### 平面区域计数
半平面交计算的是凸可行域；一般线段或曲线把平面切成多少区域属于平面图问题，不应把两种算法混成同一份代码
把所有交点加入顶点集合，并将每条原始边在交点处切成不含内部顶点的边后，设平面图有
- $V$ 个不同顶点
- $E$ 条切分后的边
- $C$ 个连通分量
- $F$ 个面，包含无界外部面
则 Euler 公式为
$$
F=E-V+C+1
$$
连通时 $C=1$，即 $F=E-V+2$；有界区域数为
$$
F-1=E-V+C
$$
共线重叠边、多个对象共享同一交点、孤立点都会影响 $V,E,C$，必须先完成平面化后再套公式。
双极定向属于给定平面嵌入上的图论结构，不由半平面交产生，在独立的平面图板子。
### 接口说明
#### 成员变量
- `HalfPlane::p`：边界直线上的一点
- `HalfPlane::dir`：非零方向向量；从 `p` 沿 `dir` 前进时，左侧为可行区域
#### 接口
- `HalfPlane(a,b)`：用有向直线 `a -> b` 构造左半平面，$O(1)$；要求 `a`、`b` 不重合。
- `out(q)`：判断点是否严格位于半平面外，$O(1)$；边界返回 `false`。
- `hp_cross(a,b)`：求两条边界直线的唯一交点；平行或重合返回 `nullopt`，$O(1)$。
- `hp_int(hps)`：返回有界、面积非零的公共交多边形，按逆时针排列且不重复首点，$O(n\log n)$。
- `box(bound)`：构造正方形 $[-bound,bound]^2$ 的四个左半平面，$O(1)$。
#### 返回值语义
`hp_int()` 返回空数组可能表示：
- 约束无解
- 公共交无界
- 公共交只剩一条线段或一个点
- 数值误差使有效边界被误判为平行或交点落在错误一侧
该接口适合“求有界非退化多边形”或“加入大框后的面积非零可行性”问题；若题目允许退化闭集，需要额外设计可行性判定
### 注意事项
- 最容易写反的是可行方向：构造 `HalfPlane(a,b)` 后保留的是有向边 `a -> b` 左侧。先用一个已知可行点调用 `out()` 自检
- 对 $ax+by\le c$，方向是 $(-b,a)$，不是 $(b,-a)$；后者对应 $ax+by\ge c$
- `hp_less()` 必须形成严格弱序，因此极角排序使用原始叉积，不能使用 `sgn()` 或 `EPS`；几何平行、出界判定再使用 `sgn()`
- 同方向平行约束只保留更严格的一条。反向平行约束可能形成条带；本实现只承诺处理最终交集有界的情况，无界问题应先加入足够大的 `box()`
- 大框只是在题目已知坐标范围内把无界区域截成有限区域。`bound` 必须严格覆盖所有可能答案，同时不能大到使叉积和直线求交严重损失精度
- 二分答案时可以每次重建约束并判断返回值是否非空，但这只判定“存在面积非零的框内区域”。答案允许恰好退化为线或点时不能直接使用
- 坐标或系数尺度很大时，应按误差传播调整 `EPS`，并避免同时混用 `double` 和 `long double`
- 多边形核要求简单多边形按边界顺序给出；顺时针输入必须先反转
### 常见用法
#### 求无界约束在指定范围内的可行区域
```cpp
vector<HalfPlane> hps = box(1E9L);
for (auto [a, b] : dir_bnds) {
    hps.emplace_back(a, b);
}
vector<Point> reg = hp_int(move(hps));
```
#### 二分答案并判定面积非零可行域
```cpp
bool check(ld ans) {
    vector<HalfPlane> hps = box(BOUND);
    // 按 ans 构造约束，全部转成“左侧可行”
    return !hp_int(move(hps)).empty();
}
```
#### 求线性不等式组的面积
```cpp
vector<HalfPlane> hps = box(BOUND);
for (auto [a, b, c] : cons) {
    Point p = fabsl(a) > fabsl(b) ? Point(c / a, 0) : Point(0, c / b);
    hps.emplace_back(p, p + Point(-b, a)); // a*x+b*y<=c
}
vector<Point> reg = hp_int(move(hps));
ld area = fabsl(poly_area2(reg)) / 2;
```
#### 求多边形核
```cpp
if (sgn(poly_area2(poly)) < 0) ranges::reverse(poly);
vector<HalfPlane> hps;
for (int i = 0, n = poly.size(); i < n; ++ i) {
    hps.emplace_back(poly[i], poly[(i + 1) % n]);
}
vector<Point> ker = hp_int(move(hps));
```
#### 用已有多边形裁剪接口代替小规模半平面交
若约束数很少，且已经有一个初始凸多边形，可以直接反复调用上一页的 `cut_poly()`：
```cpp
// [浮点版专属]
vector<Point> reg = init_poly;
for (Line bnd : bnds) {
    reg = cut_poly(reg, bnd); // 保留有向边界左侧
}
```
这种写法接口更短、容易检查，但若初始顶点数和约束数均为 $n$，最坏复杂度可达 $O(n^2)$；一般半平面交为 $O(n\log n)$
### 复杂度
设输入半平面数量为 $n$

| 操作                            |        时间复杂度 |   额外空间 |
| ----------------------------- | -----------: | -----: |
| 排序与同向去重                       | $O(n\log n)$ | $O(n)$ |
| 双端队列扫描                        |       $O(n)$ | $O(n)$ |
| `hp_int()` 总计 | $O(n\log n)$ | $O(n)$ |
| `box()`              |       $O(1)$ | $O(1)$ |
平面图区域计数在完成平面化并已知 $V,E,C$ 后仅为 $O(1)$；求全部交点、切分边和连通分量的复杂度取决于具体平面图构造方法
