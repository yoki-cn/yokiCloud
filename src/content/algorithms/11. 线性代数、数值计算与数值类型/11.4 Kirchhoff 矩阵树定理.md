### Kirchhoff 矩阵树定理
---
**依赖 11.5 的 `determinant_mod_prime(a, mod)`**，它返回模质数行列式。这样全章只维护一套行列式实现；如果要求合数模，替换为该节的 `determinant_mod_any(a, mod)`。
```cpp
struct MatrixTree {
    int n, mod;
    vector<vector<int>> lap;
    MatrixTree(int n_, int mod_) : n(n_), mod(mod_), lap(n_, vector<int>(n_)) {
        assert(n >= 0 && mod >= 2); // mod 必须为质数
    }
private:
    void add(int i, int j, i64 w) {
        lap[i][j] = (lap[i][j] + w % mod + (i64)mod) % mod;
    }
public:
    // ===== 三种边模型：按计数目标选择其中一种调用，不混用 =====
    void add_undirected(int u, int v, i64 w = 1) {
        if (u == v) return;
        add(u, u, w);
        add(v, v, w);
        add(u, v, -(w % mod));
        add(v, u, -(w % mod));
    }
    // 有向入树：每个非根点沿边走到 root（out-degree Laplacian）
    void add_toward_root(int u, int v, i64 w = 1) {
        if (u == v) return;
        add(u, u, w);
        add(u, v, -(w % mod));
    }
    // 有向出树：从 root 沿边可达所有点（in-degree Laplacian）
    void add_away_from_root(int u, int v, i64 w = 1) {
        if (u == v) return;
        add(v, v, w);
        add(v, u, -(w % mod));
    }
    // ===== 余子式行列式：计数接口 =====
    int count(int root = 0) const {
        if (n == 0) return 0;
        assert(0 <= root && root < n);
        vector a(n - 1, vector<int>(n - 1));
        for (int i = 0, x = 0; i < n; ++ i) if (i != root) {
            for (int j = 0, y = 0; j < n; ++ j) if (j != root) {
                a[x][y ++] = lap[i][j];
            }
            ++ x;
        }
        return determinant_mod_prime(move(a), mod);
    }
};
```
#### 接口说明
- `MatrixTree(n, mod)`：创建 $n$ 个点（`0base`）的拉普拉斯矩阵，`mod` 为质数，$O(n^2)$ 空间。
- `add_undirected(u,v,w=1)`：无向边，两端度数加权，非对角元减权，$O(1)$。
- `add_toward_root(u,v,w=1)`：插入有向边 `u -> v`，用于计数**朝根有向生成树**，$O(1)$。
- `add_away_from_root(u,v,w=1)`：插入有向边 `u -> v`，用于计数**从根出发的有向生成树**，$O(1)$。
- `count(root=0)`：删去根的行与列，计算主余子式，$O(n^3+n\log mod)$；无向图中任意根结果相同。
三类 `add` 都可以添加权重 $w$，结果为所有合法树的**边权乘积之和**。无权图使用默认权重 `1`。
#### 注意事项
- **`mod` 必须是质数**，除非自行将依赖改为 11.5 的任意模数行列式实现。不能对合数模数直接用费马小定理求逆。
- 无向重边可重复添加，权重可为负数；自环对生成树没有贡献，直接忽略。
- 有向生成树的方向非常容易写反：`toward_root` 是所有非根节点**最终指向根**，`away_from_root` 是从根**能到达所有节点**。一棵合法树恰有 `n-1` 条边。
- 未连通无向图和无法形成对应方向树的有向图返回 `0`。但模数下返回 `0` 也可能仅表示真实计数是模数的倍数。
- `n=0` 约定返回 `0`；`n=1` 返回 `1`，因为空边集是一棵单点树（自环被忽略）。
- 按题目使用一种有向/无向建图方式；不要把同一条有向边同时用 `add_toward_root` 与 `add_away_from_root` 建入一个计数器。
- 这里使用稠密矩阵，$n$ 很大、图很稀疏时 $O(n^3)$ 通常不可承受。计数精确整数值可用多模 CRT 或大整数行列式，需证明模数乘积覆盖答案上界。
#### 数学速查
- 无向图：$L=D-A$，$\tau(G)=\det L^{(r)}$，即删去任一行、同编号一列后的主子式。
- 带权图：$\tau_w(G)=\sum_{T\text{ spanning tree}}\prod_{e\in T}w_e$。
- 完全图：$\tau(K_n)=n^{n-2}$（$n\ge2$）；无向环：$\tau(C_n)=n$（$n\ge3$）。
- 有向图：以出度减邻接矩阵得到**朝根入树**计数；以内度构成的列拉普拉斯矩阵得到**离根出树**计数。均删除指定根的行和列。
#### 常见用法
##### 无向三角形：3 棵生成树
```cpp
MatrixTree mt(3, 998244353);
mt.add_undirected(0, 1);
mt.add_undirected(1, 2);
mt.add_undirected(0, 2);
int ans = mt.count(); // 3
```
##### 边权 / 重边
```cpp
MatrixTree mt(2, 998244353);
mt.add_undirected(0, 1, 3);
mt.add_undirected(0, 1, 5);
int ans = mt.count(); // 8：可选其中任意一条边
```
##### 有向生成树
```cpp
MatrixTree in(3, 998244353);
in.add_toward_root(0, 1);
in.add_toward_root(1, 2);
int a = in.count(2); // 1：0 -> 1 -> 2

MatrixTree out(3, 998244353);
out.add_away_from_root(0, 1);
out.add_away_from_root(1, 2);
int b = out.count(0); // 1：0 -> 1 -> 2
```
#### 复杂度

| 操作 | 时间 | 额外空间 |
| --- | --- | --- |
| 构造 | $O(n^2)$ | $O(n^2)$ |
| 插入一条边 | $O(1)$ | $O(1)$ |
| 一次 `count(root)` | $O(n^3+n\log mod)$ | $O(n^2)$ |
