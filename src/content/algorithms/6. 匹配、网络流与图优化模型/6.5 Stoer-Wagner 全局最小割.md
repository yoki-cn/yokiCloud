### Stoer--Wagner 全局最小割
---
```cpp
template<class T = i64>
T stoer_wagner(vector<vector<T>> g) {
    int n{ int(g.size()) };
    if (n <= 1) return 0;
    T ans{ numeric_limits<T>::max() };
    vector<int> v(n);
    iota(v.begin(), v.end(), 0);
    while (v.size() > 1) {
        vector<T> w(n);
        vector<char> used(n);
        int prev{ -1 }, last{ -1 };
        // Maximum Adjacency Search：最后加入的点给出本阶段最小割
        for (int it = 0; it < int(v.size()); ++ it) {
            int sel{ -1 };
            for (int x : v) if (!used[x] && (sel == -1 || w[x] > w[sel])) sel = x;
            used[sel] = true;
            prev = last;
            last = sel;
            if (it + 1 == int(v.size())) {
                ans = min(ans, w[last]);
                if (ans == 0) return 0;
                // 将阶段最后点 last 缩并到倒数第二点 prev
                for (int x : v) if (x != prev && x != last) {
                    g[prev][x] += g[last][x];
                    g[x][prev] = g[prev][x];
                }
                v.erase(find(v.begin(), v.end(), last));
            } else {
                for (int x : v) if (!used[x]) w[x] += g[sel][x];
            }
        }
    }
    return ans;
}
```
#### 原理
每一轮在当前缩点图上进行 Maximum Adjacency Search
从任意点开始，每次选择与当前已选集合连接总权最大的未选点，并维护
```cpp
w[x] = x 到已选点集合的边权和
```
若最后加入的两个点依次为 `prev`、`last`，则这一阶段得到的 `prev-last` 最小割值就是 `w[last]`
记录该值后将 `last` 缩并进 `prev`，继续在更小的图上执行，所有阶段割值中的最小值即为全局最小割
#### 接口说明
##### 接口
- `stoer_wagner(g)`：返回无向非负容量图的全局最小割值，$O(n^3)$
- `g` 按值传递，缩点只修改内部副本，不影响调用者
#### 注意事项
- `g` 必须是 $n\times n$ 对称矩阵，满足 `g[u][v] == g[v][u]`
- 点编号为 `0base`
- 容量必须非负
- `g[u][u]` 应为 `0`
- 平行边需要预先累加到 `g[u][v]`
- 图不连通时答案为 `0`，代码会在首次得到零割后直接返回
- `n <= 1` 时返回 `0`
- 缩点时边权会不断累加，`T` 必须能容纳缩点后的容量和，范围较大时使用 `i128`
- 该算法只适用于**无向图**
- 有向全局最小割不是 Stoer--Wagner 的适用范围
- 本板只返回最小割值，不恢复割集
- 若需要所有点对最小割信息，使用 **6.5.1 Gomory--Hu 最小割树**
- 若只需要指定 `s-t` 最小割，直接使用 Dinic，根据最大流最小割定理求解更合适
#### 常见用法
```cpp
vector<vector<i64>> g(n, vector<i64>(n));
for (auto [u, v, cap] : edges) {
    g[u][v] += cap;
    g[v][u] += cap;
}
i64 cut{ stoer_wagner(g) };
```
##### 判断图是否存在零容量割
```cpp
if (stoer_wagner(g) == 0) {
    // 存在两个非空点集，使跨越它们的总容量为 0
}
```
对于普通正权图，这等价于图不连通
#### 复杂度
时间复杂度：$O(n^3)$
空间复杂度：$O(n^2)$
