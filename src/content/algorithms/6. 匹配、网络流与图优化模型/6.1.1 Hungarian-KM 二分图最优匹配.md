### Hungarian-KM 二分图最优匹配
---
```cpp
template<bool MAX = false, class T = i64>
pair<T, vector<int>> hungarian(const vector<vector<T>> &a) {
    int n = a.size();
    if (!n) return {T{}, {}};
    int m = a[0].size();
    assert(n <= m);
    for (const auto &row : a) assert(int(row.size()) == m);
    const T INF = numeric_limits<T>::max() / 4;
    vector<T> u(n + 1), v(m + 1), minv(m + 1);
    vector<int> p(m + 1), way(m + 1);
    vector<char> used(m + 1);
    // 逐个加入左部点，维护势能与到未使用右部点的最短增广路
    for (int i = 1; i <= n; ++ i) {
        p[0] = i;
        int j0{ 0 };
        ranges::fill(minv, INF);
        ranges::fill(used, false);
        do {
            used[j0] = true;
            int i0{ p[j0] }, j1{ 0 };
            T delta{ INF };
            for (int j = 1; j <= m; ++ j) if (!used[j]) {
                T cur;
                if constexpr (MAX) cur = u[i0] + v[j] - a[i0 - 1][j - 1];
                else cur = a[i0 - 1][j - 1] - u[i0] - v[j];
                if (cur < minv[j]) minv[j] = cur, way[j] = j0;
                if (minv[j] < delta) delta = minv[j], j1 = j;
            }
            for (int j = 0; j <= m; ++ j) {
                if (used[j]) {
                    if constexpr (MAX) u[p[j]] -= delta, v[j] += delta;
                    else u[p[j]] += delta, v[j] -= delta;
                } else {
                    minv[j] -= delta;
                }
            }
            j0 = j1;
        } while (p[j0] != 0);
        // 沿 way[] 翻转增广路
        do {
            int j1{ way[j0] };
            p[j0] = p[j1];
            j0 = j1;
        } while (j0 != 0);
    }
    vector<int> match(n, -1);
    for (int j = 1; j <= m; ++ j) if (p[j]) match[p[j] - 1] = j - 1;
    T value{};
    for (int i = 0; i < n; ++ i) value += a[i][match[i]];
    return {value, match};
}
template<class T = i64>
pair<T, vector<int>> hungarian_min(const vector<vector<T>> &a) { return hungarian<false>(a); }
template<class T = i64>
pair<T, vector<int>> hungarian_max(const vector<vector<T>> &a) { return hungarian<true>(a); }
```
#### 接口
- `hungarian_min(a)`：求最小权指派，返回 `{最小总权值, match}`，时间复杂度 $O(n^2m)$
- `hungarian_max(a)`：求最大权指派，返回 `{最大总权值, match}`，时间复杂度 $O(n^2m)$
- `hungarian<MAX>(a)`：统一核心；`MAX = false` 为最小化，`MAX = true` 为最大化
- `match[i]`：左部点 `i` 匹配到的右部点编号，范围为 $[0,m)$
- 输入为 $n\times m$ 权值矩阵，要求 $n\le m$
- 算法要求**每个左部点恰好匹配一个不同的右部点**；右部点可以不全部使用
#### `assert` 条件
- `n <= m`：右部点数量必须不少于左部点，否则无法让所有左部点匹配不同的右部点
- `row.size() == m`：所有行长度必须相同，输入必须是合法矩阵
#### 注意事项
- $n=m$ 时求二分图带权完美匹配；$n<m$ 时所有左部点均匹配，右部有 $m-n$ 个点未匹配
- 若原问题两侧大小不同且只要求较小一侧全部匹配，应将**较小的一侧作为矩阵的行**
- `hungarian_max()` 直接维护最大化对应的势能，等价于对权值取负后运行最小化版本，但不需要复制或修改输入矩阵
- 权值可以为负数；算法并不要求边权非负
- 默认矩阵中的**每个位置都是合法边**；它首先解决的是完全二分图上的指派问题
- 若存在少量禁边，可以赋一个足够差的权值，并在求解后检查最终匹配是否经过禁边
- 表示禁边时不要使用接近 `numeric_limits<T>::max()` 或 `lowest()` 的值，否则 `u + v - a`、`a - u - v` 等运算可能溢出
- 若合法边很稀疏或需要自然处理不存在的边，通常更适合使用**最小费用流**
- 若允许某些左部点不匹配真实右部点，应加入足够多的**虚拟右部点**
- 松弛量的有效上界须严格小于内部哨兵 `numeric_limits<T>::max() / 4`；大权值应选更宽类型，不能只检查最终答案
- `T` 需要容纳原始权值、势能、松弛量以及最终权值和；范围较大时使用 `i128`
- 不建议使用无符号整数类型，尤其最大化版本的势能和松弛过程中可能出现负值
- Hungarian / KM 解决的是**带权一对一二分图指派**；无权最大匹配优先使用 Hopcroft--Karp
- 若一个点允许匹配多个对象、边有容量，或还存在流量约束，应使用网络流 / 费用流
- 一般图带权匹配不属于二分图指派，需要使用带权 Blossom
#### 常见用法
##### 最小权指派
```cpp
auto [cost, match] = hungarian_min(a);
for (int i = 0; i < n; ++ i) {
    int j{ match[i] };
    // 左部 i 分配给右部 j
}
```
##### 最大权指派
```cpp
auto [weight, match] = hungarian_max(a);
```
##### 矩形指派
有 $n$ 个人、$m$ 个任务，且 $n\le m$，要求每个人领取一个不同任务：
```cpp
vector<vector<i64>> cost(n, vector<i64>(m));
for (int i = 0; i < n; ++ i) {
    for (int j = 0; j < m; ++ j) {
        cost[i][j] = calc_cost(i, j);
    }
}
auto [ans, match] = hungarian_min(cost);
```
不需要补成方阵，最终自然有 $m-n$ 个任务未被选择
##### 恢复右部对应的左部点
`match` 保存左到右映射；若还需要右到左：
```cpp
vector<int> rev(m, -1);
for (int i = 0; i < n; ++ i) {
    rev[match[i]] = i;
}
```
其中 `rev[j] == -1` 表示右部点 `j` 未匹配
##### 允许左部点不匹配真实对象
给每个左部点准备足够多的虚拟右部点
例如最大化收益，允许放弃某个人：
```cpp
vector<vector<i64>> a(n, vector<i64>(m + n));
for (int i = 0; i < n; ++ i) {
    for (int j = 0; j < m; ++ j) {
        a[i][j] = profit[i][j];
    }
    // 后 n 列为虚拟任务，收益为 0
}
auto [ans, match] = hungarian_max(a);
for (int i = 0; i < n; ++ i) {
    if (match[i] < m) {
        // i 选择真实任务 match[i]
    } else {
        // i 放弃匹配真实任务
    }
}
```
之所以通常准备 $n$ 个虚拟右部点，是因为右部点仍然**每个至多只能使用一次**；只添加一个公共虚点不能让多个左部点同时选择“不匹配”
最小化问题同理，可把虚拟边设为“不分配”的固定代价
##### 存在少量禁边
例如最小化问题：
```cpp
constexpr i64 BAD = 1E15;
vector<vector<i64>> cost(n, vector<i64>(m, BAD));
for (auto [u, v, w] : edges) cost[u][v] = w;
auto [ans, match] = hungarian_min(cost);
bool ok{ true };
for (int i = 0; i < n; ++ i) {
    if (cost[i][match[i]] == BAD) ok = false;
}
```
需要保证 `BAD` 足够差，同时所有中间运算和答案仍不会溢出
##### 最大化两组对象的总相似度
```cpp
vector<vector<i64>> score(n, vector<i64>(m));
for (int i = 0; i < n; ++ i) {
    for (int j = 0; j < m; ++ j) {
        score[i][j] = calc_score(i, j);
    }
}

auto [ans, match] = hungarian_max(score);
```
#### 复杂度
设左部大小为 $n$，右部大小为 $m$，且 $n\le m$

|操作|时间复杂度|
|---|---|
|`hungarian_min()`|$O(n^2m)$|
|`hungarian_max()`|$O(n^2m)$|
|方阵 $n=m$|$O(n^3)$|
算法额外空间复杂度为 $O(n+m)$；输入矩阵本身占用 $O(nm)$ 空间
