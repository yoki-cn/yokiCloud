### 公平组合游戏
---
默认讨论双方轮流行动、信息完全、无随机且双方策略最优的公平组合游戏。除特别说明外均采用 normal play：**无法行动者输**
#### Nim
---
```cpp
u64 nim_sum(const vector<u64> &a) {
    u64 s{};
    for (u64 x : a) s ^= x;
    return s;
}

optional<pair<int, u64>> nim_move(const vector<u64> &a) {
    u64 s = nim_sum(a);
    if (!s) return nullopt;
    for (int i = 0; i < (int)a.size(); ++ i) {
        u64 x = a[i] ^ s;
        if (x < a[i]) return pair{i, x};
    }
    return nullopt;
}
```
##### 接口说明
- `nim_sum(a)`：返回所有堆大小的异或和
- `nim_move(a)`：返回一种必胜操作 `{堆编号, 操作后的大小}`
- `nim_move(a)==nullopt`：当前为必败态
##### 注意事项
- 普通 Nim 每次只能选择**一堆**并减少任意正数颗石子
- 先手必胜当且仅当
  $$
  a_1\oplus a_2\oplus\cdots\oplus a_n\ne0
  $$
- 必胜操作一定可以把总异或和变成 `0`
- 若一次能同时操作多堆，不能直接套普通 Nim
- 若最后一步者输，应使用 Anti-Nim
##### 常见用法
只判断胜负：
```cpp
bool win = nim_sum(a) != 0;
```
构造一步必胜操作：
```cpp
if (auto mv = nim_move(a)) {
    auto [i, x] = *mv;
    a[i] = x;
}
```
##### 复杂度
- `nim_sum()`：$O(n)$
- `nim_move()`：$O(n)$
- 空间：$O(1)$
#### SG 与 Mex
---
适用于**一定会终止**的 impartial game。一个状态的 SG 值为所有后继 SG 值的 `mex`，多个独立子游戏的 SG 值取异或
```cpp
struct Mex {
    vector<int> vis;
    int tim{ 1 };
    explicit Mex(int n) : vis(n + 1) {}
    void clear() {
        if (++ tim == numeric_limits<int>::max()) {
            fill(vis.begin(), vis.end(), 0);
            tim = 1;
        }
    }
    void add(int x) {
        if (0 <= x && x < (int)vis.size()) vis[x] = tim;
    }
    int get() const {
        int x{};
        while (x < (int)vis.size() && vis[x] == tim) ++ x;
        return x;
    }
};

vector<int> sg_dag(const vector<vector<int>> &g, const vector<int> &ord) {
    int d{};
    for (auto &e : g) d = max(d, (int)e.size());
    Mex mex(d + 1);
    vector<int> sg(g.size());
    for (int u : ord) {
        mex.clear();
        for (int v : g[u]) mex.add(sg[v]);
        sg[u] = mex.get();
    }
    return sg;
}
```
`ord` 中必须保证每个状态的所有后继均出现在它之前。
##### 接口说明
- `Mex(n)`：支持求值域 `0..n` 的 mex
- `clear()`：开始计算新的集合
- `add(x)`：将 `x` 标记为已出现
- `get()`：返回当前集合的最小未出现非负整数
- `sg_dag(g,ord)`：求 DAG 上所有状态的 SG 值
##### 注意事项
- 定义：
  $$
  SG(u)=\operatorname{mex}\{SG(v)\mid u\to v\}
  $$
- 无后继状态满足 `SG=0`
- `SG=0` 为必败态，`SG!=0` 为必胜态
- 多个**独立**子游戏组成的和满足
  $$
  SG=SG_1\oplus SG_2\oplus\cdots\oplus SG_k
  $$
- 一个状态若最多有 $d$ 个不同后继，则其 SG 值至多为 $d$，因此 Mex 不需要按状态总数开得很大
- `sg_dag()` 要求 `ord` 是逆拓扑序，即后继先计算
- 若状态图有环并可能无限进行，普通 SG 不能直接使用，应做胜/负/平局逆推
- 若游戏规则不是“每次只操作一个独立子游戏”，普通 SG 异或定理可能失效
##### 常见用法
多个独立游戏：
```cpp
int s{};
for (int u : st) s ^= sg[u];
bool win = s != 0;
```
固定取石集合 `{1,3,4}`：
```cpp
int n = 1000000;
vector<int> take{1, 3, 4};
vector<int> sg(n + 1);
Mex mex(take.size() + 1);
for (int i = 1; i <= n; ++ i) {
    mex.clear();
    for (int x : take) {
        if (x > i) break;
        mex.add(sg[i - x]);
    }
    sg[i] = mex.get();
}
```
记忆化搜索也可直接按定义求 SG：
```cpp
auto dfs = [&](auto &&self, int u) -> int {
    if (sg[u] != -1) return sg[u];
    vector<int> a;
    for (int v : g[u]) a.push_back(self(self, v));
    sort(a.begin(), a.end());
    a.erase(unique(a.begin(), a.end()), a.end());
    int x{};
    for (int y : a) {
        if (y != x) break;
        ++ x;
    }
    return sg[u] = x;
};
```
##### 复杂度
- `Mex`：一次 `clear()` 为均摊 $O(1)$，`add()` 为 $O(1)$，`get()` 最坏 $O(d)$
- `sg_dag()`：$O(V+E)$
- 空间：$O(V+D)$，其中 $D$ 为最大出度
#### Bash 博弈
---
每次从一堆中取走 `1..m` 颗，无法行动者输
必败态：
$$
n\equiv0\pmod{m+1}
$$
即：
```cpp
bool bash(u64 n, u64 m) {
    return m >= n ? n != 0 : n % (m + 1) != 0;
}
```
##### 接口说明
- `bash(n,m)`：返回先手是否必胜
- `n`：当前石子数量
- `m`：单次最多取走的数量
##### 注意事项
- 这是普通 Bash：每次必须取至少 `1` 颗、至多 `m` 颗
- 必胜时可取
  $$
  n\bmod(m+1)
  $$
  颗，把状态送入下一必败态
- 若最后一颗者输、双方取石上限不同或下一次上限依赖上一步操作，不能套此结论
##### 常见用法
```cpp
if (bash(n, m)) {
    u64 take = m >= n ? n : n % (m + 1);
}
```
##### 复杂度
- 时间：$O(1)$
- 空间：$O(1)$
#### Anti-Nim
---
每次任选一堆取走正数颗石子，但**取走最后一颗石子者输**
```cpp
bool anti_nim(const vector<u64> &a) {
    u64 s{};
    int cnt{};
    bool one = true;
    for (u64 x : a) if (x) {
        s ^= x;
        ++ cnt;
        one &= x == 1;
    }
    return one ? cnt % 2 == 0 : s != 0;
}
```
##### 接口说明
- `anti_nim(a)`：返回当前局面先手是否必胜
- `a[i]`：第 `i` 堆石子数量
##### 注意事项
- 若所有非空堆大小均为 `1`，偶数堆为必胜态
- 若存在一堆大小大于 `1`，结论恢复为普通 Nim：异或和非零时先手必胜
- 空堆不参与堆数统计
- 该结论只针对标准 Anti-Nim，不能直接推广到任意 misère impartial game
##### 常见用法
```cpp
cout << (anti_nim(a) ? "First\n" : "Second\n");
```
##### 复杂度
- 时间：$O(n)$
- 空间：$O(1)$
#### 阶梯 Nim
---
第 `i` 级台阶上的石子可移动任意正数颗到第 `i-1` 级，`0` 级视为地面，进入地面的石子不再参与游戏
```cpp
bool stair_nim(const vector<u64> &a) {
    u64 s{};
    for (int i = 0; i < (int)a.size(); ++ i) {
        if (i % 2 == 0) s ^= a[i];
    }
    return s != 0;
}
```
##### 接口说明
- `a[0]`：第 `1` 级台阶，即最靠近地面的一级
- `stair_nim(a)`：返回先手是否必胜
##### 注意事项
- 只对**奇数级台阶**上的石子做普通 Nim 异或
- 若题目编号从 `0` 开始或从顶层开始，必须先转换编号含义，不能机械地异或奇数下标
- 偶数层上的操作可以由对手通过对应操作抵消，本质上只有奇数层决定胜负
##### 常见用法
```cpp
bool win = stair_nim(a);
```
##### 复杂度
- 时间：$O(n)$
- 空间：$O(1)$
#### Wythoff 博弈
---
有两堆石子，每次可以从一堆取任意正数颗，或从两堆中取走相同的正数颗
令两堆满足 $a\le b$，记
$$
k=b-a,\quad \varphi=\frac{1+\sqrt5}{2}
$$
必败态恰为
$$
(a,b)=(\lfloor k\varphi\rfloor,\lfloor k\varphi\rfloor+k)
$$
##### 接口说明
- 先令 `a <= b`
- `k=b-a`
- 判断 `a == floor(k*phi)` 即可判断是否为必败态
##### 注意事项
- `(0,0)` 对应 `k=0`，也是必败态
- 不要在大整数范围直接用 `double` 计算 `floor(k*phi)`，临界位置可能因精度误判
- 数据较大时应通过高精度或精确整数平方根计算
  $$
  \left\lfloor k\varphi\right\rfloor
  =\left\lfloor\frac{k+\lfloor k\sqrt5\rfloor}{2}\right\rfloor
  $$
- 两堆规则稍有改变，例如只能同时取固定倍数，就不再是 Wythoff
##### 常见用法
完整 u64 范围可直接精确判断，无须浮点或大整数平方根；返回 true 表示先手必胜：
```cpp
bool wythoff(u64 a, u64 b) {
    if (a > b) swap(a, b);
    u128 k = b - a, x = a;
    if (!k) return a != 0;
    if (x < k) return true;
    return x * (x - k) > k * k || (x + 1) * (x + 1 - k) <= k * k;
}
```
用法：`bool win = wythoff(a,b);`。当 k>0 且 x>=k 时，必败条件等价于 x(x-k)<=k²<(x+1)(x+1-k)。由于 a<b<=u64 上界，所有乘积均可放入 u128；k=0 与 x<k 已单独处理。
##### 复杂度
- 上面的 u128 精确比较：$O(1)$
- 精确整数平方根版本：取决于整数平方根实现
#### Fibonacci Nim
---
一堆 `n` 颗石子，首步不能全部取完；之后每次最多取走上一次取走数量的两倍
`z(n)` 表示 `n` 的 Zeckendorf 分解中的**最小 Fibonacci 项**
```cpp
u64 fib_low(u64 n) {
    static const vector<u64> f = [] {
        vector<u64> a{1, 2};
        constexpr u64 INF{ numeric_limits<u64>::max() };
        while (u128(a.end()[-1]) + a.end()[-2] <= INF) a.push_back(a.end()[-1] + a.end()[-2]);
        return a;
    }();
    u64 res{};
    for (int i = int(upper_bound(f.begin(), f.end(), n) - f.begin()) - 1; i >= 0; -- i) {
        if (f[i] <= n) {
            n -= f[i];
            res = f[i];
        }
    }
    return res;
}

bool fib_nim(u64 n, u64 lim) {
    return n && lim >= fib_low(n);
}
```
##### 接口说明
- `fib_low(n)`：返回 `n` 的 Zeckendorf 分解中的最小项
- `fib_nim(n,lim)`：还剩 `n` 颗、当前最多可取 `lim` 颗时，返回当前玩家是否必胜
- 标准首步 n>=1 时调用 `fib_nim(n,n-1)`；n=0 为终止必败态，fib_low(0)=0
- 完整 u64 Fibonacci 表仅首次调用构造，之后复用
##### 注意事项
- Zeckendorf 定理：每个正整数都能唯一表示为若干个**不相邻 Fibonacci 数**之和
- 当前最大可取数量 `lim >= fib_low(n)` 时必胜，并可取 `fib_low(n)` 颗
- 标准首步不能取完，因此 `n` 本身为 Fibonacci 数时先手必败
- Fibonacci 序列按 `1,2,3,5,...` 使用
- 若“下一步最多取上一步的倍数”不是 `2`，结论不再成立
##### 常见用法
标准 Fibonacci Nim：
```cpp
bool win = fib_nim(n, n - 1);
```
构造必胜操作：
```cpp
u64 x = fib_low(n);
if (x && lim >= x) {
    // 取 x 颗
}
```
##### 复杂度
- Fibonacci 数数量为 $O(\log n)$
- `fib_low()`：$O(\log n)$
- 空间：$O(\log n)$
#### Anti-SG：适用范围
---
misère 规则为**无法行动者胜**。普通 SG 值一般不足以判断这种游戏的胜负，不能将任意子游戏先求普通 SG，再套 Anti-Nim 的规则。
反例：状态 0 无后继，1→0，2→{0,1}，3→2。普通 SG 依次为 {0,1,2,0}，misère 胜负依次为 {胜,负,胜,负}。状态 0 与 3 的 SG 都为 0，但胜负不同。
下列函数保留旧名以兼容调用，**只用于真正的 Nim 堆大小，或已经另外证明在 misère 下可作同样替换的游戏**；它不是通用 Anti-SG 算法。
```cpp
bool anti_sg(const vector<int> &a) {
    int s{};
    bool big = false;
    for (int x : a) {
        s ^= x;
        big |= x > 1;
    }
    return big ? s != 0 : s == 0;
}
```
##### 接口说明
- a[i] 是非负 Nim 堆大小，不是任意游戏的普通 SG 值；完整 u64 堆请用 anti_nim
- 任意有限无环状态图应按“终止状态胜；存在必败后继则胜，否则负”逆推
- 多个一般子游戏需在组合状态上计算，或使用已证明适用的 misère quotient 等方法
- 可用 13.4 GameGraph 对完整组合状态图逆推，将所有终止状态 fix 为 WIN；不能把普通 SG 值直接异或代替组合状态
- 理论参考：[Aaron N. Siegel, Misère Games and Misère Quotients](https://www.ias.edu/sites/default/files/math/csdm/06-07/asiegel_misere_games_and_misere_quotients.pdf)
##### 常见用法
```cpp
vector<int> a{1, 1, 2}; // 实际 Nim 堆，而非任意状态的 SG 值
bool win = anti_sg(a);
```
##### 复杂度
- 时间：$O(n)$
- 空间：$O(1)$
#### Green Hackenbush 树上删边
---
根固定，每次删除一条边，并同时删去因此与根断开的部分；无法行动者输。
```cpp
u64 hack_sg(const vector<vector<int>> &g, int u, int fa = -1) {
    vector<int> p(g.size(), -1), ord{u};
    p[u] = fa;
    for (int i = 0; i < int(ord.size()); ++ i) {
        int x = ord[i];
        for (int v : g[x]) if (v != p[x]) p[v] = x, ord.push_back(v);
    }
    vector<u64> s(g.size());
    for (int i = int(ord.size()) - 1; i > 0; -- i) {
        int x = ord[i];
        s[p[x]] ^= s[x] + 1;
    }
    return s[u];
}
```
##### 接口说明
- `hack_sg(g,root)`：返回以 `root` 为根的树上删边游戏 SG 值
- 返回值为 `0` 时当前玩家必败
##### 注意事项
- 叶子节点 SG 值为 `0`
- 对每条子树分支：
  $$
  SG_{\text{branch}}=SG_{\text{child}}+1
  $$
  各分支再异或
- 此模板只适用于**树**
- 一般无向图删边游戏需要先使用 Fusion Principle 等化简，不能直接找一棵 DFS 树后套本模板
- 有边权或其他删边规则时还需要相应扩展，不能机械使用 `+1`
##### 常见用法
```cpp
u64 s = hack_sg(g, root);
cout << (s ? "First\n" : "Second\n");
```
##### 复杂度
- 时间：$O(n)$
- 额外空间：$O(n)$；显式遍历并逆序合并，避免长链递归爆栈
