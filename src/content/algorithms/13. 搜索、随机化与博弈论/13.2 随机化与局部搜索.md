### 随机化与局部搜索
---
#### 随机数
---
```cpp
mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
template<class T>
T rnd(T l, T r) {
    if constexpr (is_integral_v<T>) return uniform_int_distribution<T>(l, r)(rng);
    else return uniform_real_distribution<T>(l, r)(rng);
}
```
##### 接口说明
- `rng`：64 位 Mersenne Twister 随机数生成器
- `rnd<T>(l,r)`：
  - 整数类型：均匀生成 $[l,r]$
  - 浮点类型：均匀生成 $[l,r)$
- 随机打乱直接使用 `shuffle(a.begin(),a.end(),rng)`
##### 注意事项
- 调试时建议使用固定种子，便于复现：`rng.seed(123456789);`
- `rand()` 随机范围和质量较差，不用于 64 位随机数、随机打乱或随机哈希
- 若随机算法单次失败概率不超过 $p$，独立运行 $t$ 次仍全部失败的概率不超过 $p^t$
- Monte Carlo 算法可能返回错误答案；Las Vegas 算法答案始终正确，只随机运行时间
- 若随机得到的候选可以快速验证，优先考虑 Las Vegas：不断生成候选直到验证成功
- 随机打乱只能改善依赖输入顺序的期望性能，不能修复算法本身错误的最坏复杂度
##### 常见用法
随机整数：
```cpp
int x = rnd(0, n - 1);
i64 y = rnd<i64>(1, (i64)1E18);
```
随机浮点数：
```cpp
double x = rnd(0.0, 1.0);
```
随机下标：
```cpp
int p = rnd(0, (int)a.size() - 1);
```
随机打乱：
```cpp
shuffle(a.begin(), a.end(), rng);
```
随机选择两个不同位置：
```cpp
int x = rnd(0, n - 1);
int y = rnd(0, n - 2);
if (y >= x) ++ y;
```
##### 复杂度
- rnd 的整数类型限标准分布支持的 short/int/long/long long 及其 unsigned 版本（不含 bool/char/i128），要求 l<=r；浮点限 float/double/long double，要求有限 l<r 且区间宽度可表示
- `rnd()`：期望 $O(1)$
- `shuffle()`：$O(n)$
#### 模拟退火
---
统一按**最小化**目标函数编写。状态原地修改，通过 `apply/undo` 避免每次复制整个状态
```cpp
template<class S, class F, class G, class A, class U>
pair<S, double> sa(S s, F f, G gen, A apply, U undo, double t0, double te, double k, int rep = 1) {
    assert(isfinite(t0) && isfinite(te) && isfinite(k) && t0 > 0 && te >= 0 && 0 < k && k < 1 && rep >= 1);
    uniform_real_distribution<double> prob(0, 1);
    S best = s;
    double cur = f(s), ans = cur;
    for (double t = t0; t > te;) {
        for (int z = 0; z < rep; ++ z) {
            auto op = gen(s, t);
            apply(s, op);
            double nv = f(s);
            double d = nv - cur;
            if (d <= 0 || prob(rng) < exp(-d / t)) {
                cur = nv;
                if (cur < ans) {
                    ans = cur;
                    best = s;
                }
            } else {
                undo(s, op);
            }
        }
        double nt = t * k;
        if (!(nt < t)) break;
        t = nt;
    }
    return {best, ans};
}
```
##### 接口说明
- `sa(s,f,gen,apply,undo,t0,te,k,rep)`：返回 `{搜索到的最优状态, 最优目标值}`
- `s`：初始状态
- `f(s)`：计算目标值，模板默认最小化
- `gen(s,t)`：根据当前状态和温度生成一次操作
- `apply(s,op)`：执行操作
- `undo(s,op)`：撤销操作，必须与 `apply` 严格互逆
- `t0`：初始温度
- `te`：终止温度
- `k`：降温系数，要求 $0<k<1$
- `rep`：每个温度执行的尝试次数，要求 >=1
- 温度参数必须有限，t0>0、te>=0；t0<=te 时不执行搜索。f(s) 必须返回有限 double；连续变量撤销应保存原值，不能假定浮点加减精确互逆
##### 注意事项
- 当前值 `cur` 和历史最优值 `ans` 必须分开维护；模拟退火允许暂时接受更差状态
- 当新状态更优，即 $d\le0$ 时直接接受；否则以 $e^{-d/t}$ 的概率接受
- 温度较高时容易接受差解，用于跳出局部最优；温度较低时逐渐接近普通爬山
- 必须返回搜索过程中保存的 `best`，不能直接返回最终状态
- 最大化时可令 `f(s)=-score(s)`
- `t0`、`te`、`k`、`rep` 没有固定最优值，需要结合目标值尺度和时限调整
- `k` 越接近 `1`，降温越慢，搜索通常越充分，但运行时间也越长
- 邻域设计通常比参数微调更重要；应尽量让一次修改既能局部调整，又能跨越局部最优
- `gen` 可利用温度调整扰动范围：高温大范围修改，低温小范围修改
- 若 `f(s)` 计算较慢，应尽量维护一次修改造成的目标值增量，而不是每次完整重算
- 大状态应使用 `apply/undo` 原地修改，避免频繁复制 `vector`、排列或图
- 模拟退火不保证找到全局最优解，但实现仍应保证状态合法、撤销正确和返回历史最优，重要题目应多次随机重启并保存全局最好答案
##### 常见用法
排列中每次随机交换两个位置：
```cpp
struct Op {
    int x, y;
};

auto [best, val] = sa(a,
    [&](const vector<int> &a) {
        return cost(a);
    },
    [&](const vector<int> &a, double t) {
        int x = rnd(0, (int)a.size() - 1);
        int y = rnd(0, (int)a.size() - 1);
        return Op{x, y};
    },
    [&](vector<int> &a, Op op) {
        swap(a[op.x], a[op.y]);
    },
    [&](vector<int> &a, Op op) {
        swap(a[op.x], a[op.y]);
    },
    1000, 1E-6, 0.995, 5);
```
若交换相同位置没有意义：
```cpp
auto gen = [&](const vector<int> &a, double t) {
    int n = a.size();
    int x = rnd(0, n - 1);
    int y = rnd(0, n - 2);
    if (y >= x) ++ y;
    return Op{x, y};
};
```
区间翻转：
```cpp
struct Op {
    int l, r;
};
auto gen = [&](const vector<int> &a, double t) {
    int l = rnd(0, (int)a.size() - 1);
    int r = rnd(0, (int)a.size() - 1);
    if (l > r) swap(l, r);
    return Op{l, r};
};
auto apply = [&](vector<int> &a, Op op) {
    reverse(a.begin() + op.l, a.begin() + op.r + 1);
};
auto undo = apply;
```
连续变量可让扰动范围随温度变化：
```cpp
auto gen = [&](const vector<double> &a, double t) {
    int p = rnd(0, (int)a.size() - 1);
    double d = rnd(-t, t);
    return tuple{p, d, a[p]};
};
auto apply = [&](vector<double> &a, auto op) {
    a[get<0>(op)] += get<1>(op);
};
auto undo = [&](vector<double> &a, auto op) {
    a[get<0>(op)] = get<2>(op);
};
```
多次随机重启：
```cpp
constexpr double INF{ numeric_limits<double>::max() };
double ans = INF;
for (int z = 0; z < 20; ++ z) {
    auto s = init();
    auto [best, val] = sa(s, f, gen, apply, undo, 1000, 1E-6, 0.995, 5);
    ans = min(ans, val);
}
```
##### 复杂度
当 0<te<t0 且忽略浮点舍入时，温度层数为
$$
L=\left\lceil\frac{\log(te/t0)}{\log k}\right\rceil
$$
te=0 时该公式不适用；实现检测 t*k 未能严格减小时退出，避免次正规浮点数导致停滞。
每层尝试 rep 次，令 C 包含生成、执行/撤销、目标计算和必要的最优状态复制，则：
- 时间复杂度：$O(L\cdot rep\cdot C)$
- 额外空间主要为当前状态和最优状态各一份，即 $O(S)$
