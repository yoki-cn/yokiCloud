### 启发式搜索与指数级搜索
---
#### A*
---
适用于边权非负的隐式状态图
`nxt(s)` 返回所有 `{下一状态, 代价}`，`h(s)` 返回到目标的代价下界，`goal(s)` 判断目标状态
复杂度最坏**指数级**；空间与实际访问状态数同阶
```cpp
template<class S, class Next, class Heu, class Goal, class Hash = hash<S>>
optional<i64> astar(const S &st, Next nxt, Heu h, Goal goal, Hash hs = Hash()) {
    struct Node {
        i128 f;
        i64 d;
        S s;
    };
    auto cmp = [](const Node &a, const Node &b) { return a.f != b.f ? a.f > b.f : a.d < b.d; };
    priority_queue<Node, vector<Node>, decltype(cmp)> q(cmp);
    unordered_map<S, i64, Hash> dis(0, hs);
    constexpr i64 INF{ numeric_limits<i64>::max() };
    dis[st] = 0;
    q.push({h(st), 0, st});
    while (!q.empty()) {
        Node cur = q.top();
        q.pop();
        auto it = dis.find(cur.s);
        if (it == dis.end() || it->second != cur.d) continue;
        if (goal(cur.s)) return cur.d;
        for (auto [v, w] : nxt(cur.s)) {
            if (w > INF - cur.d) continue;
            i64 nd = cur.d + w;
            auto jt = dis.find(v);
            if (jt != dis.end() && jt->second <= nd) continue;
            dis[v] = nd;
            q.push({i128(nd) + h(v), nd, move(v)});
        }
    }
    return nullopt;
}
```
- `astar(st,nxt,h,goal)`：返回从 `st` 到任意目标状态的最小代价；不可达返回 `nullopt`
- `nxt(s)`：返回 `{状态, 边权}` 序列，要求边权非负
- `h(s)`：从 `s` 到目标真实最短距离的下界；要求所有目标满足 `h(goal)=0`
- `goal(s)`：判断 `s` 是否为目标
- `S` 需要支持相等比较和哈希；特殊状态可传自定义 `Hash`
##### 注意事项
- `h(s)=0` 时退化为 Dijkstra
- `h` 必须可采纳，即不能高估真实剩余代价，否则可能剪掉最优解
- 模板允许状态重新入队，因此可处理可采纳但不一致的启发式
- 启发式越接近真实距离通常越快，但计算 `h` 本身也不能过重
- g 距离与返回值使用 i64，f=g+h 使用 i128；超过 i64 上界的非负路径不再扩展。因此 nullopt 表示不可达或最短距离超出 i64 范围。h 返回 i64 范围内的整数；同 f 时优先较大 g，不改变最优性
- 若需要恢复方案，在松弛时额外记录父状态和操作
##### 常见用法
```cpp
auto ans = astar(st,
    [&](const State &s) {
        vector<pair<State, i64>> res;
        // 生成后继状态
        return res;
    },
    [&](const State &s) {
        return heuristic(s);
    },
    [&](const State &s) {
        return s == target;
    });
if (ans) cout << *ans << '\n';
```
#### IDA*
---
适用于单位代价、答案深度较小且状态无法全部存储的搜索
`gen(s,last)` 返回可选操作编号，状态需支持 `apply(op)` / `undo(op)`
复杂度最坏**指数级**，路径空间为 $O(d)$；还需计入状态及递归各层生成的操作列表，若每层至多 b 个操作则为 $O(S+bd)$，其中 d 为当前搜索深度
```cpp
template<class S, class Heu, class Gen, class Goal>
optional<vector<int>> ida(S st, Heu h, Gen gen, Goal goal, int ub) {
    vector<int> path;
    constexpr i64 INF{ numeric_limits<i64>::max() };
    auto dfs = [&](auto &&self, S &s, i64 dep, i64 bnd) -> i64 {
        i64 f = dep + h(s);
        if (f > bnd) return f;
        if (goal(s)) return -1;
        i64 nb = INF;
        int last = path.empty() ? -1 : path.back();
        for (int op : gen(s, last)) {
            s.apply(op);
            path.push_back(op);
            i64 t = self(self, s, dep + 1, bnd);
            if (t == -1) return -1;
            nb = min(nb, t);
            path.pop_back();
            s.undo(op);
        }
        return nb;
    };
    for (i64 bnd = h(st); bnd <= ub;) {
        S s = st;
        i64 nb = dfs(dfs, s, 0, bnd);
        if (nb == -1) return path;
        if (nb == INF) break;
        bnd = nb;
    }
    return nullopt;
}
```
- `ida(st,h,gen,goal,ub)`：在答案不超过 `ub` 时返回操作序列，否则返回 `nullopt`
- `h(s)`：从当前状态到目标至少还需多少步，返回非负 int，且不能高估；目标处为 0。深度与阈值中间量用 i64，避免 dep+h 溢出
- `gen(s,last)`：返回当前可执行操作；可根据 `last` 排除立即撤销的反向操作
- `S::apply(op)` / `S::undo(op)`：执行、撤销一次操作
##### 注意事项
- 每轮不是简单令深度界加一，而是跳到本轮所有越界状态中最小的 `dep+h`
- `h` 越强，实际搜索量通常越小；若 `h=0`，基本退化为迭代加深 DFS
- `gen` 应优先安排更可能接近答案的操作，并尽量去掉立即反向、重复和对称状态
- 模板默认每步代价为 `1`；带权状态搜索优先使用 A*
- `ub` 必须覆盖可能答案；若题目无自然上界，可根据题意自行扩大
##### 常见用法
```cpp
auto ans = ida(st,
    [&](const State &s) { return heuristic(s); },
    [&](const State &s, int last) {
        vector<int> ops;
        // 生成操作，并根据 last 剪去反向操作
        return ops;
    },
    [&](const State &s) { return s == target; },
    100);
```
#### 最大团
---
使用位压缩、贪心染色上界与分支限界，支持至多 `64` 个点。最大独立集等价于补图最大团
复杂度最坏**指数级**；每个搜索节点的贪心染色为 $O(n^2)$ 的位运算级处理，`n <= 64`
```cpp
struct MaxClique {
    int n, best{};
    u64 ans{};
    vector<u64> g;
    explicit MaxClique(int n_) : n(n_), g(n) {}
    void add(int u, int v) {
        if (u == v) return;
        g[u] |= 1ULL << v;
        g[v] |= 1ULL << u;
    }
    void dfs(u64 p, int sz, u64 cur) {
        if (!p) {
            if (sz > best) best = sz, ans = cur;
            return;
        }
        array<int, 64> v, c;
        int m = 0, col = 0;
        u64 rem = p;
        while (rem) {
            ++ col;
            u64 q = rem;
            while (q) {
                int x = __builtin_ctzll(q);
                u64 b = 1ULL << x;
                v[m] = x;
                c[m ++] = col;
                rem ^= b;
                q ^= b;
                q &= ~g[x];
            }
        }
        for (int i = m - 1; i >= 0; -- i) {
            if (sz + c[i] <= best) return;
            int x = v[i];
            u64 b = 1ULL << x;
            if (!(p & b)) continue;
            dfs(p & g[x], sz + 1, cur | b);
            p ^= b;
        }
    }
    pair<int, vector<int>> solve() {
        best = 0;
        ans = 0;
        u64 p = n == 64 ? ~0ULL : (1ULL << n) - 1;
        dfs(p, 0, 0);
        vector<int> res;
        for (int i = 0; i < n; ++ i) if (ans >> i & 1ULL) res.push_back(i);
        return {best, res};
    }
};
```
- `MaxClique(n)`：建立 `n` 个点的无向图，要求 `0 <= n <= 64`
- `add(u,v)`：加入无向边
- `solve()`：返回 `{最大团大小, 最大团点集}`
- 最大独立集：对原图取补图后调用最大团
##### 分支限界
指数级搜索最重要的是尽早获得较优可行解，并使用正确方向的界剪枝：
- 最大化：维护当前最好答案，若 `当前值 + 乐观上界 <= best` 则剪枝
- 最小化：若 `当前值 + 乐观下界 >= best` 则剪枝
- 优先搜索更可能得到优解的分支，可以更早收紧 `best`
- 固定变量顺序、按度数排序、强制选择、对称性消除、支配关系都可能显著减少搜索树
- 上界或下界必须保证正确，界太弱只影响速度，界错误会直接产生错误答案
##### 注意事项
- 使用分支限界搜索
- `sz + c[i] <= best` 时剪枝，其中 `c[i]` 是贪心染色得到的最大团上界
- 模板仅适用于无向简单图
- 贪心染色把候选点分为若干独立集，因此颜色数是候选子图最大团大小的上界
- `n <= 64` 时位运算版本非常方便；更大规模应改动态 `bitset` 或其他最大团实现
- 最大团仍是指数级算法，复杂图上的实际速度高度依赖结构和搜索顺序
##### 常见用法
```cpp
MaxClique mc(n);
for (auto [u, v] : edges) mc.add(u, v);
auto [sz, ver] = mc.solve();
```
最大独立集：
```cpp
MaxClique mc(n);
vector<vector<bool>> e(n, vector<bool>(n));
for (auto [u, v] : edges) e[u][v] = e[v][u] = true;
for (int i = 0; i < n; ++ i) {
    for (int j = i + 1; j < n; ++ j) {
        if (!e[i][j]) mc.add(i, j);
    }
}
auto [sz, ver] = mc.solve();
```
