### 日期与星期计算
---
采用公历（Gregorian calendar），支持公元 $1\sim9999$ 年
- 日期与整数天数互转，`0001-01-01` 对应第 `0` 天
- 判断闰年、月份天数、日期合法性
- 日期差、日期加减天数、年内第几天
- 星期一为 `1`，星期日为 `7`
```cpp
struct Date {
    int y{}, m{}, d{};
    // ===== 基础日期函数 =====
    static bool leap(int y) { return y % 4 == 0 && (y % 100 != 0 || y % 400 == 0); }
    static int mdays(int y, int m) {
        static constexpr int a[13]{0,31,28,31,30,31,30,31,31,30,31,30,31};
        return a[m] + (m == 2 && leap(y));
    }
    bool valid() const { return 1 <= y && y <= 9999 && 1 <= m && m <= 12 && 1 <= d && d <= mdays(y, m); }
    // ===== 日期与天数互转 =====
    i64 days() const {
        int yy = y - (m <= 2);
        int era = yy / 400, yo = yy % 400;
        int mm = m > 2 ? m - 3 : m + 9;
        return 1LL * era * 146097 + 365LL * yo + yo / 4 - yo / 100 + (153 * mm + 2) / 5 + d - 307;
    }
    static Date from_days(i64 z) {
        z += 306;
        i64 era = z / 146097;
        int doe = z % 146097;
        int yo = (doe - doe / 1460 + doe / 36524 - doe / 146096) / 365;
        int y = int(era * 400 + yo);
        int doy = doe - (365 * yo + yo / 4 - yo / 100);
        int mp = (5 * doy + 2) / 153;
        int d = doy - (153 * mp + 2) / 5 + 1;
        int m = mp < 10 ? mp + 3 : mp - 9;
        y += m <= 2;
        return {y, m, d};
    }
    // ===== 扩展功能 =====
    int wday() const { return int(days() % 7) + 1; }
    int yday() const { return int(days() - Date{y, 1, 1}.days()) + 1; }
    optional<Date> add(i64 k) const {
        i64 z = days(), mx = Date{9999, 12, 31}.days();
        if (k < -z || k > mx - z) return nullopt;
        return from_days(z + k);
    }
};
```
#### 独立星期公式（Kim Larsen）
只需计算星期时，可以直接使用以下函数，不依赖 `Date`
```cpp
int wday(int y, int m, int d) {
    if (m <= 2) m += 12, -- y;
    return (d + 2 * m + 3 * (m + 1) / 5 + y + y / 4 - y / 100 + y / 400) % 7 + 1;
}
```
#### 成员变量
- `y`：年份，范围 $[1,9999]$
- `m`：月份，范围 $[1,12]$
- `d`：当月日期，从 `1` 开始
#### 接口
- `Date{y,m,d}`：创建日期对象，$O(1)$
- `Date::leap(y)`：判断是否为闰年，$O(1)$
- `Date::mdays(y,m)`：返回当月天数，要求月份合法，$O(1)$
- `valid()`：判断是否为合法日期，$O(1)$
- `days()`：日期转整数天数，$O(1)$
- `Date::from_days(z)`：整数天数转日期，$O(1)$
- `wday()`：返回星期编号，星期一为 `1`，星期日为 `7`，$O(1)$
- `yday()`：返回年内第几天，范围 $[1,365]$ 或 $[1,366]$，$O(1)$
- `add(k)`：日期增加 `k` 天，`k` 可为负数，超出支持范围返回 `nullopt`，$O(1)$
#### 注意事项
- 使用前推公历，即将现代公历的闰年规则延伸至公元 1582 年之前，不处理历史上的儒略历与历法切换
- 所有日期计算均不涉及时区、夏令时和闰秒
- `days()`、`wday()`、`yday()`、`add()` 均要求当前日期合法，`from_days(z)` 要求 $0\le z\le3652058$
- `mdays(y,m)` 要求月份在 $[1,12]$ 内，不能直接传入非法月份
- `0001-01-01` 为星期一，`1970-01-01` 为星期四
- `days()` 返回的天数从 `0001-01-01` 开始计算，与 Unix 时间戳的纪元不同
- 日期相减按实际经过天数计算，不包含起点当天；若题目要求首尾日期均计入，需要额外加 `1`
- `from_days()` 不负责越界检查，带偏移的日期计算优先调用 `add()`
#### 常见用法
#### 闰年、日期合法性和月份天数
```cpp
Date a{2024, 2, 29};
bool ok = a.valid();       // true
bool lp = Date::leap(2024); // true
int cnt = Date::mdays(2024, 2); // 29
```
#### 计算两个日期相差的天数
```cpp
Date a{2024, 2, 28}, b{2024, 3, 1};
i64 diff = b.days() - a.days(); // 2

// 计算绝对天数差
i64 dis = abs(diff);
```
#### 日期增加或减少指定天数
```cpp
Date a{2024, 2, 29};
auto b = a.add(10); // 2024-03-10
auto c = a.add(-30); // 2024-01-30

if (b) cout << b->y << ' ' << b->m << ' ' << b->d << '\n';
```
#### 计算星期、年内第几天
```cpp
Date a{2024, 2, 29};
int w = a.wday(); // 4，星期四
int d = a.yday(); // 60

// 只需要星期时直接使用独立公式
int x = wday(2024, 2, 29); // 4
```
#### 日期与整数天数转换
```cpp
Date a{1970, 1, 1};
i64 z = a.days(); // 719162

Date b = Date::from_days(z);
// b = {1970, 1, 1}
```
#### 日期字符串的输入输出
```cpp
string s = "2024-02-29";
Date a;
sscanf(s.c_str(), "%d-%d-%d", &a.y, &a.m, &a.d);

// 格式化为 YYYY-MM-DD
ostringstream os;
os << setfill('0') << setw(4) << a.y << '-'
   << setw(2) << a.m << '-' << setw(2) << a.d;
string t = os.str(); // "2024-02-29"
```
输入格式需要自行保证合法，读取完成后可以使用 `valid()` 检查
#### C++20 `chrono` 标准库写法
若比赛使用 C++20，可以直接通过标准库完成日期合法性、日期差和日期加减
```cpp
using namespace chrono;

// 创建日期、检查合法性
year_month_day a{year{2024}, month{2}, day{29}};
bool ok = a.ok(); // true

// 闰年、月份最后一天
bool lp = year{2024}.is_leap(); // true
auto last_day = year{2024}/February/last;
int cnt = unsigned(last_day.day()); // 29

// 日期加减、日期差
sys_days z{a};
year_month_day b{z + days{10}}; // 2024-03-10
i64 diff = (sys_days{b} - z).count(); // 10

// 星期：1~7 对应星期一至星期日
int w = weekday{z}.iso_encoding(); // 4

// 年内第几天
int yd = (z - sys_days{year{2024}/January/day{1}}).count() + 1; // 60

// 2024 年 10 月的第二个星期二
auto t = year{2024}/October/Tuesday[2];
year_month_day d{sys_days{t}}; // 2024-10-08
```
`sys_days` 表示精度为天的时间点，可直接相减得到天数差
需要注意：`year_month_day + months` 是日历月份运算，例如 1 月 31 日加一个月可能得到非法的 2 月 31 日，应当检查 `.ok()`；按实际天数加减则使用 `sys_days + days`
#### 复杂度

| 操作                       | 时间复杂度  | 空间复杂度  |
| ------------------------ | ------ | ------ |
| 闰年判断、月份天数、合法性            | $O(1)$ | $O(1)$ |
| `days()` / `from_days()` | $O(1)$ | $O(1)$ |
| `wday()` / `yday()`      | $O(1)$ | $O(1)$ |
| `add()`                  | $O(1)$ | $O(1)$ |
| 独立星期公式                   | $O(1)$ | $O(1)$ |
