### 二分、三分与黄金分割
---
#### 整数二分
---
```cpp
i64 mid_floor(i64 l, i64 r) { return i64(i128(l) + (i128(r) - l) / 2); }
i64 mid_ceil(i64 l, i64 r) { return i64(i128(l) + (i128(r) - l + 1) / 2); }

template<class F>
i64 fst_true(i64 l, i64 r, F f) {
    while (l < r) {
        i64 m = mid_floor(l, r);
        if (f(m)) r = m;
        else l = m + 1;
    }
    return l;
}

template<class F>
i64 lst_true(i64 l, i64 r, F f) {
    while (l < r) {
        i64 m = mid_ceil(l, r);
        if (f(m)) l = m;
        else r = m - 1;
    }
    return l;
}
```
##### 接口说明
- `mid_floor(l,r)`：$\lfloor(l+r)/2\rfloor$，要求 `l <= r`
- `mid_ceil(l,r)`：$\lceil(l+r)/2\rceil$，要求 `l <= r`
- `fst_true(l,r,f)`：在 `false...true` 中找第一个真，要求 `f(r) = true`
- `lst_true(l,r,f)`：在 `true...false` 中找最后一个真，要求 `f(l) = true`
##### 注意事项
- 搜索区间为闭区间 `[l,r]`
- 使用 `i128` 计算区间长度，可处理负数区间和完整 `i64` 范围
- 答案可能不存在时需要额外哨兵或返回后验证
- 不要改成 `(l + r) / 2`，既可能溢出，也不能正确表达负数情况下的向下取整
##### 常见用法
```cpp
i64 ans = fst_true(l, r, [&](i64 x) {
    return ok(x);
});
```
```cpp
i64 ans = lst_true(l, r, [&](i64 x) {
    return ok(x);
});
```
##### 复杂度
$O(\log(r-l+1))$ 次判定，额外空间 $O(1)$
#### 标准库二分
---
已有有序范围时优先使用标准库
```cpp
auto p1 = ranges::lower_bound(a, x); // 第一个 >= x
auto p2 = ranges::upper_bound(a, x); // 第一个 > x
```
一般的单调谓词可以使用 `partition_point`
```cpp
auto p = ranges::partition_point(a, [&](const auto &x) {
    return check(x);
});
```
整数候选区间也可以配合 `views::iota`
```cpp
auto rg = views::iota(l, r);
auto p = ranges::partition_point(rg, [&](i64 x) {
    return !ok(x);
});
if (p != rg.end()) {
    i64 ans = *p;
}
```
##### 接口说明
- `ranges::lower_bound(a,x)`：第一个 `>= x`
- `ranges::upper_bound(a,x)`：第一个 `> x`
- `ranges::partition_point(a,f)`：`true...false` 中第一个假
- `views::iota(l,r)`：生成整数范围 `[l,r)`
##### 注意事项
- `partition_point` 要求范围已经按谓词分为 `true...false`
- 若目标谓词为 `false...true`，通常传入 `!ok(x)`
- `views::iota(l,r)` 是半开区间，与手写整数二分的闭区间不同
- `p == end()` 表示不存在对应位置，不能直接解引用
- `ranges` / `views` 写法需要 C++20
##### 复杂度
随机访问范围上为 $O(\log n)$ 次比较或谓词判断
#### 实数二分
---
固定迭代次数通常优先使用
```cpp
template<class F>
ld bin_real(ld l, ld r, F f, int it = 100) {
    while (it --) {
        ld m = l + (r - l) / 2;
        if (f(m)) r = m;
        else l = m;
    }
    return (l + r) / 2;
}
```
##### 接口说明
- `bin_real(l,r,f,it)`：在单调实数谓词上逼近 `false...true` 的分界点
- 返回分界点的近似值
##### 注意事项
- 固定次数不会因为浮点精度导致死循环
- `long double` 下 `100` 次通常已经足够
- 若谓词方向为 `true...false`，反转更新方向或谓词
##### 复杂度
`it` 次判定，额外空间 $O(1)$
#### 整数单峰：斜率二分
---
对于先不增后不减的整数函数，优先使用相邻值比较
找最左极小点：
```cpp
template<class F>
i64 argmin(i64 l, i64 r, F f) {
    while (l < r) {
        i64 m = mid_floor(l, r);
        if (f(m) <= f(m + 1)) r = m;
        else l = m + 1;
    }
    return l;
}
```
若存在一段极小值平台，找最右极小点：
```cpp
template<class F>
i64 argmin_r(i64 l, i64 r, F f) {
    while (l < r) {
        i64 m = mid_floor(l, r);
        if (f(m) < f(m + 1)) r = m;
        else l = m + 1;
    }
    return l;
}
```
##### 接口说明
- `argmin(l,r,f)`：返回 `[l,r]` 中最左极小点
- `argmin_r(l,r,f)`：返回 `[l,r]` 中最右极小点
##### 注意事项
- 要求 `f` 在整数域上先不增后不减
- 本质是在二分 `f(x+1)-f(x)` 的符号
- `m < r`，因此 `f(m + 1)` 始终合法
- 求最大值时反转比较符号
- 若 `f(x)` 很贵，可自行缓存相邻位置的函数值
##### 常见用法
```cpp
i64 p = argmin(l, r, [&](i64 x) {
    return calc(x);
});
auto ans = calc(p);
```
##### 复杂度
$O(\log(r-l+1))$ 轮，每轮至多两次函数计算，额外空间 $O(1)$
#### 整数三分
---
无法方便使用相邻斜率时可使用三分
```cpp
template<class F>
auto ter_int(i64 l, i64 r, F f) {
    while (i128(r) - l > 6) {
        i128 d = (i128(r) - l) / 3;
        i64 m1 = i64(i128(l) + d);
        i64 m2 = i64(i128(r) - d);
        if (f(m1) <= f(m2)) r = m2 - 1;
        else l = m1 + 1;
    }
    i64 p = l;
    auto v = f(l);
    for (i64 x = l; x != r; ) {
        ++ x;
        auto y = f(x);
        if (y < v) v = y, p = x;
    }
    return pair{p, v};
}
```
##### 接口说明
- `ter_int(l,r,f)`：求 `[l,r]` 上单峰函数的最小值
- 返回 `{最小值位置, 最小值}`
##### 注意事项
- 对离散凸函数通常优先使用 `argmin`
- 必须保证函数确实单峰
- 最后直接枚举剩余常数个位置，避免离散三分的边界问题
- 求最大值时反转比较符号
##### 复杂度
$O(\log(r-l+1))$ 次函数计算，额外空间 $O(1)$
#### 实数三分
---
```cpp
template<class F>
ld ter_real(ld l, ld r, F f, int it = 150) {
    while (it --) {
        ld d = (r - l) / 3;
        ld m1 = l + d, m2 = r - d;
        if (f(m1) <= f(m2)) r = m2;
        else l = m1;
    }
    return (l + r) / 2;
}
```
##### 接口说明
- `ter_real(l,r,f,it)`：求实数区间上单峰函数的最小值位置
##### 注意事项
- 要求 `f` 先下降后上升，允许极小值平台
- 若导数容易计算且单调，通常直接二分导数更合适
- 求最大值时反转比较符号
##### 复杂度
`2it` 次函数计算，额外空间 $O(1)$
#### 二分导数
---
连续凸函数且导数可计算时，可直接对导数零点二分
```cpp
ld x = bin_real(l, r, [&](ld x) {
    return df(x) >= 0;
});
```
##### 注意事项
- 要求导数单调不减
- 不要求真的存在 `df(x) == 0`，搜索的是导数由负变非负的分界位置
- 通常比实数三分更直接
##### 复杂度
与实数二分相同
#### 黄金分割
---
单次函数计算较贵时，比普通实数三分少一次重复计算
```cpp
template<class F>
ld golden(ld l, ld r, F f, int it = 150) {
    constexpr ld k = 0.6180339887498948482L;
    ld x1 = r - (r - l) * k;
    ld x2 = l + (r - l) * k;
    auto y1 = f(x1), y2 = f(x2);
    while (it --) {
        if (y1 <= y2) {
            r = x2;
            x2 = x1;
            y2 = y1;
            x1 = r - (r - l) * k;
            y1 = f(x1);
        } else {
            l = x1;
            x1 = x2;
            y1 = y2;
            x2 = l + (r - l) * k;
            y2 = f(x2);
        }
    }
    return (l + r) / 2;
}
```
##### 接口说明
- `golden(l,r,f,it)`：黄金分割搜索实数单峰函数最小值位置
##### 注意事项
- 与实数三分前提相同
- 初始化计算两次 `f`，之后每轮只新增一次计算
- `f(x)` 较便宜时普通三分通常已经足够
##### 复杂度
共 `it + 2` 次函数计算，额外空间 $O(1)$
