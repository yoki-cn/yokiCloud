### 并行二分
---
有 `m` 次按顺序发生的更新和 `q` 个询问，每个询问都要求最早在哪次更新后满足单调条件
```cpp
template<class R, class A, class C>
vector<int> pbs(int q, int m, R rst, A add, C ok) {
    vector<int> l(q, -1), r(q, m + 1);
    vector<vector<int>> buc(m + 1);
    while (true) {
        bool any = false;
        for (auto &v : buc) v.clear();
        for (int id = 0; id < q; ++ id) if (l[id] + 1 < r[id]) {
            any = true;
            int mid = l[id] + (r[id] - l[id]) / 2;
            buc[mid].push_back(id);
        }
        if (!any) break;
        rst();
        for (int t = 0; t <= m; ++ t) {
            if (t) add(t);
            for (int id : buc[t]) {
                if (ok(id)) r[id] = t;
                else l[id] = t;
            }
        }
    }
    return r; // 0：初始满足，m + 1：始终不满足
}
```
#### 接口说明
- `pbs(q,m,rst,add,ok)`：求每个询问第一次满足条件的更新时间
- 询问编号为 `0..q-1`
- 更新编号为 `1..m`
- `rst()`：恢复到所有更新发生前的状态
- `add(t)`：加入第 `t` 次更新
- `ok(id)`：判断询问 `id` 在当前状态下是否满足
- 返回 `ans[id] = 0` 表示不执行更新已经满足
- 返回 `ans[id] = m + 1` 表示执行全部更新仍不满足
- 否则第 `ans[id]` 次更新后第一次满足
#### 注意事项
- 对每个询问，`ok(id)` 必须随 `t` 单调地从假变真
- 每轮都会 `rst()`，随后严格按 `1..m` 的顺序重新加入更新
- `ok(id)` 只能依赖当前已经加入的更新，不能残留上一轮状态
- 更新若会使询问从真重新变假，则不能直接使用并行二分
- `rst()` 较贵时可使用时间戳、记录修改位置后撤销等方式降低清空代价
- 所有询问必须共享同一条更新时间轴，否则通常需要重新建模
- 若只是单个询问，普通二分通常更简单
#### 常见用法
下面只展示接口语义，实际题目通常把 `cur` 换成 BIT、线段树、并查集等结构
```cpp
i64 cur = 0;
auto ans = pbs(q, m,
    [&] {
        cur = 0;
    },
    [&](int t) {
        cur += a[t];
    },
    [&](int id) {
        return cur >= need[id];
    }
);
```
判断返回值：
```cpp
for (int id = 0; id < q; ++ id) {
    if (ans[id] == 0) {
        // 初始状态已经满足
    } else if (ans[id] == m + 1) {
        // 全部更新后仍不满足
    } else {
        // 第 ans[id] 次更新后第一次满足
    }
}
```
典型 BIT 型接入形式：
```cpp
auto ans = pbs(q, m,
    [&] {
        // 清空 BIT
    },
    [&](int t) {
        // 加入第 t 次修改
    },
    [&](int id) {
        // 查询当前 BIT，判断询问 id 是否满足
        return true;
    }
);
```
#### 复杂度
设一轮中：
- `rst()` 总代价为 $R$
- 执行全部 `add()` 的总成本为 $A$
- 执行全部 `ok()` 的总成本为 $C$
总时间复杂度为
$$
O((m+q+R+A+C)\log(m+2))
$$
其中 `m+q` 来自分桶和扫描
若 `add`、`ok` 均为 $O(\log n)$，且清空代价可忽略，则为  
$$
O((m+q)\log n\log m)
$$
空间复杂度为 $O(m+q)$
