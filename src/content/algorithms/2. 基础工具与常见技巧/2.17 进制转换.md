### 进制转换
---
支持 $2\sim62$ 进制整数转换，包含普通整数转进制字符串、任意长度整数的跨进制转换
- $2\sim36$ 进制：`0-9A-Z`，输入字母不区分大小写
- $37\sim62$ 进制：`0-9A-Za-z`，输入字母区分大小写
- 不依赖高精度整数类，支持负数、前导零和任意长度整数
```cpp
// ===== 字符映射 =====
int digit_value(char c, int base) {
    int x = -1;
    if ('0' <= c && c <= '9') x = c - '0';
    else if ('A' <= c && c <= 'Z') x = c - 'A' + 10;
    else if ('a' <= c && c <= 'z') x = c - 'a' + (base <= 36 ? 10 : 36);
    return x < base ? x : -1;
}
char digit_char(int x) {
    if (x < 10) return char('0' + x);
    if (x < 36) return char('A' + x - 10);
    return char('a' + x - 36);
}
// ===== 普通整数转进制 =====
string to_base(i64 x, int base) {
    bool neg = x < 0;
    u64 y = neg ? u64(-(x + 1)) + 1 : u64(x);
    string s;
    do {
        s.push_back(digit_char(y % base));
        y /= base;
    } while (y);
    if (neg) s.push_back('-');
    reverse(s.begin(), s.end());
    return s;
}
// ===== 任意长度进制转换 =====
string convert_base(const string &s, int from_base, int to_base) {
    bool neg = s[0] == '-';
    int p = (s[0] == '-' || s[0] == '+');
    while (p < int(s.size()) && s[p] == '0') ++ p;
    if (p == int(s.size())) return "0";
    vector<int> a;
    a.reserve(s.size() - p);
    for (int i = p; i < int(s.size()); ++ i) {
        a.push_back(digit_value(s[i], from_base));
    }
    if (from_base == to_base) {
        string t;
        if (neg) t += '-';
        for (int x : a) t += digit_char(x);
        return t;
    }
    vector<int> q;
    q.reserve(a.size());
    string out;
    while (!a.empty()) {
        q.clear();
        int rem = 0;
        for (int x : a) {
            int cur = rem * from_base + x;
            int d = cur / to_base;
            rem = cur % to_base;
            if (d || !q.empty()) q.push_back(d);
        }
        out += digit_char(rem);
        a.swap(q);
    }
    if (neg) out += '-';
    reverse(out.begin(), out.end());
    return out;
}
```
`to_base()` 可以单独使用，但需要 `digit_char()`；`convert_base()` 需要两个字符映射函数，不依赖 `to_base()`
#### 接口
- `digit_value(c, base)`：返回字符 `c` 在指定进制下的数值，不合法时返回 `-1`，$O(1)$
- `digit_char(x)`：返回数字 `x` 对应的字符，要求 $0\le x$ 二进制字符串
```cpp
string s = bitset<8>(42).to_string(); // "00101010"
// 二进制字符串 -> 整数 u64 x = bitset<64>("101010").to_ullong(); // 42
// 直接输出固定位宽二进制 cout << bitset<32>(42) << '\n';
```
`bitset<N>` 的宽度 `N` 必须是编译期常量。输入位数不足 `N` 时高位补零；整数转换超过指定宽度时保留低 `N` 位。`to_ullong()` 的结果若无法放入 `unsigned long long`，会抛出 `overflow_error`
若需要去除前导零，直接使用板子中的 `to_base(x, 2)` 更方便
#### 使用 `stoi` / `stoll` 转换字符串
---
适用于字符串表示的 $2\sim36$ 进制整数转换为十进制整数
```cpp
int a = stoi("101010", nullptr, 2); // 42
int b = stoi("FF", nullptr, 16);     // 255
i64 c = stoll("777", nullptr, 8);    // 511
u64 d = stoull("FFFFFFFFFFFFFFFF", nullptr, 16);
// 自动识别十进制、0 开头的八进制和 0x 开头的十六进制
int x = stoi("0xFF", nullptr, 0); // 255
````
`stoi` 返回 `int`，`stoll` 返回 `i64`，`stoull` 返回 `u64`。遇到非法输入或数值超出范围时会抛出异常；如果只转换了合法前缀，默认不会报错，可使用第二个参数取得已解析的字符数
#### 使用 `stringstream` 转换八、十、十六进制
---
```cpp
// 整数 -> 十六进制字符串
ostringstream os;
os << uppercase << hex << 255;
string s = os.str(); // "FF"

// 十六进制字符串 -> 整数
istringstream is("FF");
int x = 0;
is >> hex >> x; // 255

// 直接按八进制、十六进制输出
cout << oct << 255 << '\n'; // 377
cout << hex << 255 << '\n'; // ff
cout << dec << 255 << '\n'; // 255
```
- `dec` / `oct` / `hex`：切换十、八、十六进制
- `uppercase`：十六进制字母使用大写
- `showbase`：输出进制前缀，例如十六进制的 `0x`
- 操纵符会影响流的后续输入输出，使用后需要时应切回 `dec`
#### 使用 `from_chars` / `to_chars`
---
适用于整数与 $2\sim36$ 进制字符串之间的转换。无需构造字符串流，也不通过异常报告解析失败
整数转字符串
```cpp
char buf[70];
auto [p, ec] = to_chars(buf, buf + 70, 255, 16);
string s(buf, p); // "ff"，要求 ec == errc{}
```
字符串转整数
```cpp
string s = "FF";
i64 x = 0;
auto [p, ec] = from_chars(s.data(), s.data() + s.size(), x, 16);
bool ok = (ec == errc{} && p == s.data() + s.size());
// ok 为 true，x 为 255
```
> [!warning] `from_chars()` 不跳过前导空白、不接受前置 `+`，指定 16 进制时也不接受 `0x` 前缀。必须同时检查 `ec` 和 `p`，才能确认整个字符串合法
> 
> `to_chars()` 不附加字符串终止符 `'\0'`，默认输出小写字母，缓冲区不足时通过错误码报告
#### 任意长度整数的进制转换
---
```cpp
to_base(255, 16);               // "FF"
to_base(-255, 2);                // "-11111111"
convert_base("FF", 16, 2);      // "11111111"
convert_base("-255", 10, 16);   // "-FF"
convert_base("000FF", 16, 16);  // "FF"
convert_base("zz", 62, 10);     // "3843"
```
输入数字超过 `i64` 范围时，仍然可以使用 `convert_base()`，无需先转换为整数
#### 二进制与八、十六进制快速互转
---
对于 $2^k$ 进制，可以直接按每 $k$ 个二进制位分组。八进制每组 3 位，十六进制每组 4 位，无需使用任意长度进制转换算法
十六进制字符串转二进制字符串
```cpp
string s = "00AF", bin;
for (char c : s) {
    bin += bitset<4>(digit_value(c, 16)).to_string();
}
// bin = "0000000010101111"
```
二进制字符串转十六进制字符串
```cpp
string bin = "10101111", hex;
bin.insert(0, (4 - bin.size() % 4) % 4, '0');
for (int i = 0; i < int(bin.size()); i += 4) {
    hex += digit_char(bitset<4>(bin.substr(i, 4)).to_ulong());
}
// hex = "AF"
```
上述写法会按分组保留前导零；需要规范化整数表示时，再删除前导零即可
将每组 4 位改为 3 位、`bitset<4>` 改为 `bitset<3>`，即可处理二进制与八进制的转换
#### 复杂度
设 $L$ 为输入数字位数，$M$ 为输出数字位数，$B$ 为目标进制，$N$ 为 `bitset` 宽度

| 操作                              | 时间复杂度                  | 额外空间复杂度          |
| ------------------------------- | ---------------------- | ---------------- |
| `digit_value` / `digit_char`    | $O(1)$                 | $O(1)$           |
| `to_base`                       | $O(\log_B(\|x\|+1)+1)$ | $O(M)$           |
| `convert_base`                  | $O(LM)$，即 $O(L^2)$     | $O(L+M)$         |
| `convert_base`（进制相同）            | $O(L)$                 | $O(L)$           |
| `stoi` / `stoll` / `from_chars` | $O(L)$                 | $O(1)$（解析本身）     |
| `to_chars`                      | $O(M)$                 | $O(1)$（不计调用方缓冲区） |
| `bitset<N>::to_string()`        | $O(N)$                 | $O(N)$           |
| `二进制分组转换`                       | $O(L)$                 | $O(L)$           |
