### 位运算与二进制

#### 1到n连续按位异或和规律

设

$$
S(n)=1\oplus 2\oplus 3\oplus \cdots \oplus n
$$

则有：

$$
S(n)=
\begin{cases}
n, & n\bmod 4=0 \\
1, & n\bmod 4=1 \\
n+1, & n\bmod 4=2 \\
0, & n\bmod 4=3
\end{cases}
$$

#### Bit-Tricks

##### 异号判定（有符号整数）
```cpp
bool opposite_sign(i64 x, i64 y) { return (x < 0) != (y < 0); }
```

##### 位逆序置换（0 <= n <= 24；内存 O(2^n)）
```cpp
vector<unsigned> bit_reversal(int n) {
    assert(0 <= n && n <= 24);
    unsigned len = 1u << n;
    vector<unsigned> ans(len);
    for (unsigned i=0,j=0;i<len;++i) {
        ans[i]=j;
        if (i+1 == len) break; // 不对最后一个数继续进位，避免 k=0 死循环
        unsigned k=len>>1;
        while (j & k) { j ^= k; k >>= 1; }
        j ^= k;
    }
    return ans;
}
```

##### 枚举子掩码与超掩码（含零子掩码和掩码本身）
```cpp
template<class F> void subsets(unsigned mask, F visit) {
    for (unsigned s=mask;;s=(s-1)&mask) {
        visit(s);
        if (s==0) break;
    }
}
template<class F> void supersets(unsigned t, int n, F visit) {
    assert(0 <= n && n < 32 && t < (1u<<n));
    unsigned limit=1u<<n;
    for (unsigned s=t;s<limit;s=(s+1)|t) visit(s);
}
```

所有 n 位掩码的子掩码总数为 $\sum_{k=0}^{n}\binom nk 2^k=3^n$：
```cpp
template<class F> void all_subsets(int n,F visit) {
    assert(0 <= n && n < 32);
    for(unsigned mask=0;mask<(1u<<n);++mask)
        subsets(mask,[&](unsigned sub){visit(mask,sub);});
}
```

##### 下一个相同 popcount 的 u64（Gosper）
没有更大同 popcount 值时返回 false，并保持 x 不变；x=0 也返回 false。
```cpp
bool next_same_popcount(u64& x) {
    if (!x) return false;
    u64 low=x&(~x+1), r=x+low;
    if (!r) return false;
    x=r|(((r^x)>>2)/low);
    return true;
}
```

#### x和y位运算中1的个数

```cpp
assert(__builtin_popcount(x ^ y) == __builtin_popcount(x) + __builtin_popcount(y) - 2 * __builtin_popcount(x & y));
assert(__builtin_popcount(x | y) == __builtin_popcount(x) + __builtin_popcount(y) - __builtin_popcount(x & y));
assert(__builtin_popcount(x & y) == (__builtin_popcount(x) + __builtin_popcount(y) - __builtin_popcount(x ^ y)) / 2);
```
因为$2 \times \text{popcount}(x \mathbin{\&} y)$ 必然是偶数，所以 $x \oplus y$ 中 1 的个数的奇偶性，完全取决于 $x$ 和 $y$ 中 1 的个数之和。
如果两者同奇偶，那么 $x \oplus y$ 结果中 1 的个数必为偶数；否则为奇数。

#### 三个有关位运算的有用性质

1. **加法等式**：`a + b = (a ^ b) + 2 * (a & b)`
   > *`a ^ b` 是不带进位的按位加法，`a & b` 找出均是1的位，乘以2代表进位左移1位*
2. **按位或等式**：`a | b = (a ^ b) + (a & b)`
   > *按位或等于“两数不同的位”加上“两数同为1的位”*
3. **由等式1、2可以推得** `a + b = (a & b) + (a | b)`
   > *证明：*
*将等式 (1) 中的 `2 * (a & b)` 拆开：*
*`a + b = [(a ^ b) + (a & b)] + (a & b)`*
*把等式 (2) 代入方括号中，直接得到：*
*`a + b = (a | b) + (a & b)`*

---
由于二进制运算独立作用于每一位，我们只需要证明在任意单个比特位上，上述等式成立即可，因此也可以在固定的一位上枚举四种情况证明上述三种性质，在此不再列出

#### 异或的各种性质可以使用按位拆分，使用 mod 2 加法的方式得出

异或的各种性质可以使用按位拆分，使用 mod 2 加法的方式得出。

比如说这个分配律。

$$c_1 P_1 \oplus c_2(P_1 \oplus P_2) \oplus c_3(P_2 \oplus P_3) \oplus \dots \oplus c_k(P_{k-1} \oplus P_k) = 0$$

$$(c_1 \oplus c_2)P_1 \oplus (c_2 \oplus c_3)P_2 \oplus (c_3 \oplus c_4)P_3 \oplus \dots \oplus (c_{k-1} \oplus c_k)P_{k-1} \oplus c_k P_k = 0$$

对于二进制中的任意一位 $x$，都有

$$c_1 P_{1,x} + c_2(P_{1,x} + P_{2,x}) + \dots + c_k(P_{k-1,x} + P_{k,x}) \equiv 0 \pmod 2$$

$$(c_1 + c_2)P_{1,x} + (c_2 + c_3)P_{2,x} + \dots + (c_{k-1} + c_k)P_{k-1,x} + c_k P_{k,x} \equiv 0 \pmod 2$$

那么不难得出上面的结论。

#### 快速求 n个数的 popcount 和

一种以 $O(\log n)$ 求 $\sum_{i=1}^{n} \operatorname{popcount}(i)$ 的方法

逐位统计：令 $N=n+1$，第 $k$ 位贡献为
$$\lfloor N/2^{k+1}\rfloor 2^k+\max(0,N\bmod 2^{k+1}-2^k).$$
对 $k=0,\ldots,63$ 求和，使用 u128 保存 n+1 和结果。

```cpp
// 返回 sum_{i=0}^n popcount(i)，支持整个 u64 范围。
u128 popcount_sum(u64 n) {
    u128 ans = 0, count = u128(n) + 1;
    for (int k = 0; k < 64; ++k) {
        u128 half = u128(1) << k, period = half * 2;
        ans += (count >> (k + 1)) * half;
        u128 rem = count & (period - 1);
        if (rem > half) ans += rem - half;
    }
    return ans;
}
```

#### 按操作对二进制位的影响划分过程

##### 适用场景

当操作包含加一、异或、或、与等位运算时，整体状态很难维护，但每一位或低若干位的变化规律清楚，可以按二进制位划分过程。

##### 核心观察

在二进制下，$+1$ 会把末尾连续的 $1$ 变成 $0$，并向更高一位进位。也就是说，低位状态会经历类似：

$$
s \to 0 \to t
$$

的阶段。

因此，可以把“完整数值变化”拆成“低 $i$ 位如何从初态变为终态”的问题，并维护是否产生进位、是否使用某些异或操作等状态。

##### 常见状态

- 当前处理到第几位；
- 初态来自原数还是 $0$；
- 终态来自目标数还是 $0$；
- 已使用的操作集合；
- 是否产生进位。

##### 易错点

- 加法进位会影响更高位，不能逐位完全独立处理。
- 位运算操作如果作用于所有位，需要记录其在低位上的整体效果。
- 位数上界要覆盖所有可能值，例如 $2^{40}$ 就要处理到第 $40$ 位。

#### 整数拍扁成 01 前缀表示差值

##### 适用场景

当需要处理非负整数之间的绝对差，并且值域不大时，可以把整数展开为 01 前缀。

##### 核心思路

把整数 $x$ 表示为长度足够的串 $f_x=\underbrace{11\cdots1}_{x}00\cdots0$。则两个数的差值可以转化为两个 01 串在某些位上的不同数量，从而用 bitset 优化批量计算。

##### 使用条件

- 转化前后的信息必须等价，不能丢失题目真正需要维护的量。
- 通常适用于该结构能够被预处理、离线排序、分组维护或用数据结构快速合并的场景。

##### 易错点

该方法依赖值域长度，值域过大时不可行。

#### 最大化多重集异或和的求和

给定一个序列，两个多重集（初始是空的），把每个数划分到两个**多重集**中，使得两个多重集的`xor 和` 再相加，结果最大

根据 $A + B = (A \oplus B) + 2(A \textbf{ and } B) = S + 2 \cdot (A \textbf{ and } B)$
实际上，考虑 $S = \bigoplus_{i = 1}^{n} a_i$，这是基础值，是确定的，只需要最大化 $A \textbf{ and } B$

- 选出一个子集 $A$，最大化 $A \textbf{ and } B$，而 $S = A \oplus B$
- 注意到 $S$ 为 `1` 的位一定形如 `(a(i), b(i)) = (1, 0)`，它的 $\&$  运算结果一定是 `0` 
  而 $S$ 为 `0` 的位呢，形如 `(1, 1) or (0, 0)`，它的 $\&$ 运算结果取决于 $a$ 这一位的值

**综上所述**，若 $A \oplus B = S$，那么 $A \ \& \ B = A \ \& \ (\sim S)$

这个问题就转化成，给定 $S$ ，给定 $a[1\sim n]$，选一个子集构成 $A$，使得 $A \textbf{ and } (\sim S)$  最大
实际上就是最大化 $\bigoplus_{i = 1}^{m} (a_i \textbf{ and } (\sim S))$

这个让每个数 $a_i = a_i \ \& (\sim S)$，是标准的**选取一个子集，使其异或和最大**的问题，这就成了线性基模版题了

#### 构造相邻二进制数仅相差一位的数组

想要实现这样的数组,就是在构造**格雷码** , 这里有一个简单的构造方式
构造包含 $2^n$ 个元素的 $n$ 位格雷码数组 $a$（$0 \le i < 2^n$）
$$
a_i = i\oplus (i>>1)

**应用**
1. 构造**相邻异或值之和最小**的数组

3. 格雷码也可以看作上是 $n$ 维超立方体图的一条**哈密顿路径**

#### 求连续 111..1 段的个数

给定一个数，求有多少个连续全 1 段，比如 11...1 0...0 111..1，`cnt[ 连续全 1 段 ] = 2` 
这个问题，等价于问**对每一位考虑，有多少个相邻的 `01`**

这很重要，因为这可以转化成**状态机**，相邻位就只有 `(00, 01, 10, 11)`，可以用这四种状态来表示

比如给你一个序列，然后若干次操作，每次操作$\ \&, \oplus , |$ 上一个随便的数，比如说 $x$
然后统计每个数**连续全 1 段**的**和**，怎么做呢？
总不能对每个询问挨个去暴力加吧，会超时
考虑**维护整体的和，以及操作之后每一位的状态变化**

- 你只需要维护每一个位的`(00, 01, 10, 11)`四种状态
比如 `cnt(k, "00")`表示第 `(k+1, k)` 位的状态是 `00` 的数有多少个？

- 比如位运算，$\oplus x$，你只要拿 $x$ 去对齐第 $k$ 位，看看 $x$ 的 `(k+1, k)` 位组成的状态是多少？
那么是 `mask =  x >> k & 3`，是吧？

- 然后就考虑转移，枚举 `4` 种相邻位的状态，`cnt(k, sta)`
令 `nsta = sta ^ mask`，实际上，所有原来是 `sta` 的状态都变成了 `nsta`，自然对应的 `cnt`个数也要相等
于是令 `ncnt[nsta] = cnt[k, sta]`，四个状态都枚举之后
更新 `cnt[k] = ncnt`，继续考虑更高的位

最高位前补一个 0，才能统计以最高位 1 开头的段。OR/AND 的状态转移可能多对一，必须 ncnt[nsta] += cnt[k,sta]；只有 XOR 的置换转移可以直接赋值。
