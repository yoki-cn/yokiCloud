### 2.15 贪心定式与证明

> 所有结论均须同时满足其模型约束；以下默认整数运算不会溢出。复杂度中的 $n$ 表示输入元素个数。

#### 2.15.1 Huffman 与最优合并

##### 二叉 / $k$ 叉最优合并

**问题。** 给定 $n$ 个非负权值 $w_1,\ldots,w_n$。每次将至多 $k$ 个当前对象（$k\ge2$）合并成一个新对象，新权值等于这些对象的权值之和，本次操作的代价也等于这个和。要求最终合并成一个对象，**最小化总代价**。普通合并果子对应 $k=2$；最优前缀码对应构造最小加权路径长度的树。

**贪心方法。** 每次取当前权值最小的 $k$ 个对象进行合并，把新权值重新加入小根堆。对于 $n>1$ 的 $k$ 叉版本，为统一每步取恰好 $k$ 个，先补充权值为 $0$ 的虚叶，使 $(n-1)\bmod(k-1)=0$。当 $k>n$ 时，可将 $k$ 限制为 $n$。

该模型等价于最小化叶子的加权深度和：

$$
\operatorname{cost}=\sum_{u\text{ 为原叶}}w_u\,\operatorname{depth}(u).
$$

**简证。** 在某棵最优满 $k$ 叉树中，最小的 $k$ 个权值可以安排在最深层的一组同父兄弟上：若小权叶比大权叶浅，交换二者不会增大代价。将这 $k$ 个兄弟收缩成权值为其和的新叶，其他叶深度不变，问题缩小，归纳成立。虚叶权值为零，补满树不会改变原叶的代价。

**注意事项。** $n\le1$ 时总代价为 $0$；所有权值都要求非负。若题目规定每步**必须恰好合并 $k$ 个原有对象且不允许补零**，应先检查可行性，不能把虚叶视为真实对象。若要求只能合并原序列中**相邻**对象，则不属于普通 Huffman 问题。

##### 仅计算最优合并代价

```cpp
// 传入非负权值；k >= 2。无需构造树时只复制本函数。
i64 huffman_cost(vector<i64> a, int k = 2) {
    int n = a.size();
    if (n <= 1) return 0;
    assert(k >= 2);
    k = min(k, n);
    int pad = (k - 1 - (n - 1) % (k - 1)) % (k - 1);
    priority_queue<i64, vector<i64>, greater<>> pq;
    for (i64 x : a) pq.push(x);
    while (pad --) pq.push(0);

    i64 ans = 0;
    while (pq.size() > 1) {
        i64 sum = 0;
        for (int j = 0; j < k; ++ j) {
            sum += pq.top();
            pq.pop();
        }
        ans += sum;
        pq.push(sum);
    }
    return ans;
}
```

##### 需要构造 Huffman 树

```cpp
struct Huffman {
    vector<i64> w;
    vector<vector<int>> ch;
    vector<int> fa;
    int root = -1, leaves = 0;
    i64 cost = 0;

    explicit Huffman(const vector<i64> &a, int k = 2) : leaves(a.size()) {
        assert(k >= 2);
        int n = a.size();
        if (!n) return;
        k = min(k, n);
        priority_queue<pair<i64, int>, vector<pair<i64, int>>, greater<>> pq;
        auto add = [&](i64 x) {
            int id = w.size();
            w.push_back(x);
            ch.emplace_back();
            fa.push_back(-1);
            pq.push({x, id});
        };
        for (i64 x : a) add(x);
        if (n > 1) {
            int pad = (k - 1 - (n - 1) % (k - 1)) % (k - 1);
            while (pad --) add(0);
        }
        while (pq.size() > 1) {
            vector<int> son;
            i64 sum = 0;
            for (int j = 0; j < k; ++ j) {
                auto [x, id] = pq.top();
                pq.pop();
                sum += x;
                son.push_back(id);
            }
            int u = w.size();
            w.push_back(sum);
            ch.push_back(move(son));
            fa.push_back(-1);
            for (int v : ch[u]) fa[v] = u;
            cost += sum;
            pq.push({sum, u});
        }
        root = pq.top().second;
    }
};
```

**接口说明。** 仅求代价时调用 `huffman_cost(a, k)`；需要编码或输出合并方案时用 `Huffman(a, k)`，其中 `cost` 为总代价，`root` 为根，`ch[u]`、`fa[u]` 分别为孩子和父亲，原始叶子编号为 `[0, leaves)`，新添虚叶与内部节点紧随其后。

**复杂度。** 两种实现均为 $O(n\log n)$ 时间、$O(n)$ 空间（这里 $k$ 已限制为不超过 $n$）。

#### 2.15.2 区间贪心

##### 最多选择多少个互不相交区间

**问题。** 给定 $n$ 个非空半开区间 $[l_i,r_i)$，选择尽可能多的区间，使选出的区间两两不相交。端点相接视为不相交。

**贪心方法。** 按右端点升序排列，每次选择第一个满足 $l\ge\mathrm{last\_r}$ 的区间，并更新最后一个所选区间的右端点。

**简证（交换）。** 取任意最优方案的第一个区间，将其替换成所有区间中结束最早的区间，后续区间仍然能放下，最优数量不减；归纳处理剩余区间。

**变式。** 最少删除区间使剩下两两不交 = $n$ 减去最多能选择的区间数。带价值的最大权独立区间集合通常需要 DP，不能仅按右端点贪心。

##### 最少选多少点刺穿全部区间

**问题。** 给定 $n$ 个非空闭区间 $[l_i,r_i]$，在数轴上选择尽可能少的点，使每个区间都包含至少一个所选点。

**贪心方法。** 按区间右端点 $r$ 升序排列，遇到尚未覆盖的区间时，直接选择它的右端点 $r$。

**简证（交换）。** 对最先未覆盖区间，任何可行解都要在其中选一个点；将所选点右移到 $r$ 不会失去对之后尚未处理区间的覆盖（这些区间的右端点都不早于 $r$）。

**边界。** 区间必须是闭区间或整数点意义下的闭区间。若是实数半开 $[l,r)$，$r$ 本身不属于区间，不能直接在 $r$ 选点。

##### 用最少区间覆盖目标 $[L,R)$

**问题。** 给定目标半开区间 $[L,R)$ 和若干可用区间 $[l_i,r_i)$，选出最少个数的可用区间，使它们的并集覆盖整个目标区间；若无法覆盖则报告无解。

**贪心方法。** 按左端点升序排列。当前已经覆盖到 `cur` 时，在全部满足 $l\le\mathrm{cur}$ 的候选区间中取右端点最大的一个，将 `cur` 向右推进；若无法严格推进则无解。

**简证（交换）。** 任意合法覆盖下一步都必须选一个左端点不超过 `cur` 且向右延伸的区间，改选能延伸最远者只会扩大后续可覆盖范围，不增区间数。

##### 最少资源容纳所有区间

**问题。** 给定 $n$ 个任务的占用时段 $[l_i,r_i)$，每个任务必须完整执行，同一份资源不能同时执行重叠任务。求同时完成所有任务至少需要多少份资源。

**贪心方法。** 按左端点排序；用小根堆维护当前正在占用资源的任务右端点，处理新区间前弹出所有 $r\le l$ 的已结束区间，再加入当前右端点。答案是堆大小的历史最大值。

**简证（下界达到）。** 任意时刻重叠 $d$ 个区间至少需要 $d$ 份资源；该算法恰好只在所有已有资源都被占用时新开资源，使用资源数始终不超过最大重叠数。

**边界。** 与 18.2.1 相同，半开区间允许一个区间结束时另一个立即开始；$[l,r]$ 闭区间则不能这样复用端点。

##### 区间三件套

```cpp
// [l, r)：最多不相交区间个数，要求 l < r
i64 max_disjoint(vector<pair<i64, i64>> a) {
    sort(a.begin(), a.end(), [](auto x, auto y) {
        return tie(x.second, x.first) < tie(y.second, y.first);
    });
    i64 ans = 0, last = numeric_limits<i64>::min();
    for (auto [l, r] : a) {
        if (l >= last) {
            ++ ans;
            last = r;
        }
    }
    return ans;
}

// [l, r]：最少打点个数及具体选点，要求 l <= r
vector<i64> stab_intervals(vector<pair<i64, i64>> a) {
    sort(a.begin(), a.end(), [](auto x, auto y) {
        return tie(x.second, x.first) < tie(y.second, y.first);
    });
    vector<i64> ans;
    for (auto [l, r] : a) {
        if (ans.empty() || ans.back() < l) ans.push_back(r);
    }
    return ans;
}

// [l, r)：覆盖 [L, R) 最少区间数；无解 -1；L >= R 时返回 0
int min_interval_cover(vector<pair<i64, i64>> a, i64 L, i64 R) {
    if (L >= R) return 0;
    sort(a.begin(), a.end());
    int n = a.size(), i = 0, ans = 0;
    i64 cur = L;
    while (cur < R) {
        i64 far = cur;
        while (i < n && a[i].first <= cur) {
            far = max(far, a[i].second);
            ++ i;
        }
        if (far == cur) return -1;
        cur = far;
        ++ ans;
    }
    return ans;
}
```

**复杂度。** 排序均为 $O(n\log n)$，扫描 $O(n)$；空间 $O(n)$（排序缓冲及答案）。

#### 2.15.3 单机任务调度

以下模型均假设只有一台机器、全部任务在时刻 $0$ 可用、任务没有前置依赖且不可抢占。$p_i$ 表示处理时间，$w_i$ 表示任务权值，$d_i$ 表示截止时间，$C_i$ 表示完成时刻。**目标不同，贪心方法也不同。**

#####  全部任务必须执行：最优排序

**问题。** 给定 $n$ 个任务，必须安排全部任务执行，要求分别最小化所有完成时刻之和、带权完成时刻之和，或最大延误。每种目标的最优顺序如下。

| 目标 | 贪心方法 | 简证 |
|---|---|---|
| 最小化 $\sum_i C_i$ | 按 $p_i$ 升序（SPT） | 交换相邻两项，短任务在前不增大总完成时间 |
| 最小化 $\sum_i w_i C_i$ | 按 $p_i/w_i$ 升序（Smith 法则） | $i$ 在 $j$ 前更优当且仅当 $p_iw_j\le p_jw_i$ |
| 最小化 $\max_i(C_i-d_i)$ | 按 $d_i$ 升序（EDD） | 交换截止时间逆序的相邻两项，不增大最大延误 |

**边界。** 上述 $p_i,w_i$ 非负；Smith 法则对 $w_i>0$ 的任务用交叉乘积 `i128(p[i]) * w[j] < i128(p[j]) * w[i]` 比较，避免浮点误差。零权任务安排在末尾；$p_i=0,w_i>0$ 的任务在最前。最大延误 $\max_i(C_i-d_i)$ 可以为负；EDD 对最大拖期 $\max_i\max(0,C_i-d_i)$ 也最优，但两者目标值不同。

#####  任意耗时：最多按时完成多少任务

**问题。** 给定处理时间 $p_i\ge0$、截止时间 $d_i\ge0$ 的任务，可以放弃部分任务，要求**最大化能够在各自截止时间前完成的任务数量**（不是总收益）。

**贪心方法。** 按截止时间升序枚举任务，暂时加入当前任务；如果已选任务总耗时超过当前截止时间，则从已选任务中**删除耗时最长的一个**，用大根堆支持反悔。

**简证。** 截止时间升序处理时，当前所选任务可以按此顺序执行。若新加入的任务导致超时，就必须在当前候选任务中舍弃至少一个；删除耗时最长者能在保留相同任务数的情况下腾出最多的时间。结合归纳交换论证，保留最有利于后续扩展的可行解，最终完成任务数最大。

**注意事项。** 本策略允许舍弃任务，但不允许拆分、并行或存在额外前置约束；存在释放时间、不同收益或其他资源限制时不能直接套用。

###### Moore–Hodgson 反悔调度

```cpp
// 任务 (duration, deadline)，均非负；返回选中的原始下标，按 deadline 排好
vector<int> max_ontime_jobs(const vector<pair<i64, i64>> &job) {
    int n = job.size();
    vector<int> ord(n);
    iota(ord.begin(), ord.end(), 0);
    sort(ord.begin(), ord.end(), [&](int i, int j) {
        return tie(job[i].second, i) < tie(job[j].second, j);
    });
    priority_queue<pair<i64, int>> pq;
    vector<char> use(n);
    i64 sum = 0;
    for (int id : ord) {
        auto [p, d] = job[id];
        pq.push({p, id});
        sum += p;
        use[id] = true;
        if (sum > d) {
            auto [len, j] = pq.top();
            pq.pop();
            sum -= len;
            use[j] = false;
        }
    }
    vector<int> res;
    for (int id : ord) if (use[id]) res.push_back(id);
    return res;
}
```

##### 单位耗时：截止时间内收益最大
**问题。** 每个任务恰好占用一个整数时间槽，任务 $i$ 必须安排在不晚于 $d_i$ 的时槽，完成后获得收益 $w_i$；允许不执行某些任务，要求**最大化总收益**。最早时间槽为 $1$。

**贪心方法。** 按收益从大到小处理正收益任务，把每个任务安排到不晚于截止时间的**最晚空闲时槽**。用并查集寻找不超过指定时槽的最大空位。

**简证。** 可安排任务集合满足交换性质：若高收益任务能够加入某可行集合，则可用它替换某个收益不更高的已选任务而不减总收益。放入最晚空位不会减少此前时槽的可用性，故可继续选择后续任务。

**注意事项。** 必须是单位耗时且时槽离散；如果每个任务耗时不同，不能用这份收益贪心。截止时间大于 $n$ 时可截断到 $n$，因为总共最多执行 $n$ 个任务。

###### 并查集维护最晚空闲时槽

```cpp
// job[i] = {deadline, profit}；一个任务耗时 1，最早时槽为 1
// 返回 {最大收益, 各时槽执行的原下标}；slot[0] 为 -1
pair<i64, vector<int>> schedule_unit_profit(vector<pair<int, i64>> job) {
    int n = job.size();
    vector<int> ord(n), fa(n + 1), slot(n + 1, -1);
    iota(ord.begin(), ord.end(), 0);
    iota(fa.begin(), fa.end(), 0);
    auto find = [&](int x) {
        while (fa[x] != x) {
            fa[x] = fa[fa[x]];
            x = fa[x];
        }
        return x;
    };
    sort(ord.begin(), ord.end(), [&](int i, int j) {
        return tie(job[i].second, i) > tie(job[j].second, j);
    });
    i64 ans = 0;
    for (int id : ord) {
        auto [d, w] = job[id];
        if (d <= 0 || w <= 0) continue;
        int t = find(min(d, n));
        if (!t) continue;
        ans += w;
        slot[t] = id;
        fa[t] = find(t - 1);
    }
    return {ans, slot};
}
```

**复杂度。** 上述两份任务选择实现均为 $O(n\log n)$ 时间、$O(n)$ 空间；三种排序型调度排序为 $O(n\log n)$。

#### 2.15.4 堆上动态候选与最少次数

##### 最少加油次数（油箱无限容量）

**问题。** 给定起点、终点距离 $D$、初始油量，以及沿途若干加油站的位置和可提供油量。每单位距离耗油 $1$，油箱容量无限，每站最多使用一次；求到达终点的**最少加油次数**，无法到达则返回无解。

**贪心方法。** 按位置从小到大考虑加油站。行驶到下一站或终点所需的油量不足时，从此前经过的站点中选择**可提供油量最多**的站补加，使用大根堆维护候选。

**证明（交换）。** 在必须补一次油的位置，换用此前可选站中油量最大的补给，不增加次数并使剩余可达距离不短于任何其他选择。将选择视为“之前经过站点时已经加油”，不会影响可达性；归纳成立。

```cpp
// stations[i] = {从起点的距离, 可取得的油量}；target >= 0
// 初始燃料 fuel，可获得的额外油量和耗油量均非负，单位距离耗油 1
int min_refuel_stops(vector<pair<i64, i64>> stations, i64 target, i64 fuel) {
    vector<pair<i64, i64>> a;
    for (auto [x, v] : stations) {
        if (0 <= x && x <= target) a.push_back({x, v});
    }
    a.push_back({target, 0});
    sort(a.begin(), a.end());
    priority_queue<i64> pq;
    i64 prev = 0;
    int ans = 0;
    for (auto [x, v] : a) {
        fuel -= x - prev;
        while (fuel < 0) {
            if (pq.empty()) return -1;
            fuel += pq.top();
            pq.pop();
            ++ ans;
        }
        pq.push(v);
        prev = x;
    }
    return ans;
}
```

**边界。** 油箱容量没有上限；站点油量不可拆分限制不影响上式（加整份即可），但若有油箱容量、油价、每站限额或必须现场决定加多少，结论可能失效。`fuel` 与最终可达距离可能超出 `i64` 时需改用更大类型。

##### 最少跳跃次数（从下标 $0$ 跳到 $n-1$）

**问题。** 给定非负数组 $a$，从下标 $0$ 出发，在位置 $i$ 可以前进 $1$ 至 $a_i$ 步，求到达 $n-1$ 的最少跳跃次数；不可达返回 $-1$。

**贪心方法。** 扫描当前跳跃次数可到达的整层下标 $[L,R]$，计算这层所有位置能扩展出的最大右端点 $\max(i+a_i)$，将其作为下一层边界；无法向右扩展则无解。

**简证（BFS 分层）。** 使用 $t$ 次跳跃可到达的下标恰形成从起点起的连续前缀；其右端点由上一步可达点的最大延伸确定。这是隐式图的 BFS 分层，不是“每次只选择跳得最远的下一格”。

```cpp
// 非负步长；若不可达返回 -1。空数组返回 0。
int min_jumps(const vector<int> &a) {
    int n = a.size();
    if (n <= 1) return 0;
    int ans = 0, r = 0, far = 0;
    for (int i = 0; i < n - 1; ++ i) {
        if (i > r) return -1;
        far = max(far, int(min<i64>(n - 1, i64(i) + a[i])));
        if (i == r) {
            if (far == r) return -1;
            r = far;
            ++ ans;
            if (r == n - 1) break;
        }
    }
    return ans;
}
```

##### 气站环路：最低前缀和确定起点

**问题。** 给定一个环上每站的供油量 $\mathrm{gas}_i$ 和从该站到下一站的耗油量 $\mathrm{cost}_i$，油箱无上限、初始燃料为 $0$；求是否存在出发站，使车辆按固定方向恰好绕环一圈。

**贪心方法。** 令净增量 $b_i=\mathrm{gas}_i-\mathrm{cost}_i$。若 $\sum_i b_i<0$ 则无解；否则令 $s_0=0$、$s_{i+1}=s_i+b_i$，取 $s_0,\ldots,s_{n-1}$ 的一个最小值位置 $k$，从站 $k$ 出发一定可行。

**简证。** 从最小前缀之后开始，未绕回的相对前缀和都非负；绕回后的相对前缀和等于 总和加上某个更早的前缀和，再减去最小前缀和，也非负。总和为负则不可能完成全环。

#### 2.15.5 排序、配对与数值结论

##### 重排不等式

**问题。** 给定两个长度相同的数组，只能重排其中一个数组，要求求出元素逐项相乘之和的最大值、最小值。

**贪心方法。** 最大值同向排序后配对，最小值反向排序后配对。对非降数组 $a_0,\dots,a_{n-1}$ 和 $b_0,\dots,b_{n-1}$：

$$
\sum_i a_i b_{n-1-i}\;\le\;\sum_i a_i b_{\pi(i)}\;\le\;\sum_i a_i b_i.
$$

**简证（去逆序）。** 当 $a_i\le a_j$、$b_x\le b_y$ 时，顺序配对相对于交叉配对多出 $(a_j-a_i)(b_y-b_x)\ge0$；逐个消除配对逆序即可。元素可以为负；仅需两数组都按同一方向排序。

##### 最小化两列的绝对差之和

**问题。** 给定两个长度相同的数组 $a,b$，建立一一匹配，最小化所有匹配对绝对差之和。

**贪心方法。** 将两数组分别升序排序，按相同下标匹配：

$$
\min_{\pi}\sum_i |a_i-b_{\pi(i)}|=\sum_i|a_i^\uparrow-b_i^\uparrow|.
$$

**简证（消交叉）。** 对 $a\le b$、$c\le d$，满足 $|a-c|+|b-d|\le|a-d|+|b-c|$；因此交换交叉匹配边不会变坏。

##### 最小化最大配对和

**问题。** 给定长度相同的两个数组 $a,b$，建立一一匹配，要求最小化所有匹配对之和的最大值 $\max_i(a_i+b_{\pi(i)})$。同一数组元素两两配对也是常见变式（此时数组长度为偶数）。

**贪心方法。** 将一个数组升序、另一个降序排序，小配大；若是同一个数组，则反复将最小元素与最大元素配对。

**简证。** 若 $a\le b,\ c\le d$ 却顺序配成 $(a,c),(b,d)$，换成 $(a,d),(b,c)$ 后，两组新和都不超过原来的较大者 $b+d$，反复交换即可。

##### 中位数最优、平均数最优、极差中心

**问题。** 给定实数序列 $a_i$，选择同一个值 $x$，使所有元素到 $x$ 的某种距离总量（绝对差、平方差、最大绝对差）最小。

**贪心方法与最优结论。** 根据题目具体的目标函数分别选择中位数、均值或极值中点：

- $\min_x\sum_i|a_i-x|$：任意中位数最优；偶数长度时两中位数之间均最优。证明：函数在相邻样本点间的斜率为“左侧数目 - 右侧数目”，穿过中位数时由负转正。
- $\min_x\sum_i w_i|a_i-x|$（$w_i\ge0$）：取**加权中位数**，即左右侧权值都不超过总权值的一半的 $x$。证明同上，把数量换成权值。
- $\min_x\sum_i(a_i-x)^2$：取算术平均数；若 $x$ 必须为整数，检查均值的上下取整。证明：展开平方或令导数为零。
- $\min_x\max_i|a_i-x|$：取 $\frac{\min_i a_i+\max_i a_i}{2}$，最优值 $\frac{\max_i a_i-\min_i a_i}{2}$；若 $x$ 整数，取中点附近的整数。证明：最远距离至少为极差的一半，取中点达到下界。

##### 已排序数轴上两两距离之和

**问题。** 给定数轴上的 $n$ 个点，快速求所有无序点对的距离之和 $\sum_{i<j}|a_i-a_j|$。

**方法。** 将点按位置升序排序，按每个点作为较大数或较小数的次数统计贡献。设 $a_0\le\cdots\le a_{n-1}$：

$$
\sum_{0\le i<j<n}|a_j-a_i|=\sum_{i=0}^{n-1}(2i-n+1)a_i.
$$

**简证（贡献计数）。** 每个 $a_i$ 以正号出现在 $i$ 对中，以负号出现在 $n-1-i$ 对中。

##### 定和正整数乘积最大

**问题。** 把整数 $S\ge n$ 拆成恰好 $n$ 个正整数之和，要求最大化这 $n$ 个数的乘积。

**贪心方法。** 尽量均分总和，得到的数两两差至多为 $1$；设 $q=\lfloor S/n\rfloor,\ r=S\bmod n$，最优乘积为 $q^{n-r}(q+1)^r$（可能需高精度）。

**简证。** 若 $a+2\le b$，将 $(a,b)$ 改成 $(a+1,b-1)$，乘积增加 $b-a-1>0$；反复均衡直至差不超过 1。允许零、负数或对每个元素另有限制时，要重新判断。

##### 分数背包

**问题。** 给定背包容量 $W\ge0$，每件物品重量 $m_i>0$、价值 $v_i\ge0$，允许只取某件物品的一部分且价值按取用比例计算，求最大总价值。

**贪心方法。** 按单位重量价值 $\frac{v_i}{m_i}$ 从大到小取，最后一件可以只取部分。

**简证。** 若先取了低密度物品，却仍有更高密度未取满，则交换等重量的两份可以提高收益。

**边界。** 0/1 背包中整件不可分割，按单位价值排序不保证最优；需要 DP 或其他算法。

##### 整除链硬币体系

**问题。** 给定面额严格递增的硬币 $c_0=1,c_1,\ldots$，满足 $c_i\mid c_{i+1}$，每种硬币数量无限；求凑出非负整数 $X$ 的最少硬币数。

**贪心方法。** 从面额最大者开始尽量取，余数继续由较小面额凑出。

**简证。** $c_{i+1}/c_i$ 个 $c_i$ 可以替换为一个 $c_{i+1}$ 而严格减少硬币数，故较小面额数量在最优方案中可规范化。

**边界。** 对一般面额不成立，例如面额 $\{1,3,4\}$ 凑 $6$，取 $4+1+1$ 是 3 枚，最优 $3+3$ 是 2 枚。

#### 2.15.6 字符串与字典序构造

##### 固定长度的字典序最小子序列

**问题。** 给定长度为 $n$ 的字符串 $s$，必须保留恰好 $k$ 个字符并保持原有相对顺序，要求得到**字典序最小**的长度为 $k$ 的子序列。

**贪心方法。** 用单调栈维护当前答案，最多删除 $n-k$ 个字符。遇到较小字符时，只要还有删除额度，就不断弹出栈顶更大的字符；遍历结束后截取前 $k$ 个字符。

**简证。** 在仍能补齐剩余长度的前提下，尽量让最早的尚未确定位置更小，必优于保留一个更大的字符。操作对每个字符至多进出栈一次。

```cpp
string min_subsequence(const string &s, int k) {
    int n = s.size();
    assert(0 <= k && k <= n);
    int rem = n - k;
    string st;
    for (char c : s) {
        while (rem && !st.empty() && st.back() > c) {
            st.pop_back();
            -- rem;
        }
        st.push_back(c);
    }
    st.resize(k);
    return st;
}
```

**变式。** 删除 $k$ 个十进制数字使**数值**最小：保留 $n-k$ 个数字按同样方法求最小序列，最后去掉前导零；若结果全为零或空，则输出 $0$。若题目要求结果固定长度、禁止前导零或要求恰好若干非零数字，必须调整可行性判断。

##### 字典序最小拓扑序

**问题。** 给定一张有向无环图（DAG），在所有满足依赖先后顺序的拓扑排序中，找出按顶点编号比较时**字典序最小**的那个。

**贪心方法。** 每次从当前入度为 $0$ 的顶点中取编号最小者（小根堆），将其加入答案并删除其出边。

**简证。** 任何合法拓扑序的下一点都必须是入度为 0 的点，选最小可行首点使当前位最优；余下仍是一个 DAG，归纳。

**边界。** 图存在环时不存在完整拓扑序。要求字典序最大的拓扑序改用大根堆。普通队列只能得到某种拓扑序，不保证字典序最小。

#### 2.15.7 拟阵贪心（可行集合的交换性质）

**问题。** 给定有限元素集 $E$，每个元素具有权值，并规定哪些子集可行。要求从中选择一个**大小达到最大可能值**的可行子集（称为基），并使所选元素权值之和最大。何时可以直接按权值从大到小选择？

**贪心方法。** 若可行集合族构成**拟阵**，即同时满足以下两个条件，则将元素按权值降序考虑，只要加入后仍可行就选入，最终得到最大权基。

- **遗传性：** 任一可行集的所有子集仍然可行。
- **交换性：** 若 $A,B$ 可行且 $|A|<|B|$，则存在 $e\in B\setminus A$，使 $A\cup\{e\}$ 仍然可行。

**简证。** 由交换公理，每当贪心选择一项较大权值的可行元素时，可以将某个最优基中的相应元素换成它，仍保持可行且不减小权和。逐步交换，最终使一个最优基与贪心所选基完全一致。

**例子。** “至多选择 $k$ 个元素”对应均匀拟阵；“每种类别最多选择给定数量”对应划分拟阵；“单位耗时任务必须在各自截止时间前完成”也具有相应的交换性质。

**注意事项。** 上面保证的是**最大权基**（固定最大可行元素数）。如果允许选任意数量且只最大化权值总和，应跳过非正权元素；若选出的集合不需要达到最大基数，则不能把负权元素强行选进去。一般的 $0/1$ 背包约束不构成拟阵，不能只按价值或密度排序贪心。

#### 2.15.8 反例速查（容易误判成贪心）

| 想当然的策略 | 反例 / 应用边界 |
|---|---|
| 带权区间选结束最早的 | $[0,2)$ 权 100；$[0,1)$、$[1,2)$ 权各 1。结束早贪心仅得 2，应区间 DP |
| 0/1 背包按价值密度排序 | 容量 50；(重量,价值) 为 $(10,60),(20,100),(30,120)$，密度法取前两件仅 160，最优 220 |
| 任意硬币体系先拿最大面额 | $\{1,3,4\}$ 凑 6，贪心需 3 枚而最优 2 枚 |
| Huffman 用于必须相邻合并 | 例如 $(1,100,1)$，任意合并最优总代价 104；只能相邻合并最优总代价 203 |
| 单机任务全部按最短耗时排列，总能按时做最多任务 | 任务 $(p,d)$：$(2,2),(1,100),(1,100)$；最短优先可能先做后两件，导致第一个超时，而按截止时间可做 3 件 |
| 资源分配的区间按结束最早即可 | 若目标是**同时安排所有任务且资源数最少**，下界是最大重叠数，应该按起点排序配堆 |
| 一般集合覆盖每次选新增覆盖元素最多者 | 这只保证经典对数级近似（一般集合覆盖问题），不是精确最优 |

#### 2.15.9 判断贪心正确性的速查方法

1. **交换论证。** 交换最优解中的一部分，使其先选当前贪心选择且不变差（Huffman、区间选取、排序配对、Smith 法则）。
2. **始终不劣的前缀。** 保证贪心在处理前 $i$ 项后，留下的余量、可达端点或累计用时不比任何同等规模方案差（覆盖、最少跳跃、反悔调度）。
3. **下界构造。** 先证明任何方案至少需要这么多资源或代价，再给出贪心达到下界的构造（区间分组、中位数、极差中心）。
4. **可扩展交换系统。** 可行集满足拟阵交换公理时，按权重排序就能做最大权基；不满足时需找反例或另用 DP、流、匹配。
5. **先审条件。** 区间是否闭合、任务能否拆分、是否有释放时间、是否只能相邻合并、物品能否分割、权值能否为负，都会直接改变结论。
