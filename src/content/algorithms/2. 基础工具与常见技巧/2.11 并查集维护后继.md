### 并查集维护后继（删除跳点 DSU）
---
```cpp
struct NextDSU {
    int n;
    vector<int> pa;
    explicit NextDSU(int n_) : n(n_), pa(n + 1) { ranges::iota(pa, 0); }
    // 返回第一个 >= x 且尚未删除的位置；返回 n 表示不存在
    int next(int x) {
        while (x != pa[x]) x = pa[x] = pa[pa[x]];
        return x;
    }
    // 删除位置 x，并返回删除后第一个 > x 且尚未删除的位置
    int erase(int x) { return pa[x] = next(x + 1); }
};
```
#### 成员变量
- `n`：有效位置为 `[0,n)`
- `pa[n]`：额外的哨兵，表示“后面已经没有可用位置”
#### 接口
- `next(x)`：返回第一个不小于 `x` 的未删除位置，均摊 $O(\alpha(n))$
- `erase(x)`：删除位置 `x`，并返回删除后的下一个未删除位置，均摊 $O(\alpha(n))$
这里“删除”的实际操作就是：
```cpp
pa[x] = next(x + 1);
```
也就是把 `x` 永久接到自己的后继上。之后所有经过 `x` 的查询都会直接跳过去
#### 注意事项
- 有效位置是 `[0,n)`，`n` 是**哨兵**，不能作为普通位置使用
- `next(x) == n` 表示 `[x,n)` 已经没有未删除位置
- 只适用于**单向删除、不会恢复**的场景；普通并查集的路径压缩无法撤销
- 一个位置一旦删除，之后查询会永久跳过它
- `erase(x)` 可以重复调用；对于已经删除的位置，只会重新指向其当前后继，不会把后继一起删除
- 如果既要删除又要恢复，通常改用 `set`、Fenwick、线段树，或者考虑离线倒序处理
#### 常见用法
##### 查询下一个未删除位置
```cpp
NextDSU dsu(n);
dsu.erase(3);
dsu.erase(4);
int x = dsu.next(3); // 5
```
这就是最直接的 **successor with delete**
##### 跳过已经处理的位置
```cpp
for (int x = dsu.next(l); x < r; x = dsu.erase(x)) {
    // 处理 x
}
```

例如“把 `[l,r)` 中所有**第一次出现的、尚未处理的位置**赋值”：
```cpp
for (int x = dsu.next(l); x < r; x = dsu.erase(x)) {
    a[x] = value;
}
```
即使有很多区间操作，每个位置也只真正进入循环一次
##### 区间只处理一次
例如有 $q$ 个区间，每个位置一旦被覆盖后以后都不用处理：
```cpp
NextDSU dsu(n);
for (auto [l, r] : queries) {
    for (int x = dsu.next(l); x < r; x = dsu.erase(x)) {
        // x 第一次被覆盖
        vis[x] = true;
    }
}
```
所有循环加起来最多真正处理 $n$ 个位置，而不是每个询问重新扫描整个区间
##### 找下一个空闲位置
还有一类很常见的写法是：
```cpp
int p = dsu.next(x);
if (p == n) {
    // 不存在位置
} else {
    // 使用 p
    dsu.erase(p);
}
```
可以表示：
- 第一个未使用位置  
- 第一个未分配槽位
- 第一个还没处理的元素
- 从 `x` 开始第一个可用位置
#### 复杂度

| 操作                     |             时间复杂度 |
| ---------------------- | ----------------: |
| 构造                     |            $O(n)$ |
| `next(x)` / `erase(x)` | 均摊 $O(\alpha(n))$ |
空间复杂度：$O(n)$
如果每个位置最多删除一次，那么像
```cpp
for (int x = dsu.next(l); x < r; x = dsu.erase(x)) {
    ...
}
```
这样的所有区间扫描中，**每个位置最多被真正处理一次**，因此总复杂度通常可以看成
$$O((n+q)\alpha(n))$$
