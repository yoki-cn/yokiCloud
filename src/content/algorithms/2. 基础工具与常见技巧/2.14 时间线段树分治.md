### 时间线段树分治
---
将对象的有效时间区间挂到时间线段树上，DFS 时加入对象、离开节点时回滚，适用于**离线动态维护**。
```cpp
template<class Item>
struct TimeSegmentTree {
    int q, n{1};
    vector<vector<Item>> seg;
    explicit TimeSegmentTree(int q_) : q(q_) {
        while (n < q) n <<= 1;
        seg.resize(2 * n);
    }
    // ===== 有效区间挂载：O(log q) =====
    void add(int l, int r, const Item &item) {
        for (l += n, r += n; l < r; l >>= 1, r >>= 1) {
            if (l & 1) seg[l ++].push_back(item);
            if (r & 1) seg[-- r].push_back(item);
        }
    }
    // ===== DFS 与回滚：被 run() 依赖 =====
    template<class State, class Answer>
    void dfs(int p, int l, int r, State &state, Answer &answer) const {
        if (l >= q) return;
        auto snap = state.snap();
        for (const Item &item : seg[p]) state.apply(item);
        if (r - l == 1) {
            answer(l, as_const(state));
        } else {
            int m = (l + r) / 2;
            dfs(2 * p, l, m, state, answer);
            dfs(2 * p + 1, m, r, state, answer);
        }
        state.rollback(snap);
    }
    template<class State, class Answer>
    void run(State &state, Answer &&answer) const {
        if (q) dfs(1, 0, n, state, answer);
    }
};
// ===== 可撤销异或线性基 =====
template<int B = 64>
struct RollbackBasis {
    static_assert(1 <= B && B <= 64);
    array<u64, B> p{};
    array<int, B> his{};
    int sz{};
    int snap() const { return sz; }
    void apply(u64 x) {
        if constexpr (B < 64) assert((x >> B) == 0);
        for (int b = B - 1; b >= 0; -- b) {
            if (!(x >> b & 1ULL)) continue;
            if (p[b]) x ^= p[b];
            else {
                p[b] = x;
                his[sz ++] = b;
                return;
            }
        }
    }
    void rollback(int t) {
        while (sz > t) p[his[-- sz]] = 0;
    }
    u64 maximum(u64 x = 0) const {
        for (int b = B - 1; b >= 0; -- b) x = max(x, x ^ p[b]);
        return x;
    }
    // ===== 扩展查询：不需要秩/可表示性时，可删除以下函数 =====
    int rank() const { return sz; }
    bool contains(u64 x) const {
        if constexpr (B < 64) if (x >> B) return false;
        for (int b = B - 1; b >= 0; -- b) {
            if ((x >> b & 1ULL) && p[b]) x ^= p[b];
        }
        return x == 0;
    }
};
```
#### 接口说明
##### `TimeSegmentTree<Item>`
- `TimeSegmentTree(q)`：建立 `q` 个时间点 `0, 1, ..., q-1`；内部叶子数 `n` 为不小于 `max(1, q)` 的最小二次幂。初始化时间、空间均为 $O(q + 1)$。
- `add(l, r, item)`：令对象 `item` 在 `[l, r)` 内生效，允许空区间；时间 $O(log(q + 1))$，新增存储 $O(log(q + 1))$。
- `run(state, answer)`：按时间顺序访问叶子，调用 `answer(t, const State&)`；若 `snap/apply/rollback` 符合约定，结束后 `state` 恢复到运行前。`q = 0` 时不调用回调。
- `dfs(...)`：`run()` 使用的内部递归函数，无需直接调用。
`State` 的必需接口：
```cpp
auto snap() const;                // 记录当前状态
void apply(const Item &item);     // 加入一个有效对象
void rollback(Snapshot snapshot); // 恢复到指定快照
```
`Snapshot` 可以是任意能正确保存和传递的快照类型，不一定是整数。`answer` 应为**只读查询**。
##### `RollbackBasis<B>`
- `B`：整数位数，`1 <= B <= 64`；`B < 64` 时插入值必须小于 $2^B$。
- `snap()`：返回当前历史记录长度，$O(1)$。
- `apply(x)`：向异或线性基插入 `x`，$O(B)$；线性相关时不产生状态变化。
- `rollback(t)`：撤销到历史记录长度 `t`，每撤销一个主元 $O(1)$。
- `maximum(x = 0)`：计算 `x` 异或当前有效值的某个子集后可得到的最大无符号整数，$O(B)$。
- `rank()`：当前向量空间的维数，而非有效对象个数，$O(1)$。
- `contains(x)`：判断 `x` 能否由当前有效值异或得到，$O(B)$。
#### 注意事项
- **离线算法**：所有生效区间应在 `run()` 前确定。原操作时间点按 `0base` 编号，区间统一为 `[l, r)`，要求 `0 <= l <= r <= q`。
- **操作顺序**：对象会按线段树节点的 DFS 路径顺序加入，**不保证按原始时间或输入顺序加入**。要求结果与有效对象的加入顺序无关；并非任意可撤销操作都能直接套用。
- **回滚完整性**：`apply()` 改写的全部状态都必须能由 `rollback()` 恢复；不能使用未记录修改的路径压缩、缓存、懒标记更新等。回滚 DSU 通常不使用路径压缩。
- **查询只读**：叶子回调接收 `const State&`，不允许在查询过程中破坏当前状态。对存在内部修改的查询，需要另外设计可回滚的实现。
- **时间端点**：若操作 `t` 先修改、再观察状态，则第 `t` 次插入通常从 `t` 开始有效，第 `t` 次删除通常从 `t` 开始失效。实际端点须根据题目查询发生的时刻确定。
- **重复对象**：同一个值可以出现多次，应按对象 ID 或每次插入分别配对删除，不可随意用数值唯一标识生命周期。
- **线性基限制**：`RollbackBasis` 只记录新出现的主元；依赖插入不修改 `p`，故无需入栈。`rank()` 不是当前元素数量；`maximum()` 的选择允许空子集。
- **不适用情形**：普通 LCT 的 `access/splay/link/cut` 不自带完整回滚能力，不能直接放入 `State`；普通可持久化结构/CDQ 也不是本框架的直接替代实现。
- **多测**：每组数据重新构造时间树与状态；通常一次 `run()` 即可完成全部查询。若 `Item` 很大，可存对象 ID 并在 `State::apply(id)` 中读取原对象，减少区间挂载的复制开销。
#### 常见用法
##### 1. 有效时间区间内的最大子集异或
```cpp
TimeSegmentTree<u64> time(q);
time.add(l, r, value);

RollbackBasis<> basis;
vector<u64> ans(q);
time.run(basis, [&](int t, const auto &cur) {
    ans[t] = cur.maximum();
});
```
##### 2. 将插入、删除操作变成有效区间
以下假设 `op[t]` 为 `'+'`、`'-'` 或 `'?'`，每个对象有唯一 ID `id[t]`，并且 `value[id]` 固定；每个 ID 不会重复插入而不先删除。
```cpp
TimeSegmentTree<u64> time(q);
vector<int> start(m, -1);
for (int t = 0; t < q; ++ t) {
    if (op[t] == '+') {
        start[id[t]] = t;
    } else if (op[t] == '-') {
        int x = id[t];
        time.add(start[x], t, value[x]);
        start[x] = -1;
    }
}
for (int x = 0; x < m; ++ x) {
    if (start[x] != -1) time.add(start[x], q, value[x]);
}

RollbackBasis<> basis;
time.run(basis, [&](int t, const auto &cur) {
    if (op[t] == '?') cout << cur.maximum() << '\n';
});
```
##### 3. 自定义 `Item` 类型
```cpp
struct ActiveVector { u64 value; int id; };
struct ActiveBasis : RollbackBasis<> {
    void apply(const ActiveVector &x) { RollbackBasis<>::apply(x.value); }
};

TimeSegmentTree<ActiveVector> time(q);
time.add(l, r, {value, id});
ActiveBasis state;
time.run(state, [&](int t, const auto &cur) {
    ans[t] = cur.maximum();
});
```
#### 复杂度
令 `m` 为有效区间个数，`q` 为时间点个数，`A` 为一次 `apply()` 的最坏时间，`R` 为撤销一次 `apply()` 所引起状态变化的摊还时间，`Q` 为一次叶子查询时间，`S` 为 `State` 的空间开销。

| 操作        | 时间复杂度                                | 额外空间                               |
| --------- | ------------------------------------ | ---------------------------------- |
| 构造时间树     | $O(q + 1)$                           | $O(q + 1)$                         |
| 挂载一个区间    | $O(log(q + 1))$                      | $O(log(q + 1))$                    |
| 全部挂载      | $O(m log(q + 1))$                    | $O(m log(q + 1))$                  |
| DFS 回滚与查询 | $O(q + m log(q + 1) · (A + R) + qQ)$ | $O(S + log(q + 1))$（不计已存储的区间对象与答案） |
总空间 $O(q + m log(q + 1) + S)$，不计答案和对象自身额外持有的存储
`RollbackBasis<B>` 的插入与最大异或查询均为 $O(B)$，一次主元撤销 $O(1)$，状态空间 $O(B)$。若每个时间点都计算最大异或，总时间为 $O((m log(q + 1) + q)B + q)$，总空间为 $O(q + m log(q + 1) + B)$。
