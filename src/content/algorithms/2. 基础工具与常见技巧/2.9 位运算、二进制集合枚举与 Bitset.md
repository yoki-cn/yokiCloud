### 位运算、二进制集合枚举与 Bitset
---
#### 标准位函数与 GNU 内建函数
---
以下默认 `x` 为 `u64`

| 功能 | C++20 / C++23 | GNU / C++17 |
|---|---|---|
| `1` 的数量 | `popcount(x)` | `__builtin_popcountll(x)` |
| `1` 的数量奇偶性 | `popcount(x) & 1` | `__builtin_parityll(x)` |
| 末尾 `0` 数量 | `countr_zero(x)` | `x ? __builtin_ctzll(x) : 64` |
| 前导 `0` 数量 | `countl_zero(x)` | `x ? __builtin_clzll(x) : 64` |
| 末尾 `1` 数量 | `countr_one(x)` | `~x ? __builtin_ctzll(~x) : 64` |
| 前导 `1` 数量 | `countl_one(x)` | `~x ? __builtin_clzll(~x) : 64` |
| 是否为二的幂 | `has_single_bit(x)` | `x && !(x & (x - 1))` |
| 二进制位宽 | `bit_width(x)` | `x ? __lg(x) + 1 : 0` |
| 不大于 `x` 的最大二次幂 | `bit_floor(x)` | `x ? 1ULL << __lg(x) : 0` |
| 不小于 `x` 的最小二次幂 | `bit_ceil(x)` | `x <= 1 ? 1 : 1ULL << (__lg(x - 1) + 1)` |
| $\lfloor\log_2x\rfloor$ | `bit_width(x) - 1` | `__lg(x)` |
| $\lceil\log_2x\rceil$ | `bit_width(x - 1)` | `x <= 1 ? 0 : __lg(x - 1) + 1` |
| 最低 `1` 的 `1base` 位置 | `x ? countr_zero(x) + 1 : 0` | `__builtin_ffsll(x)` |
| 字节翻转 | `byteswap(x)` C++23 | `__builtin_bswap64(x)` |
其中 `__lg(x)` 是 GNU libstdc++ 扩展，不属于 ISO C++，要求 `x > 0`
也可以完全不用 `__lg`：
```cpp
int lg = 63 - __builtin_clzll(x); // x > 0
int bw = x ? 64 - __builtin_clzll(x) : 0;
```
##### 注意事项
- `<bit>` 中上述计数、二次幂和循环移位接口主要接受无符号整数，位运算默认优先使用 `u64`
- `countr_zero(0ULL) == 64`、`countl_zero(0ULL) == 64`
- `__builtin_ctzll(0)`、`__builtin_clzll(0)` 未定义，必须提前判断
- `__lg(0)` 未定义，不要拿它代替带零处理的 `bit_width`
- `bit_floor(0) == 0`，`bit_ceil(0) == 1`
- `bit_ceil(x)` 要求结果能由参数类型表示；对 `u64` 即 `x <= 1ULL << 63`，否则行为未定义
- `byteswap` 是 C++23，其余表中的标准位操作均为 C++20
- GNU 内建函数按类型有无后缀、`l`、`ll` 三组，`u64` 通常使用 `ll`
#### 循环移位
---
C++20 直接使用：
```cpp
u64 a = rotl(x, k);
u64 b = rotr(x, k);
```
C++17 没有对应的标准函数，可以写：
```cpp
u64 rotl64(u64 x, int k) {
    k %= 64;
    if (k < 0) k += 64;
    return k ? (x << k) | (x >> (64 - k)) : x;
}
u64 rotr64(u64 x, int k) {
    k %= 64;
    if (k < 0) k += 64;
    return k ? (x >> k) | (x << (64 - k)) : x;
}
```
##### 接口说明
- `rotl(x,k)` / `rotl64(x,k)`：循环左移 `k` 位
- `rotr(x,k)` / `rotr64(x,k)`：循环右移 `k` 位
- `k` 可以为负数，负左移等价于正右移
##### 复杂度
$O(1)$
#### GNU 特有函数
---
以下没有常用的标准库一一对应接口：

| 函数 | 含义 |
|---|---|
| `__builtin_ffsll(x)` | 最低 `1` 的位置，`1base`，`x = 0` 返回 `0` |
| `__builtin_parityll(x)` | `popcount(x) & 1` |
| `__builtin_clrsbll(x)` | 除符号位外的冗余符号位数量 |
| `__builtin_bswap64(x)` | 64 位整数按字节翻转 |
`parity`、`ffs` 在现代 C++ 中通常直接由 `popcount`、`countr_zero` 表达，不需要额外封装函数
#### 基础位操作
---
第 `k` 位从最低位开始 `0base`

| 操作 | 写法 |
|---|---|
| 读取第 `k` 位 | `(x >> k) & 1ULL` |
| 判断第 `k` 位为 `1` | `x & (1ULL << k)` |
| 第 `k` 位设为 `1` | `x \|= 1ULL << k` |
| 第 `k` 位设为 `0` | `x &= ~(1ULL << k)` |
| 翻转第 `k` 位 | `x ^= 1ULL << k` |
| 第 `k` 位赋值为 `v` | `x = (x & ~(1ULL << k)) \| (u64(v) << k)` |
| 删除最低位 `1` | `x &= x - 1` |
| 保留最低位 `1` | `x & -x` |
| 将最低位 `0` 设为 `1` | `x \| (x + 1)` |
| 清除末尾连续 `1` | `x & (x + 1)` |
低位掩码：
```cpp
u64 mask(int k) { return k == 64 ? ~0ULL : (1ULL << k) - 1; }
u64 mask(int l, int r) { return mask(r) ^ mask(l); }
u64 bits(u64 x, int l, int r) { return (x >> l) & mask(r - l); }
```
##### 接口说明
- `mask(k)`：低 `k` 位为 `1`，要求 `0 <= k <= 64`
- `mask(l,r)`：第 `[l,r)` 位为 `1`
- `bits(x,l,r)`：取出 `x` 的 `[l,r)` 位并移动到最低位
##### 注意事项
- `x << k`、`x >> k` 要求 `0 <= k < 64`
- `1ULL << 64` 未定义，因此低 `64` 位掩码必须单独处理
- 常量使用 `1ULL`，不要写 `1 << k`
- `~x` 会翻转全部 `64` 位，只翻低 `n` 位使用 `x ^ mask(n)`
- 无符号整数中的 `-x` 按模 $2^{64}$ 运算，因此 `x & -x` 定义良好
#### 最低位与最高位
---
最低位：
```cpp
u64 lb = x & -x;
x &= x - 1; // 删除最低位 1
```
对于 `x > 0`：
$$
\operatorname{lowbit}(x)=2^{\operatorname{countr\_zero}(x)}
$$
最高位：
```cpp
u64 hb = bit_floor(x);                    // C++20
u64 hb2 = x ? 1ULL << __lg(x) : 0;       // GNU
```
常用恒等式：

| 表达式 | 效果 |
|---|---|
| `x & -x` | 保留最低位 `1` |
| `x & (x - 1)` | 删除最低位 `1` |
| `x \| (x - 1)` | 最低位 `1` 以下全部置 `1`，要求 `x > 0` |
| `x ^ (x - 1)` | 最低位 `1` 及以下全部置 `1`，要求 `x > 0` |
| `x \| (x + 1)` | 最低位 `0` 置 `1` |
| `x & (x + 1)` | 清除末尾连续 `1` |
| `~x & (x + 1)` | 保留最低位 `0` |
| `x ^ (x + 1)` | 最低位 `0` 及以下全部置 `1` |
对于 `x > 0`：
$$
x\oplus(x-1)=2\operatorname{lowbit}(x)-1
$$
#### 二进制位宽与对数
---
对于 `x > 0`：
```cpp
int fl = bit_width(x) - 1; // floor(log2(x))
int ce = bit_width(x - 1); // ceil(log2(x))
```
GNU 写法：
```cpp
int fl = __lg(x);
int ce = x <= 1 ? 0 : __lg(x - 1) + 1;
```
并且：
$$
\operatorname{bit\_width}(x)=
\begin{cases}
0,&x=0\\
\lfloor\log_2x\rfloor+1,&x>0
\end{cases}
$$
#### 二的幂
---
现代 C++：
```cpp
bool ok = has_single_bit(x);
u64 lo = bit_floor(x);
u64 hi = bit_ceil(x);
```
老版本：
```cpp
bool ok = x && !(x & (x - 1));
u64 lo = x ? 1ULL << __lg(x) : 0;
u64 hi = x <= 1 ? 1 : 1ULL << (__lg(x - 1) + 1);
```
对于 `x > 0`，以下条件等价：
```cpp
has_single_bit(x)
(x & (x - 1)) == 0
popcount(x) == 1
(x & -x) == x
bit_floor(x) == x
bit_ceil(x) == x
```
##### 注意事项
判断二的幂时，裸写
```cpp
(x & (x - 1)) == 0
```
会错误地把 `0` 判为二的幂
#### 二的幂取模与对齐
---
设 `p = 2^k`
对于非负整数：
```cpp
x % p == (x & (p - 1))
```
向下对齐：
```cpp
u64 y = x & ~(p - 1);
```
向上对齐：
```cpp
u64 y = (x + p - 1) & ~(p - 1);
```
##### 注意事项
- 要求 `p` 为二的幂
- 向上对齐必须保证 `x + p - 1` 不溢出
#### 加法与位运算
---
对于非负整数：
$$
a+b=(a\oplus b)+2(a\mathbin{\&}b)
$$
$$
a+b=(a\mathbin{|}b)+(a\mathbin{\&}b)
$$
$$
a\mathbin{|}b=(a\oplus b)+(a\mathbin{\&}b)
$$

因此 `(a & b) == 0` 时：
$$
a+b=a\oplus b=a\mathbin{|}b
$$
这也是判断区间和等于区间异或和时常用的无进位条件
无符号整数可以无溢出地计算平均数：
```cpp
u64 fl = (a & b) + ((a ^ b) >> 1);
u64 ce = (a | b) - ((a ^ b) >> 1);
```
#### 二进制集合
---
低 `n` 位分别表示 `n` 个元素

| 集合操作 | 位运算 |
|---|---|
| $A\cap B$ | `a & b` |
| $A\cup B$ | `a \| b` |
| $A\triangle B$ | `a ^ b` |
| $A\setminus B$ | `a & ~b` |
| 全集 | `mask(n)` |
| 补集 | `mask(n) ^ a` |
| 加入 `i` | `a \|= 1ULL << i` |
| 删除 `i` | `a &= ~(1ULL << i)` |
| 翻转 `i` | `a ^= 1ULL << i` |
| 大小 | `popcount(a)` / `__builtin_popcountll(a)` |
子集关系：
```cpp
(a & b) == a   // a ⊆ b
(a | b) == b   // a ⊆ b
(a & ~b) == 0  // a ⊆ b
(a & b) == 0   // a ∩ b = ∅
```
##### 数量结论
一个 `n` 元集合：
- 子集数为 $2^n$
- 大小恰好为 `k` 的子集数为 $\binom nk$
- 每个元素出现在 $2^{n-1}$ 个子集中
- 所有子集大小之和为 $n2^{n-1}$
状态 `s`：
- 子集数为 $2^{\operatorname{popcount}(s)}$
- `n` 位内超集数为 $2^{n-\operatorname{popcount}(s)}$
所有 `(s,t)` 满足 `t ⊆ s` 的有序对共有
$$
3^n
$$
#### 枚举所有状态
---
要求 `0 <= n < 64`
```cpp
for (u64 s = 0, lim = 1ULL << n; s < lim; ++ s) {
    // s
}
```
##### 复杂度
$O(2^n)$
#### 枚举状态中的所有元素
---
```cpp
for (u64 t = s; t; t &= t - 1) {
    int k = countr_zero(t);// __builtin_ctzll(t)
}
```
若只需要对应的二次幂：
```cpp
for (u64 t = s; t; t &= t - 1) {
    u64 lb = t & -t;
}
```
##### 复杂度
$O(\operatorname{popcount}(s))$
#### 枚举子集
---
非空子集：
```cpp
for (u64 t = s; t; t = (t - 1) & s) {
    // t
}
```
包括空集：
```cpp
for (u64 t = s;; t = (t - 1) & s) {
    // t
    if (!t) break;
}
```
非空真子集，要求 `s != 0`：
```cpp
for (u64 t = (s - 1) & s; t; t = (t - 1) & s) {
    // t
}
```
##### 注意事项
不能对无符号数写：
```cpp
for (u64 t = s; t >= 0; ...)
```
因为 `t >= 0` 永远成立
##### 复杂度
$O(2^{\operatorname{popcount}(s)})$
全部 `n` 位状态再分别枚举子集的总复杂度为 $O(3^n)$
#### 枚举超集
---
在低 `n` 位内枚举 `s` 的全部超集：
```cpp
u64 all = mask(n);
for (u64 t = s;; t = (t + 1) | s) {
    // s ⊆ t
    if (t == all) break;
}
```
##### 复杂度
$O(2^{n-\operatorname{popcount}(s)})$
#### 集合二分
---
枚举所有有序划分 `a ∪ b = s, a ∩ b = ∅`：
```cpp
for (u64 a = s;; a = (a - 1) & s) {
    u64 b = s ^ a;
    // a, b
    if (!a) break;
}
```
若 `(a,b)` 与 `(b,a)` 视为相同，可以固定最低位属于 `a`：
```cpp
if (s) {
    u64 lb = s & -s;
    for (u64 a = s; a; a = (a - 1) & s) if (a & lb) {
        u64 b = s ^ a;
        // 每个无序划分一次
    }
}
```
#### Gosper Hack
---
按数值递增枚举 `n` 位中恰有 `k` 个 `1` 的状态
要求 `0 < k <= n < 64`
```cpp
u64 s = (1ULL << k) - 1;
u64 lim = 1ULL << n;
while (s < lim) {
    // s
    u64 lb = s & -s;
    u64 x = s + lb;
    s = x | (((x ^ s) >> 2) / lb);
}
```
`k == 0` 时唯一状态为 `0`
##### 复杂度
共枚举 $\binom nk$ 个状态，每次转移 $O(1)$
#### Gray Code
---
编码：
```cpp
u64 gray(u64 x) { return x ^ (x >> 1); }
```
解码：
```cpp
u64 igray(u64 g) {
    u64 x = 0;
    for (; g; g >>= 1) x ^= g;
    return x;
}
```
枚举：
```cpp
for (u64 i = 0; i < (1ULL << n); ++ i) {
    u64 s = gray(i);
}
```
相邻 Gray Code 只改变一位，第 `i - 1 -> i` 次改变的位置为：
```cpp
int k = countr_zero(i);          // C++20
int k = __builtin_ctzll(i);      // GNU
```
且：
```cpp
gray(i) ^ gray(i - 1) == (i & -i)
```
##### 复杂度
编码 $O(1)$，解码 $O(\log g)$
#### 区间异或
---
```cpp
u64 xor_pre(u64 n) {
    if ((n & 3) == 0) return n;
    if ((n & 3) == 1) return 1;
    if ((n & 3) == 2) return n + 1;
    return 0;
}
u64 xor_sum(u64 l, u64 r) {
    return xor_pre(r) ^ (l ? xor_pre(l - 1) : 0);
}
```
##### 接口说明
- `xor_pre(n)`：$0\oplus1\oplus\cdots\oplus n$
- `xor_sum(l,r)`：闭区间 `[l,r]` 的异或和
##### 复杂度
$O(1)$
#### 两个只出现奇数次的元素
---
若恰有两个不同元素出现奇数次，其余元素出现偶数次：
```cpp
u64 s = 0;
for (u64 v : a) s ^= v;

u64 lb = s & -s;
u64 x = 0, y = 0;
for (u64 v : a) {
    if (v & lb) x ^= v;
    else y ^= v;
}
```
利用 `x ^ y` 任意一个为 `1` 的位把两个答案分组
##### 复杂度
$O(n)$
#### 成对编号
---
若对象严格按
```text
0 <-> 1
2 <-> 3
4 <-> 5
```
连续成对插入，则另一对象为：
```cpp
int rev = id ^ 1;
```
常用于网络流反向边
##### 注意事项
只有每一对连续编号且第一对从偶数开始时才能使用
#### 逐位统计数对贡献
---
设第 `k` 位为 `1` 的元素数为 `c`，总数为 `n`

| 运算 | 所有无序对在第 `k` 位为 `1` 的对数 |
|---|---|
| XOR | $c(n-c)$ |
| AND | $\binom c2$ |
| OR | $\binom n2-\binom{n-c}2$ |
例如所有无序数对 XOR 之和：
```cpp
i64 ans = 0;
for (int k = 0; k < 60; ++ k) {
    i64 c = 0;
    for (u64 x : a) c += x >> k & 1ULL;
    ans += c * (a.size() - c) * (1LL << k);
}
```
所有有序对：

| 运算 | 第 `k` 位为 `1` 的对数 |
|---|---|
| XOR | $2c(n-c)$ |
| AND | $c^2$ |
| OR | $n^2-(n-c)^2$ |
##### 注意事项
答案可能远大于元素本身范围，应先估算乘法与答案是否需要 `i128` 或取模
#### AND / OR 重分配
---
把两个数
```cpp
x, y
```
替换为
```cpp
x & y, x | y
```
每一位上 `1` 的总数不变，因此：
$$
x+y=(x\mathbin{\&}y)+(x\mathbin{|}y)
$$
这种操作可以重新分配各二进制位，但不会改变每一位出现 `1` 的总次数
#### 拆成若干二次幂
---
正整数 `n` 能拆成恰好 `k` 个正的二次幂之和，当且仅当：
$$
\operatorname{popcount}(n)\le k\le n
$$
二进制分解给出最少项数，每个 $2^i$ 又可以继续拆成两个 $2^{i-1}$
#### Bitset
---
当位数在编译期确定且可能超过 `64` 时使用：
```cpp
bitset<N> b;
```
常用接口：
```cpp
b[i]
b.test(i)

b.set(i)
b.reset(i)
b.flip(i)

b.set()
b.reset()
b.flip()

b.count()
b.any()
b.none()
b.all()

b.to_string()
b.to_ullong()
```
整体位运算：
```cpp
a & b
a | b
a ^ b
~a
a << k
a >> k
```
从字符串构造：
```cpp
bitset<8> b("00101101");
```
字符串最右侧字符对应第 `0` 位
##### 注意事项
- `bitset<N>` 的 `N` 必须为编译期常量
- `test(i)` 会检查越界，`operator[]` 通常用于竞赛中的直接访问
- `to_ullong()` 要求结果能够表示为 `unsigned long long`
#### GNU Bitset 枚举置位位置
---
libstdc++ 提供非标准扩展：
```cpp
for (size_t i = b._Find_first(); i < N; i = b._Find_next(i)) {
    // 第 i 位为 1
}
```
##### 注意事项
- `_Find_first()` / `_Find_next()` 不是 ISO C++ 接口，只能依赖 GNU libstdc++
- 找不到时返回 `N`
#### Bitset 子集和
---
所有数非负且总和上界可控时，0/1 子集和可写成：
```cpp
constexpr int S = 200000;
bitset<S + 1> dp;
dp[0] = 1;
for (int x : a) dp |= dp << x;
```
处理完成后 `dp[s]` 表示是否存在子集和为 `s`
##### 注意事项
- 每个元素最多使用一次
- 负数不能直接套用
- 左移后超过 `S` 的部分自动丢弃
##### 复杂度
设机器字宽为 `w`，时间复杂度约为 $O(nS/w)$，空间复杂度为 $O(S/w)$
#### 总体注意事项
- 位运算默认使用 `u64`
- 所有 `1ULL << k` 都要求 `k < 64`
- 枚举 `2^n` 个状态时通常要求 `n < 64`，且实际复杂度往往远早于位宽成为瓶颈
- `ctz/clz` 的 GNU builtin 不能传 `0`
- `mask - 1` 的无符号下溢本身有定义，但循环终止条件必须正确
