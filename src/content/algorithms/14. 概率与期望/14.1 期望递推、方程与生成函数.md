### 期望递推、方程与生成函数
---
```cpp
// ===== Markov 链方程：依赖高斯消元 =====
template<class T>
vector<vector<T>> markov_system(const vector<vector<T>> &p,
        const vector<char> &term, const vector<T> &cost) {
    int n = p.size();
    vector a(n, vector<T>(n + 1));
    for (int u = 0; u < n; ++ u) {
        a[u][u] = 1;
        if (term[u]) continue;
        for (int v = 0; v < n; ++ v) a[u][v] -= p[u][v];
        a[u][n] = cost[u];
    }
    return a;
}
// ===== 树上随机游走 =====
vector<i64> tree_random_walk_to_root(const vector<vector<int>> &g, int root) {
    int n = g.size();
    vector<int> fa(n, -1), sub(n, 1), order{root};
    fa[root] = root;
    for (int i = 0; i < (int)order.size(); ++ i) {
        int u = order[i];
        for (int v : g[u]) if (fa[v] == -1) {
            fa[v] = u;
            order.push_back(v);
        }
    }
    for (int i = n - 1; i > 0; -- i) {
        int u = order[i];
        sub[fa[u]] += sub[u];
    }
    vector<i64> e(n);
    for (int u : order) if (u != root) {
        e[u] = e[fa[u]] + 2LL * sub[u] - 1;
    }
    return e;
}
```
#### 接口说明

|接口|功能|复杂度|
|---|---|---|
|`markov_system(p, term, cost)`|构造吸收 Markov 链的增广矩阵|\(O(n^2)\)|
|`tree_random_walk_to_root(g, root)`|求树上每个点首次到达吸收根的期望步数|\(O(n)\)|
`markov_system()`
- `p[u][v]`：状态 `u` 转移到 `v` 的概率。
- `term[u]`：是否为终止状态；终止状态的未知量固定为 0。
- `cost[u]`：状态 `u` 的期望即时成本；计算首次吸收步数时，非终止状态填 1。
- 返回 `n × (n + 1)` 增广矩阵，交给 11.1 矩阵与线性方程组 中对应类型的高斯消元求解。
- `T` 可使用 `ld` 或静态模整数 `MInt`，但求解器必须支持对应数域。
`tree_random_walk_to_root()`
- `g`：`0-based` 无权无向树邻接表。
- `root`：吸收点，首次抵达即停止。
- 返回 `e[u]`：从 `u` 首次到达 `root` 的期望步数。
- 输入必须是一棵合法树；不执行合法性检查。
#### 注意事项
- 有限期望：若从某状态有正概率永远无法吸收，则首次吸收时间的期望为无穷。构造线性方程不等于保证存在唯一的有限解。
- 转移概率：每个非终止状态的完整转移概率之和必须为 1，包括自环和进入终止状态的概率。
- 即时成本：`cost[u]` 是进行下一次转移时产生的期望成本，包含最后一次进入终止状态的转移成本。
- 自环处理：若除自环外的后继状态均已求出，可直接使用 $E=(c+\sum p_iE_i)/(1-p_{\mathrm{self}})$，不需要高斯消元。对应 12.3 树、轮廓线、概率与期望 DP。
- 有环依赖：一般需要解线性方程；若去掉自环后形成 DAG，可移项后按逆拓扑序递推。
- 期望与最短路：当状态可以选择动作时，Bellman 方程可能包含取最小值操作。不能直接套用 Dijkstra，除非证明定值顺序的正确性。
- 模意义期望：概率须能表示为模数下的元素，求解所需的除数必须可逆；模意义方程有解不代表原随机过程的期望有限。
- 树上随机游走：只适用于无权无向树、每一步等概率选择相邻点的模型。结果可能达到 $O(n^2)$，使用 `i64` 保存。
- PGF 截断：只保留低次项会丢失尾部概率，不能直接把截断结果的矩当作原分布的矩。
#### 常见用法
##### 1. DAG 期望 DP
终止状态期望为 0，按照后继先于前驱的顺序计算。
```cpp
// g[u] 存储 (to, probability, cost)
vector<ld> e(n);
for (int u : reverse_topological) {
    if (term[u]) continue;
    for (auto [v, p, cost] : g[u]) {
        e[u] += p * (cost + e[v]);
    }
}
```
##### 2. 吸收 Markov 链期望
求每个状态首次到达终止状态的期望步数。
```cpp
vector<ld> cost(n, 1);
auto a = markov_system(transition, term, cost);
auto res = gauss_real(a);
// 确认唯一解后：
// E[u] = res.particular[u];
```
若只关心到达指定终止集合的概率，可将终止状态的方程右端设为相应边界值（目标为 1，其他终止状态为 0），再求解。
##### 3. 首达时间的方差
设 $E_u=\mathbb E[T_u]$，$M_u=\mathbb E[T_u^2]$。每走一步计 1，且最终吸收时：
$$(I-P)E=\mathbf 1,\qquad (I-P)M=2E-\mathbf 1$$
先求 `E`，再以 `2 * E[u] - 1` 作为非终止状态的右端求 `M`：
```cpp
vector<ld> rhs(n);
for (int u = 0; u < n; ++ u) {
    if (!term[u]) rhs[u] = 2 * E[u] - 1;
}
auto a = markov_system(transition, term, rhs);
auto res = gauss_real(a);
// 确认唯一解后：
// variance[u] = res.particular[u] - E[u] * E[u];
```
这里假定 `E` 已经正确求出，且所有相关状态的首达时间二阶矩有限。
##### 4. 树上随机游走
```cpp
auto e = tree_random_walk_to_root(g, root);
cout << e[source] << '\n';
```
核心公式：以 `root` 为根，`sub[u]` 表示子树大小，则
$$ E_u=E_{\operatorname{fa}(u)}+2\operatorname{sub}(u)-1, \qquad E_{\mathrm{root}}=0 $$
##### 5. 概率生成函数
对于非负整数随机变量 $X$，令
$$ G_X(z)=\sum_{k\ge0}\Pr(X=k)z^k$$
独立随机变量之和对应 PGF 相乘，直接调用 10.1 FFT、NTT 与 FWT 的 `convolution`，不再重复实现。
求期望与方差：
$$ \begin{aligned} \mathbb E[X]&=G_X'(1),\\ \operatorname{Var}(X) &=G_X''(1)+G_X'(1)-G_X'(1)^2. \end{aligned} $$
若只给出完整概率数组 `p[k]`，可直接累加：
```cpp
ld e = 0, e2 = 0;
for (int k = 0; k < (int)p.size(); ++ k) {
    e += (ld)k * p[k];
    e2 += (ld)k * k * p[k];
}
ld variance = e2 - e * e;
```
#### 复杂度

| 操作           | 时间复杂度        | 空间复杂度      |
| ------------ | ------------ | ---------- |
| DAG 期望 DP    | $O(V+E)$     | $O(V)$，不计图 |
| Markov 方程构造  | $O(n^2)$     | $O(n^2)$   |
| 稠密高斯消元       | $O(n^3)$     | $O(n^2)$   |
| 树上随机游走期望     | $O(n)$       | $O(n)$     |
| 朴素 PGF 卷积    | $O(ab)$      | $O(a+b)$   |
| FFT / NTT 卷积 | $O(n\log n)$ | $O(n)$     |
| PGF 一阶、二阶矩   | $O(n)$       | $O(1)$     |
