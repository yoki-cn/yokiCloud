### AC 自动机
---
```cpp
template<int A = 26, int offset = 'a'>
struct AC {
    struct Node {
        int len{ 0 }, link{ 0 };
        array<int, A> next{};
    };
    vector<Node> t;
    vector<int> ord;
    explicit AC(int m = 0) : t(2) {
        t.reserve(m + 2);
        ord.reserve(m + 2);
        t[0].next.fill(1);
        t[0].len = -1;
    }
    // ===== 基础函数：插入与 build() 依赖，不建议删除 =====
    template<class T>
    static int id(const T &c) { return int(c) - offset; }
    int new_node() {
        t.emplace_back();
        return int(t.size()) - 1;
    }
    // ===== Trie 构建：所有模式串必须在 build() 前插入 =====
    template<class Seg>
    int add(const Seg &s) {
        int p{ 1 };
        for (const auto &c : s) {
            int x{ id(c) };
            if (!t[p].next[x]) {
                t[p].next[x] = new_node();
                t[t[p].next[x]].len = t[p].len + 1;
            }
            p = t[p].next[x];
        }
        return p;
    }
    // ===== AC 构建：计算 Fail 并补全所有自动机转移 =====
    // ord 为 Fail 父亲在儿子之前的拓扑序，后续统计与 DP 常用
    void build() {
        queue<int> q;
        q.push(1);
        ord.clear();
        while (!q.empty()) {
            int u{ q.front() };
            q.pop();
            ord.push_back(u);
            for (int c = 0; c < A; ++ c) {
                int &v = t[u].next[c];
                if (!v) {
                    v = t[t[u].link].next[c];
                } else {
                    t[v].link = t[t[u].link].next[c];
                    q.push(v);
                }
            }
        }
    }
    // ===== 状态接口：手写匹配与自动机 DP 使用 =====
    int next(int p, int x) const { return t[p].next[x]; }
    template<class T>
    int next(int p, const T &c) const { return next(p, id(c)); }
    int link(int p) const { return t[p].link; }
    int len(int p) const { return t[p].len; }
    int size() const { return int(t.size()); }
    template<class Seg, class F>
    void scan(const Seg &s, F f) const {
        int p{ 1 };
        for (const auto &c : s) {
            p = next(p, c);
            f(p);
        }
    }
    // ===== Fail 信息传播：统计、权值、禁用状态与状压 DP 共用 =====
    // propagate：Fail 父亲 -> 儿子；f(a[u], a[link[u]])
    template<class T, class F>
    void propagate(vector<T> &a, F f) const {
        for (int i = 1; i < int(ord.size()); ++ i) {
            int u{ ord[i] };
            f(a[u], a[t[u].link]);
        }
    }
    // aggregate：儿子 -> Fail 父亲；f(a[link[u]], a[u])
    template<class T, class F>
    void aggregate(vector<T> &a, F f) const {
        for (int i = int(ord.size()) - 1; i > 0; -- i) {
            int u{ ord[i] };
            f(a[t[u].link], a[u]);
        }
    }
    template<class T>
    void propagate_sum(vector<T> &a) const {
        propagate(a, [](T &x, const T &y) { x += y; });
    }
    template<class T>
    void aggregate_sum(vector<T> &a) const {
        aggregate(a, [](T &x, const T &y) { x += y; });
    }
    // ===== 常用统计：统计层不占用 AC 的成员空间，可按需删除 =====
    // score[u] 表示到达状态 u 时当前位置产生的贡献
    template<class Seg, class T>
    T query(const Seg &s, const vector<T> &score) const {
        T ans{};
        scan(s, [&](int p) {
            ans += score[p];
        });
        return ans;
    }
    // 返回每个状态对应 Trie 字符串在文本中的出现次数
    template<class Seg>
    vector<i64> count_states(const Seg &s) const {
        vector<i64> cnt(size());
        scan(s, [&](int p) { ++ cnt[p]; });
        aggregate_sum(cnt);
        return cnt;
    }
    // ===== Fail 树：若不需要树上问题，可直接删除 =====
    vector<vector<int>> fail_tree() const {
        vector<vector<int>> g(size());
        for (int u = 2; u < size(); ++ u) {
            g[t[u].link].push_back(u);
        }
        return g;
    }
};
```
#### 成员变量
- `0`：哨兵状态，不属于实际 AC 自动机
- `1`：根节点，表示空串
- `t[u].next[c]`：
    - `build()` 前表示 Trie 中字符编号 `c` 的儿子，`0` 表示不存在
    - `build()` 后表示 AC 自动机沿字符编号 `c` 的完整转移
- `t[u].link`：状态 `u` 的 Fail 指针
- `t[u].len`：状态 `u` 对应 Trie 字符串的长度
- `ord`：`build()` 得到的 BFS 序，同时满足 Fail 父亲一定在儿子之前
#### 核心接口
- `AC(m)`：构造空自动机，`m` 为预计所有模式串的总长度，仅用于预留空间  
- `add(s)`：插入模式串 `s`，返回其终止状态，$O(|s|)$
- `build()`：构造 Fail 指针并补全自动机转移，$O(SA)$
- `next(p,x)`：从状态 `p` 沿字符编号 `x` 转移，$O(1)$
- `next(p,c)`：从状态 `p` 沿字符 `c` 转移，$O(1)$
- `link(p)`：返回状态 `p` 的 Fail 状态，$O(1)$
- `len(p)`：返回状态对应字符串长度，$O(1)$
- `size()`：返回状态数，包含哨兵 `0` 与根 `1`，$O(1)$
- `scan(s,f)`：扫描文本 `s`，每到达一个状态调用一次 `f(state)`，$O(|s|)$
#### Fail 信息传播
- `propagate(a,f)`：按照 `ord` 正序执行 `f(a[u],a[link[u]])`，即 Fail 父亲向儿子传播，$O(S)$
- `aggregate(a,f)`：按照 `ord` 逆序执行 `f(a[link[u]],a[u])`，即儿子向 Fail 父亲汇总，$O(S)$
- `propagate_sum(a)`：执行 `a[u] += a[link[u]]`，$O(S)$
- `aggregate_sum(a)`：执行 `a[link[u]] += a[u]`，$O(S)$
`propagate()` / `aggregate()` 不限定运算必须是加法，例如：
```cpp
ac.propagate(mask, [](auto &x, const auto &y) {
    x |= y;
});
```
即可传播模式集合
#### 统计接口
- `query(s,score)`：扫描文本，对每个到达状态 `u` 累加 `score[u]`，$O(|s|)`
- `count_states(s)`：返回每个状态对应 Trie 字符串在文本中的出现次数，$O(|s|+S)$
- `fail_tree()`：构造 Fail 树邻接表，$O(S)$
其中 $S$ 为自动机状态数
#### 注意事项
- 所有 `add()` 必须发生在 `build()` 之前
- `build()` 会把缺失 Trie 边改成完整自动机转移，因此调用后不能继续插入模式串，也不能再用 `next == 0` 判断 Trie 边是否存在
- 当前实现按“一次构建”设计，同一个对象不要重复调用 `build()`
- `add()` 返回的终止状态在 `build()` 前后保持不变，应保存下来用于后续统计
- `ord[0] = 1`，即根节点；逆序上传时应跳过根，因此 `aggregate()` 内部只处理 `ord[1..]`
- 默认处理小写字母；大写字母使用 `AC<26, 'A'>`
- 已经映射到 `[0,A)` 的整数序列使用 `AC<A, 0>`
- 必须保证所有字符满足 `0 <= id(c) < A`
- 当前采用稠密转移表，空间为 $O(SA)$；字符集很大且转移稀疏时不适合直接开很大的 `A`
- 默认模式串非空；空模式串的出现次数通常定义为 $|text|+1$，需要单独处理
- 原先的 `val / sum` 已从 `Node` 中移除；模式串终止状态、权值、禁用标记、状态贡献等全部放在外部数组中
- 原来的 `query(text)` 功能仍然存在，但现在写作 `query(text, score)`；这是统计层与自动机核心分离后的通用形式
#### 常见用法
##### 所有模式串出现总次数
保存每个模式串的终止状态：
```cpp
AC<> ac(sum_len);
vector<int> pos;
for (auto &s : pattern) {
    pos.push_back(ac.add(s));
}
ac.build();
```
令每个模式串权值为 `1`：
```cpp
vector<i64> score(ac.size());
for (int p : pos) {
    ++ score[p];
}
ac.propagate_sum(score);
```
此时 `score[u]` 表示：
> 到达状态 `u` 时，当前位置能够结束的所有模式串数量

因此：
```cpp
cout << ac.query(text, score) << '\n';
```
即为所有模式串在文本中的出现次数总和
重复插入相同模式串时，终止状态相同，但 `score` 会被重复增加，因此仍会按照模式串的多重集合统计
##### 统计每个模式串出现次数
```cpp
AC<> ac(sum_len);
vector<int> pos(n);
for (int i = 0; i < n; ++ i) {
    pos[i] = ac.add(pattern[i]);
}
ac.build();
auto cnt = ac.count_states(text);
for (int i = 0; i < n; ++ i) {
    cout << cnt[pos[i]] << '\n';
}
```
例如模式串为 `a`、`aa`，文本为 `aaa`，对应答案分别为 `3`、`2`
`count_states()` 内部等价于：
```cpp
vector<i64> cnt(ac.size());
ac.scan(text, [&](int p) {
    ++ cnt[p];
});
ac.aggregate_sum(cnt);
```
其本质为：
$$occ[u] = \sum_{v\in subtree_{\rm fail}(u)} visit[v]$$
也就是说：
$$\boxed{\text{AC 出现次数统计本质上是 Fail 树子树求和}}$$
重复模式串对应同一个终止状态，因此自然得到相同的出现次数
##### 扫描文本 / 手写自动机 DP
最简单写法：
```cpp
int p{ 1 };
for (char c : text) {
    p = ac.next(p, c);
    // 当前文本前缀对应的 AC 状态为 p
}
```
也可以直接使用：
```cpp
ac.scan(text, [&](int p) {
    // 当前状态为 p
});
```
扫描长度为 $n$ 的文本总复杂度为 $O(n)$
##### 构造 Fail 树
直接：
```cpp
auto g = ac.fail_tree();
```
或者手写：
```cpp
vector<vector<int>> g(ac.size());
for (int u = 2; u < ac.size(); ++ u) {
    g[ac.link(u)].push_back(u);
}
```
根节点为 `1`
Fail 树常用于：
- Fail 子树统计
- 祖先 / 后代关系
- Euler 序
- 树状数组 / 线段树维护
- LCA 类后缀关系问题
##### Fail 的核心定理
设状态 `u` 对应 Trie 字符串为 $S_u$
则：
$$\boxed{ link[u] = S_u\text{ 的最长真后缀中，同时也是某个 Trie 前缀的状态} }$$
不断执行：
```text
u
link[u]
link[link[u]]
...
1
```
即可枚举 $S_u$ 的所有同时也是 Trie 前缀的后缀
##### Fail 树祖先与后缀
将：
```text
link[u] -> u
```
作为树边，则：
$$\boxed{ u\text{ 是 }v\text{ 的 Fail 树祖先} \iff S_u\text{ 是 }S_v\text{ 的后缀} }$$
扫描文本后当前自动机状态为 `v` 时：
$$\boxed{ \text{模式状态 }u\text{ 在当前位置结尾出现} \iff u\text{ 是 }v\text{ 的 Fail 树祖先} }$$
这个结论是出现次数统计、动态启停模式串和 Fail 树建模的核心
##### `ord` 的方向
任意非根状态都满足：
$$len[link[u]] < len[u]$$
因此 `build()` 得到的 BFS 序满足：
> Fail 父亲一定出现在儿子之前

正序：
```cpp
for (int i = 1; i < int(ac.ord.size()); ++ i) {
    int u{ ac.ord[i] };
    // ac.link(u) -> u
}
```
适合从 Fail 祖先向后继传播：
- 模式串权值
- 禁止状态
- 模式集合状压
- 其他继承型信息
即 `propagate()`
逆序：
```cpp
for (int i = int(ac.ord.size()) - 1; i > 0; -- i) {
    int u{ ac.ord[i] };
    // u -> ac.link(u)
}
```
适合沿 Fail 向上汇总：
- 模式串出现次数
- Fail 子树贡献
- 文本访问次数
即 `aggregate()`

|顺序|典型用途|
|---|---|
|`ord` 正序|`sum[u] += sum[link[u]]`、传播 `bad` / `mask`|
|`ord` 逆序|`cnt[link[u]] += cnt[u]`、出现次数汇总|
##### 统计所有模式串的带权匹配总和
设模式串 `i` 的权值为 `w[i]`：
```cpp
AC<> ac(sum_len);
vector<int> pos(n);
for (int i = 0; i < n; ++ i) {
    pos[i] = ac.add(pattern[i]);
}
ac.build();
vector<i64> score(ac.size());
for (int i = 0; i < n; ++ i) {
    score[pos[i]] += w[i];
}
```
沿 Fail 正序继承后缀模式的权值：
```cpp
ac.propagate_sum(score);
```
此时：
```cpp
score[u]
```
表示：
> 到达状态 `u` 时，当前位置能够结束的所有模式串权值之和

因此：
```cpp
i64 ans{ ac.query(text, score) };
```
即为文本中所有模式匹配的总权值
当所有 `w[i] = 1` 时，就退化为所有模式串出现总次数
##### 判断是否已经匹配禁止模式串
保存所有禁止模式串的终止状态：
```cpp
vector<int> terminal;
for (auto &s : pattern) {
    terminal.push_back(ac.add(s));
}
ac.build();
```
标记终点：
```cpp
vector<char> bad(ac.size());
for (int p : terminal) {
    bad[p] = true;
}
```
因为 Fail 祖先代表当前字符串的后缀，因此需要沿 Fail 正序传播：
```cpp
ac.propagate(bad, [](auto &x, const auto &y) {
    x |= y;
});
```
此时：
```cpp
bad[u]
```
表示到达状态 `u` 时，当前字符串后缀中是否已经出现至少一个禁止模式串
##### AC + 自动机 DP：禁止出现某些模式串
定义：
```cpp
dp[i][u]
```
表示已经构造长度为 `i` 的字符串，且当前处于状态 `u`
转移：
```cpp
for (int u = 1; u < ac.size(); ++ u) if (!bad[u]) {
    for (int c = 0; c < A; ++ c) {
        int v{ ac.next(u, c) };
        if (bad[v]) continue;
        dp[i + 1][v] += dp[i][u];
    }
}
```
即可求：
> 长度为 $n$，且不包含任意禁止模式串的字符串数量

复杂度为：
$$O(nSA)$$
若 $n$ 极大，则状态转移本质为固定矩阵：
$$\boxed{\text{AC 自动机}+\text{矩阵快速幂}}$$
##### AC + 权值 DP
先构造每个状态的当前位置匹配权值：
```cpp
vector<i64> score(ac.size());
for (int i = 0; i < n; ++ i) {
    score[pos[i]] += w[i];
}
ac.propagate_sum(score);
```
从状态 `u` 加字符 `c` 后：
```cpp
int v{ ac.next(u, c) };
```
当前新产生的所有模式匹配贡献正好为：
```cpp
score[v]
```
因此例如最大化长度为 `n` 的字符串的匹配权值：
```cpp
ndp[v] = max(ndp[v], dp[u] + score[v]);
```
可用于：
- 最大 / 最小模式匹配权值
- 固定长度字符串最优构造
- AC + Max-Plus 矩阵快速幂
若 $n$ 极大：
$$\boxed{\text{AC}+\text{Max-Plus 矩阵快速幂}}$$
##### AC + 状压：记录匹配过的模式集合
模式串数量较小时，例如 $m\le20$：
```cpp
vector<int> mask(ac.size());
for (int i = 0; i < m; ++ i) {
    mask[pos[i]] |= 1 << i;
}
```
沿 Fail 正序传播：
```cpp
ac.propagate(mask, [](auto &x, const auto &y) {
    x |= y;
});
```
此时：
```cpp
mask[u]
```
表示到达状态 `u` 时，在当前位置结束的所有模式串集合
之后可以在：
```text
(state, mask)
```
上进行 BFS / DP
典型问题：
- 最短包含全部给定模式串的字符串
- 长度为 $n$ 时至少出现指定模式集合
- 匹配模式集合满足某条件的字符串计数
- 出现至少 / 恰好 $k$ 种模式串
##### AC + 数位 DP
若模式串由数字组成，例如禁止：
```text
13
666
2026
```
建立：
```cpp
AC<10, '0'> ac;
```
将禁止状态按前面的方式构造后，把 AC 状态直接加入数位 DP：
```cpp
dp[pos][state][tight][lead]
```
即可处理：
- `[0,N]` 中不包含禁止数字串的整数数量
- 包含指定数字模式的整数数量
- 数字模式出现次数或权值统计
即：
$$\boxed{\text{AC 状态可以直接作为数位 DP 的一维状态}}$$
注意 `lead` 是否应参与 AC 转移取决于题目对前导零的定义
##### 动态启用 / 禁用模式串：Fail 树 + BIT
假设所有模式串固定，但会动态：
```text
activate(i)
deactivate(i)
```
并询问文本中当前启用模式串的匹配贡献
首先构造 Fail 树，并求 Euler 序：
```cpp
tin[u], tout[u]
```
使 Fail 子树对应：
```text
[tin[u], tout[u])
```
根据：
$$u\text{ 在当前状态 }p\text{ 匹配} \iff u\text{ 是 }p\text{ 的 Fail 树祖先}$$
激活模式终止状态 `u`、权值 `w`，等价于：
```cpp
range_add(tin[u], tout[u], +w);
```
禁用：
```cpp
range_add(tin[u], tout[u], -w);
```
扫描文本：
```cpp
int p{ 1 };
i64 ans{ 0 };
for (char c : text) {
    p = ac.next(p, c);
    ans += point_query(tin[p]);
}
```
因为给 `u` 的整个 Fail 子树加 `w`，正好意味着：
> 所有以 `u` 为 Fail 祖先的状态都会获得该模式串贡献

因此：
$$\boxed{ \text{动态模式匹配} = \text{AC} + \text{Fail 树 Euler 序} + \text{BIT 区间加单点查} }$$
如果 BIT 使用差分形式，则对子树区间 `[l,r)` 加 `w` 可以写成：
```cpp
bit.add(l, w);
bit.add(r, -w);
```
查询状态 `p` 时取 `tin[p]` 的前缀和即可
#### 复杂度
设：
- $M$：所有模式串总长度
- $S$：自动机状态数，$S\le M+2$
- $A$：字符集大小
- $L$：文本长度

| 操作                                            |    时间复杂度 |
| --------------------------------------------- | -------: |
| 插入全部模式串                                       |   $O(M)$ |
| `build()`                                     |  $O(SA)$ |
| 单次 `next()`                                   |   $O(1)$ |
| `scan(text)` / `query(text,score)`            |   $O(L)$ |
| `propagate()` / `aggregate()` / `fail_tree()` |   $O(S)$ |
| `count_states(text)`                          | $O(L+S)$ |
| 禁止串普通自动机 DP                                   | $O(nSA)$ |
空间复杂度为：
$$O(SA)$$
当字符集大小 $A$ 为固定常数，例如小写字母的 `26` 时，通常简记为：
- 建立自动机：$O(M)$
- 扫描文本：$O(L)$
- 空间：$O(M)$
