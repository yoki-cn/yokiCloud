### Bitset LCS
---
```cpp
struct BitsetLCS {
    int m, words;
    u64 last_mask{ ~0ULL };
    array<vector<u64>, 256> pos;
    explicit BitsetLCS(string_view b)
        : m(int(b.size())), words((m + 63) / 64) {
        for (auto &v : pos) v.assign(words, 0);
        for (int i = 0; i < m; ++ i) {
            pos[(unsigned char)b[i]][i >> 6] |= 1ULL << (i & 63);
        }
        if (m % 64) last_mask = (1ULL << (m % 64)) - 1;
    }
    int query(string_view a) const {
        if (!m) return 0;
        vector<u64> s(words);
        for (unsigned char c : a) {
            u64 carry{ 1 }, borrow{ 0 };
            for (int i = 0; i < words; ++ i) {
                u64 old{ s[i] }, x{ pos[c][i] | old }, y{ (old << 1) | carry };
                carry = old >> 63;
                u64 subtrahend{ y + borrow }, sub{ x - subtrahend };
                bool overflow{ subtrahend < y };
                borrow = overflow || x < subtrahend;
                s[i] = x & ~sub;
            }
            s.back() &= last_mask;
        }
        int ans{ 0 };
        for (u64 x : s) ans += popcount(x);
        return ans;
    }
};
int lcs_bitset(string_view a, string_view b) {
    if (a.size() < b.size()) swap(a, b);
    return BitsetLCS(b).query(a);
}
```
#### 接口说明
##### `BitsetLCS`
将固定字符串 `b` 预处理成字符位置位集。
- `BitsetLCS(b)`：预处理 `b`
- `query(a)`：返回 `LCS(a,b)` 的长度
适用于：
> 一个固定 `b`，需要和多个字符串分别求 LCS
##### `lcs_bitset(a,b)`
一次性求：
```cpp
LCS(a, b)
```
内部自动让较短字符串作为位集维度，以降低空间和常数
返回值只有 **LCS 长度**
#### 注意事项
- 这里求的是**最长公共子序列**，不是最长公共子串
- 当前实现针对字节字符集，因此使用 `unsigned char` 的 `0..255`
- `string_view` 中 UTF-8 中文会按字节处理，不是按 Unicode 字符处理
- 如果字符已经离散化到 `[0,A)`，可以把 `256` 改成 `A`，并把字符索引改成离散值
- 该算法支持重复字符，是一般 LCS，不是“位置映射后求 LIS”的特殊版本
- 当前只求长度，不直接恢复一个 LCS
- 需要恢复方案时优先使用普通 DP、Hirschberg 等专门方法
- 多字版本中：
    - 左移进位
    - 无符号减法借位
    - 最后一个 `u64` 的无效高位清零
    都不能删除
- 当 `b.size() <= 64` 时整个 DP 状态只有一个 `u64`，速度尤其快
#### 核心公式
设：
- `S` 表示当前 LCS DP 的差分位集
- `M[c]` 表示字符 `c` 在 `b` 中出现的位置集合
每处理 `a` 中一个字符 `c`：
$$X=M[c]\mid S$$
$$Y=(S\ll1)\mid1$$

$$\boxed{S=X\mathbin{\&}\neg(X-Y)}$$
最终：
$$\boxed{ LCS(a,b)=popcount(S) }$$
板子中复杂的多字借位逻辑，只是在多个 `u64` 上精确实现：
```text
X - Y
```
这个大整数减法
#### 常见用法
##### 一次性求 LCS
```cpp
cout << lcs_bitset(a, b) << '\n';
```
无需手动判断哪一个字符串更短
##### 固定一个字符串，多次查询
例如有很多询问：
```text
LCS(a1, b)
LCS(a2, b)
LCS(a3, b)
...
```
只预处理一次：
```cpp
BitsetLCS lcs(b);
for (auto &a : query) {
    cout << lcs.query(a) << '\n';
}
```
此时位置位集 `pos` 不需要重复构造
##### 小字符集整数序列
假设元素已经离散化到：
```text
[0,A)
```
可以将：
```cpp
array<vector<u64>, 256> pos;
```
改成：
```cpp
array<vector<u64>, A> pos;
```
并将：
```cpp
pos[(unsigned char)b[i]]
```
改成：
```cpp
pos[b[i]]
```
核心算法完全不变
##### 与普通 LCS DP 的选择
经典 DP：
$$O(nm)$$
Bitset LCS：
$$O\left(n\left\lceil\frac m{64}\right\rceil\right)$$
个 `u64` 运算
因此当：
```text
n,m ≈ 10^4 ~ 10^5
```
且只需要长度时，Bitset 优化往往非常有价值
##### 为什么让较短串作为位集维度
算法复杂度近似：
$$|a|\cdot\left\lceil\frac{|b|}{64}\right\rceil$$
交换二者不改变主要乘积数量级，但令 `b` 较短可以减少：
- `pos` 空间
- 单轮位集长度
- 尾部无效位
所以一次性接口自动执行：
```cpp
if (a.size() < b.size()) swap(a, b);
```
##### 与“LCS 转 LIS”的区别
如果第二个序列中的元素唯一，可以将：
```text
元素 -> 第二序列位置
```
映射后求 LIS
但一般存在重复元素时：
```text
LCS != 简单位置映射后的 LIS
```
Bitset LCS 没有这个限制，可以直接处理重复字符
#### 复杂度
令：
- $n=|a|$
- $m=|b|$
- $W=\lceil m/64\rceil$
##### 预处理
`BitsetLCS(b)`：
$$O(m+256W)$$
空间：
$$O(256W)$$
##### 单次查询
`query(a)`：
$$O(nW)$$
因此一次性：
$$\boxed{ O\left( \max(n,m) \left\lceil \frac{\min(n,m)}{64} \right\rceil \right) }$$
实际额外 DP 空间只有：
$$O(W)$$
固定模式串的位置表为：
$$O(256W)$$
