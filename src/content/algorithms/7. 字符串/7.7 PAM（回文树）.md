### PAM（回文树）
---
```cpp
template<int A = 26, int offset = 'a'>
struct PAM {
    struct Node {
        int len{ 0 }, link{ 0 }, num{ 0 };
        i64 occ{ 0 };
        array<int, A> next{};
    };
    vector<Node> t;
    vector<int> s;
    int suff{ 1 };
    explicit PAM(int m = 0) : t(2) {
        t.reserve(m + 2);
        s.reserve(m);
        t[0].len = -1;
    }
    template<class Seg>
    explicit PAM(const Seg &a) : PAM(int(a.size())) { build(a); }
    // ===== 基础函数：插入依赖，不建议删除 =====
    template<class T>
    static int id(const T &c) { return int(c) - offset; }
    int new_node(int len) {
        t.emplace_back();
        t.back().len = len;
        return int(t.size()) - 1;
    }
    // 找最长回文后缀 p，使其两侧可以再加入当前字符
    int get_link(int p) const {
        int i{ int(s.size()) - 1 };
        while (i - t[p].len - 1 < 0 || s[i - t[p].len - 1] != s[i]) {
            p = t[p].link;
        }
        return p;
    }
    // ===== 在线插入：每次最多新建一个本质不同回文串 =====
    bool add_id(int x) {
        s.push_back(x);
        int p{ get_link(suff) };
        bool created{ false };
        if (!t[p].next[x]) {
            int q{ new_node(t[p].len + 2) };
            if (t[q].len == 1) t[q].link = 1;
            else t[q].link = t[get_link(t[p].link)].next[x];
            t[q].num = t[t[q].link].num + 1;
            t[p].next[x] = q;
            created = true;
        }
        suff = t[p].next[x];
        ++ t[suff].occ;
        return created;
    }
    template<class T>
    bool add(const T &c) { return add_id(id(c)); }
    template<class Seg>
    void build(const Seg &a) { for (const auto &c : a) add(c); }
    // ===== 基础状态接口 =====
    int size() const { return int(t.size()); }
    int distinct() const { return int(t.size()) - 2; }
    int longest_suffix() const { return suff; }
    int longest_suffix_len() const { return t[suff].len; }
    int suffix_count() const { return t[suff].num; }
    // 枚举当前串的所有非空回文后缀
    template<class F>
    void suffixes(F f) const {
        for (int p = suff; p > 1; p = t[p].link) f(p);
    }
    // ===== 出现次数统计：不需要完整出现次数时可删除 =====
    vector<i64> count() const {
        vector<i64> res(t.size());
        for (int p = 2; p < t.size(); ++ p) {[p].occ;
        for (int p = int(t.size()) - 1; p >= 2; -- p) res[t[p].link] += res[p];
        return res;
    }
    // ===== 后缀链接树：不需要树上问题时可删除 =====
    vector<vector<int>> link_tree() const {
        vector<vector<int>> g(t.size());
        for (int p = 2; p < t.size(); ++ p) g[t[p].link].push_back(p);
        return g;
    }
};
```
#### 成员变量
- `t[0]`：奇根，`len = -1`
- `t[1]`：偶根，`len = 0`
- `t[p].len`：节点 `p` 对应回文串长度
- `t[p].link`：节点 `p` 的最长真回文后缀
- `t[p].next[c]`：由当前回文串两侧各加入字符 `c` 后得到的回文节点
- `t[p].num`：节点 `p` 的非空回文后缀数量
- `t[p].occ`：节点 `p` 被作为**当前前缀最长回文后缀**访问的次数；不是最终完整出现次数
- `suff`：当前整个字符串的最长回文后缀节点
- `s`：已经加入的字符编号序列
真实回文串节点范围为：
```text
[2, size())
```
##### 接口
- `PAM(m)`：构造空 PAM，`m` 仅用于预留长度
- `PAM(s)`：直接构造字符串 `s` 的 PAM，$O(n)$
- `add(c)`：向末尾加入字符，返回是否新建了一个本质不同回文串，均摊 $O(1)$
- `build(s)`：依次插入整个字符串，$O(n)$
- `size()`：包括两个根的总节点数，$O(1)$
- `distinct()`：当前本质不同非空回文子串数量，$O(1)$
- `longest_suffix()`：当前最长回文后缀节点，$O(1)$
- `longest_suffix_len()`：当前最长回文后缀长度，$O(1)$
- `suffix_count()`：当前前缀的非空回文后缀个数，$O(1)$
- `suffixes(f)`：枚举当前所有非空回文后缀节点，$O(k)$
- `count()`：返回每个回文节点的完整出现次数，$O(S)$
- `link_tree()`：构造回文后缀链接树，$O(S)$
#### 注意事项
- 必须保证字符满足 `0 <= id(c) < A`
- 默认小写字母；大写字母可用 `PAM<26, 'A'>`
- 已经映射到 `[0,A)` 的整数序列使用 `PAM<A, 0>`
- 每加入一个字符，最多产生一个新的本质不同回文串，因此长度为 $n$ 的字符串最多只有 $n$ 个本质不同非空回文子串
- `add(c) == true` 只表示这一步新建了一个本质不同回文串，并不表示该回文串只出现一次
- `t[p].occ` 不是最终完整出现次数；必须调用 `count()` 后读取结果
- 节点创建时 `link` 一定指向更早创建的节点，因此可以按节点编号逆序汇总出现次数
- 若只需要静态区间回文判断，应优先使用 Manacher；PAM 的优势是在线维护**不同回文串及其结构**
- `suffixes()` 最坏一次可能枚举 $O(n)$ 个回文后缀；大量回文 DP 若因此退化，应使用 Series PAM
#### 常见用法
##### 本质不同回文子串数量
```cpp
PAM<> pam(s);
cout << pam.distinct() << '\n';
```
核心结论：
$$\boxed{ \text{PAM 中每个真实节点恰好对应一个本质不同回文子串} }$$
因此：
$$\boxed{ \#\text{distinct palindrome}=size()-2\le n. }$$
##### 在线统计每个前缀新增的本质回文串
```cpp
PAM<> pam;
for (char c : s) {
    bool created{ pam.add(c) };
    if (created) {
        // 当前字符加入后恰好新增了一个本质不同回文串
    }
    cout << pam.distinct() << '\n';
}
```
每次加入一个字符时，所有新出现的回文必须是当前前缀的后缀，而其中只有**最长的那个**可能此前没有出现过，因此一次最多新建一个节点
##### 当前前缀的最长回文后缀
```cpp
pam.add(c);
int p{ pam.longest_suffix() };
int len{ pam.t[p].len };
```
因此 PAM 可以在线维护每个前缀的最长回文后缀
##### 枚举当前所有回文后缀
不断沿 `link`：
```text
suff
link[suff]
link[link[suff]]
...
1
```
恰好枚举当前字符串的所有非空回文后缀
```cpp
pam.suffixes([&](int p) {
    int len{ pam.t[p].len };
    // 当前前缀存在一个长度为 len 的回文后缀
});
```
核心结论：
$$\boxed{ link[p] = p\text{ 对应回文串的最长真回文后缀} }$$
因此整个 `link` 链就是所有回文后缀
##### 当前前缀的回文后缀数量
构造节点时：
$$num[p]=num[link[p]]+1$$
所以：
```cpp
pam.add(c);
cout << pam.suffix_count() << '\n';
```
就是当前前缀的非空回文后缀数量
##### 所有回文子串出现次数总和
每一个回文子串都有唯一的右端点
对于前缀 `s[0..i]`，以 `i` 结尾的回文子串数量正好等于：
```cpp
pam.suffix_count()
```
因此：
```cpp
PAM<> pam;
i64 ans{ 0 };
for (char c : s) {
    pam.add(c);
    ans += pam.suffix_count();
}
```
最终：
$$\boxed{ ans=\text{字符串中所有回文子串的出现次数} }$$
这与 Manacher 的：
```cpp
man.count()
```
得到的是同一个量，只是 PAM 可以在线计算
##### 每个本质回文串的出现次数
```cpp
PAM<> pam(s);
auto occ = pam.count();
for (int p = 2; p < pam.size(); ++ p) {
    cout << pam.t[p].len << ' ' << occ[p] << '\n';
}
```
为什么需要沿 `link` 逆序上传？
每个位置只给其**最长回文后缀**的 `occ` 加 `1`，但它的所有回文后缀也都在该位置出现。
因此：
$$\boxed{ occ[link[p]]\mathrel{+}=occ[p] }$$
即可把所有出现贡献上传完整
##### 求 $\max |P|\cdot occ(P)$
```cpp
auto occ = pam.count();
i64 ans{ 0 };
for (int p = 2; p < pam.size(); ++ p) {
    ans = max(ans, 1LL * pam.t[p].len * occ[p]);
}
```
这是 PAM 最经典的统计用途之一
##### 按长度统计回文串
统计本质不同回文串：
```cpp
vector<int> distinct_by_len(s.size() + 1);
for (int p = 2; p < pam.size(); ++ p) {
    ++ distinct_by_len[pam.t[p].len];
}
```
统计回文出现次数：
```cpp
auto occ = pam.count();
vector<i64> occ_by_len(s.size() + 1);
for (int p = 2; p < pam.size(); ++ p) {
    occ_by_len[pam.t[p].len] += occ[p];
}
```
##### 后缀链接树
将：
```text
link[p] -> p
```
连成树
则：
$$\boxed{ u\text{ 是 }v\text{ 的 link 树祖先} \iff P_u\text{ 是 }P_v\text{ 的回文后缀} }$$
由于 $P_v$ 本身是回文，所以它的回文后缀同时也是回文前缀
```cpp
auto g = pam.link_tree();
```
可以进一步进行：
- 子树统计
- Euler 序
- LCA
- 树上 DP  
- 动态维护某些回文节点
##### 恢复节点对应的实际回文串
核心结构不额外保存位置，但当 `add()` 新建节点时：
```cpp
PAM<> pam;
vector<int> first_end(s.size() + 2, -1);
for (int i = 0; i < s.size(); ++ i) {
    if (pam.add(s[i])) first_end[pam.longest_suffix()] = i;
}
```
于是节点 `p` 的一个首次出现区间为：
```cpp
int r{ first_end[p] + 1 };
int l{ r - pam.t[p].len };
// s[l..r) 即节点 p 对应的回文串
```
这样无需为了少数恢复题在 PAM 核心里永久增加 `first_pos` 字段
#### 复杂度
设字符串长度为 $n$，PAM 节点数为 $S\le n+2$

| 操作                                                   |     时间复杂度 |
| ---------------------------------------------------- | --------: |
| 单次 `add(c)`                                          | 均摊 $O(1)$ |
| `build(s)`                                           |    $O(n)$ |
| `distinct()` / `longest_suffix()` / `suffix_count()` |    $O(1)$ |
| `suffixes()`                                         |    $O(k)$ |
| `count()` / `link_tree()`                            |    $O(S)$ |
固定字符集大小 `A` 时空间复杂度为 $O(n)$；严格写为 $O(SA)$
