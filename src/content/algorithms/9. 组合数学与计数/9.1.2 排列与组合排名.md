### 排列与组合排名
---
排列使用康托展开；组合排名为较低频扩展，可整段删除。依赖已有 `BIT<int>`，组合部分额外依赖 `comb_i128()`
```cpp
struct Cantor {
    static vector<i128> fac(int n) {
        vector<i128> f(n + 1, 1);
        for (int i = 1; i <= n; ++ i) f[i] = f[i - 1] * i;
        return f;
    }
    static i128 rank(const vector<int> &p) {
        int n{ int(p.size()) };
        auto f{ fac(n) };
        BIT<int> fw(vector<int>(n, 1));
        i128 ans{};
        for (int i = 0; i < n; ++ i) {
            ans += i128(fw.sum(p[i])) * f[n - i - 1];
            fw.add(p[i], -1);
        }
        return ans;
    }
    // ===== 以下函数可直接删除：不需要逆排名时 =====
    static vector<int> unrank(int n, i128 r) {
        auto f{ fac(n) };
        BIT<int> fw(vector<int>(n, 1));
        vector<int> p(n);
        for (int i = 0; i < n; ++ i) {
            i128 d{ f[n - i - 1] };
            int k{ int(r / d) };
            r %= d;
            p[i] = fw.kth(k + 1);
            fw.add(p[i], -1);
        }
        return p;
    }
};
// ===== 以下代码可直接删除：组合字典序排名 / 逆排名 =====
i128 comb_rank(int n, const vector<int> &a) {
    int k{ int(a.size()) }, pre{ -1 };
    i128 ans{};
    for (int i = 0; i < k; ++ i) {
        ans += comb_i128(n - pre - 1, k - i) - comb_i128(n - a[i], k - i);
        pre = a[i];
    }
    return ans;
}
vector<int> comb_unrank(int n, int k, i128 r) {
    vector<int> a(k);
    int pre{ -1 };
    for (int i = 0; i < k; ++ i) {
        int rem{ k - i };
        i128 tot{ comb_i128(n - pre - 1, rem) };
        int l{ pre + 1 }, rr{ n - rem };
        while (l < rr) {
            int mid{ (l + rr) / 2 };
            i128 cnt{ tot - comb_i128(n - mid - 1, rem) };
            if (cnt > r) rr = mid;
            else l = mid + 1;
        }
        r -= tot - comb_i128(n - l, rem);
        a[i] = pre = l;
    }
    return a;
}
```
#### 接口说明
##### 康托展开
- `Cantor::rank(p)`：返回排列 `p` 的 `0base` 字典序排名，$O(n\log n)$
- `Cantor::unrank(n,r)`：恢复 `0base` 排名 `r` 对应的排列，$O(n\log n)$
- `p` 必须恰为 `0..n-1` 的排列
- 使用 `i128` 保存阶乘和排名，因此要求 $n!\le2^{127}-1$，即 `n <= 33`
- `unrank()` 要求 $0\le r<n!$
##### 组合排名
- `comb_rank(n,a)`：严格递增组合 `a` 转为 `0base` 字典序排名
- `comb_unrank(n,k,r)`：恢复排名 `r` 对应的严格递增 `k` 元组合
- `a` 要求满足 $0\le a_0<a_1<\cdots<a_{k-1}<n$
- `comb_unrank()` 要求 $0\le r<\binom nk$
- 所有涉及的精确组合数都必须能放入 `i128`
#### 注意事项
- `BIT::sum(r)` 统计 `[0,r)`，因此 `fw.sum(p[i])` 正好表示剩余元素中小于 `p[i]` 的数量
- `BIT::kth(k)` 的 `k` 从 `1` 开始，所以逆康托使用 `fw.kth(k + 1)`
- 这里直接利用 `BIT(vector<T>)` 的 $O(n)$ 建树，不需要逐个 `add(i,1)`
- 康托代码默认输入合法，不额外检查重复元素和越界
- 组合排名是**字典序排名**，与排列的康托展开不是同一种编码
- 组合排名必须使用精确的 `comb_i128()`，不能使用取模后的 `comb.C()`
- `comb_unrank()` 二分确定每一位，适合 $n$ 较大而 $k$ 较小的情况
#### 常见用法
##### 排列排名 / 逆排名
```cpp
i128 r = Cantor::rank(p);
vector<int> q = Cantor::unrank(p.size(), r);
```
##### 组合排名 / 逆排名
```cpp
i128 r = comb_rank(n, a);
vector<int> b = comb_unrank(n, a.size(), r);
```
例如 `n=5,k=3` 时：
```text
0 1 2
0 1 3
0 1 4
0 2 3
0 2 4
0 3 4
1 2 3
...
```
#### 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
|---|---:|---:|
| `Cantor::rank` | $O(n\log n)$ | $O(n)$ |
| `Cantor::unrank` | $O(n\log n)$ | $O(n)$ |
| `comb_rank` | $O(k)$ 次 `comb_i128()` | $O(1)$ |
| `comb_unrank` | $O(k\log n)$ 次 `comb_i128()` | $O(k)$ |
