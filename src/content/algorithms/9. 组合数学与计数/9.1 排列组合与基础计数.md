### 排列组合与基础计数
---
#### 杨辉三角（Pascal's Triangle）
```cpp
vector<vector<i64>> pascal(int n, i64 mod) {
    vector c(n + 1, vector<i64>(n + 1));
    c[0][0] = 1 % mod;
    for (int i = 1; i <= n; ++ i) {
        c[i][0] = c[i][i] = 1 % mod;
        for (int j = 1; j < i; ++ j) {
            c[i][j] = (i128(c[i - 1][j - 1]) + c[i - 1][j]) % mod;
        }
    }
    return c;
}
```
- `pascal(n, mod)`：返回所有 $0\le k\le i\le n$ 的 $\binom{i}{k}\bmod mod$；要求 `n >= 0`、`mod > 0`，$O(n^2)$
#### 精确组合数
```cpp
i128 comb_i128(i64 n, i64 k) {
    if (n < 0 || k < 0 || k > n) return 0;
    k = min(k, n - k);
    i128 ans{ 1 };
    for (i64 i = 1; i <= k; ++ i) {
        i64 a{ n - k + i }, b{ i };
        i64 g{ gcd(a, b) };
        a /= g;
        b /= g;
        g = gcd(i64(ans % b), b);
        ans /= g;
        b /= g;
        ans *= a;
    }
    return ans;
}
template<class Big>
Big comb_big(i64 n, i64 k) {
    if (n < 0 || k < 0 || k > n) return Big(0);
    k = min(k, n - k);
    Big ans{ 1 };
    for (i64 i = 1; i <= k; ++ i) {
        ans *= n - k + i;
        ans /= i;
    }
    return ans;
}
```

#### 基础排列、分组与配对

| 问题 | 方案数 | 条件 |
|---|---:|---|
| $n$ 个不同元素中选 $k$ 个，不计顺序 | $\binom nk$ | 子集计数 |
| $n$ 个不同元素中依次选 $k$ 个 | $P(n,k)$ | 顺序不同视为不同 |
| 第 $i$ 类有 $c_i$ 个相同元素 | $\dfrac{n!}{\prod_i c_i!}$ | $\sum_i c_i=n$ |
| 分入大小为 $n_i$ 的有标号组 | $\dfrac{n!}{\prod_i n_i!}$ | $\sum_i n_i=n$ |
| 大小为 $s$ 的无标号组恰有 $m_s$ 个 | $\dfrac{n!}{\prod_s(s!)^{m_s}m_s!}$ | $\sum_s sm_s=n$ |
| $n$ 个互异元素作圆排列 | $(n-1)!$ | 只把旋转视为相同 |
| $n\ge3$ 个互异元素作手链排列 | $(n-1)!/2$ | 旋转、翻转均视为相同 |
| 将 $2n$ 个不同元素两两配对 | $(2n-1)!!=\dfrac{(2n)!}{2^n n!}$ | 每对无序，各对之间无序 |
从 $n$ 个不同元素中选择 $k>0$ 个再作圆排列：
$$
\frac{P(n,k)}k=\binom nk(k-1)!
$$
从一列 $n$ 个位置中选 $k$ 个且两两不相邻：
$$
\binom{n-k+1}{k}
$$
#### 隔板法与整数解
对
$$
x_1+\cdots+x_k=n
$$
有：

| 限制 | 解数 |
|---|---:|
| $x_i\ge0$ | $\binom{n+k-1}{k-1}$ |
| $x_i\ge1$ | $\binom{n-1}{k-1}$ |
| $x_i\ge L_i$ | $\binom{n-\sum_iL_i+k-1}{k-1}$ |
正整数 $n$ 恰好拆成 $k$ 个有序正整数有 $\binom{n-1}{k-1}$ 种；拆成任意个有序正整数共有 $2^{n-1}$ 种
若 $0\le x_i\le u_i$，对事件 $x_i\ge u_i+1$ 容斥：
$$
\sum_{S\subseteq[k]}(-1)^{|S|}
\binom{n-\sum_{i\in S}(u_i+1)+k-1}{k-1}
$$
若所有上界相同为 $u$：
$$
\sum_{j=0}^k(-1)^j\binom kj
\binom{n-j(u+1)+k-1}{k-1}
$$

#### 容斥、错排与禁止位置
若 $A_i$ 表示违反第 $i$ 个条件的方案集合，则
$$
\left|U\setminus\bigcup_{i=1}^nA_i\right|=\sum_{S\subseteq[n]}(-1)^{|S|}
\left|\bigcap_{i\in S}A_i\right|
$$

错排数：
$$
D_0=1,\quad D_1=0,\quad
D_n=(n-1)(D_{n-1}+D_{n-2})
=n!\sum_{k=0}^n\frac{(-1)^k}{k!}
$$
恰有 $k$ 个不动点的排列数：
$$
\binom nkD_{n-k}
$$
一般禁止位置中，若 $r_k$ 为在禁止格中放置 $k$ 个互不同行、互不同列的车的方案数，则合法排列数为
$$
\sum_{k=0}^n(-1)^kr_k(n-k)!
$$
#### 网格路径、反射原理与投票问题
从 $(0,0)$ 到 $(a,b)$，每步向右或向上：
$$
\binom{a+b}{a}
$$
必须经过 $(x,y)$：
$$
\binom{x+y}{x}\binom{a+b-x-y}{a-x}
$$
当 $a\ge b$ 且全程要求 $y\le x$：
$$
\binom{a+b}{b}-\binom{a+b}{b-1}=\frac{a-b+1}{a+1}\binom{a+b}{b}
$$
Bertrand 投票问题中，$a>b$ 且 A 全程严格领先：
$$
\frac{a-b}{a+b}\binom{a+b}{a}
$$
Raney 引理：若整数序列每项 $a_i\le1$ 且总和为 $r>0$，则按起点计的循环移位中恰有 $r$ 个满足所有非空前缀和均为正
#### 常用组合恒等式

| 名称 | 恒等式 |
|---|---|
| 二项式定理 | $(x+y)^n=\sum_{k=0}^n\binom nkx^ky^{n-k}$ |
| 奇偶项和 | $\sum_{k\text{ even}}\binom nk=\sum_{k\text{ odd}}\binom nk=2^{n-1}$，$n\ge1$ |
| Hockey-stick | $\sum_{i=r}^n\binom ir=\binom{n+1}{r+1}$ |
| Vandermonde | $\sum_k\binom ak\binom b{n-k}=\binom{a+b}n$ |
| 平方和 | $\sum_k\binom nk^2=\binom{2n}n$ |
| 一阶带权和 | $\sum_k k\binom nk=n2^{n-1}$ |
| 二阶下降幂和 | $\sum_k k(k-1)\binom nk=n(n-1)2^{n-2}$ |
| 二阶幂和 | $\sum_k k^2\binom nk=n(n+1)2^{n-2}$ |
| Fibonacci 对角线 | $\sum_{k\ge0}\binom{n-k}{k}=F_{n+1}$ |
| 嵌套选集 | $\binom nm\binom mk=\binom nk\binom{n-k}{m-k}$ |
二项式反演：
$$
f_n=\sum_{k=0}^n\binom nk g_k
\iff
g_n=\sum_{k=0}^n(-1)^{n-k}\binom nkf_k
$$
#### 题型识别

| 题目特征 | 优先检查 |
|---|---|
| 相同物品分给不同对象、变量和固定 | 隔板法；有上界再容斥 |
| 不同物品分成无标号非空组 | 第二类 Stirling 数 |
| 排列统计置换环、下降位置 | 第一类 Stirling 数、Eulerian 数 |
| 每个元素不能回原位、一般禁止位置 | 错排、车多项式、容斥 |
| 合法括号、栈序列、二叉树、三角剖分 | Catalan 数 |
| 单调路径不能越过直线边界 | 反射原理、投票问题 |
| 每种物品可选次数不同 | 背包 DP、生成函数 |
| 旋转或翻转后视为相同 | Burnside、Pólya |
| 有标号树或一般图生成树 | Prüfer、Matrix--Tree |
