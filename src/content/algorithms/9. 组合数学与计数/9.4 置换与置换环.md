### 置换与置换环
---
**解决问题：** 对置换求复合、逆、幂、循环分解、阶与奇偶性，并利用置换环分析周期结构
约定 `p[i]` 表示置换把 `i` 映射到 `p[i]`
```cpp
struct Perm {
    vector<int> p;
    explicit Perm(int n = 0) : p(n) { iota(p.begin(), p.end(), 0); }
    explicit Perm(vector<int> p_) : p(move(p_)) {}
    int size() const { return p.size(); }
    int &operator[](int i) { return p[i]; }
    const int &operator[](int i) const { return p[i]; }
    // p * q = p ∘ q：先作用 q，再作用 p
    Perm operator*(const Perm &q) const {
        int n{ size() };
        Perm r(n);
        for (int i = 0; i < n; ++ i) r[i] = p[q[i]];
        return r;
    }
    Perm inv() const {
        int n{ size() };
        Perm q(n);
        for (int i = 0; i < n; ++ i) q[p[i]] = i;
        return q;
    }
    vector<vector<int>> cycles() const {
        int n{ size() };
        vector<char> vis(n);
        vector<vector<int>> res;
        for (int i = 0; i < n; ++ i) if (!vis[i]) {
            vector<int> c;
            for (int u = i; !vis[u]; u = p[u]) {
                vis[u] = true;
                c.push_back(u);
            }
            res.push_back(move(c));
        }
        return res;
    }
    // O(n)，支持负指数
    Perm pow(i64 k) const {
        int n{ size() };
        Perm r(n);
        for (const auto &c : cycles()) {
            int m{ int(c.size()) };
            int d{ int(k % m) };
            if (d < 0) d += m;
            for (int i = 0; i < m; ++ i) r[c[i]] = c[(i + d) % m];
        }
        return r;
    }
    // ===== 以下函数可直接删除：只需要基本置换运算时 =====
    vector<int> lens() const {
        vector<int> a;
        for (const auto &c : cycles()) a.push_back(c.size());
        return a;
    }
    i64 ord() const {
        i64 res{ 1 };
        for (int x : lens()) res = lcm(res, i64(x));
        return res;
    }
    // 0：偶置换，1：奇置换
    int parity() const {
        return (size() - int(cycles().size())) & 1;
    }
};
```
#### 抽象模型
一个 `0..n-1` 上的置换是一个双射
$$p:[0,n)\to[0,n)$$
把每个 `i` 向 `p[i]` 连一条有向边，由于每个点的入度、出度都恰为 \(1\)，整个图一定分解成若干个**互不相交的有向环**：
$$p=(a_1\,a_2\,\ldots\,a_k)
(b_1\,b_2\,\ldots\,b_m)\cdots$$
因此处理置换时最重要的思想是：
> **不要把它当普通数组；先考虑能不能拆成置换环**
很多看似需要快速幂、图遍历的问题，在环上都只是取模
#### 接口说明
- `Perm(n)`：构造大小为 `n` 的恒等置换
- `Perm(p)`：由映射数组构造置换
- `p * q`：置换复合，定义为 \(p\circ q\)，即**先 `q` 后 `p`**
- `p.inv()`：返回逆置换
- `p.cycles()`：返回所有置换环，包括长度为 `1` 的不动点
- `p.pow(k)`：返回 \(p^k\)，支持负指数
- `p.lens()`：返回所有置换环长度
- `p.ord()`：返回置换的阶
- `p.parity()`：`0` 表示偶置换，`1` 表示奇置换
所有接口要求 `p` 恰为 `0..n-1` 的一个排列；代码不额外检查合法性
#### 置换复合与逆
若
$$r=p\circ q$$
则
$$r(i)=p(q(i))$$
代码中约定：
```cpp
Perm r = p * q;
```
表示先作用 `q`，再作用 `p`
逆置换满足
$$p^{-1}(p(i))=i$$
因此直接：
```cpp
q[p[i]] = i;
```
即可在 $O(n)$ 求出
注意置换复合一般**不满足交换律**：
$$pq\ne qp$$
所以复合顺序必须统一
#### 置换幂
若一个环为
$$(a_0\,a_1\,\ldots\,a_{m-1})$$
则
$$p(a_i)=a_{i+1\bmod m}$$
于是
$$p^k(a_i)=a_{i+k\bmod m}$$
所以 `pow(k)` 不需要普通二进制快速幂，可以直接在每个环上移动
$$k\bmod m$$
个位置，总复杂度只有
$$O(n)$$
这比把置换当普通映射做 $$O(n\log k)$$ 快速幂更自然
##### 负指数
因为
$$p^{-k}=(p^{-1})^k$$
环上只需把位移
$$k\bmod m$$
调整到 `0..m-1`，因此同一份代码可以直接处理负数 `k`
#### 置换的阶
置换的阶是最小正整数 $t$，满足
$$p^t=\operatorname{id}$$
若置换环长度分别为
$$l_1,l_2,\ldots,l_c$$
则
$$\boxed{
\operatorname{ord}(p)
=
\operatorname{lcm}(l_1,l_2,\ldots,l_c)
}
$$
原因是每个环都必须同时回到原位
> `ord()` 使用 `i64`，调用前应保证所有环长的最小公倍数不会溢出
#### $p^k$ 的环结构
一个长度为 $m$ 的环，在 $p^k$ 中会分裂成
$$\gcd(m,k)$$
个环，每个环长度为
$$\frac{m}{\gcd(m,k)}$$
因此若 `p` 的环长为 $l_1,\ldots,l_c$，则
$$
\boxed{
c(p^k)
=
\sum_{i=1}^c\gcd(l_i,k)
}
$$
其中 $c(q)$ 表示置换 `q` 的置换环数量
##### $p^k$ 的不动点
原来一个长度为 $m$ 的环中的所有元素在 $p^k$ 下都是不动点，当且仅当
$$m\mid k$$
若长度为 $m$ 的环有 $a_m$ 个，则
$$\boxed{
|\operatorname{Fix}(p^k)|
=
\sum_{m\mid k}m\,a_m
}
$$
这在循环群作用计数里尤其常见
#### 奇偶性与交换次数
一个长度为 $m$ 的环可以写成 $m-1$ 个交换：
$$
(a_1\,a_2\,\ldots\,a_m)
=
(a_1\,a_m)\cdots(a_1\,a_3)(a_1\,a_2)
$$
若一个 $n$ 元置换共有 $c$ 个环，包括不动点，则总共需要
$$n-c$$
个交换
因此置换符号为
$$\operatorname{sgn}(p)=(-1)^{n-c}$$
所以：
- $n-c$ 为偶数：偶置换
- $n-c$ 为奇数：奇置换
同时，
$$\boxed{n-c}$$
也是把该置换变成恒等置换所需的**最少交换次数**
这与逆序数奇偶性一致：
$$\operatorname{inv}(p)\equiv n-c\pmod2$$
#### 环型与共轭
只记录各个环的长度，而忽略环中具体元素，得到置换的**环型**
例如
$$(0\,3\,2)(1\,5)(4)$$
的环型为
$$(3,2,1)$$
所以一个 $n$ 元置换的环型，本质上就是 $n$ 的一个整数分拆
在对称群 $S_n$ 中：
$$\boxed{
p,q\text{ 共轭}
\iff
p,q\text{ 环型相同}
}
$$
因此以后处理 Burnside、共轭类或置换群时，很多时候真正重要的并不是具体置换，而是**各种长度的环分别有多少个**
若长度为 $i$ 的环恰有 $m_i$ 个，
$$\sum_{i\ge1}i\,m_i=n$$
则具有该环型的置换数为
$$\boxed{
\frac{n!}
{\displaystyle\prod_{i\ge1}i^{m_i}m_i!}
}
$$
#### 与经典数列的关系
无符号第一类 Stirling 数
$$\left[{n\atop k}\right]$$
正好计数：
> `n` 元置换恰有 `k` 个置换环的方案数
#### 常见用法
##### 循环分解
```cpp
Perm p(a);
auto cs = p.cycles();
for (const auto &c : cs) {
    // c 是一个置换环
}
```
##### 求逆置换
```cpp
Perm q = p.inv();
```
##### 复合
```cpp
Perm r = p * q; // r = p ∘ q，先 q 后 p
```
##### 求很大的置换幂
```cpp
Perm q = p.pow(k);
```
即使 `k` 很大，也只需 $$O(n)$$
##### 求周期
```cpp
i64 t = p.ord();
```
满足
$$p^t=\operatorname{id}$$
##### 判断奇偶置换
```cpp
if (p.parity()) {
    // 奇置换
} else {
    // 偶置换
}
```
#### 题型识别

| 题目特征                  | 优先检查                      |
| --------------------- | ------------------------- |
| 每个元素恰好映射到另一个元素，且映射为双射 | 置换环                       |
| 重复执行同一个重排很多次          | 环分解 + `k % len`           |
| 求多少次操作后整体恢复           | 环长 `lcm`                  |
| 求重复作用后的环数             | $\sum\gcd(l_i,k)$         |
| 求重复作用后的不动点            | 枚举满足 $l_i\mid k$ 的环       |
| 最少交换多少次恢复             | $n-c$                     |
| 判断奇偶置换                | $(n-c)\bmod2$             |
| 只关心置换的结构、不关心具体标号      | 环型                        |
| 统计恰有 `k` 个环的排列        | 第一类 Stirling              |
| 排列字典序排名               | 康托展开                      |
| 统计下降位置                | Eulerian 数                |
| 旋转、反射等对称操作计数          | 下一节群作用 / Burnside / Pólya |
## 注意事项
- 本节全部采用 `0base`
- `p[i]` 表示 `i -> p[i]`
- `p * q` 定义为 \(p\circ q\)，即先 `q` 后 `p`
- `cycles()` **包含不动点**
- `parity()` 和最少交换次数计算环数时也必须包含不动点
- 普通置换幂不要写成 \(O(n\log k)\) 快速幂；利用环可以做到 \(O(n)\)
- `ord()` 的最小公倍数可能超过 `i64`
- “排列的逆序数”“下降数”等是排列作为序列的统计量；“环长、阶、共轭类”等是置换作为映射的结构量，两类概念不要混在一起
#### 复杂度

| 接口                                                                          |  时间复杂度 |  空间复杂度 |
| --------------------------------------------------------------------------- | -----: | -----: |
| `p * q` / `inv()` / `cycles()` / `pow(k)` / `lens()` / `ord()` / `parity()` | $O(n)$ | $O(n)$ |
