### 经典数列与分拆
---
```cpp
// ===== 第一类 Stirling：n 元排列恰有 k 个置换环 =====
template<class T = Z>
vector<vector<T>> stir1(int n) {
    vector s(n + 1, vector<T>(n + 1));
    s[0][0] = 1;
    for (int i = 1; i <= n; ++ i) {
        for (int k = 1; k <= i; ++ k) {
            s[i][k] = s[i - 1][k - 1] + T(i - 1) * s[i - 1][k];
        }
    }
    return s;
}
// ===== 第二类 Stirling：n 个不同元素分成 k 个非空无标号集合 =====
template<class T = Z>
vector<vector<T>> stir2(int n) {
    vector s(n + 1, vector<T>(n + 1));
    s[0][0] = 1;
    for (int i = 1; i <= n; ++ i) {
        for (int k = 1; k <= i; ++ k) {
            s[i][k] = s[i - 1][k - 1] + T(k) * s[i - 1][k];
        }
    }
    return s;
}
// ===== Eulerian：n 元排列恰有 k 个下降位置 =====
template<class T = Z>
vector<vector<T>> euler(int n) {
    vector a(n + 1, vector<T>(n + 1));
    a[0][0] = 1;
    for (int i = 1; i <= n; ++ i) {
        for (int k = 0; k < i; ++ k) {
            a[i][k] = T(k + 1) * a[i - 1][k];
            if (k) a[i][k] += T(i - k) * a[i - 1][k - 1];
        }
    }
    return a;
}
// ===== Bell：n 个不同元素划分成任意个非空无标号集合 =====
// Bell 三角，O(n) 空间；只需要 Bell 时比先求 stir2 更省空间。
template<class T = Z>
vector<T> bell(int n) {
    vector<T> b(n + 1), a(n + 1);
    b[0] = a[0] = 1;
    for (int i = 1; i <= n; ++ i) {
        T pre{ a[0] };
        a[0] = a[i - 1];
        for (int k = 1; k <= i; ++ k) {
            T cur{ a[k] };
            a[k] = a[k - 1] + pre;
            pre = cur;
        }
        b[i] = a[0];
    }
    return b;
}
// ===== p(n,k)：n 无序分拆成恰好 k 个正整数 =====
template<class T = Z>
vector<vector<T>> part_k(int n) {
    vector p(n + 1, vector<T>(n + 1));
    p[0][0] = 1;
    for (int s = 1; s <= n; ++ s) {
        for (int k = 1; k <= s; ++ k) {
            p[s][k] = p[s - 1][k - 1] + p[s - k][k];
        }
    }
    return p;
}
// ===== p(n)：Euler 五边形数递推 =====
template<class T = Z>
vector<T> part(int n) {
    vector<T> p(n + 1);
    p[0] = 1;
    for (int i = 1; i <= n; ++ i) {
        for (i64 k = 1; ; ++ k) {
            i64 a{ k * (3 * k - 1) / 2 };
            if (a > i) break;
            if (k & 1) p[i] += p[i - a];
            else p[i] -= p[i - a];
            i64 b{ k * (3 * k + 1) / 2 };
            if (b <= i) {
                if (k & 1) p[i] += p[i - b];
                else p[i] -= p[i - b];
            }
        }
    }
    return p;
}
```
#### 接口说明
- `stir1<T>(n)`：返回无符号第一类 Stirling 数 $[i\ k]$，$0\le i,k\le n$
- `stir2<T>(n)`：返回第二类 Stirling 数 $\{i\ k\}$
- `euler<T>(n)`：返回 Eulerian 数，`a[i][k]` 表示 $i$ 元排列恰有 $k$ 个下降位置
- `bell<T>(n)`：返回 $B_0,\ldots,B_n$
- `part_k<T>(n)`：返回 $p(i,k)$，即 $i$ 无序分拆成恰好 $k$ 个正整数的方案数
- `part<T>(n)`：返回整数分拆数 $p(0),\ldots,p(n)$
#### 注意事项
- `stir1()` 返回的是**无符号**第一类 Stirling 数；有符号版本为 $(-1)^{n-k}[n\ k]$
- `stir2[n][k]\cdot k!` 是从 $n$ 元集合到 $k$ 元集合的满射数
- `euler[n][k]` 中的 `k` 表示下降位置数量，范围为 $0\le k<n$
- `part_k()` 的分拆不计顺序；正整数的**有序拆分**是 composition，不是整数分拆
- `part()` 中五边形数的符号按 `+,+,-,-,+,+,...` 循环
- 显式公式出现除法时要确认分母可逆；上述递推代码只有加减乘，没有这一限制
- 若只求很大的某一个下标，应使用对应的快速算法或生成函数方法，不应机械预处理到该下标
#### 常见用法
##### Catalan 数
Catalan 数常见于：
- $n$ 对合法括号
- Dyck 路径
- $n$ 个结点的有根有序二叉树
- 凸 $(n+2)$ 边形三角剖分
- 不越过对角线的 $(n,n)$ 单调路径
$$
\operatorname{Cat}_n
=
\frac1{n+1}\binom{2n}n
=
\binom{2n}n-\binom{2n}{n+1}
$$
已有 `Comb` 时无需单独板子：
```cpp
Z cat = comb.C(2 * n, n) - comb.C(2 * n, n + 1);
```
后一个形式不需要显式除以 $n+1$
若普通 `Comb::C()` 的范围不满足要求，换用 Lucas 或任意模组合数接口
递推为
$$
\operatorname{Cat}_0=1,\qquad
\operatorname{Cat}_n=
\sum_{i=0}^{n-1}\operatorname{Cat}_i\operatorname{Cat}_{n-1-i}
$$
相邻项满足
$$
\operatorname{Cat}_n
=
\operatorname{Cat}_{n-1}\frac{4n-2}{n+1}
$$
##### Motzkin 数
Motzkin 路径每步为 $(1,1)$、$(1,0)$ 或 $(1,-1)$，从 $(0,0)$ 到 $(n,0)$ 且不低于横轴
$$
M_0=1,\qquad
M_n=M_{n-1}+\sum_{i=0}^{n-2}M_iM_{n-2-i}
$$
也有
$$
M_n=
\sum_{k=0}^{\lfloor n/2\rfloor}
\binom n{2k}\operatorname{Cat}_k
$$
递推很短且使用频率较低，不单独保留代码
##### Stirling、Bell 与 Eulerian

| 数列                             | 计数对象                      | 递推                                                                            |
| ------------------------------ | ------------------------- | ----------------------------------------------------------------------------- |
| 第一类 Stirling $[n\ k]$          | $n$ 元排列恰有 $k$ 个置换环        | $[n\ k]=[n-1\ k-1]+(n-1)[n-1\ k]$                                             |
| 第二类 Stirling $\{n\ k\}$        | $n$ 个不同元素划分成 $k$ 个非空无标号集合 | $\{n\ k\}=\{n-1\ k-1\}+k\{n-1\ k\}$                                           |
| Bell $B_n$                     | 划分成任意数量的非空无标号集合           | $B_n=\sum_{k=0}^n\{n\ k\}$                                                    |
| Eulerian $\langle n\ k\rangle$ | $n$ 元排列恰有 $k$ 个下降位置       | $\langle n\ k\rangle=(k+1)\langle n-1\ k\rangle+(n-k)\langle n-1\ k-1\rangle$ |
第二类 Stirling 的显式式：
$$
\left\{{n\atop k}\right\}
=
\frac1{k!}
\sum_{i=0}^k(-1)^i
\binom ki(k-i)^n
$$
Eulerian 数显式式：
$$
\left\langle{n\atop k}\right\rangle
=
\sum_{j=0}^{k+1}
(-1)^j\binom{n+1}j(k+1-j)^n
$$
$$\left\langle{n\atop k}\right\rangle = \left\langle{n\atop n-1-k}\right\rangle$$
$$\sum_{k=0}^{n-1} \left\langle{n\atop k}\right\rangle=n!$$
Worpitzky 恒等式：
$$x^n = \sum_{k=0}^{n-1} \left\langle{n\atop k}\right\rangle \binom{x+k}{n}$$
它可以理解成另一种“普通幂 → 组合数基”的换基关系

如果已经计算 `stir2`，Bell 数可直接求：
```cpp
auto s = stir2(n);
Z B{};
for (int k = 0; k <= n; ++ k) B += s[n][k];
```
只需要所有 Bell 数时使用 `bell(n)`，可把空间降到 $O(n)$
##### 错排
错排数 $D_n$：
$$
D_0=1,\quad D_1=0
$$
$$
D_n=(n-1)(D_{n-1}+D_{n-2})
$$

亦有
$$
D_n
=
n!\sum_{k=0}^n\frac{(-1)^k}{k!}
$$
递推只有一行，不单独保留代码
##### 对合排列
所有置换环长度只能为 $1$ 或 $2$：
$$
I_0=I_1=1
$$
$$
I_n=I_{n-1}+(n-1)I_{n-2}
$$
也可写为
$$
I_n=
\sum_{k=0}^{\lfloor n/2\rfloor}
\frac{n!}{2^k k!(n-2k)!}
$$
同样不单独维护代码
##### 指定置换环结构
若长度为 $i$ 的置换环恰有 $m_i$ 个，且
$$
\sum_{i\ge1}im_i=n
$$
则排列数为
$$
\frac{n!}
{\displaystyle\prod_{i\ge1}i^{m_i}m_i!}
$$
##### 整数分拆
$p(n,k)$ 表示把 $n$ 无序分拆成恰好 $k$ 个正整数：
$$
p(n,k)=p(n-1,k-1)+p(n-k,k)
$$
且
$$
p(n)=\sum_{k=0}^np(n,k)
$$
只需要 $p(n)$ 时，五边形数递推更快。令
$$
g_k^-=\frac{k(3k-1)}2,\qquad
g_k^+=\frac{k(3k+1)}2
$$
则
$$
p(0)=1
$$
$$
p(n)=
\sum_{k\ge1}(-1)^{k-1}
\left(
p(n-g_k^-)+p(n-g_k^+)
\right)
$$
负下标项视为 $0$
整数分拆生成函数：
$$
\sum_{n\ge0}p(n)x^n
=
\prod_{i\ge1}\frac1{1-x^i}
$$
分拆成互不相同的正整数，与分拆成奇数的方案数相同：
$$
\prod_{i\ge1}(1+x^i)
=
\prod_{i\ge1}\frac1{1-x^{2i-1}}
$$
#### 复杂度

| 接口          |         时间复杂度 |    空间复杂度 |
| ----------- | ------------: | -------: |
| `stir1(n)`  |      $O(n^2)$ | $O(n^2)$ |
| `stir2(n)`  |      $O(n^2)$ | $O(n^2)$ |
| `euler(n)`  |      $O(n^2)$ | $O(n^2)$ |
| `bell(n)`   |      $O(n^2)$ |   $O(n)$ |
| `part_k(n)` |      $O(n^2)$ | $O(n^2)$ |
| `part(n)`   | $O(n\sqrt n)$ |   $O(n)$ |
