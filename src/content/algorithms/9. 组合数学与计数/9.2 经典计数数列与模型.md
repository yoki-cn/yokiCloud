### 经典数列与分拆
---
```cpp
// ===== 第一类 Stirling：n 元排列恰有 k 个置换环 =====
template<class T = Z>
vector<vector<T>> stir1(int n) {
    vector s(n + 1, vector<T>(n + 1));
    s[0][0] = 1;
    for (int i = 1; i <= n; ++ i) {
        for (int k = 1; k <= i; ++ k) {
            s[i][k] = s[i - 1][k - 1] + T(i - 1) * s[i - 1][k];
        }
    }
    return s;
}
// ===== 第二类 Stirling：n 个不同元素分成 k 个非空无标号集合 =====
template<class T = Z>
vector<vector<T>> stir2(int n) {
    vector s(n + 1, vector<T>(n + 1));
    s[0][0] = 1;
    for (int i = 1; i <= n; ++ i) {
        for (int k = 1; k <= i; ++ k) {
            s[i][k] = s[i - 1][k - 1] + T(k) * s[i - 1][k];
        }
    }
    return s;
}
// ===== Eulerian：n 元排列恰有 k 个下降位置 =====
template<class T = Z>
vector<vector<T>> euler(int n) {
    vector a(n + 1, vector<T>(n + 1));
    a[0][0] = 1;
    for (int i = 1; i <= n; ++ i) {
        for (int k = 0; k < i; ++ k) {
            a[i][k] = T(k + 1) * a[i - 1][k];
            if (k) a[i][k] += T(i - k) * a[i - 1][k - 1];
        }
    }
    return a;
}
// ===== Bell：n 个不同元素划分成任意个非空无标号集合 =====
// Bell 三角，O(n) 空间；只需要 Bell 时比先求 stir2 更省空间。
template<class T = Z>
vector<T> bell(int n) {
    vector<T> b(n + 1), a(n + 1);
    b[0] = a[0] = 1;
    for (int i = 1; i <= n; ++ i) {
        T pre{ a[0] };
        a[0] = a[i - 1];
        for (int k = 1; k <= i; ++ k) {
            T cur{ a[k] };
            a[k] = a[k - 1] + pre;
            pre = cur;
        }
        b[i] = a[0];
    }
    return b;
}
// ===== p(n,k)：n 无序分拆成恰好 k 个正整数 =====
template<class T = Z>
vector<vector<T>> part_k(int n) {
    vector p(n + 1, vector<T>(n + 1));
    p[0][0] = 1;
    for (int s = 1; s <= n; ++ s) {
        for (int k = 1; k <= s; ++ k) {
            p[s][k] = p[s - 1][k - 1] + p[s - k][k];
        }
    }
    return p;
}
// ===== p(n)：Euler 五边形数递推 =====
template<class T = Z>
vector<T> part(int n) {
    vector<T> p(n + 1);
    p[0] = 1;
    for (int i = 1; i <= n; ++ i) {
        for (i64 k = 1; ; ++ k) {
            i64 a{ k * (3 * k - 1) / 2 };
            if (a > i) break;
            if (k & 1) p[i] += p[i - a];
            else p[i] -= p[i - a];
            i64 b{ k * (3 * k + 1) / 2 };
            if (b <= i) {
                if (k & 1) p[i] += p[i - b];
                else p[i] -= p[i - b];
            }
        }
    }
    return p;
}
```
#### 接口说明
- `stir1<T>(n)`：返回无符号第一类 Stirling 数 $[i\ k]$，$0\le i,k\le n$
- `stir2<T>(n)`：返回第二类 Stirling 数 $\{i\ k\}$
- `euler<T>(n)`：返回 Eulerian 数，`a[i][k]` 表示 $i$ 元排列恰有 $k$ 个下降位置
- `bell<T>(n)`：返回 $B_0,\ldots,B_n$
- `part_k<T>(n)`：返回 $p(i,k)$，即 $i$ 无序分拆成恰好 $k$ 个正整数的方案数
- `part<T>(n)`：返回整数分拆数 $p(0),\ldots,p(n)$
#### 注意事项
- `stir1()` 返回的是**无符号**第一类 Stirling 数；有符号版本为 $(-1)^{n-k}[n\ k]$
- `stir2[n][k]\cdot k!` 是从 $n$ 元集合到 $k$ 元集合的满射数
- `euler[n][k]` 中的 `k` 表示下降位置数量，范围为 $0\le k<n$
- `part_k()` 的分拆不计顺序；正整数的**有序拆分**是 composition，不是整数分拆
- `part()` 中五边形数的符号按 `+,+,-,-,+,+,...` 循环
- 显式公式出现除法时要确认分母可逆；上述递推代码只有加减乘，没有这一限制
- 若只求很大的某一个下标，应使用对应的快速算法或生成函数方法，不应机械预处理到该下标
#### 常见用法
##### Catalan 数
Catalan 数常见于：
- $n$ 对合法括号
- Dyck 路径
- $n$ 个结点的有根有序二叉树
- 凸 $(n+2)$ 边形三角剖分
- 不越过对角线的 $(n,n)$ 单调路径
$$
\operatorname{Cat}_n
=
\frac1{n+1}\binom{2n}n
=
\binom{2n}n-\binom{2n}{n+1}
$$
已有 `Comb` 时无需单独板子：
```cpp
Z cat = comb.C(2 * n, n) - comb.C(2 * n, n + 1);
```
后一个形式不需要显式除以 $n+1$
若普通 `Comb::C()` 的范围不满足要求，换用 Lucas 或任意模组合数接口
递推为
$$
\operatorname{Cat}_0=1,\qquad
\operatorname{Cat}_n=
\sum_{i=0}^{n-1}\operatorname{Cat}_i\operatorname{Cat}_{n-1-i}
$$
相邻项满足
$$
\operatorname{Cat}_n
=
\operatorname{Cat}_{n-1}\frac{4n-2}{n+1}
$$
##### Motzkin 数
Motzkin 路径每步为 $(1,1)$、$(1,0)$ 或 $(1,-1)$，从 $(0,0)$ 到 $(n,0)$ 且不低于横轴
$$
M_0=1,\qquad
M_n=M_{n-1}+\sum_{i=0}^{n-2}M_iM_{n-2-i}
$$
也有
$$
M_n=
\sum_{k=0}^{\lfloor n/2\rfloor}
\binom n{2k}\operatorname{Cat}_k
$$
递推很短且使用频率较低，不单独保留代码
##### Stirling、Bell 与 Eulerian

| 数列                             | 计数对象                      | 递推                                                                            |
| ------------------------------ | ------------------------- | ----------------------------------------------------------------------------- |
| 第一类 Stirling $[n\ k]$          | $n$ 元排列恰有 $k$ 个置换环        | $[n\ k]=[n-1\ k-1]+(n-1)[n-1\ k]$                                             |
| 第二类 Stirling $\{n\ k\}$        | $n$ 个不同元素划分成 $k$ 个非空无标号集合 | $\{n\ k\}=\{n-1\ k-1\}+k\{n-1\ k\}$                                           |
| Bell $B_n$                     | 划分成任意数量的非空无标号集合           | $B_n=\sum_{k=0}^n\{n\ k\}$                                                    |
| Eulerian $\langle n\ k\rangle$ | $n$ 元排列恰有 $k$ 个下降位置       | $\langle n\ k\rangle=(k+1)\langle n-1\ k\rangle+(n-k)\langle n-1\ k-1\rangle$ |
第二类 Stirling 的显式式：
$$
\left\{{n\atop k}\right\}
=
\frac1{k!}
\sum_{i=0}^k(-1)^i
\binom ki(k-i)^n
$$
Eulerian 数显式式：
$$
\left\langle{n\atop k}\right\rangle
=
\sum_{j=0}^{k+1}
(-1)^j\binom{n+1}j(k+1-j)^n
$$
$$\left\langle{n\atop k}\right\rangle = \left\langle{n\atop n-1-k}\right\rangle$$
$$\sum_{k=0}^{n-1} \left\langle{n\atop k}\right\rangle=n!$$
Worpitzky 恒等式：
$$x^n = \sum_{k=0}^{n-1} \left\langle{n\atop k}\right\rangle \binom{x+k}{n}$$
它可以理解成另一种“普通幂 → 组合数基”的换基关系

如果已经计算 `stir2`，Bell 数可直接求：
```cpp
auto s = stir2(n);
Z B{};
for (int k = 0; k <= n; ++ k) B += s[n][k];
```
只需要所有 Bell 数时使用 `bell(n)`，可把空间降到 $O(n)$
##### 错排
错排数 $D_n$：
$$
D_0=1,\quad D_1=0
$$
$$
D_n=(n-1)(D_{n-1}+D_{n-2})
$$

亦有
$$
D_n
=
n!\sum_{k=0}^n\frac{(-1)^k}{k!}
$$
递推只有一行，不单独保留代码
##### 对合排列
所有置换环长度只能为 $1$ 或 $2$：
$$
I_0=I_1=1
$$
$$
I_n=I_{n-1}+(n-1)I_{n-2}
$$
也可写为
$$
I_n=
\sum_{k=0}^{\lfloor n/2\rfloor}
\frac{n!}{2^k k!(n-2k)!}
$$
同样不单独维护代码
##### 指定置换环结构
若长度为 $i$ 的置换环恰有 $m_i$ 个，且
$$
\sum_{i\ge1}im_i=n
$$
则排列数为
$$
\frac{n!}
{\displaystyle\prod_{i\ge1}i^{m_i}m_i!}
$$
##### 整数分拆
$p(n,k)$ 表示把 $n$ 无序分拆成恰好 $k$ 个正整数：
$$
p(n,k)=p(n-1,k-1)+p(n-k,k)
$$
且
$$
p(n)=\sum_{k=0}^np(n,k)
$$
只需要 $p(n)$ 时，五边形数递推更快。令
$$
g_k^-=\frac{k(3k-1)}2,\qquad
g_k^+=\frac{k(3k+1)}2
$$
则
$$
p(0)=1
$$
$$
p(n)=
\sum_{k\ge1}(-1)^{k-1}
\left(
p(n-g_k^-)+p(n-g_k^+)
\right)
$$
负下标项视为 $0$
整数分拆生成函数：
$$
\sum_{n\ge0}p(n)x^n
=
\prod_{i\ge1}\frac1{1-x^i}
$$
分拆成互不相同的正整数，与分拆成奇数的方案数相同：
$$
\prod_{i\ge1}(1+x^i)
=
\prod_{i\ge1}\frac1{1-x^{2i-1}}
$$
#### 复杂度

| 接口          |         时间复杂度 |    空间复杂度 |
| ----------- | ------------: | -------: |
| `stir1(n)`  |      $O(n^2)$ | $O(n^2)$ |
| `stir2(n)`  |      $O(n^2)$ | $O(n^2)$ |
| `euler(n)`  |      $O(n^2)$ | $O(n^2)$ |
| `bell(n)`   |      $O(n^2)$ |   $O(n)$ |
| `part_k(n)` |      $O(n^2)$ | $O(n^2)$ |
| `part(n)`   | $O(n\sqrt n)$ |   $O(n)$ |
#### Young 钩长公式
若 $\lambda\vdash n$，标准 Young 表要求 $1,\ldots,n$ 各出现一次，且每行、每列严格递增。格子 $c$ 的钩长 $h(c)$ 为其右侧格子数、下方格子数再加 $1$，则
$$f^\lambda= \frac{n!}{\prod_{c\in\lambda}h(c)}$$
#### Narayana 数
Narayana 数是 **Catalan 数按某个统计量细分后的计数**
##### 抽象模型
当题目本身属于 Catalan 模型，但额外限制了“峰 / 叶子”的数量时，优先考虑 Narayana 数
最典型的两个等价模型：
- 长度为 $2n$ 的 Dyck 路径恰有 $k$ 个峰
- 有 $n$ 条边的有根有序树恰有 $k$ 个叶子
其中 Dyck 路径中的峰指连续的
$$  
UD 
$$
在括号序列中对应一个相邻的
```
()
```
因此，题目若是：
> 合法括号序列 + 统计恰有多少个直接闭合的 `()`

也可以转成 Narayana 数
##### 公式
记 Narayana 数为 $N(n,k)$：
$$
\frac1n  
\binom nk  
\binom n{k-1},  
\qquad  
1\le k\le n  
$$
边界：
$$  
N(0,0)=1
$$
一整行的和正好是 Catalan 数：
$$
\operatorname{Cat}_n
$$
并且关于 $k$ 对称：
$$  
N(n,k)=N(n,n-k+1)
$$
##### 如何识别
普通 Catalan 问：

> 有多少个合法结构？

Narayana 往往问：

> 合法结构中，恰好有 $k$ 个某种局部结构有多少个？

尤其关注：

- Dyck 路径的峰数
    
- 有序树的叶子数
    
- 合法括号中的 `()` 数量
    

如果只限制路径不能越界，而没有额外统计峰数，仍然直接使用 Catalan，不需要 Narayana。

##### 求解
已有 `Comb` 时直接使用公式：
```cpp
Z nara(int n, int k, Comb<> &comb) {
    if (n == 0) return Z(k == 0);
    if (k <= 0 || k > n) return 0;
    return comb.C(n, k) * comb.C(n, k - 1) / Z(n);
}
```
要求 `n` 在模意义下可逆
在通常的质数模阶乘预处理场景中，如果已经保证
$$  
n<mod
$$
则可以直接使用
如果模数不保证使 $n$ 可逆，不能机械做 `/ n`，应改用精确整数、质因数指数或任意模组合方法
##### 例子
$n=4$ 时：
$$1,6,6,1$$
而
$$  
1+6+6+1=14=\operatorname{Cat}_4
$$
#### Fuss-Catalan 数
Fuss-Catalan 是 Catalan 的自然高阶推广
Catalan 对应“一个根拆成两个有序子结构”；Fuss-Catalan 对应：
> **一个根固定拆成 $m$ 个有序子结构**
##### 抽象模型
最典型的模型是**满 $m$ 叉有序树**：
- 每个内部结点恰有 $m$ 个孩子
- 孩子的顺序有区别
- 一共有 $n$ 个内部结点
其数量为 Fuss-Catalan 数
当 $m=2$ 时，就是普通满二叉树，对应 Catalan 数
因此，遇到递归结构：
$$
\text{叶子}  
+  
\text{根}\times  
(\text{结构})^m  
$$
就应该想到 Fuss-Catalan
##### 生成函数模型
设 $F(x)$ 表示该类结构，则：
$$  
F(x)=1+xF(x)^m
$$
这实际上是识别 Fuss-Catalan 最重要的抽象形式
使用 Lagrange 反演可得系数：
$$
\frac1{(m-1)n+1}  
\binom{mn}{n}
$$
因此定义
$$
\frac1{(m-1)n+1}  
\binom{mn}{n}
$$
$m=2$ 时：
$$\frac1{n+1}\binom{2n}{n}
\operatorname{Cat}_n
$$
##### 如何识别
看到下面的结构尤其值得检查：
```
一个根
├── 子结构 1
├── 子结构 2
├── ...
└── 子结构 m
```
且：
- 每个内部结点固定有 $m$ 个孩子
- 子结构之间有顺序
- 总规模由内部结点数控制
就很可能是 Fuss-Catalan
普通 Catalan 是：
```
root = left + right
```
Fuss-Catalan 则推广为：
```
root = child[0] + child[1] + ... + child[m-1]
```
##### 求解
已有 `Comb`：
```cpp
Z fuss_cat(int n, int m, Comb<> &comb) {
    if (n < 0 || m < 2) return 0;
    return comb.C(m * n, n) / Z((m - 1) * n + 1);
}
```
要求：
$$  
mn<mod  
$$
时可直接使用普通阶乘 `Comb`，此时分母也小于模数并可逆
如果 $mn\ge mod$，则不能继续直接调用普通 `comb.C()`，要根据模数切换 Lucas 或其他组合数算法
##### 递归理解
设 $f_n$ 为答案
根结点占一个内部结点，剩下 $n-1$ 个内部结点分给 $m$ 个有序子树：
$$
\sum_{\substack{n_1+\cdots+n_m=n-1\ n_i\ge0}}  
\prod_{i=1}^mf_{n_i}
$$
这正对应：
$$  
F(x)=1+xF(x)^m
$$
赛场上一般不直接使用这个高维递推，而是用闭式公式
#### 整数分拆的共轭模型
这一部分不是新数列，而是**非常重要的模型变换**
很多带限制的整数分拆问题经过共轭后，会直接变成已有的 `part_k()` 或普通背包
##### Ferrers 图
例如分拆
$$  
7=4+2+1  
$$
画成：
```
****
**
*
```
交换行列后得到：
```
***
**
*
*
```
对应分拆：
$$  
7=3+2+1+1
$$
这个操作叫**共轭分拆**
###### 核心等价关系
共轭会交换：
> 部分数量 ↔ 最大部分大小

因此：
$$
\#{\text{$n$ 的最大部分恰为 $k$}}
$$
也有更常用的：
$$
\#{\text{$n$ 的每个部分都不超过 $k$}}
$$
###### 如何识别
如果题目给出的限制是：
- 最多使用 $k$ 个数
- 最大的数不能超过 $k$
这两个条件在分拆问题中其实是对偶的
因此如果其中一个方向不好 DP，可以共轭成另一个方向
###### 求解
“每个部分不超过 $k$”可以直接看成：
> 有物品 $1,2,\ldots,k$，每种可以使用任意次，凑出总和 $n$

即完全背包：
```cpp
vector<Z> dp(n + 1);
dp[0] = 1;
for (int x = 1; x <= k; ++ x) {
    for (int s = x; s <= n; ++ s) {
        dp[s] += dp[s - x];
    }
}
```
得到：
$$
\#{\text{$n$ 的每个部分都不超过 $k$}}.  
$$
通过共轭，它也等于：
$$
\#{\text{$n$ 至多分成 $k$ 个正整数}}
$$
##### 恰好 $k$ 个部分的平移模型
另一个很常用的变换是：
> 每一部分先减去 $1$

若
$$  
n=x_1+x_2+\cdots+x_k,  
\quad  
x_i\ge1  
$$
且不计顺序，令
$$  
y_i=x_i-1\ge0
$$
则
$$  
y_1+\cdots+y_k=n-k
$$
去掉其中为 $0$ 的部分后得到：
$$
\#{\text{$n-k$ 的分拆，部分数量至多为 $k$}}
$$
再结合共轭：
$$
\#{\text{$n-k$ 的分拆，每一部分都不超过 $k$}}
$$
因此生成函数为
$$
\frac{x^k}  
{(1-x)(1-x^2)\cdots(1-x^k)}
$$
###### 如何求解
若只求一个范围内的答案，可以直接完全背包：
```cpp
vector<Z> dp(n - k + 1);
dp[0] = 1;
for (int x = 1; x <= k; ++ x) {
    for (int s = x; s <= n - k; ++ s) {
        dp[s] += dp[s - x];
    }
}
Z ans = dp[n - k];
```
它计算的是：
$$  
n-k  
$$
的分拆中每部分不超过 $k$ 的数量，因此恰好等于 $p(n,k)$
当然，如果已经有 `part_k()` 的二维递推：
$$  
p(n,k)=p(n-1,k-1)+p(n-k,k)
$$
直接查询即可
#### 题型识别总结

|题目抽象|优先想到|
|---|---|
|Catalan 模型 + 恰有 $k$ 个峰|Narayana|
|有根有序树 + 恰有 $k$ 个叶子|Narayana|
|每个内部结点固定有 $m$ 个有序孩子|Fuss-Catalan|
|生成函数满足 $F=1+xF^m$|Fuss-Catalan|
|分拆成至多 $k$ 部分|共轭成每部分 $\le k$|
|最大部分 $\le k$|完全背包 `1..k`|
|恰好分成 $k$ 个正整数|每部分减 $1$，转成 $n-k$ 至多 $k$ 部分|
|恰好 $k$ 部分|`part_k(n,k)` 或上述背包模型|
