### 容斥与反演
---
**解决问题：** 已知若干条件同时成立时的计数，反推出“不满足任何条件”“恰满足若干条件”等答案；或在集合包含关系上的前缀和与原函数之间相互转换
#### 子集容斥
设 `f(s)` 表示编号集合 `s` 中的所有条件**同时成立**时的方案数，则没有任何坏条件成立的方案数为
```cpp
template<class T, class F>
T ie(int n, F f) {
    T ans{};
    for (int s = 0; s < (1 << n); ++ s) {
        if (__builtin_parity((unsigned)s)) ans -= f(s);
        else ans += f(s);
    }
    return ans;
}
```
#### 子集 Zeta / Möbius
```cpp
// f[S] <- sum_{T subseteq S} f[T]
template<class T>
void zeta_sub(vector<T> &f) {
    int n{ __lg(f.size()) };
    for (int i = 0; i < n; ++ i)
        for (int s = 0; s < (1 << n); ++ s)
            if (s >> i & 1) f[s] += f[s ^ (1 << i)];
}
// zeta_sub 的逆变换
template<class T>
void mobius_sub(vector<T> &f) {
    int n{ __lg(f.size()) };
    for (int i = 0; i < n; ++ i)
        for (int s = 0; s < (1 << n); ++ s)
            if (s >> i & 1) f[s] -= f[s ^ (1 << i)];
}
// f[S] <- sum_{T supseteq S} f[T]
template<class T>
void zeta_sup(vector<T> &f) {
    int n{ __lg(f.size()) };
    for (int i = 0; i < n; ++ i)
        for (int s = 0; s < (1 << n); ++ s)
            if (!(s >> i & 1)) f[s] += f[s | (1 << i)];
}
// zeta_sup 的逆变换
template<class T>
void mobius_sup(vector<T> &f) {
    int n{ __lg(f.size()) };
    for (int i = 0; i < n; ++ i)
        for (int s = 0; s < (1 << n); ++ s)
            if (!(s >> i & 1)) f[s] -= f[s | (1 << i)];
}
```
#### 容斥原理
设全集为 $U$，坏事件为 $A_1,\ldots,A_n$
##### 至少一个条件成立
$$
\left|\bigcup_{i=1}^nA_i\right|
=
\sum_{\varnothing\ne S\subseteq[n]}
(-1)^{|S|+1}
\left|\bigcap_{i\in S}A_i\right|
$$
##### 没有任何坏条件成立
$$
\left|U\setminus\bigcup_{i=1}^nA_i\right|
=
\sum_{S\subseteq[n]}
(-1)^{|S|}
\left|\bigcap_{i\in S}A_i\right|
$$
这正是 `ie(n,f)` 的含义，其中
```text
f(S) = S 中所有坏条件同时成立的方案数
```
因此容斥的核心不是背符号，而是：
> **先强制若干条件同时成立，使计数变简单；再用正负号消除重复计数**
##### 如何识别
典型信号：
- 所有条件都满足很难算，但指定一批条件违反后容易算
- 每个对象不能具有某些性质
- 禁止位置、禁止颜色、禁止质因子
- 至少 / 至多 / 恰好满足若干性质
- 答案中出现交集计数，而各交集结构相似
#### 按命中个数容斥
这是普通容斥非常重要的推广
设一个方案可能满足 $n$ 个性质中的若干个
定义
$$
S_j=
\sum_{\substack{T\subseteq[n]\\|T|=j}}
\#\{\text{同时满足 }T\text{ 中全部性质的方案}\}
$$
注意：一个恰好满足 $r$ 个性质的方案，会在 $S_j$ 中被计算
$$
\binom rj
$$
次
##### 恰好满足 $k$ 个性质
记答案为 $E_k$，则
$$
\boxed{
E_k=
\sum_{j=k}^n
(-1)^{j-k}
\binom jk S_j
}
$$
这可以理解为一次二项式反演
特别地，
$$
E_0=
\sum_{j=0}^n(-1)^jS_j
$$
就是普通容斥
##### 至少满足 $k$ 个性质
记答案为 $A_k$：
$$
\boxed{
A_k=
\sum_{j=k}^n
(-1)^{j-k}
\binom{j-1}{k-1}S_j
}
$$
特别地 $k=1$：
$$
A_1=
\sum_{j=1}^n(-1)^{j-1}S_j
$$
就是并集大小
##### 如何识别
如果题目不是问：
> 一个条件都不能违反

而是问：
> 恰好有 $k$ 个条件成立 / 违反

不要硬套普通容斥
应先计算每个阶数的交集总和 $S_j$，再做上述反演
#### 对称容斥
如果任取 $j$ 个条件同时成立时，方案数只与 $j$ 有关，记为 $F_j$，那么
$$
S_j=\binom njF_j
$$
此时指数级枚举子集可以直接压成：
$$
E_0=
\sum_{j=0}^n
(-1)^j\binom njF_j
$$
也就是从
$$
O(2^n)
$$
降到
$$
O(n)
$$
##### 典型模型：满射
$n$ 个不同元素映射到 $m$ 个不同盒子，要求每个盒子非空
令坏事件 $A_i$ 为“第 $i$ 个盒子为空”
任取 $j$ 个盒子强制为空后：
$$
F_j=(m-j)^n
$$
所以满射数为
$$
\sum_{j=0}^m
(-1)^j
\binom mj(m-j)^n
=
m!\left\{{n\atop m}\right\}
$$
看到：
> 条件完全对称，交集计数只依赖选择了几个条件

时，应优先尝试把 $2^n$ 容斥按集合大小合并
#### 二项式反演
若
$$
f_n=
\sum_{k=0}^n
\binom nk g_k
$$
则
$$
\boxed{
g_n=
\sum_{k=0}^n
(-1)^{n-k}
\binom nk f_k
}
$$
反之亦然
另一种常见写法：
$$
f_n=
\sum_{k=0}^n
(-1)^k\binom nk g_k
$$
则
$$
g_n=
\sum_{k=0}^n
(-1)^k\binom nk f_k
$$
这种带 $(-1)^k$ 的变换是自己的逆变换
##### 抽象模型
二项式反演最常出现于：
> `f[n]` 统计“从 $n$ 个可选条件中任选若干个”的总贡献，需要恢复“恰好使用全部 $n$ 个条件”的贡献

典型关系：
```text
容易求：至少包含某些东西 / 可以缺失若干东西
要求：  恰好包含全部 / 恰好命中 k 个
```
本质上就是把**集合容斥按集合大小聚合**后的结果
因此不要把“二项式反演”和“容斥”当成两个毫无关系的技巧
#### 子集 Zeta 变换
若有一个集合函数 $f(S)$，定义
$$
F(S)=
\sum_{T\subseteq S}f(T)
$$
称为子集 Zeta 变换
直接对每个 $S$ 枚举子集需要约 $O(3^n)$，而 `zeta_sub()` 可以在
$$
O(n2^n)
$$
时间内求出所有 $F(S)$
##### 如何理解
代码：
```cpp
if (s >> i & 1)
    f[s] += f[s ^ (1 << i)];
```
表示依次决定：
> 第 $i$ 位是否允许从当前集合中删掉

全部位处理完后，所有子集的贡献都汇总到了 `f[s]`
##### 逆变换
若已知
$$
F(S)=\sum_{T\subseteq S}f(T)
$$
则
$$
\boxed{
f(S)=
\sum_{T\subseteq S}
(-1)^{|S|-|T|}F(T)
}
$$
这正是 Boolean 格上的 Möbius 反演
实现就是把 Zeta 中的 `+=` 改为 `-=`：
```cpp
mobius_sub(f);
```
#### 超集 Zeta / Möbius
另一种常见方向：
$$
F(S)=
\sum_{T\supseteq S}f(T)
$$
使用：
```cpp
zeta_sup(f);
```
恢复原函数：
```cpp
mobius_sup(f);
```
##### 怎么区分方向
如果要求的是：
```text
所有 T ⊆ S 的贡献
```
用 `sub`
如果要求的是：
```text
所有 T ⊇ S 的贡献
```
用 `sup`
赛场最容易犯的错误就是把方向写反
#### 一般 Möbius 反演
Zeta / Möbius 并不只存在于子集
在偏序集合中，如果
$$
F(x)=\sum_{y\le x}f(y)
$$
则可以通过 Möbius 函数反演：
$$
f(x)=
\sum_{y\le x}
\mu(y,x)F(y)
$$
几个重要实例：

| 偏序      | Zeta 求和               | Möbius               |     |     |     |     |
| ------- | --------------------- | -------------------- | --- | --- | --- | --- |
| 子集包含    | $\sum_{T\subseteq S}$ | $(-1)^{              | S   | -   | T   | }$  |
| 整除关系    | $\sum_{d\mid n}$      | 数论 Möbius $\mu(n/d)$ |     |     |     |     |
| 按集合大小聚合 | $\sum\binom nk$       | 二项式反演                |     |     |     |     |
因此：
```text
普通容斥
    ↓
子集 Möbius
    ↓ 按集合大小聚合
二项式反演
```
本质上属于同一套反演思想
整除关系的 Möbius 反演放在**数论**模块，本节不重复代码
#### 最大最小容斥
对数值 $x_1,\ldots,x_n$：
$$
\max_i x_i
=
\sum_{\varnothing\ne S\subseteq[n]}
(-1)^{|S|+1}
\min_{i\in S}x_i
$$
对偶地：
$$
\min_i x_i
=
\sum_{\varnothing\ne S\subseteq[n]}
(-1)^{|S|+1}
\max_{i\in S}x_i
$$
这个形式常用于：
- 期望最大值 / 最小值
- 所有子集的 `min/max` 容斥
- 把难处理的最大值转成容易统计的最小值
#### 接口说明
- `ie<T>(n,f)`：计算没有任何坏条件成立的方案数；`f(s)` 返回 `s` 中所有坏条件同时成立的方案数
- `zeta_sub(f)`：`f[S] <- Σ_{T⊆S} f[T]`
- `mobius_sub(f)`：`zeta_sub()` 的逆变换
- `zeta_sup(f)`：`f[S] <- Σ_{T⊇S} f[T]`
- `mobius_sup(f)`：`zeta_sup()` 的逆变换
四个子集变换均要求：
```text
f.size() = 2^n
```
并且 `T` 支持加减
#### 注意事项
- 普通容斥的符号取决于“当前算的是合法方案还是并集”，不要只背 `+ - + -`
- `ie()` 中 `s = 0` 表示没有强制任何坏条件，其贡献就是全集大小
- 条件具有完全对称性时，先按 `|S|` 合并，不要直接枚举 $2^n$
- “恰好 $k$ 个条件成立”应使用按命中数反演，不是普通容斥
- 二项式反演中的 $(-1)^{n-k}$ 与 $(-1)^k$ 两种写法不要混用
- `zeta_sub` / `mobius_sub` 与 `zeta_sup` / `mobius_sup` 方向相反
- 子集 Möbius 与 FWT 的 OR/AND 变换形式相近，但用途不同；OR/AND 卷积仍放在 FWT 模块
- 整除偏序上的 Möbius 反演属于数论，本节只说明统一抽象
#### 常见用法
##### 普通容斥
```cpp
Z ans = ie<Z>(n, [&](int s) {
    // 返回 s 中所有坏条件同时成立时的方案数
    return calc(s);
});
```
##### 所有子集和
已知 `f[S]`，求
$$
g[S]=\sum_{T\subseteq S}f[T]
$$
```cpp
auto g = f;
zeta_sub(g);
```
##### 从所有子集和恢复原数组
```cpp
mobius_sub(g);
// 此时 g == f
```
##### 所有超集和
```cpp
auto g = f;
zeta_sup(g);
```
#### 题型识别

| 题目特征 | 优先检查 |
|---|---|
| 禁止若干性质，交集容易统计 | 普通容斥 |
| 条件完全对称，只与选了几个有关 | 按大小合并容斥 |
| 恰好 / 至少满足 $k$ 个条件 | 按命中数容斥 |
| 出现 $\sum\binom nk f_k$ | 二项式反演 |
| 对所有 `S` 求所有子集贡献和 | `zeta_sub` |
| 对所有 `S` 求所有超集贡献和 | `zeta_sup` |
| 已知上述和，恢复原数组 | Möbius 逆变换 |
| 出现 $\sum_{d\mid n}$ 或倍数求和 | 数论 Möbius 反演 |
#### 复杂度

| 接口 / 方法                   |             时间复杂度 |       空间复杂度 |
| ------------------------- | ----------------: | ----------: |
| 直接子集容斥                    | $O(2^n)$ 次 `f` 计算 | $O(1)$ 额外空间 |
| 对称容斥                      |      $O(n)$ 次交集计数 |      $O(1)$ |
| `zeta_sub` / `mobius_sub` |         $O(n2^n)$ | $O(1)$ 额外空间 |
| `zeta_sup` / `mobius_sup` |         $O(n2^n)$ | $O(1)$ 额外空间 |
| 普通二项式反演直接计算               |          $O(n^2)$ |         依实现 |
