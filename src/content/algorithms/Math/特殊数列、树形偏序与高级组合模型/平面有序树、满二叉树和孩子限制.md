有序根树按边数 $n$ 计，数量为 $C_n$；按顶点数 $n\ge1$ 计，数量为 $C_{n-1}$。含 $n$ 个内部节点的满二叉树数量为 $C_n$。

每个内部节点恰有 $m$ 个有序孩子、恰有 $n$ 个内部节点的满 $m$ 叉树数为


$$
\frac{1}{(m-1)n+1}\binom{mn}n.
$$


有序根树若孩子数属于集合 $D$，以顶点计的 GF 可写成


$$
T(x)=x\sum_{d\in D}T(x)^d
$$


（此时以顶点计，$T=x\Phi(T)$，边数是顶点数减 $1$）；用 Lagrange 反演取系数。若孩子无序，应改用集合/循环指标，不可沿用该式。


**Fuss–Catalan 的生成函数识别**：对于满 $m$ 叉有序树（$m\ge2$），每个内部结点**恰好**有 $m$ 个有序孩子；$n$ 为内部结点数、空树为 $1$，则


$$
F(x)=1+xF(x)^m,\qquad [x^n]F(x)=\boxed{\frac1{(m-1)n+1}\binom{mn}{n}}\quad(n\ge0).
$$


$$
f_0=1,\qquad f_n=\sum_{n_1+\cdots+n_m=n-1}\prod_{i=1}^m f_{n_i}\quad(n\ge1),\qquad\#\text{叶结点}=(m-1)n+1.
$$


$m=2$ 即 Catalan；这对应一个根组合成 $m$ 个有序子结构，而不是 $m$ 个无序孩子。若以 $r=m-1$ 为参数，也常写成 $\frac1{rn+1}\binom{(r+1)n}{n}$，与 1.9 完全同一公式，不要把两个版本当成不同数列。

**何时用**：根有固定数目 $m$ 个有序子结构、每个内部结点必须有 $m$ 个孩子、规模按内部结点数计。若只要求孩子数不超过 $m$ 或孩子无序，此式一般不适用。

```cpp
template<class Z, class Comb>
Z fuss_catalan(int n, int m, Comb &comb) {
    if (n < 0 || m < 2) return 0;
    return comb.C(m * n, n) / Z((m - 1) * n + 1);
}
```

模素数 $p$ 且使用普通阶乘表时，一个充分条件是 $mn<p$，保证阶乘可用、分母非零且可逆；若 $mn\ge p$，不能只凭调用 `comb.C()` 就保证正确，需要 Lucas 或任意模组合算法。`m*n` 在 C++ 中还要检查整型溢出。
