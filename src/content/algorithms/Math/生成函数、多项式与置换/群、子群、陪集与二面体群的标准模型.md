**子群判据**：非空 $H\subseteq G$ 为子群，当且仅当 $ab^{-1}\in H$ 对任意 $a,b\in H$ 成立。群 $G=\langle g_1,\ldots,g_t\rangle$ 表示由这些生成元及其逆元任意有限次复合生成。左陪集 $gH=\{gh:h\in H\}$ 的大小恒为 $|H|$，所以


$$
[G:H]=\frac{|G|}{|H|}\in\mathbb N,\quad |H|\mid|G|,\quad \operatorname{ord}(g)\mid |G|.
$$


**$C_n$ 与 $D_n$**。采用 $|C_n|=n,|D_n|=2n$（$n\ge3$）的记号。定义旋转 $r$ 和翻转 $s$：


$$
C_n=\langle r\mid r^n=e\rangle,\qquad D_n=\langle r,s\mid r^n=s^2=e,\ srs=r^{-1}\rangle.
$$


$$
D_n=\{r^k:0\le k<n\}\cup\{r^ks:0\le k<n\}.
$$


在下标 $i\in\{0,\ldots,n-1\}$ 上定义 $r(i)=i+1\pmod n,\ s(i)=-i\pmod n$，则**按先右后左的复合作用**


$$
r^k(i)=i+k\pmod n,\qquad (r^ks)(i)=k-i\pmod n,\qquad c(r^k)=\gcd(n,k).
$$


这里 $r^ks$ 不应误写为 $sr^k$ 后仍用 $k-i$：在上述复合约定下 $(sr^k)(i)=-i-k\pmod n$。若 $0\le i,k<n$，可以直接写：

```cpp
int rot(int i, int k, int n) { return (i + k) % n; }
int ref(int i, int k, int n) { return (k - i + n) % n; }
```

**使用场景**：若操作能复合且可撤销，先判断形成何种群；只需旋转／翻转时先写 $C_n,D_n$；若颜色名字也允许置换，则群不仅作用于位置，必须将颜色变换纳入固定点计算。普通位置染色的轨道、稳定子与 Burnside 见 2.6，二面体循环指标见 2.21。自由作用要求所有对象的稳定子平凡；忠实作用只要求没有非单位元同时固定所有对象，两者不可混同。
