`huffman_cost(a)` 解决经典的**最优合并问题**：
每次选择两个权值：`x, y`
合并为：`x + y`
并付出代价：`x + y`
不断合并直到只剩一个元素，求最小总代价
Huffman 贪心每次选择当前最小的两个值合并
```cpp
template<class T>
T huffman_cost(vector<T> a) {
    priority_queue<T, vector<T>, greater<T>> q(a.begin(), a.end());
    T ans{};
    while (q.size() > 1) {
        T x = q.top();
        q.pop();
        T y = q.top();
        q.pop();
        ans += x + y;
        q.push(x + y);
    }
    return ans;
}
```
### 接口
- `huffman_cost(a)`：返回最优合并总代价，$O(n\log n)$
### 注意事项
- 经典 Huffman / 最优合并问题通常要求权值非负
- `T` 至少需要支持：
    - 比较
    - 加法
    - 默认构造为零值
- 如果总权值或答案可能很大，要使用足够大的类型，例如：
```cpp
vector<i64> a;
i64 ans{ huffman_cost(a) };
```
- 空数组或只有一个元素时，合并次数为 $0$，返回 `T{}`
- 函数只返回最小总代价，不恢复 Huffman 树本身
- 如果需要获得编码、父子关系或每个节点深度，应另外维护节点编号，不能只使用这一极简版本
### 最优合并总代价
```cpp
vector<i64> a{ 1, 2, 3, 4 };
cout << huffman_cost(a) << '\n';
```
过程为：
```cpp
1 + 2 = 3
3 + 3 = 6
4 + 6 = 10
```
总代价：`3+6+10=19`
### 复杂度
设初始有 $n$ 个元素

|操作|时间复杂度|
|---|---|
|建堆|$O(n)$|
|$n-1$ 次合并|$O(n\log n)$|
|总复杂度|$O(n\log n)$|
空间复杂度：$O(n)$
