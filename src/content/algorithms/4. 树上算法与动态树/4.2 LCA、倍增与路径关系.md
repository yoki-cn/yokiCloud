### LCA、倍增与路径关系
---
**解决问题：** 预处理最近公共祖先，支持祖先跳跃、树上距离、路径第 $k$ 点、动态换根、路径交并关系以及基于 LCA 的树上差分
#### 版本选择
---

| 需求 | 选择 |
|---|---|
| 普通 LCA、祖先跳跃、路径第 $k$ 点 | **倍增 `LCA`** |
| 大量纯 LCA / 距离查询 | **`ELCA` + 状压 RMQ** |
| 已经需要完整 HLD | 直接使用后面 **4.3 HLD** 的 LCA，不再复制本节 |
| 所有询问离线 | 一般仍可用前两版；Tarjan 离线 LCA 不单独保留板子 |
| 路径交 / 包含 / 合并 | `PathRel<LCA>` 或 `PathRel<ELCA>` |
| 批量路径点 / 边计数 | `TreeDiff` |
#### 倍增 LCA
---
依赖 **4.1.1 `TreeInfo`**，必须先调用 `TreeInfo::build()`
```cpp
struct LCA {
    const TreeInfo &t;
    int lg;
    vector<vector<int>> up;
    explicit LCA(const TreeInfo &t_) : t(t_), lg(__lg(max(1, t.n)) + 1),
        up(lg, vector<int>(t.n)) {
        up[0] = t.fa;
        for (int k = 1; k < lg; ++ k) {
            for (int u = 0; u < t.n; ++ u) {
                up[k][u] = up[k - 1][up[k - 1][u]];
            }
        }
    }
    // ===== 基础 LCA 与距离 =====
    int lca(int u, int v) const {
        if (t.is_anc(u, v)) return u;
        if (t.is_anc(v, u)) return v;
        for (int k = lg - 1; k >= 0; -- k) {
            if (!t.is_anc(up[k][u], v)) u = up[k][u];
        }
        return t.fa[u];
    }
    int len(int u, int v) const {
        int p{ lca(u, v) };
        return t.dep[u] + t.dep[v] - 2 * t.dep[p];
    }
    i64 dist(int u, int v) const {
        int p{ lca(u, v) };
        return i128(t.dis[u]) + t.dis[v] - 2 * i128(t.dis[p]);
    }
    // ===== 祖先与路径跳跃 =====
    int jump(int u, int k) const {
        if (k < 0 || k > t.dep[u]) return -1;
        for (int i = 0; i < lg; ++ i) if (k >> i & 1) u = up[i][u];
        return u;
    }
    int kth(int u, int v, int k) const {
        int p{ lca(u, v) };
        int a{ t.dep[u] - t.dep[p] }, b{ t.dep[v] - t.dep[p] };
        if (k < 0 || k > a + b) return -1;
        return k <= a ? jump(u, k) : jump(v, a + b - k);
    }
    // ===== 动态换根 =====
    int lca_r(int u, int v, int r) const {
        int a{ lca(u, v) }, b{ lca(u, r) }, c{ lca(v, r) };
        if (t.dep[b] > t.dep[a]) a = b;
        if (t.dep[c] > t.dep[a]) a = c;
        return a;
    }
    int par_r(int u, int r) const {
        if (u == r) return -1;
        if (!t.is_anc(u, r)) return t.fa[u];
        return jump(r, t.dep[r] - t.dep[u] - 1);
    }
    int siz_r(int u, int r) const {
        if (u == r) return t.n;
        if (!t.is_anc(u, r)) return t.siz[u];
        int v{ jump(r, t.dep[r] - t.dep[u] - 1) };
        return t.n - t.siz[v];
    }
};
```
##### 成员变量
- `t`：已经完成 `build()` 的 `TreeInfo`
- `lg`：倍增层数
- `up[k][u]`：`u` 向上的第 $2^k$ 个祖先，根的所有倍增祖先均为根
##### 接口
- `LCA(t)`：建立倍增表，$O(n\log n)$
- `lca(u,v)`：最近公共祖先，$O(\log n)$
- `len(u,v)`：路径边数，$O(\log n)$
- `dist(u,v)`：路径边权和，$O(\log n)$
- `jump(u,k)`：`u` 的第 `k` 级祖先，不存在返回 `-1`，$O(\log n)$
- `kth(u,v,k)`：路径 `u -> v` 上从 `u` 开始第 `k` 个点，`k=0` 时为 `u`，不存在返回 `-1`，$O(\log n)$
- `lca_r(u,v,r)`：临时以 `r` 为根时的 LCA，$O(\log n)$
- `par_r(u,r)`：临时以 `r` 为根时 `u` 的父节点，`u=r` 返回 `-1`，$O(\log n)$
- `siz_r(u,r)`：临时以 `r` 为根时 `u` 的子树大小，$O(\log n)$
##### 注意事项
- 构造 `LCA` 前必须执行 `TreeInfo::build()`
- 若之后重新调用 `TreeInfo::build()` 换根，必须重新构造 `LCA`，原 `up` 表已经失效
- `dist()` 是唯一树路径的边权和，允许负边权；根距离与最终答案须能放入 i64，中间表达式使用 i128，避免相消前溢出
- `len()` 只计算路径边数，不受边权影响
- `jump(u,k)` 中 `k<0` 或 `k>dep[u]` 时返回 `-1`
- `lca_r()`、`par_r()`、`siz_r()` 不会真正重新建树，只按照临时根解释原树
##### 常见用法
###### 路径第 k 个点
```cpp
TreeInfo tr(n);
// tr.add(...)
tr.build(0);
LCA lca(tr);

int x{ lca.kth(u, v, k) };
```
###### 动态换根
```cpp
int p{ lca.lca_r(u, v, r) };
int fa{ lca.par_r(u, r) };
int siz{ lca.siz_r(u, r) };
```
##### 复杂度

| 操作 | 时间复杂度 |
|---|---:|
| 构造 | $O(n\log n)$ |
| `lca()` / `jump()` / `kth()` | $O(\log n)$ |
| `len()` / `dist()` | $O(\log n)$ |
| 动态换根接口 | $O(\log n)$ |
空间复杂度：$O(n\log n)$
#### 欧拉序 + 状压 RMQ LCA
当题目有大量 LCA / 距离查询，而不需要 `jump()`、`kth()` 时可以使用本版
依赖前面的 `TreeInfo` 以及通用 `RMQ<T,Cmp>`
```cpp
struct ELCA {
    const TreeInfo &t;
    vector<int> fir, eul;
    optional<RMQ<int>> rmq;
    explicit ELCA(const TreeInfo &t_) : t(t_), fir(t.n, -1) {
        struct F { int u, it; };
        vector<F> stk{{t.root, 0}};
        eul.reserve(2 * t.n - 1);
        fir[t.root] = 0;
        eul.push_back(t.root);
        while (!stk.empty()) {
            F &f{ stk.back() };
            if (f.it == int(t.g[f.u].size())) {
                stk.pop_back();
                if (!stk.empty()) eul.push_back(stk.back().u);
                continue;
            }
            int v{ t.g[f.u][f.it ++].first };
            if (t.fa[v] != f.u) continue;
            fir[v] = eul.size();
            eul.push_back(v);
            stk.push_back({v, 0});
        }
        vector<int> d(eul.size());
        for (int i = 0; i < int(eul.size()); ++ i) d[i] = t.dep[eul[i]];
        rmq.emplace(move(d));
    }
    int lca(int u, int v) const {
        int l{ fir[u] }, r{ fir[v] };
        if (l > r) swap(l, r);
        return eul[rmq->query_index(l, r + 1)];
    }
    int len(int u, int v) const {
        int p{ lca(u, v) };
        return t.dep[u] + t.dep[v] - 2 * t.dep[p];
    }
    i64 dist(int u, int v) const {
        int p{ lca(u, v) };
        return i128(t.dis[u]) + t.dis[v] - 2 * i128(t.dis[p]);
    }
    // ===== 动态换根 =====
    int lca_r(int u, int v, int r) const {
        int a{ lca(u, v) }, b{ lca(u, r) }, c{ lca(v, r) };
        if (t.dep[b] > t.dep[a]) a = b;
        if (t.dep[c] > t.dep[a]) a = c;
        return a;
    }
};
```
##### 接口说明
- `fir[u]`：`u` 第一次出现在 Euler Tour 中的位置
- `eul`：Euler Tour，长度为 $2n-1$
- `ELCA(t)`：构造欧拉序并建立 RMQ
- `lca(u,v)`：最近公共祖先，$O(1)$
- `len(u,v)`：路径边数，$O(1)$
- `dist(u,v)`：路径边权和，$O(1)$
- `lca_r(u,v,r)`：临时换根 LCA，$O(1)$
##### 注意事项
- 同样要求 `TreeInfo::build()` 已完成，重新 `build()` 后必须重新构造 `ELCA`
- 本版**没有祖先跳跃**，需要 `jump()`、`kth()`、`par_r()`、`siz_r()` 时优先使用倍增版
- `eul` 是真正的 Euler Tour，与 4.1 中长度为 `n` 的 DFS 先序 `seq` 不同
- RMQ 查询的是 Euler Tour 上的**最小深度位置**，所以直接使用 `RMQ<int>` 的默认 `less<int>`
- 不需要把整棵树节点编号放进 RMQ；RMQ 内保存的是 Euler Tour 对应的深度数组
##### 复杂度
令 $N=2n-1$，RMQ 块大小为 $B=64$：

| 操作 | 时间复杂度 |
|---|---:|
| 建 Euler Tour | $O(n)$ |
| 建 RMQ | $O(N+\frac NB\log\frac NB)$ |
| `lca()` / `len()` / `dist()` | $O(1)$ |
空间复杂度为 $O(N+\frac NB\log\frac NB)$
> [!tip]
> 实际竞赛规模下 $B=64$，这部分非常接近线性；但严格写复杂度时没必要把块上 ST 强行写成 $O(n)$
#### 路径关系
---
使用 `LCA` 或 `ELCA` 均可，所有判定都使用**路径边数**，因此与边权正负无关
```cpp
template<class L>
struct PathRel {
    const L &l;
    explicit PathRel(const L &l_) : l(l_) {}
    bool on(int x, int u, int v) const {
        return l.len(u, x) + l.len(x, v) == l.len(u, v);
    }
    bool subset(int a, int b, int c, int d) const {
        return on(a, c, d) && on(b, c, d);
    }
    optional<pair<int, int>> inter(int a, int b, int c, int d) const {
        array<int, 4> p{
            l.lca(a, c), l.lca(a, d),
            l.lca(b, c), l.lca(b, d)
        };
        sort(p.begin(), p.end(), [&](int x, int y) {
            if (l.t.dep[x] != l.t.dep[y]) return l.t.dep[x] < l.t.dep[y];
            return l.t.in[x] < l.t.in[y];
        });
        int x{ l.lca(a, b) }, y{ l.lca(c, d) };
        if (l.t.dep[p[0]] < min(l.t.dep[x], l.t.dep[y])) return nullopt;
        if (l.t.dep[p[2]] < max(l.t.dep[x], l.t.dep[y])) return nullopt;
        return pair{p[2], p[3]};
    }
    int inter_size(int a, int b, int c, int d) const {
        auto p{ inter(a, b, c, d) };
        return p ? l.len(p->first, p->second) + 1 : 0;
    }
    optional<pair<int, int>> join(int a, int b, int c, int d) const {
        if (!inter(a, b, c, d)) return nullopt;
        array<int, 4> p{a, b, c, d};
        pair<int, int> ans{a, a};
        for (int i = 0; i < 4; ++ i) {
            for (int j = i + 1; j < 4; ++ j) {
                if (l.len(p[i], p[j]) > l.len(ans.first, ans.second)) {
                    ans = {p[i], p[j]};
                }
            }
        }
        for (int x : p) if (!on(x, ans.first, ans.second)) return nullopt;
        return ans;
    }
};
```
##### 接口说明
- `PathRel(l)`：绑定 `LCA` 或 `ELCA`
- `on(x,u,v)`：判断 `x` 是否位于路径 `u-v` 上
- `subset(a,b,c,d)`：判断路径 `a-b` 是否完全包含于路径 `c-d`
- `inter(a,b,c,d)`：返回两条路径交集的端点；无交集返回 `nullopt`
- `inter_size(a,b,c,d)`：返回交集包含的节点数；无交集返回 `0`
- `join(a,b,c,d)`：若两条路径的并仍是一条路径，返回并路径端点，否则返回 `nullopt`
使用倍增 `LCA` 时以上接口均为 $O(\log n)$；使用 `ELCA` 时均为 $O(1)$
##### 注意事项
- 路径包含端点
- 两条路径仅在一个节点相交时，`inter()` 返回 `{x,x}`
- `join()` 要求两条路径本身相交；若两条路径之间存在一段未被覆盖的空隙，即使四个端点共线也返回 `nullopt`
- 两条相交路径的并不一定仍是一条路径，例如在某个节点形成三叉形时 `join()` 会返回空
- 这里完全使用 `len()` 判断路径关系，因此负边权不会影响结果
##### 常见用法
```cpp
LCA lca(tr);
PathRel rel(lca);

bool ok{ rel.on(x, u, v) };
auto p{ rel.inter(a, b, c, d) };
if (p) {
    auto [x, y]{ *p };
}
```
##### 复杂度

| 实现 | 路径关系单次复杂度 |
|---|---:|
| `PathRel<LCA>` | $O(\log n)$ |
| `PathRel<ELCA>` | $O(1)$ |
额外空间复杂度：$O(1)$
#### 树上差分
---
用于批量给若干条路径增加贡献，最后一次自底向上累加得到每个点或每条边的总贡献
```cpp
template<class L, class T = i64>
struct TreeDiff {
    const L &l;
    vector<T> node, edge;
    explicit TreeDiff(const L &l_) : l(l_), node(l.t.n), edge(l.t.n) {}
    void clear() {
        fill(node.begin(), node.end(), T{});
        fill(edge.begin(), edge.end(), T{});
    }
    // ===== 点差分 =====
    void add_node(int u, int v, const T &x = T{ 1 }) {
        int p{ l.lca(u, v) };
        node[u] += x;
        node[v] += x;
        node[p] -= x;
        if (p != l.t.root) node[l.t.fa[p]] -= x;
    }
    // ===== 边差分 =====
    void add_edge(int u, int v, const T &x = T{ 1 }) {
        int p{ l.lca(u, v) };
        edge[u] += x;
        edge[v] += x;
        edge[p] -= x + x;
    }
    // ===== 所有修改完成后调用一次 =====
    void calc() {
        for (int i = l.t.n - 1; i > 0; -- i) {
            int u{ l.t.seq[i] }, p{ l.t.fa[u] };
            node[p] += node[u];
            edge[p] += edge[u];
        }
    }
};
```
##### 接口说明
- `TreeDiff(l)`：绑定 `LCA` 或 `ELCA`
- `clear()`：清空全部差分，$O(n)$
- `add_node(u,v,x)`：路径 `u-v` 上所有节点增加 `x`
- `add_edge(u,v,x)`：路径 `u-v` 上所有边增加 `x`
- `calc()`：自底向上累加全部差分，$O(n)$
调用 `calc()` 后：
- `node[u]`：节点 `u` 的最终贡献
- 对 `u != root`，`edge[u]`：边 `(fa[u],u)` 的最终贡献
- `edge[root]` 没有对应的父边，应忽略
##### 注意事项
- 固定调用顺序为：加入所有路径差分 → `calc()` → 读取答案
- `calc()` 会原地把差分数组转为答案，调用后不能继续添加修改再重复累加；新一轮先 `clear()`
- `T` 需要支持 `+`、`-`、`+=`、`-=`
- 若只使用点差分，可以删除 `edge`、`add_edge()` 及 `calc()` 中对应语句；只使用边差分同理
- 子树批量修改不需要树上差分，直接利用 `[in[u],out[u])` 做普通一维差分即可
##### 常见用法
###### 统计节点经过次数
```cpp
LCA lca(tr);
TreeDiff diff(lca);

for (auto [u, v] : qry) diff.add_node(u, v);
diff.calc();

cout << diff.node[u] << '\n';
```
###### 统计每条边经过次数
```cpp
for (auto [u, v] : qry) diff.add_edge(u, v);
diff.calc();

int x{ tr.dep[u] > tr.dep[v] ? u : v };
cout << diff.edge[x] << '\n';
```
##### 复杂度
设路径修改数为 $q$：

| LCA 版本 | 单次差分 | 总复杂度 |
|---|---:|---:|
| 倍增 `LCA` | $O(\log n)$ | $O(n+q\log n)$ |
| `ELCA` | $O(1)$ | $O(n+q)$，不计 RMQ 预处理 |
差分本身空间复杂度：$O(n)$
