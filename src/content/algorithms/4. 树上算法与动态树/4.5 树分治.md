### 树分治
---
#### 选型
---

| 问题 | 优先方案 |
|---|---|
| 静态统计所有树路径 | `PointDiv` |
| 距离 $\le k$ 的点对计数 | `PointDiv::count_leq()` |
| 节点状态动态变化、距离查询 | `CDTree` |
| 动态最近标记点 | `CDNear` |
| 动态距离范围计数 / 求和 | `CDTree::up` + Fenwick 等 |
| 点分治难以得到合适的跨点结构，而跨边更自然 | `EdgeDiv` |
| 特殊动态路径问题 | 再考虑链分治等专用技巧 |
#### 点分治与路径统计
---
**解决问题：** 对所有树上路径进行离线统计。每层选择当前连通块重心，只处理“路径经过当前重心”的部分，再递归处理删除重心后的各个连通块
依赖 **4.1.1 `TreeInfo`**，这里只使用 `n` 与 `g`，不要求提前 `build()`
```cpp
struct PointDiv {
    const TreeInfo &t;
    vector<int> siz, pre;
    vector<char> ban;
    explicit PointDiv(const TreeInfo &t_) : t(t_), siz(t.n), pre(t.n), ban(t.n) {}
private:
    // ===== 找当前连通块重心 =====
    int cen(int s) {
        vector<int> ord, stk{s};
        pre[s] = -1;
        while (!stk.empty()) {
            int u{ stk.back() };
            stk.pop_back();
            ord.push_back(u);
            for (auto [v, w] : t.g[u]) {
                if (v == pre[u] || ban[v]) continue;
                pre[v] = u;
                stk.push_back(v);
            }
        }
        for (int i = int(ord.size()) - 1; i >= 0; -- i) {
            int u{ ord[i] };
            siz[u] = 1;
            for (auto [v, w] : t.g[u]) if (!ban[v] && pre[v] == u) siz[u] += siz[v];
        }
        int rt{ s }, best{ int(ord.size()) + 1 }, tot{ int(ord.size()) };
        for (int u : ord) {
            int mx{ tot - siz[u] };
            for (auto [v, w] : t.g[u]) if (!ban[v] && pre[v] == u) mx = max(mx, siz[v]);
            if (mx < best) best = mx, rt = u;
        }
        return rt;
    }
    // 收集某个重心分支内所有点到重心的距离
    vector<i64> dists(int s, int p, i64 d) const {
        vector<i64> res;
        vector<tuple<int, int, i64>> stk{{s, p, d}};
        while (!stk.empty()) {
            auto [u, fa, dis]{ stk.back() };
            stk.pop_back();
            res.push_back(dis);
            for (auto [v, w] : t.g[u]) {
                if (v == fa || ban[v]) continue;
                stk.push_back({v, u, dis + w});
            }
        }
        return res;
    }
    static i64 cnt(vector<i64> &a, i64 k) {
        sort(a.begin(), a.end());
        i64 res{};
        for (int l = 0, r = int(a.size()) - 1; l < r;) {
            if (i128(a[l]) + a[r] <= k) res += r - l, ++ l;
            else -- r;
        }
        return res;
    }
public:
    // ===== 通用点分治：f(c, all, sub) 处理当前重心 =====
    template<class F>
    void run(F f) {
        fill(ban.begin(), ban.end(), false);
        auto dfs = [&](auto &&self, int s) -> void {
            int c{ cen(s) };
            vector<i64> all{0};
            vector<vector<i64>> sub;
            for (auto [v, w] : t.g[c]) {
                if (ban[v]) continue;
                sub.push_back(dists(v, c, w));
                all.insert(all.end(), sub.back().begin(), sub.back().end());
            }
            f(c, all, sub);
            ban[c] = true;
            for (auto [v, w] : t.g[c]) if (!ban[v]) self(self, v);
        };
        dfs(dfs, 0);
    }
    // ===== 距离不超过 k 的点对计数 =====
    i64 count_leq(i64 k) {
        i64 ans{};
        run([&](int, vector<i64> &all, vector<vector<i64>> &sub) {
            ans += cnt(all, k);
            for (auto &a : sub) ans -= cnt(a, k);
        });
        return ans;
    }
};
```
##### 成员变量
- `ban[u]`：`u` 是否已经作为某层分治重心被删除
- `siz[u]`、`pre[u]`：寻找当前连通块重心时使用的临时数组
##### 接口
- `PointDiv(t)`：绑定原树，$O(n)$
- `run(f)`：执行一次完整点分治
- `f(c,all,sub)`：处理重心 `c`
  - `all`：当前连通块所有点到 `c` 的距离，包含 `c` 自己的 `0`
  - `sub[i]`：删除 `c` 后第 `i` 个分支内所有点到 `c` 的距离
- `count_leq(k)`：返回距离不超过 `k` 的**无序不同点对**数量
#### 核心统计方式
---
若某类路径信息可以由距离集合函数 $F(S)$ 求出，则所有**经过重心 `c` 的路径**通常写成：
$$
F(\text{all})-\sum_i F(\text{sub}_i)
$$
因为 `all` 会统计整个连通块的点对，而同一个分支内部的路径不经过当前重心，需要减掉
这正是点分治来源中“处理经过当前根的路径，再对子树继续分治”的结构
##### 注意事项
- `run()` 每次都会清空 `ban`，因此同一个对象可以重复执行不同统计
- `f()` 必须在当前调用中完成该重心的信息统计；`all/sub` 调用结束后即销毁
- 点分治递归的是**重心分治树**，深度为 $O(\log n)$；节点遍历本身使用显式栈，不会因为原树是一条链而爆 DFS 栈
- 距离使用 `i64`，需要保证单条树路径权值和不溢出
- `count_leq()` 的双指针比较使用 `i128`，避免两个 `i64` 距离相加溢出
- `count_leq()` 对边权正负都可工作；这里只使用唯一树路径的权值和
##### 常见用法
###### 距离不超过 k 的点对数
```cpp
PointDiv pd(tr);
i64 ans{ pd.count_leq(k) };
```
###### 自定义路径统计
例如要求“距离恰好出现于某个集合”时，可以自己处理 `all/sub`：
```cpp
PointDiv pd(tr);
pd.run([&](int c, vector<i64> &all, vector<vector<i64>> &sub) {
    // 统计 all
    // 减去每个 sub
});
```
##### 复杂度
- 通用 `run()`：$O(n\log n)$ 次节点访问，不计回调内部复杂度
- 临时空间：$O(n)$
- `count_leq(k)`：由于每层还需要排序，最坏 $O(n\log^2 n)$
#### 点分树与动态查询
---
**解决问题：** 原树不变，但节点状态不断修改，在线询问与某点距离有关的信息，例如：
- 到最近标记点的距离
- 某距离范围内标记点个数 / 权值和
- 点权修改后询问距离限制内的贡献
已有动态点分治模板会为一个原树节点保存它到各级分治重心的距离，并在每个重心维护总结构、分支结构，通过“总贡献减当前分支贡献”避免重复
```cpp
struct CDTree {
    struct A {
        int c, s;
        i64 d;
    };
    const TreeInfo &t;
    int root{ -1 }, sc{};
    vector<int> siz, pre, par, dep;
    vector<char> ban;
    vector<vector<A>> up;
    explicit CDTree(const TreeInfo &t_) : t(t_), siz(t.n), pre(t.n),
        par(t.n, -1), dep(t.n), ban(t.n), up(t.n) { build(); }
private:
    int cen(int s) {
        vector<int> ord, stk{s};
        pre[s] = -1;
        while (!stk.empty()) {
            int u{ stk.back() };
            stk.pop_back();
            ord.push_back(u);
            for (auto [v, w] : t.g[u]) {
                if (v == pre[u] || ban[v]) continue;
                pre[v] = u;
                stk.push_back(v);
            }
        }
        for (int i = int(ord.size()) - 1; i >= 0; -- i) {
            int u{ ord[i] };
            siz[u] = 1;
            for (auto [v, w] : t.g[u]) if (!ban[v] && pre[v] == u) siz[u] += siz[v];
        }
        int rt{ s }, best{ int(ord.size()) + 1 }, tot{ int(ord.size()) };
        for (int u : ord) {
            int mx{ tot - siz[u] };
            for (auto [v, w] : t.g[u]) if (!ban[v] && pre[v] == u) mx = max(mx, siz[v]);
            if (mx < best) best = mx, rt = u;
        }
        return rt;
    }
    void add_up(int s, int p, i64 d, int c, int id) {
        vector<tuple<int, int, i64>> stk{{s, p, d}};
        while (!stk.empty()) {
            auto [u, fa, dis]{ stk.back() };
            stk.pop_back();
            up[u].push_back({c, id, dis});
            for (auto [v, w] : t.g[u]) {
                if (v == fa || ban[v]) continue;
                stk.push_back({v, u, dis + w});
            }
        }
    }
public:
    void build() {
        fill(ban.begin(), ban.end(), false);
        fill(par.begin(), par.end(), -1);
        fill(dep.begin(), dep.end(), 0);
        for (auto &a : up) a.clear();
        sc = 0;
        auto dfs = [&](auto &&self, int s, int p) -> int {
            int c{ cen(s) };
            par[c] = p;
            dep[c] = p == -1 ? 0 : dep[p] + 1;
            up[c].push_back({c, -1, 0});
            ban[c] = true;
            for (auto [v, w] : t.g[c]) {
                if (ban[v]) continue;
                int id{ sc ++ };
                add_up(v, c, w, c, id);
                self(self, v, c);
            }
            return c;
        };
        root = dfs(dfs, 0, -1);
    }
};
```
##### 成员变量
- `root`：点分树根
- `par[c]`：重心 `c` 在点分树中的父节点
- `dep[c]`：点分树深度
- `up[u]`：原树节点 `u` 到各级分治重心的信息
- `A::c`：当前分治重心
- `A::d`：原树中 `u` 到 `c` 的距离
- `A::s`：`u` 位于 `c` 的哪个分支；`u==c` 时为 `-1`
- `sc`：所有分支编号总数
##### 接口
- `CDTree(t)`：构造点分树并预处理所有 `up[u]`
- `build()`：重新构造点分树
每个 `up[u]` 的长度为 $O(\log n)$
##### 注意事项
- `par` 是**点分树父节点**，与 `TreeInfo::fa` 完全不同
- `d` 是原树距离，不是点分树距离
- `s` 专门用于“总贡献减分支贡献”的动态统计；如果只需要最近点，可以直接忽略
- 原树结构发生变化后必须重建；单纯点权 / 标记变化不需要重建
- `CDTree` 不依赖 `TreeInfo::fa`，因此只要 `TreeInfo::g` 已建好即可
##### 最近标记点
下面是点分树最常见的应用：支持标记 / 取消标记节点，并查询距离某点最近的标记点
```cpp
struct CDNear {
    const CDTree &cd;
    vector<multiset<i64>> s;
    vector<char> on;
    explicit CDNear(const CDTree &cd_) : cd(cd_), s(cd.t.n), on(cd.t.n) {}
    void set(int u, bool v) {
        if (on[u] == v) return;
        on[u] = v;
        for (auto [c, id, d] : cd.up[u]) {
            if (v) s[c].insert(d);
            else s[c].erase(s[c].find(d));
        }
    }
    void flip(int u) { set(u, !on[u]); }
    i64 query(int u) const {
        constexpr i128 INF{ numeric_limits<i128>::max() };
        i128 ans{ INF };
        for (auto [c, id, d] : cd.up[u]) {
            if (!s[c].empty()) ans = min(ans, i128(d) + *s[c].begin());
        }
        return ans == INF ? -1 : i64(ans);
    }
};
```
##### 常见用法
```cpp
CDTree cd(tr);
CDNear ds(cd);

ds.set(u, true);   // 标记
ds.set(u, false);  // 取消
ds.flip(u);        // 翻转状态

i64 d{ ds.query(v) };
```
没有任何标记点时 `query()` 返回 `-1`。**CDNear 要求边权非负**，才能使用三角不等式取各级候选最小值；负边会使绕行重心的候选低估真实距离。根到点及任意原树路径距离须能放入 i64，候选相加使用 i128，支持包括 LLONG_MAX 在内的合法答案。CDTree 本身与总贡献减分支的统计不要求非负边。重建 CDTree 后应重新构造 CDNear。
##### 距离限制统计的扩展
若要支持：
```text
修改节点权值
查询 dist(u,v) <= k 的所有 v 的权值和
```
对 `up[u]` 中每个 `{c,s,d}`：
- 修改时向重心 `c` 的总结构加入距离 `d`
- 若 `s!=-1`，同时向分支 `s` 的结构加入距离 `d`
- 查询时统计总结构中距离不超过 `k-d` 的贡献
- 再减去分支 `s` 中距离不超过 `k-d` 的贡献
即：
$$
\sum_c \text{all}_c(k-d)-\sum_c \text{sub}_s(k-d)
$$
距离离散后可为各重心 / 分支挂 Fenwick、前缀数组或其他数据结构
##### 复杂度
`CDTree`：
- 构造时间：$O(n\log n)$
- `up` 总空间：$O(n\log n)$
`CDNear`：

| 操作 | 时间复杂度 |
|---|---:|
| `set()` / `flip()` | $O(\log^2 n)$ |
| `query()` | $O(\log n)$ |
| 空间 | $O(n\log n)$ 最坏 |
`set()` 多一个 $\log n$ 来自 `multiset` 插入 / 删除
#### 边分治
---
点分治保证每次按**点**把规模折半；边分治则希望找到一条较平衡的边，删除后递归两侧，并统计所有**跨过该边**的路径
普通树中未必存在足够平衡的边，例如菊花图。因此常先把高度数节点拆成若干**零权虚点**，使新树最大度数不超过 `3`，且所有原节点之间的距离保持不变，再进行边分治
依赖已经执行 `TreeInfo::build()` 的 `TreeInfo`，因为需要借助 `fa` 将原树定向后拆高度数点
```cpp
struct EdgeDiv {
    struct E {
        int to, id;
        i64 w;
    };
    const TreeInfo &t;
    int n0;
    vector<vector<E>> g;
    vector<int> eu, ev, siz, fa, pe;
    vector<i64> ew;
    vector<char> cut;
    explicit EdgeDiv(const TreeInfo &t_) : t(t_), n0(t.n), g(t.n) { build(); }
private:
    int node() {
        g.push_back({});
        return int(g.size()) - 1;
    }
    int link(int u, int v, i64 w) {
        int id{ int(eu.size()) };
        eu.push_back(u);
        ev.push_back(v);
        ew.push_back(w);
        cut.push_back(false);
        g[u].push_back({v, id, w});
        g[v].push_back({u, id, w});
        return id;
    }
    // ===== 将高儿子数节点拆成零权虚点链，使最大度数 <= 3 =====
    void build() {
        for (int u = 0; u < n0; ++ u) {
            vector<pair<int, i64>> ch;
            for (auto [v, w] : t.g[u]) if (t.fa[v] == u) ch.push_back({v, w});
            if (ch.size() <= 2) {
                for (auto [v, w] : ch) link(u, v, w);
                continue;
            }
            link(u, ch[0].first, ch[0].second);
            int cur{ u };
            for (int i = 1; i + 1 < int(ch.size()); ++ i) {
                int x{ node() };
                link(cur, x, 0);
                link(x, ch[i].first, ch[i].second);
                cur = x;
            }
            link(cur, ch.back().first, ch.back().second);
        }
        siz.resize(g.size());
        fa.resize(g.size());
        pe.resize(g.size());
    }
    // ===== 找当前连通块的平衡边 =====
    int cen(int s) {
        vector<int> ord, stk{s};
        fa[s] = pe[s] = -1;
        while (!stk.empty()) {
            int u{ stk.back() };
            stk.pop_back();
            ord.push_back(u);
            for (auto [v, id, w] : g[u]) {
                if (cut[id] || v == fa[u]) continue;
                fa[v] = u;
                pe[v] = id;
                stk.push_back(v);
            }
        }
        for (int i = int(ord.size()) - 1; i >= 0; -- i) {
            int u{ ord[i] };
            siz[u] = 1;
            for (auto [v, id, w] : g[u]) {
                if (!cut[id] && fa[v] == u) siz[u] += siz[v];
            }
        }
        int id{ -1 }, best{ int(ord.size()) + 1 }, tot{ int(ord.size()) };
        for (int u : ord) {
            if (pe[u] == -1) continue;
            int mx{ max(siz[u], tot - siz[u]) };
            if (mx < best) best = mx, id = pe[u];
        }
        return id;
    }
    // 返回某一侧所有原节点及其到该侧端点的距离
    vector<pair<int, i64>> side(int s, int ban_id) const {
        vector<pair<int, i64>> res;
        vector<tuple<int, int, i64>> stk{{s, -1, 0}};
        while (!stk.empty()) {
            auto [u, p, d]{ stk.back() };
            stk.pop_back();
            if (u < n0) res.push_back({u, d});
            for (auto [v, id, w] : g[u]) {
                if (id == ban_id || cut[id] || v == p) continue;
                stk.push_back({v, u, d + w});
            }
        }
        return res;
    }
public:
    // ===== 通用边分治 =====
    template<class F>
    void run(F f) {
        fill(cut.begin(), cut.end(), false);
        auto dfs = [&](auto &&self, int s) -> void {
            int id{ cen(s) };
            if (id == -1) return;
            auto a{ side(eu[id], id) };
            auto b{ side(ev[id], id) };
            f(eu[id], ev[id], ew[id], a, b);
            cut[id] = true;
            self(self, eu[id]);
            self(self, ev[id]);
        };
        dfs(dfs, 0);
    }
};
```
##### 编号
- `0..n0-1`：原树节点
- `n0..g.size()-1`：自动加入的零权虚点
- 虚点只为保证分治平衡，不应被当作题目中的真实节点
##### 接口
`run(f)` 每次找到分治边 `(u,v,w)`，调用：
```cpp
f(u, v, w, a, b);
```
其中：
- `a`：`u` 一侧所有**原节点**，元素为 `{x,dist(x,u)}`
- `b`：`v` 一侧所有**原节点**，元素为 `{y,dist(y,v)}`
- `w`：分治边权
任取：
```text
{x, dx} ∈ a
{y, dy} ∈ b
```
则原树中：
$$
\operatorname{dist}(x,y)=dx+w+dy
$$
因此所有跨越当前分治边的路径都可以在回调中统计
##### 常见用法
```cpp
EdgeDiv ed(tr);
ed.run([&](int u, int v, i64 w, auto &a, auto &b) {
    // 枚举 / 排序 / 数据结构统计 a 与 b 之间的跨边路径
});
```
##### 注意事项
- 构造前必须先执行 `TreeInfo::build()`
- 拆点加入的边权全部为 `0`，因此原节点之间的树上距离保持不变
- 拆点后节点总数仍为 $O(n)$，且最大度数不超过 `3`
- 与点分治类似，回调只统计**当前分治边两侧之间**的路径；同侧路径留给后续递归
- 若题目天然更适合点分治，一般不要主动使用边分治：它代码更长、虚点处理也更容易出错
##### 复杂度
拆点后设节点数为 $N=O(n)$：
- 建辅助树：$O(n)$
- 分治层数：$O(\log n)$
- 不计回调，所有节点枚举总复杂度：$O(n\log n)$
- 空间复杂度：$O(n)$
