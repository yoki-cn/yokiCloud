### 树链分解与树上序列化
---
**解决问题：** 将子树和树上路径映射为少量连续区间，接入 BIT / 线段树等序列数据结构；或利用长儿子优先顺序压缩深度相关树形 DP 的存储与合并
#### 选型
---

| 需求 | 使用 |
|---|---|
| 子树转连续区间 | `HLD::sub()` |
| 任意路径转少量区间 | `HLD::for_path()` |
| 非交换路径信息 | `HLD::path()` |
| 点权 / 边权路径数据结构 | HLD |
| 换根后的子树转区间 | `HLD::sub_r()` |
| LCA / 第 k 祖先且已经复制 HLD | HLD 自带接口 |
| 只需要 LCA | 4.2 |
| 按深度维护树形 DP | `LongChain` |
| 希望重儿子 DP 与父亲错位共享内存 | `LongChain` |
#### HLD / 重链剖分
---
依赖 **4.1.1 `TreeInfo`**，构造前必须已经执行 `TreeInfo::build()`
```cpp
struct HLD {
    struct Seg {
        int l, r;
        bool rev;
    };
    const TreeInfo &t;
    vector<int> son, top, in, out, seq;
    explicit HLD(const TreeInfo &t_) : t(t_), son(t.n, -1), top(t.n),
        in(t.n), out(t.n), seq(t.n) { build(); }
    // ===== 建树：按子树大小选择重儿子，并生成重儿子优先 DFS 序 =====
    void build() {
        fill(son.begin(), son.end(), -1);
        for (int u = 0; u < t.n; ++ u) {
            for (auto [v, w] : t.g[u]) {
                if (t.fa[v] == u && (son[u] == -1 || t.siz[v] > t.siz[son[u]])) son[u] = v;
            }
        }
        int cur{ 0 };
        vector<pair<int, int>> stk{{t.root, t.root}};
        while (!stk.empty()) {
            auto [u, tp]{ stk.back() };
            stk.pop_back();
            for (int x = u; x != -1; x = son[x]) {
                top[x] = tp;
                in[x] = cur;
                seq[cur ++] = x;
                for (auto it = t.g[x].rbegin(); it != t.g[x].rend(); ++ it) {
                    int v{ it->first };
                    if (t.fa[v] == x && v != son[x]) stk.push_back({v, v});
                }
            }
        }
        for (int u = 0; u < t.n; ++ u) out[u] = in[u] + t.siz[u];
    }
    // ===== 固定根子树与无序路径 =====
    pair<int, int> sub(int u, bool edge = false) const {
        return {in[u] + edge, out[u]};
    }
    template<class F>
    void for_path(int u, int v, F &&f, bool edge = false) const {
        while (top[u] != top[v]) {
            if (t.dep[top[u]] < t.dep[top[v]]) swap(u, v);
            f(in[top[u]], in[u] + 1);
            u = t.fa[top[u]];
        }
        if (t.dep[u] > t.dep[v]) swap(u, v);
        int l{ in[u] + edge }, r{ in[v] + 1 };
        if (l < r) f(l, r);
    }
    // ===== 有序路径：若所有维护信息满足交换律，可删除 Seg 和以下函数 =====
    vector<Seg> path(int u, int v, bool edge = false) const {
        vector<Seg> a, b;
        while (top[u] != top[v]) {
            if (t.dep[top[u]] >= t.dep[top[v]]) {
                a.push_back({in[top[u]], in[u] + 1, true});
                u = t.fa[top[u]];
            } else {
                b.push_back({in[top[v]], in[v] + 1, false});
                v = t.fa[top[v]];
            }
        }
        if (t.dep[u] >= t.dep[v]) {
            int l{ in[v] + edge }, r{ in[u] + 1 };
            if (l < r) a.push_back({l, r, true});
        } else {
            int l{ in[u] + edge }, r{ in[v] + 1 };
            if (l < r) b.push_back({l, r, false});
        }
        reverse(b.begin(), b.end());
        a.insert(a.end(), b.begin(), b.end());
        return a;
    }
    // ===== 定位接口 =====
    int lca(int u, int v) const {
        while (top[u] != top[v]) {
            if (t.dep[top[u]] < t.dep[top[v]]) swap(u, v);
            u = t.fa[top[u]];
        }
        return t.dep[u] < t.dep[v] ? u : v;
    }
    int jump(int u, int k) const {
        if (k < 0 || k > t.dep[u]) return -1;
        int d{ t.dep[u] - k };
        while (t.dep[top[u]] > d) u = t.fa[top[u]];
        return seq[in[u] - (t.dep[u] - d)];
    }
    int kth(int u, int v, int k) const {
        int p{ lca(u, v) };
        int a{ t.dep[u] - t.dep[p] }, b{ t.dep[v] - t.dep[p] };
        if (k < 0 || k > a + b) return -1;
        return k <= a ? jump(u, k) : jump(v, a + b - k);
    }
    // ===== 换根子树：依赖 jump() =====
    vector<pair<int, int>> sub_r(int u, int r) const {
        if (u == r) return {{0, t.n}};
        if (!t.is_anc(u, r)) return {{in[u], out[u]}};
        int v{ jump(r, t.dep[r] - t.dep[u] - 1) };
        vector<pair<int, int>> res;
        if (in[v]) res.push_back({0, in[v]});
        if (out[v] < t.n) res.push_back({out[v], t.n});
        return res;
    }
};
```
##### 成员变量
- `son[u]`：`u` 的重儿子，即子树大小最大的儿子，不存在为 `-1`
- `top[u]`：`u` 所在重链的链顶
- `in[u]`：`u` 在重儿子优先 DFS 序中的位置
- `out[u]`：子树右端点，子树对应 `[in[u],out[u])`
- `seq[i]`：位置 `i` 对应的原树节点
- `Seg{l,r,rev}`：有向路径段 `[l,r)`；`rev=true` 表示实际经过顺序为 `r-1 -> l`
##### 接口
- `HLD(t)`：基于已完成预处理的 `TreeInfo` 建立 HLD，$O(n)$
- `build()`：重新构建 HLD，$O(n)$
- `sub(u,edge)`：返回固定根下 `u` 的子树区间，$O(1)$
- `for_path(u,v,f,edge)`：把路径拆成 $O(\log n)$ 个区间并调用 `f(l,r)`，$O(\log n)$
- `path(u,v,edge)`：按实际 `u -> v` 顺序返回路径段，$O(\log n)$
- `lca(u,v)`：LCA，$O(\log n)$
- `jump(u,k)`：向上跳 `k` 条边，不存在返回 `-1`，$O(\log n)$
- `kth(u,v,k)`：路径 `u -> v` 上从 `u` 起第 `k` 个点，不存在返回 `-1`，$O(\log n)$
- `sub_r(u,r)`：临时以 `r` 为根时，将 `u` 的子树表示成至多两个序列区间，$O(\log n)$
##### 注意事项
- `TreeInfo::build()` 与 `HLD::build()` 必须使用同一棵有根树；若重新调用了前者，必须再次调用后者
- `HLD::in/out` 与 `TreeInfo::in/out` 是两套不同序列；接入数据结构时使用 **HLD 自己的** `in/out`
- `for_path()` 不保证回调顺序等于 `u -> v` 的路径顺序，只适合加法、最大值、最小值、异或等交换型维护
- 矩阵乘法、字符串拼接等非交换信息使用 `path()`，并按 `rev` 选择正向或反向区间信息
- `edge=false` 为点权模式；`edge=true` 会排除 LCA 对应位置，用于边权模式。
- 边权模式把边 `(fa[u],u)` 的权值存到位置 `in[u]`，根节点位置不对应任何父边
- 一条树路径只会跨过 $O(\log n)$ 条重链，因此配合单次 $O(\log n)$ 的线段树操作时，整条路径通常为 $O(\log^2 n)$
##### 常见用法
###### 点权序列化
```cpp
vector<i64> a(n);
for (int u = 0; u < n; ++ u) a[hld.in[u]] = w[u];
```
###### 子树查询
```cpp
auto [l, r]{ hld.sub(u) };
auto ans{ seg.query(l, r) };
```
###### 路径查询 / 修改
```cpp
i64 ans{};
hld.for_path(u, v, [&](int l, int r) {
    ans += seg.query(l, r);
});
```
路径修改同理：
```cpp
hld.for_path(u, v, [&](int l, int r) {
    seg.apply(l, r, x);
});
```
###### 边权路径
每条边挂到较深端点：
```cpp
int x{ tr.dep[u] > tr.dep[v] ? u : v };
a[hld.in[x]] = w;
```
查询时：
```cpp
hld.for_path(u, v, [&](int l, int r) {
    ans += seg.query(l, r);
}, true);
```
###### 非交换路径信息
```cpp
for (auto [l, r, rev] : hld.path(u, v)) {
    // 查询 [l,r)；
    // rev=true 时使用该区间的反向聚合信息
}
```
###### 动态根子树
```cpp
for (auto [l, r] : hld.sub_r(u, root)) {
    ans += seg.query(l, r);
}
```
##### 复杂度

| 操作 | 时间复杂度 |
|---|---:|
| 构建 | $O(n)$ |
| `sub()` | $O(1)$ |
| `for_path()` / `path()` | $O(\log n)$ 个区间 |
| `lca()` / `jump()` / `kth()` | $O(\log n)$ |
| `sub_r()` | $O(\log n)$ |
空间复杂度：$O(n)$
> [!tip]
> 如果已经复制 HLD，就不必为了 `lca()`、`jump()`、`kth()` 再复制 4.2 的倍增 LCA；反过来，如果题目完全没有路径 / 子树数据结构操作，只需要 LCA，则 4.2 的版本更合适
#### 长链剖分
---
长链剖分选择的是**向下最深的儿子**，而不是 HLD 中**子树最大的儿子**。旧版也明确将 `len[u]` 定义为从 `u` 向下的最大节点数，并据此选择长儿子
```cpp
struct LongChain {
    const TreeInfo &t;
    vector<int> len, son, top, in, seq;
    explicit LongChain(const TreeInfo &t_) : t(t_), len(t.n, 1), son(t.n, -1), top(t.n), in(t.n), seq(t.n) { build(); }
    void build() {
        fill(len.begin(), len.end(), 1);
        fill(son.begin(), son.end(), -1);
        for (int i = t.n - 1; i > 0; -- i) {
            int u{ t.seq[i] }, p{ t.fa[u] };
            if (len[u] + 1 > len[p]) {
                len[p] = len[u] + 1;
                son[p] = u;
            }
        }
        int cur{ 0 };
        vector<pair<int, int>> stk{{t.root, t.root}};
        while (!stk.empty()) {
            auto [u, tp]{ stk.back() };
            stk.pop_back();
            for (int x = u; x != -1; x = son[x]) {
                top[x] = tp;
                in[x] = cur;
                seq[cur ++] = x;
                for (auto it = t.g[x].rbegin(); it != t.g[x].rend(); ++ it) {
                    int v{ it->first };
                    if (t.fa[v] == x && v != son[x]) stk.push_back({v, v});
                }
            }
        }
    }
    // ===== 长儿子路径区间：常用于深度 DP 的共享存储 =====
    pair<int, int> down(int u) const { return {in[u], in[u] + len[u]}; }
};
```
##### 成员变量
- `len[u]`：从 `u` 向下的最长路径包含的节点数，叶子为 `1`
- `son[u]`：使 `len[v]` 最大的长儿子，不存在为 `-1`
- `top[u]`：`u` 所在长链的链顶
- `in[u]`：长儿子优先序中的位置
- `seq[i]`：位置 `i` 对应的原树节点
满足：
```text
son[u] != -1  =>  in[son[u]] = in[u] + 1
```
并且：
```text
seq[in[u]], seq[in[u]+1], ..., seq[in[u]+len[u]-1]
```
恰好是从 `u` 不断沿 `son` 向下得到的最长链
###### 接口
- `LongChain(t)`：构建长链剖分，$O(n)$
- `build()`：重新构建，$O(n)$
- `down(u)`：返回从 `u` 开始沿长儿子向下的连续区间 `[l,r)`，$O(1)$
##### 注意事项
- HLD 的 `son[u]` 按 `siz` 最大选择；长链剖分的 `son[u]` 按 `len` 最大选择，二者不能混用
- 长链剖分的主要用途是**与深度有关的树形 DP**，不是把任意路径拆成 $O(\log n)$ 段
- `in[u]+len[u]` 不超过当前长链分配的连续区域，可以直接用于 DP 数组错位共享
- `TreeInfo` 换根后必须重新 `build()`
- 长链剖分本身是 $O(n)$；具体 DP 是否能做到 $O(n)$ 取决于轻儿子状态的合并方式，并不是用了长链剖分就自动线性。旧版也特别强调只有短链元素总共被合并 $O(1)$ 次时才能得到线性复杂度
##### 常见用法
###### 深度 DP 共享存储
若 `f[u][d]` 表示距 `u` 深度为 `d` 的某类状态，可以把所有 DP 统一放进长度为 `n` 的缓冲区：
```cpp
LongChain lc(tr);
vector<i64> buf(n);
auto f = [&](int u) { return buf.data() + lc.in[u]; };
```
于是长儿子天然满足：
```cpp
if (lc.son[u] != -1) {
    // f(lc.son[u]) == f(u) + 1
}
```
即长儿子的：
```text
f[son[u]][d]
```
与父节点的：
```text
f[u][d+1]
```
直接共享同一位置
###### 枚举长儿子路径
```cpp
auto [l, r]{ lc.down(u) };
for (int i = l; i < r; ++ i) {
    int v{ lc.seq[i] };
}
```

| 操作 | 时间复杂度 |
|---|---:|
| 构建 | $O(n)$ |
| `down()` | $O(1)$ |
空间复杂度：$O(n)$
