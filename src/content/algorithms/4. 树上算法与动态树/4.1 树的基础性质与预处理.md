### 树的基础性质与预处理
---
#### 树信息、DFS 序与子树
---
```cpp
struct TreeInfo {
    int n, root{ -1 };
    vector<vector<pair<int, i64>>> g;
    vector<int> fa, dep, siz, in, out, seq;
    vector<i64> dis;
    explicit TreeInfo(int n_) : n(n_), g(n), fa(n, -1), dep(n), siz(n),
        in(n), out(n), seq(n), dis(n) {}
    void add(int u, int v, i64 w = 1) {
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }
    void build(int root_ = 0) {
        root = root_;
        fill(fa.begin(), fa.end(), -1);
        int cur{ 0 };
        vector<int> stk{ root };
        fa[root] = root;
        dep[root] = 0;
        dis[root] = 0;
        while (!stk.empty()) {
            int u{ stk.back() };
            stk.pop_back();
            in[u] = cur;
            seq[cur ++] = u;
            for (auto it = g[u].rbegin(); it != g[u].rend(); ++ it) {
                auto [v, w]{ *it };
                if (v == fa[u]) continue;
                fa[v] = u;
                dep[v] = dep[u] + 1;
                dis[v] = dis[u] + w;
                stk.push_back(v);
            }
        }
        fill(siz.begin(), siz.end(), 1);
        for (int i = n - 1; i > 0; -- i) {
            int u{ seq[i] };
            siz[fa[u]] += siz[u];
        }
        for (int u = 0; u < n; ++ u) out[u] = in[u] + siz[u];
    }
    bool is_anc(int u, int v) const { return in[u] <= in[v] && in[v] < out[u]; }
    pair<int, int> sub(int u) const { return {in[u], out[u]}; }
};
```
##### 成员变量
- `n`：节点数，编号为 `0..n-1`
- `root`：最近一次 `build()` 使用的根
- `g[u]`：无向带权邻接表，无权树直接使用默认边权 `1`
- `fa[u]`：预处理根下的父节点，内部满足 `fa[root] = root`
- `dep[u]`：深度，`dep[root] = 0`
- `siz[u]`：子树大小
- `dis[u]`：从 `root` 到 `u` 的路径边权和
- `in[u]`、`out[u]`：子树对应 DFS 序区间 `[in[u],out[u])`
- `seq[i]`：DFS 序位置 `i` 对应的原节点，满足 `seq[in[u]] = u`
##### 接口
- `TreeInfo(n)`：初始化 `n` 个节点，$O(n)$
- `add(u,v,w)`：加入无向边，默认 `w=1`，均摊 $O(1)$
- `build(root)`：预处理父节点、深度、根距离、子树大小和 DFS 序，$O(n)$
- `is_anc(u,v)`：判断 `u` 是否为 `v` 的祖先，$O(1)$
- `sub(u)`：返回 `u` 的子树区间 `[in[u],out[u])`，$O(1)$
##### 注意事项
- 要求 `n>=1`，输入为含 `n-1` 条边的连通无向树
- 所有节点和区间均为 `0base`，区间使用 `[l,r)`
- `fa[root]=root` 是内部约定；判断根节点时直接与 `root` 比较
- `seq` 是 DFS 先序，不是 LCA 中长度约为 `2n-1` 的 Euler Tour
- `dis` 只是唯一树路径的权值和，即使有负边也能正常计算；但数值必须能够放入 `i64`
- `build()` 不修改邻接表，可以换根后重新调用
##### 常见用法
###### 子树转连续区间
```cpp
TreeInfo tr(n);
// tr.add(...)
tr.build(0);
auto [l, r]{ tr.sub(u) };
```
###### 点权按 DFS 序展开
```cpp
vector<i64> b(n);
for (int u = 0; u < n; ++ u) b[tr.in[u]] = a[u];
```
###### 自底向上遍历
```cpp
for (int i = n - 1; i > 0; -- i) {
    int u{ tr.seq[i] }, p{ tr.fa[u] };
    // 用 u 的信息更新 p
}
```
##### 复杂度

| 操作 | 时间复杂度 |
|---|---:|
| `add()` | 均摊 $O(1)$ |
| `build()` | $O(n)$ |
| `is_anc()` / `sub()` | $O(1)$ |
空间复杂度：$O(n)$
#### 直径、中心与重心
---
```cpp
struct TreeProp {
    const TreeInfo &t;
    explicit TreeProp(const TreeInfo &t_) : t(t_) {}
    // ===== 距离与直径：diam() / ecc() / center() 依赖 =====
    vector<i64> dists(int s) const {
        vector<i64> d(t.n);
        vector<pair<int, int>> stk{{s, -1}};
        while (!stk.empty()) {
            auto [u, p]{ stk.back() };
            stk.pop_back();
            for (auto [v, w] : t.g[u]) {
                if (v == p) continue;
                d[v] = d[u] + w;
                stk.push_back({v, u});
            }
        }
        return d;
    }
    pair<int, i64> far(int s) const {
        auto d{ dists(s) };
        int u{ int(max_element(d.begin(), d.end()) - d.begin()) };
        return {u, d[u]};
    }
    tuple<int, int, i64> diam() const {
        int s{ far(0).first };
        auto [t, d]{ far(s) };
        return {s, t, d};
    }
    // ===== 离心率与中心 =====
    vector<i64> ecc() const {
        int s{ far(0).first };
        auto ds{ dists(s) };
        int t{ int(max_element(ds.begin(), ds.end()) - ds.begin()) };
        auto dt{ dists(t) };
        for (int u = 0; u < this->t.n; ++ u) ds[u] = max(ds[u], dt[u]);
        return ds;
    }
    pair<i64, vector<int>> center() const {
        auto e{ ecc() };
        i64 r{ *min_element(e.begin(), e.end()) };
        vector<int> res;
        for (int u = 0; u < t.n; ++ u) if (e[u] == r) res.push_back(u);
        return {r, res};
    }
    // ===== 重心 =====
    vector<int> centroid() const {
        vector<int> res;
        for (int u = 0; u < t.n; ++ u) {
            int mx{ t.n - t.siz[u] };
            for (auto [v, w] : t.g[u]) {
                if (t.fa[v] == u) mx = max(mx, t.siz[v]);
            }
            if (mx * 2 <= t.n) res.push_back(u);
        }
        return res;
    }
};
```
##### 接口说明
- `TreeProp(t)`：绑定一棵 `TreeInfo`，$O(1)$
- `dists(s)`：返回 `s` 到所有节点的路径权值和，$O(n)$
- `far(s)`：返回距离 `s` 最远的节点及距离，要求边权非负，$O(n)$
- `diam()`：返回 `{s,t,d}`，其中 `s-t` 为一条直径、`d` 为直径长度，$O(n)$
- `ecc()`：返回每个节点的离心率，即到最远节点的距离，$O(n)$
- `center()`：返回 `{半径,所有节点中心}`，$O(n)$
- `centroid()`：返回一个或两个重心，需要先调用 `TreeInfo::build()`，$O(n)$
##### 注意事项
- `far()`、`diam()`、`ecc()`、`center()` 的端点性质要求边权非负
- 若存在负边权，最大权路径应改用树形 DP，不能使用两次 `far()`
- `center()` 求的是**节点中心**；无权树中即经典树中心
- 带权树若允许中心落在边内部，则连续中心位于某条直径中点，本函数不表示边内部位置
- `centroid()` 只由树拓扑决定，与边权无关
- 树重心最多有两个；若有两个则相邻
- `centroid()` 依赖 `fa` 和 `siz`，因此调用前必须完成 `build()`
##### 常见用法
```cpp
TreeInfo tr(n);
// tr.add(...)
tr.build(0);
TreeProp tp(tr);

auto [s, t, d]{ tp.diam() };
auto [r, cen]{ tp.center() };
vector<int> cog{ tp.centroid() };
```
##### 复杂度

| 操作 | 时间复杂度 |
|---|---:|
| `dists()` / `far()` | $O(n)$ |
| `diam()` | $O(n)$ |
| `ecc()` / `center()` | $O(n)$ |
| `centroid()` | $O(n)$ |
额外空间复杂度：$O(n)$
#### 树哈希与树同构
---
```cpp
struct TreeIso {
    map<vector<int>, int> id;
    // ===== 有根树规范编号：核心功能 =====
    vector<int> rids(const vector<vector<int>> &g, int root) {
        int n{ int(g.size()) };
        vector<int> fa(n, -1), seq(n), val(n);
        int ord{ 1 };
        seq[0] = root;
        fa[root] = root;
        for (int i = 0; i < ord; ++ i) {
            int u{ seq[i] };
            for (int v : g[u]) {
                if (fa[v] != -1) continue;
                fa[v] = u;
                seq[ord ++] = v;
            }
        }
        for (int i = n - 1; i >= 0; -- i) {
            int u{ seq[i] };
            vector<int> ch;
            for (int v : g[u]) if (fa[v] == u) ch.push_back(val[v]);
            sort(ch.begin(), ch.end());
            auto [it, ok]{ id.try_emplace(move(ch), int(id.size())) };
            val[u] = it->second;
        }
        return val;
    }
    int rid(const vector<vector<int>> &g, int root) { return rids(g, root)[root]; }
    bool same_root(const vector<vector<int>> &a, int ra,
                   const vector<vector<int>> &b, int rb) {
        return a.size() == b.size() && rid(a, ra) == rid(b, rb);
    }
    // ===== 无根树同构 =====
    vector<int> cent(const vector<vector<int>> &g) const {
        int n{ int(g.size()) };
        if (n <= 2) {
            vector<int> res(n);
            iota(res.begin(), res.end(), 0);
            return res;
        }
        vector<int> deg(n);
        queue<int> q;
        for (int u = 0; u < n; ++ u) {
            deg[u] = g[u].size();
            if (deg[u] == 1) q.push(u);
        }
        int rem{ n };
        while (rem > 2) {
            int cnt{ int(q.size()) };
            rem -= cnt;
            while (cnt --) {
                int u{ q.front() };
                q.pop();
                for (int v : g[u]) if (-- deg[v] == 1) q.push(v);
            }
        }
        vector<int> res;
        while (!q.empty()) {
            res.push_back(q.front());
            q.pop();
        }
        return res;
    }
    vector<int> uid(const vector<vector<int>> &g) {
        vector<int> res;
        for (int u : cent(g)) res.push_back(rid(g, u));
        sort(res.begin(), res.end());
        return res;
    }
    bool same(const vector<vector<int>> &a, const vector<vector<int>> &b) {
        return a.size() == b.size() && uid(a) == uid(b);
    }
};
```
##### 成员变量
- `id`：规范子树结构到唯一整数编号的映射；同一组比较中必须共享
##### 接口
- `rids(g,root)`：返回以 `root` 为根时每个节点子树的规范编号，$O(n\log n)$
- `rid(g,root)`：返回整棵有根树的规范编号，$O(n\log n)$
- `same_root(a,ra,b,rb)`：判断两棵有根树是否同构，$O(n\log n)$
- `cent(g)`：返回无根树的一个或两个拓扑中心，$O(n)$
- `uid(g)`：返回无根树规范编号，$O(n\log n)$
- `same(a,b)`：判断两棵无根树是否同构，$O(n\log n)$
##### 注意事项
- `g` 必须表示一棵 `0base` 连通无向树，且节点数至少为 `1`
- AHU 规范编号为确定性算法，不存在随机哈希碰撞
- **需要比较的多棵树必须使用同一个 `TreeIso` 对象**，否则整数编号没有直接可比性
- `rids()` 可以直接用于判断同一棵有根树中的两个子树是否同构
- `id` 会跨调用保留已经出现过的规范类型；一组独立比较结束后可重新构造 `TreeIso`。表中已有 S 种类型时，单次时间更准确地为 O(n log n + n log(S+n))；表的空间由所有规范键的总长度决定。使用 try_emplace，已存在的键不再构造节点或复制键
- 当前版本只考虑树的拓扑。如果节点有颜色，应把规范键改成 `{color[u],ch}`；边有类型时也应把边类型纳入规范键
##### 常见用法
###### 有根树同构
```cpp
TreeIso iso;
bool ok{ iso.same_root(a, ra, b, rb) };
```
###### 无根树同构
```cpp
TreeIso iso;
bool ok{ iso.same(a, b) };
```
###### 判断两棵子树是否同构
```cpp
TreeIso iso;
auto h{ iso.rids(g, root) };
bool ok{ h[u] == h[v] };
```
##### 复杂度

| 操作 | 时间复杂度 |
|---|---:|
| `rids()` / `rid()` | $O(n\log n)$ |
| `cent()` | $O(n)$ |
| `uid()` / `same()` | $O(n\log n)$ |
单次处理额外空间复杂度：$O(n)$；`id` 的空间取决于累计出现的规范子树类型数
