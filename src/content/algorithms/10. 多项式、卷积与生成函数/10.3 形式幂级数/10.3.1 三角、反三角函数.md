### FPS 三角与反三角函数

> 依赖：`10.2.1 Poly`、静态 `Z=MInt<998244353>`。

```cpp
// 仅用于 mod=998244353；i²=-1，f[0]=0
namespace FPSFunc {
    Z imag() { static const Z I = Z(3).pow((Z::mod() - 1) / 4); return I; }
    Poly<Z> sin(Poly<Z> f, int n) {
        Z I = imag();
        auto a = (f * I).exp(n), b = (f * -I).exp(n);
        return (a - b).trunc(n) / (Z(2) * I);
    }
    Poly<Z> cos(Poly<Z> f, int n) {
        Z I = imag();
        auto a = (f * I).exp(n), b = (f * -I).exp(n);
        return (a + b).trunc(n) / Z(2);
    }
    Poly<Z> atan(Poly<Z> f, int n) {
        return (f.deriv() * (Poly<Z>{1} + f * f).inv(n)).integr().trunc(n);
    }
    Poly<Z> asin(Poly<Z> f, int n) {
        return (f.deriv() * (Poly<Z>{1} - f * f).sqrt(n, Z(1)).inv(n)).integr().trunc(n);
    }
}
```

#### 接口说明

- `FPSFunc::sin(f,n)` / `cos(f,n)`：分别计算形式三角函数。
- `FPSFunc::atan(f,n)` / `asin(f,n)`：计算常数项为零的形式反三角函数，归一化为常数项零。

#### 注意事项

- 仅适用默认 `998244353`（存在 $i^2=-1$）、`n<mod` 且 `f[0]=0`；此时使用形式指数、积分定义。
- `atan`、`asin` 不含一般数值分支选择；**不是实数角度计算器**。
- `asin` 中取常数项为 `1` 的平方根分支。

#### 常见用法

```cpp
Poly<Z> x{0, 1};
auto s = FPSFunc::sin(x, 8);
auto c = FPSFunc::cos(x, 8);
auto t = FPSFunc::atan(x, 8);
auto arcs = FPSFunc::asin(x, 8);
```

#### 复杂度

- 四种函数：$O(M(n))$ 量级时间、$O(n)$ 空间，三角函数含两次 `exp`。
