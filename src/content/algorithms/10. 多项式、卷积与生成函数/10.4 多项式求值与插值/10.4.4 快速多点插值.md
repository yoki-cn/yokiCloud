### 快速多点插值（子积树）
---
> 依赖：必须先复制 `10.4.3 ProductTree`，以及 `10.2.1 Poly`。

```cpp
// ===== 选配：只做多点求值时可删除整个函数 =====
// x_i 必须两两不同，pts 从 10.4.3 构造
Poly<Z> interpolate(const ProductTree &pts, const vector<Z> &y) {
    int n = pts.n;
    assert(int(y.size()) == n);
    if (!n) return {};
    auto d = pts.eval(pts.p[1].deriv());
    vector<Z> w(n);
    for (int i = 0; i < n; ++ i) {
        assert(d[i] != Z{});
        w[i] = y[i] / d[i];
    }
    auto dfs = [&](auto &&self, int u, int l, int r) -> Poly<Z> {
        if (r - l == 1) return Poly<Z>{w[l]};
        int m = (l + r) / 2;
        auto a = self(self, u * 2, l, m);
        auto b = self(self, u * 2 + 1, m, r);
        return a * pts.p[u * 2 + 1] + b * pts.p[u * 2];
    };
    auto f = dfs(dfs, 1, 0, n);
    f.norm();
    return f;
}
```

#### 接口说明

- `interpolate(pts,y)`：根据 `pts.x[i], y[i]` 恢复唯一的次数 `< n` 的多项式 `Poly<Z>`，已复用相同子积树。

#### 注意事项

- 点 `x[i]` 必须两两不同，否则 `P'(x_i)=0` 且插值不唯一。
- `ProductTree` 与插值应使用同一种系数域；本实现默认 `Z`。
- `n=0` 返回空多项式；恢复结果用 `norm()` 去最高零项。

#### 常见用法

```cpp
vector<Z> x{0, 1, 2}, y{1, 6, 17};
ProductTree pts(x);
auto f = interpolate(pts, y); // 1+2x+3x²
auto check = pts.eval(f);     // 等于 y
```

#### 复杂度

- $O(M(n) \log n)$ 时间，已建树时额外 $O(n \log n)$ 空间（递归中间多项式）。
