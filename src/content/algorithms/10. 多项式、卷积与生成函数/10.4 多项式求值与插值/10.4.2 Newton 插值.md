### Newton 差商插值
---
> 依赖：仅要求域上的 `+ - * /`，不依赖 `Poly`。

```cpp
// 任意互异 x[i] 对应 y[i]，返回 Newton 基系数 c
// f(t)=c[0]+c[1](t-x[0])+...+c[n-1]prod_{i<n-1}(t-x[i])
template<class T>
vector<T> newton_coeff(const vector<T> &x, vector<T> y) {
    int n = x.size();
    assert(n == int(y.size()));
    for (int j = 1; j < n; ++ j) {
        for (int i = n - 1; i >= j; -- i) {
            y[i] = (y[i] - y[i - 1]) / (x[i] - x[i - j]);
        }
    }
    return y;
}
template<class T>
T newton_eval(const vector<T> &x, const vector<T> &c, T t) {
    int n = x.size();
    assert(n == int(c.size()));
    T r{};
    for (int i = n - 1; i >= 0; -- i) r = r * (t - x[i]) + c[i];
    return r;
}
```

#### 接口说明

- `newton_coeff(x,y)`：返回差商 `c`，即 Newton 基展开系数。
- `newton_eval(x,c,t)`：不转换成普通幂基，直接 $O(n)$ 求值。

#### 注意事项

- 所有采样横坐标 `x[i]` 必须两两不同，且 `x[i]-x[j]` 可逆。
- 返回的系数不是标准幂基 $1,x,x^2,\ldots$ 的系数！若需要常规 `Poly`，应显式做基底转换。

#### 常见用法

```cpp
vector<Z> x{2, 5, 7}, y{9, 36, 64}; // (x+1)^2
auto c = newton_coeff(x, y);
Z ans = newton_eval(x, c, Z(10)); // 121
```

#### 复杂度

- 求差商 $O(n^2)$ 时间、$O(n)$ 额外空间；给定差商后单点求值 $O(n)$。
