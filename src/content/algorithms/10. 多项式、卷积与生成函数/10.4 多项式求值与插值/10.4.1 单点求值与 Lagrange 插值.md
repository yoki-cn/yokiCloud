### 单点求值与连续点 Lagrange 插值
---
> 依赖：静态模整数或一般域上的 `T`，无需 NTT。

```cpp
// y[i]=f(i), i=0..n-1；deg(f) < n
// 查询任意一个 x 的 f(x)，O(n)
template<class T>
T lagrange(const vector<T> &y, T x) {
    int n = y.size();
    if (n == 0) return T{};
    for (int i = 0; i < n; ++ i) if (x == T(i)) return y[i];
    vector<T> fac(n), ifac(n), pre(n + 1), suf(n + 1);
    fac[0] = 1;
    for (int i = 1; i < n; ++ i) fac[i] = fac[i - 1] * T(i);
    ifac[n - 1] = T(1) / fac[n - 1];
    for (int i = n - 1; i >= 1; -- i) ifac[i - 1] = ifac[i] * T(i);
    pre[0] = suf[n] = 1;
    for (int i = 0; i < n; ++ i) pre[i + 1] = pre[i] * (x - T(i));
    for (int i = n - 1; i >= 0; -- i) suf[i] = suf[i + 1] * (x - T(i));
    T ans{};
    for (int i = 0; i < n; ++ i) {
        T cur = y[i] * pre[i] * suf[i + 1] * ifac[i] * ifac[n - 1 - i];
        ans += (n - 1 - i) & 1 ? -cur : cur;
    }
    return ans;
}
```

#### 接口说明

- `f.eval(x)`：Poly 的 Horner 法，已知系数求一个点，$O(deg f)$。
- `lagrange(y,x)`：已知 `f(0)..f(n-1)` 求 `f(x)`，不必先恢复系数，$O(n)$ 时间与空间。

#### 注意事项

- 必须**已知** `deg f < y.size()`，否则只有前 n 个采样值不足以确定多项式。
- 模数需使 `1..n-1` 可逆；`998244353` 下通常 `n<=998244353`（实际范围远小于此）。
- 若许多点重复查询，阶乘/逆阶乘可预处理在外部，避免反复 $O(n)$ 初始化。

#### 常见用法

```cpp
vector<Z> y{1, 4, 9, 16};   // f(x)=(x+1)^2
Z ans = lagrange(y, Z(100)); // 10201
Poly<Z> f{1, 2, 1};
Z val = f.eval(Z(100));
```

#### 复杂度

- `eval` $O(n)$ 时间、$O(1)$ 额外空间；`lagrange` $O(n)$ 时间与空间。
