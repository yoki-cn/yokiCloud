### 多点求值（子积树）
---
> 依赖：`10.2.1 Poly` 的 `divmod`、`*`、`eval`；底层 NTT。

```cpp
struct ProductTree {
    int n;
    vector<Z> x;
    vector<Poly<Z>> p;
    explicit ProductTree(vector<Z> x_) : n(x_.size()), x(move(x_)), p(4 * max(1, n)) {
        if (n) build(1, 0, n);
    }
    void build(int u, int l, int r) {
        if (r - l == 1) {
            p[u] = Poly<Z>{-x[l], 1};
            return;
        }
        int m = (l + r) / 2;
        build(u * 2, l, m);
        build(u * 2 + 1, m, r);
        p[u] = p[u * 2] * p[u * 2 + 1];
    }
    void dfs_eval(int u, int l, int r, Poly<Z> f, vector<Z> &ans) const {
        if (r - l == 1) {
            ans[l] = f.eval(x[l]);
            return;
        }
        int m = (l + r) / 2;
        dfs_eval(u * 2, l, m, f % p[u * 2], ans);
        dfs_eval(u * 2 + 1, m, r, f % p[u * 2 + 1], ans);
    }
    vector<Z> eval(Poly<Z> f) const {
        vector<Z> ans(n);
        if (n) {
            if (f.size() >= p[1].size()) f = f % p[1];
            dfs_eval(1, 0, n, move(f), ans);
        }
        return ans;
    }
};
```

#### 接口说明

- `ProductTree pts(x)`：按待查询点建立子积树，其中 `p[1]=∏(X-x[i])`。
- `pts.eval(f)`：计算每个 `f(x[i])`，按传入顺序返回；支持重复点。

#### 注意事项

- 每个子树保存一个乘积多项式，复用 Poly 的普通除法 `%`。
- `x` 可以重复，用于多点求值没问题；但用于后续插值时必须互异。
- 对固定一组 `x` 多次求值，`ProductTree` **只建一次**可复用，避免重复构造。

#### 常见用法

```cpp
vector<Z> xs{0, 1, 2, 3};
ProductTree pts(xs);
Poly<Z> f{1, 2, 3};
auto ys = pts.eval(f); // {1,6,17,34}
```

#### 复杂度

- `n` 个点、$\deg f<n$：建树 $O(M(n) \log n)$；求值 $O(M(n) \log n)$，保存子积树 $O(n \log n)$ 空间。
