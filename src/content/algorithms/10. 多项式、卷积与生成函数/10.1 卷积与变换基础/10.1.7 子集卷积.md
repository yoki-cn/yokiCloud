### 子集卷积
---
依赖 [[10.1.4 FWT 与位运算卷积]]：
```cpp
namespace FWT {
    int fwt_size(int need);
    template<class T>
    void fwt_or(vector<T> &a, bool inverse = false);
}
```

```cpp
namespace SubsetConv {
    // c[S] = sum_{A subseteq S} a[A] * b[S \ A]
    template<class T = Z>
    vector<T> conv_subset(const vector<T> &a, const vector<T> &b) {
        if (a.empty() || b.empty()) return {};
        int need{ int(max(a.size(), b.size())) };
        int n{ FWT::fwt_size(need) };
        int k{ countr_zero(unsigned(n)) };
        // f[r][S] / g[r][S]：仅保留 popcount(S) = r 的系数，再做子集 Zeta
        vector<vector<T>> f(k + 1, vector<T>(n));
        bool square{ &a == &b };
        vector<vector<T>> g;
        if (!square) g.assign(k + 1, vector<T>(n));
        for (unsigned s = 0; s < a.size(); ++ s) f[popcount(s)][s] = a[s];
        if (!square) {
            for (unsigned s = 0; s < b.size(); ++ s) g[popcount(s)][s] = b[s];
        }
        for (auto &v : f) FWT::fwt_or(v);
        if (!square) for (auto &v : g) FWT::fwt_or(v);
        // 每个 mask 上按集合大小做普通卷积；从高 rank 向低 rank 可原地覆盖 f
        for (int s = 0; s < n; ++ s) {
            for (int r = k; r >= 0; -- r) {
                T x{};
                for (int i = 0; i <= r; ++ i) {
                    x += f[i][s] * (square ? f[r - i][s] : g[r - i][s]);
                }
                f[r][s] = x;
            }
        }
        for (auto &v : f) FWT::fwt_or(v, true);
        vector<T> res(n);
        for (unsigned s = 0; s < n; ++ s) res[s] = f[popcount(s)][s];
        return res;
    }
}
template<class T = Z>
vector<T> conv_subset(const vector<T> &a, const vector<T> &b) {
    return SubsetConv::conv_subset(a, b);
}
```
#### 接口说明
##### `conv_subset(a, b)`
计算子集卷积：
$$
c_S=\sum_{A\subseteq S}a_A b_{S\setminus A}
$$
也可以写成：
$$
c_S=\sum_{\substack{A\cup B=S\\A\cap B=\varnothing}}a_A b_B
$$
调用：
```cpp
auto c = conv_subset(a, b);
```
数组下标视为 bitmask
若输入最大长度为 `need`，内部补到：
$$
N=2^{\lceil\log_2 need\rceil}
$$
因此两个数组会被视为定义在同一个：
$$
k=\log_2N
$$
位集合空间上，缺少的系数视为 `0`
返回数组长度为 `N`
任一输入为空时返回 `{}`
#### 原理
普通 OR 卷积计算：
$$
c_S=\sum_{A\cup B=S}a_A b_B
$$
这里允许：
$$
A\cap B\ne\varnothing
$$
而子集卷积还要求：
$$
A\cap B=\varnothing
$$
因此不能直接做一次 OR FWT
##### 按集合大小分层
定义：
$$
a_r(S)=
\begin{cases}
a_S,&|S|=r,\\
0,&|S|\ne r
\end{cases}
$$
对每个 `r` 分别进行子集 Zeta 变换：
$$
\widehat a_r(S)=\sum_{\substack{T\subseteq S\\|T|=r}}a_T
$$
`b` 同理
然后在每个 `S` 上，对集合大小做普通卷积：
$$
\widehat c_r(S)=\sum_{i=0}^{r}\widehat a_i(S)\widehat b_{r-i}(S)
$$
最后对每个 `r` 做子集 Möbius 反演
反演后：
$$
c_r(S)=\sum_{\substack{A\cup B=S\\|A|+|B|=r}}a_A b_B
$$
最终只取：
$$
r=|S|
$$
因为：
$$
|A|+|B|=|A\cup B|+|A\cap B|
$$
当：
$$
|A|+|B|=|S|=|A\cup B|
$$
时必有：
$$
A\cap B=\varnothing
$$
于是恰好得到：
$$
\boxed{c_S=\sum_{A\subseteq S}a_A b_{S\setminus A}
}
$$
#### 注意事项
##### 子集卷积不是 OR 卷积
这是最重要的区别：
$$
\text{OR 卷积：}\quad
A\cup B=S
$$
允许重叠
而：
$$
\text{子集卷积：}\quad
A\cup B=S,\quad A\cap B=\varnothing
$$
例如若：
$$
A=B=\{0\}
$$
则：
$$
A\cup B=\{0\}
$$
所以这对集合会计入 OR 卷积；但因为：
$$
A\cap B\ne\varnothing
$$
不会计入子集卷积
##### 输入表示同一个集合空间
典型情况下直接使用：
```cpp
int n{ 1 << k };
vector<Z> a(n), b(n);
```
其中：
```cpp
a[mask]
```
表示集合 `mask` 对应的权值
如果两个输入长度不同，较短的一侧会自动视为补零到相同的二次幂状态空间
##### 不需要 NTT
虽然名字叫“卷积”，这一算法完全不依赖：
```text
FFT
NTT
CRT
```
它依赖的是：
```text
按 popcount 分层
    ↓
子集 Zeta
    ↓
rank 上普通卷积
    ↓
子集 Möbius
```
因此只需要前面 OR FWT 的 Zeta / Möbius 变换
##### 对系数类型的要求较弱
算法只使用：
```text
+
-
*
```
不需要除法
因此可以使用：
```cpp
vector<Z>
vector<i64>
vector<i128>
```
等类型，只要中间结果不会溢出
这和 XOR FWT 不同：子集卷积没有除以状态数的步骤，因此不存在模数必须为奇数的限制
##### 整数中间值仍可能溢出
使用：
```cpp
T = i64
```
时，即使最终答案能够放入 `i64`，Zeta 变换及分层乘法的中间结果仍可能更大
因此：
$$
\text{最终答案不溢出}
\not\Rightarrow
\text{中间过程不溢出}
$$
数值较大时应使用 `i128` 或模整数
##### 空间消耗较大
设：
$$
N=2^k
$$
普通调用需要保存两份：
$$
(k+1)\times N
$$
的分层数组，因此空间为：
$$
O(k2^k)
$$
例如 `T = Z` 且 $k=20$ 时，仅两份分层系数大约需要：
$$
2\times21\times2^{20}\times4
\approx168\text{ MiB}
$$
所以子集卷积的实际瓶颈经常不只是时间，还有内存
当前实现已经把结果直接原地写回 `f`，没有再额外维护第三份同规模数组
#### 常见用法
##### 两个集合函数的子集卷积
```cpp
int k;
cin >> k;
int n{ 1 << k };
vector<Z> a(n), b(n);
auto c = conv_subset(a, b);
```
则对于每个 `mask`：
$$
c_{\text{mask}} = \sum_{S\subseteq\text{mask}} a_S b_{\text{mask}\setminus S}
$$
bitmask 下：
$$
\text{mask}\setminus S=\text{mask}\oplus S,
$$
因为已经保证：
$$
S\subseteq\text{mask}
$$
所以也可以写为：
$$
c_{\text{mask}}
=
\sum_{S\subseteq\text{mask}}
a_Sb_{\text{mask}\oplus S}
$$
##### 集合划分计数
如果：
```cpp
a[S]
```
表示让集合 `S` 作为第一部分的方案数
```cpp
b[S]
```
表示让集合 `S` 作为第二部分的方案数
则：
```cpp
auto c = conv_subset(a, b);
```
中的：
```cpp
c[S]
```
就是把 `S` 划分为两个**互不相交**部分：
$$
S=A\sqcup B
$$
的加权方案和
这也是子集卷积最典型的使用模型
##### 平方
```cpp
auto c = conv_subset(a, a);
```
计算：
$$
c_S=\sum_{A\subseteq S}a_Aa_{S\setminus A}
$$
会自动复用同一份 ranked Zeta 结果
#### 复杂度
设状态空间为：
$$
N=2^k
$$
共有：
$$
k+1
$$
个 `popcount` 层
每一层进行一次 OR Zeta / Möbius 变换，单次需要：
$$
O(kN)
$$
因此所有分层变换总计：
$$
O(k^2N)
$$
每个 mask 上还要计算：
$$
\widehat c_r = \sum_{i=0}^{r} \widehat a_i\widehat b_{r-i}
$$
全部 rank 共需要：
$$
O(k^2)
$$
次运算
所有 `N` 个 mask 总计：
$$O(k^2N)$$
所以总时间复杂度为：
$$
\boxed{O(k^2 2^k)}
$$
空间复杂度为：
$$
\boxed{O(k2^k)}
$$

| 接口                  |        时间复杂度 |            额外空间 |
| ------------------- | -----------: | --------------: |
| `conv_subset(a, b)` | $O(k^2 2^k)$ |       $O(k2^k)$ |
| `conv_subset(a, a)` | $O(k^2 2^k)$ | $O(k2^k)$，常数约减半 |
作为对比，直接枚举：
```cpp
for (S)
    for (A subseteq S)
```
总状态数为：
$$\sum_S2^{|S|}=3^k$$
因此朴素子集卷积为：
$$O(3^k)$$
当 $k$ 较小时暴力已经足够；真正需要这份板子时，通常是为了把：
$$O(3^k)$$
降低到：
$$O(k^2 2^k)$$
