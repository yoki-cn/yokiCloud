#### 循环与负循环卷积
依赖 [[10.1.1 NTT 与普通卷积]]中的统一接口：
```cpp
template<class T>
vector<T> convolution(const vector<T> &a, const vector<T> &b);
```
基础版本与具体卷积后端无关
```cpp
// ===== 循环折回：cyclic_convolution() 依赖；不需要循环卷积时可删除 =====
// 返回 f(x) mod (x^n - 1)，支持 f 的长度任意
template<class T = Z>
vector<T> cyclic_reduce(const vector<T> &a, int n) {
    assert(n > 0);
    vector<T> res(n);
    for (int i = 0; i < int(a.size()); ++ i) res[i % n] += a[i];
    return res;
}
// ===== 负循环折回：negacyclic_convolution() 依赖；不需要负循环卷积时可删除 =====
// 返回 f(x) mod (x^n + 1)，因为 x^n = -1
template<class T = Z>
vector<T> negacyclic_reduce(const vector<T> &a, int n) {
    assert(n > 0);
    vector<T> res(n);
    for (int i = 0; i < int(a.size()); ++ i) {
        if ((i / n) & 1) res[i % n] -= a[i];
        else res[i % n] += a[i];
    }
    return res;
}
// ===== 循环卷积：模 x^n - 1；不需要时可整段删除 =====
template<class T = Z>
vector<T> cyclic_convolution(const vector<T> &a, const vector<T> &b, int n) {
    assert(n > 0);
    if (a.empty() || b.empty()) return vector<T>(n);
    return cyclic_reduce(convolution(a, b), n);
}
// ===== 负循环卷积：模 x^n + 1；不需要时可整段删除 =====
template<class T = Z>
vector<T> negacyclic_convolution(const vector<T> &a, const vector<T> &b, int n) {
    assert(n > 0);
    if (a.empty() || b.empty()) return vector<T>(n);
    return negacyclic_reduce(convolution(a, b), n);
}
```
##### `Z + NTT` 直接加速版
下面完全是**可选扩展**，依赖 10.1.1 中：
```cpp
namespace NTT {
    constexpr int MOD;
    constexpr int G;
    constexpr int MAX_N;
    void dft(vector<Z> &a);
    void idft(vector<Z> &a);
}
```
以及：
```cpp
power()
```

```cpp
// ===== NTT 直接循环卷积：若普通卷积 + 折回已经足够，以下代码可直接删除 =====
// n 必须为 2 的幂且是合法 NTT 长度；直接做长度 n 的 NTT
vector<Z> cyclic_convolution_ntt(vector<Z> a, vector<Z> b, int n) {
    assert(n > 0 && (n & (n - 1)) == 0 && n <= NTT::MAX_N);
    a = cyclic_reduce(a, n);
    b = cyclic_reduce(b, n);
    NTT::dft(a);
    NTT::dft(b);
    for (int i = 0; i < n; ++ i) a[i] *= b[i];
    NTT::idft(a);
    return a;
}
// ===== NTT 直接负循环卷积：以下代码可直接删除 =====
// 需要存在 2n 次单位根，因此要求 2n <= NTT::MAX_N
vector<Z> negacyclic_convolution_ntt(vector<Z> a, vector<Z> b, int n) {
    assert(n > 0 && (n & (n - 1)) == 0 && 2 * n <= NTT::MAX_N);
    a = negacyclic_reduce(a, n);
    b = negacyclic_reduce(b, n);
    // w^n = -1，先做 a_i -> a_i w^i，将负循环转成普通循环
    Z w{ power(Z(NTT::G), (NTT::MOD - 1) / (2 * n)) };
    Z pw{ 1 };
    for (int i = 0; i < n; ++ i) {
        a[i] *= pw;
        b[i] *= pw;
        pw *= w;
    }
    NTT::dft(a);
    NTT::dft(b);
    for (int i = 0; i < n; ++ i) a[i] *= b[i];
    NTT::idft(a);
    // 还原 w^i
    Z iw{ w.inv() };
    pw = 1;
    for (int i = 0; i < n; ++ i) {
        a[i] *= pw;
        pw *= iw;
    }
    return a;
}
```
##### 接口说明
###### `cyclic_reduce(a, n)`
计算：
$$A(x)\bmod(x^n-1)$$
因为：
$$x^n=1$$
所以：
$$x^i=x^{i\bmod n}$$
因此每项：
$$a_ix^i$$
直接累加到：
$$a_i x^{i\bmod n}$$
返回长度始终恰为：
$$n$$
例如：
```cpp
vector<i64> a{ 1, 2, 3, 4, 5 };
auto b = cyclic_reduce(a, 3);
```
因为：
$$x^3=1,\qquad x^4=x$$
所以：
$$1+2x+3x^2+4x^3+5x^4 \equiv 5+7x+3x^2$$
得到：
```text
{5, 7, 3}
```
###### `negacyclic_reduce(a, n)`
计算：
$$A(x)\bmod(x^n+1)$$
此时：
$$x^n=-1$$
所以：
$$x^{qn+r}=(-1)^q x^r$$
也就是代码中的：
```cpp
if ((i / n) & 1) res[i % n] -= a[i];
else res[i % n] += a[i];
```
注意不只是第一次折回变负
例如：
$$x^{2n}=1,\quad x^{3n}=-1$$
因此这一版可以正确处理**任意长度**的输入
###### `cyclic_convolution(a,b,n)`
计算：
$$A(x)B(x)\pmod{x^n-1}$$
返回长度：
$$n$$
如果 `a`、`b` 都是长度 $n$ 的序列，则对应经典循环卷积：
$$c_k=\sum_{\substack{i+j\equiv k\pmod n}} a_i b_j$$
也可以写成：
$$c_k=\sum_{i=0}^{n-1} a_i b_{(k-i)\bmod n}$$
###### `negacyclic_convolution(a,b,n)`

计算：
A(x)B(x)\pmod{x^n+1}$$

若 `a,b` 的次数均小于 $n$，普通乘积次数最多为 $2n-2$，所以每个高次项最多折回一次。

于是：

# [  
c_k

## \sum_{i+j=k}a_ib_j

\sum_{i+j=k+n}a_ib_j.  
]

区别只有一个非常关键的符号：

```text
循环卷积：
x^n = +1

负循环卷积：
x^n = -1
```

这正是旧板原先提醒的区别。

---

## 思想

### 循环卷积

普通卷积：

[  
C(x)=A(x)B(x).  
]

现在只关心：

[  
C(x)\pmod{x^n-1}.  
]

因为：

[  
x^n\equiv1,  
]

所以：

[  
x^{n+k}\equiv x^k.  
]

例如 $n=4$：

[  
c_0+c_1x+c_2x^2+c_3x^3  
+c_4x^4+c_5x^5+\cdots  
]

折回为：

[  
(c_0+c_4+c_8+\cdots)  
]

[  
+(c_1+c_5+c_9+\cdots)x+\cdots.  
]

因此：

```text
普通卷积
   ↓
下标 mod n 累加
   ↓
循环卷积
```

---

### 负循环卷积

只把模多项式换成：

[  
x^n+1.  
]

因此：

[  
x^n=-1.  
]

所以：

[  
x^{n+k}=-x^k,  
]

[  
x^{2n+k}=x^k,  
]

[  
x^{3n+k}=-x^k.  
]

符号周期也是 $2n$。

---

# 为什么基础版先普通卷积再折回？

因为这让它完全复用之前已经写好的：

```cpp
convolution()
```

于是：

```cpp
vector<Z>
```

自动使用 NTT；

```cpp
vector<i64>
```

自动使用朴素卷积；

以后如果有其他卷积后端，也不需要改这里。

这符合我们整个多项式体系现在的设计：

```text
卷积后端
   ↓
统一 convolution()
   ↓
循环 / 负循环卷积
```

这页本身不关心：

```text
NTT
FFT
朴素
```

到底是哪一个。

# 为什么还有 NTT 直接版？

假设：

[  
|a|=|b|=n  
]

且 $n$ 是二次幂。

基础版先做普通卷积，需要长度：

[  
2n-1.  
]

NTT 实际补到：

[  
2n.  
]

也就是说做的是长度：

[  
2n  
]

的变换。

但循环卷积本来就在：

[  
\mathbb F[x]/(x^n-1)  
]

中。

只要存在 $n$ 次单位根，直接做**长度 $n$ 的 NTT**即可。

因此：

```cpp
cyclic_convolution_ntt()
```

只需要长度：

[  
n  
]

的变换。

常数大约能省下一截。

---

# 负循环为什么要乘 `w^i`？

负循环要求：

[  
x^n=-1.  
]

找一个：

[  
w^n=-1.  
]

令：

[  
a'_i=a_iw^i,  
\qquad  
b'_i=b_iw^i.  
]

在普通长度 $n$ 循环卷积中，若：

[  
i+j=k+n,  
]

那么：

# [  
w^{i+j}

# w^{k+n}

-w^k.  
]

于是绕一圈的贡献天然带上负号。

因此：

```text
乘 w^i
   ↓
普通循环 NTT
   ↓
乘 w^{-i}
```

就得到了负循环卷积。

为了存在这样的 $w$，需要模数中存在：

[  
2n  
]

次单位根。

在 `998244353` 下最大二次幂单位根阶为：

[  
2^{23}.  
]

所以直接负循环版本要求：

[  
2n\le2^{23},  
]

即：

[  
\boxed{n\le2^{22}}.  
]

## 注意事项

### `n` 是周期，不是输入长度

接口：

```cpp
cyclic_convolution(a, b, n);
```

中的 `n` 表示：

[  
x^n=1  
]

的周期。

并不要求：

```cpp
a.size() == n
b.size() == n
```

例如：

```cpp
cyclic_convolution(a, b, 100);
```

允许：

```text
a.size() = 30
b.size() = 70
```

不足部分相当于补零。

甚至允许长度大于 `n`，因为 `cyclic_reduce()` 可以继续折回。

---

### 空输入返回长度 `n` 的零数组

和普通卷积：

```cpp
convolution({}, b) == {}
```

略有不同。

循环卷积属于固定的：

[  
n  
]

维状态空间，因此：

```cpp
cyclic_convolution({}, b, n)
```

返回：

```cpp
vector<T>(n)
```

而不是空数组。

这样：

```cpp
ans.size() == n
```

始终成立。

---

### 只有标准长度输入时才能简单“一次折回”

如果已经知道：

[  
\deg A<n,\qquad  
\deg B<n,  
]

则：

[  
\deg AB\le2n-2.  
]

此时循环卷积确实只需要：

```cpp
for (int i = n; i < c.size(); ++ i) c[i - n] += c[i];
```

负循环只需：

```cpp
c[i - n] -= c[i];
```

你的旧板中描述的就是这种最常见情况。

但如果输入本身可能已经超过 $n$，例如存在：

[  
x^{2n},x^{3n},  
]

就不能只减一次 `n`。

所以正式板子使用：

```cpp
i % n
(i / n) & 1
```

保证通用正确。

---

### 不要和 FWT 的 XOR 卷积混淆

循环卷积的下标关系是：

[  
i+j\equiv k\pmod n.  
]

XOR 卷积则是：

[  
i\oplus j=k.  
]

两者都带“循环/群卷积”的味道，但不是同一个操作。

例如：

```text
循环：5 + 3 mod 8 = 0
XOR ：5 xor 3       = 6
```

所以不能拿 `fwt_xor()` 替代循环卷积。

---

### 负循环也不是“结果整体取负”

错误理解：

```cpp
-negacyclic == cyclic
```

当然不成立 😼

只有**发生一次跨越 $n$ 的高次项**才改变符号。

例如：

# [  
x^{n-1}\cdot x

x^n.  
]

循环卷积：

[  
x^n\equiv1.  
]

负循环卷积：

[  
x^n\equiv-1.  
]

而没有跨界的项符号完全不变。

## 裁剪指南

### 只需要普通循环卷积

只保留：

```cpp
cyclic_reduce()
cyclic_convolution()
```

一共十几行。

---

### 只需要负循环卷积

只保留：

```cpp
negacyclic_reduce()
negacyclic_convolution()
```

循环版本整个删除。

---

### 已知输入长度一定不超过 `n`

可以进一步把循环版本压成：

```cpp
template<class T = Z>
vector<T> cyclic_convolution(const vector<T> &a, const vector<T> &b, int n) {
    auto c = convolution(a, b);
    c.resize(2 * n);
    for (int i = n; i < 2 * n; ++ i) c[i - n] += c[i];
    c.resize(n);
    return c;
}
```

负循环改成：

```cpp
c[i - n] -= c[i];
```

即可。

不过正式板子不采用这个版本，因为通用版只多一点点代码，却少一个隐藏前提。

---

### 只需要高性能 `Z` 循环卷积

如果题目保证：

```text
n 为 2 的幂
```

直接保留：

```cpp
cyclic_reduce()
cyclic_convolution_ntt()
```

基础 `cyclic_convolution()` 可以删除。

---

### 只需要高性能负循环卷积

保留：

```text
negacyclic_reduce
negacyclic_convolution_ntt
```

并确认：

[  
2n\le2^{23}.  
]

## 常见用法

### 长度 4 的循环卷积

```cpp
vector<i64> a{1, 2, 3, 4};
vector<i64> b{5, 6, 7, 8};

auto c = cyclic_convolution(a, b, 4);
```

普通卷积为：

```text
5 16 34 60 61 52 32
```

模：

[  
x^4-1  
]

折回：

```text
5 + 61
16 + 52
34 + 32
60
```

所以：

```text
66 68 66 60
```

---

### 同一组数据做负循环卷积

```cpp
auto c = negacyclic_convolution(a, b, 4);
```

因为：

[  
x^4=-1,  
]

所以：

```text
5 - 61
16 - 52
34 - 32
60
```

得到：

```text
-56 -36 2 60
```

如果 `T = Z`，自然表现为对应的模意义结果。

---

### 模 `998244353` 的直接循环 NTT

```cpp
vector<Z> a(n), b(n);

auto c = cyclic_convolution_ntt(a, b, n);
```

要求：

```text
n 是 2 的幂
n <= 2^23
```

---

### 直接负循环 NTT

```cpp
auto c = negacyclic_convolution_ntt(a, b, n);
```

要求更强：

```text
n 是 2 的幂
2n <= 2^23
```

即：

[  
n\le2^{22}.  
]

## 复杂度

设普通卷积复杂度为：

[  
M(m).  
]

### 通用折回版

计算：

```cpp
convolution(a, b)
```

后再线性折回，因此：

[  
O(M(|a|+|b|)+|a|+|b|).  
]

通常简写：

[  
\boxed{O(M(|a|+|b|))}.  
]

如果：

[  
|a|,|b|\le n  
]

且使用 NTT：

[  
\boxed{O(n\log n)}.  
]

但内部普通卷积通常使用长度约：

[  
2n  
]

的变换。

### NTT 直接版

长度恰为 $n$：

[  
\boxed{O(n\log n)}.  
]

|接口|时间复杂度|返回长度|
|---|--:|--:|
|`cyclic_reduce(a,n)`|$O(|a|
|`negacyclic_reduce(a,n)`|$O(|a|
|`cyclic_convolution()`|$O(M(|a|
|`negacyclic_convolution()`|$O(M(|a|
|`cyclic_convolution_ntt()`|$O(n\log n)$|$n$|
|`negacyclic_convolution_ntt()`|$O(n\log n)$|$n$|

额外空间均为：

[  
O(n)  
]

到普通卷积后端所需的线性空间。

这样 **1.5 循环与负循环卷积** 就完整了。它的核心其实很漂亮：

[  
\boxed{\text{循环卷积}=AB\bmod(x^n-1)}  
]

[  
\boxed{\text{负循环卷积}=AB\bmod(x^n+1)}  
]

基础版只有几个很短的函数，适合绝大多数赛场情况；只有真遇到大规模固定周期卷积时，才把后面的直接 NTT 优化一起抄上。这样正好符合我们现在这套“**最短核心 + 可独立删除的高级加速层**”的板子设计喵~ 🐱
