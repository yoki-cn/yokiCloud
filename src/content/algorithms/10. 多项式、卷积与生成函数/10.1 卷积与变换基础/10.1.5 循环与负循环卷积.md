### 循环与负循环卷积
---
> 依赖：全局 `conv()`；直接版额外依赖 `10.1.1 NTT` 的 `NTT::dft/idft`

```cpp
namespace CyclicConv {
    template<class T>
    vector<T> reduce(const vector<T> &a, int n, bool neg = false) {
        assert(n > 0);
        vector<T> f(n);
        for (int i = 0; i < int(a.size()); ++ i) {
            if (neg && (i / n & 1)) f[i % n] -= a[i];
            else f[i % n] += a[i];
        }
        return f;
    }
    template<class T>
    vector<T> conv(const vector<T> &a, const vector<T> &b, int n, bool neg = false) {
        assert(n > 0);
        if (a.empty() || b.empty()) return vector<T>(n);
        auto f = reduce(a, n, neg);
        vector<T> g;
        if (&a != &b) g = reduce(b, n, neg);
        return reduce(::conv(f, &a == &b ? f : g), n, neg);
    }
    // 仅 Z；n 为 2 的幂。直接 NTT 的长度为 n 而非 2n。
    vector<Z> conv_ntt(const vector<Z> &a, const vector<Z> &b, int n, bool neg = false) {
        assert(n > 0 && has_single_bit(unsigned(n)));
        assert((neg ? 2LL * n : n) <= NTT::MAX_N);
        vector<Z> f = reduce(a, n, neg);
        bool square = &a == &b;
        vector<Z> g;
        if (!square) g = reduce(b, n, neg);
        Z w = 1, iw = 1;
        if (neg) {
            w = Z(NTT::G).pow((NTT::MOD - 1) / (2 * n));
            iw = w.inv();
        }
        Z t = 1;
        for (int i = 0; i < n; ++ i) {
            f[i] *= t;
            if (!square) g[i] *= t;
            t *= w;
        }
        NTT::dft(f);
        if (square) {
            for (Z &x : f) x *= x;
        } else {
            NTT::dft(g);
            for (int i = 0; i < n; ++ i) f[i] *= g[i];
        }
        NTT::idft(f);
        t = 1;
        for (Z &x : f) x *= t, t *= iw;
        return f;
    }
}
template<class T>
vector<T> conv_cyclic(const vector<T> &a, const vector<T> &b, int n) {
    return CyclicConv::conv(a, b, n);
}
template<class T>
vector<T> conv_negacyclic(const vector<T> &a, const vector<T> &b, int n) {
    return CyclicConv::conv(a, b, n, true);
}
```

#### 接口说明

- `conv_cyclic(a,b,n)`：模 $x^n-1$ 的乘法，返回恰好 `n` 项。
- `conv_negacyclic(a,b,n)`：模 $x^n+1$ 的乘法，返回恰好 `n` 项。
- `CyclicConv::conv_ntt(a,b,n,neg)`：`Z` 的直接 NTT 版本，`neg=true` 代表负循环。
- `CyclicConv::reduce(a,n,neg)`：单个多项式按 $x^n\mp 1$ 折回。

#### 注意事项

- 通用版先折回两边，再调用全局 `conv`，可以使用非 2 的幂周期 `n`。
- 直接版要求 `n` 为 2 的幂，循环版 `n <= 2^23`，负循环版 `2n <= 2^23`；利用 `2n` 次单位根扭转。
- 输入可以长于 `n`；空输入按零多项式处理，结果仍返回长度 `n` 的全零数组。
- `conv_ntt` 在 `n=1` 时也成立；仅需要通用版时可以整个删除 `conv_ntt()`。

#### 常见用法

```cpp
vector<Z> a{1, 2, 3}, b{4, 5};
auto c = conv_cyclic(a, b, 3);     // {19,13,22}
auto d = conv_negacyclic(a, b, 3); // {-11,13,22}（模意义）
auto e = CyclicConv::conv_ntt(a, b, 4);       // 直接循环
// auto f = CyclicConv::conv_ntt(a, b, 4, true); // 直接负循环
```

#### 复杂度

- 通用：$O(|a|+|b|+M(n))$（折回+一次长度至多 `2n-1` 的卷积）。
- 直接：$O(n \log n)$ 时间、$O(n)$ 空间；$M(n)$ 表示卷积复杂度。
