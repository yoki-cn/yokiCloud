#### NTT 与普通卷积
```cpp
using Z = MInt<998244353>;
template <typename T = i64> T power(T base, i64 exp) {
    T res{ 1 };
    for (; exp; exp >>= 1, base = base * base)
        if (exp & 1) res = res * base;
    return res;
}
// ===== 普通卷积：通用乘法后端；非 Z 系数直接使用 =====
// 若确定只需要 Z + NTT，可以删除本函数
template<class T>
vector<T> convolution(const vector<T> &a, const vector<T> &b) {
    if (a.empty() || b.empty()) return {};
    vector<T> c(a.size() + b.size() - 1);
    for (int i = 0; i < a.size(); ++ i) {
        for (int j = 0; j < b.size(); ++ j) {
            c[i + j] += a[i] * b[j];
        }
    }
    return c;
}
// ===== NTT：若不需要模 998244353 的快速卷积，以下 namespace 与后面的 Z 重载可整段删除 =====
namespace NTT {
    static_assert(Z::mod() == 998244353);
    constexpr int MOD{ 998244353 }, G{ 3 }, MAX_LOG{ 23 }, MAX_N{ 1 << MAX_LOG };
    vector<int> rev;
    vector<Z> roots{0, 1};
    // 原地正变换；长度必须为不超过 2^23 的非零 2 的幂
    void dft(vector<Z> &a) {
        int n = a.size();
        assert(n && (n & (n - 1)) == 0 && n <= MAX_N);
        if (n == 1) return;
        // 当前长度的位逆序置换
        if (rev.size() != n) {
            int k{ __builtin_ctz(n) - 1 };
            rev.resize(n);
            for (int i = 0; i < n; ++ i) rev[i] = (rev[i >> 1] >> 1) | ((i & 1) << k);
        }
        for (int i = 0; i < n; ++ i) if (i < rev[i]) swap(a[i], a[rev[i]]);
        // 单位根按需扩展；roots[k + j] 对应长度 2k 蝶形中的第 j 个单位根
        if (roots.size() < n) {
            int k{ __builtin_ctz(int(roots.size())) };
            roots.resize(n);
            while ((1 << k) < n) {
                Z e{ power(Z(G), (MOD - 1) >> (k + 1)) };
                for (int i = 1 << (k - 1); i < (1 << k); ++ i) {
                    roots[i << 1] = roots[i];
                    roots[i << 1 | 1] = roots[i] * e;
                }
                ++ k;
            }
        }
        // 蝶形合并
        for (int k = 1; k < n; k <<= 1) {
            for (int i = 0; i < n; i += 2 * k) {
                for (int j = 0; j < k; ++ j) {
                    Z u(a[i + j]), v(a[i + j + k] * roots[k + j]);
                    a[i + j] = u + v;
                    a[i + j + k] = u - v;
                }
            }
        }
    }
    // 原地逆变换；利用 DFT(ω^-1) 与下标反转的关系复用 dft()
    void idft(vector<Z> &a) {
        assert(!a.empty());
        reverse(a.begin() + 1, a.end());
        dft(a);
        Z inv_n{ Z(int(a.size())).inv() };
        for (Z &x : a) x *= inv_n;
    }
    // 模 998244353 卷积；小规模自动改用朴素卷积
    vector<Z> convolution(const vector<Z> &a, const vector<Z> &b) {
        if (a.empty() || b.empty()) return {};
        // 小规模避免 NTT 的常数；显式指定模板以调用外层普通卷积
        if (1ULL * a.size() * b.size() <= 4096) return ::convolution<Z>(a, b);
        int need = a.size() + b.size() - 1, n{ 1 };
        while (n < need) n <<= 1;
        assert(n <= MAX_N);
        vector<Z> f(a.begin(), a.end()), g(b.begin(), b.end());
        f.resize(n);
        g.resize(n);
        dft(f);
        dft(g);
        for (int i = 0; i < n; ++ i) f[i] *= g[i];
        idft(f);
        f.resize(need);
        return f;
    }
}
// Z 精确匹配本重载；其他 T 使用最前面的普通 convolution<T>()
vector<Z> convolution(const vector<Z> &a, const vector<Z> &b) {
    return NTT::convolution(a, b);
}
```
##### 接口说明
###### 普通卷积
```cpp
template<class T>
vector<T> convolution(const vector<T> &a, const vector<T> &b);
```
计算：
$$c_k=\sum_{i+j=k}a_i b_j$$
任一输入为空时：
```cpp
convolution(a, b) == vector<T>{};
```
否则返回长度严格为：
$$|a|+|b|-1$$
例如：
```cpp
vector<i64> a{ 1, 2, 3 };
vector<i64> b{ 4, 5 };
auto c = convolution(a, b);
// { 4, 13, 22, 15 }
```
因此之后：
```cpp
Poly<i64>
Poly<ld>
```
都可以直接依赖它，不需要 `Z` 或 NTT
###### `NTT::dft(a)`
原地进行 NTT 正变换
要求：
```cpp
a.size() > 0
a.size() 是 2 的幂
a.size() <= 2^23
```
不会自动扩容，因为：
> `dft()` 是底层变换，数组长度本身具有数学意义，偷偷改变长度很容易掩盖调用错误

需要补零的工作统一交给 `NTT::convolution()` 处理
###### `NTT::idft(a)`
原地进行逆变换
满足：
```cpp
auto b = a;
NTT::dft(b);
NTT::idft(b);
```
之后：
```cpp
b == a;
```
逆变换内部自动乘：
$$n^{-1}$$
```cpp
reverse(a.begin() + 1, a.end());
dft(a);
```
从而不需要维护另一套逆单位根
###### `NTT::convolution(a,b)`
专门计算 `vector<Z>` 的卷积
如果
$$|a||b|\le4096$$
直接朴素计算
否则取：
$$N=2^{\lceil\log_2(|a|+|b|-1)\rceil}$$
并执行 NTT
要求：
$$N\le2^{23}$$
###### 全局 `convolution()`
这是后续 `Poly<T>` 真正应该依赖的接口
```cpp
vector<Z> a, b;
auto c = convolution(a, b);
```
会自动选中：
```cpp
vector<Z> convolution(...)
```
从而走 NTT
而：
```cpp
vector<i64> a, b;
auto c = convolution(a, b);
```
会选中：
```cpp
template<class T>
vector<T> convolution(...)
```
从而使用普通卷积
因此以后 `Poly` 完全不需要写：
```cpp
if constexpr (is_same_v<T, Z>) ...
```
只需要：
```cpp
friend Poly operator*(const Poly &f, const Poly &g) {
    return Poly(convolution(f.a, g.a));
}
```
就够了
##### 思想
###### 普通卷积
两个多项式：
$$A(x)=\sum_{i=0}^{n-1}a_ix^i, \quad B(x)=\sum_{j=0}^{m-1}b_jx^j$$
相乘：
$$C(x)=A(x)B(x)$$
第 $k$ 项：
$$c_k=\sum_{i+j=k}a_i b_j$$
直接枚举 $(i,j)$：
$$O(nm)$$
###### NTT
NTT 是有限域上的 DFT
在模 $998244353$ 意义下，
$$998244353-1=119\cdot2^{23}$$
因此存在最大阶为 $2^{23}$ 的二次幂单位根
`3` 是模 `998244353` 的原根，所以长度 $2^k$ 变换所需单位根可由：
$$3^{(998244353-1)/2^k}$$
得到
###### 为什么卷积可以变快
卷积定理：
$$\operatorname{DFT}(A*B)=\operatorname{DFT}(A)\operatorname{DFT}(B)$$
因此：
```text
系数表示
   ↓ DFT
点值表示
   ↓ 逐点相乘
乘积的点值
   ↓ IDFT
乘积系数
```
两次正变换 + 一次逆变换即可完成卷积
##### 注意事项
###### 最大变换长度是 `2^23`
这是这一版最重要的边界：
```cpp
constexpr int MAX_N{ 1 << 23 };
```
不是说：
```text
答案长度 <= 2^23
```
就一定够
准确条件是：
$$2^{\lceil\log_2(n+m-1)\rceil}\le2^{23}$$
等价于：
$$n+m-1\le2^{23}$$
因为最终会向上取为二次幂
###### `dft()` 不接受空数组
不要：
```cpp
vector<Z> a;
NTT::dft(a);
```
`convolution()` 已经单独处理：
```cpp
a.empty() || b.empty()
```
所以普通使用不需要担心
###### 不要直接拿这个 NTT 做其他模数
这一版明确固定：
```cpp
Z::mod() == 998244353
G == 3
```
如果题目要求：
```cpp
mod = 1e9+7
```
不能：
```cpp
auto c = convolution(a, b);
// 再把结果 % 1e9+7
```
因为你得到的是：
$$A*B\pmod{998244353}$$
并不是原始整数卷积
这种问题归 **[[10.1.3 任意模卷积]]** 处理
###### 普通 `convolution<i64>` 可能溢出
例如：
```cpp
vector<i64> a, b;
auto c = convolution(a, b);
```
虽然算法不取模，但内部仍然是：
```cpp
a[i] * b[j]
```
所以必须自己确认：$\sum a_i b_j$ 可以放入 `i64`
需要更大范围时可以：
```cpp
vector<i128>
```
前提是你确实需要朴素卷积
###### `roots` 和 `rev` 多测无需清空
它们只是缓存
`rev`：
- 长度改变时重新计算
- 相同长度直接复用
`roots`：
- 只在需要更大 NTT 时扩展
- 不会因为多测中的数组内容产生污染
因此：
```cpp
while (T --) solve();
```
不需要：
```cpp
NTT::roots.clear();
NTT::rev.clear();
```
反而没必要
##### 裁剪指南
###### 只需要普通小规模卷积
只抄：
```cpp
template<class T>
vector<T> convolution(...);
```
##### 只需要 `998244353` 快速卷积
保留：
```text
普通 convolution<T>
NTT namespace
Z convolution 重载
```
###### 只需要手动 NTT
可以只抄：
```cpp
NTT::MOD
NTT::G
NTT::MAX_LOG
NTT::MAX_N
NTT::rev
NTT::roots
NTT::dft
NTT::idft
```
把两个 `convolution()` 全删掉
##### 常见用法
###### 模 `998244353` 卷积
```cpp
vector<Z> a{ 1, 2, 3 };
vector<Z> b{ 4, 5 };
auto c = convolution(a, b);
```
得到：
```text
4 13 22 15
```
即：
$$(1+2x+3x^2)(4+5x)=4+13x+22x^2+15x^3$$
###### 普通整数卷积
```cpp
vector<i64> a{ 1, 2, 3 };
vector<i64> b{ 4, 5 };
auto c = convolution(a, b);
```
接口完全一样
区别只是：
```cpp
vector<Z>   → NTT
vector<i64> → 朴素乘法
```
###### 和 `Poly<T>` 接入
后面 `Poly` 的乘法只写：
```cpp
friend Poly operator*(const Poly &f, const Poly &g) {
    return Poly(convolution(f.a, g.a));
}
```
于是：
```cpp
Poly<> f, g;          // Z，NTT
Poly<i64> f, g;       // i64，朴素
```
无需让 `Poly` 知道任何 NTT 细节
###### 手动 DFT / IDFT
```cpp
vector<Z> a(n);
NTT::dft(a);
// 在频域中操作
NTT::idft(a);
```
要求 `n` 已经是合法的二次幂
普通卷积不要自己手动补零，直接调用：
```cpp
convolution(a, b);
```
更安全
##### 复杂度
设：
$$n=|a|,\quad m=|b|$$
并令：
$$N=2^{\lceil\log_2(n+m-1)\rceil}$$

| 操作                      |        时间复杂度 |        额外空间 |
| ----------------------- | -----------: | ----------: |
| 普通 `convolution<T>`     |      $O(nm)$ |    $O(n+m)$ |
| `NTT::dft(a)`           | $O(N\log N)$ | $O(1)$ 临时空间 |
| `NTT::idft(a)`          | $O(N\log N)$ | $O(1)$ 临时空间 |
| `NTT::convolution(a,b)` | $O(N\log N)$ |      $O(N)$ |
| 首次扩展 `roots` 到 $N$      |       $O(N)$ |      $O(N)$ |
| 重建 `rev`                |       $O(N)$ |      $O(N)$ |
注意 `dft/idft` 虽然本身只在原数组上变换，但全局缓存：
```cpp
roots
rev
```
长期占用 $O(N)$ 空间
