#### FWT 与位运算卷积
```cpp
// ===== OR FWT：OR 卷积依赖；完全不需要 OR 卷积时可整段删除 =====
// 正变换为子集和，逆变换为子集 Möbius 反演
template<class T = Z>
void fwt_or(vector<T> &a, bool inverse) {
    int n = a.size();
    assert(n && (n & (n - 1)) == 0);
    for (int len = 1; len < n; len <<= 1) {
        for (int i = 0; i < n; i += len << 1) {
            for (int j = 0; j < len; ++ j) {
                if (!inverse) a[i + j + len] += a[i + j];
                else a[i + j + len] -= a[i + j];
            }
        }
    }
}
// ===== AND FWT：AND 卷积依赖；完全不需要 AND 卷积时可整段删除 =====
// 正变换为超集和，逆变换为超集 Möbius 反演
template<class T = Z>
void fwt_and(vector<T> &a, bool inverse) {
    int n = a.size();
    assert(n && (n & (n - 1)) == 0);
    for (int len = 1; len < n; len <<= 1) {
        for (int i = 0; i < n; i += len << 1) {
            for (int j = 0; j < len; ++ j) {
                if (!inverse) a[i + j] += a[i + j + len];
                else a[i + j] -= a[i + j + len];
            }
        }
    }
}
// ===== XOR FWT：XOR 卷积依赖；完全不需要 XOR 卷积时可整段删除 =====
// Hadamard 变换的逆变换等于再变换一次后整体除以 n
template<class T = Z>
void fwt_xor(vector<T> &a, bool inverse) {
    int n = a.size();
    assert(n && (n & (n - 1)) == 0);
    for (int len = 1; len < n; len <<= 1) {
        for (int i = 0; i < n; i += len << 1) {
            for (int j = 0; j < len; ++ j) {
                T x{ a[i + j] }, y{ a[i + j + len] };
                a[i + j] = x + y;
                a[i + j + len] = x - y;
            }
        }
    }
    if (inverse) for (T &x : a) x /= T(n);
}
// ===== 位运算 卷积：只需要变换本身时可删除 =====
// 修改为 And、Xor 时，只需替换 fwt_or 为 fwt_and、fwt_xor
template<class T = Z>
vector<T> convolution(vector<T> a, vector<T> b) {
    if (a.empty() || b.empty()) return {};
    int n{ 1 }, need = max(a.size(), b.size());
    while (n < need) n <<= 1;
    a.resize(n);
    b.resize(n);
    fwt_or(a, false);
    fwt_or(b, false);
    for (int i = 0; i < n; ++ i) a[i] *= b[i];
    fwt_or(a, true);
    return a;
}
```
##### 接口说明
###### `fwt_or(a, inverse)`
计算 OR FWT
正变换：
```cpp
fwt_or(a, false);
```
对应：
$$\widehat a_S=\sum_{T\subseteq S}a_T$$
因此它本质上就是**子集 Zeta 变换**
逆变换：
```cpp
fwt_or(a, true);
```
执行对应的子集 Möbius 反演：
$$a_S=\sum_{T\subseteq S} (-1)^{|S\setminus T|} \widehat a_T$$
要求：
- `a.size() > 0`
- `a.size()` 为 $2$ 的幂
只要求 `T` 支持：
```cpp
+
-
```
因此不仅可以：
```cpp
vector<Z>
```
也可以：
```cpp
vector<i64>
vector<i128>
```
###### `fwt_and(a, inverse)`
正变换：
$$\widehat a_S\sum_{T\supseteq S}a_T$$
即**超集 Zeta 变换**
逆变换是对应的超集 Möbius 反演
同样只要求：
```text
+
-
```
不涉及任何除法
###### `fwt_xor(a, inverse)`
正变换使用蝶形：
$$(x,y)\longrightarrow (x+y,x-y)$$
完整形式为 Walsh–Hadamard 变换：
$$\widehat a_S=\sum_T (-1)^{\operatorname{popcount}(S\&T)}a_T$$
Hadamard 矩阵满足：
$$H_n^2=nI$$
所以逆变换为：
$$H_n^{-1}=\frac1nH_n$$
因此直接：
1. 再进行一次相同蝶形
2. 最后统一除以 `n`
###### `or_convolution(a,b)`
计算：
$$c_k=\sum_{i\operatorname{OR}j=k} a_i b_j$$
即：
```cpp
auto c = or_convolution(a, b);
```
###### `and_convolution(a,b)`
计算：
$$c_k=\sum_{i\operatorname{AND}j=k} a_i b_j$$
###### `xor_convolution(a,b)`
计算：
$$c_k=\sum_{i\oplus j=k} a_i b_j$$
三种接口均：
- 任一输入为空时返回 `{}`
- 自动补零到不小于两者长度的最小二次幂
- 返回补齐后的完整状态空间
##### 原理
把数组下标看成 $k$ 位二进制集合：
$$0,1,\ldots,2^k-1$$
例如：
```text
5 = 101₂ = {0, 2}
```
于是位运算天然对应集合运算
###### OR
$$i\mid j=k$$
表示：
$$I\cup J=K$$
OR 卷积：
$$c_K=\sum_{I\cup J=K}a_Ib_J$$
经过子集 Zeta 变换：
$$\widehat a_K=\sum_{I\subseteq K}a_I$$
有：
$$\widehat c_K=\widehat a_K\widehat b_K$$
所以：
```text
OR Zeta
   ↓
逐点乘
   ↓
OR Möbius
```
即可完成卷积
###### AND
$$i\&j=k$$
对应集合交：
$I\cap J=K$$
使用超集 Zeta：
$$\widehat a_K=\sum_{I\supseteq K}a_I$$
同样满足：
$$\widehat c_K=\widehat a_K\widehat b_K$$
###### XOR
XOR 对应集合的对称差：
$$I\triangle J$$
Walsh–Hadamard 变换将 XOR 卷积转为逐点乘法：
$$\widehat{a*_{\oplus}b}=\widehat a\cdot\widehat b$$
因此三种卷积的程序结构完全相同：
```cpp
transform(a, false);
transform(b, false);
for (...) a[i] *= b[i];
transform(a, true);
```
###### 一个很重要的长度区别
普通多项式卷积需要长度：
$$n+m-1$$
但位运算卷积不是这样
假设：
```cpp
a.size() = 3;
b.size() = 3;
```
合法输入下标为：
```text
0, 1, 2
```
然而：
$$1\mid2=3$$
$$1\oplus2=3$$
所以答案必须能够保存下标 `3`
因此需要补到：
$$N=2^{\lceil\log_2\max(n,m)\rceil}$$
这里：
$$N=4$$
所以：
```cpp
or_convolution(a, b).size() == 4;
xor_convolution(a, b).size() == 4;
```
而不是：
```text
3
```
也不是：
```text
5 = 3 + 3 - 1
```
##### 注意事项
###### OR / AND 不需要逆元
这是三种 FWT 中一个很有用的区别
OR / AND 正逆变换都只有：
```text
+
-
```
所以理论上可以在任意交换环中工作
例如：
```cpp
vector<i64>
```
可以直接：
```cpp
auto c = or_convolution(a, b);
```
只要中间结果不溢出
###### XOR 逆变换需要除以 `n`
本实现：
```cpp
if (inverse) for (T &x : a) x /= T(n);
```
因此必须满足：
> `T(n)` 在当前系数体系中可除。

对于默认：
```cpp
T = Z
```
且模数为 `998244353` 时，只要实际数组长度小于模数，二次幂 `n` 一定可逆
对于：
```cpp
T = i64
```
也可以用于**精确整数 XOR 卷积**，因为正确变换流程最终理论上一定整除 `n`
但这里用的是整数 `/`：
```cpp
x /= n;
```
所以如果你单独对一个任意整数数组调用：
```cpp
fwt_xor(a, true);
```
而它并不是合法的频域结果，整数除法可能直接截断
###### 合数模下 XOR 要额外检查
如果使用动态模数类型，模数为：
$$M$$
则 XOR FWT 要求：
$$\gcd(n,M)=1$$
因为必须存在：
$$n^{-1}\pmod M$$
特别是偶数模数下，由于：
$$n=2^k$$
通常根本没有逆元
此时：
```text
OR FWT  ✅
AND FWT ✅
XOR FWT ❌ 通常不可直接使用
```
这一点不能因为三种代码长得相似就忽略
###### 整数 FWT 中间值可能远大于最终答案
例如使用：
```cpp
vector<i64>
```
虽然最终卷积系数可能能放进 `i64`，但是变换中的：
```text
子集和
Hadamard 和差
频域点乘
```
都可能把数值放大很多
因此：

> [!warning]  
> `i64` 最终答案不溢出，并不能保证 FWT 中间值不溢出

如果要做精确整数位运算卷积：
- 小数据可以直接 $O(N^2)$
- 中间值较大时改用 `i128`
- 模意义问题优先使用 `Z`
###### OR 和 AND 的方向不要写反
最容易现场抄错的其实就是这两行。
OR：
```cpp
a[high] += a[low];
```
即：
```text
0 → 1
```
因为 `high` 对应当前位为 `1`，收集其子集。
AND：
```cpp
a[low] += a[high];
```
即：
```text
1 → 0
```
因为 `low` 收集其超集
可以记：
```text
OR  ：向有这个 bit 的状态累加
AND ：向没有这个 bit 的状态累加
```
逆变换把 `+=` 改为 `-=` 即可。
###### FWT 不需要位逆序
和 FFT / NTT 不同：
```text
FFT / NTT
→ 通常需要 bit-reversal permutation

FWT
→ 不需要
```
这里只需要逐位做蝶形
因此代码非常短
###### 不要把 OR 卷积当成子集卷积
OR 卷积：
$$c_S=\sum_{A\cup B=S}a_Ab_B$$
允许：
$$A\cap B\ne\varnothing$$
而**子集卷积**通常定义为：
$$c_S=\sum_{A\subseteq S} a_A b_{S\setminus A}$$
等价于：
$$A\cup B=S,\qquad A\cap B=\varnothing$$
二者完全不同
在 **高级卷积 → 子集卷积** 单独整理
###### K 进制 FWT 也不属于本页核心
这里的下标是：
$$k\text{ 位二进制 mask}$$
如果每一位有：
$$0,1,\ldots,K-1$$
多种状态，则需要对应有限群上的变换
不能简单把：
```cpp
len <<= 1
```
改成：
```cpp
len *= K
```
就叫 K 进制 FWT
因此继续放在高级模块
##### 裁剪指南
###### 只需要 OR 卷积
只抄：
```cpp
fwt_or()
or_convolution()
```
AND / XOR 全删
###### 只需要 AND 卷积
只抄：
```cpp
fwt_and()
and_convolution()
```
###### 只需要 XOR 卷积
只抄：
```cpp
fwt_xor()
xor_convolution()
```
这是非常常见的最小版本，几十行都不到
###### 题目直接要求频域操作
例如题目不是简单两数组卷积，而是：
1. 做 XOR FWT
2. 在频域中执行特殊公式
3. 再逆变换
那么只抄：
```cpp
fwt_xor()
```
甚至三个卷积包装函数都不用
##### 常见用法
###### OR 卷积
```cpp
vector<Z> a(1 << k), b(1 << k);
// a[mask], b[mask]
auto c = or_convolution(a, b);
```
满足：
$$c_s=\sum_{i\mid j=s}a_i b_j$$
###### AND 卷积
```cpp
auto c = and_convolution(a, b);
```
满足：
$$c_s=\sum_{i\&j=s}a_i b_j$$
###### XOR 卷积
```cpp
auto c = xor_convolution(a, b);
```
满足：
$$c_s=\sum_{i\oplus j=s}a_i b_j$$
###### 一个最小区别例子
设：
```cpp
vector<i64> a(4), b(4);
a[1] = 2;
b[2] = 3;
```
只有一对非零下标：
$$1=01_2,\quad2=10_2$$
于是：
###### OR
$$1\mid2=3$$
所以：
```cpp
or_convolution(a, b)[3] == 6;
```
###### AND
$$1\&2=0$$
所以：
```cpp
and_convolution(a, b)[0] == 6;
```
###### XOR
$$1\oplus2=3$$
所以：
```cpp
xor_convolution(a, b)[3] == 6;
```

这个小例子很适合现场确认自己调用的是哪一种卷积
###### 手动频域操作
```cpp
fwt_xor(a, false);
// a 现在处于 XOR 频域
for (Z &x : a) {
    // 自定义操作
}
fwt_xor(a, true);
```
注意必须保持数组长度为二次幂
##### 复杂度
设补齐后的状态数：
$$N=2^{\lceil\log_2\max(|a|,|b|)\rceil}$$
如果输入本来就是 $k$ 位 mask：
$$N=2^k$$
每一位做一次所有状态的蝶形，因此：
$$O(Nk)=O(N\log N)$$

|接口|时间复杂度|额外空间|
|---|--:|--:|
|`fwt_or()`|$O(N\log N)$|$O(1)$|
|`fwt_and()`|$O(N\log N)$|$O(1)$|
|`fwt_xor()`|$O(N\log N)$|$O(1)$|
|`or_convolution()`|$O(N\log N)$|$O(N)$|
|`and_convolution()`|$O(N\log N)$|$O(N)$|
|`xor_convolution()`|$O(N\log N)$|$O(N)$|
注意这里的：
$$N$$
和 FFT / NTT 普通卷积不同
普通卷积取：
$$N\ge n+m-1$$
FWT 则只需要：
$$N\ge\max(n,m)$$
因为位运算不会产生超过当前**完整二进制状态空间**的下标
