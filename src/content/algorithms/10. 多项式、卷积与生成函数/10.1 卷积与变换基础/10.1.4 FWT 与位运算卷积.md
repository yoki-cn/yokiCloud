#### FWT 与位运算卷积
---
```cpp
namespace FWT {
    static int fwt_size(unsigned need) { return bit_ceil(need); }
    // OR：低 -> 高；正变换为子集和，逆变换为子集 Möbius 反演
    template<class T = Z>
    void fwt_or(vector<T> &a, bool inverse = false) {
        int n = a.size();
        assert(n && (n & (n - 1)) == 0);
        for (int len = 1; len < n; len <<= 1) {
            for (int i = 0; i < n; i += len << 1) {
                for (int j = 0; j < len; ++ j) {
                    if (!inverse) a[i + j + len] += a[i + j];
                    else a[i + j + len] -= a[i + j];
                }
            }
        }
    }
    // AND：高 -> 低；正变换为超集和，逆变换为超集 Möbius 反演
    template<class T = Z>
    void fwt_and(vector<T> &a, bool inverse = false) {
        int n = a.size();
        assert(n && (n & (n - 1)) == 0);
        for (int len = 1; len < n; len <<= 1) {
            for (int i = 0; i < n; i += len << 1) {
                for (int j = 0; j < len; ++ j) {
                    if (!inverse) a[i + j] += a[i + j + len];
                    else a[i + j] -= a[i + j + len];
                }
            }
        }
    }
    // XOR：Hadamard 变换；逆变换等于再次变换后整体除以 n
    template<class T = Z>
    void fwt_xor(vector<T> &a, bool inverse = false) {
        int n = a.size();
        assert(n && (n & (n - 1)) == 0);
        for (int len = 1; len < n; len <<= 1) {
            for (int i = 0; i < n; i += len << 1) {
                for (int j = 0; j < len; ++ j) {
                    T x{ a[i + j] }, y{ a[i + j + len] };
                    a[i + j] = x + y;
                    a[i + j + len] = x - y;
                }
            }
        }
        if (inverse) {
            for (T &x : a) x /= T(n);
        }
    }
    // ===== 位运算卷积公共实现：三个 conv_*() 依赖，不建议单独使用 =====
    template<class T, class F>
    vector<T> conv_impl(const vector<T> &a, const vector<T> &b, F fwt) {
        if (a.empty() || b.empty()) return {};
        int n{ fwt_size(max(a.size(), b.size())) };
        vector<T> f(n);
        ranges::copy(a, f.begin());
        fwt(f, false);
        // conv_*(a, a) 时少做一次正变换
        if (&a == &b) {
            for (T &x : f) x *= x;
        } else {
            vector<T> g(n);
            ranges::copy(b, g.begin());
            fwt(g, false);
            for (int i = 0; i < n; ++ i) f[i] *= g[i];
        }
        fwt(f, true);
        return f;
    }
    template<class T = Z>
    vector<T> conv_or(const vector<T> &a, const vector<T> &b) {
        return conv_impl(a, b, fwt_or<T>);
    }
    template<class T = Z>
    vector<T> conv_and(const vector<T> &a, const vector<T> &b) {
        return conv_impl(a, b, fwt_and<T>);
    }
    template<class T = Z>
    vector<T> conv_xor(const vector<T> &a, const vector<T> &b) {
        return conv_impl(a, b, fwt_xor<T>);
    }
}
template<class T = Z>
vector<T> conv_or(const vector<T> &a, const vector<T> &b) {
    return FWT::conv_or(a, b);
}
template<class T = Z>
vector<T> conv_and(const vector<T> &a, const vector<T> &b) {
    return FWT::conv_and(a, b);
}
template<class T = Z>
vector<T> conv_xor(const vector<T> &a, const vector<T> &b) {
    return FWT::conv_xor(a, b);
}
```
#### 接口说明
##### `FWT::fwt_size(need)`
返回不小于 `need` 的最小二次幂：
```cpp
int n = FWT::fwt_size(need);
```
即
$$
n=2^{\lceil\log_2 need\rceil}
$$
要求 `need > 0`
##### `FWT::fwt_or(a, inverse)`
原地进行 OR FWT
正变换：
```cpp
FWT::fwt_or(a);
```
对应子集 Zeta 变换：
$$
\widehat a_S=\sum_{T\subseteq S}a_T
$$
逆变换：
```cpp
FWT::fwt_or(a, true);
```
为对应的子集 Möbius 反演
变换本身只需要 `T` 支持加减法
##### `FWT::fwt_and(a, inverse)`
原地进行 AND FWT
正变换：
$$
\widehat a_S=\sum_{T\supseteq S}a_T
$$
即超集 Zeta 变换
逆变换为对应的超集 Möbius 反演
同样只需要 `T` 支持加减法
##### `FWT::fwt_xor(a, inverse)`
原地进行 XOR Walsh--Hadamard 变换。
蝶形为：
$$
(x,y)\longrightarrow(x+y,x-y)
$$
Hadamard 矩阵满足：
$$
H_N^2=NI
$$
因此逆变换为：
$$
H_N^{-1}=\frac1N H_N
$$
所以逆变换会再次执行同样的蝶形，并整体除以 `a.size()`
##### `FWT::conv_or(a, b)`
计算 OR 卷积：
$$
c_s=\sum_{i\mid j=s}a_i b_j
$$
```cpp
auto c = FWT::conv_or(a, b);
```
##### `FWT::conv_and(a, b)`
计算 AND 卷积：
$$
c_s=\sum_{i\mathbin{\&}j=s}a_i b_j
$$
```cpp
auto c = FWT::conv_and(a, b);
```
##### `FWT::conv_xor(a, b)`
计算 XOR 卷积：
$$
c_s=\sum_{i\oplus j=s}a_i b_j
$$
```cpp
auto c = FWT::conv_xor(a, b);
```
三种卷积均：
* 任一输入为空时返回 `{}`
* 自动补零到不小于两者长度的最小二次幂
* 返回整个补齐后的状态空间
* 两个参数引用同一对象时只进行一次正变换
##### 全局快捷接口
```cpp
conv_or(a, b);
conv_and(a, b);
conv_xor(a, b);
```
分别等价于：
```cpp
FWT::conv_or(a, b);
FWT::conv_and(a, b);
FWT::conv_xor(a, b);
```
与前面的卷积接口保持统一：
```cpp
conv(a, b);             // 998244353 NTT
conv_large(a, b);       // 超长 NTT
conv_mod(a, b, mod);    // 任意模 NTT + CRT
conv_or(a, b);          // OR 卷积
conv_and(a, b);         // AND 卷积
conv_xor(a, b);         // XOR 卷积
```
#### 注意事项
##### 位运算卷积的长度
普通多项式卷积需要：
$$
N\ge |a|+|b|-1
$$
位运算卷积不同，只需要覆盖完整的二进制状态空间：
$$
N=2^{\lceil\log_2\max(|a|,|b|)\rceil}
$$
因为对于：
$$
0\le i,j<N
$$
都有：
$$
i\mid j<N,
\qquad
i\mathbin{\&}j<N,
\qquad
i\oplus j<N.
$$
例如两个长度均为 `3` 的数组需要补到长度 `4`：
```text
0 1 2 3
```
答案长度为 `4`，而不是普通卷积的 `5`
如果输入本身就是完整的 `k` 位状态空间，通常直接使用：
```cpp
vector<Z> a(1 << k), b(1 << k);
```
无需额外考虑长度
##### XOR 需要能够除以状态数
OR / AND 的正逆变换都只包含：
```text
+
-
```
而 XOR 的逆变换还需要除以：
$$
N=2^k
$$
对于模意义运算，需要 $N$ 在模数下存在逆元，即：
$$
\gcd(N,M)=1
$$
因为 $N$ 是二次幂，所以等价于：
> **模意义 XOR FWT 要求模数为奇数**

默认：
```cpp
Z = MInt<998244353>
```
满足这一条件
偶数模数下：
```text
OR  ✅
AND ✅
XOR ❌ 一般不能直接使用
```
##### 整数 XOR 卷积
`T = i64` 或 `i128` 时也可以进行整数 XOR 卷积
对于由合法卷积流程产生的频域结果，最终理论值能够整除 $N$，因此：
```cpp
x /= T(n);
```
可以得到精确结果
但如果单独对任意整数数组执行：
```cpp
FWT::fwt_xor(a, true);
```
而输入并不是合法的 XOR 频域值，整数除法可能发生截断
##### 注意中间值溢出
整数 FWT 的中间值可能显著大于最终答案
正变换会产生大量和差，频域还需要进行逐点乘法，因此：
$$
\text{最终答案不溢出}
\not\Rightarrow
\text{FWT 中间值不溢出}
$$
若要求精确整数卷积：
* 数值较小时可使用 `i64`
* 中间结果可能较大时使用 `i128`
* 模意义问题优先使用 `Z`
##### OR / AND 的方向
这是最容易现场写反的地方
OR：
```cpp
high += low;
```
即：
```text
低 -> 高
```
向“当前 bit 为 `1`”的状态累加，得到子集和
AND：
```cpp
low += high;
```
即：
```text
高 -> 低
```
向“当前 bit 为 `0`”的状态累加，得到超集和
可以记成：
```text
OR ：向有这个 bit 的状态累加
AND：向没有这个 bit 的状态累加
```
逆变换将对应的 `+=` 改为 `-=`
##### OR 卷积不是子集卷积
OR 卷积：
$$
c_S=\sum_{A\cup B=S}a_A b_B
$$
允许：
$$
A\cap B\ne\varnothing
$$
而通常所说的子集卷积要求：
$$
A\cap B=\varnothing.
$$
两者不是同一种卷积
#### 常见用法

##### OR 卷积
```cpp
int k;
vector<Z> a(1 << k), b(1 << k);
auto c = conv_or(a, b);
```
满足：
$$
c_s=\sum_{i\mid j=s}a_i b_j
$$
##### AND 卷积
```cpp
auto c = conv_and(a, b);
```
满足：
$$
c_s=\sum_{i\mathbin{\&}j=s}a_i b_j
$$
##### XOR 卷积
```cpp
auto c = conv_xor(a, b);
```
满足：
$$
c_s=\sum_{i\oplus j=s}a_i b_j
$$
##### 平方卷积
```cpp
auto c = conv_xor(a, a);
```
两个参数引用同一对象时，只进行一次正向 FWT，再逐点平方
OR / AND 同样支持：
```cpp
conv_or(a, a);
conv_and(a, a);
```
##### 手动频域操作
有些题目并不是普通两数组卷积，而是需要在变换域进行特殊运算：
```cpp
FWT::fwt_xor(a);
for (Z &x : a) {
    // 在 XOR 频域中进行自定义操作
}
FWT::fwt_xor(a, true);
```
OR / AND 同理：
```cpp
FWT::fwt_or(a);
FWT::fwt_or(a, true);
FWT::fwt_and(a);
FWT::fwt_and(a, true);
```
数组长度必须始终保持为二次幂
#### 复杂度
设补齐后的状态数为：
$$
N=2^{\lceil\log_2\max(|a|,|b|)\rceil}
$$
若状态为 `k` 位 bitmask，则：
$$
N=2^k
$$
每一层遍历全部状态，共有 $\log_2N$ 层，因此三种 FWT 的时间复杂度均为：
$$
O(N\log N)
$$
变换本身为原地操作：

| 接口           |        时间复杂度 |   额外空间 |
| ------------ | -----------: | -----: |
| `fwt_or()`   | $O(N\log N)$ | $O(1)$ |
| `fwt_and()`  | $O(N\log N)$ | $O(1)$ |
| `fwt_xor()`  | $O(N\log N)$ | $O(1)$ |
| `conv_or()`  | $O(N\log N)$ | $O(N)$ |
| `conv_and()` | $O(N\log N)$ | $O(N)$ |
| `conv_xor()` | $O(N\log N)$ | $O(N)$ |
普通卷积与位运算卷积的补齐长度分别为：
$$
\begin{aligned}
\text{FFT / NTT:}\quad
&N\ge |a|+|b|-1,\\
\text{FWT:}\quad
&N\ge\max(|a|,|b|)
\end{aligned}
$$
