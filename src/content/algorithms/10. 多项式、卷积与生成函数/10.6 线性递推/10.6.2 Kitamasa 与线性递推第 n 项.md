### Kitamasa（线性递推第 n 项）

> 依赖：无需其它多项式板子。

```cpp
// initial[0..k-1]，c[0..k-1]：s[n]=Σ c[j]s[n-1-j]
template<class T>
T kitamasa(const vector<T> &initial, const vector<T> &c, i64 n) {
    int k = c.size();
    assert(k > 0 && int(initial.size()) >= k && n >= 0);
    if (n < k) return initial[n];
    auto mul = [&](const vector<T> &a, const vector<T> &b) {
        vector<T> t(2 * k - 1);
        for (int i = 0; i < k; ++ i) {
            for (int j = 0; j < k; ++ j) t[i + j] += a[i] * b[j];
        }
        for (int i = 2 * k - 2; i >= k; -- i) {
            for (int j = 1; j <= k; ++ j) t[i - j] += t[i] * c[j - 1];
        }
        t.resize(k);
        return t;
    };
    vector<T> r(k), x(k);
    r[0] = 1;
    if (k == 1) x[0] = c[0];
    else x[1] = 1;
    for (; n; n >>= 1, x = mul(x, x)) {
        if (n & 1) r = mul(r, x);
    }
    T ans{};
    for (int i = 0; i < k; ++ i) ans += r[i] * initial[i];
    return ans;
}
```

#### 接口说明

- `kitamasa(initial,c,n)`：已知 k 阶递推前 k 项，计算零基下标 `s[n]`。
- 本版不依赖 NTT、`Poly`，适合阶数较小、目标下标极大的递推。

#### 注意事项

- 输入 `c` 与 BM 输出的顺序一致：`c[0]` 乘 `s[n-1]`。
- 允许 `k=1`；对一般环也成立（不需要求逆），但整型可能溢出。
- 当 k 很大时 $O(k^2 \log n)$ 可能慢，改用 `Bostan–Mori` 加 NTT。

#### 常见用法

```cpp
vector<Z> init{0, 1}, c{1, 1};
Z f100 = kitamasa(init, c, 100);
```

#### 复杂度

- $O(k^2 \log n)$ 时间，$O(k)$ 额外空间。
