### Bostan–Mori（有理生成函数第 n 项）

> 依赖：`10.2.1 Poly`；`recurrence_gf` 可选。

```cpp
// [x^n] P(x)/Q(x)，要求 Q[0]!=0
Z bostan_mori(Poly<Z> p, Poly<Z> q, i64 n) {
    assert(n >= 0 && !q.empty() && q[0] != Z(0));
    p.norm(); q.norm();
    Z whole{};
    if (p.size() >= q.size()) {
        auto [div, rem] = divmod(p, q);
        whole = n < div.size() ? div[int(n)] : Z(0);
        p = move(rem);
    }
    while (n > 0 && !p.empty()) {
        Poly<Z> neg = q;
        for (int i = 1; i < neg.size(); i += 2) neg[i] = -neg[i];
        auto a = p * neg, b = q * neg;
        Poly<Z> np, nq;
        for (int i = n & 1; i < a.size(); i += 2) np.a.push_back(a[i]);
        for (int i = 0; i < b.size(); i += 2) nq.a.push_back(b[i]);
        p = move(np); q = move(nq);
        n >>= 1;
    }
    return whole + (p.empty() ? Z(0) : p[0] / q[0]);
}
```

#### 接口说明

- `bostan_mori(p,q,n)`：求 `[x^n]p(x)/q(x)`，`n` 可达 $10^18$。
- 若 `deg(p)>=deg(q)`，先做多项式长除，再对真分式做 Bostan–Mori。

#### 注意事项

- `q[0]!=0`；系数域是 `Z`，所有除法有模逆。
- 需要递推求第 n 项时，先使用 `10.5.3 recurrence_gf` 将递推转成分式。
- `p=0` 返回零；`n=0` 返回常数系数 `p[0]/q[0]`（含可能存在的整式部分）。

#### 常见用法

```cpp
vector<Z> init{0, 1}, c{1, 1};
auto [p, q] = recurrence_gf(init, c);
Z fib = bostan_mori(p, q, 1000000000000LL);
```

#### 复杂度

- 令 `d=max(deg P,deg Q)`，$O(M(d) \log n)$ 时间、$O(d)$ 额外空间，含初始长除。
