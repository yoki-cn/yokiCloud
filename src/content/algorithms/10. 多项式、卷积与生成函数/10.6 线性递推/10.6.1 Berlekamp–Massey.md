### Berlekamp–Massey（最短线性递推）

> 依赖：系数域 `T` 支持 `+ - * /`。

```cpp
// 给定序列 s，返回 c，使 s[n]=Σ_{i=1}^k c[i-1]s[n-i]
template<class T>
vector<T> berlekamp_massey(const vector<T> &s) {
    vector<T> c{1}, b{1};
    int l = 0, m = 1;
    T last = 1;
    for (int n = 0; n < int(s.size()); ++ n) {
        T d{};
        for (int i = 0; i <= l; ++ i) d += c[i] * s[n - i];
        if (d == T{}) {
            ++ m;
            continue;
        }
        auto old = c;
        T w = d / last;
        if (c.size() < b.size() + m) c.resize(b.size() + m);
        for (int i = 0; i < int(b.size()); ++ i) c[i + m] -= w * b[i];
        if (2 * l <= n) {
            l = n + 1 - l;
            b = move(old);
            last = d;
            m = 1;
        } else ++ m;
    }
    c.resize(l + 1);
    vector<T> rec(l);
    for (int i = 0; i < l; ++ i) rec[i] = -c[i + 1];
    return rec;
}
```

#### 接口说明

- `berlekamp_massey(s)`：返回与已给序列一致的**最短阶数**线性递推系数 `c[0..k-1]`。
- `c.empty()` 表示在观测序列上得到零阶递推（如全零）。

#### 注意事项

- 适用域上可逆非零差值：对质数模的 `Z` 合适，`i64` 不是通用的域。
- 给定有限项只能得到**拟合**递推；想恢复真实的最小递推，通常需足够多项（常见为真实阶数的两倍）并由题意保证递推存在。
- 输出系数按**最近前项在前**排列：`s[n]=c[0]*s[n-1]+...+c[k-1]*s[n-k]`。

#### 常见用法

```cpp
vector<Z> fib{0, 1, 1, 2, 3, 5, 8, 13};
auto c = berlekamp_massey(fib); // {1,1}
```

#### 复杂度

- $O(n^2)$ 时间、$O(n)$ 空间。
