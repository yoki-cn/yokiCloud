### FPS 复合与复合逆（短版，适合中小 n）

> 依赖：`10.2.1 Poly`。

```cpp
// ===== 选配：朴素复合，避免引入复杂的大规模复合算法 =====
// f(g(x)) mod x^n，要求 g[0]=0
Poly<Z> compose(const Poly<Z> &f, const Poly<Z> &g, int n) {
    assert(n >= 0 && (g.empty() || g[0] == Z(0)));
    if (!n) return {};
    Poly<Z> ans(n);
    for (int i = min(f.size(), n) - 1; i >= 0; -- i) {
        ans = (ans * g).trunc(n);
        ans[0] += f[i];
    }
    return ans;
}
// F(G(x))=x mod x^n；F[0]=0，F[1]!=0
Poly<Z> compositional_inverse(const Poly<Z> &f, int n) {
    assert(n >= 0 && f[0] == Z(0) && f[1] != Z(0));
    if (!n) return {};
    Poly<Z> g(n);
    if (n == 1) return g;
    g[1] = Z(1) / f[1];
    for (int m = 2; m < n; m <<= 1) {
        int k = min(2 * m, n);
        auto err = compose(f, g.trunc(k), k);
        err[1] -= 1;
        auto d = compose(f.deriv(), g.trunc(k), k);
        g = (g.trunc(k) - (err * d.inv(k)).trunc(k)).trunc(n);
    }
    return g;
}
```

#### 接口说明

- `compose(f,g,n)`：形式幂级数复合 `f(g(x)) mod x^n`，Horner 实现。
- `compositional_inverse(f,n)`：复合逆 `g`，使 `f(g(x))=x mod x^n`，使用 Newton 纠错。

#### 注意事项

- **这份实现专门保留较短、容易核对的版本**：适合 `n` 不大；大规模 $n\approx 10^5$ 不应使用这里的 `compose`，需要 Brent–Kung 或更高级的专用复合算法。
- 复合默认 `g[0]=0`，复合逆要求 `f[0]=0`、`f[1]` 可逆。`f` 的前两项必须存在，否则不满足调用前提。
- 复合逆过程中只关心模 $x^n$ 的前缀，勿把普通乘法逆 `inv()` 当作复合逆。

#### 常见用法

```cpp
Poly<Z> f{0, 1, 1}; // x+x²
auto g = compositional_inverse(f, 10);
auto id = compose(f, g, 10); // {0,1,0,...}
```

#### 复杂度

- `compose`：$O(n M(n))$ 时间；复合逆约 $O(n M(n))$ 量级、$O(n)$ 临时空间。
