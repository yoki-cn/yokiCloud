### Taylor Shift（计算 f(x+c)）

> 依赖：全局 `conv`（NTT），`Poly<Z>`。

```cpp
// 计算 f(x+c)，只返回 f.size() 项，模 998244353
Poly<Z> taylor_shift(const Poly<Z> &f, Z c) {
    int n = f.size();
    if (!n) return {};
    vector<Z> fac(n), ifac(n), a(n), b(n);
    fac[0] = 1;
    for (int i = 1; i < n; ++ i) fac[i] = fac[i - 1] * Z(i);
    ifac[n - 1] = fac[n - 1].inv();
    for (int i = n - 1; i >= 1; -- i) ifac[i - 1] = ifac[i] * Z(i);
    Z pw = 1;
    for (int i = 0; i < n; ++ i) {
        a[n - 1 - i] = f[i] * fac[i];
        b[i] = pw * ifac[i];
        pw *= c;
    }
    auto h = conv(a, b);
    Poly<Z> g(n);
    for (int i = 0; i < n; ++ i) g[i] = h[n - 1 - i] * ifac[i];
    return g;
}
```

#### 接口说明

- `taylor_shift(f,c)`：返回普通幂基系数表示的 `f(x+c)`，不修改次数。

#### 注意事项

- `n=f.size()` 必须使 `0!..(n-1)!` 可逆；模 `998244353` 下 `n<=mod`。
- 该版本自动保留尾部零系数，不调用 `norm()`；若需要最简多项式，可在返回后调用。

#### 常见用法

```cpp
Poly<Z> f{1, 2, 3}; // 1+2x+3x²
auto g = taylor_shift(f, Z(5)); // 86+32x+3x²
```

#### 复杂度

- $O(M(n))$ 时间、$O(n)$ 空间。
