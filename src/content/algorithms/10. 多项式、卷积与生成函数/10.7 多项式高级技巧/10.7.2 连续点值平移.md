### 连续点值平移（复用多点插值）

> 依赖：`10.4.3 ProductTree` + `10.4.4 interpolate`。

```cpp
// 给定 y[i]=f(i) (deg f<n)；求 f(c),f(c+1),...,f(c+m-1)
vector<Z> shift_samples(const vector<Z> &y, Z c, int m) {
    assert(m >= 0);
    if (m == 0) return {};
    int n = y.size();
    if (n == 0) return vector<Z>(m);
    vector<Z> x(n), target(m);
    for (int i = 0; i < n; ++ i) x[i] = i;
    for (int j = 0; j < m; ++ j) target[j] = c + Z(j);
    ProductTree old(x), cur(target);
    auto f = interpolate(old, y);
    return cur.eval(f);
}
```

#### 接口说明

- `shift_samples(y,c,m)`：由连续采样 `f(0)..f(n-1)` 求连续采样 `f(c)..f(c+m-1)`。
- 本版复用子积树，不另外维护容易在取到旧采样点时除零的专门平移公式。

#### 注意事项

- 要求 $\deg f<n$，`0..n-1` 在模域中两两不同；通常 `n<mod`。
- 本实现并非理论最快的连续点值平移特化算法，但复用经过测试的插值与多点求值模块，适合少抄板子的赛场需求。
- 目标点允许和原采样点重复，输出依然正确。

#### 常见用法

```cpp
vector<Z> y{1, 4, 9, 16}; // (x+1)^2
auto shifted = shift_samples(y, Z(10), 3); // {121,144,169}
```

#### 复杂度

- 约 $O(M(n+m) \log(n+m))$ 时间、$O((n+m)\log(n+m))$ 空间。
