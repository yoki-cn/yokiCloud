### Chirp-Z（等比点求值）

> 依赖：全局 `conv` + `Poly<Z>`。

```cpp
// 返回 f(q^j), j=0..m-1；q=0 时约定 q^0=1
vector<Z> chirp_z(const Poly<Z> &f, Z q, int m) {
    assert(m >= 0);
    int n = f.size();
    vector<Z> ans(m);
    if (m == 0 || n == 0) return ans;
    if (q == Z(0)) {
        ans[0] = f.eval(Z(1));
        for (int j = 1; j < m; ++ j) ans[j] = f[0];
        return ans;
    }
    vector<Z> a(n), b(n + m - 1);
    Z cur = 1, step = 1;
    for (int i = 0; i < n; ++ i) {
        a[i] = f[i] * cur;
        cur *= step;
        step *= q;
    }
    Z iq = q.inv();
    int start = 1 - n;
    cur = iq.pow(1LL * start * (start + 1) / 2);
    step = start + 1 < 0 ? q.pow(-start - 1) : iq.pow(start + 1);
    for (int k = start; k < m; ++ k) {
        b[k + n - 1] = cur;
        cur *= step;
        step *= iq;
    }
    auto c = conv(a, b);
    cur = 1; step = q;
    for (int j = 0; j < m; ++ j) {
        ans[j] = c[n - 1 + j] * cur;
        cur *= step;
        step *= q;
    }
    return ans;
}
```

#### 接口说明

- `chirp_z(f,q,m)`：返回 `f(1),f(q),f(q²),...,f(q^(m-1))`。
- 非零 `q` 利用平方差分解，把等比点求值化成**一次卷积**。

#### 注意事项

- 处理 `q=0`、`n=0`、`m=0`；`q=0` 的 `j=0` 位置按 `q^0=1`。
- `q` 为非零但阶很小时，查询点可能重复，**求值仍正确**；但如果要做插值需点互异。
- 用 `i64` 计算平方型指数，`n,m` 的规模不得使 `i64` 指数溢出（常见算法竞赛规模下无问题）。

#### 常见用法

```cpp
Poly<Z> f{1, 2, 3};
auto vals = chirp_z(f, Z(2), 4); // f(1),f(2),f(4),f(8)
```

#### 复杂度

- $O(M(n+m))$ 主导时间（另有少量 $O(\log(n+m))$ 快速幂），$O(n+m)$ 空间。
