### 下降阶乘 / 上升阶乘（多项式）

> 依赖：`Poly<Z>` 与 `conv`。

```cpp
// falling: x(x-1)...(x-n+1)
// rising:  x(x+1)...(x+n-1)
Poly<Z> factorial_poly(int n, bool rising = false) {
    assert(n >= 0);
    auto dfs = [&](auto &&self, int l, int r) -> Poly<Z> {
        if (r - l == 1) return {rising ? Z(l) : Z(-l), Z(1)};
        int m = (l + r) / 2;
        return self(self, l, m) * self(self, m, r);
    };
    return n ? dfs(dfs, 0, n) : Poly<Z>{1};
}
```

#### 接口说明

- `factorial_poly(n,false)`：下降阶乘 $x^{\underline{n}}$。
- `factorial_poly(n,true)`：上升阶乘 $x^{\overline{n}}$。
- 系数采用通常的 $x^i$ 形式，便于直接卷积、Taylor Shift 等。

#### 注意事项

- `n=0` 两者都等于 `1`；`n<mod` 不是本实现的数学必需条件（但规模必须可计算）。
- 下降阶乘在非负整数 `0..n-1` 处为零，可用于构造插值与组合恒等式。

#### 常见用法

```cpp
auto f = factorial_poly(3);       // x³-3x²+2x
auto g = factorial_poly(3, true); // x³+3x²+2x
```

#### 复杂度

- $O(M(n) \log n)$ 时间、$O(n \log n)$ 递归临时系数总占用上界；可回收内存实际较低。
