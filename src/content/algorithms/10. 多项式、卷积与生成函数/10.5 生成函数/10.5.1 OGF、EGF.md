### 普通 / 指数生成函数（OGF / EGF）

> 依赖：全局 `conv()`；若执行 FPS 则依赖 `Poly<Z>`。

```cpp
// 用系数存储生成函数：a[i] 表示 x^i 项系数
// OGF: A(x) = Σ a[n]x^n
// EGF: E(x) = Σ a[n] x^n/n!，实际 Poly 系数为 a[n]/n!
vector<Z> to_egf(const vector<Z> &a) {
    int n = a.size();
    if (!n) return {};
    vector<Z> b(n), invfac(n);
    Z fac = 1;
    for (int i = 1; i < n; ++ i) fac *= i;
    invfac[n - 1] = fac.inv();
    for (int i = n - 1; i >= 1; -- i) invfac[i - 1] = invfac[i] * Z(i);
    for (int i = 0; i < n; ++ i) b[i] = a[i] * invfac[i];
    return b;
}
```

#### 接口说明

- OGF：`A(x)=Σ a_n x^n`，适合无标号/顺序结构的和卷积。
- EGF：`A(x)=Σ a_n x^n/n!`，适合标号组合对象。
- 两个 EGF 相乘得到 `c_n=Σ binom(n,k)a_k b_{n-k}`。
- `to_egf(a)`：将原始计数序列转成 EGF 的系数数组。

#### 注意事项

- EGF 必须使用阶乘归一化，直接对原始计数调用 `conv` 得到的是 OGF 卷积。
- 模 `998244353` 下要求所需阶乘可逆，即系数长度不超过模数。

#### 常见用法

```cpp
vector<Z> a{1, 1, 1, 1};
Poly<Z> A(to_egf(a)); // Σ x^i/i!
auto B = A * A;       // 两个标号结构组合
// 恢复原始计数：b[i] = B[i] * i!
```

#### 复杂度

- 阶乘转换 $O(n)$；OGF/EGF 乘法复用 $O(M(n))$ 的多项式卷积。
