### Lagrange 反演（系数形式）

> 依赖：`10.2.1 Poly::pow`。

```cpp
// F(x)=x * phi(F(x)), phi(0)!=0
// [x^n]F(x)=(1/n)[t^(n-1)]phi(t)^n, n>=1
Z lagrange_inverse_coeff(const Poly<Z> &phi, int n) {
    assert(n >= 1 && !phi.empty() && phi[0] != Z(0));
    return phi.pow(n, n)[n - 1] / Z(n);
}
```

#### 接口说明

- `lagrange_inverse_coeff(phi,n)`：已知 `F=x*phi(F)`，求 `F` 的第 `n` 项，不必显式构造 F。
- 更一般地：`[x^n]H(F(x))=(1/n)[t^(n-1)]H'(t)phi(t)^n`（`n>=1`）。

#### 注意事项

- 要求 `phi(0)≠0`（标准形式）、`n` 在模数下可逆；`n=0` 单独取 `H(0)`。
- 此接口使用 Poly 的 `pow`，只能在幂级数相关假设成立时调用；需要很多相邻项时，改用 FPS 复合逆/牛顿法更适合。
#### 常见用法
```cpp
// F=x(1+F)^2: Catalan 型生成函数（F[1]=1,F[2]=2,F[3]=5）
Poly<Z> phi{1, 2, 1};
Z c3 = lagrange_inverse_coeff(phi, 3); // 5
```
#### 复杂度
- 单个系数 $O(M(n))$ 量级；需要 `n` 次除法，约定 `1<=n<mod`。
