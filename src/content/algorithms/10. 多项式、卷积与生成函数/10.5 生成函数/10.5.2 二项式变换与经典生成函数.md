### 二项式变换与经典生成函数

> 依赖：`10.1.1 NTT` 中 `conv`，`Z`。

```cpp
// b[n]=Σ_{k=0}^n C(n,k) a[k]
// inverse=true: a[n]=Σ (-1)^(n-k) C(n,k) b[k]
vector<Z> binomial_transform(const vector<Z> &a, bool inverse = false) {
    int n = a.size();
    if (!n) return {};
    vector<Z> fac(n), ifac(n), f(n), g(n);
    fac[0] = 1;
    for (int i = 1; i < n; ++ i) fac[i] = fac[i - 1] * Z(i);
    ifac[n - 1] = fac[n - 1].inv();
    for (int i = n - 1; i >= 1; -- i) ifac[i - 1] = ifac[i] * Z(i);
    for (int i = 0; i < n; ++ i) {
        f[i] = a[i] * ifac[i];
        g[i] = (inverse && (i & 1)) ? -ifac[i] : ifac[i];
    }
    auto h = conv(f, g);
    h.resize(n);
    for (int i = 0; i < n; ++ i) h[i] *= fac[i];
    return h;
}
```

#### 接口说明

- `binomial_transform(a,false)`：二项式正变换。
- `binomial_transform(a,true)`：二项式逆变换。
- 常见 OGF：`1/(1-x)` 全 1；$(1-x)^{-k}$ 系数 `C(n+k-1,k-1)`；$-\log(1-x)$ 系数 $1/n\quad(n\ge1)$。
- 常见 EGF：`exp(x)` 对应全 1；`exp(exp(x)-1)` 对应 Bell 数。

#### 注意事项

- 本变换使用阶乘逆元，仅在需要的 `i!` 可逆时有效。
- 公式里的 `a_n` 是原始系数，不是已经除以阶乘的 EGF 系数。

#### 常见用法

```cpp
vector<Z> a{1, 2, 3, 4};
auto b = binomial_transform(a);
auto recovered = binomial_transform(b, true); // recovered == a
```

#### 复杂度

- 单次正/逆变换 $O(M(n))$ 时间、$O(n)$ 空间。
