### 常系数递推与有理生成函数

> 依赖：`Poly<Z>`；可配合 Bostan–Mori。

```cpp
// s[n] = Σ_{j=1}^k c[j-1] * s[n-j] (n>=k)
// Q(x)=1-c[0]x-...-c[k-1]x^k
// P(x)=(Σ_{i=0}^{k-1}s[i]x^i)*Q(x) mod x^k
pair<Poly<Z>, Poly<Z>> recurrence_gf(const vector<Z> &s,
                                     const vector<Z> &c) {
    int k = c.size();
    assert(int(s.size()) >= k && k > 0);
    Poly<Z> q(k + 1);
    q[0] = 1;
    for (int i = 0; i < k; ++ i) q[i + 1] = -c[i];
    Poly<Z> p = (Poly<Z>(vector<Z>(s.begin(), s.begin() + k)) * q).trunc(k);
    p.norm();
    return {p, q};
}
```

#### 接口说明

- `recurrence_gf(initial,c)`：返回 `P(x),Q(x)`，满足 `Σ s_nx^n=P/Q`。
- 求前 `n` 项：`(P * Q.inv(n)).trunc(n)`。
- 求巨大下标的单项：传递给 `10.6.3 Bostan–Mori`，不必展开全部系数。

#### 注意事项

- 递推只能从 `n>=k` 起使用，`s[0..k-1]` 是初始化，不允许遗漏 `P(x)` 中的修正项。
- 若 `c[k-1]=0` 可减小递推阶数，提高效率。

#### 常见用法

```cpp
vector<Z> s{0, 1}, c{1, 1};
auto [p, q] = recurrence_gf(s, c); // Fibonacci: x/(1-x-x²)
auto first = (p * q.inv(10)).trunc(10);
```

#### 复杂度

- 建立分式 $O(M(k))$；输出前 n 项 $O(M(n))$。
