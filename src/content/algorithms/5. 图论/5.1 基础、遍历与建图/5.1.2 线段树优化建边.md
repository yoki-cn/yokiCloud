### 线段树优化建边
---
```cpp
template<class W = i64>
struct SegmentGraph {
    int n;
    vector<vector<pair<int, W>>> g;
    vector<int> out_id, in_id;
    explicit SegmentGraph(int n_) : n(n_), g(n), out_id(max(1, n << 2)), in_id(max(1, n << 2)) {
        g.reserve(max(1, 3 * n));
        if (n) build(1, 0, n);
    }
    // ===== 基础扩点与建边：额外建模时也可以直接调用 =====
    int new_node() {
        g.emplace_back();
        return int(g.size()) - 1;
    }
    void add_edge(int u, int v, W w = {}) { g[u].push_back({v, w}); }
private:
    // ===== 双线段树：所有区间建边接口依赖，不建议删除 =====
    void build(int p, int l, int r) {
        if (r - l == 1) {
            out_id[p] = in_id[p] = l;
            return;
        }
        out_id[p] = new_node();
        in_id[p] = new_node();
        int mid{ l + r >> 1 };
        build(2 * p, l, mid);
        build(2 * p + 1, mid, r);
        add_edge(out_id[p], out_id[2 * p]);
        add_edge(out_id[p], out_id[2 * p + 1]);
        add_edge(in_id[2 * p], in_id[p]);
        add_edge(in_id[2 * p + 1], in_id[p]);
    }
    void p_to_rng(int u, int ql, int qr, W w, int p, int l, int r) {
        if (qr <= l || r <= ql) return;
        if (ql <= l && r <= qr) return add_edge(u, out_id[p], w);
        int mid{ l + r >> 1 };
        p_to_rng(u, ql, qr, w, 2 * p, l, mid);
        p_to_rng(u, ql, qr, w, 2 * p + 1, mid, r);
    }

    void rng_to_p(int ql, int qr, int v, W w, int p, int l, int r) {
        if (qr <= l || r <= ql) return;
        if (ql <= l && r <= qr) return add_edge(in_id[p], v, w);
        int mid{ l + r >> 1 };
        rng_to_p(ql, qr, v, w, 2 * p, l, mid);
        rng_to_p(ql, qr, v, w, 2 * p + 1, mid, r);
    }
public:
    // ===== 区间建边接口 =====
    void p_to_rng(int u, int l, int r, W w) { if (l < r) p_to_rng(u, l, r, w, 1, 0, n); }
    void rng_to_p(int l, int r, int v, W w) { if (l < r) rng_to_p(l, r, v, w, 1, 0, n); }
    int rng_to_rng(int l1, int r1, int l2, int r2, W w) {
        if (l1 >= r1 || l2 >= r2) return -1;
        int p{ new_node() };
        rng_to_p(l1, r1, p, w);
        p_to_rng(p, l2, r2, W{});
        return p;
    }
};
```
#### 成员变量
- `n`：原图点数
- 原始点编号固定为 `0..n-1`
- `g`：扩点后的完整邻接表；内部辅助点编号从 `n` 开始
- `out_id[p]`：出线段树节点，对应“一个点连向整个区间”
- `in_id[p]`：入线段树节点，对应“整个区间连向一个点”
#### 接口
- `SegmentGraph<W>(n)`：建立双线段树图，$O(n)$
- `new_node()`：新增一个普通辅助点，均摊 $O(1)$
- `add_edge(u, v, w)`：普通单点到单点有向边，均摊 $O(1)$
- `p_to_rng(u, l, r, w)`：对所有 `v in [l,r)` 建立逻辑边 `u -> v`，权值均为 `w`
- `range_to_point(l, r, v, w)`：对所有 `u in [l,r)` 建立逻辑边 `u -> v`，权值均为 `w`
- `range_to_range(l1, r1, l2, r2, w)`：对两个区间之间建立完整有向逻辑边，返回本次建立的中转点；空区间返回 `-1`
#### 注意事项
- 所有区间统一为左闭右开 `[l,r)`
- 原始点始终保持 `0..n-1`，线段树辅助点不会改变原点编号
- 基础双线段树在 `n > 0` 时恰好使用 `3n-2` 个点，而不是固定申请 `9n` 个点
- `g.size()` 才是跑最短路时的实际总点数；不要只跑前 `n` 个点
- 出树方向为“父节点 → 子节点”，因此一个辅助节点可以沿零边走向区间内所有原点
- 入树方向为“子节点 → 父节点”，因此区间内任意原点都可以沿零边汇入对应区间节点
- `rng_to_rng()` 只新建一个中转点：源区间以权 `w` 汇入中转点，中转点再以 `0` 权连向目标区间，因此任意合法点对间的总新增代价仍为 `w`
- 若后续跑 Dijkstra，则题目新增边权必须非负；`SegmentGraph` 本身并不限制边权
- 不要枚举区间分解出来的源节点和目标节点两两连边，否则一次区间到区间建边会退化为 $O(\log^2 n)$ 条边
#### 常见用法
##### 点到点
```cpp
SegmentGraph sg(n);
sg.add_edge(u, v, w);
```
##### 点到区间
表示：
$$u\rightarrow v,\quad l\le v<r$$
且所有边权均为 `w`：
```cpp
sg.p_to_rng(u, l, r, w);
```
##### 区间到点
表示：
$$u\rightarrow v,\quad l\le u<r$$
且所有边权均为 `w`：
```cpp
sg.rng_to_p(l, r, v, w);
```
##### 区间到区间
表示：
$$u\rightarrow v,\quad l_1\le u<r_1,\quad l_2\le v<r_2$$
且所有逻辑边权均为 `w`：
```cpp
sg.rng_to_rng(l1, r1, l2, r2, w);
```
不需要手动把两个区间各自拆成 $O(\log n)$ 个节点再做笛卡尔积
##### 接入最短路
全部建边完成后，对整张扩展图运行最短路：
```cpp
int N = sg.g.size();
// 对 sg.g[0 .. N) 跑 Dijkstra
```
源点和题目中的普通目标点仍直接使用原编号 `0..n-1`
#### 复杂度
初始化时，双线段树包含：
$$3n-2$$
个节点，以及：
$$4n-4$$
条零权辅助边

| 操作                          | 新增节点 |         新增边 |       时间复杂度 |
| --------------------------- | ---: | ----------: | ----------: |
| `add_edge()`                |  $0$ |         $1$ |      $O(1)$ |
| `p_to_rng()` / `rng_to_p()` |  $0$ | $O(\log n)$ | $O(\log n)$ |
| `range_to_range()`          |  $1$ | $O(\log n)$ | $O(\log n)$ |
