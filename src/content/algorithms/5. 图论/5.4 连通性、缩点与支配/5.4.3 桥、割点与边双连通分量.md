### 桥、割点与边双连通分量
---
一次 Lowlink 同时求：
* 桥
* 割点
* 边双连通分量 EBCC
之后可以直接建立桥森林
```cpp
struct UndirectedLowlink {
    struct Edge {
        int u, v;
    };
    struct Forest {
        int n;
        vector<array<int, 3>> edges;
        vector<vector<array<int, 2>>> adj;
        vector<int> siz, cnte;
        explicit Forest(int n_) : n(n_), adj(n), siz(n), cnte(n) {}
    };
    int n, timer{}, cnt{};
    vector<Edge> edges;
    vector<vector<int>> adj;
    vector<int> dfn, low, bel;
    vector<vector<int>> comp;
    vector<char> bridge, cut;
    bool built{};
    explicit UndirectedLowlink(int n_) : n(n_), adj(n), dfn(n), low(n), bel(n, -1), cut(n) {}
    int add_edge(int u, int v) {
        assert(!built);
        int id = edges.size();
        edges.push_back({u, v});
        adj[u].push_back(id);
        adj[v].push_back(id);
        bridge.push_back(false);
        return id;
    }
private:
    int other(int id, int u) const { return edges[id].u ^ edges[id].v ^ u; }
    // ===== Lowlink：桥与割点核心 =====
    void dfs(int u, int parent_edge) {
        dfn[u] = low[u] = ++ timer;
        int child{ 0 };
        for (int id : adj[u]) {
            if (id == parent_edge) continue;
            int v{ other(id, u) };
            if (!dfn[v]) {
                ++ child;
                dfs(v, id);
                low[u] = min(low[u], low[v]);
                if (low[v] > dfn[u]) bridge[id] = true;
                if (parent_edge != -1 &&
                    low[v] >= dfn[u]) {
                    cut[u] = true;
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (parent_edge == -1 && child > 1) cut[u] = true;
    }
public:
    // ===== EBCC：删除所有桥后求连通块 =====
    int build() {
        if (built) return cnt;
        for (int u : views::iota(0, n)) {
            if (!dfn[u]) dfs(u, -1);
        }
        vector<int> stk;
        stk.reserve(n);
        for (int s : views::iota(0, n)) {
            if (bel[s] != -1) continue;
            comp.push_back({});
            bel[s] = cnt;
            stk.push_back(s);
            while (!stk.empty()) {
                int u{ stk.back() };
                stk.pop_back();
                comp.back().push_back(u);
                for (int id : adj[u]) {
                    if (bridge[id]) continue;
                    int v{ other(id, u) };
                    if (bel[v] == -1) {
                        bel[v] = cnt;
                        stk.push_back(v);
                    }
                }
            }
            ++ cnt;
        }
        built = true;
        return cnt;
    }
    bool same_ebcc(int u, int v) const {
        assert(built);
        return bel[u] == bel[v];
    }
    // ===== 桥森林：若不需要缩点，可以删除 =====
    Forest forest() const {
        assert(built);
        Forest f(cnt);
        for (int c : views::iota(0, cnt)) {
            f.siz[c] = comp[c].size();
        }
        for (int id = 0; id < edges.size(); ++ id) {
            auto [u, v] = edges[id];
            int a{ bel[u] }, b{ bel[v] };
            if (a == b) {
                ++ f.cnte[a];
            } else {
                f.edges.push_back({a, b,id});
                f.adj[a].push_back({b, id});
                f.adj[b].push_back({a, id});
            }
        }
        return f;
    }
};
```
#### 接口说明
##### `add_edge(u,v)`
加入无向边并返回稳定边编号：
```cpp
int id = low.add_edge(u, v);
```
之后：
```cpp
low.edges[id]
```
仍对应该原图边
##### `build()`
一次完成：
* `dfn / low`
* 桥标记
* 割点标记
* EBCC 划分
并返回：
```cpp
low.cnt
```
即边双连通分量数量
##### `bridge[id]`
编号为 `id` 的原图边是否是桥
对于 DFS 树边：
$$
u\rightarrow v
$$
判桥条件为：
$$
low[v]>dfn[u]
$$
##### `cut[u]`
原图点 `u` 是否为割点
非 DFS 根：
$$
low[v]\ge dfn[u]
$$
存在某个 DFS 子节点 `v` 即为割点
DFS 根节点则必须拥有至少两个 DFS 树子节点
##### `bel[u]`
原点所属 EBCC 编号：
$$
0\le bel[u]<cnt
$$
##### `comp[id]`
第 `id` 个 EBCC 包含的全部原图节点
##### `same_ebcc(u,v)`
判断两点是否属于同一个边双
等价地：
> 不存在删除某一条边后使 `u,v` 断开的情况

##### `forest()`
返回删桥缩点后的桥森林
成员：
```cpp
Forest::n
```
EBCC 数量
```cpp
Forest::edges[i] = {a, b, id}
```
表示 EBCC `a,b` 之间存在一条桥，对应原图边 `id`
```cpp
Forest::adj[a]
```
中的：
```cpp
{b, id}
```
表示森林相邻分量以及原图桥编号
```cpp
Forest::siz[a]
```
分量 `a` 包含的原图节点数
```cpp
Forest::cnte[a]
```
分量内部的原图边数
#### 常见用法
##### 求全部桥
```cpp
UndirectedLowlink low(n);
for (int i = 0; i < m; ++ i) {
    int u, v;
    cin >> u >> v;
    low.add_edge(u, v);
}
low.build();
for (int id = 0; id < low.edges.size(); ++ id) {
    if (!low.bridge[id]) continue;
    auto [u, v] = low.edges[id];
    // 原图边 id：u - v 是桥
}
```
##### 求全部割点
```cpp
low.build();
for (int u : views::iota(0, n)) {
    if (low.cut[u]) {
        // u 是割点
    }
}
```
##### 判断是否属于同一个边双
```cpp
low.build();
if (low.same_ebcc(u, v)) {
    // u、v 位于同一个 EBCC
}
```
##### 遍历所有 EBCC
```cpp
low.build();
for (int c : views::iota(0, low.cnt)) {
    for (int u : low.comp[c]) {
        // 原图节点 u 属于 EBCC c
    }
}
```
##### 建立桥森林
```cpp
auto forest = low.forest();
for (int u : views::iota(0, forest.n)) {
    for (auto [v, id] : forest.adj[u]) {
        // EBCC u -- v
        // 对应原图桥 id
    }
}
```
若原图连通，压缩后是一棵树；原图不连通时是一片森林
#### 注意事项
##### 父边而不是父点
无向图 Tarjan 最重要的细节是：
```cpp
if (id == parent_edge) continue;
```
不能写成：
```cpp
if (v == parent) continue;
```
例如存在两条平行边：
```text
u ===== v
```
DFS 使用其中一条作为树边时，另一条仍然是一条返祖边
如果按父节点跳过，会把两条边全部跳过，错误地把树边判成桥
##### 重边与自环
当前版本完整支持：
* 非连通图
* 重边
* 自环
* 孤立点
平行边中的任意一条都不可能单独成为桥
自环：
* 不会成为桥
* 不影响割点
* 属于所在 EBCC 内部边
* 在 `Forest::cnte` 中计数一次
孤立点本身构成一个 EBCC
##### 递归深度
Lowlink 使用递归 DFS
理论复杂度虽然只有：
$$
O(n+m)
$$
但极长链图的递归深度可以达到：
$$
O(n)
$$
若评测栈空间特别严格，需要改为显式栈版本；普通竞赛环境下递归 Tarjan 通常代码更短、更可靠
#### 复杂度
设点数为 $n$，边数为 $m$
`add_edge()`：
$$
O(1)
$$
Lowlink：
$$
O(n+m)
$$
删除桥后的 EBCC 染色：
$$
O(n+m)
$$
所以 `build()` 总计：
$$
O(n+m)
$$
`same_ebcc()`：
$$
O(1)
$$
`forest()`：
$$
O(n+m)
$$
总空间：
$$
O(n+m)
$$
