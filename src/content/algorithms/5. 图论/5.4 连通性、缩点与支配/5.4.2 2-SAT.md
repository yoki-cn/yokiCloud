### 2-SAT
---
依赖前面的 `SCC`
要求该 `SCC` 的缩点编号满足对于不同 SCC 间的边 `x -> y`
$$
bel[x]>bel[y]
$$
也就是编号从汇 SCC 向源 SCC递增
```cpp
struct TwoSAT {
    int n;
    SCC scc;
    explicit TwoSAT(int n_) : n(n_), scc(2 * n) {}
    int lit(int x, bool value) const { return 2 * x + value; }
    int neg(int p) const { return p ^ 1; }
    // ===== 基础二元子句 =====
    // (x == xv) OR (y == yv)
    void add_or(int x, bool xv, int y, bool yv) {
        int a = lit(x, xv), b = lit(y, yv);
        scc.add_edge(neg(a), b);
        scc.add_edge(neg(b), a);
    }
    // (x == xv) -> (y == yv)
    void imply(int x, bool xv, int y, bool yv) {
        add_or(x, !xv, y, yv);
    }
    // x == value
    void set_value(int x, bool value) {
        scc.add_edge(lit(x, !value), lit(x, value));
    }
    // x == y
    void equal(int x, int y) {
        add_or(x, false, y, true);
        add_or(x, true, y, false);
    }
    // x != y
    void different(int x, int y) {
        add_or(x, true, y, true);
        add_or(x, false, y, false);
    }
    // 禁止 (x == xv) 与 (y == yv) 同时成立
    void forbid(int x, bool xv, int y, bool yv) { add_or(x, !xv, y, !yv); }
    optional<vector<char>> solve() {
        scc.build();
        vector<char> ans(n);
        for (int x : views::iota(0, n)) {
            int f{ scc.bel[lit(x, false)] }, t{ scc.bel[lit(x, true)] };
            if (f == t) return nullopt;
            ans[x] = t < f;
        }
        return ans;
    }
};
```
#### 建图原理
每个布尔变量 `x` 拆成两个文字节点
```cpp
lit(x, false) = 2 * x;
lit(x, true)  = 2 * x + 1;
```
相反文字只需
```cpp
p ^ 1
```
##### 二元 OR
约束
$$
a\lor b
$$
等价于
$$
\lnot a\rightarrow b
$$
和
$$
\lnot b\rightarrow a
$$
因此
```cpp
add_or(x, xv, y, yv);
```
表示
$$
(x=xv)\lor(y=yv)
$$
##### 无解条件
若某个变量的真文字与假文字处于同一个 SCC
$$
bel(x=false)=bel(x=true)
$$
则两个状态能够互相推出，公式无解
反之一定存在可行赋值
#### 接口说明
##### `add_or(x,xv,y,yv)`
加入
$$
(x=xv)\lor(y=yv)
$$
常见对应关系

| 约束                   | 调用                           |
| -------------------- | ---------------------------- |
| $x\lor y$            | `add_or(x, true, y, true)`   |
| $\lnot x\lor y$      | `add_or(x, false, y, true)`  |
| $x\lor\lnot y$       | `add_or(x, true, y, false)`  |
| $\lnot x\lor\lnot y$ | `add_or(x, false, y, false)` |
##### `imply(x,xv,y,yv)`
加入
$$
(x=xv)\rightarrow(y=yv)
$$
例如
```cpp
sat.imply(x, true, y, false);
```
表示
$$
x\rightarrow\lnot y
$$
##### `set_value(x,value)`
强制
$$
x=value
$$
例如
```cpp
sat.set_value(x, true);
```
##### `equal(x,y)`
加入
$$
x=y
$$
##### `different(x,y)`
加入
$$
x\ne y
$$
也就是两者恰好一个为真
##### `forbid(x,xv,y,yv)`
禁止两个选择同时发生
$$
\lnot((x=xv)\land(y=yv))
$$
等价于
$$
(x\ne xv)\lor(y\ne yv)
$$
这是“每个物品二选一 + 某两个方案冲突”模型中最常用的接口之一
##### `solve()`
返回
```cpp
optional<vector<char>>
```
无解为 `nullopt`
否则 `ans[x]` 为变量 `x` 的一组可行赋值
```cpp
ans[x] == 0 // false
ans[x] == 1 // true
```
#### 为什么赋值写成 `t < f`
当前 `SCC` 板子的编号满足缩点边
$$
x\rightarrow y
$$
时
$$
x>y
$$
即编号越小越靠近汇点
因此对变量 `x`
```cpp
ans[x] = bel[true] < bel[false];
```
即可取得一组可行值
如果以后换成 SCC 编号方向相反的实现，这里的比较也必须反转
#### 常见建模
##### 至少一个为真
$$
x\lor y
$$
```cpp
sat.add_or(x, true, y, true);
```
##### 不能同时为真
$$
\lnot(x\land y)
$$
```cpp
sat.forbid(x, true, y, true);
```
等价于
```cpp
sat.add_or(x, false, y, false);
```
##### 不能同时选择两个指定方案
`x == xv` 与 `y == yv` 不能同时发生
```cpp
sat.forbid(x, xv, y, yv);
```
##### 二者相同
```cpp
sat.equal(x, y);
```
表示
$$
x=y
$$
##### 二者不同
```cpp
sat.different(x, y);
```
表示
$$
x\ne y
$$
##### 单向依赖
若选择方案 `(x == xv)` 就必须选择 `(y == yv)`
```cpp
sat.imply(x, xv, y, yv);
```
#### 完整示例
要求
* `x0` 或 `x1` 至少一个为真
* `x0=true` 时必须 `x2=false`
* `x1` 与 `x2` 不同
* 强制 `x2=false`
```cpp
TwoSAT sat(3);
sat.add_or(0, true, 1, true);
sat.imply(0, true, 2, false);
sat.different(1, 2);
sat.set_value(2, false);

auto ans = sat.solve();

if (!ans) {
    cout << "IMPOSSIBLE\n";
} else {
    for (int x : views::iota(0, 3)) cout << int((*ans)[x]) << " \n"[x == 2];
}
```
##### 每个物品二选一
规定
```text
choice[i] = false：方案 0
choice[i] = true ：方案 1
```
若两个指定选择不能同时发生
```cpp
for (auto [a, av, b, bv] : conflicts) sat.forbid(a, av, b, bv);
```
求解
```cpp
auto choice = sat.solve();
if (!choice) {
    // 无合法选择
}
```
#### 注意事项
* `TwoSAT(n)` 表示恰有 `n` 个布尔变量
* 变量编号为 `[0,n)`
* 一般使用者只需要 `add_or/imply/set_value/equal/different/forbid`
* 不再公开单边 `imply_node()`，避免漏加逆否边导致建图错误
* `solve()` 后底层 SCC 已完成构建，不能继续增加约束
* 若需要修改约束，应重新构造 `TwoSAT`
* 2-SAT 只能直接处理每个子句最多两个文字的 CNF
* 三个变量的 `a || b || c` 不能直接拆成若干二元 OR
* 大集合的“至多一个为真”若直接两两 `forbid()` 需要 $O(k^2)$ 个约束，可按题意引入辅助变量做线性编码
* 底层 Tarjan SCC 若使用递归实现，超深 implication graph 仍需注意递归栈
#### 复杂度
设变量数为 $n$，加入的 implication graph 边数为 $m$
建图空间
$$
O(n+m)
$$
SCC 求解
$$
O(n+m)
$$
构造答案
$$
O(n)
$$
因此总时间复杂度
$$
O(n+m)
$$
总空间复杂度
$$
O(n+m)
$$
