### 点双连通分量（VBCC）与圆方森林
---
```cpp
struct VBCC {
    struct Edge { int u, v; };
    int n, timer{}, cnt{};
    vector<Edge> edges;
    vector<vector<int>> adj;
    vector<int> dfn, low, stk;
    vector<vector<int>> comp, belong;
    vector<char> cut;
    bool built{};
    explicit VBCC(int n_) : n(n_), adj(n), dfn(n), low(n), belong(n), cut(n) { stk.reserve(n); }
    int add_edge(int u, int v) {
        assert(!built && u != v);
        int id = edges.size();
        edges.push_back({u, v});
        adj[u].push_back(id);
        adj[v].push_back(id);
        return id;
    }
private:
    int other(int id, int u) const {
        auto [x, y] = edges[id];
        return x ^ y ^ u;
    }
    // ===== Tarjan 核心 =====
    void dfs(int u, int parent_edge) {
        dfn[u] = low[u] = ++ timer;
        stk.push_back(u);
        for (int id : adj[u]) {
            if (id == parent_edge) continue;
            int v{ other(id, u) };
            if (!dfn[v]) {
                dfs(v, id);
                low[u] = min(low[u], low[v]);
                if (low[v] >= dfn[u]) {
                    comp.push_back({u});
                    while (true) {
                        int x{ stk.back() };
                        stk.pop_back();
                        comp.back().push_back(x);
                        if (x == v) break;
                    }
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }
public:
    int build() {
        if (built) return cnt;
        for (int s : views::iota(0, n)) {
            if (dfn[s]) continue;
            if (adj[s].empty()) {
                dfn[s] = low[s] = ++ timer;
                comp.push_back({s});
            } else {
                dfs(s, -1);
                stk.clear();
            }
        }
        cnt = comp.size();
        for (int cid : views::iota(0, cnt)) {
            for (int u : comp[cid]) belong[u].push_back(cid);
        }
        for (int u : views::iota(0, n)) cut[u] = belong[u].size() > 1;
        built = true;
        return cnt;
    }
    // ===== 圆方森林：若不需要树上处理，可以删除 =====
    vector<vector<int>> block_cut_forest() const {
        assert(built);
        vector<vector<int>> tr(n + cnt);
        for (int cid : views::iota(0, cnt)) {
            int b{ n + cid };
            for (int u : comp[cid]) {
                tr[u].push_back(b);
                tr[b].push_back(u);
            }
        }
        return tr;
    }
};
```
#### 接口说明
##### 定义
本板采用竞赛中常见的点双定义
- 一个桥及其两个端点构成一个大小为 $2$ 的 VBCC
- 一个孤立点单独构成大小为 $1$ 的 VBCC
- 一个割点可以同时属于多个 VBCC
- 两个不同 VBCC 至多共享一个点，共享点一定是割点
- 每条非自环无向边恰好属于一个 VBCC
因此不能像 EBCC 一样给每个点维护唯一的 `bel[u]`，而应使用
```cpp
belong[u]
```
记录点 `u` 所属的全部 VBCC
##### `add_edge(u,v)`
加入一条无向边并返回边编号
```cpp
int id = vbcc.add_edge(u, v);
```
点和边均为 `0base`
允许
- 重边
- 非连通图
当前版本不接受自环
```cpp
assert(u != v);
```
每条无向边只调用一次 `add_edge()`，内部会自动加入两个方向
##### `build()`
```cpp
int cnt = vbcc.build();
```
完成
- `dfn / low`
- 全部 VBCC
- 每个点所属 VBCC
- 割点判断
返回 VBCC 数量
构建后不能继续 `add_edge()`
##### `comp[cid]`
第 `cid` 个 VBCC 包含的原图节点
```cpp
for (int u : vbcc.comp[cid]) {}
```
##### `belong[u]`
节点 `u` 所属的全部 VBCC 编号
```cpp
for (int cid : vbcc.belong[u]) {}
```
普通点通常满足
$$|belong[u]|=1$$
割点满足
$$|belong[u]|\ge2$$
##### `cut[u]`
节点 `u` 是否为割点
当前实现直接利用
$$u\text{ 是割点}\iff |belong[u]|>1$$
因此 Tarjan 主体中不再需要单独维护根节点儿子数
##### `block_cut_forest()`
建立圆方森林
编号约定
- `[0,n)` 为原图圆点
- `[n,n+cnt)` 为方点
- 方点 `n + cid` 对应 `comp[cid]`
若原图节点 `u` 属于 VBCC `cid`，圆方森林中加入
$$u\leftrightarrow n+cid$$
调用
```cpp
auto tr = vbcc.block_cut_forest();
```
原图连通时得到一棵圆方树，原图不连通时得到圆方森林
#### Tarjan 原理
DFS 中维护
- `dfn[u]`：节点 `u` 的 DFS 时间戳
- `low[u]`：`u` 的 DFS 子树通过至多一条返祖边能到达的最小 `dfn`
对于 DFS 树边
$$u\rightarrow v$$
若
$$low[v]\ge dfn[u]$$
则 `v` 的 DFS 子树无法绕过 `u` 到达 `u` 的祖先
此时从点栈中不断弹出直到 `v`，再补上 `u`，恰好得到一个 VBCC
```cpp
comp.push_back({u});
while (true) {
    int x = stk.back();
    stk.pop_back();
    comp.back().push_back(x);
    if (x == v) break;
}
```
注意 `u` 本身不会在这里被弹出，因此同一个割点可以继续参与之后形成的其他 VBCC
#### 为什么使用点栈
原版本使用边栈，每得到一个 VBCC 后需要遍历块中所有边，再通过 `mark` 对端点去重
点栈可以直接得到块内节点
```text
树边满足 low[v] >= dfn[u]
→ 弹出栈顶节点直到 v
→ 加入 u
```
因此可以删除
- `estk`
- `mark`
- `make_comp()`
- 块内端点去重
代码更短，分量总复杂度仍为线性
#### 重边为什么安全
DFS 必须跳过**父边编号**
```cpp
if (id == parent_edge) continue;
```
不能按父节点跳过
```cpp
if (v == parent) continue; // 错误
```
例如存在两条平行边
```text
u ===== v
```
其中一条作为 DFS 树边，另一条仍然是返祖边，会使
$$low[v]\le dfn[u]$$
若按父节点跳过，会把第二条边也忽略
本实现按边编号处理，因此重边安全
#### 圆方森林性质
圆方森林是二分图
- 圆点表示原图节点
- 方点表示 VBCC
- 圆点与方点相连，当且仅当该原图节点属于该 VBC
任意原图简单路径经过的一系列 VBCC，可以转化成圆方森林中的唯一路径
因此很多一般无向图问题可以转成树上问题，例如
- 路径上是否经过某割点
- 两点路径涉及多少个点双
- 修改点权后的路径统计
- 圆方树 LCA
- HLD / 树形 DP
- 路径上的块信息维护
#### 注意事项
- VBCC 与 EBCC 不同，EBCC 中每个点只有唯一分量编号，VBCC 中割点可以属于多个分量
- 当前实现使用点栈，要求输入不含自环
- 若题目只关心不同节点之间的点双结构，可以读入时直接忽略 `u == v`
- 若题目明确要求自环所属块，应先确认题目对自环 VBCC 的定义，再单独处理
- 重边完整支持，父边必须按边编号跳过
- 孤立点会得到一个单点 VBCC
- 单条桥会得到一个包含两个端点的 VBCC
- `comp[cid]` 内节点顺序只与 DFS 和弹栈顺序有关
- `belong[u]` 中编号顺序没有拓扑或大小含义
- `build()` 只能真正执行一次，之后再次调用只返回已有 `cnt`
- 构建完成后不能继续加入边，多测时重新构造对象
- 圆方森林中的方点不是真实原图节点，树上统计原点数量或原点权值时必须区分圆点和方点
- 原图不连通时得到森林，LCA/HLD 应逐棵预处理，或按题意增加虚拟超级根
- 递归深度最坏为 $O(n)$，极深链图可能需要扩大程序栈或改成显式栈版本
#### 常见用法
##### 输出全部 VBCC
```cpp
VBCC vbcc(n);
for (int i = 0; i < m; ++ i) {
    int u, v;
    cin >> u >> v;
    -- u, -- v;
    if (u != v) vbcc.add_edge(u, v);
}
vbcc.build();
cout << vbcc.cnt << '\n';
for (const auto &vertices : vbcc.comp) {
    cout << vertices.size();
    for (int u : vertices) cout << ' ' << u + 1;
    cout << '\n';
}
```
##### 求全部割点
```cpp
vbcc.build();
for (int u : views::iota(0, n)) {
    if (vbcc.cut[u]) {
        // u 是割点
    }
}
```
##### 查询一个点属于哪些 VBCC
```cpp
vbcc.build();
for (int cid : vbcc.belong[u]) {
    // u 属于 comp[cid]
}
```
特别地
```cpp
bool is_cut = vbcc.belong[u].size() > 1;
```
与
```cpp
vbcc.cut[u]
```
等价
##### 建立圆方森林
```cpp
vbcc.build();
auto tr = vbcc.block_cut_forest();
for (int u : views::iota(0, int(tr.size()))) {
    if (u < n) {
        // 原图圆点 u
    } else {
        int cid = u - n;
        // 方点，对应 comp[cid]
    }
}
```
##### 给圆点和方点分别赋权
```cpp
auto tr = vbcc.block_cut_forest();
vector<i64> weight(tr.size());
for (int u : views::iota(0, n)) weight[u] = original_weight[u];
for (int cid : views::iota(0, vbcc.cnt)) {
    int b{ n + cid };
    weight[b] = vbcc.comp[cid].size();
}
```
##### 最小自测
```text
孤立点
0
=> {0}，无割点

单边
0 -- 1
=> {0,1}，无割点

三点链
0 -- 1 -- 2
=> {0,1}、{1,2}，1 是割点

三角形
0 -- 1
 \  /
   2
=> 一个 {0,1,2}，无割点

两个三角形共点
=> 两个 VBCC，共点属于两个块且是割点

两点间两条平行边
=> 一个 {0,1}，无割点
```
#### 复杂度
设原图有 $n$ 个点、$m$ 条非自环无向边
Tarjan：
$$O(n+m)$$
建立 `belong`：
$$O\left(\sum_C |C|\right)$$
点双连通分量的节点总出现次数满足
$$\sum_C |C|=O(n+m)$$
因此 `build()` 总时间复杂度为
$$O(n+m)$$
建立圆方森林：
$$O(n+m)$$
总空间复杂度：
$$O(n+m)$$
递归栈最坏：
$$O(n)$$
