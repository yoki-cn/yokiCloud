### 最小直径生成树
---
与普通 MST 的“最小总边权”目标不同，本算法用于解决：
> 在所有生成树中，使树的直径最小

依赖「最短路基础」中的：
```cpp
template<class T>
inline constexpr T INF = numeric_limits<T>::max() / 4;

template<class T>
vector<vector<T>> floyd(vector<vector<T>> dis);
```

```cpp
optional<i64> minimum_diameter_spanning_tree(
    int n, const vector<tuple<int, int, i64>> &edges) {
    if (n <= 1) return i64{};
    vector d(n, vector<i64>(n, INF<i64>));
    for (int u : views::iota(0, n)) d[u][u] = 0;
    for (auto [u, v, w] : edges) {
        assert(0 <= u && u < n);
        assert(0 <= v && v < n);
        assert(w >= 0);
        d[u][v] = min(d[u][v], w);
        d[v][u] = min(d[v][u], w);
    }
    d = floyd(move(d));
    if (ranges::any_of(d[0], [](i64 x) { return x == INF<i64>; })) return nullopt;
    // order[u]：所有点按 d[u][v] 从小到大排序。
    vector order(n, vector<int>(n));
    for (int u : views::iota(0, n)) {
        ranges::iota(order[u], 0);
        ranges::sort(order[u], {}, [&](int v) {
            return d[u][v];
        });
    }
    i64 ans{ INF<i64> };
    // ===== 绝对中心位于原图顶点 =====
    for (int u : views::iota(0, n)) {
        i64 ecc = d[u][order[u].back()];
        ans = min(ans, 2 * ecc);
    }
    // ===== 绝对中心位于原图边内部 =====
    for (auto [u, v, w] : edges) {
        int p{ n - 1 };
        for (int i = n - 2; i >= 0; -- i) {
            int a = order[u][i], b = order[u][p];
            if (d[v][a] <= d[v][b]) continue;
            __int128_t cur = (__int128_t)d[u][a] + d[v][b] + w;
            assert(cur <= numeric_limits<i64>::max());
            ans = min(ans, i64(cur));

            p = i;
        }
    }
    return ans;
}
```
#### 接口说明
```cpp
minimum_diameter_spanning_tree(n, edges)
```
边格式：
```cpp
{u, v, w}
```
表示一条无向边
返回：
* 图连通：所有生成树中最小可能直径
* 图不连通：`nullopt`
要求：
* 点编号 `0base`
* 边权非负
#### 与普通 MST 的区别
普通最小生成树优化：
$$
\sum_{e\in T}w_e
$$
而最小直径生成树优化：
$$
\max_{u,v\in V}d_T(u,v)
$$
两者没有包含关系
例如一棵总边权最小的 MST，其直径完全可能不是所有生成树中最小的
因此不能：
```text
先求 MST
再求该 MST 的直径
```
来解决 MDST
#### 原理
设图中的一个位置 $x$ 可以位于：
* 原图顶点
* 原图某条边内部
定义其离心率：
$$
ecc(x)=\max_{v\in V} d_G(x,v)
$$
图的**绝对中心**是使离心率最小的位置：
$$
R=\min_{x\in G}ecc(x)
$$
最小直径生成树满足：
$$
\boxed{D_{\min}=2R}
$$
因此问题转化成寻找图的绝对中心
##### 中心位于顶点
若中心就是点 `u`：
$$
2R=2\max_v d(u,v)
$$
因此直接枚举每个顶点
##### 中心位于边内部
考虑边：
$$
(u,v,w)
$$
中心距离 `u` 为 \(x\)，则一个点 `z` 到中心的最短距离为：
$$
\min
\left(
d(u,z)+x,\;
d(v,z)+w-x
\right)
$$
需要求：
$$
\min_{0\le x\le w}
\max_z
\min
\left(
d(u,z)+x,\;
d(v,z)+w-x
\right)
$$
将所有点按：
$$
d(u,z)
$$
排序后，可以线性扫描可能发生最远点切换的位置
当两个控制点分别为 `a,b` 时，对应的两倍半径为：
$$
d(u,a)+d(v,b)+w
$$
因此每条边只需要：
$$
O(n)
$$
完成内部中心枚举
#### 注意事项
* 要求无向图
* 要求非负边权，以保证距离具有通常的网络几何意义
* 支持重边；建 Floyd 矩阵时自动保留最小权值
* 图不连通时不存在生成树，返回 `nullopt`
* 返回的是**直径值**，不是半径
* 绝对中心可能位于边的内部，因此不能只枚举顶点中心
* 中心位置可能是半整数，但最终生成树直径仍按照原边权单位返回，不需要自行除以 `2`
* 当前版本不恢复具体生成树
* 若需要方案，可以记录取得最优值的顶点或边内中心，再按该中心构造最短路径树
* 所有最短距离及最终直径必须能够存入 `i64`
#### 常见用法
```cpp
vector<tuple<int, int, i64>> edges;
for (int i = 0; i < m; ++ i) {
    int u, v;
    i64 w;
    cin >> u >> v >> w;
    edges.push_back({ u, v, w });
}
auto ans = minimum_diameter_spanning_tree(n, edges);
if (!ans) {
    cout << "Disconnected\n";
} else {
    cout << *ans << '\n';
}
```
例如：
```cpp
vector<tuple<int, int, i64>> edges{
    { 0, 1, 4 },
    { 1, 2, 3 },
    { 0, 2, 10 }
};
auto ans = minimum_diameter_spanning_tree(3, edges);
```
答案为：$7$
#### 复杂度
Floyd：
$$
O(n^3)
$$
预处理每个点的距离顺序：
$$
O(n^2\log n)
$$
枚举每条原边：
$$
O(mn)
$$
所以总复杂度：
$$
O(n^3+n^2\log n+mn)
$$

对于简单图：
$$
m=O(n^2)
$$
因此可简写为：
$$
O(n^3)
$$
空间复杂度：
$$
O(n^2)
$$
