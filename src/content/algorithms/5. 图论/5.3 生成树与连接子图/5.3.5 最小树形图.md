### Chu–Liu / Edmonds 最小树形图
---
```cpp
struct DirectedMSTEdge {
    int u, v;
    i64 w;
};
optional<i64> directed_mst(
    int n, int root,
    const vector<DirectedMSTEdge> &input) {
    using i128 = __int128_t;
    struct Edge {
        int u, v;
        i128 w;
    };
    const i128 INF = i128(1) << 120;
    vector<Edge> edges;
    edges.reserve(input.size());
    for (auto [u, v, w] : input) {
        edges.push_back({u, v, w});
    }
    i128 ans{ 0 };
    while (true) {
        // ===== 1. 每个非根节点选择最小入边 =====
        vector<i128> in(n, INF);
        vector<int> pre(n, -1);
        for (auto [u, v, w] : edges) {
            if (u != v && w < in[v]) {
                in[v] = w;
                pre[v] = u;
            }
        }
        in[root] = 0;
        if (ranges::any_of(in, [&](i128 x) { return x == INF; })) return nullopt;
        for (i128 w : in) ans += w;
        // ===== 2. 找最小入边形成的环 =====
        int cnt{ 0 };
        vector<int> id(n, -1), vis(n, -1);
        for (int s : views::iota(0, n)) {
            int v{ s };
            while (v != root && vis[v] != s && id[v] == -1) {
                vis[v] = s;
                v = pre[v];
            }
            if (v != root && id[v] == -1) {
                for (int u = pre[v]; u != v; u = pre[u]) {
                    id[u] = cnt;
                }
                id[v] = cnt ++;
            }
        }
        if (cnt == 0) break;
        // ===== 3. 缩环 =====
        for (int v : views::iota(0, n)) {
            if (id[v] == -1) id[v] = cnt ++;
        }
        vector<Edge> next;
        next.reserve(edges.size());
        for (auto [u, v, w] : edges) {
            int x{ id[u] }, y{ id[v] };
            if (x == y) continue;
            next.push_back({ x, y, w - in[v] });
        }
        root = id[root];
        n = cnt;
        edges = move(next);
    }
    assert(ans >= numeric_limits<i64>::min());
    assert(ans <= numeric_limits<i64>::max());
    return i64(ans);
}
```
#### 接口说明
```cpp
directed_mst(n, root, edges)
```
求以 `root` 为根的最小权**出树形图**
要求最终选出 `n - 1` 条有向边，使得：
* 根 `root` 入度为 `0`
* 每个其他节点恰有一条入边
* 从 `root` 能到达所有节点
并使总边权最小
返回：
* 存在：最小总边权
* 不存在：`nullopt`
Chu–Liu/Edmonds 正是有向图上最小生成树问题的经典算法
#### 原理
每轮先为每个非根节点选取权值最小的入边
如果这些边不构成环，那么每个非根节点都有唯一父边，并已经得到最优树形图
若出现环 $C$，环中不能把所有边都保留，否则无法形成树
因此将整环缩成一个新节点
假设外部边：
$$
u\rightarrow v,\qquad v\in C
$$
原权为 $w$
由于当前已经把 `v` 的最小入边：
$$
in[v]
$$
计入答案，所以缩点后的边权调整为：
$$
w-in[v]
$$
若之后最终选择这条外部入边，就相当于用它替换掉环中 `v` 原来的最小入边
不断缩环直到不存在环即可
#### 注意事项
* 这是**有根有向生成树**，不是无向 MST。
* 当前版本选择的是每个非根点的一条**入边**，因此最终方向从根向外
* 如果题目要求所有节点最终指向根的入树形图，可以先把所有边反向
* 边权可以为负
* 自环会被忽略
* 重边可以直接保留
* 根的入边永远不会被选取
* 某轮存在非根节点没有任何入边时，说明不存在合法树形图，返回 `nullopt`
* 只要求“每个点有入边”并不足以保证原图可从根到达，但缩环过程最终会把与根隔离的封闭部分暴露成没有外部入边的缩点，因此仍会正确判无解
* 当前版本只返回最小权值，不恢复具体边集
* 内部调整权值使用 `i128`，避免连续缩点时 `w - in[v]` 溢出；最终答案仍要求能放入 `i64`
#### 常见用法
```cpp
vector<DirectedMSTEdge> edges;
for (int i = 0; i < m; ++ i) {
    int u, v;
    i64 w;
    cin >> u >> v >> w;
    edges.push_back({u, v, w});
}
auto ans = directed_mst(n, root, edges);
if (!ans) {
    cout << "Impossible\n";
} else {
    cout << *ans << '\n';
}
```
#### 复杂度
本实现每次缩环都线性扫描当前边集，而每轮至少缩掉一个环，因此经典朴素实现上界为：
$$
O(nm)
$$
空间复杂度：
$$
O(n+m)
$$
更高级的 Edmonds/Tarjan 实现可以达到更好的复杂度，但竞赛中只有在朴素 $O(nm)$ 明显无法通过时才值得使用
