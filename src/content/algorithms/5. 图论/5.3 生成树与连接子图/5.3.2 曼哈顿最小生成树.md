### 曼哈顿最小生成树
---
```cpp
struct ManhattanMST {
    struct Point {
        i64 x, y;
    };
    struct Edge {
        int u, v;
        i64 w;
    };
private:
    using i128 = __int128_t;
    struct WorkPoint {
        i128 x, y;
    };
    static i64 distance(const Point &a, const Point &b) {
        i128 dx{ i128(a.x) - b.x };
        i128 dy{ i128(a.y) - b.y };
        if (dx < 0) dx = -dx;
        if (dy < 0) dy = -dy;
        i128 d{ dx + dy };
        assert(d <= numeric_limits<i64>::max());
        return i64(d);
    }
public:
    // ===== O(n) 候选边生成 =====
    static vector<Edge> candidates(const vector<Point> &points) {
        int n = points.size();
        vector<WorkPoint> p(n);
        for (int i : views::iota(0, n)) {
            p[i] = { points[i].x, points[i].y };
        }
        vector<int> order(n);
        ranges::iota(order, 0);
        vector<Edge> edges;
        edges.reserve(4 * n);
        for (int dir = 0; dir < 4; ++ dir) {
            ranges::sort(order, {}, [&](int i) {
                return pair{ p[i].x + p[i].y, p[i].x };
            });
            map<i128, int> sweep;
            for (int i : order) {
                i128 key{ -p[i].y };
                for (auto it = sweep.lower_bound(key);
                     it != sweep.end();) {
                    int j{ it->second };
                    if (p[i].x - p[j].x < p[i].y - p[j].y) break;
                    edges.push_back({ i, j, distance(points[i], points[j]) });
                    it = sweep.erase(it);
                }
                sweep[key] = i;
            }
            for (auto &q : p) {
                if (dir & 1) q.x = -q.x;
                else swap(q.x, q.y);
            }
        }
        return edges;
    }
    // ===== 直接求 Manhattan MST 权值 =====
    static i64 mst_weight(const vector<Point> &points) {
        int n = points.size();
        if (n <= 1) return 0;
        auto edges = candidates(points);
        ranges::sort(edges, {}, &Edge::w);
        DSU dsu(n);
        i64 ans = 0;
        for (auto [u, v, w] : edges) {
            if (!dsu.unite(u, v)) continue;
            ans += w;
            if (dsu.count() == 1) break;
        }
        assert(dsu.count() == 1);
        return ans;
    }
};
```
#### 接口说明
##### `Point`
点编号直接等于其在输入 `vector` 中的下标：
```cpp
vector<ManhattanMST::Point> p(n);
```
不再需要额外维护 `Point::id`，从而避免坐标变换后原编号映射错误
##### `candidates(points)`
返回一个只含
$$O(n)$$
条边的候选边集合，并保证其中存在一棵完整的曼哈顿 MST
因此无需建立包含
$$\Theta(n^2)$$
条边的完全图
##### `mst_weight(points)`
直接：
1. 生成候选边
2. 按边权排序
3. Kruskal
返回曼哈顿 MST 权值
#### 原理
二维曼哈顿距离：
$$d(i,j)=|x_i-x_j|+|y_i-y_j|$$
对于每个点，只需要考虑八个方向区域中的最近候选点
利用对称性，可以通过四次坐标变换覆盖全部八个方向：
* 交换 $x,y$
* 翻转 $x$
* 再交换
* 再翻转
每轮按：
$$x+y$$
排序，并用有序表维护扫描线上的有效点
每个点在一轮扫描中只会被插入、删除有限次，因此每轮生成线性数量的候选边
#### 注意事项
* 这是**二维曼哈顿距离** MST
* 点编号自动使用输入下标 `0..n-1`
* 重合点完全允许，候选边权可以为 `0`
* `candidates()` 可能生成重复边；Kruskal 会自然忽略，不需要额外去重
* 候选边总数为 $O(n)$，实际至多常数倍于 `n`
* 内部坐标变换使用 `i128`，避免 `x+y`、取负和坐标差溢出
* 最终曼哈顿距离及 MST 总权值仍要求能够存入 `i64`
* 不要用这份候选边处理欧氏距离；欧氏 MST 应使用完全图 Prim 或 Delaunay 三角剖分
#### 常见用法
##### 直接求 MST
```cpp
vector<ManhattanMST::Point> p(n);
for (auto &[x, y] : p) {
    cin >> x >> y;
}
cout << ManhattanMST::mst_weight(p) << '\n';
```
##### 只生成候选边
如果还要处理 MST 上第 `k` 大边、边分类等其他问题：
```cpp
auto edges = ManhattanMST::candidates(p);
ranges::sort(edges, {}, &ManhattanMST::Edge::w);
DSU dsu(n);
for (auto [u, v, w] : edges) {
    if (!dsu.unite(u, v)) continue;
    // 当前边属于所构造的某棵 Manhattan MST
}
```
#### 复杂度
四次扫描，每次排序和 `map` 操作：
$$O(n\log n)$$
产生候选边：
$$O(n)$$
随后 Kruskal：
$$O(n\log n)$$
因此总时间复杂度：
$$O(n\log n)$$
空间复杂度：
$$O(n)$$
