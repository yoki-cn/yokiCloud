### 一般图 Steiner Tree
---
依赖「最短路基础」中的：
```cpp
template<class T>
inline constexpr T INF = numeric_limits<T>::max() / 4;
template<class T = i64>
using WGraph = vector<vector<pair<int, T>>>;
```

```cpp
optional<i64> steiner_tree(const WGraph<i64> &g, vector<int> term) {
    ranges::sort(term);
    term.erase(unique(term.begin(), term.end()), term.end());
    int n = g.size(), k = term.size();
    if (k <= 1) return i64{};
    assert(k < 31);
    int full{ 1 << k };
    vector dp(full, vector<i64>(n, INF<i64>));
    for (int i = 0; i < k; ++ i) {
        dp[1 << i][term[i]] = 0;
    }
    using State = pair<i64, int>;
    for (int mask = 1; mask < full; ++ mask) {
        // ===== 1. 合并两个终端集合 =====
        //
        // 固定最低位属于 sub，只枚举每个无序划分一次。
        int low{ mask & -mask };
        for (int sub = (mask - 1) & mask; sub; sub = (sub - 1) & mask) {
            if (!(sub & low)) continue;
            int other{ mask ^ sub };
            for (int v : views::iota(0, n)) {
                if (dp[sub][v] == INF<i64> || dp[other][v] == INF<i64>) continue;
                chmin(dp[mask][v], dp[sub][v] + dp[other][v]);
            }
        }
        // ===== 2. 多源 Dijkstra 闭包 =====
        //
        // 已经连接 mask 中终端并最终汇合于 u，
        // 再沿最短路移动汇合点
        priority_queue<State, vector<State>, greater<>> q;
        for (int v : views::iota(0, n)) {
            if (dp[mask][v] != INF<i64>) {
                q.push({dp[mask][v], v});
            }
        }
        while (!q.empty()) {
            auto [d, u] = q.top();
            q.pop();
            if (d != dp[mask][u]) continue;
            for (auto [v, w] : g[u]) {
                if (d > INF<i64> - w || d + w >= dp[mask][v]) continue;
                dp[mask][v] = d + w;
                q.push({dp[mask][v], v});
            }
        }
    }
    i64 ans = *ranges::min_element(dp.back());
    if (ans == INF<i64>) return nullopt;
    return ans;
}
```
#### 接口说明
给定一个无向非负权图，以及少量终端点：
```cpp
term = {t0, t1, ..., tk-1};
```
求总边权最小的连通子图，使全部终端点连通
允许额外使用非终端点，这些额外节点就是 Steiner 点。Steiner Tree 与普通 MST 的区别正是在于只要求指定终端连通，并允许借助其他点降低总代价
##### 状态
定义：
$$
dp[S][v]
$$
表示连接终端集合 `S`，并使当前连通子图包含节点 `v` 的最小代价
##### 初始化
对于第 `i` 个终端：
$$
dp[2^i][t_i]=0
$$
##### 集合合并
若两个终端集合最终都在 `v` 汇合：
$$
dp[S][v]
=
\min_{A\subset S}
\left(
dp[A][v]+dp[S\setminus A][v]
\right)
$$
代码固定 `mask` 的最低位必须位于 `sub`，因此每种无序划分只枚举一次
##### 最短路闭包
合并结束后，还可以沿图中边把汇合位置从 `u` 移动到其他节点：
$$
dp[S][v]
\le
dp[S][u]+w(u,v)
$$
因此对每个 `mask` 执行一次多源 Dijkstra
#### 返回值
```cpp
auto ans = steiner_tree(g, term);
```
* 存在连接所有终端的方案：返回最小代价
* 无法全部连通：返回 `nullopt`
* `term` 为空或只有一个不同终端：返回 `0`
重复终端会自动去重
#### 注意事项
* 当前板子处理**无向图 Steiner Tree**
* 所有边权必须非负，因为每个状态使用 Dijkstra 做最短路闭包
* 零权边允许存在
* `k` 是指数复杂度的核心，真正限制不仅来自时间，还有：
$$
2^k n
$$
的 DP 内存
* 因此不能简单理解成“`k <= 20` 就一定能跑”；例如 `n` 很大时，`k = 20` 的内存已经完全不可接受
* 实战中通常是 `k` 很小，而 `n,m` 可以相对较大
* Steiner Tree 求的是最小**连通子图**，最优解在非负边权下可以取成树，因此称为 Steiner Tree
* 如果要求每组终端满足不同连接条件，通常需要在 `mask` 上增加合法性限制，而不是直接套完整终端集合
* 网格图无需单独写一份算法：把可走格子映射成图节点，按四邻接或八邻接建边即可
* 若边权允许负数，则“最小连通子图”本身还会涉及是否应该额外吸收负权结构，不能直接使用
#### 常见用法
```cpp
WGraph<i64> g(n);
auto add_edge = [&](int u, int v, i64 w) {
    g[u].push_back({v, w});
    g[v].push_back({u, w});
};
vector<int> terminal{a, b, c};
auto ans = steiner_tree(g, terminal);
if (!ans) {
    cout << "Impossible\n";
} else {
    cout << *ans << '\n';
}
```
##### 网格 Steiner Tree
只需要把每个可走格子编号：
```cpp
id[x][y]
```
然后对相邻格子建立无向边
终端格子的编号加入：
```cpp
term
```
算法主体无需修改
#### 复杂度
集合合并部分：
$$
O(3^k n)
$$
每个状态执行一次多源 Dijkstra：
$$
O\left(
2^k(n+m)\log n
\right)
$$
因此总时间复杂度：
$$
O\left(
3^k n
+
2^k(n+m)\log n
\right)
$$
DP 空间：
$$
O(2^k n)
$$
加图后的总空间：
$$
O(2^k n+m)
$$
