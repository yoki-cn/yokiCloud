### Euler 路与回路
---
使用非递归 Hierholzer，同时支持有向图和无向图
```cpp
struct EulerTrail {
    struct Arc {
        int to, id;
    };
    struct Result {
        vector<int> vertices, edges;
        bool is_circuit() const { return edges.empty() || vertices.front() == vertices.back(); }
    };
    int n, m{};
    bool directed;
    vector<vector<Arc>> g;
    vector<int> in, out, deg;
    EulerTrail(int n_, bool directed_) : n(n_), directed(directed_), g(n), in(n), out(n), deg(n) {}
    int add_edge(int u, int v) {
        int id{ m ++ };
        g[u].push_back({v, id});
        if (directed) ++ out[u], ++ in[v];
        else g[v].push_back({u, id}), ++ deg[u], ++ deg[v];
        return id;
    }
    optional<Result> solve() const {
        if (!m) {
            Result res;
            if (n) res.vertices.push_back(0);
            return res;
        }
        // ===== 度数条件与起点 =====
        int start{ -1 };
        if (directed) {
            int plus{}, minus{};
            for (int u : views::iota(0, n)) {
                int d = out[u] - in[u];
                if (d == 1) start = u, ++ plus;
                else if (d == -1) ++ minus;
                else if (d != 0) return nullopt;
            }
            if (!((plus == 1 && minus == 1) || (!plus && !minus))) return nullopt;
            if (!plus) {
                for (int u : views::iota(0, n)) if (out[u]) {
                    start = u;
                    break;
                }
            }
        } else {
            vector<int> odd;
            for (int u : views::iota(0, n)) if (deg[u] & 1) odd.push_back(u);
            if (odd.size() != 0 && odd.size() != 2) return nullopt;
            if (odd.size() == 2) start = odd[0];
            else {
                for (int u : views::iota(0, n)) if (deg[u]) {
                    start = u;
                    break;
                }
            }
        }
        // ===== 非递归 Hierholzer =====
        vector<int> it(n);
        vector<char> used(m);
        vector<pair<int, int>> stk{{start, -1}};
        Result res;
        while (!stk.empty()) {
            int u{ stk.back().first };
            while (it[u] < g[u].size() && used[g[u][it[u]].id]) ++ it[u];
            if (it[u] == g[u].size()) {
                auto [v, id] = stk.back();
                stk.pop_back();
                res.vertices.push_back(v);
                if (id != -1) res.edges.push_back(id);
            } else {
                auto [v, id] = g[u][it[u] ++];
                used[id] = true;
                stk.push_back({v, id});
            }
        }
        if (res.edges.size() != m) return nullopt;
        ranges::reverse(res.vertices);
        ranges::reverse(res.edges);
        return res;
    }
};
```
#### 接口说明
##### `EulerTrail(n, directed)`
```cpp
EulerTrail euler(n, false); // 无向图
EulerTrail euler(n, true);  // 有向图
```
点编号为 `[0,n)`
支持
* 重边
* 自环
* 非连通图输入
只有所有非零度边最终位于同一可行 Euler 部分时 `solve()` 才会成功
##### `add_edge(u,v)`
加入一条边并返回原边编号
```cpp
int id = euler.add_edge(u, v);
```
无向边也只调用一次
两个邻接方向共享同一个 `id`，因此 Hierholzer 不会把一条无向边使用两次
##### `solve()`
返回
```cpp
optional<EulerTrail::Result>
```
无解时为 `nullopt`
有解时
```cpp
res.vertices
```
是经过的点序列
```cpp
res.edges
```
是依次经过的原边编号
始终满足
$$
|vertices|=m+1
$$
$$
|edges|=m
$$
且第 `i` 条边连接
```cpp
vertices[i] -> vertices[i + 1]
```
有向图表示实际方向，无向图则表示本次 Euler 路使用该边的方向
##### `is_circuit()`
判断结果是否为 Euler 回路
```cpp
if (res.is_circuit()) {}
```
#### 存在条件
##### 无向图
忽略孤立点后必须连通，并且奇度点数量只能是 $0$ 或$2$
奇度点数为 `0` 时存在 Euler 回路
奇度点数为 `2` 时存在 Euler 路，两个奇度点分别为起点和终点
##### 有向图
Euler 回路要求所有非零度节点满足
$$
in(u)=out(u)
$$
Euler 路要求恰有一个起点满足
$$
out(u)=in(u)+1
$$
恰有一个终点满足
$$
in(v)=out(v)+1
$$
其余点满足
$$
in(x)=out(x)
$$
此外所有边必须能够被同一次 Hierholzer 遍历使用
本实现不额外跑连通性 DFS，而是在最后检查
```cpp
res.edges.size() == m
```
若有未遍历到的边直接返回 `nullopt`
#### 常见用法
##### 无向 Euler 路
```cpp
EulerTrail euler(n, false);
for (int i = 0; i < m; ++ i) {
    int u, v;
    cin >> u >> v;
    -- u, -- v;
    euler.add_edge(u, v);
}
auto ans = euler.solve();
if (!ans) {
    cout << "No Solution\n";
} else {
    for (int u : ans->vertices) cout << u + 1 << ' ';
}
```
##### 输出边编号
```cpp
auto ans = euler.solve();
if (ans) {
    for (int id : ans->edges) {
        // 第 id 条输入边
    }
}
```
##### 恢复无向边实际经过方向
```cpp
auto ans = euler.solve();
if (ans) {
    for (int i : views::iota(0, int(ans->edges.size()))) {
        int id = ans->edges[i];
        int u = ans->vertices[i];
        int v = ans->vertices[i + 1];
        // 原边 id 本次按 u -> v 使用
    }
}
```
#### 字典序
当前代码按邻接表已有顺序选择下一条边，不保证字典序
若题目要求字典序最小，可以在 `solve()` 前按题意排序每个邻接表
例如优先经过编号更小的终点
```cpp
for (auto &adj : euler.g) {
    ranges::sort(adj, [](auto a, auto b) {
        return pair{a.to, a.id} < pair{b.to, b.id};
    });
}
```
有重边时必须明确题目究竟比较点序列还是边编号序列
#### 注意事项
* 无向边只调用一次 `add_edge()`
* 自环在无向图中贡献度数 `2`
* `solve()` 不修改图，可以重复调用
* 空边图在 `n > 0` 时返回单点序列 `{0}`
* `n == 0` 且无边时返回空点序列，但仍视为成功
* 返回空 `optional` 才表示不存在 Euler 路
* 本板只处理纯有向图或纯无向图
* 混合图 Euler 定向需要额外的流量平衡建模，不应写进本板的覆盖范围
* Hierholzer 使用显式栈，不存在递归深度问题
#### 复杂度
每个邻接项只扫描一次，每条边只使用一次
$$
O(n+m)
$$
空间复杂度
$$
O(n+m)
$$
