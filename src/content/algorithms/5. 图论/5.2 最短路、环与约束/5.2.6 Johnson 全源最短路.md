### Johnson 全源最短路
---
**解决问题：** 在允许负边但不存在负环的稀疏有向图上求所有点对最短路
依赖「最短路」中的
```cpp
template<class T>
inline constexpr T INF = numeric_limits<T>::max() / 4;
template<class T = i64>
using WGraph = vector<vector<pair<int, T>>>;
```

```cpp
optional<vector<vector<i64>>> johnson(const WGraph<i64> &g) {
    using i128 = __int128_t;
    const i128 IINF = i128(1) << 120;
    int n = g.size();
    // ===== 1. Bellman-Ford 求势能 h =====
    // 等价于增加超级源 S，并加入 S -> v 权值 0
    vector<i128> h(n);
    for (int it = 0; it < n; ++ it) {
        bool changed{ false };
        for (int u : views::iota(0, n)) {
            for (auto [v, w] : g[u]) {
                i128 nd{ h[u] + w };
                if (nd >= h[v]) continue;
                h[v] = nd;
                changed = true;
                // 第 n 轮仍能松弛 => 存在负环
                if (it == n - 1) return nullopt;
            }
        }
        if (!changed) break;
    }
    // ===== 2. 每个源点跑重标后的 Dijkstra =====
    vector ans(n, vector<i64>(n, INF<i64>));
    using State = pair<i128, int>;
    for (int s : views::iota(0, n)) {
        vector<i128> dis(n, IINF);
        priority_queue<State, vector<State>, greater<>> q;
        dis[s] = 0;
        q.push({0, s});
        while (!q.empty()) {
            auto [d, u] = q.top();
            q.pop();
            if (d != dis[u]) continue;
            for (auto [v, w] : g[u]) {
                i128 nw{ i128(w) + h[u] - h[v] };
                assert(nw >= 0);
                i128 nd{ d + nw };
                if (nd >= dis[v]) continue;
                dis[v] = nd;
                q.push({nd, v});
            }
        }
        // ===== 3. 还原原图距离 =====
        for (int v : views::iota(0, n)) {
            if (dis[v] == IINF) continue;
            i128 d{ dis[v] - h[s] + h[v] };
            assert(numeric_limits<i64>::min() <= d && d <= numeric_limits<i64>::max());
            ans[s][v] = i64(d);
        }
    }
    return ans;
}
```
#### 原理
##### 超级源与势能
增加超级源 `S`
对每个原图节点加入
$$
S\to v,\qquad w=0
$$
然后从 `S` 跑 Bellman-Ford
记
$$
h[v]=dist(S,v)
$$
因为所有节点都有一条权值为 $0$ 的入边，所以初始直接令
```cpp
vector<i128> h(n);
```
也就是
$$
h[v]=0
$$
再对原图全部边做 Bellman-Ford，与显式建立超级源完全等价
这样还能检测**图中任意位置的负环**，而不只是某个原源点可达的负环
#### 重标边权
对原边
$$
u\to v
$$
权值为 $w(u,v)$
定义新权值
$$
w'(u,v)=w(u,v)+h[u]-h[v]
$$
Bellman-Ford 完成后满足最短路三角不等式
$$
h[v]\le h[u]+w(u,v)
$$
移项得到
$$
w(u,v)+h[u]-h[v]\ge0
$$
所以
$$
w'(u,v)\ge0
$$
此时整张图已经没有负边，可以从每个源点运行 Dijkstra
#### 为什么重标后最短路不变
考虑一条路径
$$
P=v_0\to v_1\to\cdots\to v_k
$$
重标后的路径长度为
$$
\sum_{i=0}^{k-1}\left(w(v_i,v_{i+1})+h[v_i]-h[v_{i+1}]\right)
$$
中间的势能全部抵消
$$
\begin{aligned}
w'(P)
&=\sum_{i=0}^{k-1}\left(w(v_i,v_{i+1})+h[v_i]-h[v_{i+1}]\right)\\
&=\sum_{i=0}^{k-1}w(v_i,v_{i+1})+h[v_0]-h[v_k]\\
&=w(P)+h[v_0]-h[v_k]
\end{aligned}
$$
对于固定起点 $s$ 和终点 $t$
$$
h[s]-h[t]
$$
是固定值
因此所有 $s\to t$ 路径只是统一增加同一个常数，最短路径不会改变
若重标后的距离为 $d'(s,t)$，原距离为
$$
d(s,t)=d'(s,t)-h[s]+h[t]
$$
对应代码
```cpp
i128 d = dis[v] - h[s] + h[v];
```
#### 接口
```cpp
auto dis = johnson(g);
```
##### 存在负环
```cpp
if (!dis) {
    // 图中存在负环
}
```
##### 正常情况
```cpp
i64 d = (*dis)[u][v];
```
若
```cpp
d == INF<i64>
```
表示 `u` 无法到达 `v`
否则就是原图中的最短距离
#### 常见用法
```cpp
WGraph<i64> g(n);
for (int i = 0; i < m; ++ i) {
    int u, v;
    i64 w;
    cin >> u >> v >> w;
    -- u, -- v;
    g[u].push_back({v, w});
}
auto dis = johnson(g);
if (!dis) {
    cout << "Negative Cycle\n";
} else {
    for (int s : views::iota(0, n)) {
        for (int t : views::iota(0, n)) {
            if ((*dis)[s][t] == INF<i64>) {
                // s 无法到达 t
            } else {
                cout << (*dis)[s][t] << '\n';
            }
        }
    }
}
```
#### 只需要逐行答案时
完整 APSP 矩阵需要
$$
O(n^2)
$$
空间
如果题目只需要每个源点算完后立即统计答案，不需要保存完整矩阵，可以改成逐源处理
核心只需把
```cpp
vector ans(n, vector<i64>(n, INF<i64>));
```
删除，然后在每次 Dijkstra 结束后处理当前 `s`
```cpp
for (int s : views::iota(0, n)) {
    // Dijkstra ...
    for (int v : views::iota(0, n)) {
        if (dis[v] == IINF) {
            // s -> v 不可达
            continue;
        }
        i128 d = dis[v] - h[s] + h[v];
        // 立即统计 d
    }
}
```
这样除图和 Dijkstra 工作数组外，额外空间只需要
$$
O(n)
$$
#### 与 Floyd 的选型

| 条件          | 推荐                             |
| ----------- | ------------------------------ |
| 稠密图         | Floyd                          |
| $n$ 较小      | Floyd                          |
| 稀疏图且无负边     | 每个源点 Dijkstra                  |
| 稀疏图、有负边、无负环 | Johnson                        |
| 需要判断任意负环    | Johnson 的 Bellman-Ford 阶段也可以完成 |
Floyd 时间复杂度固定为
$$
O(n^3)
$$
Johnson 的优势主要来自
$$
m\ll n^2
$$
时 Dijkstra 只遍历实际存在的边
#### 为什么不用 SPFA 求势能
Johnson 第一阶段只需要一次 Bellman-Ford
理论复杂度稳定为
$$
O(nm)
$$
SPFA 虽然随机数据上可能更快，但可以退化到同级甚至出现很差的常数表现
直接使用 Bellman-Ford 更稳
#### 数值处理
内部的
* 势能 `h`
* 重标边权
* Dijkstra 距离
* 距离恢复
全部使用
```cpp
__int128_t
```
避免出现
```cpp
w + h[u] - h[v]
```
在 `i64` 中间过程溢出
最终接口仍返回
```cpp
vector<vector<i64>>
```
因此要求真实最短路答案能够放入 `i64`
若题目答案本身可能超过 `i64`，应直接把返回矩阵也改成 `i128`
#### 负环
如果第 $n$ 轮 Bellman-Ford 仍然能够松弛
```cpp
if (it == n - 1) return nullopt;
```
说明存在负环
因为超级源等价地可以到达全部节点，所以这里检测的是**整张图任意位置的负环**
有负环时某些最短距离可能不存在有限下界，因此 Johnson 直接返回失败
#### 自环与重边
重边可以直接保留
Dijkstra 与 Bellman-Ford 会自动选择更优边
自环也允许
若存在负自环
$$
u\to u,\qquad w<0
$$
它本身就是负环，Bellman-Ford 会返回 `nullopt`
非负自环不会影响结果
#### 快速回忆
```text
稀疏 APSP + 允许负边 + 无负环
    Johnson

1. 超级源 -> 所有点权值 0
   等价于 h 全部初始化 0

2. Bellman-Ford 求 h
   第 n 轮还能松弛 => 负环

3. 重标
   w' = w + h[u] - h[v]
   保证 w' >= 0

4. 每个源点 Dijkstra

5. 恢复
   d = d' - h[s] + h[v]
```
#### 注意事项
* 支持有向图，若是无向图需要自行加入两个方向
* 允许负边，不允许负环
* 支持重边和自环
* Bellman-Ford 的全零初始化等价于增加权值为 $0$ 的超级源
* 不应在原图存在负边时直接对每个源点跑 Dijkstra
* Dijkstra 必须使用重标后的非负边权
* 最终恢复距离时不能忘记 `-h[s]+h[v]`
* 内部使用 `i128` 防止重标过程溢出
* 若只需要统计每个源点的答案，不建议保存整个 $O(n^2)$ 距离矩阵
* 稠密图上通常直接使用 Floyd 更简单
#### 复杂度
Bellman-Ford
$$
O(nm)
$$
每个源点一次堆优化 Dijkstra
$$
O((n+m)\log n)
$$
共运行 $n$ 次
$$
O(n(n+m)\log n)
$$
因此严格总时间复杂度为
$$
O(nm+n(n+m)\log n)
$$
在通常的稀疏连通图中 $m=\Omega(n)$，常简写为
$$
O(nm\log n)
$$
若保存全部点对距离，空间复杂度为
$$
O(n^2+n+m)
$$
通常简写为
$$
O(n^2)
$$
若逐源处理答案，不保存距离矩阵，则空间复杂度为
$$
O(n+m)
$$
