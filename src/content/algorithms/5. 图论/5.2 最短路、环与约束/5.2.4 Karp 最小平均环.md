### Karp 最小平均环
---
```cpp
optional<ld>
minimum_mean_cycle(int n, const vector<tuple<int, int, i64>> &edges) {
    if (n == 0) return nullopt;
    using i128 = __int128_t;
    const i128 INF = i128(1) << 120;
    // dp[k][v]：
    // 从任意起点出发，恰好走 k 条边到达 v 的最小权值。
    //
    // 不保存全部 dp。
    // 第一遍滚动得到 dp[n]，第二遍重新计算 dp[0..n-1]
    // 并直接代入 Karp 公式，因此额外空间 O(n)。
    vector<i128> pre(n), cur(n), dn;
    // ===== 第一遍：求 dp[n] =====
    for (int len = 1; len <= n; ++ len) {
        ranges::fill(cur, INF);
        for (auto [u, v, w] : edges) {
            if (pre[u] == INF) continue;
            cur[v] = min(cur[v], pre[u] + w);
        }
        swap(pre, cur);
    }
    dn = pre;
    // ===== 第二遍：重新计算 dp[k] 并维护 Karp 公式 =====
    const ld LINF = numeric_limits<ld>::infinity();
    vector<ld> best(n, -LINF);
    ranges::fill(pre, i128{});
    for (int len = 0; len < n; ++ len) {
        for (int v : views::iota(0, n)) {
            if (dn[v] == INF || pre[v] == INF) continue;
            best[v] = max(best[v], ld(dn[v] - pre[v]) / (n - len));
        }
        if (len + 1 == n) break;
        ranges::fill(cur, INF);
        for (auto [u, v, w] : edges) {
            if (pre[u] == INF) continue;
            cur[v] = min(cur[v], pre[u] + w);
        }
        swap(pre, cur);
    }
    ld ans{ LINF };
    for (int v : views::iota(0, n)) {
        if (dn[v] != INF) ans = min(ans, best[v]);
    }
    if (isinf(ans)) return nullopt;
    return ans;
}
```
#### 接口说明
`minimum_mean_cycle(n, edges)` 求整张有向图中所有有向环的最小平均边权
一条环 $C$ 的平均边权定义为：
$$\mu(C)=\frac{\sum_{e\in C}w_e}{|C|}$$
返回：
```cpp
optional<ld>
```
* 有环：返回最小平均边权
* 无任何有向环：返回 `nullopt`
边格式：
```cpp
{u, v, w}
```
表示：
$$u\rightarrow v$$
边权为 `w`
边权允许为负
#### 原理
定义：
$$dp_k(v)$$
为从任意起点出发，恰好经过 `k` 条边到达 `v` 的最小权值
相当于存在一个超级源，以权值 `0` 连向所有原图节点，因此：
$$dp_0(v)=0$$
转移：
$$dp_k(v)=\min_{(u,v,w)\in E}\left(dp_{k-1}(u)+w\right)$$
Karp 定理给出最小平均环：
$$\boxed{\min_v\max_{0\le k<n}\frac{dp_n(v)-dp_k(v)}{n-k}}$$
其中只考虑 `dp_n(v)` 有限的节点
##### 为什么 `dp[n]` 有限意味着存在环
一个拥有 `n` 个节点的图中，长度恰好为 `n` 的 walk 一定访问至少 `n+1` 个节点位置
因此必然有某个节点重复出现，从而包含有向环
无环图中：
$$dp_n(v)=+\infty$$
对所有 `v` 均成立
##### 为什么只需要 `O(n)` DP 空间
公式只需要：
* 最终的 `dp[n][v]`
* 当前正在枚举的 `dp[k][v]`
因此：
1. 第一遍滚动 DP 得到 `dp[n]`
2. 第二遍从 `dp[0]` 重新滚动
3. 每得到一层 `dp[k]`，立即更新对应比值
无需保存：
$$dp[0],dp[1],\ldots,dp[n]$$
#### 注意事项
* 这是**有向环**的最小平均边权
* 图可以不连通，不需要提前建立超级源；`dp[0][v] = 0` 已经等价于所有点均可作为起点
* 自环正常参与计算，其平均边权就是自身边权
* 重边正常处理
* 边权允许为负
* 最终答案使用 `long double`，输出时应设置足够精度
* 该函数只返回最小平均值，不恢复具体环
* 若题目要求**最大平均环**，可以将所有边权取反后求最小平均环，再把答案取反；注意 `LLONG_MIN` 不能直接取负
* 若只需要判断：
$$\mu_{\min}<x$$
也可以考虑把每条边权改为 `w-x` 后判断负环，配合二分，但这是另一种实现路线
#### 常见用法
```cpp
vector<tuple<int, int, i64>> edges;
for (int i = 0; i < m; ++ i) {
    int u, v;
    i64 w;
    cin >> u >> v >> w;
    edges.push_back({ u, v, w });
}
auto ans = minimum_mean_cycle(n, edges);
if (!ans) {
    // 图中不存在有向环
} else {
    cout << fixed << setprecision(12) << *ans << '\n';
}
```
##### 最大平均环
若所有权值都能安全取负：
```cpp
for (auto &[u, v, w] : edges) w = -w;
auto ans = minimum_mean_cycle(n, edges);
if (ans) {
    ld maximum_mean = -*ans;
}
```
#### 复杂度
两遍 DP：
$$O(nm)$$
计算 Karp 公式：
$$O(n^2)$$
因此本实现严格写作：
$$O(nm+n^2)$$
对于边数满足 $m=\Omega(n)$ 的图，可简写为：
$$O(nm)$$
DP 额外空间：
$$O(n)$$
加上输入边表后的总空间：
$$O(n+m)$$
相比保存完整二维 DP 的版本：
$$O(n^2)$$
空间下降为：
$$O(n)$$
