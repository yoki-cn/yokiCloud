### 最短路
---
#### 算法选择

|条件|推荐算法|时间复杂度|
|---|---|--:|
|DAG，边权任意|拓扑序 DP|$O(n+m)$|
|所有边权均为 `1`|BFS|$O(n+m)$|
|边权仅为 `0/1`|0-1 BFS|$O(n+m)$|
|非负整数边权，最大边权 `C` 很小|Dial|$O(m+nC)$|
|一般非负边权、稀疏图|堆优化 Dijkstra|$O((n+m)\log n)$|
|一般非负边权、稠密图|朴素 Dijkstra|$O(n^2)$|
|存在负边，需要稳定复杂度|Bellman--Ford|$O(nm)$|
|存在负边，数据或图结构较友好|SPFA|最坏 $O(nm)$|
|至多经过 `k` 条边|限边 Bellman--Ford|$O(km)$|
|全源最短路，`n` 较小|Floyd--Warshall|$O(n^3)$|
|无向简单图最小环，`n` 较小|Floyd 最小环|$O(n^3)$|

#### 公共类型
- `INF<T>`：类型 `T` 对应的无穷大值
- `WGraph<T>`：带权邻接表，`g[u]` 中 `{v, w}` 表示边 `u -> v`
- `ShortestPathResult<T>::dis`：最短距离
- `ShortestPathResult<T>::par`：一棵最短路树中的父节点
- `restore_path(par, t)`：从 `par` 恢复某个源点到 `t` 的路径，$O(k)$
#### 公共类型与路径恢复
```cpp
template<class T>
inline constexpr T INF = numeric_limits<T>::max() / 4;
template<class T = i64>
using WGraph = vector<vector<pair<int, T>>>;
template<class T>
struct ShortestPathResult {
    vector<T> dis;
    vector<int> par;
};
vector<int> restore_path(const vector<int> &par, int t) {
    vector<int> path;
    for (; t != -1; t = par[t]) path.push_back(t);
    ranges::reverse(path);
    return path;
}
```
#### BFS
```cpp
template<ranges::input_range R>
ShortestPathResult<int> bfs(const vector<vector<int>> &g, R &&source) {
    int n = g.size();
    vector<int> dis(n, -1), par(n, -1), q;
    q.reserve(n);
    for (int s : source) if (dis[s] == -1) {
        dis[s] = 0;
        q.push_back(s);
    }
    for (int h = 0; h < q.size(); ++ h) {
        int u = q[h];
        for (int v : g[u]) if (dis[v] == -1) {
            dis[v] = dis[u] + 1;
            par[v] = u;
            q.push_back(v);
        }
    }
    return { move(dis), move(par) };
}
ShortestPathResult<int> bfs(const vector<vector<int>> &g, int s) {
    return bfs(g, array{s});
}
```
- `bfs(g, s)`：单源无权最短路，$O(n+m)$
- `bfs(g, source)`：多源无权最短路，$O(n+m)$
- 不可达点满足 `dis[u] == -1`
#### 堆优化 Dijkstra
```cpp
template<class T, ranges::input_range R>
ShortestPathResult<T> dijkstra(const WGraph<T> &g, R &&source) {
    int n = g.size();
    vector<T> dis(n, INF<T>);
    vector<int> par(n, -1);
    priority_queue<pair<T, int>, vector<pair<T, int>>, greater<>> q;
    for (int s : source) if (dis[s] == INF<T>) {
        dis[s] = T{};
        q.push({ T{}, s });
    }
    while (!q.empty()) {
        auto [d, u] = q.top();
        q.pop();
        if (d != dis[u]) continue;
        for (auto [v, w] : g[u]) if (d + w < dis[v]) {
            dis[v] = d + w;
            par[v] = u;
            q.push({ dis[v], v });
        }
    }
    return { move(dis), move(par) };
}
template<class T>
ShortestPathResult<T> dijkstra(const WGraph<T> &g, int s) {
    return dijkstra(g, array{s});
}
```
#### 朴素 Dijkstra
```cpp
template<class T, ranges::input_range R>
ShortestPathResult<T> dijkstra_dense(const vector<vector<T>> &a, R &&source) {
    int n = a.size();
    vector<T> dis(n, INF<T>);
    vector<int> par(n, -1);
    vector<char> vis(n);
    for (int s : source) dis[s] = T{};
    for (int it = 0; it < n; ++ it) {
        int u{ -1 };
        for (int v = 0; v < n; ++ v) {
            if (!vis[v] && (u == -1 || dis[v] < dis[u])) u = v;
        }
        if (u == -1 || dis[u] == INF<T>) break;
        vis[u] = true;
        for (int v = 0; v < n; ++ v) {
            if (a[u][v] != INF<T> && dis[u] + a[u][v] < dis[v]) {
                dis[v] = dis[u] + a[u][v];
                par[v] = u;
            }
        }
    }
    return { move(dis), move(par) };
}
template<class T>
ShortestPathResult<T> dijkstra_dense(const vector<vector<T>> &a, int s) {
    return dijkstra_dense(a, array{s});
}
```
- `dijkstra(g, s)`：单源非负权最短路
- `dijkstra(g, source)`：多源非负权最短路
- 不可达点满足 `dis[u] == INF<T>`
- `dijkstra_dense(a, ...)`：邻接矩阵版本
#### 0-1 BFS
```cpp
template<ranges::input_range R>
ShortestPathResult<int> zero_one_bfs(const WGraph<int> &g, R &&source) {
    int n = g.size();
    vector<int> dis(n, INF<int>), par(n, -1);
    deque<pair<int, int>> q;
    for (int s : source) if (dis[s] == INF<int>) {
        dis[s] = 0;
        q.push_back({ 0, s });
    }
    while (!q.empty()) {
        auto [d, u] = q.front();
        q.pop_front();
        if (d != dis[u]) continue;
        for (auto [v, w] : g[u]) {
            int nd{ d + w };
            if (nd >= dis[v]) continue;
            dis[v] = nd;
            par[v] = u;
            if (w == 0) q.push_front({ nd, v });
            else q.push_back({ nd, v });
        }
    }
    return { move(dis), move(par) };
}
ShortestPathResult<int> zero_one_bfs(const WGraph<int> &g, int s) {
    return zero_one_bfs(g, array{s});
}
```
- `zero_one_bfs(g, s)`：单源 0-1 最短路
- `zero_one_bfs(g, source)`：多源版本
- `g` 的边权类型固定为 `int`

最典型的是：**某些操作免费，某些操作代价恰好为 1，并且要求总代价最小**
也就是说，看到“最少多少次某种特殊行为”，很容易转成 `0/1` 边权
例如：
- 正常移动代价 `0`，破坏一堵墙代价 `1`，求最少破墙数
一个非常典型的抽象是：
```text
普通操作 -> 权值 0
特殊操作 -> 权值 1
答案 = 最少特殊操作次数
```
如果所有边都是 `1`，直接 BFS；只要出现 `0` 和 `1` 混合，优先想到 `0-1 BFS`
#### Dial 最短路
**针对边权值域的性能优化**
```cpp
template<ranges::input_range R>
ShortestPathResult<i64> dial(const WGraph<int> &g, R &&source, int max_w) {
    int n = g.size(), B = max_w + 1;
    vector<i64> dis(n, INF<i64>);
    vector<int> par(n, -1);
    vector<vector<pair<i64, int>>> bucket(B);
    i64 cur{ 0 };
    int pending{ 0 };
    for (int s : source) if (dis[s] == INF<i64>) {
        dis[s] = 0;
        bucket[0].push_back({ 0, s });
        ++ pending;
    }
    while (pending) {
        while (bucket[cur % B].empty()) ++ cur;
        auto [d, u] = bucket[cur % B].back();
        bucket[cur % B].pop_back();
        -- pending;
        if (d != dis[u]) continue;
        for (auto [v, w] : g[u]) {
            i64 nd{ d + w };
            if (nd >= dis[v]) continue;
            dis[v] = nd;
            par[v] = u;
            bucket[nd % B].push_back({ nd, v });
            ++ pending;
        }
    }
    return { move(dis), move(par) };
}
ShortestPathResult<i64> dial(const WGraph<int> &g, int s, int max_w) {
    return dial(g, array{s}, max_w);
}
```
- `dial(g, s, max_w)`：单源小整数非负权最短路
- `dial(g, source, max_w)`：多源版本
- `max_w` 是最大**单边权值**

Dial 可以认为是 **Dijkstra 在“小整数权值”下的专门优化**
适合：
$$0\le w\le C$$
且 `C` 很小
例如：
- 网格每种地形代价只有 `0..9`
- 道路收费只有 `1..10`
- 状态转移代价只可能是几个很小的整数
- 字符转换费用限定在很小范围
- 图非常大，`log n` 的堆常数比较明显，而 `C` 只有几十
比如：
```text
草地：1
沙地：2
沼泽：5
山地：8
```
这时虽然普通 Dijkstra 完全能做，但 Dial 可以把优先队列替换成桶
它尤其适合这种条件：
$$C \ll \log n\ \text{对应的实际常数}$$
不过比赛里 Dial 没有 Dijkstra 那么泛用。我的建议是：
- `C = 1`：直接 `0-1 BFS`
- `C` 很小：可以考虑 Dial
- `C` 不确定或达到几百、几千甚至更大：直接 Dijkstra 更稳
#### Bellman--Ford
```cpp
template<class T = i64>
struct BFEdge {
    int u, v;
    T w;
};
template<class T>
struct BellmanFordResult {
    vector<T> dis;
    vector<int> par;
    bool neg_cycle{};
};
template<class T, ranges::input_range R>
BellmanFordResult<T> bellman_ford(int n, const vector<BFEdge<T>> &edges, R &&source) {
    vector<T> dis(n, INF<T>);
    vector<int> par(n, -1);
    for (int s : source) dis[s] = T{};
    for (int it = 0; it < n; ++ it) {
        bool changed{ false };
        for (auto [u, v, w] : edges) {
            if (dis[u] == INF<T> || dis[u] + w >= dis[v]) continue;
            dis[v] = dis[u] + w;
            par[v] = u;
            changed = true;
        }
        if (!changed) return { move(dis), move(par), false };
        if (it == n - 1) return { move(dis), move(par), true };
    }
    return { move(dis), move(par), false };
}
template<class T>
BellmanFordResult<T> bellman_ford(int n, const vector<BFEdge<T>> &edges, int s) {
    return bellman_ford(n, edges, array{s});
}
```
- `BFEdge<T>{u, v, w}`：边表中的一条有向边
- `bellman_ford(n, edges, source)`：最短路并判断从源集合可达的负环
- `neg_cycle`：是否存在从源集合可达的负环
- `bellman_ford_k_edges(..., k)`：求至多经过 `k` 条边的最短距离

Bellman--Ford 最核心的用途有两个：
**允许负边**，以及**稳定地判断负环**
但是复杂度较高：$O(nm)$

典型含义包括：
- 收益可以抵消成本
- 汇率/价格变化
- 奖励边表现为负费用
- 某些状态转换会降低总代价
只要不存在从源点可达的负环，就存在有限最短路
##### 判断负环
例如：
- 判断是否存在无限套利
- 判断一组差分约束是否矛盾
- 判断图中是否存在可以无限降低代价的循环
- Wormholes / 虫洞类题
- 货币兑换套利
如果要判断**整张图任意位置**有没有负环，可以把所有点都当源点，相当于建立超级源：
```cpp
auto source = views::iota(0, n);
auto res = bellman_ford(n, edges, source);
```
#### 限定至多经过 `k` 条边
```cpp
template<class T, ranges::input_range R>
vector<T> bellman_ford_k_edges(int n, const vector<BFEdge<T>> &edges, R &&source, int k) {
    vector<T> dis(n, INF<T>);
    for (int s : source) dis[s] = T{};
    while (k --) {
        auto pre = dis;
        for (auto [u, v, w] : edges) if (pre[u] != INF<T>) {
            dis[v] = min(dis[v], pre[u] + w);
        }
    }
    return dis;
}
template<class T>
vector<T> bellman_ford_k_edges(int n, const vector<BFEdge<T>> &edges, int s, int k) {
    return bellman_ford_k_edges(n, edges, array{s}, k);
}
```

> **路径长度（边数）受到限制的最短路**

最典型场景就是“最多经过多少次转移”
例如：
- 最多乘坐 `k` 段航班
- 最多中转 `k` 次
- 在 `k` 天 / `k` 回合 / `k` 步以内到达目标。
- 有负边，但只允许走有限步，因此即使存在负环，也不能无限绕
例如：
```text
从城市 s 到城市 t
最多乘坐 5 班飞机
求最低费用
```
这时普通最短路是不够的，因为普通最短路只优化：
$$\text{总代价}$$
而题目还有：
$$\text{边数}\le k$$
的约束
Bellman--Ford 每一轮天然对应：
$$\text{最多再使用一条边}$$
所以执行 `k` 轮即可

##### 与“状态加一维”DP 的关系
它本质上就是：
$$dp[t][v] = \text{至多使用 }t\text{ 条边到达 }v\text{ 的最短距离}$$
Bellman--Ford 只是把第一维滚动掉了
所以看到：
```text
最多 k 次
恰好 k 次
不超过 k 条边
```
应该想到这一类 DP/限边最短路

#### SPFA
**差分约束 + 某些实际比较友好的负权图**
```cpp
template<class T>
struct SPFAResult {
    vector<T> dis;
    vector<int> par;
    bool neg_cycle{};
};
template<class T, ranges::input_range R>
SPFAResult<T> spfa(const WGraph<T> &g, R &&source) {
    int n = g.size();
    vector<T> dis(n, INF<T>);
    vector<int> par(n, -1), len(n);
    vector<char> inq(n);
    deque<int> q;
    for (int s : source) if (dis[s] == INF<T>) {
        dis[s] = T{};
        inq[s] = true;
        q.push_back(s);
    }
    while (!q.empty()) {
        int u = q.front();
        q.pop_front();
        inq[u] = false;
        for (auto [v, w] : g[u]) if (dis[u] + w < dis[v]) {
            dis[v] = dis[u] + w;
            par[v] = u;
            len[v] = len[u] + 1;
            if (len[v] >= n) return { move(dis), move(par), true };
            if (inq[v]) continue;
            inq[v] = true;
            if (!q.empty() && dis[v] < dis[q.front()]) q.push_front(v);
            else q.push_back(v);
        }
    }
    return { move(dis), move(par), false };
}
template<class T>
SPFAResult<T> spfa(const WGraph<T> &g, int s) {
    return spfa(g, array{s});
}
```
- `spfa(g, source)`：允许负边，并判断从源集合可达的负环
- `len[u]` 维护当前改进路径所含边数
- `neg_cycle == true` 时最短距离不再具有最终意义

##### 差分约束
这是 SPFA 最经典的用途之一
例如约束：
$$x_v-x_u\le w$$
转换成：
$$x_v\le x_u+w$$
对应一条边：
$$u\rightarrow v,\quad w$$
然后求一组满足约束的势能
常见形式：
$$x_i-x_j\le c$$
建边：
```text
j -> i，权值 c
```
因此 SPFA 常见于：
- 一堆变量大小关系
- 区间前缀和约束
- 排程约束
- 最早/最晚时间
- 连续整数选择问题
- 线性不等式约束
- 判断一组约束是否矛盾
如果出现负环，则通常意味着约束系统不可行
##### 为什么差分约束常用 SPFA
因为这类图往往：
- 比较稀疏
- 边结构特殊
- 实际运行表现通常不错
- 需要顺便判断负环
于是代码非常自然
不过不能忘记：
$$\text{SPFA 最坏仍然是 }O(nm)$$
#### Floyd--Warshall
```cpp
template<class T>
vector<vector<T>> floyd(vector<vector<T>> dis) {
    int n = dis.size();
    for (int i = 0; i < n; ++ i) dis[i][i] = min(dis[i][i], T{});
    for (int k = 0; k < n; ++ k) {
        for (int i = 0; i < n; ++ i) if (dis[i][k] != INF<T>) {
            for (int j = 0; j < n; ++ j) if (dis[k][j] != INF<T>) {
                dis[i][j] = min(dis[i][j], dis[i][k] + dis[k][j]);
            }
        }
    }
    return dis;
}
```
#### Floyd 最小环
```cpp
template<class T>
pair<vector<vector<T>>, T> floyd_min_cycle(const vector<vector<T>> &a) {
    int n = a.size();
    vector dis = a;
    for (int i = 0; i < n; ++ i) dis[i][i] = T{};
    T cycle = INF<T>;
    for (int k = 0; k < n; ++ k) {
        // 此时 dis[i][j] 只允许编号 < k 的点作为中间点
        for (int i = 0; i < k; ++ i) {
            for (int j = i + 1; j < k; ++ j) {
                if (dis[i][j] == INF<T> ||
                    a[i][k] == INF<T> ||
                    a[k][j] == INF<T>) continue;
                cycle = min(cycle, dis[i][j] + a[i][k] + a[k][j]);
            }
        }
        for (int i = 0; i < n; ++ i) if (dis[i][k] != INF<T>) {
            for (int j = 0; j < n; ++ j) if (dis[k][j] != INF<T>) {
                dis[i][j] = min(dis[i][j], dis[i][k] + dis[k][j]);
            }
        }
    }
    return { move(dis), cycle };
}
```
- `floyd(dis)`：全源最短路
- 不存在边的位置初始化为 `INF<T>`
- `floyd_min_cycle(a)`：返回 `{全源最短路, 最小简单环长度}`
#### 注意事项
- 所有点编号均为 `0base`
- 多源版本可以直接传 `vector<int>`、`array<int, N>`、`views::iota(...)` 等 range
- 多源最短路等价于建立一个到所有源点有零权边的超级源，但无需真的建立该点
- `restore_path()` **不会判断目标是否可达**；应先检查对应 `dis[t]`
- 若存在可达负环，不要对 Bellman--Ford / SPFA 返回的 `par` 直接恢复普通最短路
- `INF<T>` 只是哨兵。所有 `dis[u] + w` 必须保证真实数值不会溢出 `T`；极端负权或负环场景需要考虑扩大到 `i128`
- Dijkstra 要求所有边权非负；零权边可以正常处理
- 0-1 BFS 要求每条边权严格属于 `{0, 1}`
- Dial 要求所有边权是整数且满足 `0 <= w <= max_w`；`max_w` 很大时应改用 Dijkstra
- SPFA 的 SLF 仅优化常数，没有改善最坏复杂度；一般非负权图不要使用 SPFA
- Bellman--Ford 判断的只是**源集合可达的负环**。判断整张图是否存在负环时，把所有点作为源即可
- `bellman_ford_k_edges()` 每轮必须从上一轮的 `pre` 松弛；若直接原地连续传播，就不再满足“至多 `k` 条边”的限制
- Floyd 可以处理负边；若最终存在 `dis[i][i] < 0`，则存在负环
- Floyd 最小环版本只针对无向图，且 `a[i][j] == a[j][i]`
- 调用 `floyd_min_cycle()` 前，`a[i][i]` 应保持 `INF<T>`；函数内部会单独把 `dis[i][i]` 设为 `0`
- Floyd 最小环只统计至少包含 `3` 个不同点的简单环。自环、两条平行边构成的二元环需要建图时单独处理
#### 常见用法
##### 建立带权图
```cpp
WGraph g(n);
g[u].push_back({ v, w });
g[v].push_back({ u, w }); // 无向图
```
##### 单源 Dijkstra
```cpp
auto [dis, par] = dijkstra(g, s);
if (dis[t] != INF<i64>) {
    auto path = restore_path(par, t);
}
```
##### 多源最短路
```cpp
vector<int> source{ a, b, c };
auto [dis, par] = dijkstra(g, source);
```
也可以直接使用 range：
```cpp
auto res = bellman_ford(n, edges, views::iota(0, n));
bool has_negative_cycle = res.neg_cycle;
```
这等价于所有点同时作为源点，因此可以判断整张图是否存在负环
##### 0-1 BFS
```cpp
WGraph<int> g(n);
g[u].push_back({ v, 0 });
g[x].push_back({ y, 1 });
auto [dis, par] = zero_one_bfs(g, s);
```
##### Dial
```cpp
int max_w = 10;
auto [dis, par] = dial(g, s, max_w);
```
##### 至多经过 `k` 条边

```cpp
vector<BFEdge<>> edges;
edges.push_back({ u, v, w });

```
##### Floyd
```cpp
vector dis(n, vector<i64>(n, INF<i64>));
for (int i = 0; i < n; ++ i) dis[i][i] = 0;
for (auto [u, v, w] : edges) {
    dis[u][v] = min(dis[u][v], w);
}
dis = floyd(move(dis));
```
##### Floyd 判断负环
```cpp
bool neg_cycle = false;
for (int i = 0; i < n; ++ i) {
    neg_cycle |= dis[i][i] < 0;
}
```
##### Floyd 最小环
```cpp
vector a(n, vector<i64>(n, INF<i64>));
for (auto [u, v, w] : edges) {
    a[u][v] = min(a[u][v], w);
    a[v][u] = min(a[v][u], w);
}
auto [dis, cycle] = floyd_min_cycle(a);
if (cycle == INF<i64>) {
    // 不存在至少含三个不同点的简单环
}
```
#### 复杂度
设点数为 `n`，边数为 `m`，Dial 最大单边权为 `C`

| 算法               |            时间复杂度 |       额外空间 |
| ---------------- | ---------------: | ---------: |
| BFS              |         $O(n+m)$ |     $O(n)$ |
| 堆优化 Dijkstra     | $O((n+m)\log n)$ |   $O(n+m)$ |
| 朴素 Dijkstra      |         $O(n^2)$ |     $O(n)$ |
| 0-1 BFS          |         $O(n+m)$ |   $O(n+m)$ |
| Dial             |        $O(m+nC)$ | $O(n+m+C)$ |
| Bellman--Ford    |          $O(nm)$ |     $O(n)$ |
| 限边 Bellman--Ford |          $O(km)$ |     $O(n)$ |
| SPFA             |       最坏 $O(nm)$ |     $O(n)$ |
| Floyd--Warshall  |         $O(n^3)$ |   $O(n^2)$ |
| Floyd 最小环        |         $O(n^3)$ |   $O(n^2)$ |
恢复一条包含 `k` 个点的路径：
$$O(k)$$
