### 差分约束
---
```cpp
struct DifferenceConstraints {
    struct Edge {
        int u, v;
        i64 w;
    };
    int n;
    vector<Edge> edges;
    explicit DifferenceConstraints(int n_) : n(n_) {}
    // ===== 基础约束接口 =====
    // x[v] - x[u] <= w
    void add_leq(int u, int v, i64 w) { edges.push_back({ u, v, w }); }
    // x[v] - x[u] >= w
    void add_geq(int u, int v, i64 w) { add_leq(v, u, -w); }
    // x[v] - x[u] == w
    void add_eq(int u, int v, i64 w) {
        add_leq(u, v, w);
        add_geq(u, v, w);
    }
    // lo <= x[v] - x[u] <= hi
    void add_range(int u, int v, i64 lo, i64 hi) {
        add_geq(u, v, lo);
        add_leq(u, v, hi);
    }
    // ===== Bellman--Ford：判断可行性并返回一组解 =====
    optional<vector<i64>> feasible() const {
        vector<i64> x(n);
        if (n == 0) return x;
        // 全部初始化为 0，等价于建立超级源：
        // source -> v，边权为 0。
        for (int it = 0; it < n; ++ it) {
            bool changed{ false };
            for (auto [u, v, w] : edges) {
                if (x[v] <= x[u] + w) continue;
                x[v] = x[u] + w;
                changed = true;
            }
            if (!changed) return x;
        }
        // 第 n 轮仍能松弛 <=> 存在负环 <=> 约束无解
        return nullopt;
    }
};
```
#### 接口说明
差分约束处理形如：
$$x_v-x_u\le w$$
的不等式系统
标准变形：
$$x_v\le x_u+w$$
对应最短路约束边：
$$u\rightarrow v,\qquad w$$
即：
```cpp
dc.add_leq(u, v, w);
```
#### 常用接口
##### 小于等于
$$x_v-x_u\le w$$
```cpp
dc.add_leq(u, v, w);
```
##### 大于等于
$$x_v-x_u\ge w$$
等价于：
$$x_u-x_v\le-w$$
```cpp
dc.add_geq(u, v, w);
```
##### 等于
$$x_v-x_u=w$$
```cpp
dc.add_eq(u, v, w);
```
即同时加入：
$$x_v-x_u\le w$$
和：
$$x_v-x_u\ge w$$
##### 区间限制
$$lo\le x_v-x_u\le hi$$
```cpp
dc.add_range(u, v, lo, hi);
```
##### `feasible()`
```cpp
auto ans = dc.feasible();
```
返回：
* `nullopt`：约束系统无解
* `vector<i64>`：一组满足所有约束的可行解
因为差分约束只涉及变量之间的差：
$$(x_v+C)-(x_u+C)=x_v-x_u$$
所以所有变量同时加同一个常数后仍然是解，返回解通常不唯一
#### 常见约束翻译

| 题目约束                  | 调用                        |
| --------------------- | ------------------------- |
| $x_v-x_u\le w$        | `add_leq(u, v, w)`        |
| $x_v-x_u\ge w$        | `add_geq(u, v, w)`        |
| $x_v-x_u=w$           | `add_eq(u, v, w)`         |
| $lo\le x_v-x_u\le hi$ | `add_range(u, v, lo, hi)` |
若变量限定为整数：
$$x_v-x_u<w$$
等价于：
$$x_v-x_u\le w-1$$
而：
$$x_v-x_u>w$$
等价于：
$$x_v-x_u\ge w+1$$
这一转换**只适用于整数变量**
#### 绝对上下界
差分约束本身只描述变量差
若需要表示：
$$x_v\le c$$
增加一个基准变量 `z`，写成：
$$x_v-x_z\le c$$
即：
```cpp
dc.add_leq(z, v, c);
```
类似地：
$$x_v\ge c$$
写为：
```cpp
dc.add_geq(z, v, c);
```
求出一组解后：
```cpp
i64 shift = x[z];
for (i64 &v : x) v -= shift;
```
即可令：
$$x_z=0$$
而不改变任何差分约束
#### 建模原理
每条约束：
$$x_v\le x_u+w$$
都与最短路中的松弛条件：
$$dis[v]\le dis[u]+w$$
完全一致
因此若图中不存在负环，Bellman--Ford 最终得到的势能就是一组可行解
反之，若存在负环：
$$v_0\rightarrow v_1\rightarrow\cdots\rightarrow v_k=v_0$$
且环权和为负，把所有约束相加会得到：
$$x_{v_0}<x_{v_0}$$
矛盾，因此约束无解
##### 为什么不显式建立超级源
通常会建立超级源 `S`：
$$S\rightarrow i,\quad 0$$
连接每个变量
本实现直接：
```cpp
vector<i64> x(n);
```
令所有变量初始为 `0`
这与从超级源执行 Bellman--Ford 完全等价，可以少建一个点和 `n` 条边
#### 注意事项
* 当前版本解决的是**可行性**，不是一般线性规划
* 每条约束必须能转成两个变量之差的上下界
* 诸如
$$x+y\le c$$
或：
$$xy\le c$$
不能直接转成普通差分约束
* `feasible()` 使用 Bellman--Ford，复杂度稳定，不依赖 SPFA 的数据表现
* 全零初始化已经等价于超级源，因此能够检查整张约束图中的任何负环
* 返回解可能为负数，这是正常现象
* 如果题目只要求变量之间的相对大小，可以直接使用返回值
* 如果某个变量必须固定为 `0`，使用基准变量建模并在求解后整体平移
* `add_geq()` 内部会计算 `-w`；不要传入无法安全取负的 `LLONG_MIN`
* `x[u] + w` 必须保证不会超出 `i64`。通常只需保证有限简单路径的权值和处于 `i64` 范围
* 实数严格不等式不能简单通过 `±1` 转换
* 差分约束和“同余最短路”没有直接关系；不要因为题目中出现“约束”或“同余”就混用两个模型
#### 常见用法
##### 基本可行性
```cpp
DifferenceConstraints dc(n);
dc.add_leq(u, v, upper);
dc.add_geq(u, v, lower);
auto ans = dc.feasible();
if (!ans) {
    cout << "No\n";
} else {
    for (i64 x : *ans) cout << x << ' ';
}
```
##### 同时限制上下界
题目要求：
$$2\le x_v-x_u\le5$$
直接写：
```cpp
dc.add_range(u, v, 2, 5);
```
##### 等式约束
题目要求：
$$x_v=x_u+7$$
即：
$$x_v-x_u=7$$
写成：
```cpp
dc.add_eq(u, v, 7);
```
##### 判断矛盾
例如：
$$x-y\le-1$$
且：
$$y-x\le-1$$
可以写成：
```cpp
DifferenceConstraints dc(2);
dc.add_leq(1, 0, -1);
dc.add_leq(0, 1, -1);
auto ans = dc.feasible();
assert(!ans);
```
两式相加得到：
$$0\le-2$$
因此形成负环，系统无解
##### 时间排程
例如任务 `u` 结束后至少经过 `d` 时间才能开始任务 `v`：
$$start_v-start_u\ge d$$
写作：
```cpp
dc.add_geq(u, v, d);
```
典型应用包括：
* 时间排程
* 先后关系
* 区间前缀和约束
* 最早 / 最晚时间限制
* 相对高度、相对位置
* 一组变量之间的上下界一致性判断
#### 复杂度
设变量数为 `n`，约束数为 `m`
加入一条约束：
$$O(1)$$
`feasible()` 使用 Bellman--Ford：
$$O(nm)$$
额外空间：
$$O(n)$$
保存约束后的总空间：
$$O(n+m)$$
