### 次短路及 K 短路
---
依赖「最短路基础」中的：
```cpp
template<class T>
inline constexpr T INF = numeric_limits<T>::max() / 4;

template<class T = i64>
using WGraph = vector<vector<pair<int, T>>>;
```
#### 严格次短路
```cpp
pair<vector<i64>, vector<i64>> second_shortest(const WGraph<i64> &g, int s) {
    int n = g.size();
    vector<i64> d1(n, INF<i64>), d2(n, INF<i64>);
    priority_queue<pair<i64, int>, vector<pair<i64, int>>, greater<>> q;
    d1[s] = 0;
    q.push({ 0, s });
    while (!q.empty()) {
        auto [d, u] = q.top();
        q.pop();
        if (d > d2[u]) continue;
        for (auto [v, w] : g[u]) {
            if (d > INF<i64> - w) continue;
            i64 nd{ d + w };
            if (nd < d1[v]) {
                swap(nd, d1[v]);
                q.push({ d1[v], v });
            }
            if (d1[v] < nd && nd < d2[v]) {
                d2[v] = nd;
                q.push({ d2[v], v });
            }
        }
    }
    return { move(d1), move(d2) };
}
```
#### A* 前 `k` 短 Walk
```cpp
vector<i64> k_shortest_walks(const WGraph<i64> &g, int s, int t, int k) {
    if (k <= 0) return {};
    int n = g.size();
    // ===== 反图 Dijkstra：得到 h[u] = u -> t 的最短距离 =====
    WGraph<i64> rg(n);
    for (int u : views::iota(0, n)) {
        for (auto [v, w] : g[u]) rg[v].push_back({ u, w });
    }
    vector<i64> h(n, INF<i64>);
    priority_queue<pair<i64, int>, vector<pair<i64, int>>, greater<>> dq;
    h[t] = 0;
    dq.push({ 0, t });
    while (!dq.empty()) {
        auto [d, u] = dq.top();
        dq.pop();
        if (d != h[u]) continue;
        for (auto [v, w] : rg[u]) {
            if (d > INF<i64> -w || d + w >= h[v]) continue;
            h[v] = d + w;
            dq.push({ h[v], v });
        }
    }
    if (h[s] == INF<i64>) return {};
    // ===== A*：每个点最多有效弹出 limit 次 =====
    using State = tuple<i64, i64, int>; // f = d + h[u], d, u
    priority_queue<State, vector<State>, greater<>> q;
    vector<int> pop(n);
    vector<i64> ans;
    ans.reserve(k);
    // s == t 时第一次弹出的是长度 0 的空 walk，不计入答案。
    int limit = k + (s == t);
    q.push({ h[s], 0, s });
    while (!q.empty() && ans.size() < k) {
        auto cur = q.top();
        q.pop();
        i64 d{ get<1>(cur) };
        int u{ get<2>(cur) };
        if (++ pop[u] > limit) continue;
        if (u == t && !(s == t && pop[u] == 1)) ans.push_back(d);
        for (auto [v, w] : g[u]) {
            if (h[v] == INF<i64> || pop[v] >= limit) continue;
            if (d > INF<i64> -w) continue;
            i64 nd = d + w;
            if (nd > INF<i64> -h[v]) continue;
            q.push({ nd + h[v], nd, v });
        }
    }
    return ans;
}
i64 kth_shortest_walk(const WGraph<i64> &g, int s, int t, int k) {
    if (k <= 0) return -1;
    auto ans = k_shortest_walks(g, s, t, k);
    return ans.size() == k ? ans.back() : -1;
}
```
#### 接口说明
##### `second_shortest(g, s)`
返回：
```cpp
auto [d1, d2] = second_shortest(g, s);
```
其中：
- `d1[v]`：`s -> v` 的最短 walk 长度
- `d2[v]`：严格满足
$$d_2[v]>d_1[v]$$
的最小 walk 长度
- 不存在时为 `INF<i64>`
因此两条长度相同但经过边不同的最短路，**不会**使 `d2[v] = d1[v]`
##### `k_shortest_walks(g, s, t, k)`
返回前 `k` 条非空 `s -> t` walk 的长度，按非降序排列
这里的 walk：
- 可以重复经过点
- 可以重复经过边
- 不同边序列分别计数
- 长度相同的不同 walk 会分别占据一个名次
若不足 `k` 条，返回实际存在的全部结果
##### `kth_shortest_walk(g, s, t, k)`
返回第 `k` 短非空 walk 长度，`k` 从 `1` 开始
不存在时返回 `-1`
#### 注意事项
- 两个算法都要求所有边权非负
- 零权边允许存在
- `second_shortest()` 求的是**严格次短长度**，不是“第二条不同路径”
- `k_shortest_walks()` 求的是 walk，不是简单路径
- 如果图中存在零权环，可能存在无限多条长度相同的 walk；这些 walk 仍会分别占据 K 短排名
- 若题目要求“不允许重复点”的第 `k` 短简单路径，应使用 Yen、Eppstein 等其他模型
- `s == t` 时默认排除长度为 `0` 的空 walk，因此返回的是非空闭合 walk
- 反图在函数内部自动建立，调用者只维护 `g`，避免 `g / rg` 不一致
- 若同一终点 `t` 上要进行很多次 K 短查询，可以把反图与 `h[]` 单独预处理并封装，避免重复 Dijkstra
- 所有有限路径长度应小于 `INF<i64>`
#### 常见用法
##### 严格次短路
```cpp
WGraph<i64> g(n);
for (int i = 0; i < m; ++ i) {
    int u, v;
    i64 w;
    cin >> u >> v >> w;
    g[u].push_back({ v, w });
}
auto [d1, d2] = second_shortest(g, s);
if (d2[t] == INF<i64>) {
    // 不存在严格次短 walk
} else {
    cout << d2[t] << '\n';
}
```
##### 前 `k` 短 walk
```cpp
auto ans = k_shortest_walks(g, s, t, k);
for (i64 d : ans) cout << d << '\n';
```
##### 只要第 `k` 短
```cpp
i64 ans = kth_shortest_walk(g, s, t, k);
if (ans == -1) {
    // 不足 k 条
}
```
#### 复杂度
严格次短路：
$$O((n+m)\log n)$$
额外空间：
$$O(n+m)$$
A* 首先进行一次反图 Dijkstra：
$$O((n+m)\log n)$$
之后每个点最多被有效扩展 $O(k)$ 次，因此常用上界为：
$$O(km\log(km))$$
最坏候选状态空间：
$$O(km)$$
