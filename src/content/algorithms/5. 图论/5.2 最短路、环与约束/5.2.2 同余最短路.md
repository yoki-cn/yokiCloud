### 同余最短路
---
```cpp
struct ModShortestPath {
    static constexpr i64 INF = numeric_limits<i64>::max();
    struct Step {
        int add;
        i64 cost;
    };
    i64 g{ 1 }, base{ 0 };
    int mod{ 0 };
    vector<Step> step;
    vector<i64> dist;
    i64 max_dist{ 0 };
    explicit ModShortestPath(const vector<i64> &weights) {
        assert(!weights.empty());
        assert(ranges::all_of(weights, [](i64 w) { return w > 0; }));
        base = ranges::min(weights);
        g = 0;
        for (i64 w : weights) g = gcd(g, w);
        i64 m{ base / g };
        assert(m <= INT_MAX);
        mod = int(m);
        // ===== 压缩转移：同余增量相同时，只保留代价最小的权值 =====
        {
            vector<i64> best(mod, INF);
            for (i64 w : weights) {
                int add = int((w / g) % mod);
                if (add && w < best[add]) best[add] = w;
            }
            for (int add : views::iota(1, mod)) {
                if (best[add] != INF) step.push_back({ add, best[add] });
            }
        }
        // ===== 余数图 Dijkstra：以下代码是核心，不建议删除 =====
        dist.assign(mod, INF);
        priority_queue<pair<i64, int>, vector<pair<i64, int>>, greater<>> q;
        dist[0] = 0;
        q.push({ 0, 0 });
        while (!q.empty()) {
            auto [d, r] = q.top();
            q.pop();
            if (d != dist[r]) continue;
            for (auto [add, w] : step) {
                int nr = int((i64(r) + add) % mod);
                __int128_t nd = (__int128_t)d + w;
                if (nd < dist[nr]) {
                    dist[nr] = i64(nd);
                    q.push({ dist[nr], nr });
                }
            }
        }
        max_dist = *ranges::max_element(dist);
    }
    // ===== 基础查询 =====
    i64 min_value(i64 residue) const {
        residue %= base;
        if (residue < 0) residue += base;
        if (residue % g) return INF;
        return dist[residue / g];
    }
    bool can_make(i64 x) const {
        if (x < 0 || x % g) return false;
        i64 d = dist[(x / g) % mod];
        return d != INF && d <= x;
    }
    i64 count_leq(i64 x) const {
        if (x < 0) return 0;
        i64 ans = 0;
        for (i64 d : dist) if (d != INF && d <= x) {
            ans += (x - d) / base + 1;
        }
        return ans;
    }
    i64 count_range(i64 l, i64 r) const {
        if (l > r || r < 0) return 0;
        l = max<i64>(l, 0);
        return count_leq(r) - (l ? count_leq(l - 1) : 0);
    }
    // ===== 数值半群扩展：若不需要最大不可达数，可以删除 =====
    optional<i64> largest_unreachable() const {
        if (g != 1 || max_dist == INF) return nullopt;
        return max_dist - base;
    }
};
```
#### 成员变量
- `base`：原始权值中的最小值；所有同余类最终都以 `base` 为周期继续增长
- `g`：所有权值的最大公约数
- `mod = base / g`：实际余数图点数；自动约去 `g` 后通常显著小于原始最小权值
- `step`：压缩后的有效转移
- `dist[r]`：满足
$$\frac{x}{g}\equiv r\pmod{mod}$$
的可达非负整数 `x` 中的最小值，仍使用**原始数值尺度**
- `max_dist`：所有余数类最小可达值的最大值
例如权值为 `{6, 10}`：
$$g=2,\quad base=6,\quad mod=\frac{6}{2}=3$$
内部只建立 `3` 个状态，而查询仍然直接使用原来的 `6、10、20...`，无需手动缩放
#### 接口
- `ModShortestPath(weights)`：构造并运行余数图 Dijkstra；每种正整数权值可以使用任意非负次数
- `min_value(r)`：返回模 `base` 余数为 `r` 的最小可达非负整数；该余数不可能出现时返回 `INF`
- `can_make(x)`：判断非负整数 `x` 是否可以表示
- `count_leq(x)`：统计闭区间 `[0,x]` 中可表示的整数个数
- `count_range(l,r)`：统计闭区间 `[l,r]` 中可表示的整数个数
- `largest_unreachable()`：当 `g == 1` 时返回最大不可表示非负整数；`g != 1` 时返回 `nullopt`
#### 建模
设所有权值为
$$a_1,a_2,\ldots,a_k$$
并令
$$g=\gcd(a_1,a_2,\ldots,a_k), \qquad base=\min a_i, \qquad mod=\frac{base}{g}$$
所有可达整数一定是 `g` 的倍数，因此先在状态意义上整体除去 `g`
建立 `mod` 个状态：
$$0,1,\ldots,mod-1$$
对于权值 `w`，定义：
$$\Delta=\frac{w}{g}\bmod mod$$
则从任意状态 `r` 存在转移：
$$r\rightarrow(r+\Delta)\bmod mod$$
边权仍然使用原始的 `w`
因此 `dist[r]` 就是该同余类中能够组成的最小原始整数
因为 `base` 本身可以无限次使用，一旦 `dist[r]` 可达：
$$dist[r],\quad dist[r]+base,\quad dist[r]+2base,\quad\ldots$$
全部可达
所以：
$$x\text{ 可达} \iff x\equiv0\pmod g \quad\text{且}\quad dist[(x/g)\bmod mod]\le x$$
对于某个余数类，若 `dist[r] <= x`，则 `[0,x]` 中属于这一类的可达数共有：
$$\left\lfloor \frac{x-dist[r]}{base} \right\rfloor+1$$
将所有余数类累加即可得到 `count_leq(x)`
##### 为什么可以压缩 `step`
若两个权值 `x < y` 满足：
$$\frac{x}{g}\equiv\frac{y}{g}\pmod{mod}$$
那么它们从任何状态出发都会到达相同的下一个状态
而 `x` 的代价严格更小，因此使用 `y` 的转移不可能出现在最短路中，可以直接删除
此外：
$$w\equiv0\pmod{base}$$
对应余数图中的自环，也不可能改善最短距离，因此全部删除
最终有效转移数满足：
$$|step|\le mod-1$$
#### 注意事项
- 这是**完全背包可达性**：每个权值可以使用无限次。0/1 背包或有次数上限时不能使用
- 所有权值必须严格为正。`0` 对可达集合没有贡献，负权会破坏“最小值后不断加 `base`”的结构
- 自动约去 `g` 只压缩内部状态，所有接口仍使用原始整数，无需手动对询问除以 `g`
- 实际空间取决于
$$mod=\frac{\min a_i}{\gcd(a_1,\ldots,a_k)}$$
而不是单纯取决于最小权值
- 因此 `{10^9, 2\cdot10^9}` 实际只有一个状态；自动约 gcd 比直接以 `10^9` 为模重要得多
- 当约 gcd 后的 `mod` 仍达到几百万甚至更大时，余数图可能无法接受，应重新寻找题目的其他结构
- `dist` 使用 `i64`；代码在松弛时通过 `__int128_t` 避免加法本身溢出，但最终最小可达值仍必须能存入 `i64`
- `count_leq()` 包含 `0`，因为空选任何权值即可得到 `0`
- `count_range()` 已经处理负左端点和 `l - 1` 下溢问题，区间统计优先直接调用它
- `g > 1` 时有无穷多个整数不可达，例如所有非 `g` 倍数，因此不存在通常意义上的“最大不可达整数”
- `g == 1` 时所有充分大的整数都可达，并且最大不可达整数为
$$\max_r dist[r]-base$$
即 `largest_unreachable()`
- 若 `base == 1`，所有非负整数均可达，此时 `largest_unreachable()` 返回 `-1`
- `min_value(r)` 中的 `r` 是**原整数模 `base` 的余数**，不是内部压缩后的状态编号
- 无需显式建立余数图邻接表；所有边都由 `step` 即时枚举
#### 常见用法
##### 判断是否可表示
```cpp
vector<i64> weights(k);
for (i64 &w : weights) cin >> w;
ModShortestPath solver(weights);
i64 x;
cin >> x;
cout << (solver.can_make(x) ? "YES\n" : "NO\n");
```
##### 区间内有多少个可表示整数
```cpp
i64 l, r;
cin >> l >> r;
cout << solver.count_range(l, r) << '\n';
```
例如权值：
```cpp
ModShortestPath solver({3, 5});
```
可达集合开始为：
```text
0, 3, 5, 6, 8, 9, 10, ...
```
所以：
```cpp
solver.can_make(7);        // false
solver.can_make(8);        // true
solver.count_range(0, 8);  // 5
```
##### gcd 自动压缩
```cpp
ModShortestPath solver({6, 10});
cout << solver.g << '\n';    // 2
cout << solver.base << '\n'; // 6
cout << solver.mod << '\n';  // 3
solver.can_make(10); // true
solver.can_make(20); // true
solver.can_make(11); // false
```
不需要再手动写：
```cpp
for (i64 &w : weights) w /= g;
x /= g;
```
##### 查询某个原始余数类的最小可达值
```cpp
ModShortestPath solver({6, 10});
solver.min_value(0); // 0
solver.min_value(2); // 20
solver.min_value(4); // 10
solver.min_value(1); // INF
```

这里余数均针对原始的：
$$  6\bmod 6$$
##### 最大不可达整数
```cpp
ModShortestPath solver({3, 5});
auto x = solver.largest_unreachable();
if (x) cout << *x << '\n'; // 7
```
若：
```cpp
ModShortestPath solver({4, 6});
```
则 `g == 2`，所有奇数永远不可达：
```cpp
auto x = solver.largest_unreachable();
assert(!x);
```
#### 复杂度
设：
$$k=\text{输入权值数量}$$
约去最大公约数后的状态数为：
$$s= \frac{\min a_i} {\gcd(a_1,\ldots,a_k)}$$
压缩后的有效转移数为 `t = step.size()`，并且：
$$t\le\min(k-1,s-1)$$
构造时：
- 求 `gcd` 与建立有效转移：$O(k+s)$
- 余数图 Dijkstra：
$$O(st\log s)$$
因此总时间复杂度为：
$$O(k+s+st\log s)$$
通常简写为：
$$O(st\log s)$$
空间复杂度：
$$O(s+t)$$
查询复杂度：

| 接口                                                     |  时间复杂度 |
| ------------------------------------------------------ | -----: |
| `min_value()` / `can_make()` / `largest_unreachable()` | $O(1)$ |
| `count_leq()` / `count_range()`                        | $O(s)$ |
其中 `largest_unreachable()` 的最大 `dist` 已在构造结束时预处理
