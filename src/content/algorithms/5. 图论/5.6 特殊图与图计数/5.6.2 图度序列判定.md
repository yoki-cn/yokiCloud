### 图度序列判定
---
**解决问题：** 判断整数序列能否作为简单无向图、二分图、竞赛图或树的度序列，并在需要时实际构造一张简单无向图
#### Erdős--Gallai：简单无向图度序列
```cpp
bool graphical_degree_sequence(vector<int> d) {
    int n = d.size();
    if (ranges::any_of(d, [&](int x) { return x < 0 || x >= n; })) return false;
    ranges::sort(d, greater{});
    vector<i64> pre(n + 1);
    for (int i : views::iota(0, n)) pre[i + 1] = pre[i] + d[i];
    if (pre[n] & 1) return false;
    for (int k : views::iota(1, n + 1)) {
        int p = lower_bound(d.begin() + k, d.end(), k, greater<int>()) - d.begin();
        i64 rhs = 1LL * k * (k - 1) + 1LL * (p - k) * k + pre[n] - pre[p];
        if (pre[k] > rhs) return false;
    }
    return true;
}
```
##### 判定条件
将序列降序排列
$$
d_1\ge d_2\ge\cdots\ge d_n
$$
它是某张简单无向图的度序列，当且仅当
$$
\sum_{i=1}^{n}d_i
$$
为偶数，并且对所有 $1\le k\le n$
$$
\sum_{i=1}^{k}d_i \le k(k-1)+\sum_{i=k+1}^{n}\min(d_i,k)
$$
前 $k$ 个点最多互相贡献
$$
k(k-1)
$$
度
剩余每个点最多向前 $k$ 个点贡献
$$
\min(d_i,k)
$$
条边
##### 为什么代码需要 `p`
对固定 `k`，找到第一个满足
$$
d_p\le k
$$
的位置
于是
$$
\sum_{i=k+1}^{n}\min(d_i,k)=(p-k)k+\sum_{i=p+1}^{n}d_i
$$
利用前缀和即可快速计算
#### Havel--Hakimi：判定并构造简单图
若不仅要判断，还需要实际恢复一张满足度序列的简单无向图，可以直接使用 Havel--Hakimi
```cpp
optional<vector<pair<int, int>>> construct_graphical(vector<int> d) {
    int n = d.size();
    if (ranges::any_of(d, [&](int x) { return x < 0 || x >= n; })) return nullopt;
    priority_queue<pair<int, int>> q;
    for (int u : views::iota(0, n)) if (d[u]) q.push({d[u], u});
    vector<pair<int, int>> edges;
    while (!q.empty()) {
        auto [du, u] = q.top();
        q.pop();
        if (du > q.size()) return nullopt;
        vector<pair<int, int>> changed;
        changed.reserve(du);
        while (du --) {
            auto [dv, v] = q.top();
            q.pop();
            edges.push_back({u, v});
            if (-- dv < 0) return nullopt;
            if (dv) changed.push_back({dv, v});
        }
        for (auto x : changed) q.push(x);
    }
    return edges;
}
```
##### 原理
每次取当前度数最大的点 `u`
若
$$
deg(u)=d
$$
就把它连接到当前剩余度数最大的 $d$ 个节点，并将这些节点剩余度数减一
Havel--Hakimi 定理保证
> 原序列可图，当且仅当执行一次这种操作后得到的新序列可图

不断执行直到所有剩余度数变成 $0$
##### 使用
```cpp
auto edges = construct_graphical(d);
if (!edges) {
    cout << "Impossible\n";
} else {
    for (auto [u, v] : *edges) {
        // 构造出的简单无向边 u - v
    }
}
```
返回的边数一定为
$$
m=\frac12\sum_i d_i
$$
若只需要判定，不需要构造，优先使用 Erdős--Gallai
#### Gale--Ryser：二分图度序列
给定二分图左右两侧的度序列
$$
a_1,\ldots,a_n
$$
和
$$
b_1,\ldots,b_m
$$
判断是否存在简单二分图满足这些度数
```cpp
bool bipartite_degree_sequence(vector<int> a, vector<int> b) {
    int n = a.size(), m = b.size();
    if (ranges::any_of(a, [&](int x) { return x < 0 || x > m; })) return false;
    if (ranges::any_of(b, [&](int x) { return x < 0 || x > n; })) return false;
    ranges::sort(a, greater{});
    ranges::sort(b, greater{});
    vector<i64> pre_a(n + 1), pre_b(m + 1);
    for (int i : views::iota(0, n)) pre_a[i + 1] = pre_a[i] + a[i];
    for (int i : views::iota(0, m)) pre_b[i + 1] = pre_b[i] + b[i];
    if (pre_a[n] != pre_b[m]) return false;
    for (int k : views::iota(1, n + 1)) {
        int p = lower_bound(b.begin(), b.end(), k, greater<int>()) - b.begin();
        i64 rhs = 1LL * p * k + pre_b[m] - pre_b[p];
        if (pre_a[k] > rhs) return false;
    }
    return true;
}
```
##### 判定条件
将左侧度数降序
$$
a_1\ge a_2\ge\cdots\ge a_n
$$
首先总度数必须相等
$$
\sum_{i=1}^{n}a_i=\sum_{j=1}^{m}b_j
$$
并且对所有 $1\le k\le n$
$$
\sum_{i=1}^{k}a_i
\le
\sum_{j=1}^{m}\min(b_j,k)
$$
这就是 Gale--Ryser 判定
代码同样利用降序和前缀和把右侧求和快速计算
#### Landau：竞赛图得分序列
竞赛图是在完全图每条边上任选一个方向得到的有向图
节点得分定义为出度
```cpp
bool tournament_score_sequence(vector<int> s) {
    int n = s.size();
    if (ranges::any_of(s, [&](int x) { return x < 0 || x >= n; })) return false;
    ranges::sort(s);
    i64 sum = 0;
    for (int k : views::iota(1, n + 1)) {
        sum += s[k - 1];
        if (k < n && sum < 1LL * k * (k - 1) / 2) return false;
    }
    return sum == 1LL * n * (n - 1) / 2;
}
```
##### 判定条件
将得分升序排列
$$
s_1\le s_2\le\cdots\le s_n
$$
对于所有
$$
1\le k<n
$$
必须满足
$$
\sum_{i=1}^{k}s_i\ge\binom{k}{2}
$$
并且总得分恰好为
$$
\sum_{i=1}^{n}s_i=\binom{n}{2}
$$
这就是 Landau 定理
##### 为什么是不等号 `>=`
任选前 $k$ 个节点
它们内部恰好存在
$$
\binom{k}{2}
$$
场比赛
每场一定贡献一个胜场给这 $k$ 个节点中的某个点
因此它们的总出度至少为
$$
\binom{k}{2}
$$
#### 树的度序列
这个结论很短，不需要单独写算法
##### `n = 1`
唯一的树只有一个点，因此必须
$$
d_1=0
$$
##### `n >= 2`
一个正整数序列是某棵树的度序列，当且仅当
$$
d_i\ge1
$$
且
$$
\sum_{i=1}^{n}d_i=2(n-1)
$$
可以直接写成
```cpp
bool tree_degree_sequence(const vector<int> &d) {
    int n = d.size();
    if (!n) return false;
    if (n == 1) return d[0] == 0;
    return ranges::all_of(d, [](int x) { return x >= 1; }) &&
           accumulate(d.begin(), d.end(), 0LL) == 2LL * (n - 1);
}
```
其充分性可以直接由 Prüfer 序列得到
节点 `i` 在 Prüfer 序列中出现
$$
d_i-1
$$
次
总出现次数为
$$
\sum_i(d_i-1)=n-2
$$
恰好是一条合法 Prüfer 序列的长度
#### 选型

| 问题          | 方法            |
| ----------- | ------------- |
| 简单无向图，只判断   | Erdős--Gallai |
| 简单无向图，需要恢复边 | Havel--Hakimi |
| 简单二分图左右度数   | Gale--Ryser   |
| 竞赛图出度序列     | Landau        |
| 树的度序列       | 总度数 + 正性      |
#### 常见用法
##### 判断简单图度序列
```cpp
vector<int> d(n);
cin >> d;
if (graphical_degree_sequence(d)) {
    // 存在简单无向图
}
```
如果当前环境不支持直接 `cin >> vector`，正常循环读入即可
```cpp
for (int &x : d) cin >> x;
```
##### 构造一张简单图
```cpp
auto res = construct_graphical(d);
if (!res) {
    cout << "Impossible\n";
} else {
    cout << res->size() << '\n';
    for (auto [u, v] : *res) cout << u + 1 << ' ' << v + 1 << '\n';
}
```
##### 判断二分图度序列
```cpp
if (bipartite_degree_sequence(left_degree, right_degree)) {
    // 存在对应简单二分图
}
```
##### 判断竞赛图得分序列
```cpp
if (tournament_score_sequence(score)) {
    // 存在对应竞赛图
}
```
#### 简单图、重边图不要混淆
Erdős--Gallai、Havel--Hakimi、Gale--Ryser 都讨论**简单图**
也就是
* 不允许自环
* 两点之间最多一条边
若允许重边，判定条件会发生明显变化
例如无自环但允许平行边的无向多重图，只需要
$$
\sum_i d_i
$$
为偶数，并且最大度数满足
$$
\max_i d_i\le\sum_{j\ne i}d_j
$$
若连自环也允许，并规定自环贡献度数 $2$，则只需要总度数为偶数
因此做题时第一件事应确认题目中的“图”是否默认简单图
#### Erdős--Gallai 与 Havel--Hakimi 的选择
只判定时推荐 Erdős--Gallai
排序后检查不等式即可，复杂度稳定
Havel--Hakimi 的优势是能自然构造一张图
但如果度数很大，实际需要显式生成
$$
m=\frac12\sum_i d_i
$$
条边，因此复杂度至少与输出边数有关
#### 注意事项
* Erdős--Gallai 输入允许包含 $0$
* 简单无向图中必须有 $0\le d_i<n$
* 总度数必须为偶数
* Havel--Hakimi 返回任意一张满足条件的图，不保证字典序或其他性质
* 二分图中左侧度数不能超过右侧点数，右侧同理
* Gale--Ryser 左右两侧总度数必须相同
* Landau 使用的是竞赛图的**出度序列**
* 如果题目给的是竞赛图入度序列，仍可直接使用 Landau，因为将所有边反向后仍是竞赛图
* 有向简单图同时给定入度与出度的通用判定属于更一般的有向度序列问题，不建议塞入这份基础板子
* 若要求实际构造二分图，可以使用 Havel--Hakimi 的二分版本或最大流，不必修改 Gale--Ryser 判定函数
#### 快速回忆
```text
简单无向图
    Erdős--Gallai
    sum d 偶数
    前 k：
    sum d[1..k] <= k(k-1) + sum min(d[i], k)

需要构造简单图
    Havel--Hakimi
    最大度点连接当前度数最大的若干点

简单二分图
    Gale--Ryser
    sum left = sum right
    前 k 左度 <= sum min(right[j], k)

竞赛图
    Landau
    升序
    前 k 和 >= C(k,2)
    总和 = C(n,2)

树
    n > 1 时全部度 >= 1
    sum d = 2(n-1)
```
#### 复杂度
Erdős--Gallai
排序
$$
O(n\log n)
$$
每个 `k` 二分一次
$$
O(n\log n)
$$
总时间
$$
O(n\log n)
$$
空间
$$
O(n)
$$
Havel--Hakimi 若最终构造出 $m$ 条边
$$
O((n+m)\log n)
$$
最坏简单图中
$$
m=O(n^2)
$$
因此最坏
$$
O(n^2\log n)
$$
输出本身就可能需要
$$
O(n^2)
$$
空间
Gale--Ryser
$$
O((n+m)\log(n+m))
$$
其中这里的 $m$ 表示右侧点数，不是边数
若左右规模都记为 $O(N)$，可简写为
$$
O(N\log N)
$$
Landau
$$
O(n\log n)
$$
树度序列
$$
O(n)
$$
