### 背包家族
---
**定位：** 记录容量型 DP 的经典状态、循环方向与常见变形
以下默认最大化问题，不可达值使用
```cpp
constexpr i64 NINF = numeric_limits<i64>::lowest() / 4;
```
#### 统一状态
---
二维基础状态
`dp[i][j]`：只考虑前 `i` 种物品，容量条件为 `j` 时的最优值
压掉物品维后通常写成 `dp[j]`
初始化先区分两种语义
- 容量不超过 `W`：通常 `dp[0..W] = 0`
- 容量恰好为 `W`：`dp[0] = 0`，其余为 `NINF`
#### 0/1 背包
---
每件物品至多选一次
二维转移
$$dp_{i,j}=\max(dp_{i-1,j},dp_{i-1,j-w_i}+v_i)$$
压维后容量必须逆序
```cpp
vector<i64> dp(W + 1);
for (int i = 0; i < n; ++ i) {
    for (int j = W; j >= w[i]; -- j) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```
- 逆序保证 `dp[j-w[i]]` 仍来自上一层
- 时间 $O(nW)$，空间 $O(W)$
#### 完全背包
---
每件物品可选任意次
$$dp_j=\max(dp_j,dp_{j-w_i}+v_i)$$
容量正序
```cpp
for (int i = 0; i < n; ++ i) {
    for (int j = w[i]; j <= W; ++ j) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```
- 正序允许本层刚更新的状态继续使用当前物品
- 时间 $O(nW)$，空间 $O(W)$
#### 多重背包
---
第 `i` 种物品最多选 `c[i]` 件
朴素转移
$$dp_{i,j}=\max_{0\le t\le c_i,tw_i\le j}\{dp_{i-1,j-tw_i}+tv_i\}$$
朴素复杂度 $O(W\sum c_i)$
##### 二进制拆分
把 `c` 拆成 `1,2,4,...,rest` 个物品，再做 0/1 背包
```cpp
for (int i = 0; i < n; ++ i) {
    int c = min(cnt[i], W / w[i]);
    for (int k = 1; c; k <<= 1) {
        int t = min(k, c);
        int ww = w[i] * t;
        i64 vv = v[i] * t;
        for (int j = W; j >= ww; -- j) {
            dp[j] = max(dp[j], dp[j - ww] + vv);
        }
        c -= t;
    }
}
```
时间 $O(W\sum\log(c_i+1))$
##### 单调队列优化
固定一件物品 `(w,v,c)`，按容量模 `w` 分组
令 `j = r + kw`

$$ndp_{r+kw}=kv+\max_{k-c\le t\le k}\{dp_{r+tw}-tv\}$$
括号内是长度 `c+1` 的滑动窗口最大值，可用单调队列
```cpp
vector<i64> old = dp;
for (int r = 0; r < w && r <= W; ++ r) {
    deque<int> q;
    for (int k = 0; r + k * w <= W; ++ k) {
        while (!q.empty() && q.front() < k - c) q.pop_front();
        if (old[r + k * w] != NINF) {
            i64 x = old[r + k * w] - 1LL * k * v;
            while (!q.empty()) {
                int t = q.back();
                i64 y = old[r + t * w] - 1LL * t * v;
                if (y > x) break;
                q.pop_back();
            }
            q.push_back(k);
        }
        if (!q.empty()) {
            int t = q.front();
            dp[r + k * w] = old[r + t * w] + 1LL * (k - t) * v;
        } else dp[r + k * w] = NINF;
    }
}
```
- 必须从整层 `old` 转移
- 单件物品处理 $O(W)$，总时间 $O(nW)$
#### 混合背包
---
每种物品分别属于 0/1、完全或多重
只需按类型选对应循环
```cpp
if (c == -1) {
    for (int j = W; j >= w; -- j) dp[j] = max(dp[j], dp[j - w] + v);
} else if (c == 0) {
    for (int j = w; j <= W; ++ j) dp[j] = max(dp[j], dp[j - w] + v);
} else {
    // 二进制拆分或单调队列
}
```
#### 分组背包
---
物品分成若干组，每组至多选一件
**状态：** 处理完前若干组后，容量为 `j` 的最优值
一组内所有选择必须从上一层 `old` 转移
```cpp
for (const auto &g : group) {
    auto old = dp;
    for (int j = 0; j <= W; ++ j) {
        dp[j] = old[j];
        for (auto [w, v] : g) {
            if (j >= w) dp[j] = max(dp[j], old[j - w] + v);
        }
    }
}
```
时间 $O(W\sum |G_i|)$
#### 二维费用背包
---
每件物品同时消耗两种容量 `a[i]`,`b[i]`
0/1 形式
$$dp_{x,y}=\max(dp_{x,y},dp_{x-a_i,y-b_i}+v_i)$$
两个容量都逆序
```cpp
for (int i = 0; i < n; ++ i) {
    for (int x = A; x >= a[i]; -- x) {
        for (int y = B; y >= b[i]; -- y) {
            dp[x][y] = max(dp[x][y], dp[x - a[i]][y - b[i]] + v[i]);
        }
    }
}
```
时间 $O(nAB)$，空间 $O(AB)$
#### 有依赖的背包
---
典型条件是选择儿子前必须选择父亲

**状态：** `dp[u][j]` 表示必须选择 `u`，并在 `u` 子树内恰好使用容量 `j` 的最大价值
初始化
```cpp
dp[u][w[u]] = v[u];
```
合并一个儿子 `v`
$$ndp_{j+k}=\max(ndp_{j+k},dp_{u,j}+dp_{v,k})$$
```cpp
for (int j = min(W, su); j >= 0; -- j) {
    if (dp[u][j] == NINF) continue;
    for (int k = 1; k <= min(W - j, sv); ++ k) {
        if (dp[v][k] == NINF) continue;
        ndp[j + k] = max(ndp[j + k], dp[u][j] + dp[v][k]);
    }
}
```
- 森林可接一个体积价值都为 `0` 的虚根
- 一般上界 $O(nW^2)$，实际可用子树有效容量截断
- 特殊先修结构可能有更强优化，不能无证明套用
#### 恰好装满与不可达状态
---
最大化时
```cpp
vector<i64> dp(W + 1, NINF);
dp[0] = 0;
```
转移前检查来源可达
```cpp
if (dp[j - w] != NINF) {
    dp[j] = max(dp[j], dp[j - w] + v);
}
```
- `NINF` 不要取 `numeric_limits<i64>::lowest()` 本身再参与加法
- 最小化背包同理改用 `INF`
#### 方案数背包
---
##### 统计恰好装满的方案数
0/1 背包
```cpp
vector<i64> dp(W + 1);
dp[0] = 1;
for (int i = 0; i < n; ++ i) {
    for (int j = W; j >= w[i]; -- j) {
        dp[j] = (dp[j] + dp[j - w[i]]) % mod;
    }
}
```
完全背包只需把容量改为正序
##### 最优值的方案数
同时维护 `{val,cnt}`
若新值更优则覆盖计数，相等则累加计数
```cpp
if (nv > val[j]) {
    val[j] = nv;
    cnt[j] = cnt[j - w];
} else if (nv == val[j]) {
    cnt[j] = (cnt[j] + cnt[j - w]) % mod;
}
```
#### 计数背包的组合与排列
---
完全背包计数时，循环顺序决定统计对象
##### 组合数
每种物品可选任意次，选择顺序不同视为同一种方案
物品在外、容量在内：
```cpp
vector<i64> dp(W + 1);
dp[0] = 1;
for (int w : a) {
    for (int j = w; j <= W; ++ j) {
        dp[j] = (dp[j] + dp[j - w]) % mod;
    }
}
````
此时每种方案只会按照固定的物品顺序生成一次
#### 排列数
每种物品可选任意次，选择顺序不同视为不同方案
容量在外、物品在内：
```cpp
vector<i64> dp(W + 1);
dp[0] = 1;
for (int j = 1; j <= W; ++ j) {
    for (int w : a) if (w <= j) {
        dp[j] = (dp[j] + dp[j - w]) % mod;
    }
}
```
例如物品重量为 `{1,2}`、容量为 `3`
- 组合：`1+1+1`、`1+2`，共 `2` 种
- 排列：`1+1+1`、`1+2`、`2+1`，共 `3` 种
> [!warning]  
> 若 `a` 中相同重量表示同一种物品，计数组合前应先去重，否则相同重量会被当作不同物品类型
#### 方案恢复
---
若需要恢复一组 0/1 背包方案，最稳妥的是保留二维 `dp[i][j]`
从 `(n,W)` 逆推
- 若 `dp[i][j] == dp[i-1][j]`，可不选第 `i` 件
- 若 `j >= w[i-1]` 且 `dp[i][j] == dp[i-1][j-w[i-1]] + v[i-1]`，可选第 `i` 件
- 有平局时恢复规则决定字典序或是否偏向选择
只存一维数组时若仍要恢复，需要额外父指针或重新计算
#### 前 K 优解
---
若题目要求前 `K` 个方案值，可让每个容量维护长度 `K` 的降序数组，再把“不选”和“选当前物品”两列归并
- 时间通常 $O(nWK)$
- 必须先确认题目区分“不同方案”还是“不同价值”
- 相同价值若代表不同方案，不能去重
#### Subset Sum
---
只判断某个和是否可达时，状态为布尔值
0/1 形式
$$dp_j\mathrel{|}=dp_{j-w_i}$$
若容量较大且只做可达性，可用 `bitset` 或动态位集把整层转移改成位移与或
#### 背包选型速查
| 条件 | 循环或方法 |
|---|---|
| 每件至多一次 | 容量逆序 |
| 每件无限次 | 容量正序 |
| 每件最多 `c` 次 | 二进制拆分 / 单调队列 |
| 每组至多一件 | 整组从 `old` 转移 |
| 两种容量 | 两维都按 0/1 或完全规则枚举 |
| 父子依赖 | 树上分组合并 |
| 恰好装满 | 仅 `dp[0] = 0`，其余不可达 |
| 只求可达性 | 布尔 DP / bitset |
| 需要方案数 | 值相等时累加计数 |
| 需要方案 | 二维 DP 或父指针 |
