### 树、轮廓线、概率与期望 DP
---
**定位：** 记录树上局部状态、换根、网格轮廓状态以及概率与期望方程
#### 树形 DP 通用形态
---
先任选根，把无根树转成父子关系
常见状态写成 `dp[u][s]`，其中 `s` 只描述 `u` 与父亲、儿子交界处需要保留的信息
处理顺序通常是后序 DFS
```cpp
auto dfs = [&](auto &&self, int u, int fa) -> void {
    // init dp[u]
    for (int v : g[u]) if (v != fa) {
        self(self, v, u);
        // merge dp[v] into dp[u]
    }
};
```
#### 树上最大权独立集
---
相邻点不能同时选择
**状态**
- `dp[u][0]`：不选 `u` 的最大权值
- `dp[u][1]`：选择 `u` 的最大权值
转移
$$dp_{u,0}=\sum_v\max(dp_{v,0},dp_{v,1})$$
$$dp_{u,1}=w_u+\sum_vdp_{v,0}$$
答案 `max(dp[root][0], dp[root][1])`
时间 $O(n)$，空间 $O(n)$
#### 树上最小点覆盖
---
要求每条边至少一个端点被选择
**状态**
- `dp[u][0]`：不选 `u`
- `dp[u][1]`：选择 `u`
转移
$$dp_{u,0}=\sum_vdp_{v,1}$$
$$dp_{u,1}=w_u+\sum_v\min(dp_{v,0},dp_{v,1})$$
若是无权点覆盖令 `w[u] = 1`
#### 树上最小支配集
---
每个点必须被自己、父亲或儿子至少一个选中
三状态最常用
- `dp[u][0]`：选择 `u`
- `dp[u][1]`：不选 `u`，由至少一个儿子覆盖
- `dp[u][2]`：不选 `u`，等待父亲覆盖
对每个儿子 `v`
```text
dp[u][0] += min(dp[v][0], dp[v][1], dp[v][2])
base      += min(dp[v][0], dp[v][1])
extra      = min(extra, dp[v][0] - min(dp[v][0], dp[v][1]))
dp[u][1]   = base + extra
dp[u][2]   = base
```
- 叶子的 `dp[u][1]` 不可达
- 根不能处于等待父亲覆盖状态
- 答案 `min(dp[root][0], dp[root][1])`
#### 树上最大匹配
---
每个点最多属于一条匹配边
可设
- `dp[u][0]`：`u` 不与儿子匹配
- `dp[u][1]`：`u` 与恰好一个儿子匹配
先令
$$base=\sum_v\max(dp_{v,0},dp_{v,1})$$
若让 `u-v` 成为匹配边，则 `v` 不能再与自己的儿子匹配
$$dp_{u,1}=\max_v\{base-\max(dp_{v,0},dp_{v,1})+dp_{v,0}+w_{u,v}\}$$
$$dp_{u,0}=base$$
无权最大匹配令边权为 `1`
#### 树上背包
---
当每个子树需要再维护容量维时，状态变成 `dp[u][j]`
每合并一个儿子就是一次分组卷积
完整模型见 **12.2 有依赖的背包**
#### 换根 DP
---
目标是求每个点作为根时的答案
基本步骤
1. 任选根做一次向下 DP
2. 再从父亲向儿子传递“树外贡献”
3. 得到所有根的答案
##### 所有点距离和
树边 `u-v` 权值为 `w`
先求
- `siz[u]`：子树大小
- `down[u]`：`u` 到自己子树所有点的距离和
从 `u` 换根到儿子 `v`

$$ans_v=ans_u+(n-2siz_v)w$$
原因是 `v` 子树内 `siz[v]` 个点距离减少 `w`，其余点距离增加 `w`
##### 一般换根
若儿子贡献可以结合，常见三种写法
- 可逆运算：总贡献减去当前儿子再传下去
- 维护最大值与次大值：排除一个儿子时取另一个
- 前后缀合并：适用性最广，可排除任意一个儿子
#### 行轮廓状压 DP
---
网格的一维较短时，只保存当前行或列的边界状态
常见状态
- `mask`：当前行哪些位置被选择、占用或从上一行延伸
- `dp[row][mask]`：处理完前若干行后的方案数或最优值
典型复杂度取决于合法状态数 `S`，常见为 $O(nS^2)$ 或 $O(nmS)$
#### 网格独立集
---
每行选择若干格，同行相邻和上下相邻不能同时选择
先预处理合法行状态
```cpp
vector<int> st;
for (int s = 0; s < 1 << m; ++ s) {
    if (!(s & (s << 1))) st.push_back(s);
}
```
两行状态 `a,b` 可相邻当且仅当
```cpp
(a & b) == 0
```
有障碍时还要求
```cpp
(a & block[row]) == 0
```
若斜对角也冲突，再检查 `(a << 1) & b` 与 `(a >> 1) & b`
#### 多米诺骨牌铺满
---
用 `1 x 2` 骨牌铺满 `n x m`
**状态：** `mask` 表示当前行被上一行竖放骨牌占用的位置
逐格处理
- 当前位已占用：跳到下一格
- 当前位空：可横放，或竖放并在下一行留下一个占用位
最终答案必须回到 `mask = 0`
通常让 `m = min(n,m)`，指数维尽量小
#### 插头 DP
---
适合 Hamilton 回路、连通块、路径覆盖等需要保存边界连通关系的网格问题
常见轮廓有 `m+1` 个插头位置
单回路常用 2 bit 括号表示
- `0`：无插头
- `1`：左括号
- `2`：右括号
```cpp
struct Plug {
    u64 s{};
    int get(int p) const { return s >> (p * 2) & 3; }
    void set(int p, int x) {
        s &= ~(3ULL << (p * 2));
        s |= u64(x) << (p * 2);
    }
    int right(int p, int n) const {
        int b = 0;
        for (int i = p; i < n; ++ i) {
            int x = get(i);
            if (x == 1) ++ b;
            else if (x == 2) -- b;
            if (!b) return i;
        }
        return -1;
    }
    int left(int p) const {
        int b = 0;
        for (int i = p; i >= 0; -- i) {
            int x = get(i);
            if (x == 2) ++ b;
            else if (x == 1) -- b;
            if (!b) return i;
        }
        return -1;
    }
};
```
- 插头 DP 没有一套通用完整转移，闭环时机、障碍与连通要求都会改变规则
- 单回路通常只允许在最后一个合法格闭合最终回路
- 若 `2*(m+1) > 64`，不能继续用 `u64` 保存全部插头
#### 三进制轮廓状态
---
若每个边界位置只需独立保存 `0/1/2`，可用三进制整数编码
$$state=\sum_i d_i3^i$$
- 适合每格独立三状态
- 不适合直接表示任意连通块等价关系
#### Steiner Tree 状压 DP
---
给定 `k` 个终端点，求连接全部终端的最小子图
**状态：** `dp[s][v]` 表示连接终端集合 `s` 且当前汇合在 `v` 的最小代价
同一点合并两个终端集合
$$dp_{s,v}=\min_{t\subset s,t\ne0}\{dp_{t,v}+dp_{s\setminus t,v}\}$$
随后对每个 `s` 做一次多源最短路松弛
典型复杂度 $O(3^k n+2^k(m+n)\log n)$
具体图论实现统一放 Steiner Tree 板子，此处只保留状态模型
#### 概率 DP
---
若状态转移无环，常正向维护到达概率
**状态：** `dp[u]` 表示到达状态 `u` 的总概率
对边 `u -> v`，转移概率为 `p`
$$dp_v\mathrel{+}=dp_u p$$
- 多条路径到同一状态时概率相加
- 依赖图是 DAG 时按拓扑序转移
- 概率和是否等于 `1` 由题意决定，失败或停留状态要显式建模
#### 期望的线性性
---
若总贡献可以写成：
$$
X=\sum_i X_i
$$
则无论各随机变量是否独立，都有：
$$
E[X]=\sum_iE[X_i]
$$
特别地，令指示变量：
$$
X_i=[A_i]
$$
则：
$$
E[X_i]=P(A_i)
$$
因此：
$$
E\left[\sum_i[A_i]\right]=\sum_iP(A_i)
$$
##### 常见识别
题目询问下列量的期望时，优先尝试拆成单个元素或事件的贡献：
- 满足条件的元素个数
- 被覆盖的位置数
- 逆序对数量
- 边、点、区间产生的总贡献
例如随机排列的逆序对数：
$$
X=\sum_{i<j}[p_i>p_j]
$$
每一对成为逆序对的概率均为 $\frac12$，因此：
$$
E[X]=\binom n2\frac12
$$
> [!tip]
> 期望可加性不要求独立，但 $E[XY]=E[X]E[Y]$ 一般需要额外条件

若目标是最大值、最小值、首次到达时间等不能直接拆成加法贡献的量，再考虑概率 DP、期望 DP 或尾和公式
#### 期望 DP
---
从状态 `u` 出发到结束的期望代价为 `E[u]`
基本方程
$$E_u=c_u+\sum_v p_{u,v}E_v$$
若除自环外其余依赖无环，设自环概率为 `p`
$$E_u=c_u+pE_u+\sum_{v\ne u}p_{u,v}E_v$$
移项得到
$$E_u=\frac{c_u+\sum_{v\ne u}p_{u,v}E_v}{1-p}$$
- 终止状态通常 `E = 0`
- `p = 1` 且每步有正代价时期望发散
- 一般有环期望要建立 `(I-P)E=c` 线性方程组，不可强行按拓扑顺序递推
- 浮点无穷可写 `numeric_limits<ld>::infinity()`
#### 概率与期望方向判断
- 问“到达某状态的概率”时优先尝试正向分配概率
- 问“从当前状态到结束还需要多少”时优先尝试逆向期望方程
- 有自环先尝试移项消掉
- 有一般环再考虑高斯消元、吸收马尔可夫链或题目特有结构
#### 选型速查
| 结构 | 典型状态 |
|---|---|
| 相邻点不能同时选 | 树上独立集 `dp[u][0/1]` |
| 每条边至少覆盖一个端点 | 树上点覆盖 `dp[u][0/1]` |
| 每个点必须被邻近选点覆盖 | 树上支配集三状态 |
| 每个点最多匹配一条边 | 树上匹配两状态 |
| 求所有根答案 | 换根 DP |
| 网格短边很小 | 行轮廓状压 |
| 边界还要记录连通关系 | 插头 DP |
| 到达概率 | 正向概率 DP |
| 剩余期望代价 | 逆向期望方程 |
