### 序列、区间、数位与基础状态 DP
---
#### 通用约定
---
```cpp
constexpr i64 INF = numeric_limits<i64>::max() / 4;
constexpr i64 NINF = numeric_limits<i64>::lowest() / 4;
```
- 最小化不可达状态用 `INF`，最大化不可达状态用 `NINF`
- 不要直接用 `numeric_limits<i64>::max()` 后继续加法
- 从不可达状态转移前先判断，或保证有限值与增量的绝对值远小于 `INF`
- 计数 DP 的不可达状态通常是 `0`
- 状态压缩前先写清 `dp` 的含义、初值、转移顺序、答案位置
#### 最大子段和
---
**状态：** `dp[i]` 表示以 `i` 结尾的非空最大子段和
$$dp_i=\max(a_i,dp_{i-1}+a_i)$$
答案为 $\max_i dp_i$
```cpp
i64 cur = a[0], ans = a[0];
for (int i = 1; i < n; ++ i) {
    cur = max(a[i], cur + a[i]);
    ans = max(ans, cur);
}
```
- 全负数组仍返回最大单点
- 若允许空段，令 `ans = max<i64>(0, ans)`
- 时间 $O(n)$，空间 $O(1)$
#### LIS 最长上升子序列
---
**基础状态：** `dp[i]` 表示以 `i` 结尾的 LIS 长度
$$dp_i=1+\max_{j<i,a_j<a_i}dp_j$$
朴素复杂度 $O(n^2)$
**经典优化：** `d[len-1]` 保存长度为 `len` 的上升子序列最小末尾
```cpp
template<class T>
int lis(const vector<T> &a, bool strict = true) {
    vector<T> d;
    for (const T &x : a) {
        auto it = strict ? rangs::lower_bound(d, x) : ranges::upper_bound(d, x);
        if (it == d.end()) d.push_back(x);
        else *it = x;
    }
    return d.size();
}
```
- 严格上升用 `lower_bound`
- 不下降用 `upper_bound`
- `d` 不是实际的一条 LIS，只记录每个长度的最优末尾
- 若 `a[i]` 很大但可离散化，也可把朴素转移改成 BIT / 线段树前缀最大值
- 时间 $O(n\log n)$，空间 $O(n)$
#### LCS 最长公共子序列
---
**状态：** `dp[i][j]` 表示 `a[0..i)` 与 `b[0..j)` 的 LCS 长度
$$
dp_{i,j}=\begin{cases}
dp_{i-1,j-1}+1&a_{i-1}=b_{j-1}\\
\max(dp_{i-1,j},dp_{i,j-1})&a_{i-1}\ne b_{j-1}
\end{cases}
$$
滚动数组写法
```cpp
template<class S>
int lcs(const S &a, const S &b) {
    int n = a.size(), m = b.size();
    vector<int> dp(m + 1);
    for (int i = 1; i <= n; ++ i) {
        int pre{};
        for (int j = 1; j <= m; ++ j) {
            int old{ dp[j] };
            if (a[i - 1] == b[j - 1]) dp[j] = pre + 1;
            else dp[j] = max(dp[j], dp[j - 1]);
            pre = old;
        }
    }
    return dp[m];
}
```
- 仅求长度时把较短序列放第二维
- 两序列都是同一组互异元素的排列时，可映射位置后转 LIS，复杂度降为 $O(n\log n)$
- 普通时间 $O(nm)$，滚动后空间 $O(m)$
#### 最长公共子串
---
与 LCS 不同，要求选出的元素在两个序列中都连续
定义 `dp[j]` 为当前处理到 `a[i]` 时，以 `a[i]`、`b[j - 1]` 结尾的最长公共子串长度
$$
dp_{i,j}=
\begin{cases}
dp_{i-1,j-1}+1&a_{i-1}=b_{j-1}\\
0&a_{i-1}\ne b_{j-1}
\end{cases}
$$
滚动数组时必须倒序枚举 `j`
```cpp
template<class Seq>
int lcstr(const Seq &a, const Seq &b) {
    int m{ int(b.size()) }, ans{};
    vector<int> dp(m + 1);
    for (const auto &x : a) {
        for (int j = m - 1; j >= 0; -- j) {
            dp[j + 1] = x == b[j] ? dp[j] + 1 : 0;
            ans = max(ans, dp[j + 1]);
        }
    }
    return ans;
}
```
- LCS 失配时继承相邻状态，公共子串失配时必须清零
- 时间复杂度 $O(nm)$
- 空间复杂度 $O(m)$
#### LCIS 最长公共上升子序列
---
**状态：** `dp[j]` 表示以 `b[j]` 结尾且已经匹配当前 `a` 前缀的 LCIS 长度
```cpp
template<class T>
int lcis(const vector<T> &a, const vector<T> &b) {
    vector<int> dp(b.size());
    for (const T &x : a) {
        int best{};
        for (int j = 0; j < (int)b.size(); ++ j) {
            if (b[j] < x) best = max(best, dp[j]);
            else if (b[j] == x) dp[j] = max(dp[j], best + 1);
        }
    }
    return b.empty() ? 0 : *max_element(dp.begin(), dp.end());
}
```
- `best` 只允许来自 `b[j] < x` 的旧状态
- 两个判断不能随意改成两个独立 `if`
- 时间 $O(nm)$，空间 $O(m)$
#### 编辑距离
---
**状态：** `dp[i][j]` 表示把 `a[0..i)` 变成 `b[0..j)` 的最小代价

$$dp_{i,j}=\min\begin{cases}
dp_{i-1,j}+1&删除\\
dp_{i,j-1}+1&插入\\
dp_{i-1,j-1}+[a_{i-1}\ne b_{j-1}]&替换
\end{cases}$$
```cpp
template<class S>
int edit_dis(const S &a, const S &b) {
    int n = a.size(), m = b.size();
    vector<int> dp(m + 1);
    iota(dp.begin(), dp.end(), 0);
    for (int i = 1; i <= n; ++ i) {
        int pre{ dp[0] };
        dp[0] = i;
        for (int j = 1; j <= m; ++ j) {
            int ol{ dp[j] };
            dp[j] = min({dp[j] + 1, dp[j - 1] + 1, pre + (a[i - 1] != b[j - 1])});
            pre = old;
        }
    }
    return dp[m];
}
```
- 不同操作代价时直接替换三个转移项
- 时间 $O(nm)$，空间 $O(m)$
#### 最长回文子序列
---
**状态：** `dp[l][r]` 表示闭区间 `[l,r]` 的最长回文子序列长度
$$dp_{l,r}=\begin{cases}
dp_{l+1,r-1}+2&a_l=a_r\\
\max(dp_{l+1,r},dp_{l,r-1})&a_l\ne a_r
\end{cases}$$
- 区间长度从小到大枚举
- 单点初值 `dp[i][i] = 1`
- 也可转化为原串与反串的 LCS
- 时间 $O(n^2)$，空间 $O(n^2)$
#### 区间 DP 通用形态
---
若最后一次操作把 `[l,r)` 分为 `[l,k)` 与 `[k,r)`，常见状态为
$$dp_{l,r}=\operatorname{opt}_{l<k<r}\{dp_{l,k}+dp_{k,r}+w(l,r,k)\}$$
枚举顺序
```cpp
for (int len = 2; len <= n; ++ len) {
    for (int l = 0; l + len <= n; ++ l) {
        int r = l + len;
        for (int k = l + 1; k < r; ++ k) {
            // dp[l][r] <- dp[l][k], dp[k][r]
        }
    }
}
```
- 普通复杂度通常 $O(n^3)$
- 若最优决策单调，检查 12.4 的分治优化或 Knuth 优化
- 环形区间通常复制一倍，只计算长度不超过 `n` 的区间
#### 区间博弈 DP
---
两人轮流从区间两端取数，双方都最优，求先手相对后手的最大净胜分
定义：
$$
dp_{l,r}=\text{面对区间 }[l,r)\text{ 时当前玩家相对另一人的最大净胜分}
$$
转移：
$$
dp_{l,r}=
\max
\begin{cases}
a_l-dp_{l+1,r}\\
a_{r-1}-dp_{l,r-1}
\end{cases}
$$
边界：
$$
dp_{i,i}=0
$$
```cpp
i64 interval_game(const vector<i64> &a) {
    int n{ int(a.size()) };
    vector dp(n + 1, vector<i64>(n + 1));
    for (int len = 1; len <= n; ++ len) {
        for (int l = 0; l + len <= n; ++ l) {
            int r{ l + len };
            dp[l][r] = max(a[l] - dp[l + 1][r], a[r - 1] - dp[l][r - 1]);
        }
    }
    return dp[0][n];
}
````
若所有取得的数最终都会被分完，记总和为 `sum`、净胜分为 `d`，则：
$$A=\frac{sum+d}{2},\qquad B=\frac{sum-d}{2}$$
核心技巧是直接维护双方得分差，避免同时记录先手和后手两个状态
时间复杂度 $O(n^2)$，空间复杂度 $O(n^2)$
#### 划分 DP / 分段 DP
---
将前 `n` 个元素划分为恰好 `K` 个非空连续段，每段 `[j,i)` 的代价为 `w(j,i)`

定义：

$$
dp_{k,i}=\text{前 }i\text{ 个元素划成 }k\text{ 段的最优值}
$$

转移：

$$
dp_{k,i}=\min_{k-1\le j<i}\{dp_{k-1,j}+w(j,i)\}
$$

初始化：

$$
dp_{0,0}=0
$$

其余状态为 `INF`

直接转移复杂度 $O(Kn^2)$，只依赖上一层时空间可压到 $O(n)$

```cpp
vector<i64> dp(n + 1, INF), ndp(n + 1);
dp[0] = 0;
for (int k = 1; k <= K; ++ k) {
    fill(ndp.begin(), ndp.end(), INF);
    for (int i = k; i <= n; ++ i) {
        for (int j = k - 1; j < i; ++ j) {
            if (dp[j] != INF) chmin(ndp[i], dp[j] + w(j, i));
        }
    }
    dp.swap(ndp);
}
````

#### 优化入口

- `opt[k][i]` 随 `i` 单调 → 分治优化
- `w(j,i)` 展开后出现 `k_j x_i+b_j` → 斜率优化
- 转移矩阵满足 Monge 性质 → 检查决策单调
- 要求恰好 `K` 段且段数可通过罚值控制 → 检查 WQS 二分
#### 石子合并
---
**状态：** `dp[l][r]` 表示把 `[l,r)` 合成一堆的最小代价
$$dp_{l,r}=\min_{l<k<r}\{dp_{l,k}+dp_{k,r}+sum(l,r)\}$$
- 区间和用前缀和 $O(1)$ 求出
- 普通时间 $O(n^3)$，空间 $O(n^2)$
- 若题目满足四边形不等式，可进一步检查 Knuth 优化
#### 矩阵链乘
---
矩阵 $i$ 的维度为 $p_i\times p_{i+1}$
**状态：** `dp[l][r]` 表示乘完 `[l,r)` 的最少标量乘法次数
$$dp_{l,r}=\min_{l<k<r}\{dp_{l,k}+dp_{k,r}+p_l p_k p_r\}$$
这是最典型的“枚举最后断点”的区间 DP
#### DAG DP
---
有向无环图上按拓扑序转移
最长路形式
$$dp_v=\max_{u\to v}(dp_u+w_{u,v})$$
计数形式
$$cnt_v=\sum_{u\to v}cnt_u$$
- 关键不是 DFS 还是拓扑排序，而是所有依赖状态必须先计算完成
- 图本身的拓扑排序与路径恢复统一使用图论板子
- 时间通常 $O(n+m)$
#### TSP 状压 DP
---
固定从 `0` 出发
**状态：** `dp[s][u]` 表示访问集合 `s` 且当前停在 `u` 的最小代价
$$dp_{s\cup\{v\},v}=\min_{u\in s}\{dp_{s,u}+d_{u,v}\}$$
初值 `dp[1][0] = 0`
回路答案
$$\min_u dp_{2^n-1,u}+d_{u,0}$$
- Hamilton 路径删掉最后回到 `0` 的一步
- 时间 $O(n^2 2^n)$，空间 $O(n2^n)$
#### 子集 DP 常见状态
---
- `dp[s]`：恰好选择集合 `s` 的最优值或方案数
- `dp[s][u]`：集合 `s` 内额外记录最后点 `u`
- `dp[s][k]`：集合 `s` 内额外记录数量、阶段或边界状态
- 枚举 `s` 的非空真子集会自然产生 $O(3^n)$，不能误判成 $O(n2^n)$
- SOS DP、Gosper Hack、Subset Sum 位集统一放在位运算与集合枚举板子
#### 子集划分 DP
---
将集合划分成若干组，已知单独处理子集 `T` 的代价 `w[T]`
定义：
$$
dp_S=\text{划分集合 }S\text{ 的最优代价}
$$
转移：
$$
dp_S=\min_{\varnothing\ne T\subseteq S}\{dp_{S\setminus T}+w_T\}
$$
直接枚举：
```cpp
vector<i64> dp(1 << n, INF);
dp[0] = 0;
for (int s = 1; s < 1 << n; ++ s) {
    for (int t = s; t; t = (t - 1) & s) {
        chmin(dp[s], dp[s ^ t] + w[t]);
    }
}
```
所有 `S` 枚举其所有子集的总复杂度为：
$$\sum_{S\subseteq U}2^{|S|}=3^n$$
若组之间没有顺序，可强制当前选出的 `T` 包含 `S` 的最低位，减少重复转移：
```cpp
for (int s = 1; s < 1 << n; ++ s) {
    int b{ __builtin_ctz(s) };
    for (int t = s; t; t = (t - 1) & s) {
        if (t >> b & 1) chmin(dp[s], dp[s ^ t] + w[t]);
    }
}
```
若要求恰好划分成 `K` 组，增加组数一维：
$$dp_{k,S}=\min_{T\subseteq S}\{dp_{k-1,S\setminus T}+w_T\}$$
#### 数位 DP
---
适合统计 `[0,x]` 中十进制表示满足局部约束的整数
常用状态
- `pos`：当前数位
- `st`：与后续有关的压缩状态
- `lim`：前缀是否仍贴着上界
- `beg`：是否已经出现非前导零
只有 `lim = false` 的状态能直接记忆化
```cpp
template<class Trans, class Accept>
i64 dig_dp(i64 x, int S, int init, Trans trans, Accept accept) {
    if (x < 0) return 0;
    string s = to_string(x);
    int n = s.size();
    vector memo(n, vector(S, array<i64, 2>{-1, -1}));
    auto dfs = [&](auto &&self, int p, int st, bool lim, bool beg) -> i64 {
        if (p == n) return accept(st, beg);
        if (!lim && memo[p][st][beg] != -1) return memo[p][st][beg];
        int up = lim ? s[p] - '0' : 9;
        i64 ans = 0;
        for (int d = 0; d <= up; ++ d) {
            bool nbeg = beg || d;
            int ns = trans(st, d, beg, nbeg);
            if (ns < 0) continue;
            ans += self(self, p + 1, ns, lim && d == up, nbeg);
        }
        if (!lim) memo[p][st][beg] = ans;
        return ans;
    };
    return dfs(dfs, 0, init, true, false);
}
```
- 区间 `[l,r]` 用 `dig_dp(r) - dig_dp(l - 1)`
- 数字 `0` 是否计入由 `accept(st,false)` 决定
- 若前导零不应进入自动机，必须在 `trans` 中显式区分 `beg`
- 计数可能超过 `i64` 时改用取模类或高精度
#### 自动机 DP
---
字符串长度为 `n`，自动机状态数为 `S`
**状态：** `dp[i][s]` 表示处理前 `i` 个字符后停在自动机状态 `s` 的方案数或最优值
$$dp_{i+1,go(s,c)}\mathrel{+}=dp_{i,s}$$
常见组合
- KMP 自动机：禁止出现一个模式串
- AC 自动机：禁止或统计多个模式串
- DFA：局部规则、余数、连续段长度等状态
- 长度极大且转移与位置无关时，把转移写成矩阵快速幂
#### DP 套 DP
---
当题目要求统计“另一个 DP 的结果满足某条件”的对象时，不要直接把整张内层 DP 表作为状态
处理顺序
1. 写出内层 DP
2. 找出只会影响未来转移的信息
3. 把等价内层状态编号
4. 外层在这些编号上继续 DP
5. 状态固定且长度很大时再矩阵化
典型形式是数位 DP + 自动机状态、轮廓线 + 连通性状态、在线算法状态机化
#### 选型速查
| 特征 | 首选模型 |
|---|---|
| 只依赖前一位置或少量历史 | 线性 DP |
| 两个前缀互相匹配 | LCS / 编辑距离 |
| 最后一步把区间分成两段 | 区间 DP |
| 只需记已选择集合 | 状压 DP |
| 上界按数位限制 | 数位 DP |
| 字符约束只依赖有限状态 | 自动机 DP |
| 状态依赖形成 DAG | DAG DP |
| 转移式出现滑窗、前缀最值、直线、决策单调 | 转 12.4 检查优化 |
