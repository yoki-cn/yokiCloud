### DP 优化与选型
---
**定位：** 从转移式的结构判断能否把枚举候选的复杂度降下来
#### 优化选择表
---

| 转移特征              | 方法            | 常见变化                            |
| ----------------- | ------------- | ------------------------------- |
| 只依赖上一层或前几层        | 滚动数组          | 空间降一维                           |
| 区间和、区间固定代价反复出现    | 前缀和 / 差分      | 单次 $O(n)\to O(1)$               |
| 候选只在滑动窗口内         | 单调队列          | $O(nk)\to O(n)$                 |
| 候选是前缀最值或偏序最值      | BIT / 线段树     | $O(n^2)\to O(n\log n)$          |
| 候选可写成直线在 `x` 处取最值 | CHT / Li Chao | $O(n^2)\to O(n)$ 或 $O(n\log n)$ |
| 一层最优决策随位置单调       | 分治优化          | 常见 $O(Kn^2)\to O(Kn\log n)$     |
| 区间决策满足 Knuth 单调   | Knuth         | $O(n^3)\to O(n^2)$              |
| 左半状态批量贡献右半状态      | CDQ           | 常见 $O(n^2)\to O(n\log^2 n)$     |
| 恰好选 `K` 个且关于数量凸或凹 | WQS 二分        | 去掉数量维再二分罚金                      |
| 固定小状态且转移与位置无关     | 矩阵快速幂         | $O(nS^2)\to O(S^3\log n)$       |
| 布尔可达性批量平移         | bitset        | 约降一个机器字因子                       |
| 转移本质是卷积           | FFT / NTT     | $O(n^2)\to O(n\log n)$          |
| 一元凸分段线性函数反复加折线    | Slope Trick   | 每次 $O(\log n)$                  |
先改状态再改转移，一个多余状态维通常比任何数据结构都贵
#### 数据结构优化
---
若转移是前缀、后缀或偏序范围内的最值
$$dp_i=w_i+\max_{j<i,a_j<a_i}dp_j$$
把 `a` 离散化后，用 BIT 或线段树维护键值前缀最大值
典型应用
- 带权 LIS
- 二维偏序 DP
- 坐标范围内的最优前驱
注意同一第一关键字不能互相转移时，要分组查询后再批量更新
#### 斜率优化 DP
---
先把转移严格化成
$$dp_i=c_i+\operatorname{opt}_{j<i}(k_jx_i+b_j)$$
此时
- 历史状态 `j` 对应直线 `y = k_j x + b_j`
- 当前状态 `i` 对应查询横坐标 `x_i`
##### 单调斜率 + 单调查询
支持最大值或最小值、斜率递增或递减、查询点递增或递减
```cpp
template<bool MAX = true, bool K_INC = true, bool X_INC = true>
struct MonoCHT {
    struct Line {
        i64 k, b;
        i128 get(i64 x) const { return (i128)k * x + b; }
    };
    vector<Line> q;
    int h{};
    MonoCHT() = default;
    explicit MonoCHT(int n) { q.reserve(n); }
    static bool better(const Line &a, const Line &b, i64 x) {
        if constexpr (MAX) return a.get(x) >= b.get(x);
        else return a.get(x) <= b.get(x);
    }
    static bool bad(const Line &a, const Line &b, const Line &c) {
        i128 x = ((i128)b.b - a.b) * ((i128)b.k - c.k);
        i128 y = ((i128)c.b - b.b) * ((i128)a.k - b.k);
        if constexpr (MAX == K_INC) return x >= y;
        else return x <= y;
    }
    void add(i64 k, i64 b) {
        Line c{k, b};
        if ((int)q.size() > h && q.back().k == k) {
            if (better(q.back(), c, 0)) return;
            q.pop_back();
        }
        while ((int)q.size() - h >= 2 && bad(q[q.size() - 2], q.back(), c)) q.pop_back();
        q.push_back(c);
    }
    i128 query(i64 x) {
        static constexpr bool FRONT = X_INC == (MAX == K_INC);
        if constexpr (FRONT) {
            while ((int)q.size() - h >= 2 && better(q[h + 1], q[h], x)) ++ h;
            return q[h].get(x);
        } else {
            while ((int)q.size() - h >= 2 && better(q[q.size() - 2], q.back(), x)) q.pop_back();
            return q.back().get(x);
        }
    }
};
```
模板参数
- `MAX = true/false`：最大值 / 最小值
- `K_INC = true/false`：斜率不降 / 不升
- `X_INC = true/false`：查询 `x` 不降 / 不升

两种单调性满足时 `add/query` 均摊 $O(1)$

##### 单调斜率 + 任意查询
查询点不单调时，凸包保留完整并二分最优直线
```cpp
template<bool MAX = true, bool K_INC = true>
struct BinCHT {
    struct Line {
        i64 k, b;
        i128 get(i64 x) const { return (i128)k * x + b; }
    };
    vector<Line> q;
    BinCHT() = default;
    explicit BinCHT(int n) { q.reserve(n); }
    static bool better(i128 a, i128 b) {
        if constexpr (MAX) return a >= b;
        else return a <= b;
    }
    static bool bad(const Line &a, const Line &b, const Line &c) {
        i128 x = ((i128)b.b - a.b) * ((i128)b.k - c.k);
        i128 y = ((i128)c.b - b.b) * ((i128)a.k - b.k);
        if constexpr (MAX == K_INC) return x >= y;
        else return x <= y;
    }
    void add(i64 k, i64 b) {
        Line c{k, b};
        if (!q.empty() && q.back().k == k) {
            if (better(q.back().b, b)) return;
            q.pop_back();
        }
        while (q.size() >= 2 && bad(q[q.size() - 2], q.back(), c)) q.pop_back();
        q.push_back(c);
    }
    i128 query(i64 x) const {
        int l = 0, r = q.size() - 1;
        while (l < r) {
            int m = (l + r) / 2;
            if (better(q[m + 1].get(x), q[m].get(x))) l = m + 1;
            else r = m;
        }
        return q[l].get(x);
    }
};
```
查询 $O(\log n)$

##### CHT 使用条件
- 斜率必须按 `K_INC` 指定方向加入
- `MonoCHT` 的查询必须按 `X_INC` 指定方向进行
- 相同斜率只保留截距更优的直线
- `query()` 前必须至少有一条线
- `i64` 乘法与交叉乘积先提升到 `i128`
- 斜率也不单调时优先考虑 Li Chao、CDQ + CHT 或重新排序
- 查询不单调但斜率单调时用 `BinCHT`
- 浮点版不能直接照搬整数交叉乘，需统一相对误差比较

#### Li Chao Tree
---
适合
- 斜率任意顺序加入
- 查询点任意顺序
- 横坐标范围已知或可离散
单次加入和查询通常 $O(\log C)$ 或 $O(\log n)$
具体实现统一使用数据结构章节的 Li Chao Tree，不在 DP 文件重复维护
#### Monge / 四边形不等式与决策单调
很多 DP 优化的关键并不是某个数据结构，而是证明最优决策位置单调
考虑：
$$
cur_i=\min_j\{pre_j+w(j,i)\}
$$
记最小的最优决策为：
$$
opt_i=\min\arg\min_j\{pre_j+w(j,i)\}
$$
若代价满足 Monge 性质：
$$
w(a,c)+w(b,d)\le w(a,d)+w(b,c)
$$
其中：
$$
a\le b,\quad c\le d
$$
则在常见合法区间下通常可推出：
$$
opt_i\le opt_{i+1}
$$
加入只依赖 `j` 的项 `pre[j]` 不会破坏 Monge 性质
##### 优化入口
若已经证明：
$$
opt_i\le opt_{i+1}
$$
则形如：
$$
cur_i=\min_j\{pre_j+w(j,i)\}
$$
的分层 DP 应优先检查分治优化
若区间 DP：
$$
dp_{l,r}=\min_{l<k<r}\{dp_{l,k}+dp_{k,r}+w(l,r)\}
$$
还能得到更强的：
$$
opt_{l,r-1}\le opt_{l,r}\le opt_{l+1,r}
$$
则检查 Knuth 优化
常见充分条件是 `w` 同时满足四边形不等式与区间包含单调性，但具体题目应按实际状态证明
> [!warning]
> 不要因为代价看起来“凸”或样例中的决策位置单调就直接套优化
> 分治优化真正需要的是决策单调，Knuth 需要更强的决策范围关系

最大化问题可对目标整体取负后转成最小化统一判断
#### 分治优化 DP
---
典型分层转移
$$dp_{t,i}=\min_{k\le i}\{dp_{t-1,k}+w(k,i)\}$$
若一层的最优决策 `opt[i]` 随 `i` 单调不下降，可递归计算中点，只搜索允许的决策区间
```cpp
template<class Cost>
void dc_dp(int l, int r, int ql, int qr,
           const vector<i64> &pre, vector<i64> &cur, Cost cost) {
    if (l > r) return;
    int m = (l + r) / 2;
    pair<i64, int> best{INF, -1};
    int R = min(m, qr);
    for (int k = ql; k <= R; ++ k) {
        if (pre[k] == INF) continue;
        best = min(best, {pre[k] + cost(k, m), k});
    }
    cur[m] = best.first;
    int p = best.second;
    dc_dp(l, m - 1, ql, p, pre, cur, cost);
    dc_dp(m + 1, r, p, qr, pre, cur, cost);
}
```
- 若要求 `k < i`，把 `R` 改为 `min(m - 1, qr)`
- 每层常见 $O(n\log n)$，总计 $O(Kn\log n)$
- 有些标准结构可以进一步分析到每层 $O(n)$
- 决策单调必须证明或引用已知结论
#### 四边形不等式与 Knuth 优化
---
区间 DP 形如
$$dp_{l,r}=\min_{l<k<r}\{dp_{l,k}+dp_{k,r}+w(l,r)\}$$
若满足
$$opt[l][r-1]\le opt[l][r]\le opt[l+1][r]$$
则只需在这个小区间枚举 `k`
```cpp
template<class Cost>
i64 knuth(int n, Cost cost) {
    vector dp(n + 1, vector<i64>(n + 1, INF));
    vector opt(n + 1, vector<int>(n + 1));
    for (int i = 0; i <= n; ++ i) {
        dp[i][i] = 0;
        opt[i][i] = i;
        if (i < n) {
            dp[i][i + 1] = 0;
            opt[i][i + 1] = i + 1;
        }
    }
    for (int len = 2; len <= n; ++ len) {
        for (int l = 0; l + len <= n; ++ l) {
            int r = l + len;
            int L = max(l + 1, opt[l][r - 1]);
            int R = min(r - 1, opt[l + 1][r]);
            for (int k = L; k <= R; ++ k) {
                i64 x = dp[l][k] + dp[k][r] + cost(l, r);
                if (x < dp[l][r]) dp[l][r] = x, opt[l][r] = k;
            }
        }
    }
    return dp[0][n];
}
```
时间 $O(n^2)$，空间 $O(n^2)$
不能因为转移长得像区间 DP 就默认满足 Knuth 条件
#### CDQ 分治优化 DP
---
适合时间方向固定为 `j < i`，但候选加入顺序不适合直接在线维护
```cpp
template<class Relax>
void cdq(int l, int r, Relax relax) {
    if (r - l <= 1) return;
    int m = (l + r) / 2;
    cdq(l, m, relax);
    relax(l, m, r);
    cdq(m, r, relax);
}
```
`relax(l,m,r)` 只允许用 `[l,m)` 已确定状态更新 `[m,r)`
内部常配合
- BIT / 线段树
- CHT
- 排序扫描
若每层 `relax` 为 $O(n\log n)$，总复杂度常见 $O(n\log^2 n)$
#### WQS 二分
---
用于“恰好选 `K` 个”的最优化，并且最优值关于选择数量具有离散凸或凹性质
最大化时给每次选择加罚金 `-lambda`
原目标
$$\max\{value\mid cnt=K\}$$
调整后
$$\max(value-\lambda cnt)$$
一次 `calc(lambda)` 同时返回调整后最优值与对应选择数
若 `lambda` 增大时最优 `cnt` 单调不增，就可二分 `lambda`
恢复原答案
$$ans=adjusted+\lambda K$$
关键点
- 同调整值时的 `cnt` tie-break 必须固定，通常最大化问题偏向更大的 `cnt`
- 二分范围必须覆盖最优罚金
- 并非所有带 `K` 限制的 DP 都可 WQS
#### bitset 优化
---
布尔可达性转移
$$dp\leftarrow dp\lor(dp\ll w)$$
适合 0/1 Subset Sum 等只关心可达性的状态
复杂度从 $O(nW)$ 降到约 $O(nW/word)$
动态位集实现统一放位运算章节
#### SOS DP（子集 / 超集 DP）
---
对所有状态 `S` 同时统计其全部子集或超集的信息，也称快速 Zeta 变换
典型形式：
$$
f_S=\sum_{T\subseteq S}a_T
$$
或：
$$
f_S=\sum_{T\supseteq S}a_T
$$
直接对每个 `S` 枚举所有子集总复杂度为：
$$
O(3^n)
$$
SOS DP 利用每一位依次加入贡献，将复杂度降为：
$$
O(n2^n)
$$
##### 子集 Zeta 变换
变换后：
$$
f_S=\sum_{T\subseteq S}a_T
$$
```cpp
template<class T>
void sub_zeta(vector<T> &f, int n) {
    for (int i = 0; i < n; ++ i) {
        for (int s = 0; s < 1 << n; ++ s) {
            if (s >> i & 1) f[s] += f[s ^ (1 << i)];
        }
    }
}
```
例如 `a[S]` 表示状态 `S` 的出现次数，变换后 `a[S]` 表示所有 `T ⊆ S` 的出现次数之和
##### 子集 Möbius 逆变换
将：
$$f_S=\sum_{T\subseteq S}a_T$$
还原为原数组 `a`
```cpp
template<class T>
void sub_mobius(vector<T> &f, int n) {
    for (int i = 0; i < n; ++ i) {
        for (int s = 0; s < 1 << n; ++ s) {
            if (s >> i & 1) f[s] -= f[s ^ (1 << i)];
        }
    }
}
```
即：
$$a_S=\sum_{T\subseteq S}(-1)^{|S|-|T|}f_T$$
##### 超集 Zeta 变换
变换后：
$$f_S=\sum_{T\supseteq S}a_T$$
```cpp
template<class T>
void sup_zeta(vector<T> &f, int n) {
    for (int i = 0; i < n; ++ i) {
        for (int s = 0; s < 1 << n; ++ s) {
            if (!(s >> i & 1)) f[s] += f[s | 1 << i];
        }
    }
}
```
例如 `a[S]` 表示状态 `S` 的出现次数，变换后 `a[S]` 表示所有 `T ⊇ S` 的出现次数之和
##### 超集 Möbius 逆变换
```cpp
template<class T>
void sup_mobius(vector<T> &f, int n) {
    for (int i = 0; i < n; ++ i) {
        for (int s = 0; s < 1 << n; ++ s) {
            if (!(s >> i & 1)) f[s] -= f[s | 1 << i];
        }
    }
}
```
##### 最大值 / 最小值版本
若只需要：
$$f_S=\max_{T\subseteq S}a_T$$
可将加法改为 `max`
```cpp
template<class T>
void sub_max(vector<T> &f, int n) {
    for (int i = 0; i < n; ++ i) {
        for (int s = 0; s < 1 << n; ++ s) {
            if (s >> i & 1) f[s] = max(f[s], f[s ^ (1 << i)]);
        }
    }
}
```
类似地可得到：
- 子集最小值：`max` 改为 `min`
- 超集最大值：使用超集 Zeta 的枚举方向
- 超集最小值：同时改为 `min`
此类 `max / min` 变换通常不可通过简单逆变换恢复原数组
##### 与补集结合
全集：
```cpp
int all{ (1 << n) - 1 };
```
若已经对子集和做过 `sub_zeta`，则与 `S` 不相交的所有状态之和为：
```cpp
f[all ^ s]
```
因为：
$$T\cap S=\varnothing \iff T\subseteq \overline S$$
类似地，包含 `S` 的所有状态直接使用超集 Zeta 后的 `f[S]`
##### OR 卷积
若：
$$c_S=\sum_{A\cup B=S}a_A b_B$$
对子集 Zeta 变换有：
$$\widehat c_S=\widehat a_S\widehat b_S$$
因此可以：
```cpp
sub_zeta(a, n);
sub_zeta(b, n);
for (int s = 0; s < 1 << n; ++ s) a[s] *= b[s];
sub_mobius(a, n);
```
得到 OR 卷积，复杂度 $O(n2^n)$
##### AND 卷积
若：
$$c_S=\sum_{A\cap B=S}a_A b_B$$
使用超集 Zeta 变换：
```cpp
sup_zeta(a, n);
sup_zeta(b, n);
for (int s = 0; s < 1 << n; ++ s) a[s] *= b[s];
sup_mobius(a, n);
```
同样为 $O(n2^n)$
##### 识别
出现以下形式时优先考虑 SOS DP：
$$f_S=\sum_{T\subseteq S}a_T \]\[ f_S=\sum_{T\supseteq S}a_T$$
或需要对所有 `S` 批量查询：
- `S` 的所有子集贡献
- `S` 的所有超集贡献
- 与 `S` 不相交的状态贡献
- OR / AND 卷积
若对每个状态枚举：
```cpp
for (int t = s; ; t = (t - 1) & s)
```
且转移只是在对子集信息做可合并的统计，应检查能否改为 SOS DP
##### 与子集划分 DP 的区别
子集划分 DP：
$$dp_S=\min_{T\subseteq S}\{dp_{S\setminus T}+w_T\}$$
转移同时依赖 `T` 与 `S \ T`，普通 SOS DP 通常不能直接将其从 $O(3^n)$ 降为 $O(n2^n)$
SOS DP 适合的是对所有子集或超集做统一的加法、计数、最大值、最小值等聚合
更一般的：
$$c_S=\sum_{A\sqcup B=S}a_A b_B$$
属于子集卷积，不等同于普通 SOS DP
##### 复杂度
四种 Zeta / Möbius 变换均为：
- 时间复杂度 $O(n2^n)$
- 空间复杂度 $O(2^n)$
- 原地变换无需额外数组
#### 矩阵快速幂加速
---
若状态数 `S` 固定且每一步使用同一个线性转移
$$v_{i+1}=v_iT$$
则
$$v_n=v_0T^n$$
- 普通 DP $O(nS^2)$
- 矩阵快速幂 $O(S^3\log n)$
- `S` 大时矩阵未必更快
- 稀疏转移可考虑稀疏矩阵、线性递推或 Bostan-Mori
矩阵实现统一使用线性代数章节
#### 卷积优化
若转移出现
$$dp_i=\sum_{j=0}^i a_jb_{i-j}$$
或分治后能把跨区间贡献写成卷积，可考虑 FFT / NTT
典型方向
- 计数 DP
- 生成函数
- 分治卷积
- 在线卷积
卷积实现统一使用多项式章节
#### Slope Trick（凸分段线性函数 DP）
---
维护关于变量 `x` 的一元凸分段线性函数，适合 DP 状态本身是一整个凸函数的情况
常见操作：
$$
f(x)\leftarrow f(x)+(a-x)_+
$$
$$
f(x)\leftarrow f(x)+(x-a)_+
$$
$$
f(x)\leftarrow f(x)+|x-a|
$$
以及：
$$
g(x)=\min_{x-r\le y\le x-l}f(y)
$$
通常只需维护函数的最小值以及斜率发生变化的位置，可用两个堆实现
##### 与斜率优化 DP 的区别
斜率优化维护的是一组直线：
$$
\operatorname{opt}_j(k_jx+b_j)
$$
Slope Trick 维护的是一个完整的凸分段线性函数：
$$
f(x)
$$
识别时：
- 历史状态 `j` 能整理成 `k_jx_i+b_j` → CHT / Li Chao
- `dp_i(x)` 本身是关于 `x` 的凸折线，并不断加入 `|x-a|` 或 $(x-a)_+$ → Slope Trick
```cpp
template<class T = i64>
struct SlopeTrick {
    T ans{}, dl{}, dr{};
    priority_queue<T> l;
    priority_queue<T, vector<T>, greater<T>> r;
    T top_l() const { return l.empty() ? numeric_limits<T>::lowest() / 4 : l.top() + dl; }
    T top_r() const { return r.empty() ? numeric_limits<T>::max() / 4 : r.top() + dr; }
    void push_l(T x) { l.push(x - dl); }
    void push_r(T x) { r.push(x - dr); }
    void add_l(T a) {
        if (!r.empty() && a > top_r()) {
            ans += a - top_r();
            push_r(a);
            T x = top_r();
            r.pop();
            push_l(x);
        } else push_l(a);
    }
    void add_r(T a) {
        if (!l.empty() && a < top_l()) {
            ans += top_l() - a;
            push_l(a);
            T x = top_l();
            l.pop();
            push_r(x);
        } else push_r(a);
    }
    void add_abs(T a) { add_l(a), add_r(a); }
    void shift(T a, T b) { dl += a, dr += b; }
    T get() const { return ans; }
};
```
`shift(a,b)` 对应
$$f_{new}(x)=\min_{x-b\le y\le x-a}f_{old}(y)$$
且要求 `a <= b`
每次加折线 $O(\log n)$，平移与查询最小值 $O(1)$
#### 赛场检查顺序
---
1. 状态是否有多余维度
2. 能否滚动数组或原地转移
3. 区间量能否前缀和预处理
4. 候选是否形成滑动窗口
5. 候选是否只是前缀 / 后缀最值
6. 转移能否整理成 `k*x+b`
7. 最优决策是否单调
8. 区间 DP 是否满足 Knuth 条件
9. 数量限制是否具有 WQS 所需凸性或凹性
10. 布尔状态能否 bitset
11. 转移是否固定线性，可否矩阵快速幂
12. 是否出现卷积结构
#### 转移特征速查
---

| 转移特征 | 优先检查 |
|---|---|
| 固定区间内取最值 | 单调队列 |
| 前缀 / 后缀范围取最值 | BIT / 线段树 |
| $\operatorname{opt}(kx+b)$ | CHT / Li Chao |
| 最优决策位置单调 | 分治优化 |
| $opt_{l,r-1}\le opt_{l,r}\le opt_{l+1,r}$ | Knuth |
| 恰好选 `K` 个且数量可被罚值控制 | WQS |
| 状态是一元凸分段线性函数 | Slope Trick |
| 每个状态枚举所有子集 | SOS / 子集卷积 |
| 固定小状态、步数极大 | 矩阵快速幂 |
| 转移是卷积形式 | FFT / NTT |
