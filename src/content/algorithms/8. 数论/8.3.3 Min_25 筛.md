### Min_25 筛
**解决问题：** 对积性函数 $f$，在 $n$ 很大时计算
$$
S_f(n)=\sum_{i=1}^n f(i)
$$
Min_25 的核心分两步：先求若干完全积性基函数在质数上的前缀和，再按最小质因子递归枚举质数幂
这里整理为**可修改的通用基函数版**，默认计算
$$
\sum_{i=1}^n\varphi(i)
$$
顶部四个函数是主要修改区，其余部分通常不用动
```cpp
template<class T = __int128_t, int K = 2>
struct Min25 {
    using A = array<T, K>;
    i64 n, sq;
    vector<int> primes, id1, id2;
    vector<i64> w;
    vector<A> g, pre;
    // ===== 按题修改：f(p) 的基函数、基函数前缀和、f(p^e) =====
    // 默认 f = phi，f(p) = p - 1
    A basis(i64 p) const { return { T(1), T(p) }; }
    // 返回 sum_{i=2}^x basis(i)
    A basis_sum(i64 x) const {
        T s = x & 1 ? T(x) * T((x + 1) / 2) : T(x / 2) * T(x + 1);
        return { T(x - 1), s - T(1) };
    }
    // 输入各基函数在一段质数上的和，返回对应的 sum f(p)
    T prime_sum(const A &a) const { return a[1] - a[0]; }
    // f(p^e)，pe = p^e
    T prime_power(i64 p, int e, i64 pe) const { return T(pe - pe / p); }
    explicit Min25(i64 n_) : n(n_) {
        assert(n >= 1);
        sq = sqrtl((long double)n);
        while (sq + 1 <= n / (sq + 1)) ++ sq;
        while (sq > n / sq) -- sq;
        build_primes();
        build_prime_sum();
    }
    T solve() const { return T(1) + dfs(n, -1); }
private:
    int id(i64 x) const { return x <= sq ? id1[x] : id2[n / x]; }
    // 统计 <= x 且最小质因子 > primes[k] 的贡献
    T dfs(i64 x, int k) const {
        if (x <= 1 || (k >= 0 && primes[k] > x)) return T{};
        int t{ id(x) };
        A s{};
        for (int j = 0; j < K; ++ j) s[j] = g[t][j] - pre[k + 1][j];
        // ===== 先计入所有可选质数本身 =====
        T ans{ prime_sum(s) };
        // ===== 枚举最小质因子及其指数 =====
        for (int i = k + 1; i < int(primes.size()); ++ i) {
            i64 p{ primes[i] };
            if (p > x / p) break;
            // p 已在上面的质数贡献中出现，先删除再统一枚举 p^e
            ans -= prime_sum(basis(p));
            for (i64 pe = p, e = 1; pe <= x; ++ e) {
                ans += prime_power(p, int(e), pe) * (T(1) + dfs(x / pe, i));
                if (pe > x / p) break;
                pe *= p;
            }
        }
        return ans;
    }
    // ===== 筛 sqrt(n) 内质数，并维护各基函数的质数前缀和 =====
    void build_primes() {
        vector<int> minp(sq + 1);
        pre.push_back({});
        for (int i = 2; i <= sq; ++ i) {
            if (!minp[i]) {
                minp[i] = i;
                primes.push_back(i);
                A s{ pre.back() }, b{ basis(i) };
                for (int j = 0; j < K; ++ j) s[j] += b[j];
                pre.push_back(s);
            }
            for (int p : primes) {
                if (p > sq / i) break;
                minp[i * p] = p;
                if (p == minp[i]) break;
            }
        }
    }
    // ===== Min_25 第一阶段：求各整除商位置的质数基函数前缀和 =====
    void build_prime_sum() {
        id1.assign(sq + 1, -1);
        id2.assign(sq + 1, -1);
        for (i64 l = 1, r; l <= n; l = r + 1) {
            i64 v{ n / l };
            r = n / v;
            int t{ int(w.size()) };
            w.push_back(v);
            g.push_back(basis_sum(v));
            if (v <= sq) id1[v] = t;
            else id2[n / v] = t;
        }
        for (int k = 0; k < int(primes.size()); ++ k) {
            i64 p{ primes[k] };
            A b{ basis(p) };
            for (int i = 0; i < int(w.size()) && p <= w[i] / p; ++ i) {
                int t{ id(w[i] / p) };
                for (int j = 0; j < K; ++ j) {
                    g[i][j] -= b[j] * (g[t][j] - pre[k][j]);
                }
            }
        }
    }
};
```
质数筛部分采用经典 Min_25 的整除商离散化：只保存 $\lfloor n/i\rfloor$ 的不同值，并用 `id1 / id2` 在 $O(1)$ 时间找到状态；质数更新也是标准的
$$
G(v)\leftarrow G(v)-g(p)\left(G\left(\left\lfloor\frac vp\right\rfloor\right)-G(p^-)\right)
$$
#### 接口说明
构造
```cpp
Min25 min25(n);
```
默认 `T = __int128_t`、`K = 2`，计算欧拉函数前缀和
```cpp
auto ans = min25.solve();
```
返回
$$
\sum_{i=1}^n\varphi(i)
$$
成员含义：
- `sq`：$\lfloor\sqrt n\rfloor$
- `primes`：不超过 $\sqrt n$ 的质数
- `w`：所有不同的 $\lfloor n/i\rfloor$
- `id1 / id2`：将整除商映射到 `w` 下标
- `g[t][j]`：Min_25 第一阶段结束后，第 `j` 个基函数在 $p\le w[t]$ 的质数上的和
- `pre[k][j]`：前 `k` 个质数的第 `j` 个基函数之和
- `dfs(x,k)`：内部递归，统计不超过 $x$ 且最小质因子大于 `primes[k]` 的数的贡献
#### 使用条件
Min_25 处理的是积性函数
$$
\gcd(a,b)=1\quad\Longrightarrow\quad f(ab)=f(a)f(b)
$$
还需要能 $O(1)$ 计算
$$
f(p^e)
$$
并且质数处的函数值能够写成少量**完全积性基函数的线性组合**
$$
f(p)=\sum_{j=0}^{K-1}c_jg_j(p)
$$
其中每个 $g_j$ 满足
$$
g_j(ab)=g_j(a)g_j(b)
$$
并且
$$
\sum_{i=2}^x g_j(i)
$$
能够快速计算
常见基函数就是
$$
1,\quad n,\quad n^2,\quad n^3
$$

#### 默认版本为什么是 $\varphi$
对于质数 $p$
$$
\varphi(p)=p-1
$$
因此取两个基函数
$$
g_0(p)=1,\quad g_1(p)=p
$$
对应
```cpp
A basis(i64 p) const { return { T(1), T(p) }; }
```
它们从 $2$ 到 $x$ 的普通前缀和分别是
$$
\sum_{i=2}^x1=x-1
$$
$$
\sum_{i=2}^xi=\frac{x(x+1)}2-1
$$
所以
```cpp
T prime_sum(const A &a) const { return a[1] - a[0]; }
```
而质数幂上
$$
\varphi(p^e)=p^e-p^{e-1}
$$
对应
```cpp
T prime_power(i64 p, int e, i64 pe) const {
    return T(pe - pe / p);
}
```
#### 第一阶段：筛质数前缀和
对每个基函数 $g_j$，初始化
$$
G_j(v)=\sum_{i=2}^v g_j(i)
$$
此时包含质数与合数
按质数 $p_k$ 依次筛去最小质因子为 $p_k$ 的合数
$$
G_j(v)
\mathrel{-}=
g_j(p_k)
\left(
G_j\left(\left\lfloor\frac v{p_k}\right\rfloor\right)
-
\sum_{i<k}g_j(p_i)
\right)
$$
处理完成后
$$
G_j(v)=\sum_{\substack{p\le v\\p\text{ prime}}}g_j(p)
$$
由于只关心
$$
v=\left\lfloor\frac ni\right\rfloor
$$
所有状态数量只有
$$
O(\sqrt n)
$$
#### 第二阶段：枚举最小质因子
设 `dfs(x,k)` 只允许使用
$$
p>p_k
$$
的质因子
先利用第一阶段直接得到所有允许质数的贡献
$$
\sum_{\substack{p\le x\\p>p_k}}f(p)
$$
随后枚举下一个最小质因子 $p_i$ 和指数 $e$
$$
p_i^e
$$
剩余部分必须只含大于 $p_i$ 的质因子，因此递归到
$$
\operatorname{dfs}\left(\left\lfloor\frac{x}{p_i^e}\right\rfloor,i\right)
$$
每个整数按自己的最小质因子与其指数被唯一枚举一次，所以不会重复
#### 修改为其他积性函数
通常只需要修改代码开头四个函数

##### 约数个数 $\tau$
有
$$
\tau(p^e)=e+1,\quad \tau(p)=2
$$
只需要常数基函数即可，可以仍保留 `K = 2`，让第二项恒为 $0$
```cpp
A basis(i64 p) const { return { T(1), T(0) }; }
A basis_sum(i64 x) const { return { T(x - 1), T(0) }; }
T prime_sum(const A &a) const { return T(2) * a[0]; }
T prime_power(i64 p, int e, i64 pe) const { return T(e + 1); }
```
##### Jordan 函数 $J_2$
有
$$
J_2(p)=p^2-1
$$
$$
J_2(p^e)=p^{2e}-p^{2e-2}
$$
改成基函数
$$
1,\quad p^2
$$
其中平方和
$$
\sum_{i=1}^x i^2=\frac{x(x+1)(2x+1)}6
$$
若在模意义下计算，建议先在整数中约掉 $2,3$ 再转为 `T`，避免要求模数下存在 $6^{-1}$

##### $\mu$
有
$$
\mu(p)=-1,\quad
\mu(p^e)=0\quad(e\ge2)
$$
也可以套 Min_25，但这一类函数直接使用上一节杜教筛更短
#### 基函数超过两个
若
$$
f(p)=c_0+c_1p+c_2p^2
$$
将模板改成
```cpp
Min25<T, 3>
```
并让
```cpp
basis(p)
```
返回
```cpp
{1, p, p * p}
```
`basis_sum(x)` 返回三个基函数从 $2$ 到 $x$ 的前缀和
`prime_sum(a)` 返回
```cpp
c0 * a[0] + c1 * a[1] + c2 * a[2]
```
内部筛法和递归部分不需要修改
这里 `prime_sum()` 必须是各基函数和的**线性组合**，因为它需要满足
$$
\operatorname{prime\_sum}
\left(
\sum_p\mathbf g(p)
\right)
=
\sum_p f(p)
$$
#### 常见用法
默认求欧拉函数前缀和
```cpp
i64 n;
cin >> n;
Min25 min25(n);
auto ans = min25.solve();
```
若答案保证在 `i64` 内，可以减少一半左右的大数组单元大小
```cpp
Min25<i64> min25(n);
i64 ans = min25.solve();
```
若已经有模整数 `Z`
```cpp
Min25<Z> min25(n);
Z ans = min25.solve();
```
此时 `basis_sum()` 等函数也应避免依赖不可逆整数的模逆元，优先先约分再乘
#### 为什么默认用 `__int128_t`
Min_25 常用于 $n$ 已经无法线性筛的情况，此时很多函数前缀和很容易超过 `i64`
例如
$$
\sum_{i=1}^n\varphi(i)=\Theta(n^2)
$$
所以默认结果类型使用 `__int128_t`
若题目要求取模，应将 `T` 换成模整数类型，这也能明显减少内存
#### 注意事项
`Min25` 对象与构造时的 `n` 绑定，不能构造一次后直接调用另一个 `n`
```cpp
Min25 a(n);
auto ans = a.solve();
```
若查询另一个 $m$，需要重新构造
```cpp
Min25 b(m);
```
`basis()` 中的每一项必须对应一个完全积性函数，不能直接把
$$
p^2+p+1
$$
整个作为单个基函数
应该拆成
$$
p^2,\quad p,\quad1
$$
`basis_sum(x)` 是对**所有整数 $2\ldots x$** 求和，不是对质数求和，质数限制会由 Min_25 第一阶段筛出来
`prime_power(p,e,pe)` 必须返回
$$
f(p^e)
$$
而不是仅返回 $f(p)$
`solve()` 已经补上
$$
f(1)=1
$$
因此 `dfs()` 本身不包含 $1$
循环中均使用
```cpp
p > x / p
pe > x / p
```
而不是 `p * p > x`、`pe * p > x`，避免整数乘法溢出
#### 与杜教筛的选择
| 场景 | 更适合 |
|---|---|
| $\sum\mu(i)$、$\sum\varphi(i)$ | 杜教筛，代码更短 |
| 容易找到 $f*g$ 使卷积前缀和简单 | 杜教筛 |
| $f(p)$ 是低次多项式或少量完全积性函数的线性组合 | Min_25 |
| $f(p^e)$ 容易计算，但整体没有好用的杜教卷积 | Min_25 |
| 只求 $\pi(n)$ 或 $\sum_{p\le n}p$ | Min_25 第一阶段即可 |
#### 复杂度
设 `basis()`、`basis_sum()`、`prime_sum()`、`prime_power()` 均为 $O(1)$
不同整除商数量为
$$
O(\sqrt n)
$$
空间复杂度为
$$
O(K\sqrt n)
$$
固定 $K$ 时即
$$
O(\sqrt n)
$$
经典 Min_25 的时间复杂度为
$$
O\left(\frac{n^{3/4}}{\log n}\right)
$$
实际常数与基函数数量 $K$、`T` 的大小和递归中的质数幂数量有关
