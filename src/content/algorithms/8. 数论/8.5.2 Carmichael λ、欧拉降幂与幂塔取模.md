### Carmichael $\lambda$、欧拉降幂与幂塔取模
---
**解决问题：** 求乘法群的统一周期 Carmichael 函数 $\lambda(n)$，处理超大十进制指数，并计算右结合幂塔
$$
a_0^{a_1^{a_2^{\cdot^{\cdot^\cdot}}}}\bmod m
$$
已有单独的“欧拉降幂 / 扩展欧拉定理”内容，这里在其基础上补齐 Carmichael $\lambda$、非互质情况下的严格降幂和幂塔取模 
#### Carmichael $\lambda$ 函数
---
$\lambda(n)$ 定义为使所有与 $n$ 互质的整数都满足
$$
a^{\lambda(n)}\equiv1\pmod n
\qquad \gcd(a,n)=1
$$
的最小正整数
因此
$$
\operatorname{ord}_n(a)\mid\lambda(n)\mid\varphi(n)
$$
相比 Euler 定理，$\lambda(n)$ 给出的周期通常更短
输入 `fac = {{p1,e1},{p2,e2},...}` 为 $n$ 的完整质因数分解
```cpp
// 返回 {phi(n), lambda(n)}，fac = {{p, e}, ...}
pair<i64, i64> phi_lambda(const vector<pair<i64, int>> &fac) {
    __int128_t phi{ 1 };
    i64 lambda{ 1 };
    for (auto [p, e] : fac) {
        assert(p >= 2 && e >= 1);
        __int128_t pk{ 1 };
        for (int i = 0; i < e; ++ i) pk *= p;
        i64 ph{ i64(pk / p * (p - 1)) };
        i64 la{ p == 2 && e >= 3 ? i64(pk / 4) : ph };
        phi *= ph;
        lambda = i64((__int128_t)(lambda / gcd(lambda, la)) * la);
    }
    return { i64(phi), lambda };
}
```
##### 公式
对于奇质数 $p$：
$$
\lambda(p^k)=\varphi(p^k)=p^{k-1}(p-1)
$$
对于 $2$ 的幂：
$$
\lambda(2)=1\quad,\quad
\lambda(4)=2\quad,\quad
\lambda(2^k)=2^{k-2}\ \ (k\ge3)
$$
不同质数幂之间取最小公倍数：
$$
\lambda\left(\prod_i p_i^{e_i}\right)
=
\operatorname{lcm}_i\lambda(p_i^{e_i})
$$
特别地：
$$
\lambda(1)=1
$$
##### 常见用法
若已经通过 8.2 Pollard--Rho 得到：
```cpp
vector<pair<i64, int>> fac;
```
直接：
```cpp
auto [phi, lambda] = phi_lambda(fac);
```
例如
$$
n=24=2^3\cdot3
$$
有
$$
\varphi(24)=8,\quad\lambda(24)=2
$$
所以任意
$$
\gcd(a,24)=1
$$
都有
$$
a^2\equiv1\pmod{24}
$$
##### 与乘法阶、原根的关系
对任意
$$
\gcd(a,m)=1
$$
都有
$$
\operatorname{ord}_m(a)\mid\lambda(m)
$$
因此上一节求乘法阶时，也可以从 $\lambda(m)$ 开始消质因子，而不是从 $\varphi(m)$ 开始
若模 $m$ 存在原根，则单位群为循环群，因此
$$
\lambda(m)=\varphi(m)
$$
反过来，一般模数可能满足
$$
\lambda(m)<\varphi(m)
$$
例如
$$
\lambda(8)=2,\quad\varphi(8)=4
$$
##### 复杂度
已知质因数分解后，设不同质因子数为 $\omega(n)$：
$$
O(\omega(n)+\log n)
$$
实际主要成本通常来自前面的整数分解
#### 超大指数降幂
---
设指数 $E$ 是一个无法放入整数类型的十进制字符串
##### 互质时使用 Carmichael $\lambda$
若
$$
\gcd(a,m)=1
$$
则
$$
a^E\equiv a^{E\bmod\lambda(m)}\pmod m
$$
这是处理互质底数时最短的周期
##### 非互质时使用扩展 Euler 定理
任意 $a$ 都可以使用：
$$
a^E\equiv
\begin{cases}
a^E & E<\varphi(m)\\
a^{E\bmod\varphi(m)+\varphi(m)} & E\ge\varphi(m)
\end{cases}
\pmod m
$$
关键不是只求
$$
E\bmod\varphi(m)
$$
还必须知道
$$
E\ge\varphi(m)
$$
是否成立
```cpp
i64 norm_mod(i64 x, i64 mod) {
    x %= mod;
    if (x < 0) x += mod;
    return x;
}
i64 mul_mod(i64 a, i64 b, i64 mod) {
    return i64((__int128_t)norm_mod(a, mod) * norm_mod(b, mod) % mod);
}
i64 qpow_mod(i64 a, u64 b, i64 mod) {
    i64 res{ 1 % mod };
    a = norm_mod(a, mod);
    for (; b; b >>= 1, a = mul_mod(a, a, mod)) {
        if (b & 1) res = mul_mod(res, a, mod);
    }
    return res;
}
// 返回 {E mod mod, E >= mod}
pair<i64, bool> decimal_mod_ge(string_view s, i64 mod) {
    assert(mod > 0 && !s.empty());
    i64 r{};
    __int128_t cap{};
    bool ge{};
    for (char c : s) {
        assert('0' <= c && c <= '9');
        int d{ c - '0' };
        r = i64(((__int128_t)r * 10 + d) % mod);
        if (!ge) {
            cap = cap * 10 + d;
            if (cap >= mod) ge = true;
        }
    }
    return { r, ge };
}
// 任意 a，phi = phi(mod)
i64 power_big(i64 a, string_view e, i64 mod, i64 phi) {
    assert(mod > 0 && phi > 0);
    if (mod == 1) return 0;
    auto [r, ge] = decimal_mod_ge(e, phi);
    u64 exp{ u64(r) + (ge ? u64(phi) : 0) };
    return qpow_mod(a, exp, mod);
}
// gcd(a, mod) = 1，lambda = lambda(mod)
i64 power_big_coprime(i64 a, string_view e, i64 mod, i64 lambda) {
    assert(mod > 0 && lambda > 0);
    assert(gcd(norm_mod(a, mod), mod) == 1);
    if (mod == 1) return 0;
    auto [r, ge] = decimal_mod_ge(e, lambda);
    return qpow_mod(a, u64(r), mod);
}
```
##### 接口说明
任意底数：
```cpp
i64 ans = power_big(a, exponent_string, mod, phi);
```
其中 `phi` 必须为
$$
\varphi(mod)
$$
若已知
$$
\gcd(a,mod)=1
$$
优先：
```cpp
i64 ans = power_big_coprime(a, exponent_string, mod, lambda);
```
其中
$$
lambda=\lambda(mod)
$$
##### 为什么非互质时不能直接使用 $\lambda$
Carmichael 周期只保证**可逆元素**
例如
$$
m=8,\quad\lambda(8)=2
$$
取
$$
a=2,\quad E=4
$$
实际：
$$
2^4\equiv0\pmod8
$$
若错误地使用
$$
E\bmod\lambda(8)+\lambda(8)
$$
得到指数
$$
4\bmod2+2=2
$$
但
$$
2^2\equiv4\pmod8
$$
因此不互质时不能把扩展 Euler 定理中的 $\varphi(m)$ 直接替换成 $\lambda(m)$
> [!tip]
> **互质底数：优先 $\lambda(m)$**
>
> **不保证互质：使用 $\varphi(m)$ 的扩展 Euler 降幂**
#### 幂塔取模
---
定义右结合幂塔
$$
T_i=a_i^{T_{i+1}}
$$
最后一层
$$
T_{k-1}=a_{k-1}
$$
例如
$$
[2,3,2]
\Longrightarrow
2^{3^2}=512
$$
下面约定
$$
0^0=1
$$
这样递归边界唯一，代码也与常见快速幂约定一致
内部使用 `phi_trial()` 计算每层模数的 Euler 函数，中等模数可以直接使用；完整 `i64` 大模数应将这里替换为 8.2 的 Pollard--Rho 分解
```cpp
// ===== 以下函数可直接替换为 8.2 分解后的 phi =====
i64 phi_trial(i64 n) {
    assert(n >= 1);
    i64 ans{ n };
    for (i64 p = 2; p <= n / p; ++ p) if (n % p == 0) {
        ans = ans / p * (p - 1);
        while (n % p == 0) n /= p;
    }
    if (n > 1) ans = ans / n * (n - 1);
    return ans;
}
// min(a^e, cap)
u64 pow_cap(u64 a, u64 e, u64 cap) {
    if (!cap) return 0;
    __uint128_t res{ 1 }, x{ a };
    for (; e; e >>= 1) {
        if (e & 1) {
            res *= x;
            if (res >= cap) return cap;
        }
        if (e >> 1) {
            x *= x;
            if (x >= cap) x = cap;
        }
    }
    return u64(min<__uint128_t>(res, cap));
}
// min(T_l, cap)，用于判断真实指数是否 >= cap
u64 tower_cap(const vector<u64> &a, int l, u64 cap) {
    if (!cap) return 0;
    u64 x{ a[l] };
    if (l + 1 == int(a.size())) return min(x, cap);
    if (x == 0) {
        u64 e{ tower_cap(a, l + 1, 1) };
        return min<u64>(e == 0, cap);
    }
    if (x == 1) return 1;
    if (cap == 1) return 1;
    // 最小 need，使 x^need >= cap
    u64 need{}, v{ 1 };
    while (v < cap) {
        ++ need;
        if (x >= cap || v > (cap - 1) / x) v = cap;
        else v *= x;
    }
    u64 e{ tower_cap(a, l + 1, need) };
    if (e >= need) return cap;
    return pow_cap(x, e, cap);
}
i64 power_tower_mod_impl(const vector<u64> &a, int l, i64 mod) {
    if (mod == 1) return 0;
    if (l + 1 == int(a.size())) return i64(a[l] % u64(mod));
    i64 phi{ phi_trial(mod) };
    // 判断真实指数 T_{l+1} 是否已经达到 phi
    u64 small{ tower_cap(a, l + 1, u64(phi)) };
    u64 e;
    if (small < u64(phi)) {
        e = small; // 指数较小，必须使用真实值
    } else {
        e = u64(power_tower_mod_impl(a, l + 1, phi)) + u64(phi);
    }
    return qpow_mod(i64(a[l] % u64(mod)), e, mod);
}

i64 power_tower_mod(const vector<u64> &a, i64 mod) {
    assert(!a.empty() && mod > 0);
    return power_tower_mod_impl(a, 0, mod);
}
```
##### 常见用法
```cpp
vector<u64> a{ 2, 3, 2 };
i64 ans = power_tower_mod(a, mod);
```
计算
$$
2^{3^2}\bmod mod
$$
再例如：
```cpp
vector<u64> a{ 3, 4, 5, 6 };
i64 ans = power_tower_mod(a, mod);
```
计算
$$
3^{4^{5^6}}\bmod mod
$$
##### 为什么还需要 `tower_cap`
假设当前需要计算
$$
a^E\bmod m
$$
令
$$
\phi=\varphi(m)
$$
递归可以得到
$$
E\bmod\phi
$$
但仅有这个值无法判断应该使用
$$
E\bmod\phi
$$
还是
$$
E\bmod\phi+\phi
$$
因此额外计算
$$
\min(E,\phi)
$$
若结果小于 $\phi$，说明指数还很小，可以直接使用真实指数
若结果等于 $\phi$，说明
$$
E\ge\phi
$$
需要进入扩展 Euler 降幂
##### 为什么 `tower_cap` 不会真的算出巨大幂
若需要判断
$$
x^E\ge C
$$
只需知道最小的
$$
k
$$
满足
$$
x^k\ge C
$$
对于
$$
x\ge2
$$
有
$$
k\le\lceil\log_2C\rceil
$$
所以即使 $E$ 是巨大的幂塔，也只需把下一层截断到一个很小的阈值
#### Euler $\varphi$ 链
---
幂塔取模会不断递归：
$$
m
\to
\varphi(m)
\to
\varphi(\varphi(m))
\to\cdots\to1
$$
这通常称为 Euler $\varphi$ 链
链长很短，例如对 $m>2$：
$$
\varphi(m)<m
$$
并且会很快下降到 $1$
因此幂塔即使高度很大，真正有意义的模递归层数也不会很深
若有大量相同模数的幂塔询问，可以预处理：
```cpp
vector<i64> phi_chain(i64 m) {
    vector<i64> a{ m };
    while (m != 1) {
        m = phi_trial(m);
        a.push_back(m);
    }
    return a;
}
```
再复用整条链
#### $\lambda$ 链与 $\varphi$ 链
---
如果能保证**每一层当前底数都与当前模数互质**，理论上可以使用更短的
$$
m\to\lambda(m)\to\lambda(\lambda(m))\to\cdots
$$
但一般幂塔不能保证这一点
所以通用幂塔模板使用 $\varphi$ 链，而不是 $\lambda$ 链
#### 常见场景
##### 巨大十进制指数
$$
a^E\bmod m
$$
其中 $E$ 是长度 $10^5$ 的字符串：
```cpp
auto [phi, lambda] = phi_lambda(fac);

if (gcd(a, m) == 1) {
    ans = power_big_coprime(a, E, m, lambda);
} else {
    ans = power_big(a, E, m, phi);
}
```
##### 指数本身又是幂
$$
a^{b^c}\bmod m
$$
直接：
```cpp
vector<u64> tower{ u64(a), u64(b), u64(c) };
i64 ans = power_tower_mod(tower, m);
```
##### 很高的固定底数幂塔
例如
$$
2^{2^{2^{2^{\cdot^{\cdot^\cdot}}}}}\bmod m
$$
只需要把足够多层的 `2` 放入数组
当高度超过 $\varphi$ 链有效深度后，再增加高度往往不会增加递归深度
#### 注意事项
`phi_lambda()` 要求传入 $n$ 的**完整质因数分解**
`power_big_coprime()` 必须满足
$$
\gcd(a,m)=1
$$
非互质时只能使用 `power_big()` 的扩展 Euler 规则
扩展 Euler 定理的关键判断是
$$
E\ge\varphi(m)
$$
不能只保存
$$
E\bmod\varphi(m)
$$
`power_tower_mod()` 当前只处理非负整数底数
```cpp
vector<u64>
```
幂塔默认右结合，不能误写成
$$
((a_0^{a_1})^{a_2})^{\cdots}
$$
板子约定
$$
0^0=1
$$
若题目另有定义，需要单独修改
`phi_trial()` 是方便独立复制的短依赖，大模数应换成 8.2 的分解结果
#### 复杂度
`phi_lambda()` 在已知分解后：
$$
O(\log n)
$$
`decimal_mod_ge()` 对长度为 $L$ 的十进制指数：
$$
O(L)
$$
一次模快速幂：
$$
O(\log E')
$$
其中降幂后的指数
$$
E'<2\varphi(m)
$$
幂塔本身的递归层数受 Euler $\varphi$ 链限制
若各层 $\varphi$ 已经给出或快速得到，模运算部分可以粗略看作
$$
O(\log^2m)
$$
当前自包含版本使用 `phi_trial()`，实际复杂度主要取决于每层求 $\varphi$ 的试除成本
完整 `i64` 范围下应接 8.2 Pollard--Rho，而不是依赖试除
