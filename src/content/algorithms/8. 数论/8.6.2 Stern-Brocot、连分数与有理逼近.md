### Stern-Brocot、连分数与有理逼近
---
**解决问题：** 在只使用整数运算的前提下处理有理数搜索、最佳逼近、Stern-Brocot 路径、连分数展开与收敛分数，以及模意义下的小分数还原
“取模还原分数”和带分子、分母上界的 Stern-Brocot 二分，这里将它们与连分数统一整理，并将 Stern-Brocot 搜索改成显式有界跳跃，避免逐层走树
#### 分数基础
---
后面的所有接口统一使用约分后的
$$
\frac pq,\quad q>0
$$
```cpp
struct Frac {
    i64 p{}, q{ 1 };
};
Frac make_frac(i64 p, i64 q) {
    assert(q != 0);
    if (q < 0) p = -p, q = -q;
    i64 g{ gcd(p < 0 ? -p : p, q) };
    return { p / g, q / g };
}
int frac_cmp(const Frac &a, const Frac &b) {
    __int128_t x{ (__int128_t)a.p * b.q };
    __int128_t y{ (__int128_t)b.p * a.q };
    return x < y ? -1 : x > y ? 1 : 0;
}
```
`frac_cmp(a,b)` 返回：
- `-1`：$a<b$
- `0`：$a=b$
- `1`：$a>b$
#### 连分数
---
任意有理数均可写成有限简单连分数
$$
\frac pq
=
[a_0;a_1,a_2,\ldots,a_k]
=
a_0+
\cfrac1{a_1+
\cfrac1{a_2+\cdots}}
$$
其中对标准表示有
$$
a_i>0\quad(i\ge1)
$$
连分数展开本质上就是欧几里得算法的商序列
```cpp
pair<i64, i64> floor_divmod(i64 a, i64 b) {
    assert(b > 0);
    i64 q{ a / b }, r{ a % b };
    if (r < 0) -- q, r += b;
    return { q, r };
}
// p / q 的简单连分数，允许 p < 0，要求 q > 0
vector<i64> continued_fraction(i64 p, i64 q) {
    assert(q > 0);
    vector<i64> a;
    while (q) {
        auto [k, r] = floor_divmod(p, q);
        a.push_back(k);
        p = q, q = r;
    }
    return a;
}
// 根据连分数求所有收敛分数
vector<Frac> convergents(const vector<i64> &a) {
    __int128_t p0{ 0 }, p1{ 1 }, q0{ 1 }, q1{ 0 };
    vector<Frac> res;
    for (i64 x : a) {
        __int128_t p2{ (__int128_t)x * p1 + p0 };
        __int128_t q2{ (__int128_t)x * q1 + q0 };
        res.push_back({ i64(p2), i64(q2) });
        p0 = p1, p1 = p2;
        q0 = q1, q1 = q2;
    }
    return res;
}
```
##### 接口说明
```cpp
auto cf = continued_fraction(p, q);
auto conv = convergents(cf);
```
例如
$$
\frac{355}{113}
=
[3;7,16]
$$
其收敛分数为
$$
3,\quad\frac{22}{7},\quad\frac{355}{113}
$$
##### 递推
设第 $k$ 个收敛分数为
$$
\frac{P_k}{Q_k}
$$
初始化
$$
P_{-2}=0,\quad P_{-1}=1
$$
$$
Q_{-2}=1,\quad Q_{-1}=0
$$
递推
$$
P_k=a_kP_{k-1}+P_{k-2}
$$
$$
Q_k=a_kQ_{k-1}+Q_{k-2}
$$
相邻收敛分数满足
$$
P_kQ_{k-1}-P_{k-1}Q_k=\pm1
$$
因此天然互质
##### 复杂度
设
$$
g=\gcd(|p|,q)
$$
连分数展开与收敛分数数量均为
$$
O\left(\log\frac qg\right)
$$
#### 分母受限的最佳有理逼近
---
给定精确有理数
$$
x=\frac pq
$$
以及
$$
1\le d\le D
$$
求使
$$
\left|x-\frac nd\right|
$$
最小的分数
这不能只枚举普通收敛分数，边界处还可能需要**半收敛分数**

下面的误差比较不用浮点数
```cpp
__uint128_t abs128(__int128_t x) {
    return x < 0 ? __uint128_t(-x) : __uint128_t(x);
}
// 比较 a / b 与 c / d，不做交叉乘法，避免 u128 再次溢出
int ratio_cmp(__uint128_t a, __uint128_t b, __uint128_t c, __uint128_t d) {
    bool rev{};
    for (;;) {
        __uint128_t x{ a / b }, y{ c / d };
        if (x != y) {
            int res{ x < y ? -1 : 1 };
            return rev ? -res : res;
        }
        a %= b, c %= d;
        if (!a || !c) {
            int res{ !a && !c ? 0 : !a ? -1 : 1 };
            return rev ? -res : res;
        }
        swap(a, b), swap(c, d);
        rev = !rev;
    }
}
// 比较 a、b 到 p / q 的绝对误差
int error_cmp(const Frac &a, const Frac &b, i64 p, i64 q) {
    assert(a.q > 0 && b.q > 0 && q > 0);
    auto x = abs128((__int128_t)p * a.q - (__int128_t)a.p * q);
    auto y = abs128((__int128_t)p * b.q - (__int128_t)b.p * q);
    return ratio_cmp(x, a.q, y, b.q);
}
// 分母 <= limit 的最近分数，误差相同时优先收敛分数
Frac best_approx_den(i64 p, i64 q, i64 limit) {
    assert(q > 0 && limit > 0);
    i64 g{ gcd(p < 0 ? -p : p, q) };
    p /= g, q /= g;
    if (q <= limit) return { p, q };
    i64 n{ p }, d{ q };
    __int128_t p0{ 0 }, p1{ 1 }, q0{ 1 }, q1{ 0 };
    for (;;) {
        auto [a, r] = floor_divmod(n, d);
        __int128_t q2{ q0 + (__int128_t)a * q1 };
        if (q2 > limit) break;
        __int128_t p2{ p0 + (__int128_t)a * p1 };
        p0 = p1, p1 = p2;
        q0 = q1, q1 = q2;
        n = d, d = r;
    }
    __int128_t k{ (limit - q0) / q1 };
    Frac a{ i64(p0 + k * p1), i64(q0 + k * q1) };
    Frac b{ i64(p1), i64(q1) };
    return error_cmp(b, a, p, q) <= 0 ? b : a;
}
```
##### 接口说明
```cpp
Frac ans = best_approx_den(p, q, D);
```
返回约分分数
$$
\frac{ans.p}{ans.q}
$$
满足
$$
1\le ans.q\le D
$$
并使
$$
\left|
\frac pq-\frac{ans.p}{ans.q}
\right|
$$
最小
##### 常见用法
逼近 $\pi\approx355/113$，限制分母不超过 $10$：
```cpp
auto x = best_approx_den(355, 113, 10);
// 22 / 7
```
限制分母不超过 $100$：
```cpp
auto x = best_approx_den(355, 113, 100);
// 311 / 99
```
接口支持负数：
```cpp
auto x = best_approx_den(-3, 7, 5);
// -2 / 5
```
##### 为什么要半收敛分数
若当前两个连续收敛分数为
$$
\frac{P_{k-2}}{Q_{k-2}},\quad \frac{P_{k-1}}{Q_{k-1}}
$$
但下一个完整收敛分数的分母已经超过 $D$，则还能沿这一段走
$$
\frac{P_{k-2}+tP_{k-1}}
{Q_{k-2}+tQ_{k-1}}
$$
其中最大的合法
$$
t=
\left\lfloor
\frac{D-Q_{k-2}}{Q_{k-1}}
\right\rfloor
$$
最佳答案只需要比较这个半收敛分数与上一个完整收敛分数
##### 复杂度
$$
O(\log q)
$$
时间
$$
O(1)
$$
额外空间
#### Stern-Brocot 树
---
Stern-Brocot 树恰好包含所有正既约分数且每个只出现一次
从边界
$$
\frac01,\quad\frac10
$$
开始，两个相邻分数
$$
\frac ab<\frac cd
$$
的中介数为
$$
\frac{a+c}{b+d}
$$
若它们满足
$$
bc-ad=1
$$
则任意严格位于二者之间的既约分数都可以写成
$$
\frac{xa+yc}{xb+yd},\quad x,y>0
$$
因此中介数的分子、分母分别都是区间中可能出现的最小值
#### Stern-Brocot 路径
---
从根
$$
\frac11
$$
向左记 `L`，向右记 `R`
逐步相减会退化为减法版欧几里得算法，因此同方向操作可以一次压缩成一个 run
```cpp
vector<pair<char, i64>> stern_path(i64 p, i64 q) {
    assert(p > 0 && q > 0 && gcd(p, q) == 1);
    vector<pair<char, i64>> path;
    while (p != q) {
        if (p < q) {
            i64 k{ (q - 1) / p };
            path.push_back({ 'L', k });
            q -= k * p;
        } else {
            i64 k{ (p - 1) / q };
            path.push_back({ 'R', k });
            p -= k * q;
        }
    }
    return path;
}
Frac stern_from_path(const vector<pair<char, i64>> &path) {
    __int128_t lp{ 0 }, lq{ 1 }, rp{ 1 }, rq{ 0 };
    for (auto [c, k] : path) {
        assert(k > 0);
        if (c == 'L') rp += (__int128_t)k * lp, rq += (__int128_t)k * lq;
        else lp += (__int128_t)k * rp, lq += (__int128_t)k * rq;
    }
    return { i64(lp + rp), i64(lq + rq) };
}
```
##### 常见用法
```cpp
auto path = stern_path(2, 5);
// L^2 R

auto x = stern_from_path(path);
// 2 / 5
```
例如
$$
\frac25
$$
的路径为
$$
L^2R
$$
而
$$
\frac52
$$
的路径为
$$
R^2L
$$
##### 与连分数的关系
Stern-Brocot 的连续 `L / R` 长度，与连分数的商本质上是同一组欧几里得信息
连分数记录
$$
a_0,a_1,\ldots,a_k
$$
Stern-Brocot 则将这些商解释为交替的左右移动次数
因此：
- 连分数适合直接做逼近和收敛分数
- Stern-Brocot 适合在有理数集合上做单调搜索和边界约束
##### 复杂度
压缩路径的 run 数：
$$
O(\log\max(p,q))
$$
若真的将 `L^k / R^k` 展开成单字符路径，长度可能达到
$$
O(p+q)
$$
#### 带分子、分母上界的 Stern-Brocot 二分
---
给定
$$
0\le p\le P,\quad1\le q\le Q
$$
以及关于分数值 $p/q$ 的单调谓词 `f`
要求谓词满足从小到大形如：
```text
false false false true true true
```
可以同时求：
- 最大的合法 `false` 分数
- 最小的合法 `true` 分数
```cpp
struct SternBounds {
    optional<Frac> lo; // 最大 false
    optional<Frac> hi; // 最小 true
};
template<class F>
SternBounds stern_brocot_bounds(i64 max_p, i64 max_q, F f) {
    assert(max_p >= 0 && max_q >= 1);
    Frac lo{ 0, 1 }, hi{ 1, 0 };
    if (f(0, 1)) return { nullopt, lo };
    auto add = [&](Frac a, Frac b, i64 k) {
        return Frac{
            i64((__int128_t)a.p + (__int128_t)b.p * k),
            i64((__int128_t)a.q + (__int128_t)b.q * k)
        };
    };
    auto max_step = [&](Frac a, Frac b) {
        i64 k{ numeric_limits<i64>::max() };
        if (b.p) k = min(k, (max_p - a.p) / b.p);
        if (b.q) k = min(k, (max_q - a.q) / b.q);
        return k;
    };
    for (;;) {
        if (max_step(lo, hi) < 1) break;
        Frac mid{ lo.p + hi.p, lo.q + hi.q };
        if (f(mid.p, mid.q)) {
            i64 l{ 1 }, r{ max_step(hi, lo) };
            while (l < r) {
                i64 k{ l + (r - l + 1) / 2 };
                Frac x{ add(hi, lo, k) };
                if (f(x.p, x.q)) l = k;
                else r = k - 1;
            }
            hi = add(hi, lo, l);
        } else {
            i64 l{ 1 }, r{ max_step(lo, hi) };
            while (l < r) {
                i64 k{ l + (r - l + 1) / 2 };
                Frac x{ add(lo, hi, k) };
                if (!f(x.p, x.q)) l = k;
                else r = k - 1;
            }
            lo = add(lo, hi, l);
        }
    }
    return { lo, hi.q ? optional<Frac>{ hi } : nullopt };
}
```
`fracBS` 从 $0/1$ 与 $1/0$ 出发，并一次跳过多个相同方向的 Stern-Brocot 步骤；这里将跳跃长度为受分子、分母上界约束的显式二分，更方便检查边界
##### 接口说明
例如在
$$
p\le P,\quad q\le Q
$$
中寻找最靠近阈值
$$
\frac ab
$$
两侧的分数：
```cpp
auto res = stern_brocot_bounds(P, Q, [&](i64 p, i64 q) {
    return (__int128_t)p * b >= (__int128_t)a * q;
});
```
此时：
```cpp
res.lo // < a / b 的最大合法分数
res.hi // >= a / b 的最小合法分数
```
若没有有限的 `true` 分数：
```cpp
!res.hi
```
若连 $0/1$ 都满足谓词：
```cpp
!res.lo
res.hi == 0 / 1
```
##### 为什么终止条件正确
若相邻 Stern-Brocot 边界为
$$
\frac ab<\frac cd
$$
且
$$
bc-ad=1
$$
区间中的任意分数都至少需要分子、分母达到中介数
$$
\frac{a+c}{b+d}
$$
因此若
$$
a+c>P
$$
或
$$
b+d>Q
$$
就已经不存在满足两个上界且位于二者之间的分数
##### 复杂度
Stern-Brocot 的方向切换次数为欧几里得级别
$$
O(\log(P+Q))
$$
每一段对跳跃长度二分，因此谓词调用次数为
$$
O(\log^2(P+Q))
$$
空间为
$$
O(1)
$$
#### 同时限制分子与分母的最近逼近
---
若目标为非负有理数
$$
x=\frac ab
$$
同时要求
$$
0\le p\le P,\quad1\le q\le Q
$$
先通过 Stern-Brocot 求目标左右紧邻分数，再比较两边误差即可
```cpp
optional<Frac> best_approx_box(i64 a, i64 b, i64 max_p, i64 max_q) {
    assert(b > 0 && max_p >= 0 && max_q >= 1);
    bool neg{ a < 0 };
    if (neg) a = -a;
    auto s = stern_brocot_bounds(max_p, max_q, [&](i64 p, i64 q) {
        return (__int128_t)p * b >= (__int128_t)a * q;
    });
    optional<Frac> ans;
    if (s.lo) ans = s.lo;
    if (s.hi && (!ans || error_cmp(*s.hi, *ans, a, b) < 0)) ans = s.hi;
    if (ans && neg) ans->p = -ans->p;
    return ans;
}
```
##### 常见用法
```cpp
auto x = best_approx_box(a, b, max_num, max_den);
```
适合题目同时限制：
$$
|p|\le P
$$
以及
$$
q\le Q
$$
只限制分母时，前面的 `best_approx_den()` 更短且复杂度更优
#### 模意义下的有理数还原
---
有时已知
$$
r\equiv\frac ab\pmod m
$$
希望从模值 `r` 恢复一个“小分数”
等价于寻找
$$
a\equiv rb\pmod m
$$
并要求
$$
|a|\le A,\quad0<b\le B
$$
这是扩展欧几里得 / 连分数的另一个直接应用
```cpp
optional<Frac> rational_reconstruction(i64 r, i64 mod, i64 A, i64 B) {
    assert(mod > 0 && A >= 0 && B > 0);
    r %= mod;
    if (r < 0) r += mod;
    __int128_t r0{ mod }, r1{ r };
    __int128_t t0{}, t1{ 1 };
    auto abs_i128 = [](__int128_t x) {
        return x < 0 ? -x : x;
    };
    while (abs_i128(r1) > A) {
        if (!r1) return nullopt;
        __int128_t q{ r0 / r1 };
        __int128_t nr{ r0 - q * r1 };
        __int128_t nt{ t0 - q * t1 };
        r0 = r1, r1 = nr;
        t0 = t1, t1 = nt;
    }
    if (t1 < 0) r1 = -r1, t1 = -t1;
    if (t1 <= 0 || t1 > B || abs_i128(r1) > A) return nullopt;
    i64 p{ i64(r1) }, q{ i64(t1) };
    if (gcd(p < 0 ? -p : p, q) != 1 || gcd(q, mod) != 1) return nullopt;
    if (((__int128_t)r * q - p) % mod) return nullopt;
    return Frac{ p, q };
}
```
##### 接口说明
```cpp
auto x = rational_reconstruction(r, mod, A, B);
```
若成功返回
$$
\frac pq
$$
满足
$$
|p|\le A,\quad1\le q\le B
$$
$$
\gcd(p,q)=1,\quad\gcd(q,m)=1
$$
以及
$$
p\equiv rq\pmod m
$$
于是
$$
r\equiv pq^{-1}\pmod m
$$

##### 唯一性
若满足经典唯一性条件
$$
2AB<m
$$
则这样的既约分数至多只有一个
因此这一条件下函数成功返回时，可以将结果视为唯一重构
##### 常见用法
若
$$
r\equiv\frac37\pmod{101}
$$
因为
$$
7^{-1}\equiv29\pmod{101}
$$
所以
$$
r\equiv87\pmod{101}
$$
调用：
```cpp
auto x = rational_reconstruction(87, 101, 10, 10);
// 3 / 7
```
##### 复杂度
本质为一次欧几里得算法
$$
O(\log m)
$$
时间
$$
O(1)
$$
空间

#### 三者之间的关系
---
这三个工具本质上都来自同一套 Euclidean 结构

| 工具 | 保存的信息 | 更适合解决 |
|---|---|---|
| 连分数 | 欧几里得商序列 | 收敛分数、最佳逼近 |
| Stern-Brocot | 左右路径 / 邻接分数 | 有理数单调搜索、双上界 |
| 有理重构 | 欧几里得余数与 Bézout 系数 | 从模值恢复小分数 |

连分数中的一个大商，对应 Stern-Brocot 中连续走很多次同一方向
半收敛分数，对应 Stern-Brocot 一条边上只走一部分
模分数还原，则是在欧几里得过程中寻找第一个足够小的余数及其系数

#### 注意事项
`continued_fraction()`、`best_approx_den()` 要求
$$
q>0
$$
`stern_path()` 要求输入已经约分且
$$
p>0,\quad q>0
$$
Stern-Brocot 搜索本身只覆盖非负有理数，负数问题通常先取相反数再恢复符号
`stern_brocot_bounds()` 的谓词必须关于分数值单调，不能依赖分子、分母的其他非单调性质
涉及分数比较时不要转成 `double`
```cpp
double(p) / q
```
应优先使用交叉乘法或这里的精确误差比较
`best_approx_den()` 返回的是**绝对误差最小**的分数，并非单纯“最后一个收敛分数”
`rational_reconstruction()` 若不满足
$$
2AB<m
$$
仍可能返回一个符合约束的候选，但唯一性不再由该条件保证
#### 复杂度速查
| 接口 | 时间复杂度 | 空间 |
|---|---:|---:|
| `continued_fraction` | $O(\log q)$ | $O(\log q)$ |
| `convergents` | $O(k)$ | $O(k)$ |
| `best_approx_den` | $O(\log q)$ | $O(1)$ |
| `stern_path` | $O(\log\max(p,q))$ 个压缩段 | $O(\log\max(p,q))$ |
| `stern_from_path` | $O(k)$ | $O(1)$ |
| `stern_brocot_bounds` | $O(\log^2(P+Q))$ 次谓词调用 | $O(1)$ |
| `best_approx_box` | $O(\log^2(P+Q))$ | $O(1)$ |
| `rational_reconstruction` | $O(\log m)$ | $O(1)$ |
