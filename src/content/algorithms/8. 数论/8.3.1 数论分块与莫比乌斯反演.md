### 数论分块与莫比乌斯反演
---
**解决问题：** 将含有 $\left\lfloor n/i\right\rfloor$ 的求和压缩为 $O(\sqrt n)$ 个整除块，并结合 Möbius 反演快速统计互质数对、$\gcd=k$ 数对以及各种 $\gcd$ 权值和。
### 数论分块
对于正整数 $n$，若当前左端点为 `l`：
```cpp
for (i64 l = 1, r; l <= n; l = r + 1) {
    i64 q{ n / l };
    r = n / q;
    // i in [l, r] 时 n / i == q
}
```
若同时需要
$$
\left\lfloor\frac ni\right\rfloor,\quad
\left\lfloor\frac mi\right\rfloor
$$
保持不变，则取两个右端点的最小值：
```cpp
i64 lim{ min(n, m) };
for (i64 l = 1, r; l <= lim; l = r + 1) {
    i64 qn{ n / l }, qm{ m / l };
    r = min({ lim, n / qn, m / qm });
    // i in [l, r] 时 n / i、m / i 均不变
}
```
#### 原理
固定
$$
q=\left\lfloor\frac nl\right\rfloor
$$
满足
$$
\left\lfloor\frac ni\right\rfloor=q
$$
的最大 $i$ 为
$$
r=
\left\lfloor
\frac n q
\right\rfloor
=
\left\lfloor
\frac{n}{
\lfloor n/l\rfloor
}
\right\rfloor
$$
因此可以将整个区间
$$
[l,r]
$$
一次处理
$\lfloor n/i\rfloor$ 只有 $O(\sqrt n)$ 个不同取值：当 $i\le\sqrt n$ 时最多 $\sqrt n$ 个，而 $i>\sqrt n$ 时商小于 $\sqrt n$
#### 常见用法
求
$$
\sum_{i=1}^n
\left\lfloor\frac ni\right\rfloor:
$$
```cpp
__int128_t sum_floor_div(i64 n) {
    __int128_t ans{};
    for (i64 l = 1, r; l <= n; l = r + 1) {
        i64 q{ n / l };
        r = n / q;
        ans += (__int128_t)(r - l + 1) * q;
    }
    return ans;
}
```
同时有恒等式：
$$
\sum_{i=1}^n
\left\lfloor\frac ni\right\rfloor
=
\sum_{i=1}^n\tau(i)
$$
因为左边统计的就是满足
$$
ab\le n
$$
的正整数对 $(a,b)$ 数量
#### 带权求和
若已经有前缀和
$$
S(x)=\sum_{i=1}^x f(i)
$$
要求
$$
\sum_{i=1}^n
f(i)
G\left(
\left\lfloor\frac ni\right\rfloor
\right)
$$
则直接：
```cpp
for (i64 l = 1, r; l <= n; l = r + 1) {
    i64 q{ n / l };
    r = n / q;
    ans += (pre[r] - pre[l - 1]) * calc(q);
}
```
这是后面 $\mu$ 前缀和、$\varphi$ 前缀和参与数论分块时最常用的形式
#### 注意事项
数论分块中的除法默认都是**正整数整除**。不要把同一写法直接用于负数，因为 C++ 的有符号整数除法和数学上的 floor division 不完全等价
单变量右端点：
```cpp
r = n / (n / l);
```
多个整除项共同分块时，必须取各自右端点的最小值。比如：
```cpp
r = min(n / (n / l), m / (m / l));
```
否则其中一个商可能已经改变
循环从 `l = 1` 开始；不要让 `n / l == 0` 后再计算：
```cpp
n / (n / l)
```
否则会除以零
这里的“数论分块”与后面 8.6 的
$$
\sum_i
\left\lfloor
\frac{ai+b}{m}
\right\rfloor
$$
型 `floor_sum` 不是同一个算法
#### 复杂度
单个
$$
\left\lfloor\frac ni\right\rfloor
$$
的整除分块数量为
$$
O(\sqrt n)
$$
因此每块 $O(1)$ 处理时，总时间为
$$
O(\sqrt n)
$$
额外空间为
$$
O(1)
$$
两个整数 $n,m$ 共同分块时，复杂度为块数，即至多
$$
O(\sqrt n+\sqrt m)
$$
### Möbius 反演与 gcd 条件
这一部分最值得记住的不是公式本身，而是一个固定套路
假设某个对象拥有参数 $g$，例如：
$$
g=\gcd(x,y)
$$
令：
$$
F(d)
=
\#\{\,\text{对象}:d\mid g\,\}
$$
以及：
$$
f(k)
=
\#\{\,\text{对象}:g=k\,\}
$$
显然：
$$
F(d)
=
\sum_{d\mid k}f(k)
$$
对“倍数关系”做 Möbius 反演：
$$
f(d)
=
\sum_{t\ge1}
\mu(t)F(dt)
$$
特别地：
$$
f(1)
=
\sum_{t\ge1}\mu(t)F(t)
$$
所以当目标条件是
$$
\gcd(x,y)=1
$$

时，通常先把它改写成
$$
[\gcd(x,y)=1]
=
\sum_{d\mid\gcd(x,y)}\mu(d)
$$
这就是竞赛中 Möbius 反演处理 gcd 计数最常见的入口
### 互质数对与 $\gcd=k$
```cpp
struct CoprimeCounter {
    int n;
    vector<int> sum_mu;
    explicit CoprimeCounter(int n_) : n(n_), sum_mu(n + 1) {
        vector<int> minp(n + 1), primes, mu(n + 1);
        if (n >= 1) mu[1] = 1;
        for (int i = 2; i <= n; ++ i) {
            if (!minp[i]) {
                minp[i] = i;
                primes.push_back(i);
                mu[i] = -1;
            }
            for (int p : primes) {
                i64 v{ 1LL * i * p };
                if (v > n) break;
                minp[v] = p;
                if (p == minp[i]) {
                    mu[v] = 0;
                    break;
                }
                mu[v] = -mu[i];
            }
        }
        for (int i = 1; i <= n; ++ i) {
            sum_mu[i] = sum_mu[i - 1] + mu[i];
        }
    }
    // ===== 基础功能：统计 [1,a] × [1,b] 中的互质有序数对 =====
    i64 count(i64 a, i64 b) const {
        if (a <= 0 || b <= 0) return 0;
        i64 lim{ min(a, b) };
        assert(lim <= n);
        i64 ans{};
        for (i64 l = 1, r; l <= lim; l = r + 1) {
            i64 qa{ a / l }, qb{ b / l };
            r = min({ lim, a / qa, b / qb });
            ans += i64(sum_mu[r] - sum_mu[l - 1]) * qa * qb;
        }
        return ans;
    }
    // ===== 以下函数可直接删除：统计 gcd 恰好为 k =====
    i64 count_gcd(i64 a, i64 b, i64 k) const {
        assert(k > 0);
        return count(a / k, b / k);
    }
    // ===== 以下函数可直接删除：矩形内 gcd 恰好为 k =====
    i64 rect(i64 a, i64 b, i64 c, i64 d, i64 k) const {
        assert(1 <= a && a <= b && 1 <= c && c <= d && k > 0);
        return count_gcd(b, d, k) - count_gcd(a - 1, d, k)
             - count_gcd(b, c - 1, k) + count_gcd(a - 1, c - 1, k);
    }
};
```
#### 原理
考虑
$$
1\le x\le n,\quad
1\le y\le m
$$
有：
$$
[\gcd(x,y)=1]
=
\sum_{d\mid x,\ d\mid y}\mu(d)
$$
交换求和：
$$
\begin{aligned}
C(n,m)
&=
\sum_{x=1}^n
\sum_{y=1}^m
[\gcd(x,y)=1]\\
&=
\sum_{d=1}^{\min(n,m)}
\mu(d)
\left\lfloor\frac nd\right\rfloor
\left\lfloor\frac md\right\rfloor
\end{aligned}
$$
于是令
$$
M(x)=\sum_{i=1}^x\mu(i)
$$
对两个整除商共同分块：
$$
C(n,m)
=
\sum_{[l,r]}
\bigl(M(r)-M(l-1)\bigr)
\left\lfloor\frac nl\right\rfloor
\left\lfloor\frac ml\right\rfloor
$$
这正是 `count()`
#### `count()` 接口
```cpp
CoprimeCounter counter(N);
i64 ans = counter.count(n, m);
```
返回满足
$$
1\le x\le n,\quad
1\le y\le m,\quad
\gcd(x,y)=1
$$
的**有序数对**数量
要求：
$$
\min(n,m)\le N
$$
#### $\gcd=k$
若：
$$
\gcd(x,y)=k
$$
令：
$$
x=kx',\qquad y=ky'
$$
则：
$$
\gcd(x',y')=1
$$
因此：
$$
\#\{\gcd(x,y)=k\}
=
C\left(
\left\lfloor\frac nk\right\rfloor,
\left\lfloor\frac mk\right\rfloor
\right)
$$
对应：
```cpp
i64 ans = counter.count_gcd(n, m, k);
```
#### 矩形查询
求：
$$
a\le x\le b,
\quad
c\le y\le d,
\quad
\gcd(x,y)=k
$$
直接二维前缀容斥：
```cpp
i64 ans = counter.rect(a, b, c, d, k);
```
等价于：
$$
F(b,d)-F(a-1,d)-F(b,c-1)+F(a-1,c-1)
$$
#### 常见用法
##### $[1,n]\times[1,m]$ 互质数对
```cpp
int N = min(n, m);
CoprimeCounter counter(N);
cout << counter.count(n, m) << '\n';
```
##### gcd 恰好为 $k$
```cpp
cout << counter.count_gcd(n, m, k) << '\n';
```
##### 多次矩形询问
若所有查询满足坐标除以 $k$ 后不超过统一上界 `N`：
```cpp
CoprimeCounter counter(N);
for (...) {
    cout << counter.rect(a, b, c, d, k) << '\n';
}
```
这是很经典的一类 Möbius + 数论分块查询
#### 注意事项
`count()` 统计的是**有序数对**：
$$
(x,y)
$$
和
$$
(y,x)
$$
通常是两个不同对象
如果题目要求：
$$
x<y,\quad x\le y
$$
之类的限制，不能直接把答案除以 $2$，必须结合对角线是否允许单独处理
构造上界 `N` 必须覆盖所有查询真正需要的：
$$
\min\left(
\left\lfloor\frac nk\right\rfloor,
\left\lfloor\frac mk\right\rfloor
\right)
$$
如果已经在 8.3 中构造了：
```cpp
ArithmeticSieve sieve(N);
```
那么 `CoprimeCounter` 里那段 Möbius 线性筛可以删除，直接使用：
```cpp
sieve.sum_mu
```
但单独复制 `CoprimeCounter` 时无需其他板子
#### 复杂度
构造：
$$
O(N)
$$
时间和空间
一次 `count(n,m)`：
$$
O(\sqrt n+\sqrt m)
$$
时间，额外空间 $O(1)$
若所有参数都不超过 $N$，通常直接写作：
$$
O(\sqrt N)
$$
`count_gcd()` 同阶
`rect()` 调用四次，所以渐进复杂度仍为：
$$
O(\sqrt N)
$$
$q$ 次询问总复杂度：
$$
O(N+q\sqrt N)
$$
### gcd 权值和
Möbius反演不只是能判断 `gcd == 1`。更一般地，如果某个函数 $F$ 可以写成：
$$
F(n)=\sum_{d\mid n}f(d)
$$
那么：
$$
\sum_{i=1}^n
\sum_{j=1}^m
F(\gcd(i,j))
$$
可以交换求和为：
$$
\sum_{d=1}^{\min(n,m)}
f(d)
\left\lfloor\frac nd\right\rfloor
\left\lfloor\frac md\right\rfloor
$$
于是只要有 $f$ 的前缀和，又变成同一个数论分块模板
这个结论我建议哥哥一定保留，它能把很多看起来完全不同的 gcd 求和统一起来
### gcd 总和
由经典恒等式：
$$
\sum_{d\mid n}\varphi(d)=n
$$
得到：
$$
\gcd(i,j)
=
\sum_{d\mid\gcd(i,j)}\varphi(d)
$$
因此：
$$
\sum_{i=1}^n
\sum_{j=1}^m
\gcd(i,j)
=
\sum_{d=1}^{\min(n,m)}
\varphi(d)
\left\lfloor\frac nd\right\rfloor
\left\lfloor\frac md\right\rfloor
$$
传入上一节已经预处理好的：
$$
\Phi(x)
=
\sum_{i=1}^x\varphi(i)
$$
```cpp
__int128_t gcd_sum(i64 n, i64 m, const vector<i64> &sum_phi) {
    if (n <= 0 || m <= 0) return 0;
    i64 lim{ min(n, m) };
    assert(lim < i64(sum_phi.size()));
    __int128_t ans{};
    for (i64 l = 1, r; l <= lim; l = r + 1) {
        i64 qn{ n / l }, qm{ m / l };
        r = min({ lim, n / qn, m / qm });
        ans += (__int128_t)(sum_phi[r] - sum_phi[l - 1]) * qn * qm;
    }
    return ans;
}
```
#### 接口说明
```cpp
auto ans = gcd_sum(n, m, sieve.sum_phi);
```
计算：

$$
\sum_{i=1}^n
\sum_{j=1}^m
\gcd(i,j)
$$
这里使用 `__int128_t`，因为即使 `n,m` 本身能放入 `i64`，GCD 总和也可能较早超过 `i64`
#### 常见用法
```cpp
ArithmeticSieve sieve(min(n, m));
__int128_t ans = gcd_sum(n, m, sieve.sum_phi);
```
如果题目要求取模，可以直接在每个分块贡献处取模，不必真的保存 `__int128_t` 总答案
#### 复杂度
若 $\varphi$ 前缀和已经预处理：
$$
O(\sqrt n+\sqrt m)
$$
时间，
$$
O(1)
$$
额外空间
若连筛法一起计算，则还需：
$$
O(\min(n,m))
$$
预处理
### 其他 gcd 权值的统一写法
若：
$$
F=f*\mathbf1
$$
即：
$$
F(n)=\sum_{d\mid n}f(d)
$$
则：
$$
\boxed{
\sum_{i=1}^n
\sum_{j=1}^m
F(\gcd(i,j))
=
\sum_{d=1}^{\min(n,m)}
f(d)
\left\lfloor\frac nd\right\rfloor
\left\lfloor\frac md\right\rfloor
}
$$
几个非常常见的对应关系：

| $F(n)$ | $f(n)$ | 得到的统计 |
|---|---|---|
| $[n=1]$ | $\mu(n)$ | 互质数对 |
| $n$ | $\varphi(n)$ | $\gcd$ 总和 |
| $\tau(n)$ | $1$ | $\tau(\gcd)$ 总和 |
| $\sigma_k(n)$ | $n^k$ | $\sigma_k(\gcd)$ 总和 |
例如：
$$
\tau(n)
=
\sum_{d\mid n}1
$$
所以：
$$
\sum_{i=1}^n
\sum_{j=1}^m
\tau(\gcd(i,j))
=
\sum_{d=1}^{\min(n,m)}
\left\lfloor\frac nd\right\rfloor
\left\lfloor\frac md\right\rfloor
$$
此时分块内 $f(d)=1$，所以 `[l,r]` 的权值和直接是：
```cpp
r - l + 1
```
### Möbius 反演常见推导模板
遇到题目含有：
```text
gcd(x, y) == 1
gcd(x, y) == k
gcd(x, y) | k
k | gcd(x, y)
F(gcd(x, y))
```
时，可以优先按下面这个思路检查：
1. **先把 gcd 条件变成约数条件**
   例如：
   $$
   [\gcd(x,y)=1]
   =
   \sum_{d\mid x,\ d\mid y}\mu(d)
   $$
2. **交换枚举顺序**
   原来枚举 $(x,y)$，改成先枚举公共约数 $d$
3. **计算 $d$ 的倍数数量**
   $[1,n]$ 中 $d$ 的倍数有：
   $$
   \left\lfloor\frac nd\right\rfloor
   $$
4. **得到形如**
   $$
   \sum_d
   f(d)
   \left\lfloor\frac nd\right\rfloor
   \left\lfloor\frac md\right\rfloor
   $$
5. **对 $f$ 建前缀和，再数论分块**
### 注意事项
数论分块只有在“块内剩余部分可以 $O(1)$ 求出”时才真正有用。例如：
$$
\sum_{i=l}^r\mu(i)
$$
如果每个块里仍然逐项枚举 $\mu(i)$，复杂度又会退回 $O(n)$；因此要先有 Möbius 前缀和
同理：
$$
\sum_{i=l}^r\varphi(i)
$$
需要：
```cpp
sum_phi[r] - sum_phi[l - 1]
```
而不是块内循环
另外，“莫比乌斯反演”本身通常**不会自动降低复杂度**。真正的加速往往来自：
```text
莫比乌斯反演
→ 出现 floor(n / d)
→ 相同整除商分块
→ 用 μ / φ 等前缀和一次处理整块
```
这四步通常是一起出现的
### 复杂度速查

| 内容 | 时间复杂度 | 额外空间 |
|---|---:|---:|
| 单个 $\lfloor n/i\rfloor$ 数论分块 | $O(\sqrt n)$ | $O(1)$ |
| 两个整除项共同分块 | $O(\sqrt n+\sqrt m)$ | $O(1)$ |
| Möbius 前缀预处理 | $O(N)$ | $O(N)$ |
| `CoprimeCounter::count` | $O(\sqrt N)$ | $O(1)$ |
| `count_gcd` | $O(\sqrt N)$ | $O(1)$ |
| `rect` | $O(\sqrt N)$ | $O(1)$ |
| 已有 $\varphi$ 前缀和的 `gcd_sum` | $O(\sqrt N)$ | $O(1)$ |
| $q$ 次互质 / gcd 查询 | $O(N+q\sqrt N)$ | $O(N)$ |
