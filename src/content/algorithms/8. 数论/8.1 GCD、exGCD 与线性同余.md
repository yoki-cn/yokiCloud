### GCD、exGCD 与线性同余
---
#### GCD 与 LCM
- 求一组数全部相同模意义、平移后具有公共周期等问题时，经常需要对**差分**取 GCD：
```cpp
i64 g{};
for (int i = 1; i < n; ++ i) g = gcd(g, a[i] - a[0]);
```
因为
$$
x\mid(a_i-a_0)
$$
等价于这些数模 $x$ 同余
##### 复杂度
一次
```cpp
gcd(a, b)
```
时间复杂度为
$$
O(\log \min(|a|,|b|))
$$
额外空间为 $O(1)$
对 $n$ 个绝对值不超过 $V$ 的整数连续求 GCD，时间复杂度为
$$
O(n\log V)
$$
#### exGCD 与 Bézout 方程
---
返回
```text
{g, x, y}
```
满足
$$
ax+by=g
$$
```cpp
array<i64, 3> exgcd(i64 a, i64 b) {
    if (!b) return {a, 1, 0};
    auto [g, x, y] = exgcd(b, a % b);
    return {g, y, x - a / b * y};
}
```
若题目中 `a,b` 都保证非负，则返回的
$$
g=\gcd(a,b)\ge0
$$
若允许任意符号并希望强制 `g > 0`，调用后统一处理即可：
```cpp
auto [g, x, y] = exgcd(a, b);
if (g < 0) g = -g, x = -x, y = -y;
```
##### 接口说明
- `exgcd(a,b)`：返回 `{g,x,y}`，满足
$$
ax+by=g
$$
- 对通常的非负输入，$g=\gcd(a,b)$
- 它不仅求 GCD，还给出 Bézout 系数 $x,y$
Bézout 定理说明：对于 $a,b$ 不全为 $0$，
$$
ax+by=c
$$
存在整数解，当且仅当
$$
\gcd(a,b)\mid c
$$
因此 exGCD 可以直接解决二元一次不定方程；这也是常见数论模板中 exGCD 的主要用途
##### 注意事项
若
```cpp
auto [g, x, y] = exgcd(a, b);
```
得到了
$$
ax+by=g
$$
那么方程
$$
ax+by=c
$$
在 $g\mid c$ 时的一组特解为
$$
x_0=x\frac cg,\qquad
y_0=y\frac cg.
$$
全部整数解为
$$
x=x_0+\frac bg t
$$
$$
y=y_0-\frac ag t
$$
其中
$$
t\in\mathbb Z
$$
计算 `x * (c / g)` 等表达式时，若数值可能很大，应在乘法之前转成 `i128`：
```cpp
i128 x0 = i128(x) * (c / g);
i128 y0 = i128(y) * (c / g);
```
如果后续还要求：
- $x>0,y>0$
- $L_x\le x\le R_x$
- 统计某个范围内解的数量
只需要把上述通解代入区间，转化成对参数 $t$ 的上下界。此时直接复用基础工具中的 `floor_div / ceil_div` 即可求正整数解
##### 常见用法
###### 求一组 Bézout 系数
```cpp
auto [g, x, y] = exgcd(a, b);
// a * x + b * y = g
```
##### 解 $ax+by=c$
```cpp
auto [g, x, y] = exgcd(a, b);
if (c % g) {
    // 无整数解
} else {
    i128 k = c / g;
    i128 x0 = i128(x) * k;
    i128 y0 = i128(y) * k;
    // 全部解：
    // x = x0 + (b / g) * t
    // y = y0 - (a / g) * t
}
```
###### 判断某个整数能否表示成 $ax+by$
只需要：
```cpp
if (c % gcd(a, b) == 0) {
    // 可以
}
```
若只判断存在性，完全不需要调用 `exgcd()`
##### 复杂度
`exgcd(a,b)` 与普通 Euclid 算法同阶：
$$
O(\log \min(|a|,|b|))
$$
时间
递归深度也是
$$
O(\log \min(|a|,|b|))
$$
#### 线性同余
---
求解
$$
ax\equiv b\pmod m
$$
依赖 `exgcd()`
返回：
```text
{x0, period}
```
表示全部整数解为
$$
x\equiv x_0\pmod{\text{period}}
$$
若无解返回 `nullopt`
```cpp
optional<pair<i64, i64>> linear_congruence(i64 a, i64 b, i64 m) {
    assert(m > 0);
    a %= m;
    b %= m;
    if (a < 0) a += m;
    if (b < 0) b += m;
    auto [g, x, y] = exgcd(a, m);
    if (b % g) return nullopt;
    i64 mod{m / g};
    i64 x0{i64(i128(x) * (b / g) % mod)};
    if (x0 < 0) x0 += mod;
    return pair{x0, mod};
}
```
把一个线性同余压缩成“最小非负解 + $m/g$ 周期”的形式；相比直接枚举所有余数解，这更适合作为后续 CRT 等算法的底层接口
##### 接口说明
```cpp
auto sol = linear_congruence(a, b, m);
```
解决
$$
ax\equiv b\pmod m,
\quad m>0
$$
设
$$
g=\gcd(a,m)
$$
有解的充要条件是
$$
g\mid b
$$
若有解，返回
```cpp
{x0, m / g}
```
其中
$$
0\le x_0<\frac mg
$$
全部整数解为
$$
x=x_0+k\frac mg,\quad k\in\mathbb Z
$$
因此模原模数 $m$ 看，恰好有 $g$ 个不同解：
$$
x_0,\quad
x_0+\frac mg,\quad
\dots,\quad
x_0+(g-1)\frac mg
$$
这里不直接枚举，是因为 `{x0, period}` 信息已经完整，而且更适合继续参与 CRT 合并
##### 注意事项
###### `m` 必须为正
接口要求：
```cpp
m > 0
```
不要用负数模数
###### 返回的第二项不是原模数
例如：
$$
6x\equiv8\pmod{14}
$$
有
$$
g=\gcd(6,14)=2
$$
所以结果的周期是
$$
\frac{14}{2}=7
$$
也就是说：
$$
x\equiv6\pmod7
$$
模 $14$ 下对应两个解：
$$
x=6,\ 13
$$
###### `a=0` 也能处理
对于
$$
0x\equiv b\pmod m
$$
若
$$
m\mid b
$$
则任意整数都是解，函数返回：
```text
{0, 1}
```
表示
$$
x\equiv0\pmod1
$$
即所有整数
否则返回 `nullopt`
###### 乘法需要扩大类型
核心式子中：
```cpp
x * (b / g)
```
即使最终已经对 `m / g` 取模，中间乘法仍可能溢出 `i64`，因此板子使用：
```cpp
i128(x) * (b / g)
```
不要删掉这个扩大类型
##### 常见用法
###### 求一个线性同余
```cpp
auto sol = linear_congruence(a, b, m);

if (!sol) {
    // 无解
} else {
    auto [x, mod] = *sol;
    // 全部解 x ≡ x0 (mod mod)
}
```
###### 枚举 $[0,m)$ 中全部解
```cpp
auto sol = linear_congruence(a, b, m);

if (sol) {
    auto [x, step] = *sol;
    for (i64 v = x; v < m; v += step) {
        // v 是一个解
    }
}
```
解的数量为
```cpp
m / step
```
也就是
$$
\gcd(a,m)
$$
###### 模逆元实际上是特殊情形
若
$$
\gcd(a,m)=1
$$
则
$$
ax\equiv1\pmod m
$$
唯一对应：
```cpp
auto inv = linear_congruence(a, 1, m);
```
但正式的逆元接口、质数模快速幂求逆以及线性预处理逆元，仍统一放到后面的 **8.4 逆元、CRT 与模方程**，这里不重复
##### 复杂度
主要耗时来自一次 `exgcd(a,m)`，因此时间复杂度为
$$
O(\log m)
$$
递归额外空间为
$$
O(\log m)
$$
若枚举模 $m$ 下全部 $g=\gcd(a,m)$ 个不同余数解，则还需要
$$
O(g)
$$

时间
##### 常用结论速查
这几条我建议直接放在文件最后，比单独做“数论公式”更容易赛场上找到：
$$
ax+by=c
\iff
\gcd(a,b)\mid c
$$
若 $(x_0,y_0)$ 是一组解，则全部解：
$$
x=x_0+\frac bg t,\quad
y=y_0-\frac ag t,\quad t\in\mathbb Z
$$
对于
$$
ax\equiv b\pmod m
$$
设
$$
g=\gcd(a,m)
$$
则：
- $g\nmid b$：无解；
- $g\mid b$：模 $m$ 恰有 $g$ 个不同解；
- 所有整数解可以压成一个同余类
$$
x\equiv x_0\pmod{m/g}
$$
而
$$
a^{-1}\pmod m
$$
存在当且仅当
$$
\gcd(a,m)=1
$$
