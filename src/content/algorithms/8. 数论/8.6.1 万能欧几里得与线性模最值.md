### 万能欧几里得与线性模最值
---
**解决问题：** 将
$$
y_i=\left\lfloor\frac{pi+r}{q}\right\rfloor
$$
对应的格点路径抽象为一串 `U / R` 操作，在只要求操作满足结合律时仍能用欧几里得递归快速求整段操作的合成结果；同时求
$$
\min_{0\le i<n}(ai+b)\bmod m
\quad,\quad
\max_{0\le i<n}(ai+b)\bmod m
$$
#### 万能欧几里得
考虑直线
$$
y=\frac{px+r}{q},\quad 0<x\le n
$$
生成一个操作序列：
- 穿过一条横线执行一次 `U`
- 穿过一条竖线执行一次 `R`
- 同时穿过整点时先 `U` 后 `R`
因此第 $i$ 个 `R` 前恰有
$$
\left\lfloor\frac{pi+r}{q}\right\rfloor
$$
个 `U`
`T{}` 为单位元，`operator+` 表示**按先左后右顺序合并两段操作**，只要求满足结合律，不要求交换律
```cpp
template<class T>
T repeat(T a, i64 k) {
    T res{};
    for (; k; k >>= 1, a = a + a) {
        if (k & 1) res = res + a;
    }
    return res;
}
template<class T>
T euclid_word_impl(i64 p, i64 q, i64 r, i64 n, T U, T R) {
    if (!n) return T{};
    // ===== 提取斜率的整数部分 =====
    if (p >= q) {
        return euclid_word_impl(p % q, q, r, n, U, repeat(U, p / q) + R);
    }
    // ===== 此时 0 <= p < q，交换横纵坐标递归 =====
    i64 h{ i64((__int128_t(p) * n + r) / q) };
    if (!h) return repeat(R, n);
    i64 pre{ (q - r - 1) / p };
    i64 suf{ n - i64((__int128_t(q) * h - r - 1) / p) };
    return repeat(R, pre) + U
         + euclid_word_impl(q, p, (q - r - 1) % p, h - 1, R, U)
         + repeat(R, suf);
}
// p >= 0, q > 0, r >= 0, n >= 0
template<class T>
T euclid_word(i64 p, i64 q, i64 r, i64 n, T U, T R) {
    assert(p >= 0 && q > 0 && r >= 0 && n >= 0);
    if (!n) return T{};
    return repeat(U, r / q) + euclid_word_impl(p, q, r % q, n, U, R);
}
```
##### 接口说明
```cpp
T ans = euclid_word(p, q, r, n, U, R);
```
返回直线
$$
y=\frac{px+r}{q},\quad 0<x\le n
$$
生成的完整操作序列的合成结果
要求：
$$
p\ge0,\quad q>0,\quad r\ge0,\quad n\ge0
$$
并且类型 `T` 满足：
```cpp
T{}        // 单位元
a + b      // 先执行 a，再执行 b
(a + b) + c == a + (b + c)
```
`operator+` **不需要满足交换律**，矩阵乘法、仿射变换、状态转移以及自定义区间摘要都可以使用
##### 为什么能做任意结合操作
普通类欧几里得通常针对某个具体和式单独推：
$$
\sum y_i,\quad \sum iy_i,\quad \sum y_i^2
$$
万能欧几里得不再直接维护这些量，而是先求出 `U / R` 操作串的**压缩表示**
只要某个问题能设计出：
```text
U：跨过一条横线后的状态变化
R：跨过一条竖线后的状态变化
```
并且相邻两段可以结合，就可以直接复用同一套递归
##### 递推：斜率不小于 1
若
$$
p=kq+p',\quad 0\le p'<q
$$
则每次 `R` 前都会额外多出 $k$ 个 `U`
因此：
$$
R\longrightarrow U^kR
$$
对应代码：
```cpp
euclid_word_impl(p % q, q, r, n, U, repeat(U, p / q) + R)
```
##### 递推：斜率小于 1
设
$$
0<p<q,\quad h=\left\lfloor\frac{pn+r}{q}\right\rfloor
$$
交换横纵轴后，`U / R` 的角色互换，新的参数为
$$
(q,p,q-r-1,h-1)
$$
两端还需要补上若干 `R`，于是得到：
```cpp
repeat(R, pre) + U
+ euclid_word_impl(q, p, (q - r - 1) % p, h - 1, R, U)
+ repeat(R, suf)
```
这正是万能欧几里得的核心递归结构
#### 万能欧几里得使用示例
例如重新计算
$$
\sum_{i=1}^n\left\lfloor\frac{ai+b}{m}\right\rfloor
$$
只需要令状态记录：
- `x`：出现多少个 `R`
- `y`：出现多少个 `U`
- `sum`：每次 `R` 时当前 `y` 的总和
```cpp
struct FloorPath {
    i64 x{}, y{};
    __int128_t sum{};
    friend FloorPath operator+(const FloorPath &a, const FloorPath &b) {
        return { a.x + b.x, a.y + b.y, a.sum + b.sum + (__int128_t)a.y * b.x };
    }
};
```
调用：
```cpp
FloorPath U{ 0, 1, 0 };
FloorPath R{ 1, 0, 0 };
auto s = euclid_word(a, m, b, n, U, R);
auto ans = s.sum;
```
得到
$$
ans=
\sum_{i=1}^n
\left\lfloor\frac{ai+b}{m}\right\rfloor
$$
因为把两段 `A + B` 拼起来时，右半段的每一个 `R` 都会额外看到左半段的 `a.y` 个 `U`，所以：
$$
sum_{A+B}
=
sum_A+sum_B+y_Ax_B
$$

> [!tip]
> 如果只需要普通 `floor_sum` 或上一节的 $f,g,h$ 三类和，直接使用上一节专门板子更短  
> 万能欧几里得的价值主要在于**题目要求的状态变了，但操作仍能用结合律合并**
#### 常见设计方式
`T` 常见可以设计成：
- 矩阵，`+` 表示矩阵乘法
- 仿射变换，`+` 表示函数复合
- 自定义统计量，合并时计算左右两段及跨段贡献
- 维护 $x,y$ 的低次多项式和，例如 $\sum x^ay^b$
因此万能欧几里得特别适合：
$$
\sum P\left(i,\left\lfloor\frac{ai+b}{m}\right\rfloor\right)
$$
其中 $P$ 为低次多项式，或对应操作能压缩进固定维状态
#### 注意事项
`euclid_word()` 的下标约定是
$$
1\le i\le n
$$
而上一节的 `floor_sum()` 使用
$$
0\le i<n
$$
不要直接混用参数
模板要求 $p,r\ge0$，负系数的普通取整和应优先使用上一节支持负数的 `floor_sum`
`T{}` 必须是真正的单位元
例如矩阵类型默认构造若是零矩阵，就不能直接使用，必须让默认构造表示单位矩阵，或者修改 `repeat()` 的单位元来源
组合顺序不能写反：
```cpp
a + b
```
表示**先执行 `a` 再执行 `b`**
即使 `operator+` 不可交换也完全合法
#### 复杂度
若一次 `T + T` 的复杂度为 $C$，欧几里得递归层数与快速重复总操作次数均为对数级：
$$
O(C\log\max(p,q))
$$
递归空间：
$$
O(\log\max(p,q))
$$

### 线性模最值
给定
$$
r_i=(ai+b)\bmod m,\quad 0\le i<n
$$
求：
$$
\min r_i,\quad \max r_i
$$
```cpp
i64 norm_mod(i64 x, i64 mod) {
    x %= mod;
    if (x < 0) x += mod;
    return x;
}
// min_{0 <= i < n} (a * i + b) mod m
i64 min_mod_linear(i64 n, i64 m, i64 a, i64 b) {
    assert(n > 0 && m > 0);
    a = norm_mod(a, m);
    __int128_t bb{ norm_mod(b, m) };
    // ===== 完整覆盖一个周期时可以直接返回 =====
    i64 g{ gcd(a, m) };
    if (n >= m / g) return i64(bb % g);
    i64 ans{ m };
    for (; n; swap(a, m)) {
        a %= m;
        bb %= m;
        if (bb < 0) bb += m;
        ans = min(ans, i64(bb));
        __int128_t y{ __int128_t(n - 1) * a + bb };
        n = i64(y / m);
        bb -= __int128_t(m) * n;
    }
    return ans;
}
// 同时返回 {最小值, 最大值}
pair<i64, i64> mod_extrema_linear(i64 n, i64 m, i64 a, i64 b) {
    assert(n > 0 && m > 0);
    i64 aa{ norm_mod(a, m) }, bb{ norm_mod(b, m) };
    i64 g{ gcd(aa, m) };
    // ===== 已覆盖完整周期 =====
    if (n >= m / g) {
        i64 r{ bb % g };
        return { r, r + m - g };
    }
    i64 mn{ min_mod_linear(n, m, aa, bb) };
    // m - 1 - r_i = (-a * i - b - 1) mod m
    i64 na{ aa ? m - aa : 0 };
    i64 nb{ m - 1 - bb };
    i64 mx{ m - 1 - min_mod_linear(n, m, na, nb) };
    return { mn, mx };
}
```
#### 接口说明
最小值：
```cpp
i64 mn = min_mod_linear(n, m, a, b);
```
返回：
$$
\min_{0\le i<n}(ai+b)\bmod m
$$
同时求最小值与最大值：
```cpp
auto [mn, mx] = mod_extrema_linear(n, m, a, b);
```
要求：
$$
n>0,\quad m>0
$$
`a,b` 可以为负数
#### 周期
令
$$
g=\gcd(a,m)
$$
则：
$$
(ai+b)\bmod m
$$
的周期长度为
$$
\frac m g
$$
一个完整周期中恰好出现所有满足
$$
x\equiv b\pmod g
$$
的模 $m$ 剩余类
因此若
$$
n\ge\frac m g
$$
令
$$
r=b\bmod g
$$
则可以直接得到：
$$
\min=r,\quad \max=r+m-g
$$
这也是板子中的 $O(1)$ 快速出口
#### 最小值递推原理
先规范化：
$$
0\le a,b<m
$$
当前一定要考虑候选值 $b$，随后计算：
$$
n'
=
\left\lfloor
\frac{(n-1)a+b}{m}
\right\rfloor
$$
并将截距变成：
$$
b'=b-mn'
$$
随后交换：
$$
a\leftrightarrow m
$$
新的问题规模与欧几里得算法一致
代码核心因此只有：
```cpp
ans = min(ans, i64(bb));

__int128_t y{ __int128_t(n - 1) * a + bb };
n = i64(y / m);
bb -= __int128_t(m) * n;
swap(a, m);
```
不断交换直到 `n == 0`
#### 最大值为什么可以转成最小值
对于任意：
$$
0\le r<m
$$
有：
$$
m-1-r=(-r-1)\bmod m
$$
于是：
$$
\max r_i
=
m-1-
\min\bigl((-ai-b-1)\bmod m\bigr)
$$
所以最大值不需要再写一套欧几里得递推
#### 常见用法
普通最小模值：
```cpp
i64 ans = min_mod_linear(n, m, a, b);
```
同时求最值：
```cpp
auto [mn, mx] = mod_extrema_linear(n, m, a, b);
```
求区间
$$
L\le i\le R
$$
上的最值，只需要平移下标
令
$$
i=L+j
$$
则：
$$
ai+b=a j+(aL+b)
$$
代码：
```cpp
i64 len = R - L + 1;
__int128_t shift = (__int128_t)a * L + b;
i64 bb = i64(shift % m);
if (bb < 0) bb += m;

auto [mn, mx] = mod_extrema_linear(len, m, a, bb);
```
#### 求最值所在位置
若已经得到最小值 `mn`，要求某个达到最小值的下标，只需解：
$$
ai+b\equiv mn\pmod m
$$
即：
$$
ai\equiv mn-b\pmod m
$$
可以直接交给 8.4 的线性同余：
```cpp
i64 aa = norm_mod(a, m);
i64 bb = norm_mod(b, m);
i64 rhs = norm_mod(mn - bb, m);

auto sol = Congruence::linear(aa, rhs, m);
auto [i, period] = *sol;
```
因为 `mn` 确实来自区间 $0\le i<n$，所以返回的最小非负解必满足：
$$
i<n
$$
最大值位置同理，将 `mn` 换成 `mx`
#### 与 floor_sum 的关系
两者处理的都是线性函数经过整除或取模后的序列，但目标不同：

| 问题 | 形式 | 算法 |
|---|---|---|
| 取整和 | $\sum\lfloor(ai+b)/m\rfloor$ | `floor_sum` |
| 复杂取整路径统计 | 自定义 $U/R$ 状态 | 万能欧几里得 |
| 模最小值 | $\min(ai+b)\bmod m$ | `min_mod_linear` |
| 模最大值 | $\max(ai+b)\bmod m$ | 最小值取补 |
#### 注意事项
`min_mod_linear()` 中的 `%` 每轮都会重新规范化 `bb`，这是因为递归过程中 `bb` 可以变成负数
中间量：
$$
(n-1)a+b
$$
和
$$
mn
$$
的计算使用 `__int128_t`，避免 `i64` 乘法溢出
`min_mod_linear()` 要求 `n > 0`，空区间没有最小值
当
$$
a\equiv0\pmod m
$$
整个序列为常数：
$$
b\bmod m
$$
模板中的完整周期出口会直接处理
如果只需要判断序列中是否出现 $0$，也可以直接解：
$$
ai\equiv-b\pmod m
$$
并检查最小非负解是否小于 $n$，这比先求最小值语义更直接
#### 复杂度
万能欧几里得：
$$
O(\log\max(p,q))
$$
次状态合并
线性模最小值：
$$
O(\log m)
$$
线性模最大值：
$$
O(\log m)
$$
同时求最小值与最大值：
$$
O(\log m)
$$
全部额外空间均为 $O(1)$，万能欧几里得递归版额外递归栈为
$$
O(\log\max(p,q))
$$
