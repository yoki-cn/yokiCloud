### 二次剩余与模平方根
---
**解决问题：** 判断
$$
x^2\equiv a\pmod p
$$
是否有解，并在 $p$ 为质数时求出模平方根；补充勒让德符号、Jacobi 符号以及合数模数下的处理框架
这里主板子用 **Euler 判别 + Tonelli--Shanks**，额外保留 Cipolla 作为可删除替代实现
#### 勒让德符号
---
对于奇质数 $p$，勒让德符号定义为
$$
\left(\frac ap\right)=
\begin{cases}
0 & p\mid a\\
1 & a\not\equiv0\pmod p\text{ 且 }a\text{ 是二次剩余}\\
-1 & a\text{ 是二次非剩余}
\end{cases}
$$
Euler 判别：
$$
\left(\frac ap\right)\equiv a^{(p-1)/2}\pmod p
$$
因此
$$
a^{(p-1)/2}\equiv
\begin{cases}
0 & p\mid a\\
1 & a\text{ 是二次剩余}\\
-1 & a\text{ 是二次非剩余}
\end{cases}
\pmod p
$$
常用结论：
$$
\left(\frac{-1}{p}\right)=(-1)^{(p-1)/2}
\quad,\quad
\left(\frac2p\right)=(-1)^{(p^2-1)/8}
$$
对不同奇质数 $p,q$，二次互反律：
$$
\left(\frac pq\right)
\left(\frac qp\right)
=
(-1)^{(p-1)(q-1)/4}
$$
#### 质数模平方根
---
```cpp
struct ModSqrt {
    static i64 norm(i64 x, i64 mod) {
        x %= mod;
        if (x < 0) x += mod;
        return x;
    }
    static i64 mul(i64 a, i64 b, i64 mod) {
        return i64((__int128_t)norm(a, mod) * norm(b, mod) % mod);
    }
    static i64 add(i64 a, i64 b, i64 mod) {
        return a >= mod - b ? a - (mod - b) : a + b;
    }
    static i64 power(i64 a, u64 b, i64 mod) {
        i64 res{ 1 % mod };
        a = norm(a, mod);
        for (; b; b >>= 1, a = mul(a, a, mod)) {
            if (b & 1) res = mul(res, a, mod);
        }
        return res;
    }
    // ===== 勒让德符号：要求 p 为奇质数 =====
    static int legendre(i64 a, i64 p) {
        assert(p > 2 && (p & 1));
        a = norm(a, p);
        if (!a) return 0;
        return power(a, (p - 1) / 2, p) == 1 ? 1 : -1;
    }
    // ===== Tonelli-Shanks：返回较小的平方根，无解返回 nullopt =====
    static optional<i64> sqrt_prime(i64 a, i64 p) {
        assert(p >= 2);
        a = norm(a, p);
        if (p == 2 || a == 0) return a;
        if (legendre(a, p) < 0) return nullopt;
        // p ≡ 3 (mod 4)
        if (p % 4 == 3) {
            i64 x{ power(a, p / 4 + 1, p) };
            return min(x, p - x);
        }
        // p ≡ 5 (mod 8)
        if (p % 8 == 5) {
            i64 x{ power(a, p / 8 + 1, p) };
            if (mul(x, x, p) != a) x = mul(x, power(2, (p - 1) / 4, p), p);
            return min(x, p - x);
        }
        // p - 1 = q * 2^s，q 为奇数
        i64 q{ p - 1 };
        int s{};
        while (!(q & 1)) q >>= 1, ++ s;
        // 找一个二次非剩余 z
        i64 z{ 2 };
        while (legendre(z, p) != -1) ++ z;
        i64 c{ power(z, q, p) };
        i64 x{ power(a, (q + 1) / 2, p) };
        i64 t{ power(a, q, p) };
        int m{ s };
        while (t != 1) {
            int i{ 1 };
            i64 tt{ mul(t, t, p) };
            while (tt != 1) tt = mul(tt, tt, p), ++ i;
            i64 b{ power(c, u64(1) << (m - i - 1), p) };
            x = mul(x, b, p);
            c = mul(b, b, p);
            t = mul(t, c, p);
            m = i;
        }
        return min(x, p - x);
    }
    // ===== 以下函数可直接删除：返回全部平方根 =====
    static vector<i64> roots_prime(i64 a, i64 p) {
        auto r = sqrt_prime(a, p);
        if (!r) return {};
        i64 x{ *r }, y{ norm(-x, p) };
        if (x == y) return { x };
        if (x > y) swap(x, y);
        return { x, y };
    }
    // ===== 以下函数可直接删除：Jacobi 符号，n 必须为正奇数 =====
    static int jacobi(i64 a, i64 n) {
        assert(n > 0 && (n & 1));
        a = norm(a, n);
        int res{ 1 };
        while (a) {
            while (!(a & 1)) {
                a >>= 1;
                i64 r{ n & 7 };
                if (r == 3 || r == 5) res = -res;
            }
            swap(a, n);
            if ((a & 3) == 3 && (n & 3) == 3) res = -res;
            a %= n;
        }
        return n == 1 ? res : 0;
    }
    // ===== 以下函数可直接删除：Cipolla 替代实现 =====
    static optional<i64> cipolla(i64 a, i64 p) {
        assert(p >= 2);
        a = norm(a, p);
        if (p == 2 || a == 0) return a;
        if (legendre(a, p) < 0) return nullopt;
        static mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
        i64 w, v;
        do {
            w = i64(rng() % u64(p));
            v = norm(mul(w, w, p) - a, p);
        } while (legendre(v, p) != -1);
        struct E { i64 x, y; };
        auto prod = [&](E a, E b) {
            return E{
                add(mul(a.x, b.x, p), mul(mul(a.y, b.y, p), v, p), p),
                add(mul(a.x, b.y, p), mul(a.y, b.x, p), p)
            };
        };
        E res{ 1, 0 }, x{ w, 1 };
        u64 e{ u64(p / 2 + 1) };
        for (; e; e >>= 1, x = prod(x, x)) {
            if (e & 1) res = prod(res, x);
        }
        i64 r{ res.x };
        return min(r, p - r);
    }
};
```
##### 接口说明
判断 $a$ 是否为模奇质数 $p$ 的非零二次剩余：
```cpp
int s = ModSqrt::legendre(a, p);
if (s == 1) {
    // 非零二次剩余
} else if (s == 0) {
    // a ≡ 0 (mod p)
} else {
    // 二次非剩余
}
```
求一个平方根：
```cpp
auto r = ModSqrt::sqrt_prime(a, p);
if (!r) {
    // 无解
} else {
    i64 x = *r;
}
```
返回的 `x` 满足
$$
0\le x\le\frac p2
\quad,\quad
x^2\equiv a\pmod p
$$
求全部平方根：
```cpp
auto roots = ModSqrt::roots_prime(a, p);
```
对于奇质数 $p$：
- `a == 0` 时只有根 $0$
- 非零二次剩余恰有两个根 $x,p-x$
- 二次非剩余没有根
#### 特殊模数的直接公式
---
若
$$
p\equiv3\pmod4
$$
并且 $a$ 为二次剩余，则
$$
x\equiv a^{(p+1)/4}\pmod p
$$
所以这一情况只需要一次快速幂
若
$$
p\equiv5\pmod8
$$
先令
$$
x=a^{(p+3)/8}
$$
如果
$$
x^2\not\equiv a\pmod p
$$
再令
$$
x\leftarrow x\cdot2^{(p-1)/4}\pmod p
$$
真正需要完整 Tonelli--Shanks 的主要是
$$
p\equiv1\pmod8
$$
#### Tonelli--Shanks 原理
---
将
$$
p-1=q2^s
\quad,\quad
q\text{ 为奇数}
$$
选取一个二次非剩余 $z$，令
$$
c=z^q,\quad x=a^{(q+1)/2},\quad t=a^q
$$
维护
$$
x^2\equiv at\pmod p,\quad t^{2^m}\equiv1\pmod p
$$
若 $t\ne1$，找最小的 $i$ 使
$$
t^{2^i}\equiv1\pmod p
$$
再取
$$
b=c^{2^{m-i-1}}
$$
更新
$$
x\leftarrow xb,\quad t\leftarrow tb^2,\quad c\leftarrow b^2,\quad m\leftarrow i
$$
每轮都会严格缩小 $m$，最终得到
$$
t=1,\quad x^2\equiv a\pmod p
$$
#### Cipolla
来源中的实现采用 Cipolla：随机寻找 $w$ 使
$$
v=w^2-a
$$
为二次非剩余，然后在扩域
$$
\mathbb F_p[\sqrt v]
$$
中计算
$$
(w+\sqrt v)^{(p+1)/2}
$$
其虚部最终为 $0$，实部就是一个模平方根
代码中的
```cpp
cipolla(a, p)
```
与 `sqrt_prime()` 接口相同，同样返回较小根
实际板子中通常**二选一即可**
- 更习惯标准群论过程时保留 Tonelli--Shanks
- 想要实现结构固定、随机期望复杂度较好时可以保留 Cipolla
#### Jacobi 符号
---
Jacobi 符号将勒让德符号推广到任意正奇数 $n$
若
$$
n=\prod_i p_i^{e_i}
$$
则
$$
\left(\frac an\right)
=
\prod_i
\left(\frac a{p_i}\right)^{e_i}
$$
调用：
```cpp
int s = ModSqrt::jacobi(a, n);
```
返回 `-1 / 0 / 1`
若 $n$ 是奇质数，则 Jacobi 符号就是勒让德符号
但当 $n$ 为合数时
$$
\left(\frac an\right)=1
$$
**不能推出** $a$ 是模 $n$ 的二次剩余
例如
$$
\left(\frac2{15}\right)=1
$$
但
$$
x^2\equiv2\pmod{15}
$$
无解
因此一般合数模数不能只用 Jacobi 符号判断是否存在平方根
#### 常见用法
##### 判断是否有非零平方根
```cpp
if (a % p && ModSqrt::legendre(a, p) == 1) {
    // 有两个不同根
}
```
##### 求较小根
```cpp
auto r = ModSqrt::sqrt_prime(a, p);
if (r) cout << *r << '\n';
```
##### 输出全部根
```cpp
auto roots = ModSqrt::roots_prime(a, p);
for (i64 x : roots) cout << x << ' ';
```
##### 解二次方程
对于
$$
Ax^2+Bx+C\equiv0\pmod p
$$
且
$$
p\nmid2A
$$
判别式
$$
\Delta=B^2-4AC\pmod p
$$
先求
$$
y^2\equiv\Delta\pmod p
$$
再由
$$
x\equiv\frac{-B\pm y}{2A}\pmod p
$$
得到两个候选根
代码中可直接结合上一节的逆元：
```cpp
i64 delta = ModSqrt::norm(ModSqrt::mul(b, b, p) - ModSqrt::mul(ModSqrt::mul(4, a, p), c, p), p);
auto r = ModSqrt::sqrt_prime(delta, p);
if (r) {
    i64 inv = *inv_mod(2 * a % p, p);
    i64 x1 = ModSqrt::mul(ModSqrt::norm(-b + *r, p), inv, p);
    i64 x2 = ModSqrt::mul(ModSqrt::norm(-b - *r, p), inv, p);
}
```
#### 奇素数幂
---
若模数不是质数，而是
$$
p^e
$$
其中 $p$ 为奇质数，则先处理模 $p$ 的平方根，再用 Hensel 提升
当
$$
p\nmid a
$$
时，模 $p$ 的每个根都会**唯一**提升到模 $p^e$
已知
$$
x^2\equiv a\pmod{p^k}
$$
令
$$
x'=x+t p^k
$$
需要满足
$$
\frac{x^2-a}{p^k}+2xt\equiv0\pmod p
$$
因此
$$
t\equiv
-\frac{x^2-a}{p^k}(2x)^{-1}
\pmod p
$$
因为此时 $p\nmid x$，所以 $2x$ 一定存在模 $p$ 逆元

#### $p\mid a$ 的情况
---
设模数为 $p^e$，$p$ 为奇质数
若
$$
a\equiv0\pmod{p^e}
$$
则全部根满足
$$
x\equiv t p^{\lceil e/2\rceil}
\pmod{p^e}
$$
根的数量为
$$
p^{\lfloor e/2\rfloor}
$$
否则令
$$
v_p(a)=v<e
$$
若 $v$ 为奇数，则无解
若
$$
v=2s
$$
令
$$
a=p^{2s}u,\quad p\nmid u
$$
则需要先解
$$
y^2\equiv u\pmod{p^{e-2s}}
$$
若可解，则根的数量为
$$
2p^s
$$
因此 $p\mid a$ 时不能直接套“每个根唯一 Hensel 提升”的非奇异版本
#### 一般合数模数
---
若
$$
m=\prod_{i=1}^k p_i^{e_i}
$$
求
$$
x^2\equiv a\pmod m
$$
的一般流程：
1. 用 8.2 的整数分解得到全部 $p_i^{e_i}$
2. 分别求每个质数幂模数下的全部平方根
3. 对每种根的组合使用 8.4 的 CRT 合并
例如如果两个互质模数分别有 $r_1,r_2$ 个根，则合并后会有
$$
r_1r_2
$$
个根
所以一般合数模数的答案数量本身就可能很大，不适合把所有情况强行塞进一个短的 `sqrt_mod(m)` 接口
#### $2^e$ 的补充结论
对奇数 $a$：
- 模 $2$ 总有根
- 模 $4$ 有根当且仅当
$$
a\equiv1\pmod4
$$
- 当 $e\ge3$ 时有根当且仅当
$$
a\equiv1\pmod8
$$
且此时有 $4$ 个不同平方根
因此一般合数模平方根中，$2^e$ 需要单独处理，不能直接复用奇素数的 Hensel 公式
#### 注意事项
`sqrt_prime(a,p)` 要求 `p` 为质数，函数本身不做 Miller--Rabin 判定
`legendre(a,p)` 要求 `p` 为奇质数
`jacobi(a,n)` 只要求 `n` 为正奇数，但 Jacobi 符号为 $1$ 不代表合数模下存在平方根
对于奇质数 $p$ 和非零二次剩余 $a$，两个平方根一定为
$$
x\quad,\quad p-x
$$
所以只要求任意一个根时无需继续搜索
板子使用 `__int128_t` 做模乘，可以安全处理 `i64` 范围内的正质数模数
当前 `sqrt_prime()` 返回两个根中较小的那个，因此结果具有稳定性
#### 复杂度
`legendre()`：
$$
O(\log p)
$$
`jacobi()`：
$$
O(\log n)
$$
`p\equiv3\pmod4` 或 `p\equiv5\pmod8` 的快速求根：
$$
O(\log p)
$$
Tonelli--Shanks 在找到二次非剩余后：
$$
O(\log^2p)
$$
额外空间：
$$
O(1)
$$
Cipolla 的随机选取二次非剩余期望尝试常数次，之后扩域快速幂：
$$
O(\log p)
$$
期望额外空间：
$$
O(1)
$$
