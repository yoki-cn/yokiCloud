### 离散对数、乘法阶与原根
---
**解决问题：** 求解
$$
a^x\equiv b\pmod m
$$
求元素 $a$ 在模 $m$ 乘法群中的阶，判断与寻找原根，并利用原根把乘法群问题转成指数上的线性同余
这一节建议保留两个主要代码块：
- `DiscreteLog`：BSGS / exBSGS，自包含，解决离散对数
- `ModGroup`：乘法阶、原根及中等范围试除辅助
下面将接口统一为“返回最小非负解，无解返回 `-1`”，并使用 `__int128_t` 模乘覆盖 `i64` 模数

**只要离散对数就整段复制 `DiscreteLog`；只要阶或原根就复制 `ModGroup`；模数很大时删掉里面的试除辅助，直接接 8.2 的 Pollard--Rho 分解结果**
#### BSGS 与 exBSGS
---
```cpp
struct DiscreteLog {
    struct Hash {
        static u64 splitmix64(u64 x) {
            x += 0x9e3779b97f4a7c15ULL;
            x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
            x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
            return x ^ (x >> 31);
        }
        size_t operator()(u64 x) const {
            static const u64 seed{ u64(chrono::steady_clock::now().time_since_epoch().count()) };
            return splitmix64(x + seed);
        }
    };
    static i64 norm(i64 x, i64 mod) {
        x %= mod;
        if (x < 0) x += mod;
        return x;
    }
    static i64 mul(i64 a, i64 b, i64 mod) {
        return i64((__int128_t)norm(a, mod) * norm(b, mod) % mod);
    }
private:
    // 解 k * a^x ≡ b (mod mod)，要求 gcd(a, mod) = 1
    static i64 bsgs_core(i64 a, i64 b, i64 mod, i64 k) {
        if (mod == 1) return 0;
        a = norm(a, mod), b = norm(b, mod), k = norm(k, mod);
        if (k == b) return 0;
        i64 m{ i64(sqrtl((long double)mod)) };
        while ((__int128_t)m * m < mod) ++ m;
        while (m > 0 && (__int128_t)(m - 1) * (m - 1) >= mod) -- m;
        unordered_map<u64, i64, Hash> mp;
        mp.reserve(size_t(m) * 2 + 3);
        mp.max_load_factor(0.7f);
        i64 cur{ b }, am{ 1 };
        for (i64 j = 0; j < m; ++ j) {
            mp[u64(cur)] = j;
            cur = mul(cur, a, mod);
            am = mul(am, a, mod);
        }
        i64 giant{ k };
        for (i64 i = 1; i <= m + 1; ++ i) {
            giant = mul(giant, am, mod);
            auto it = mp.find(u64(giant));
            if (it != mp.end()) return i * m - it->second;
        }
        return -1;
    }
public:
    // gcd(a, mod) = 1，返回最小非负解，无解返回 -1
    static i64 bsgs(i64 a, i64 b, i64 mod) {
        if (mod <= 0 || gcd(a, mod) != 1) return -1;
        return bsgs_core(a, b, mod, 1);
    }
    // 任意正模数，返回最小非负解，无解返回 -1
    static i64 exbsgs(i64 a, i64 b, i64 mod) {
        if (mod <= 0) return -1;
        if (mod == 1) return 0;
        a = norm(a, mod), b = norm(b, mod);
        if (b == 1) return 0;
        i64 k{ 1 }, add{};
        while (true) {
            i64 g{ gcd(a, mod) };
            if (g == 1) break;
            if (b % g) return -1;
            b /= g, mod /= g, ++ add;
            k = mod == 1 ? 0 : mul(k, a / g, mod);
            if (k == b) return add;
        }
        i64 x{ bsgs_core(a, b, mod, k) };
        return x < 0 ? -1 : x + add;
    }
};
```
##### 接口说明
`bsgs(a,b,mod)` 求最小非负整数 $x$：
$$
a^x\equiv b\pmod{mod}
$$
要求
$$
mod>0,\quad \gcd(a,mod)=1
$$
无解返回 `-1`
```cpp
i64 x = DiscreteLog::bsgs(a, b, mod);
if (x == -1) {
    // 无解
}
```
`exbsgs(a,b,mod)` 不要求 $a$ 与 `mod` 互质：
```cpp
i64 x = DiscreteLog::exbsgs(a, b, mod);
```
实际赛场上如果不确定是否互质，直接调用 `exbsgs()` 即可
##### BSGS 原理
设
$$
M=\lceil\sqrt m\rceil
$$
将指数写成
$$
x=iM-j
$$
则
$$
a^{iM-j}\equiv b\pmod m
$$
等价于
$$
a^{iM}\equiv ba^j\pmod m
$$
先预处理 baby step：
$$
ba^j\quad 0\le j<M
$$
再依次枚举 giant step：
$$
a^{iM}\quad 1\le i\le M
$$
发生碰撞时得到
$$
x=iM-j
$$
代码中同一 baby 值保留**最大的 $j$**：
```cpp
mp[u64(cur)] = j;
```
并按 $i$ 从小到大寻找，因此返回最小非负解
##### exBSGS 原理
当
$$
g=\gcd(a,m)>1
$$
方程
$$
a^x\equiv b\pmod m
$$
若有正指数解，则必须满足
$$
g\mid b
$$
于是可以约去一个 $g$，不断得到更小的方程
维护已经约掉的次数 `add` 与左侧系数 `k`，最终化为
$$
ka^y\equiv b\pmod{m'}
$$
其中
$$
\gcd(a,m')=1
$$
再交给 BSGS，最终
$$
x=y+\text{add}
$$
##### 特殊情况
`exbsgs()` 将 $x=0$ 时
$$
a^0=1
$$
因此：
```cpp
DiscreteLog::exbsgs(a, 1, mod) == 0
```
对于
$$
0^x\equiv0\pmod m\quad m>1
$$
最小非负解为
$$
x=1
$$
模数为 $1$ 时所有整数均同余，返回最小非负解 `0`
##### 常见用法
普通离散对数：
```cpp
i64 x = DiscreteLog::exbsgs(a, b, m);
```
例如
$$
2^x\equiv8\pmod{13}
$$
得到
```cpp
x == 3
```
判断 $b$ 是否属于 $a$ 生成的子群：
```cpp
bool in_group = DiscreteLog::bsgs(a, b, m) != -1;
```
其中要求
$$
\gcd(a,m)=1
$$
##### 注意事项
- BSGS / exBSGS 求的是**指数上的离散对数**，不要与实数上的 `log()` 混淆
- BSGS 的空间也是 $O(\sqrt m)$，所以即使渐进复杂度看起来不错，`m` 接近完整 `i64` 范围时通常仍不可行
- 这里使用随机化整数哈希，避免普通 `unordered_map<i64,...>` 在恶意数据下出现严重冲突
- 如果题目模数只到 $10^9$ 左右，也可以把哈希替换为 `map`，代码更简单但多一个对数
- 若已知指数只可能落在较短区间，优先利用该上界调整 BSGS，而不是机械按 $\sqrt m$ 建表
##### 复杂度
设模数为 $m$
BSGS 期望时间：
$$
O(\sqrt m)
$$
空间：
$$
O(\sqrt m)
$$
exBSGS 前面的 gcd 消去只增加
$$
O(\log m)
$$
因此主复杂度仍为
$$
O(\sqrt m)
$$
#### 乘法阶与原根
---
```cpp
struct ModGroup {
    static i64 norm(i64 x, i64 mod) {
        x %= mod;
        if (x < 0) x += mod;
        return x;
    }
    static i64 mul(i64 a, i64 b, i64 mod) {
        return i64((__int128_t)norm(a, mod) * norm(b, mod) % mod);
    }
    static i64 power(i64 a, i64 b, i64 mod) {
        i64 res{ 1 % mod };
        a = norm(a, mod);
        for (; b; b >>= 1, a = mul(a, a, mod)) {
            if (b & 1) res = mul(res, a, mod);
        }
        return res;
    }
    // ===== 试除辅助：已有 Rho 分解时可直接删除 =====
    static i64 phi_trial(i64 n) {
        i64 ans{ n };
        if (n % 2 == 0) {
            ans /= 2;
            while (n % 2 == 0) n /= 2;
        }
        for (i64 p = 3; p <= n / p; p += 2) if (n % p == 0) {
            ans = ans / p * (p - 1);
            while (n % p == 0) n /= p;
        }
        if (n > 1) ans = ans / n * (n - 1);
        return ans;
    }
    static vector<i64> factor_distinct_trial(i64 n) {
        vector<i64> fac;
        if (n % 2 == 0) {
            fac.push_back(2);
            while (n % 2 == 0) n /= 2;
        }
        for (i64 p = 3; p <= n / p; p += 2) if (n % p == 0) {
            fac.push_back(p);
            while (n % p == 0) n /= p;
        }
        if (n > 1) fac.push_back(n);
        return fac;
    }
    // ===== 乘法阶：phi = phi(mod)，fac_phi 为 phi 的不同质因子 =====
    static i64 order(i64 a, i64 mod, i64 phi, const vector<i64> &fac_phi) {
        if (mod <= 1 || gcd(a, mod) != 1) return -1;
        a = norm(a, mod);
        i64 ord{ phi };
        for (i64 p : fac_phi) {
            while (ord % p == 0 && power(a, ord / p, mod) == 1) ord /= p;
        }
        return ord;
    }
    // ===== 以下函数可直接删除：中等模数下自动试除 =====
    static i64 order_trial(i64 a, i64 mod) {
        if (mod <= 1 || gcd(a, mod) != 1) return -1;
        i64 phi{ phi_trial(mod) };
        return order(a, mod, phi, factor_distinct_trial(phi));
    }
    // 原根存在 iff mod = 2, 4, p^k, 2p^k，p 为奇质数
    static bool has_primitive_root_trial(i64 mod) {
        if (mod == 2 || mod == 4) return true;
        if (mod < 2) return false;
        if (mod % 2 == 0) mod /= 2;
        if (mod % 2 == 0) return false;
        i64 x{ mod }, p{ 3 };
        while (p <= x / p && x % p) p += 2;
        if (p > x / p) return true;
        while (x % p == 0) x /= p;
        return x == 1;
    }
    // ===== 原根：要求 mod 确实存在原根 =====
    static i64 primitive_root(i64 mod, i64 phi, const vector<i64> &fac_phi) {
        for (i64 g = 1; g < mod; ++ g) {
            if (gcd(g, mod) != 1) continue;
            bool ok{ true };
            for (i64 p : fac_phi) if (power(g, phi / p, mod) == 1) {
                ok = false;
                break;
            }
            if (ok) return g;
        }
        return -1;
    }
    // ===== 以下函数可直接删除：中等模数下自动判断并试除 =====
    static i64 primitive_root_trial(i64 mod) {
        if (!has_primitive_root_trial(mod)) return -1;
        i64 phi{ phi_trial(mod) };
        return primitive_root(mod, phi, factor_distinct_trial(phi));
    }
};
```
原根的判定基于检查 $\varphi(m)$ 的质因子：若对每个质因子 $q\mid\varphi(m)$ 都有 $g^{\varphi(m)/q}\not\equiv1$，则 $g$ 的阶达到 $\varphi(m)$
#### 乘法阶
当
$$
\gcd(a,m)=1
$$
定义 $a$ 模 $m$ 的乘法阶为最小正整数 $k$：
$$
a^k\equiv1\pmod m
$$
记作
$$
\operatorname{ord}_m(a)
$$
##### 常用性质
由 Euler 定理：
$$
\operatorname{ord}_m(a)\mid\varphi(m)
$$
因此只要从 $\varphi(m)$ 开始不断尝试除掉质因子即可
若
$$
d=\operatorname{ord}_m(a)
$$
则
$$
a^x\equiv1\pmod m
\iff
d\mid x
$$
还有
$$
\operatorname{ord}_m(a^k)
=
\frac{d}{\gcd(d,k)}
$$
##### 接口
中等范围直接：
```cpp
i64 ord = ModGroup::order_trial(a, mod);
```
要求
$$
mod>1,\quad \gcd(a,mod)=1
$$
不满足时返回 `-1`
若已经知道
$$
\varphi(mod)
$$
及其不同质因子：
```cpp
i64 ord = ModGroup::order(a, mod, phi, fac_phi);
```
其中 `fac_phi` 必须完整包含 $\varphi(mod)$ 的所有不同质因子
##### 原理
初始令
$$
d=\varphi(m)
$$
对于每个质因子 $p\mid d$，只要
$$
a^{d/p}\equiv1\pmod m
$$
就说明真正的阶仍整除 $d/p$，因此：
```cpp
while (ord % p == 0 && power(a, ord / p, mod) == 1) {
    ord /= p;
}
```
最终剩下的就是最小阶
##### 大模数
`order_trial()` 内部使用 $O(\sqrt m)$ 试除，因此主要面向中等范围
若 `mod` 很大，应复用 8.2 的 Pollard--Rho：
1. 分解 `mod` 得到 $\varphi(mod)$
2. 再分解 $\varphi(mod)$ 得到不同质因子
3. 调用 `order(a, mod, phi, fac_phi)`
这样 `ModGroup` 不需要再复制整份 Pollard--Rho
##### 复杂度
已知 $\varphi(m)$ 的不同质因子时，设
$$
\varphi(m)=\prod p_i^{e_i}
$$
需要快速幂次数至多
$$
\sum_i e_i=O(\log m)
$$
每次快速幂为 $O(\log m)$，粗略上界：
$$
O(\log^2m)
$$
`order_trial()` 还需加上试除：
$$
O(\sqrt m)
$$
#### 原根
若
$$
\operatorname{ord}_m(g)=\varphi(m)
$$
则称 $g$ 为模 $m$ 的原根
这意味着
$$
1,g,g^2,\ldots,g^{\varphi(m)-1}
$$
恰好遍历模 $m$ 下所有与 $m$ 互质的剩余类
##### 原根存在条件
对于
$$
m>1
$$
原根存在当且仅当
$$
m=2,\quad4,\quad p^k,\quad2p^k
$$
其中 $p$ 为奇质数，$k\ge1$
因此并不是每个模数都有原根，例如：
$$
8,\quad12,\quad15,\quad16
$$
都没有原根
##### 判定原根
设
$$
\varphi(m)=\prod q_i^{e_i}
$$
在已知模 $m$ 存在原根的前提下，$g$ 为原根当且仅当
$$
\gcd(g,m)=1
$$
且对于所有不同质因子
$$
q_i\mid\varphi(m)
$$
都有
$$
g^{\varphi(m)/q_i}\not\equiv1\pmod m
$$
因此无需真的调用一次完整的 `order()`
##### 接口
中等范围直接：
```cpp
i64 g = ModGroup::primitive_root_trial(mod);
```
若不存在原根返回 `-1`
若已知模数存在原根，并已经分解好 $\varphi(mod)$：
```cpp
i64 g = ModGroup::primitive_root(mod, phi, fac_phi);
```
例如质数 $p$：
```cpp
i64 phi = p - 1;
auto fac = ModGroup::factor_distinct_trial(phi);
i64 g = ModGroup::primitive_root(p, phi, fac);
```
由于质数模一定存在原根，不需要额外调用 `has_primitive_root_trial()`
##### 全部原根
若 $g$ 是模 $m$ 的一个原根，则全部原根恰好为
$$
g^k\pmod m
$$
其中
$$
1\le k\le\varphi(m)\quad,\quad\gcd(k,\varphi(m))=1
$$
所以原根数量为
$$
\varphi(\varphi(m))
$$
通常只需要一个原根，因此不建议默认枚举全部
##### 大质数
若 $p$ 很大但已知为质数，寻找原根只需要分解
$$
p-1
$$
此时不要调用 `primitive_root_trial(p)`，因为它还会用试除法重新判断 $p$ 的结构
更适合：
```cpp
// fac 为通过 Pollard-Rho 得到的 p - 1 的不同质因子
i64 g = ModGroup::primitive_root(p, p - 1, fac);
```
##### 复杂度
已知 $\varphi(m)$ 及其质因子后，每测试一个候选 $g$ 需要
$$
O(\omega(\varphi(m))\log m)
$$
其中 $\omega(n)$ 为不同质因子个数
设第一个原根为 $g$，则搜索总复杂度约为
$$
O(g\,\omega(\varphi(m))\log m)
$$
`primitive_root_trial()` 还包含 $O(\sqrt m)$ 的试除部分
#### 同一小质数下大量离散对数
---
如果模数 $p$ 较小、为质数，而且需要大量查询
$$
g^x\equiv b\pmod p
$$
则找到原根以后可以一次建立完整指数表，而不是每次跑 BSGS
这正是原根模板中 `pw[] / ind[]` 的用途
```cpp
vector<int> primitive_log_table(int p, int g) {
    vector<int> ind(p, -1);
    i64 x{ 1 };
    for (int e = 0; e < p - 1; ++ e) {
        ind[x] = e;
        x = x * g % p;
    }
    return ind;
}
```
##### 常见用法
```cpp
int g = ModGroup::primitive_root_trial(p);
auto ind = primitive_log_table(p, g);
int x = ind[b];
```
对于
$$
1\le b<p
$$
一定有
$$
g^x\equiv b\pmod p
$$
且
$$
0\le x<p-1
$$
##### 复杂度
预处理：
$$
O(p)
$$
空间：
$$
O(p)
$$
之后单次离散对数查询：
$$
O(1)
$$
因此只适合“小模数 + 大量询问”
#### 离散对数与乘法阶的关系
---
若
$$
\gcd(a,m)=1
$$
并设
$$
d=\operatorname{ord}_m(a)
$$
则 $a$ 生成的子群大小恰好是 $d$
若
$$
a^{x_0}\equiv b\pmod m
$$
有解，则所有指数解满足
$$
x\equiv x_0\pmod d
$$
所以 BSGS 返回最小非负 $x_0$ 后，可以用乘法阶描述全部解
特别地，如果 $a$ 是原根：
$$
d=\varphi(m)
$$
#### 用原根把乘法方程变成线性同余
---
这是原根最重要的实际用途之一
以质数模 $p$ 为例，设 $g$ 为原根，则任意非零数都可以唯一写成
$$
a\equiv g^A\pmod p
$$
考虑
$$
x^k\equiv a\pmod p
$$
令
$$
x\equiv g^X\pmod p
$$
则原方程变成
$$
g^{kX}\equiv g^A\pmod p
$$
因此只需要解决指数上的线性同余
$$
kX\equiv A\pmod{p-1}
$$
其中：
```cpp
i64 g = ModGroup::primitive_root_trial(p);
i64 A = DiscreteLog::bsgs(g, a, p);
// 再交给 8.4 的 linear_congruence(k, A, p - 1)
```
设
$$
d=\gcd(k,p-1)
$$
若
$$
d\nmid A
$$
则无非零解
若可解，则模 $p$ 下一共有 $d$ 个不同非零解
下一节的二次剩余
$$
x^2\equiv a\pmod p
$$
就是 $k=2$ 的特殊情况，不过实际求平方根会使用更快、更专门的算法，不会真的跑一次原根 + BSGS
#### 常用结论速查
---
$$
\operatorname{ord}_m(a)
=
\min\{k>0:a^k\equiv1\pmod m\}
$$
$$
\operatorname{ord}_m(a)\mid\varphi(m)
$$
$$
a^x\equiv1\pmod m
\iff
\operatorname{ord}_m(a)\mid x
$$
$$
\operatorname{ord}_m(a^k)
=
\frac{\operatorname{ord}_m(a)}
{\gcd(\operatorname{ord}_m(a),k)}
$$
$$
g\text{ 为原根}
\iff
\operatorname{ord}_m(g)=\varphi(m)
$$
原根存在当且仅当
$$
m=2,\quad4,\quad p^k,\quad2p^k
$$
若 $g$ 为原根，则全部原根为
$$
g^k\quad
\gcd(k,\varphi(m))=1
$$
若 $a^x\equiv b\pmod m$ 有解且 $\gcd(a,m)=1$，则全部指数解为
$$
x\equiv x_0\pmod{\operatorname{ord}_m(a)}
$$
#### 选择方法
---

| 需求                                     | 方法                          |
| -------------------------------------- | --------------------------- |
| $a^x\equiv b\pmod m$ 且已知 $\gcd(a,m)=1$ | `bsgs()`                    |
| $a^x\equiv b\pmod m$，互质性未知             | `exbsgs()`                  |
| 求 $a$ 的最小正周期                           | `order()` / `order_trial()` |
| 求质数模原根                                 | `primitive_root()`          |
| 一般模数判断并求原根                             | `primitive_root_trial()`    |
| 同一小质数下大量离散对数                           | 原根 + 指数表                    |
| 大模数求阶 / 原根                             | 8.2 Pollard--Rho 分解后调用核心接口  |
| $x^k\equiv a\pmod p$                   | 原根 + 离散对数 + 8.4 线性同余        |
| $x^2\equiv a\pmod p$                   | 下一节专门的模平方根算法                |
