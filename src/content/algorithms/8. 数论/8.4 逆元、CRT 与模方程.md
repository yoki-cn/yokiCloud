### 逆元、CRT 与模方程
---
**解决问题：** 求单个或批量模逆元，求解线性同余
$$
ax\equiv b\pmod m
$$
以及同余方程组
$$
x\equiv r_i\pmod{m_i}
$$
这里直接保留**广义 CRT / exCRT**，它本身就包含模数两两互质的普通 CRT，不再另存一份功能重复的代码
#### 模逆元
---
整数 $a$ 在模 $m$ 下存在逆元，当且仅当
$$
\gcd(a,m)=1
$$
此时存在唯一的 $a^{-1}\in[0,m)$ 满足
$$
aa^{-1}\equiv1\pmod m
$$
常见做法是质数模下使用费马小定理，一般模数下使用 exGCD；线性递推则可以 $O(n)$ 求质数模下 $1\ldots n$ 的全部逆元
```cpp
i64 norm_mod(i64 x, i64 mod) {
    x %= mod;
    if (x < 0) x += mod;
    return x;
}
i64 mul_mod(i64 a, i64 b, i64 mod) {
    return i64((__int128_t)norm_mod(a, mod) * norm_mod(b, mod) % mod);
}
i64 qpow_mod(i64 a, u64 b, i64 mod) {
    i64 res{ 1 % mod };
    a = norm_mod(a, mod);
    for (; b; b >>= 1, a = mul_mod(a, a, mod)) {
        if (b & 1) res = mul_mod(res, a, mod);
    }
    return res;
}
array<i64, 3> exgcd(i64 a, i64 b) {
    if (!b) return { a, 1, 0 };
    auto [g, x, y] = exgcd(b, a % b);
    return { g, y, x - a / b * y };
}
// 任意正模数，逆元不存在时返回 nullopt
optional<i64> inv_mod(i64 a, i64 mod) {
    if (mod <= 1) return nullopt;
    a = norm_mod(a, mod);
    auto [g, x, y] = exgcd(a, mod);
    if (g != 1) return nullopt;
    return norm_mod(x, mod);
}
// 质数模，要求 a % p != 0
i64 inv_prime(i64 a, i64 p) {
    return qpow_mod(a, p - 2, p);
}
// 质数模下预处理 1..n 的逆元，要求 1 <= n < p
vector<i64> inverses_prime(int n, i64 p) {
    vector<i64> inv(n + 1);
    inv[1] = 1;
    for (int i = 2; i <= n; ++ i) {
        inv[i] = (__int128_t)(p - p / i) * inv[p % i] % p;
    }
    return inv;
}
```
##### 接口说明
`inv_mod(a, mod)`：一般模数逆元，要求 `mod > 1`
```cpp
auto inv = inv_mod(a, mod);
if (!inv) {
    // gcd(a, mod) != 1
} else {
    i64 x = *inv;
}
```
`inv_prime(a, p)`：要求 $p$ 为质数且 $p\nmid a$
```cpp
i64 x = inv_prime(a, p);
```
`inverses_prime(n,p)`：要求 $p$ 为质数且
$$
1\le n<p
$$
返回 `inv[i] = i^{-1} mod p`
```cpp
auto inv = inverses_prime(n, p);
```
##### 原理
一般模数下由 Bézout
$$
ax+my=1
$$
可知
$$
ax\equiv1\pmod m
$$
所以 exGCD 求出的 $x$ 就是逆元
质数模下由费马小定理
$$
a^{p-1}\equiv1\pmod p
$$
得到
$$
a^{-1}\equiv a^{p-2}\pmod p
$$
线性递推由
$$
p=\left\lfloor\frac pi\right\rfloor i+(p\bmod i)
$$
两边模 $p$：
$$
(p\bmod i)\equiv-\left\lfloor\frac pi\right\rfloor i\pmod p
$$
从而
$$
i^{-1}\equiv-\left\lfloor\frac pi\right\rfloor(p\bmod i)^{-1}\pmod p
$$
即代码中的
$$
\operatorname{inv}[i]
=
\left(p-\left\lfloor\frac pi\right\rfloor\right)
\operatorname{inv}[p\bmod i]\bmod p
$$
##### 常见用法
除法转乘逆元：
```cpp
auto ib = inv_mod(b, mod);
if (ib) {
    i64 ans = mul_mod(a, *ib, mod);
}
```
质数模：
```cpp
i64 ans = mul_mod(a, inv_prime(b, mod), mod);
```
一次预处理后大量查询：
```cpp
auto inv = inverses_prime(n, mod);
i64 x = inv[k];
```
##### 注意事项
模除法
$$
\frac ab\bmod m
$$
只有在
$$
\gcd(b,m)=1
$$
时才能直接写成
$$
ab^{-1}\bmod m
$$
`inv_prime()` 不能因为代码更短就用于合数模
`inverses_prime()` 的递推版主要保留给质数模且 `n < p` 的场景
阶乘逆元属于组合数模块，不在这里重复保存
##### 复杂度
`inv_mod()`：
$$
O(\log m)
$$
`inv_prime()`：
$$
O(\log p)
$$
`inverses_prime()`：
$$
O(n)
$$
#### 任意数组批量逆元
---
若给定
$$
a_1,a_2,\ldots,a_n
$$
且每个数在模 $m$ 下都有逆元，可以只调用**一次**逆元算法求出全部 $a_i^{-1}$
```cpp
optional<vector<i64>> batch_inverse(const vector<i64> &a, i64 mod) {
    if (mod <= 1) return nullopt;
    int n{ int(a.size()) };
    vector<i64> x(n), pre(n + 1, 1), inv(n);
    for (int i = 0; i < n; ++ i) {
        x[i] = norm_mod(a[i], mod);
        pre[i + 1] = mul_mod(pre[i], x[i], mod);
    }
    auto suf = inv_mod(pre[n], mod);
    if (!suf) return nullopt;
    i64 cur{ *suf };
    for (int i = n - 1; i >= 0; -- i) {
        inv[i] = mul_mod(pre[i], cur, mod);
        cur = mul_mod(cur, x[i], mod);
    }
    return inv;
}
```
##### 原理
记
$$
P_i=\prod_{j=0}^{i-1}a_j
$$
先求
$$
P_n^{-1}
$$
再从右向左维护后缀乘积的逆元
对于第 $i$ 个数：
$$
a_i^{-1}
=
P_i
\left(\prod_{j=i}^n a_j\right)^{-1}
$$
因此只需要一次 `inv_mod()`
##### 常见用法
```cpp
auto inv = batch_inverse(a, mod);
if (!inv) {
    // 至少一个 a[i] 与 mod 不互质
} else {
    // (*inv)[i] = a[i]^{-1} mod mod
}
```
##### 注意事项
要求每个
$$
\gcd(a_i,m)=1
$$
否则总乘积也没有逆元，函数返回 `nullopt`
空数组合法，返回空数组
这个版本适用于合数模，只要每个元素都与模数互质
##### 复杂度
只有一次 exGCD，其余为线性扫描：
$$
O(n+\log m)
$$
空间：
$$
O(n)
$$
#### CRT 与 exCRT
---
普通 CRT 要求模数两两互质，exCRT 则逐个合并两个同余方程，因此**不要求模数互质**
以下模块完全自包含，同时提供单个线性同余、两个同余合并、CRT 与一般线性模方程组
```cpp
struct Congruence {
    static i64 norm(i64 x, i64 mod) {
        x %= mod;
        if (x < 0) x += mod;
        return x;
    }
    static array<i64, 3> exgcd(i64 a, i64 b) {
        if (!b) return { a, 1, 0 };
        auto [g, x, y] = exgcd(b, a % b);
        return { g, y, x - a / b * y };
    }
    static i64 mul(i64 a, i64 b, i64 mod) {
        return i64((__int128_t)norm(a, mod) * norm(b, mod) % mod);
    }
    // ===== 单个线性同余 ax ≡ b (mod m) =====
    // 返回 {最小非负解, 解的周期}
    static optional<pair<i64, i64>> linear(i64 a, i64 b, i64 mod) {
        if (mod <= 0) return nullopt;
        a = norm(a, mod), b = norm(b, mod);
        auto [g, x, y] = exgcd(a, mod);
        if (b % g) return nullopt;
        i64 m{ mod / g };
        i64 r{ m == 1 ? 0 : mul(x, b / g, m) };
        return pair{ r, m };
    }
    // ===== 合并 x ≡ r1 (mod m1), x ≡ r2 (mod m2) =====
    static optional<pair<i64, i64>> merge(i64 r1, i64 m1, i64 r2, i64 m2) {
        if (m1 <= 0 || m2 <= 0) return nullopt;
        r1 = norm(r1, m1), r2 = norm(r2, m2);
        auto [g, x, y] = exgcd(m1, m2);
        i64 d{ r2 - r1 };
        if (d % g) return nullopt;
        i64 m{ m2 / g };
        i64 t{ m == 1 ? 0 : mul(x, d / g, m) };
        __int128_t lcm{ (__int128_t)(m1 / g) * m2 };
        if (lcm > numeric_limits<i64>::max()) return nullopt;
        __int128_t ans{ (__int128_t)r1 + (__int128_t)m1 * t };
        i64 mod{ i64(lcm) };
        i64 r{ i64(ans % mod) };
        if (r < 0) r += mod;
        return pair{ r, mod };
    }
    // ===== CRT / exCRT：eq[i] = {ri, mi} =====
    static optional<pair<i64, i64>> crt(const vector<pair<i64, i64>> &eq) {
        pair<i64, i64> cur{ 0, 1 };
        for (auto [r, m] : eq) {
            auto nxt = merge(cur.first, cur.second, r, m);
            if (!nxt) return nullopt;
            cur = *nxt;
        }
        return cur;
    }
    // ===== 一般线性模方程组：eq[i] = {ai, bi, mi} =====
    // ai * x ≡ bi (mod mi)
    static optional<pair<i64, i64>> solve(const vector<array<i64, 3>> &eq) {
        pair<i64, i64> cur{ 0, 1 };
        for (auto [a, b, m] : eq) {
            auto one = linear(a, b, m);
            if (!one) return nullopt;
            auto nxt = merge(cur.first, cur.second, one->first, one->second);
            if (!nxt) return nullopt;
            cur = *nxt;
        }
        return cur;
    }
};
```
#### 单个线性同余
---
`linear(a,b,m)` 求
$$
ax\equiv b\pmod m
$$
设
$$
g=\gcd(a,m)
$$
有解当且仅当
$$
g\mid b
$$
若有解，返回 `{r, mod}`，表示
$$
x\equiv r\pmod{\frac m g}
$$
其中
$$
0\le r<\frac m g
$$
这与 8.1 中的线性同余接口一致，但这里重新带了一份短实现，使整个 CRT / 模方程模块可以独立复制
##### 常见用法
```cpp
auto sol = Congruence::linear(a, b, m);
if (sol) {
    auto [x, period] = *sol;
}
```
##### 复杂度
$$
O(\log m)
$$
#### 两个同余方程合并
---
求
$$
x\equiv r_1\pmod{m_1}
$$
$$
x\equiv r_2\pmod{m_2}
$$
令
$$
x=r_1+m_1t
$$
代入第二式：
$$
m_1t\equiv r_2-r_1\pmod{m_2}
$$
因此有解当且仅当
$$
\gcd(m_1,m_2)\mid(r_2-r_1)
$$
若有解，所有解构成一个新的同余类
$$
x\equiv r\pmod{\operatorname{lcm}(m_1,m_2)}
$$
##### 常见用法
```cpp
auto sol = Congruence::merge(r1, m1, r2, m2);
if (sol) {
    auto [r, mod] = *sol;
}
```
##### 注意事项
要求
$$
m_1>0\quad,\quad m_2>0
$$
板子内部使用 `__int128_t` 防止中间乘法溢出
最终周期仍保存为 `i64`，因此要求最终
$$
\operatorname{lcm}(m_1,m_2)\le2^{63}-1
$$
如果超过 `i64`，当前实现返回 `nullopt`
##### 复杂度
一次 exGCD：
$$
O(\log\min(m_1,m_2))
$$
#### CRT / exCRT 方程组
---
对于
$$
x\equiv r_i\pmod{m_i}
$$
输入：
```cpp
vector<pair<i64, i64>> eq{
    {r1, m1},
    {r2, m2},
    {r3, m3}
};
auto sol = Congruence::crt(eq);
```
若有解：
```cpp
auto [r, mod] = *sol;
```
表示全部整数解
$$
x\equiv r\pmod{mod}
$$
其中
$$
0\le r<mod
$$
模数无需互质
若模数两两互质，则退化成普通 CRT，此时
$$
mod=\prod_i m_i
$$
普通 CRT 的闭式形式为：令
$$
M=\prod_i m_i\quad,\quad M_i=\frac M{m_i}
$$
再令
$$
t_i\equiv M_i^{-1}\pmod{m_i}
$$
则
$$
x\equiv\sum_i r_iM_it_i\pmod M
$$
实际代码仍建议使用上面的逐个合并版，因为同一份实现可以同时覆盖普通 CRT 与 exCRT
##### 空方程组
```cpp
Congruence::crt({})
```
返回
```cpp
{0, 1}
```
表示
$$
x\equiv0\pmod1
$$
即任意整数
##### 复杂度
设有 $k$ 个方程，当前合并模数为 $M_i$
$$
O\left(\sum_{i=1}^k\log\min(M_i,m_i)\right)
$$
通常简记为
$$
O(k\log M)
$$
#### 一般线性模方程组
---
进一步求
$$
a_ix\equiv b_i\pmod{m_i}
$$
每个方程先化成
$$
x\equiv r_i\pmod{m_i'}
$$
再用 exCRT 合并
这个过程已经封装在 `solve()`
##### 常见用法
```cpp
vector<array<i64, 3>> eq{
    {a1, b1, m1},
    {a2, b2, m2},
    {a3, b3, m3}
};
auto sol = Congruence::solve(eq);
if (!sol) {
    // 无解
} else {
    auto [x, period] = *sol;
    // x ≡ x0 (mod period)
}
```
例如
$$
2x\equiv4\pmod6
$$
先化为
$$
x\equiv2\pmod3
$$
再与其他方程合并即可
##### 注意事项
每个 `m_i` 必须为正
若某一个线性同余无解，整个方程组无解
若两个已经化简的同余类不兼容，整个方程组也无解
最终周期要求能放入 `i64`
指数方程
$$
a^x\equiv b\pmod m
$$
不属于这里，放到后面的 BSGS / exBSGS
平方同余
$$
x^2\equiv a\pmod p
$$
也不属于这里，放到二次剩余与模平方根
#### CRT 与线性同余关系速查
---

| 问题 | 条件 | 返回形式 |
|---|---|---|
| $a^{-1}\bmod m$ | $\gcd(a,m)=1$ | 一个余数 |
| $ax\equiv b\pmod m$ | $\gcd(a,m)\mid b$ | $x\equiv r\pmod{m/g}$ |
| 两个同余合并 | $r_1\equiv r_2\pmod{\gcd(m_1,m_2)}$ | $x\equiv r\pmod{\operatorname{lcm}(m_1,m_2)}$ |
| 多个同余方程 | 逐个合并均可行 | `crt()` |
| 多个线性模方程 | 每个可解且化简后可合并 | `solve()` |
