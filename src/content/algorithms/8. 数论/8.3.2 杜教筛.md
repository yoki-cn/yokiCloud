### 杜教筛
**解决问题：** 已知积性函数 $f$，在 $n$ 很大、无法线性筛到 $n$ 时，利用狄利克雷卷积与数论分块求前缀和
$$
S_f(n)=\sum_{i=1}^n f(i)
$$
典型应用是
$$
M(n)=\sum_{i=1}^n\mu(i),\quad \Phi(n)=\sum_{i=1}^n\varphi(i)
$$

下面给出最常用的 $\mu/\varphi$ 自包含版本，内部直接带线性筛，复制这一块即可使用
```cpp
struct Dujiao {
    int limit;
    vector<i64> pre_mu, pre_phi;
    unordered_map<i64, i64> memo_mu;
    unordered_map<i64, __int128_t> memo_phi;
    explicit Dujiao(int n) : limit(n) {
        assert(n >= 1);
        vector<int> minp(n + 1), primes;
        vector<i64> mu(n + 1), phi(n + 1);
        mu[1] = phi[1] = 1;
        for (int i = 2; i <= n; ++ i) {
            if (!minp[i]) {
                minp[i] = i;
                primes.push_back(i);
                mu[i] = -1;
                phi[i] = i - 1;
            }
            for (int p : primes) {
                if (p > n / i) break;
                int v{ i * p };
                minp[v] = p;
                if (p == minp[i]) {
                    mu[v] = 0;
                    phi[v] = phi[i] * p;
                    break;
                }
                mu[v] = -mu[i];
                phi[v] = phi[i] * (p - 1);
            }
        }
        for (int i = 1; i <= n; ++ i) {
            mu[i] += mu[i - 1];
            phi[i] += phi[i - 1];
        }
        pre_mu = move(mu);
        pre_phi = move(phi);
    }
    // ===== Mertens 函数 =====
    i64 sum_mu(i64 n) {
        if (n <= limit) return pre_mu[n];
        if (auto it = memo_mu.find(n); it != memo_mu.end()) return it->second;
        __int128_t ans{ 1 };
        for (i64 l = 2, r; l <= n; l = r + 1) {
            i64 q{ n / l };
            r = n / q;
            ans -= (__int128_t)(r - l + 1) * sum_mu(q);
        }
        return memo_mu[n] = i64(ans);
    }

    // ===== phi 前缀和 =====
    __int128_t sum_phi(i64 n) {
        if (n <= limit) return pre_phi[n];
        if (auto it = memo_phi.find(n); it != memo_phi.end()) return it->second;
        __int128_t ans{ (__int128_t)n * (n + 1) / 2 };
        for (i64 l = 2, r; l <= n; l = r + 1) {
            i64 q{ n / l };
            r = n / q;
            ans -= (__int128_t)(r - l + 1) * sum_phi(q);
        }
        return memo_phi[n] = ans;
    }
};
```
 采用 `sumMu(n)` 的经典递归形式，同时将 $\varphi$ 前缀和补成对称接口，并避免把 `mu` 的点值和前缀值混在外部接口里
#### 接口说明
- `Dujiao(limit)`：线性预处理 $1\ldots limit$ 的 $\mu,\varphi$ 前缀和
- `sum_mu(n)`：返回 Mertens 函数
$$
M(n)=\sum_{i=1}^n\mu(i)
$$
- `sum_phi(n)`：返回欧拉函数前缀和
$$
\Phi(n)=\sum_{i=1}^n\varphi(i)
$$
- `memo_mu / memo_phi`：缓存大于 `limit` 的递归状态，多次查询会自动复用
- 支持 `n = 0`，此时两个前缀和均为 $0$
`sum_phi()` 返回 `__int128_t`，因为
$$
\Phi(n)=\Theta(n^2)
$$
即使 `n` 能放入 `i64`，答案也可能超过 `i64`
#### 核心原理
设
$$
h=f*g
$$
并定义
$$
S(n)=\sum_{i=1}^n f(i),\quad G(n)=\sum_{i=1}^n g(i),\quad H(n)=\sum_{i=1}^n h(i)
$$
由狄利克雷卷积
$$
h(n)=\sum_{d\mid n}f(d)g(n/d)
$$
交换求和顺序可得
$$
H(n)=\sum_{t=1}^n g(t)S\left(\left\lfloor\frac nt\right\rfloor\right)
$$
于是
$$
g(1)S(n)
=
H(n)
-
\sum_{t=2}^n
g(t)S\left(\left\lfloor\frac nt\right\rfloor\right)
$$
若 $g(1)=1$，对 $\lfloor n/t\rfloor$ 数论分块，设当前块为 $[l,r]$
$$
S(n)
=
H(n)
-
\sum_{[l,r]}
\bigl(G(r)-G(l-1)\bigr)
S\left(\left\lfloor\frac nl\right\rfloor\right)
$$
因此杜教筛能使用的关键条件是：$f*g$ 的前缀和容易计算，$g$ 的区间和容易计算，再用数论分块把递归压缩下来，这也是通用杜教筛的标准形式
#### Möbius 前缀和
取
$$
f=\mu,\quad g=\mathbf1
$$
由于
$$
\mu*\mathbf1=\varepsilon
$$
并且
$$
\sum_{i=1}^n\varepsilon(i)=1,\quad \sum_{i=1}^n\mathbf1(i)=n
$$
得到
$$
M(n)
=
1-
\sum_{i=2}^n
M\left(\left\lfloor\frac ni\right\rfloor\right)
$$
数论分块后
$$
M(n)
=
1-
\sum_{[l,r]}
(r-l+1)
M\left(\left\lfloor\frac nl\right\rfloor\right)
$$
对应代码核心就是
```cpp
__int128_t ans{ 1 };
for (i64 l = 2, r; l <= n; l = r + 1) {
    i64 q{ n / l };
    r = n / q;
    ans -= (__int128_t)(r - l + 1) * sum_mu(q);
}
```
#### 欧拉函数前缀和
取
$$
f=\varphi,\quad g=\mathbf1
$$
由于
$$
\varphi*\mathbf1=\operatorname{id}
$$
并且
$$
\sum_{i=1}^n i=\frac{n(n+1)}2
$$
得到
$$
\Phi(n)
=
\frac{n(n+1)}2
-
\sum_{i=2}^n
\Phi\left(\left\lfloor\frac ni\right\rfloor\right)
$$
数论分块后
$$
\Phi(n)
=
\frac{n(n+1)}2
-
\sum_{[l,r]}
(r-l+1)
\Phi\left(\left\lfloor\frac nl\right\rfloor\right)
$$
因此 $\mu$ 与 $\varphi$ 两个版本实际上只有初始项不同
```cpp
// mu
__int128_t ans{ 1 };
// phi
__int128_t ans{ (__int128_t)n * (n + 1) / 2 };
```
#### 常见用法
求
$$
\sum_{i=1}^n\mu(i)
$$
```cpp
Dujiao dujiao(2'000'000);
i64 ans = dujiao.sum_mu(n);
```
求
$$
\sum_{i=1}^n\varphi(i)
$$
```cpp
Dujiao dujiao(2'000'000);
__int128_t ans = dujiao.sum_phi(n);
```
同时需要二者时只构造一次
```cpp
Dujiao dujiao(2'000'000);
i64 smu = dujiao.sum_mu(n);
__int128_t sphi = dujiao.sum_phi(n);
```
多次询问可以继续复用同一个对象
```cpp
Dujiao dujiao(limit);
while (q --) {
    i64 n;
    cin >> n;
    auto ans = dujiao.sum_mu(n);
}
```
已经线性筛到 `limit` 的查询不会进入递归
```cpp
dujiao.sum_mu(x);   // x <= limit 时直接 O(1)
dujiao.sum_phi(x);  // x <= limit 时直接 O(1)
```
#### 预处理大小
设最大查询值为 $N$，经典复杂度分析中通常预处理约
$$
B\approx N^{2/3}
$$
个小值，此时杜教筛可做到单次约
$$
O(N^{2/3})
$$
实际比赛中不必机械计算 $N^{2/3}$，通常根据内存直接取一个合适的 `limit`，例如
```cpp
Dujiao dujiao(1'000'000);
Dujiao dujiao(2'000'000);
Dujiao dujiao(5'000'000);
```
`limit` 越大，线性筛占用越多，但递归和哈希状态越少
ECNU 模板同样采用“小范围线性预处理 + 大范围递归缓存”的结构，并指出在经典 $N^{2/3}$ 预处理下可得到 $O(N^{2/3})$ 复杂度

#### 为什么必须记忆化
递归中只会反复访问形如
$$
\left\lfloor\frac Ni\right\rfloor
$$
的状态
若不缓存，同一个状态会被大量重复计算
```cpp
if (auto it = memo_mu.find(n); it != memo_mu.end()) return it->second;
```
对于一次最大查询 $N$，大于 `limit` 的有效商值数量约为
$$
O\left(\frac N{\text{limit}}\right)
$$
所以缓存远小于直接保存 $1\ldots N$ 的所有值
#### 通用杜教筛改法
遇到其他积性函数 $f$ 时，不需要另写算法，按下面三步替换即可
1. 选择容易处理的 $g$，最好满足 $g(1)=1$
2. 求出
$$
H(n)=\sum_{i=1}^n(f*g)(i)
$$
和
$$
G(n)=\sum_{i=1}^n g(i)
$$
3. 将递归改为
```cpp
T ans = H(n);
for (i64 l = 2, r; l <= n; l = r + 1) {
    i64 q{ n / l };
    r = n / q;
    ans -= (G(r) - G(l - 1)) * solve(q);
}
```
对应数学式
$$
S_f(n)
=
H(n)
-
\sum_{[l,r]}
\bigl(G(r)-G(l-1)\bigr)
S_f\left(\left\lfloor\frac nl\right\rfloor\right)
$$
若找不到一个使 $H(n)$、$G(n)$ 都容易求的 $g$，杜教筛通常就不是合适的方法
#### 注意事项
`sum_mu()` 中虽然最终结果一定落在 `i64` 范围内，递推的中间乘积仍使用 `__int128_t`，不要提前改回 `i64`
`sum_phi()` 的初值必须先扩大类型
```cpp
(__int128_t)n * (n + 1) / 2
```
不能写成
```cpp
n * (n + 1) / 2
```
否则乘法会先在 `i64` 中溢出
若只需要 $\mu$，可以删除 `pre_phi`、`memo_phi`、`sum_phi()` 以及线性筛中的 `phi` 转移
若只需要 $\varphi$，可以删除 `pre_mu`、`memo_mu`、`sum_mu()` 以及线性筛中的 `mu` 转移
若答案要求取模，可以把递推值改成模整数，但三角和最好先做整数除法
$$
\frac{n(n+1)}2\bmod P
$$
不需要假设 $2$ 在模 $P$ 下存在逆元
`unordered_map` 中保存的是函数前缀和而不是单点 $\mu(n),\varphi(n)$
杜教筛解决的是**前缀和**，若只要求单点函数值，应继续使用 8.2 的质因数分解或 8.3 的线性筛
#### 复杂度
设最大查询为 $N$，预处理上界为 $B$
线性筛时间与空间
$$
O(B)
$$
经典取
$$
B=\Theta(N^{2/3})
$$
时，单次杜教筛时间
$$
O(N^{2/3})
$$
空间由线性筛占主导
$$
O(N^{2/3})
$$
