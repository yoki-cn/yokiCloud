### floor_sum 与欧几里得类算法
---
**解决问题：** 快速计算线性取整和
$$
\sum_{i=0}^{n-1}\left\lfloor\frac{ai+b}{m}\right\rfloor
$$
以及进一步计算
$$
\sum_{i=0}^{n-1}i\left\lfloor\frac{ai+b}{m}\right\rfloor,\quad \sum_{i=0}^{n-1}\left\lfloor\frac{ai+b}{m}\right\rfloor^2
$$
核心过程与欧几里得算法相同：先提出整除部分，再交换分子斜率与分母继续递归，因此复杂度为对数级
#### floor_sum
---
下面统一使用数学意义的 `floor`，因此允许 `a,b` 为负数，并使用 `__int128_t` 保存中间结果和答案
```cpp
__int128_t floor_sum(__int128_t n, __int128_t m, __int128_t a, __int128_t b) {
    assert(n >= 0 && m > 0);
    // 先把 a、b 规范到 [0, m)，同时提出整数部分
    __int128_t qa{ a / m }, ra{ a % m };
    if (ra < 0) -- qa, ra += m;
    __int128_t qb{ b / m }, rb{ b % m };
    if (rb < 0) -- qb, rb += m;
    __int128_t ans{ n * (n - 1) / 2 * qa + n * qb };
    a = ra, b = rb;
    for (;;) {
        if (a >= m) ans += n * (n - 1) / 2 * (a / m), a %= m;
        if (b >= m) ans += n * (b / m), b %= m;
        __int128_t y{ a * n + b };
        if (y < m) break;
        n = y / m;
        b = y % m;
        swap(m, a);
    }
    return ans;
}
```
##### 接口说明
```cpp
auto ans = floor_sum(n, m, a, b);
```
返回
$$
\sum_{i=0}^{n-1}\left\lfloor\frac{ai+b}{m}\right\rfloor
$$
要求
$$
n\ge0,\quad m>0
$$
`a,b` 可以为任意有符号整数
原始常见模板通常要求
$$
0\le a,b<m
$$
或使用无符号数，这里额外做了负数规范化，避免 C++ 的整数除法向 $0$ 截断与数学 `floor` 不一致
##### 原理
首先将
$$
a=q_am+r_a,\quad 0\le r_a<m
$$
$$
b=q_bm+r_b,\quad 0\le r_b<m
$$
则
$$
\left\lfloor\frac{ai+b}{m}\right\rfloor
=
q_ai+q_b+
\left\lfloor\frac{r_ai+r_b}{m}\right\rfloor
$$
因此整数部分贡献为
$$
q_a\frac{n(n-1)}2+q_bn
$$
接下来只需考虑
$$
0\le a,b<m
$$
令
$$
y=an+b
$$
若
$$
y<m
$$
则所有项均为 $0$
否则通过格点区域转置，可将剩余问题转化为参数
$$
n'=\left\lfloor\frac{an+b}{m}\right\rfloor
$$
并交换
$$
a\leftrightarrow m
$$
继续处理
参数变化与欧几里得算法一致，因此只会进行 $O(\log m)$ 轮
##### 常见用法
区间
$$
L\le i\le R
$$
上的取整和：
```cpp
auto ans = floor_sum((__int128_t)R - L + 1, m, a, (__int128_t)a * L + b);
```
因为令
$$
i=L+j
$$
即可得到
$$
\sum_{i=L}^R\left\lfloor\frac{ai+b}{m}\right\rfloor
=
\operatorname{floor\_sum}
\left(R-L+1,m,a,aL+b\right)
$$
若求
$$
\sum_{i=0}^{n-1}\left\lceil\frac{ai+b}{m}\right\rceil
$$
利用
$$
\lceil x\rceil=-\lfloor-x\rfloor
$$
直接：
```cpp
auto ans = -floor_sum(n, m, -a, -b);
```
若题目使用下标 $0\ldots N$：
```cpp
auto ans = floor_sum((__int128_t)N + 1, m, a, b);
```
##### 注意事项
这里的 `n` 表示**项数**，下标范围固定为
$$
0\le i<n
$$
不是 $0\le i\le n$
答案可能远大于 `i64`，因此返回 `__int128_t`
如果题目保证结果在 `i64` 内，可以在调用后转换：
```cpp
i64 ans = i64(floor_sum(n, m, a, b));
```
不要把普通 C++ 表达式
```cpp
(a * i + b) / m
```
直接当作数学 floor 使用，若分子为负数，两者可能不同
##### 复杂度
时间：
$$
O(\log m+\log(|a|+1))
$$
通常简记为
$$
O(\log\max(|a|,m))
$$
额外空间：
$$
O(1)
$$
#### 类欧几里得三类和
---
有些题目不只需要普通 `floor_sum`，还会出现
$$
f=\sum_{i=0}^{n-1}y_i,\quad g=\sum_{i=0}^{n-1}iy_i,\quad h=\sum_{i=0}^{n-1}y_i^2
$$
其中
$$
y_i=\left\lfloor\frac{ai+b}{m}\right\rfloor
$$
传统类欧几里得正是同时维护这三个量  
下面将常见的 $0\ldots N$ 递推统一改成与 `floor_sum` 一致的 $[0,n)$ 接口
```cpp
struct FloorSums {
    __int128_t f{}, g{}, h{};
};
// 0 <= a, b < c，计算 i = 0..n
FloorSums floor_sums_nonneg(__int128_t a, __int128_t b, __int128_t c, __int128_t n) {
    if (n < 0) return {};
    // ===== 提取整数部分 =====
    if (a >= c || b >= c) {
        __int128_t A{ a / c }, B{ b / c };
        auto t = floor_sums_nonneg(a % c, b % c, c, n);
        __int128_t s1{ n * (n + 1) / 2 }, s2{ n * (n + 1) * (2 * n + 1) / 6 }, cnt{ n + 1 };
        return { t.f + A * s1 + B * cnt, t.g + A * s2 + B * s1,
            t.h + A * A * s2 + B * B * cnt + 2 * A * B * s1 + 2 * A * t.g + 2 * B * t.f
        };
    }

    // ===== 交换坐标轴，进入下一层欧几里得递归 =====
    __int128_t k{ (a * n + b) / c };
    if (!k) return {};
    auto t = floor_sums_nonneg(c, c - b - 1, a, k - 1);
    __int128_t f{ n * k - t.f }, g{ (n * (n + 1) * k - t.f - t.h) / 2 };
    __int128_t h{ n * k * (k + 1) - 2 * t.g - 2 * t.f - f };
    return { f, g, h };
}
// ===== 对外接口：n 项，允许 a、b 为负 =====
FloorSums floor_sums(__int128_t n, __int128_t m, __int128_t a, __int128_t b) {
    assert(n >= 0 && m > 0);
    if (!n) return {};
    __int128_t A{ a / m }, aa{ a % m };
    if (aa < 0) -- A, aa += m;
    __int128_t B{ b / m }, bb{ b % m };
    if (bb < 0) -- B, bb += m;
    auto t = floor_sums_nonneg(aa, bb, m, n - 1);
    __int128_t s1{ n * (n - 1) / 2 }, s2{ n * (n - 1) * (2 * n - 1) / 6 };
    __int128_t f{ t.f }, g{ t.g };
    t.h += A * A * s2 + B * B * n + 2 * A * B * s1 + 2 * A * g + 2 * B * f;
    t.g += A * s2 + B * s1;
    t.f += A * s1 + B * n;
    return t;
}
```
##### 接口说明
```cpp
auto [f, g, h] = floor_sums(n, m, a, b);
```
令
$$
y_i=\left\lfloor\frac{ai+b}{m}\right\rfloor,\quad 0\le i<n
$$
返回：
$$
f=\sum_{i=0}^{n-1}y_i
$$
$$
g=\sum_{i=0}^{n-1}iy_i
$$
$$
h=\sum_{i=0}^{n-1}y_i^2
$$
其中
$$
n\ge0,\quad m>0
$$
`a,b` 可以为负数
##### 提取整数部分
写成
$$
a=Am+a',\quad b=Bm+b'
$$
则
$$
y_i=Ai+B+z_i
$$
其中
$$
z_i=\left\lfloor\frac{a'i+b'}m\right\rfloor
$$
于是
$$
f=f'+A\sum i+B\sum1
$$
$$
g=g'+A\sum i^2+B\sum i
$$
$$
h=h'+A^2\sum i^2+B^2\sum1+2AB\sum i+2Ag'+2Bf'
$$
需要的基础和为
$$
\sum_{i=0}^{n-1}i=\frac{n(n-1)}2,\quad \sum_{i=0}^{n-1}i^2=\frac{n(n-1)(2n-1)}6
$$
##### 互换递推
规范化到
$$
0\le a,b<c
$$
后，定义
$$
k=\left\lfloor\frac{an+b}{c}\right\rfloor
$$
传统类欧几里得通过交换坐标轴，把问题转换为参数
$$
(c,c-b-1,a,k-1)
$$
##### 常见用法
只需要
$$
\sum\left\lfloor\frac{ai+b}{m}\right\rfloor
$$
时优先使用前面的 `floor_sum()`，代码更短、常数更小
若同时需要：
```cpp
auto s = floor_sums(n, m, a, b);
auto sum_floor = s.f;
auto sum_i_floor = s.g;
auto sum_floor_sq = s.h;
```
例如要求
$$
\sum_{i=0}^{n-1}
\left(
u i+v
\right)
\left\lfloor\frac{ai+b}{m}\right\rfloor
$$
直接利用
$$
u g+v f
$$
代码：
```cpp
auto s = floor_sums(n, m, a, b);
__int128_t ans = (__int128_t)u * s.g + (__int128_t)v * s.f;
```
若要求
$$
\sum
\left(
\left\lfloor\frac{ai+b}{m}\right\rfloor+c
\right)^2
$$
则：
```cpp
auto s = floor_sums(n, m, a, b);
__int128_t ans = s.h + 2 * (__int128_t)c * s.f + (__int128_t)c * c * n;
```
##### 注意事项
`floor_sums_nonneg()` 是内部递归，要求
$$
c>0,\quad a,b\ge0
$$
正常使用只调用：
```cpp
floor_sums(n, m, a, b)
```
递归中出现
```cpp
floor_sums_nonneg(c, c - b - 1, a, k - 1)
```
时若 `k > 0`，必有 `a > 0`，因此不会出现除以 $0$
三类和都可能迅速超过 `i64`，统一使用 `__int128_t`
如果只需要 `f`，不要为了复用而调用 `floor_sums()`，直接使用 `floor_sum()` 更合适
##### 复杂度
每次递归都会进行一次与欧几里得算法相同的参数交换和取模，因此递归层数为
$$
O(\log m)
$$
每层只进行常数次运算，所以：
$$
O(\log m)
$$
额外递归空间：
$$
O(\log m)
$$
#### 与普通数论分块的区别
8.3.1 中的数论分块处理的是
$$
\left\lfloor\frac ni\right\rfloor
$$
利用商在连续区间内相同，将 $O(n)$ 枚举压到 $O(\sqrt n)$
这里处理的是
$$
\left\lfloor\frac{ai+b}{m}\right\rfloor
$$
利用格点区域转置与欧几里得递归，将复杂度降到 $O(\log m)$
两者虽然都大量使用 floor，但优化思想不同：

| 类型 | 典型形式 | 核心思想 | 复杂度 |
|---|---|---|---:|
| 数论分块 | $\lfloor n/i\rfloor$ | 相同商分块 | $O(\sqrt n)$ |
| `floor_sum` | $\lfloor(ai+b)/m\rfloor$ | 欧几里得递归 | $O(\log m)$ |
