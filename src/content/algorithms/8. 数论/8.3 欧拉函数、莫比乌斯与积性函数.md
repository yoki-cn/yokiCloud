### 欧拉函数、莫比乌斯与积性函数
---
**解决问题：** 计算欧拉函数 $\varphi(n)$、莫比乌斯函数 $\mu(n)$，批量筛出 $\varphi/\mu$ 及其前缀和；处理积性函数、狄利克雷卷积与整除关系上的 Zeta / Möbius 变换
### 单点欧拉函数与莫比乌斯函数
---
```cpp
pair<i64, int> phi_mu(i64 n) {
    assert(n >= 1);
    i64 x{ n }, phi{ n };
    int mu{ 1 };
    for (i64 p = 2; p <= x / p; ++ p) {
        if (x % p) continue;
        phi = phi / p * (p - 1);
        x /= p;
        mu = -mu;
        if (x % p == 0) mu = 0;
        while (x % p == 0) x /= p;
    }
    if (x > 1) phi = phi / x * (x - 1), mu = -mu;
    return { phi, mu };
}
```
这里把 $\varphi$ 和 $\mu$ 合成一次试除，避免需要二者时重复分解
#### 接口说明
```cpp
auto [phi, mu] = phi_mu(n);
```
要求
$$
n\ge1
$$
返回：
$$
\phi=\varphi(n),
\qquad
\mu=\mu(n)
$$
欧拉函数定义为 $1\sim n$ 中与 $n$ 互质的整数个数：
$$
\varphi(n)
=
n\prod_{p\mid n}
\left(1-\frac1p\right)
$$
若
$$
n=\prod_{i=1}^k p_i^{e_i}
$$
则
$$
\varphi(n)
=
\prod_{i=1}^k p_i^{e_i-1}(p_i-1)
$$
莫比乌斯函数定义为
$$
\mu(1)=1
$$
若 $n$ 含有平方质因子，则
$$
\mu(n)=0
$$

否则若 $n$ 含有 $k$ 个不同质因子：
$$
\mu(n)=(-1)^k
$$
#### 常用结论
对于质数 $p$：
$$
\varphi(p)=p-1
$$
以及
$$
\varphi(p^k)=p^{k-1}(p-1)
$$
对于 $n>1$：
$$
\sum_{d\mid n}\varphi(d)=n
$$
更统一地：
$$
\sum_{d\mid n}\varphi(d)=n
$$
对所有 $n\ge1$ 都成立
欧拉定理：
$$
\gcd(a,m)=1
\Longrightarrow
a^{\varphi(m)}\equiv1\pmod m
$$
因此在互质条件下：
$$
a^b
\equiv
a^{b\bmod\varphi(m)}
\pmod m
$$
常见的扩展欧拉降幂形式为
$$
a^b\bmod m=
\begin{cases}
a^{b\bmod\varphi(m)}\bmod m,
&\gcd(a,m)=1,\\[4pt]
a^b\bmod m,
&\gcd(a,m)\ne1,\ b<\varphi(m),\\[4pt]
a^{b\bmod\varphi(m)+\varphi(m)}\bmod m,
&\gcd(a,m)\ne1,\ b\ge\varphi(m)
\end{cases}
$$
莫比乌斯函数最重要的恒等式：
$$
\sum_{d\mid n}\mu(d)
=
[n=1]
$$
其中 `[P]` 表示命题 $P$ 成立时为 $1$，否则为 $0$
#### 常见用法
只求欧拉函数：
```cpp
auto [phi, mu] = phi_mu(n);
// 使用 phi
```
只求 Möbius：
```cpp
auto [phi, mu] = phi_mu(n);
// 使用 mu
```
若整数已经在 8.2 中完成质因数分解，则**不要再试除一次**。直接由
```cpp
vector<pair<u64, int>> fac;
```
计算：
```cpp
u64 phi = n;
int mu = 1;
for (auto [p, e] : fac) {
    phi = phi / p * (p - 1);
    if (e > 1) mu = 0;
    else mu = -mu;
}
```
#### 注意事项
`phi_mu(1)` 返回
```cpp
{1, 1}
```
这是数学定义，不是特殊失败状态
若 $n$ 已经大到试除不可接受，应先使用 8.2 的 Pollard--Rho 分解，而不是继续使用这个函数
#### 复杂度
最坏时间复杂度：
$$
O(\sqrt n)
$$
额外空间：
$$
O(1)
$$
### 线性筛 $\varphi$ 与 $\mu$
---
```cpp
struct ArithmeticSieve {
    int n;
    vector<int> minp, primes, phi, mu;
    // ===== 前缀和：不需要莫反 / 杜教筛时可直接删除 =====
    vector<i64> sum_phi;
    vector<int> sum_mu;
    explicit ArithmeticSieve(int n_) : n(n_), minp(n + 1), phi(n + 1), mu(n + 1), sum_phi(n + 1), sum_mu(n + 1) {
        if (n >= 1) phi[1] = mu[1] = 1;
        for (int i = 2; i <= n; ++ i) {
            if (!minp[i]) {
                minp[i] = i;
                primes.push_back(i);
                phi[i] = i - 1;
                mu[i] = -1;
            }
            for (int p : primes) {
                i64 v{ 1LL * i * p };
                if (v > n) break;
                minp[v] = p;
                if (p == minp[i]) {
                    phi[v] = phi[i] * p;
                    mu[v] = 0;
                    break;
                }
                phi[v] = phi[i] * (p - 1);
                mu[v] = -mu[i];
            }
        }
        // ===== 以下函数可直接删除：只在需要前缀和时保留 =====
        for (int i = 1; i <= n; ++ i) {
            sum_phi[i] = sum_phi[i - 1] + phi[i];
            sum_mu[i] = sum_mu[i - 1] + mu[i];
        }
    }
};
```
#### 接口说明
构造：
```cpp
ArithmeticSieve sieve(n);
```
成员变量：

| 成员           | 含义                       |
| ------------ | ------------------------ |
| `primes`     | 不超过 `n` 的全部质数            |
| `minp[x]`    | `x` 的最小质因子               |
| `phi[x]`     | $\varphi(x)$             |
| `mu[x]`      | $\mu(x)$                 |
| `sum_phi[x]` | $\sum_{i=1}^x\varphi(i)$ |
| `sum_mu[x]`  | $\sum_{i=1}^x\mu(i)$     |
合法查询范围：
$$
1\le x\le n
$$
#### 递推原理
若 $p\mid n$：
$$
\varphi(np)=p\varphi(n)
$$
且因为 $np$ 出现平方质因子：
$$
\mu(np)=0
$$
若
$$
p\nmid n
$$
则：
$$
\varphi(np)=(p-1)\varphi(n)
$$
以及
$$
\mu(np)=-\mu(n)
$$
因此在线性筛中，每个合数只由其最小质因子对应的状态转移一次
#### 常见用法
查询：
```cpp
ArithmeticSieve sieve(N);
cout << sieve.phi[x] << '\n';
cout << sieve.mu[x] << '\n';
```
区间 $\varphi$ 和：
```cpp
i64 sum = sieve.sum_phi[r] - sieve.sum_phi[l - 1];
```
区间 Möbius 和：
```cpp
int sum = sieve.sum_mu[r] - sieve.sum_mu[l - 1];
```
只需要 `phi / mu`，不需要前缀和时，可以直接删除：
```cpp
vector<i64> sum_phi;
vector<int> sum_mu;
```
以及构造函数最后的前缀循环
#### 注意事项
这一份内部再次维护了 `minp / primes`，虽然与 8.2 的线性筛有少量重复，但这是**刻意保留的自包含依赖**：复制整个 8.3 线性筛后就能直接使用，不必再去拼 8.2
如果某道题已经使用了 8.2 的 `LinearSieve`，并且只需要少量额外信息，也可以直接在那份筛里加入 `phi / mu` 转移，不需要同时构造两个筛
`sum_phi[n]` 的数量级为 $O(n^2)$，因此必须使用 `i64`，不能跟 `phi` 一起使用 `int`
#### 复杂度
构造：
$$
O(n)
$$
时间
空间：
$$
O(n)
$$
单点查询：
$$
O(1)
$$
前缀区间查询：
$$
O(1)
$$
### 通用积性函数线性筛
---
这一块属于**扩展功能，可整段删除**
若题目出现一个新的积性函数，而且已知其质数幂上的值
$$
f(p^e),
$$
则不必每次重新手写一套线性筛
`prime_power(p,e,pe)` 需要返回
$$
f(p^e)
$$
其中
$$
pe=p^e
$$
```cpp
template<class T, class F>
vector<T> multiplicative_sieve(int n, F prime_power) {
    vector<int> minp(n + 1), primes, pp(n + 1), exp(n + 1);
    vector<T> f(n + 1);
    f[1] = T{1};
    for (int i = 2; i <= n; ++ i) {
        if (!minp[i]) {
            minp[i] = i;
            primes.push_back(i);
            pp[i] = i;
            exp[i] = 1;
            f[i] = prime_power(i, 1, i);
        }
        for (int p : primes) {
            i64 v{ 1LL * i * p };
            if (v > n) break;
            minp[v] = p;
            if (p == minp[i]) {
                pp[v] = pp[i] * p;
                exp[v] = exp[i] + 1;
                f[v] = f[i / pp[i]] * prime_power(p, exp[v], pp[v]);
                break;
            }
            pp[v] = p;
            exp[v] = 1;
            f[v] = f[i] * prime_power(p, 1, p);
        }
    }
    return f;
}
```
#### 接口说明
要求 $f$ 为积性函数，即：
$$
\gcd(a,b)=1
\Longrightarrow
f(ab)=f(a)f(b)
$$
传入的回调：
```cpp
prime_power(p, e, pe)
```
表示
$$
pe=p^e
$$
并返回
$$
f(p^e)
$$
函数返回：
```cpp
f[x]
```
即所有
$$
1\le x\le n
$$
的函数值
#### 常见用法
##### 欧拉函数
```cpp
auto phi = multiplicative_sieve<i64>(n, [](i64 p, int e, i64 pe) {
    return pe / p * (p - 1);
});
```
##### 莫比乌斯函数
```cpp
auto mu = multiplicative_sieve<int>(n, [](int p, int e, int pe) {
    return e == 1 ? -1 : 0;
});
```
##### 约数个数函数
若
$$
\tau(p^e)=e+1
$$
则：
```cpp
auto tau = multiplicative_sieve<i64>(n, [](i64 p, int e, i64 pe) {
    return i64(e + 1);
});
```
##### 约数和函数
有
$$
\sigma(p^e)=1+p+p^2+\cdots+p^e
$$
可以写：
```cpp
auto sigma = multiplicative_sieve<i64>(n, [](i64 p, int e, i64 pe) {
    return (pe * p - 1) / (p - 1);
});
```
这里要求中间值 `pe * p` 不溢出
若有模数，则应自行写不依赖整数除法的质数幂公式
#### 注意事项
这个通用版的价值是处理**临时出现的新积性函数**
对于 `phi / mu` 这种极常见函数，仍优先使用上一节专用 `ArithmeticSieve`：
- 更短
- 同时计算两个函数
- 能直接维护前缀和
- 常数也更小
`prime_power()` 应为 $O(1)$。如果回调内部每次都重新快速幂，那么整个筛就不再是严格的 $O(n)$ 常数操作
#### 复杂度
若 `prime_power()` 为 $O(1)$，则：
$$
O(n)
$$
时间
$$
O(n)
$$

空间
### 积性函数与狄利克雷卷积
---
#### 基本定义
若算术函数 $f$ 满足
$$
f(1)=1
$$
并且对于
$$
\gcd(a,b)=1
$$
有
$$
f(ab)=f(a)f(b)
$$
则称 $f$ 为**积性函数**
若对任意 $a,b$ 都有
$$
f(ab)=f(a)f(b)
$$
则称为**完全积性函数**
常见算术函数：

| 函数 | 定义 |
|---|---|
| $\varepsilon(n)$ | $[n=1]$ |
| $\mathbf 1(n)$ | 恒为 $1$ |
| $\operatorname{id}(n)$ | $n$ |
| $\operatorname{id}_k(n)$ | $n^k$ |
| $\mu(n)$ | Möbius 函数 |
| $\varphi(n)$ | 欧拉函数 |
| $\tau(n)$ | 正约数个数 |
| $\sigma_k(n)$ | $\sum_{d\mid n}d^k$ |
狄利克雷卷积定义为
$$
(f*g)(n)
=
\sum_{d\mid n}
f(d)g\left(\frac nd\right)
$$
#### 常用恒等式
单位元：
$$
f*\varepsilon=f
$$
Möbius 函数是常数函数 $\mathbf1$ 的 Dirichlet 逆：
$$
\mu*\mathbf1=\varepsilon
$$
欧拉函数：
$$
\varphi
=
\operatorname{id}*\mu
$$
因此：
$$
\varphi(n)
=
\sum_{d\mid n}\mu(d)\frac nd
$$
约数个数：
$$
\tau
=
\mathbf1*\mathbf1
$$
约数幂和：
$$
\sigma_k
=
\operatorname{id}_k*\mathbf1
$$
特别地：
$$
\sigma_0=\tau
$$
两个积性函数的狄利克雷卷积仍然是积性函数
### 狄利克雷卷积
---
数组使用 `1..n`，下标 `0` 不参与计算
```cpp
template<class T>
vector<T> dirichlet_conv(const vector<T> &a, const vector<T> &b) {
    int n{ int(min(a.size(), b.size())) - 1 };
    vector<T> c(n + 1);
    for (int i = 1; i <= n; ++ i) {
        for (int j = 1, ij = i; ij <= n; ++ j, ij += i) {
            c[ij] += a[i] * b[j];
        }
    }
    return c;
}
```
#### 接口说明
返回
$$
c=a*b
$$
即：
$$
c[n]
=
\sum_{d\mid n}
a[d]\ b[n/d]
$$
例如：
```cpp
vector<i64> one(n + 1, 1);
one[0] = 0;
auto tau = dirichlet_convolution(one, one);
```
得到：
$$
\tau=\mathbf1*\mathbf1
$$
#### 常见用法
验证：
```cpp
for (int x = 1; x <= n; ++ x) {
    // c[x] = sum_{d | x} a[d] * b[x / d]
}
```
若运算在模意义下进行，可以直接令 `T` 为 `MInt`
#### 注意事项
不要误认为这里是普通多项式卷积
普通卷积按照
$$
i+j=n
$$
组合下标
狄利克雷卷积按照
$$
ij=n
$$
组合下标
两者完全不同
#### 复杂度
循环次数为
$$
\sum_{i=1}^n
\left\lfloor\frac ni\right\rfloor
$$
因此时间复杂度为
$$
O(n\log n)
$$
空间：
$$
O(n)
$$
### 整除 Zeta 与 Möbius 变换
---
```cpp
// a[n] <- sum_{d | n} a[d]
template<class T>
void divisor_zeta(vector<T> &a) {
    int n{ int(a.size()) - 1 };
    for (int d = n; d >= 1; -- d) {
        for (int x = d + d; x <= n; x += d) a[x] += a[d];
    }
}
// divisor_zeta 的逆变换
template<class T>
void divisor_mobius(vector<T> &a) {
    int n{ int(a.size()) - 1 };
    for (int d = 1; d <= n; ++ d) {
        for (int x = d + d; x <= n; x += d) a[x] -= a[d];
    }
}
// a[d] <- sum_{d | n} a[n]
template<class T>
void multiple_zeta(vector<T> &a) {
    int n{ int(a.size()) - 1 };
    for (int d = 1; d <= n; ++ d) {
        for (int x = d + d; x <= n; x += d) a[d] += a[x];
    }
}
// multiple_zeta 的逆变换
template<class T>
void multiple_mobius(vector<T> &a) {
    int n{ int(a.size()) - 1 };
    for (int d = n; d >= 1; -- d) {
        for (int x = d + d; x <= n; x += d) a[d] -= a[x];
    }
}
```
#### 接口说明
`divisor_zeta(a)`：
$$
a'_n
=
\sum_{d\mid n}a_d
$$
之后：
```cpp
divisor_mobius(a);
```
可以恢复原数组
`multiple_zeta(a)`：
$$
a'_d
=
\sum_{d\mid n}a_n
$$
即统计所有 $d$ 的倍数
`multiple_mobius()` 是它的逆操作
#### Möbius 反演
经典形式为：
若
$$
F(n)
=
\sum_{d\mid n}f(d)
$$
则
$$
f(n)
=
\sum_{d\mid n}
\mu(d)
F\left(\frac nd\right)
$$
本质上：
$$
F=f*\mathbf1
$$
两边卷积 $\mu$：
$$
F*\mu
=
f*\mathbf1*\mu
=
f
$$
这就是 Möbius 反演
#### 常见用法
##### 求每个数的约数权值和
原数组：
```cpp
vector<i64> f(n + 1);
```
执行：
```cpp
divisor_zeta(f);
```
之后：
```cpp
f[x]
```
就是
$$
\sum_{d\mid x}f_{\text{old}}(d)
$$
##### 从约数和恢复原函数
```cpp
divisor_mobius(f);
```
即可恢复
##### 求所有倍数贡献
若需要：
$$
g[d]
=
\sum_{d\mid x}f[x]
$$
直接：
```cpp
multiple_zeta(f);
```
##### 互质指示函数
最常用的 Möbius 技巧：
$$
[\gcd(a,b)=1]
=
\sum_{d\mid\gcd(a,b)}\mu(d)
$$
更一般地：
$$
[\gcd(a,b)=k]
=
\sum_{d\mid\gcd(a/k,b/k)}\mu(d)
$$
在 $k\mid a,b$ 时成立
很多“统计互质数对”的题，就是把 `gcd == 1` 换成上述约数求和，再交换求和顺序
#### 注意事项
四个变换都是**原地修改**
例如：
```cpp
divisor_zeta(a);
```
以后 `a` 已经不再保存原函数。如果后面仍需要原数组，应先复制
循环方向不能随便修改：
```text
divisor_zeta       : d 从大到小
divisor_mobius     : d 从小到大
multiple_zeta      : d 从小到大
multiple_mobius    : d 从大到小
```
方向写反会让已经更新过的值再次参与贡献，产生重复计数
这里的 `divisor_mobius()` 是**整除偏序上的 Möbius 逆变换**；它与“直接把每个值乘上 `mu[i]`”不是一回事
#### 复杂度
四个函数的循环次数都是调和级数：
$$
\sum_{d=1}^n O\left(\frac nd\right)
=
O(n\log n)
$$
因此时间复杂度：
$$
O(n\log n)
$$
除输入数组外额外空间：
$$
O(1)
$$
### 常用公式速查
$$
\varphi(n)
=
n\prod_{p\mid n}\left(1-\frac1p\right)
$$

$$
\varphi(p^k)
=
p^{k-1}(p-1)
$$

$$
\sum_{d\mid n}\varphi(d)=n
$$

$$
\mu(n)=
\begin{cases}
1,&n=1,\\
0,&\exists p^2\mid n,\\
(-1)^k,&n\text{ 含 }k\text{ 个不同质因子}
\end{cases}
$$

$$
\sum_{d\mid n}\mu(d)=[n=1]
$$
$$
(f*g)(n)
=
\sum_{d\mid n}f(d)g(n/d)
$$
$$
\mu*\mathbf1=\varepsilon
$$
$$
\varphi=\operatorname{id}*\mu
$$
$$
\tau=\mathbf1*\mathbf1
$$
$$
\sigma_k=\operatorname{id}_k*\mathbf1
$$
以及最常用的：
$$
[\gcd(a,b)=1]
=
\sum_{d\mid\gcd(a,b)}\mu(d)
$$
