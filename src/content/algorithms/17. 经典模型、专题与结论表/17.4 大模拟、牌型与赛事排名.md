### 大模拟、牌型与赛事排名
---
#### 大模拟通用拆解
---
**解决问题：** 处理规则多、分支多、平局细则多的模拟题，避免把输入解析、状态修改、比较规则和输出逻辑混在一起
**思路：** 优先拆成“解析 → 标准状态 → 单步更新 → 评分 / 排序键 → 输出”。能转成字典序比较元组的规则尽量一次编码，状态修改尽量在检查合法后一次提交

| 题型 | 稳定核心 | 优先复用 | 题目特化部分 |
|---|---|---|---|
| 扑克牌 / 牌型 | 编码为可字典序比较的评分元组 | `PokerVal` | 短牌、大小王、自定义牌型 |
| Blackjack | A 先按 1，再尽量提升一个 A 为 11 | `bj_val` | 保险、分牌、double 等流程 |
| 保龄球 | 10 局 + strike / spare 奖励球 | `bowl_score` | 字符串输入格式 |
| 足球 / 篮球联赛 | 逐场累计，再按规则依次比较 | `League` | 积分制、相互战绩、公平竞赛分 |
| 分组晋级 | 组内排序后抽取名次，再跨组排序 | `select_qual` | 是否扣除对末名成绩 |
| 循环赛赛程 | 固定一人，其余循环旋转 | `round_robin` | 主客场平衡、双循环 |
| 事件时间线 | `(时间,优先级,输入序号)` 排序 | 扫描线 / 事件模拟 | 同刻事件顺序 |
| 循环座位 / 淘汰 | 活跃集合 + 方向 + 取模 | 约瑟夫 / 下标链表 | 跳过、反转、额外回合 |
| 日志 / 协议 | 分词 + FSM + 原子更新 | 字符串与 IO | 非法命令处理 |
##### 注意事项
- 开写前先固定编号方式、闭开区间、同刻事件顺序、平局规则和非法输入行为
- 状态修改前先检查全部前置条件，避免失败分支留下半次修改
- 赛事名称不能替代题面规则；同一运动不同年份、不同赛事的破平规则可能不同
##### 常见用法
- 牌型：先转为 `(类别, 破平关键字)`
- 排名：把每条比较规则写成独立字段，严格按题面顺序排序
- 时间线：所有事件先标准化成统一结构，再排序执行
#### 德州扑克：五张牌评分与七选五
---
**解决问题：** 比较标准德州扑克牌力；支持恰好五张牌评分，以及从 5～7 张牌中选择最强五张
**思路：** 五张牌先统计点数频次、同花和顺子，再编码为 `(cat,key)`；`cat` 越大牌型越强，`key` 按破平顺序存储，因此可直接字典序比较。七选五最多枚举 $\binom75=21$ 组
```cpp
struct Card {
    int r{0}, s{0};
    friend bool operator==(const Card &a, const Card &b) {
        return tie(a.r, a.s) == tie(b.r, b.s);
    }
};
optional<Card> parse_card(string_view x) {
    if (x.size() != 2 && x.size() != 3) return nullopt;
    static constexpr string_view rs = "23456789TJQKA";
    static constexpr string_view ss = "SHDC";
    int r;
    if (x.size() == 3) {
        if (x[0] != '1' || x[1] != '0') return nullopt;
        r = 10;
    } else {
        size_t p = rs.find(x[0]);
        if (p == string_view::npos) return nullopt;
        r = int(p) + 2;
    }
    size_t s = ss.find(x.back());
    if (s == string_view::npos) return nullopt;
    return Card{r, (int)s};
}
struct PokerVal {
    int cat{-1};
    array<int, 5> key{};
    friend bool operator==(const PokerVal &a, const PokerVal &b) {
        return tie(a.cat, a.key) == tie(b.cat, b.key);
    }
    friend bool operator<(const PokerVal &a, const PokerVal &b) {
        return tie(a.cat, a.key) < tie(b.cat, b.key);
    }
};
PokerVal eval5(const array<Card, 5> &a) {
    array<int, 15> cnt{};
    bool flush = true;
    for (Card c : a) {
        ++ cnt[c.r];
        flush &= c.s == a[0].s;
    }
    array<int, 5> rs{};
    array<pair<int, int>, 5> gp{};
    int nr = 0;
    for (int r = 14; r >= 2; -- r) if (cnt[r]) {
        rs[nr] = r;
        gp[nr ++] = {cnt[r], r};
    }
    sort(gp.begin(), gp.end(), greater<pair<int, int>>());
    int hi = 0;
    if (nr == 5) {
        if (rs[0] - rs[4] == 4) hi = rs[0];
        else if (rs[0] == 14 && rs[1] == 5 && rs[4] == 2) hi = 5;
    }
    PokerVal v;
    if (flush && hi) v.cat = 8, v.key[0] = hi;
    else if (gp[0].first == 4) v.cat = 7, v.key = {gp[0].second, gp[1].second};
    else if (gp[0].first == 3 && gp[1].first == 2) v.cat = 6, v.key = {gp[0].second, gp[1].second};
    else if (flush) v.cat = 5, v.key = rs;
    else if (hi) v.cat = 4, v.key[0] = hi;
    else if (gp[0].first == 3) {
        v.cat = 3;
        v.key[0] = gp[0].second;
        int p = 1;
        for (int i = 0; i < nr; ++ i) if (rs[i] != gp[0].second) v.key[p ++] = rs[i];
    } else if (gp[0].first == 2 && gp[1].first == 2) {
        v.cat = 2;
        v.key = {gp[0].second, gp[1].second, gp[2].second};
    } else if (gp[0].first == 2) {
        v.cat = 1;
        v.key[0] = gp[0].second;
        int p = 1;
        for (int i = 0; i < nr; ++ i) if (rs[i] != gp[0].second) v.key[p ++] = rs[i];
    } else {
        v.cat = 0;
        v.key = rs;
    }
    return v;
}
struct BestHand {
    PokerVal val;
    array<int, 5> id{};
};
optional<BestHand> best_hand(const vector<Card> &a) {
    if (a.size() < 5 || a.size() > 7) return nullopt;
    BestHand ans;
    for (int i = 0; i < a.size(); ++ i)
        for (int j = i + 1; j < a.size(); ++ j)
            for (int k = j + 1; k < a.size(); ++ k)
                for (int l = k + 1; l < a.size(); ++ l)
                    for (int t = l + 1; t < a.size(); ++ t) {
                        array<int, 5> id{i, j, k, l, t};
                        array<Card, 5> h{a[i], a[j], a[k], a[l], a[t]};
                        PokerVal v = eval5(h);
                        if (ans.val < v) ans = {v, id};
                    }
    return ans;
}
int cmp_poker(const PokerVal &a, const PokerVal &b) {
    return (b < a) - (a < b);
}
```

| `cat` | 牌型 | `key` 比较顺序 |
|---:|---|---|
| 8 | 同花顺 | 顺子最高张，A2345 记为 5 |
| 7 | 四条 | 四条点数、单张 |
| 6 | 葫芦 | 三条点数、对子点数 |
| 5 | 同花 | 五张点数从大到小 |
| 4 | 顺子 | 顺子最高张 |
| 3 | 三条 | 三条点数、两张散牌从大到小 |
| 2 | 两对 | 大对子、小对子、单张 |
| 1 | 一对 | 对子点数、三张散牌从大到小 |
| 0 | 高牌 | 五张点数从大到小 |
##### 接口说明
- `parse_card(x)`：解析 `2S..AS` 或 `10S` 形式，点数为 `2..14`，花色编号只用于判同花
- `eval5(a)`：恰好五张牌评分，返回可直接比较的 `PokerVal`
- `best_hand(a)`：接受 5～7 张牌，返回最优五张下标与牌力；其他张数返回 `nullopt`
- `cmp_poker(a,b)`：A 强返回 `1`，相同返回 `0`，B 强返回 `-1`
##### 注意事项
- A2345 是五高顺子，低于 23456；标准德州扑克花色无大小
- 皇家同花顺只是 A 高同花顺，不需要额外类别
- 必须保证输入没有重复实体牌；短牌、大小王、五条等规则需要修改评分逻辑
##### 常见用法
```cpp
vector<Card> a;
for (string s : in) a.push_back(*parse_card(s));
auto best = best_hand(a);
if (best) cout << best->val.cat << '\n';
```
##### 复杂度
- `eval5()` 为 $O(1)$；`best_hand()` 最多检查 21 个五张子集，仍为 $O(1)$
#### Blackjack 点数
---
**解决问题：** 给定一手 Blackjack 牌，计算不超过 21 时尽可能大的标准点数，并判断当前是否为 soft hand
**思路：** 所有 A 先按 1 计，其余 J/Q/K 按 10；若至少有一个 A 且总点数加 10 不超过 21，就把一个 A 提升为 11
```cpp
pair<int, bool> bj_val(const vector<Card> &a) {
    int sum = 0, ace = 0;
    for (Card c : a) {
        if (c.r == 14) ++ ace, ++ sum;
        else sum += min(c.r, 10);
    }
    bool soft = ace && sum + 10 <= 21;
    if (soft) sum += 10;
    return {sum, soft};
}
```
##### 接口说明
- `bj_val(a)`：返回 `{最佳点数, soft}`；点数大于 21 表示 bust
##### 注意事项
- 只实现标准点数，不处理 blackjack 天然牌奖金、保险、分牌、double、庄家流程等规则
- 地方规则若含“五小龙”等特殊胜负条件，应在点数之外单独判断
##### 常见用法
```cpp
auto [sum, soft] = bj_val(a);
if (sum > 21) {
    // bust
}
```
##### 复杂度
- 设手牌数为 $k$，时间 $O(k)$，额外空间 $O(1)$
#### 十瓶保龄球计分
---
**解决问题：** 对一场合法完整的十瓶保龄球投球序列计算总分，包括 strike 和 spare 的奖励球
**思路：** 逐局维护当前投球下标；strike 取后两球奖励，spare 取后一球奖励，普通局只加本局两球
```cpp
int bowl_score(const vector<int> &a) {
    int ans = 0, p = 0;
    for (int f = 0; f < 10; ++ f) {
        if (a[p] == 10) {
            ans += 10 + a[p + 1] + a[p + 2];
            ++ p;
        } else {
            int s = a[p] + a[p + 1];
            ans += s;
            if (s == 10) ans += a[p + 2];
            p += 2;
        }
    }
    return ans;
}
```
##### 接口说明
- `bowl_score(a)`：`a` 按实际投球顺序存击倒瓶数，并已包含第 10 局需要的奖励球
##### 注意事项
- 函数假设输入合法，不检查单局击倒数、第 10 局奖励球数量等约束
- 若题目输入为 `X / -` 字符串，应先解析成投球数组
- 全 strike 的投球序列长度为 12
##### 常见用法
```cpp
int ans = bowl_score(a);
```
##### 复杂度
- 固定 10 局，时间和额外空间均为 $O(1)$
#### 联赛积分、相互战绩与排序
---
**解决问题：** 处理足球、篮球等联赛积分榜，支持总积分、净胜分、得分、胜场、失分、外部附加值，以及并列后按相互战绩小表重新排序
**思路：** 先逐场累计统一统计量；比较规则用 `Crit` 按题面顺序描述。需要相互战绩时，只重算并列队伍之间的比赛；若部分队伍仍并列，可按规则选择是否对子组再次重算小表
```cpp
struct Match {
    int a, b;
    i64 x, y;
};
struct PointRule {
    i64 win{3}, draw{1}, loss{0};
};
struct TeamStat {
    int id{0}, game{0}, win{0}, draw{0}, loss{0};
    i64 pt{0}, sf{0}, sa{0}, extra{0};
    i64 diff() const { return sf - sa; }
};
vector<TeamStat> calc_stat(int n, const vector<Match> &e,
        PointRule pr = {}, const vector<int> &sub = {}) {
    vector<TeamStat> st(n);
    vector<char> use(n, sub.empty());
    for (int i = 0; i < n; ++ i) st[i].id = i;
    for (int u : sub) use[u] = true;
    for (const auto &g : e) if (use[g.a] && use[g.b]) {
        auto &a = st[g.a];
        auto &b = st[g.b];
        ++ a.game;
        ++ b.game;
        a.sf += g.x;
        a.sa += g.y;
        b.sf += g.y;
        b.sa += g.x;
        if (g.x > g.y) {
            ++ a.win;
            ++ b.loss;
            a.pt += pr.win;
            b.pt += pr.loss;
        } else if (g.x < g.y) {
            ++ b.win;
            ++ a.loss;
            b.pt += pr.win;
            a.pt += pr.loss;
        } else {
            ++ a.draw;
            ++ b.draw;
            a.pt += pr.draw;
            b.pt += pr.draw;
        }
    }
    return st;
}
enum class Field { PT, DIFF, SF, WIN, SA, EXTRA };
struct Crit {
    Field f;
    bool hi{true};
};
i64 stat_val(const TeamStat &s, Field f) {
    if (f == Field::PT) return s.pt;
    if (f == Field::DIFF) return s.diff();
    if (f == Field::SF) return s.sf;
    if (f == Field::WIN) return s.win;
    if (f == Field::SA) return s.sa;
    return s.extra;
}
int cmp_stat(const TeamStat &a, const TeamStat &b, const vector<Crit> &c) {
    for (auto q : c) {
        i64 x = stat_val(a, q.f), y = stat_val(b, q.f);
        if (x == y) continue;
        return (q.hi ? x > y : x < y) ? -1 : 1;
    }
    return 0;
}
vector<int> sort_rank(const vector<TeamStat> &st, vector<int> p,
        const vector<Crit> &c) {
    sort(p.begin(), p.end(), [&](int a, int b) {
        int d = cmp_stat(st[a], st[b], c);
        return d ? d < 0 : a < b;
    });
    return p;
}
vector<vector<int>> split_tie(const vector<TeamStat> &st,
        const vector<int> &p, const vector<Crit> &c) {
    vector<vector<int>> g;
    for (int u : p) {
        if (g.empty() || cmp_stat(st[g.back().back()], st[u], c)) g.push_back({});
        g.back().push_back(u);
    }
    return g;
}
struct League {
    int n;
    vector<Match> e;
    PointRule pr;
    vector<TeamStat> all;
    League(int n_, vector<Match> e_, PointRule pr_ = {})
        : n(n_), e(move(e_)), pr(pr_), all(calc_stat(n, e, pr)) {}
    vector<int> rank(const vector<Crit> &c) const {
        vector<int> p(n);
        iota(p.begin(), p.end(), 0);
        return sort_rank(all, move(p), c);
    }
    vector<int> rank_group(vector<int> g, const vector<Crit> &head,
            const vector<Crit> &fall, bool reap) const {
        if (g.size() <= 1) return g;
        auto st = calc_stat(n, e, pr, g);
        auto p = sort_rank(st, g, head);
        auto tie = split_tie(st, p, head);
        if (tie.size() == 1) return sort_rank(all, move(g), fall);
        vector<int> ans;
        for (auto &q : tie) {
            vector<int> cur = q.size() <= 1 ? q
                : reap ? rank_group(q, head, fall, true)
                       : sort_rank(all, q, fall);
            ans.insert(ans.end(), cur.begin(), cur.end());
        }
        return ans;
    }
    vector<int> rank_h2h(const vector<Crit> &pre, const vector<Crit> &head,
            const vector<Crit> &fall, bool reap = true) const {
        vector<int> p = rank(pre), ans;
        for (auto &g : split_tie(all, p, pre)) {
            auto q = rank_group(g, head, fall, reap);
            ans.insert(ans.end(), q.begin(), q.end());
        }
        return ans;
    }
};
```
##### 接口说明
- `Match{a,b,x,y}`：队伍 `a,b` 的一场比赛，比分 / 得分为 `x:y`
- `calc_stat(n,e,pr,sub)`：统计全部队伍，`sub` 非空时只计算子集内部相互战绩
- `Crit{field,hi}`：`hi=true` 表示字段越大越优
- `League::rank(c)`：只按全局统计排序
- `League::rank_h2h(pre,head,fall,reap)`：先按 `pre` 划分并列组，再按相互战绩 `head` 排序，仍并列时用 `fall`；`reap=true` 对剩余并列子组重新计算相互战绩
##### 注意事项
- 体育赛事没有统一破平规则，必须严格按题面填写 `Crit` 顺序
- `Field::EXTRA` 不由 `calc_stat()` 自动计算；纪律分、抽签值等需外部写入
- 若相互战绩也要比较某种 `EXTRA`，必须明确它能否从子组比赛重算
- `reap=false / true / rank()` 分别对应“不对子组重算 / 对子组重算 / 不使用相互战绩”
##### 常见用法
```cpp
League tb(n, e, {3, 1, 0});
vector<Crit> pre{{Field::PT, true}};
vector<Crit> head{
    {Field::PT, true},
    {Field::DIFF, true},
    {Field::SF, true}
};
vector<Crit> fall{
    {Field::DIFF, true},
    {Field::SF, true}
};
auto p = tb.rank_h2h(pre, head, fall, true);
```
##### 复杂度
- `calc_stat()` 为 $O(n+m)$，其中 $m$ 为比赛数
- `rank()` 为 $O(n+m+n\log n)$
- 相互战绩递归会重复扫描比赛，最坏可到 $O(nm+n^2\log n)$；常见小组规模下通常很小
#### 分组晋级
---
**解决问题：** 多个小组已完成组内排名后，先取每组前若干名直接晋级，再从各组下一名中选择若干最佳候选
**思路：** 直接晋级者按组截取；每组第一支未直通队伍进入跨组候选池，再用题目给定比较器排序
```cpp
struct Qual {
    vector<int> direct, wild;
};
template<class F>
Qual select_qual(const vector<vector<int>> &g, int d, int w, F better) {
    Qual ans;
    vector<int> c;
    d = max(d, 0);
    w = max(w, 0);
    for (const auto &p : g) {
        int k = min(d, (int)p.size());
        ans.direct.insert(ans.direct.end(), p.begin(), p.begin() + k);
        if (k < (int)p.size()) c.push_back(p[k]);
    }
    sort(c.begin(), c.end(), [&](int a, int b) {
        if (better(a, b)) return true;
        if (better(b, a)) return false;
        return a < b;
    });
    c.resize(min(w, (int)c.size()));
    ans.wild = move(c);
    return ans;
}
```
##### 接口说明
- `select_qual(g,d,w,better)`：每个 `g[i]` 必须已经按组内规则排好；取前 `d` 名直通，再从第 `d` 名位置的候选中选 `w` 支
- `better(a,b)`：跨组比较器，`a` 更优时返回 `true`
##### 注意事项
- 最佳第三名等规则若要求扣除对小组末名球队的成绩，应先重新计算跨组统计，不能直接把原积分表交给 `better`
- 不同组队数、退赛、取消比赛等情况都可能改变跨组比较口径
##### 常见用法
```cpp
auto q = select_qual(g, 2, 4, [&](int a, int b) {
    return key[a] > key[b];
});
```
##### 复杂度
- 设共有 $g$ 个小组、跨组候选数为 $c$，时间 $O(g+c\log c)$，额外空间 $O(c)$
#### 并列显示名次
---
**解决问题：** 已有从优到劣的排序结果，需要输出竞赛排名 `1,2,2,4` 或稠密排名 `1,2,2,3`
**思路：** 相邻元素等价时沿用前一名次；否则竞赛排名使用当前位置 `i+1`，稠密排名只加 1
```cpp
template<class Eq>
vector<int> show_rank(const vector<int> &p, Eq eq, bool dense = false) {
    vector<int> r(p.size());
    for (int i = 0; i < (int)p.size(); ++ i) {
        if (i == 0) r[i] = 1;
        else if (eq(p[i - 1], p[i])) r[i] = r[i - 1];
        else r[i] = dense ? r[i - 1] + 1 : i + 1;
    }
    return r;
}
```
##### 接口说明
- `show_rank(p,eq,false)`：竞赛排名，如 `1,2,2,4`
- `show_rank(p,eq,true)`：稠密排名，如 `1,2,2,3`
##### 注意事项
- `p` 必须已经按最终规则排好序
- `eq(a,b)` 必须表示“显示名次意义下完全并列”，不能只比较部分指标
##### 常见用法
```cpp
auto r = show_rank(p, [&](int a, int b) {
    return score[a] == score[b];
});
```
##### 复杂度
- 时间 $O(n)$，额外空间 $O(n)$
#### 单循环赛程：圆圈法
---
**解决问题：** 为 $n$ 个选手生成单循环赛程，使每一对选手恰好相遇一次，并尽量让每轮每人只赛一场
**思路：** 偶数人数时固定一个位置，其余编号每轮旋转；奇数人数先补一个虚拟轮空选手再使用同一构造
```cpp
vector<vector<pair<int, int>>> round_robin(int n) {
    if (n <= 1) return {};
    int m = n + (n & 1);
    vector<int> a(m);
    iota(a.begin(), a.end(), 0);
    if (m != n) a.back() = -1;
    vector<vector<pair<int, int>>> ans;
    for (int rd = 0; rd < m - 1; ++ rd) {
        vector<pair<int, int>> cur;
        for (int i = 0; i < m / 2; ++ i) {
            int x = a[i], y = a[m - 1 - i];
            if (x != -1 && y != -1) cur.push_back({x, y});
        }
        ans.push_back(move(cur));
        int x = a.back();
        for (int i = m - 1; i >= 2; -- i) a[i] = a[i - 1];
        a[1] = x;
    }
    return ans;
}
```
##### 接口说明
- `round_robin(n)`：返回各轮对阵；偶数 `n` 有 `n-1` 轮，奇数 `n>1` 有 `n` 轮
- 返回 pair 只表示一场对阵，不保证主客场方向平衡
##### 注意事项
- 双循环可复制全部对阵并交换主客场
- 若要求主客场连续场次最少、场地冲突、休息天数等额外目标，则已经是更复杂的排程问题
##### 常见用法
```cpp
auto rd = round_robin(n);
for (auto &g : rd) {
    for (auto [a, b] : g) {
        // a vs b
    }
}
```
##### 复杂度
- 输出比赛总数为 $\binom n2$，时间和输出空间均为 $\Theta(n^2)$
#### 两回合淘汰赛
---
**解决问题：** 两队进行主客场两回合比赛，按总比分、可选客场进球规则和外部决胜结果判断晋级者
**思路：** 先比较两回合总比分；若相同且题面启用客场进球，再比较各队客场得分；仍相同则交给加时、点球等外部规则
```cpp
struct TwoLeg {
    i64 a1, b1;
    i64 a2, b2;
};
optional<int> two_leg(const TwoLeg &g, bool away,
        optional<int> last = nullopt) {
    i64 a = g.a1 + g.a2, b = g.b1 + g.b2;
    if (a != b) return a > b ? 0 : 1;
    if (away && g.a2 != g.b1) return g.a2 > g.b1 ? 0 : 1;
    return last;
}
```
##### 接口说明
- `a1,b1`：首回合 A 主场时 A/B 得分
- `a2,b2`：次回合仍按 A/B 记录，因此 A 客场得分是 `a2`，B 客场得分是 `b1`
- `two_leg(g,away,last)`：返回 `0/1` 表示 A/B 晋级；仍无法决定且 `last` 为空时返回 `nullopt`
##### 注意事项
- 客场进球规则只有题面明确存在时才能启用，不要根据赛事名称猜测
- 加时阶段客场进球是否生效、点球是否计入总比分等都必须按题面单独处理
##### 常见用法
```cpp
auto w = two_leg(g, use_away, shootout_winner);
if (!w) {
    // 仍未决
}
```
##### 复杂度
- 时间和额外空间均为 $O(1)$
#### 系列赛胜者判定
---
**解决问题：** 在 BO3、BO5、BO7 等“先赢 `need` 场”系列赛中，根据当前双方胜场判断是否已经产生胜者
**思路：** 一方达到目标胜场且另一方尚未达到时即可确定胜者
```cpp
optional<int> series_win(int a, int b, int need) {
    if (a >= need && b < need) return 0;
    if (b >= need && a < need) return 1;
    return nullopt;
}
```
##### 接口说明
- `series_win(a,b,need)`：返回 `0/1` 表示 A/B 已胜出，否则返回 `nullopt`
##### 注意事项
- 函数只判断当前胜场，不验证总比赛数是否合法
- 若系列赛存在让分、平局或重赛规则，应额外处理
##### 常见用法
```cpp
auto w = series_win(wa, wb, 4); // BO7
```
##### 复杂度
- 时间和额外空间均为 $O(1)$
