### 构造、搜索与经典模型
---
#### N 皇后一组解
---
**解决问题：** 在 $n\times n$ 棋盘上放置 $n$ 个皇后，使任意两个皇后不同列且不在同一条对角线上，只要求构造任意一组解
**思路：** 普通 N 皇后在 $n=1$ 或 $n\ge4$ 时都有解，可按 $n\bmod6$ 分类直接排列列号，无需 DFS；返回每行皇后的 0base 列号
```cpp
optional<vector<int>> queens(int n) {
    if (n == 0) return vector<int>{};
    if (n == 2 || n == 3) return nullopt;
    if (n == 1) return vector<int>{0};
    vector<int> p;
    p.reserve(n);
    if (n % 6 != 2 && n % 6 != 3) {
        for (int x = 2; x <= n; x += 2) p.push_back(x);
        for (int x = 1; x <= n; x += 2) p.push_back(x);
    } else if (n % 6 == 2) {
        for (int x = 2; x <= n; x += 2) p.push_back(x);
        p.push_back(3);
        p.push_back(1);
        for (int x = 7; x <= n; x += 2) p.push_back(x);
        p.push_back(5);
    } else {
        for (int x = 4; x <= n; x += 2) p.push_back(x);
        p.push_back(2);
        for (int x = 5; x <= n; x += 2) p.push_back(x);
        p.push_back(1);
        p.push_back(3);
    }
    for (int &x : p) -- x;
    return p;
}
```
##### 接口说明
- `queens(n)`：返回每行皇后的 0base 列号；`n=2,3` 返回 `nullopt`
##### 注意事项
- 只解决普通 N 皇后的任意一组解；若要求方案数、全部方案、带障碍或额外约束，应改用位压 DFS / DLX
##### 常见用法
```cpp
auto p = queens(n);
if (!p) {
    // 无解
}
```
##### 复杂度
- 时间 $O(n)$，额外空间 $O(n)$
#### 幻方
---
**解决问题：** 构造 $n$ 阶正常幻方，使 $1..n^2$ 各出现一次，且每行、每列、两条主对角线的元素和相同
**思路：** 奇数阶使用 Siamese 法；$4k$ 阶使用互补翻转；$4k+2$ 阶先构造半阶奇数幻方，再按四块偏移并交换指定列。$n=2$ 无解
```cpp
vector<vector<int>> odd_magic(int n) {
    vector a(n, vector<int>(n));
    int r = 0, c = n / 2;
    for (int x = 1; x <= n * n; ++ x) {
        a[r][c] = x;
        int nr = (r - 1 + n) % n, nc = (c + 1) % n;
        if (a[nr][nc]) r = (r + 1) % n;
        else r = nr, c = nc;
    }
    return a;
}
optional<vector<vector<int>>> magic(int n) {
    if (n <= 0 || n == 2) return nullopt;
    if (n & 1) return odd_magic(n);
    vector a(n, vector<int>(n));
    if (n % 4 == 0) {
        for (int i = 0; i < n; ++ i) for (int j = 0; j < n; ++ j) {
            int x = i * n + j + 1;
            if (i % 4 == j % 4 || i % 4 + j % 4 == 3) x = n * n + 1 - x;
            a[i][j] = x;
        }
        return a;
    }
    int m = n / 2, k = (m - 1) / 2, d = m * m;
    auto b = odd_magic(m);
    for (int i = 0; i < m; ++ i) for (int j = 0; j < m; ++ j) {
        a[i][j] = b[i][j];
        a[i][j + m] = b[i][j] + 2 * d;
        a[i + m][j] = b[i][j] + 3 * d;
        a[i + m][j + m] = b[i][j] + d;
    }
    for (int i = 0; i < m; ++ i) {
        for (int j = 0; j < k; ++ j) if (i != k || j != 0) {
            swap(a[i][j], a[i + m][j]);
        }
        for (int j = n - k + 1; j < n; ++ j) swap(a[i][j], a[i + m][j]);
    }
    swap(a[k][k], a[k + m][k]);
    return a;
}
```
##### 接口说明
- `magic(n)`：构造 $n$ 阶正常幻方；`n=2` 或 `n<=0` 返回 `nullopt`
- `odd_magic(n)`：内部奇数阶构造，通常不单独调用
##### 注意事项
- 普通正常幻方与 pandiagonal / most-perfect 等特殊幻方不是同一模型
##### 常见用法
```cpp
auto a = magic(n);
if (a) {
    cout << (*a)[i][j] << '\n';
}
```
##### 复杂度
- 时间 $O(n^2)$，空间 $O(n^2)$，与输出规模同阶
#### $h\times w$ 宫 Sudoku 终盘
---
**解决问题：** 构造一个完整合法的广义 Sudoku 终盘。每个宫为 $h\times w$，整盘边长为 $n=hw$，每行、每列、每宫都恰含 $1..n$
**思路：** 让第 $i$ 行相对首行循环平移 $(i\bmod h)w+\lfloor i/h\rfloor$，可同时保证行、列和宫内均为排列
```cpp
vector<vector<int>> sudoku(int h, int w) {
    int n = h * w;
    vector a(n, vector<int>(n));
    for (int i = 0; i < n; ++ i) for (int j = 0; j < n; ++ j) {
        a[i][j] = ((i % h) * w + i / h + j) % n + 1;
    }
    return a;
}
```
##### 接口说明
- `sudoku(h,w)`：返回边长为 `h*w` 的完整合法终盘，数字范围为 `1..h*w`
##### 注意事项
- 只构造完整终盘；带空格求解、唯一解判定、字典序最小补全应使用搜索 / DLX
##### 常见用法
```cpp
auto a = sudoku(h, w);
cout << a[i][j] << '\n';
```
##### 复杂度
- 设 $n=hw$，时间 $O(n^2)$，空间 $O(n^2)$
#### Hadamard 矩阵
---
**解决问题：** 当 $n=2^k$ 时构造元素为 $\pm1$ 的 Hadamard 矩阵，使任意不同两行或两列的点积均为 0
**思路：** 从 $H_1=[1]$ 出发反复使用 Sylvester 构造 $H_{2n}=\begin{bmatrix}H_n&H_n\\H_n&-H_n\end{bmatrix}$
```cpp
vector<vector<int>> hadamard(int n) {
    if (n <= 0 || (n & (n - 1))) return {};
    vector a(n, vector<int>(n));
    a[0][0] = 1;
    for (int len = 1; len < n; len <<= 1) {
        for (int i = 0; i < len; ++ i) for (int j = 0; j < len; ++ j) {
            a[i][j + len] = a[i + len][j] = a[i][j];
            a[i + len][j + len] = -a[i][j];
        }
    }
    return a;
}
```
##### 接口说明
- `hadamard(n)`：构造 $2^k$ 阶 Hadamard 矩阵；`n` 不是正二次幂时返回空矩阵
##### 注意事项
- Hadamard 猜想并未给出所有 $4k$ 阶的统一构造；本板子只保证 $2^k$ 阶
##### 常见用法
```cpp
auto h = hadamard(n);
if (h.empty()) {
    // 不支持该阶数
}
```
##### 复杂度
- 时间 $O(n^2)$，空间 $O(n^2)$
#### Hanoi
---
**解决问题：** 将 $n$ 个大小不同的圆盘从起点柱移动到目标柱，每次只能移动一个圆盘，且大盘不能放在小盘上
**思路：** 先把前 $n-1$ 个盘移到辅助柱，再移动最大盘，最后把前 $n-1$ 个盘移到目标柱；通过回调 `move(s,t)` 处理每次操作
```cpp
template<class F>
void hanoi(int n, int s, int t, int h, const F &move) {
    if (!n) return;
    hanoi(n - 1, s, h, t, move);
    move(s, t);
    hanoi(n - 1, h, t, s, move);
}
```
##### 接口说明
- `hanoi(n,s,t,h,move)`：把 `n` 个圆盘从 `s` 移到 `t`，`h` 为辅助柱；每一步调用 `move(u,v)`
##### 注意事项
- 三柱 Hanoi 恰有 $2^n-1$ 次移动；四柱及更多柱不能直接套本递归
##### 常见用法
```cpp
hanoi(n, 0, 2, 1, [&](int u, int v) {
    cout << u << ' ' << v << '\n';
});
```
##### 复杂度
- 时间 $O(2^n)$，递归栈 $O(n)$；输出本身有 $2^n-1$ 步
#### 滑块拼图可达性
---
**解决问题：** 判断两个 $h\times w$ 滑块拼图状态能否通过移动空格互相到达，只判可达性，不求最短步数
**思路：** 忽略空格计算逆序奇偶性；宽度为奇数时奇偶性不变，宽度为偶数时还要结合空格距底部的行号形成不变量
```cpp
int inv_parity(const vector<int> &a, int blank = 0) {
    int p = 0;
    for (int i = 0; i < (int)a.size(); ++ i) if (a[i] != blank) {
        for (int j = i + 1; j < (int)a.size(); ++ j) {
            if (a[j] != blank && a[i] > a[j]) p ^= 1;
        }
    }
    return p;
}
bool puzzle_ok(const vector<int> &a, const vector<int> &b, int w) {
    if (w & 1) return inv_parity(a) == inv_parity(b);
    auto f = [&](const vector<int> &s) {
        int z = find(s.begin(), s.end(), 0) - s.begin();
        int r = int(s.size()) / w - z / w;
        return inv_parity(s) ^ (r & 1);
    };
    return f(a) == f(b);
}
```
##### 接口说明
- `inv_parity(a,blank)`：返回忽略空格后的逆序奇偶性
- `puzzle_ok(a,b,w)`：判断宽度为 `w` 的两个状态是否可达
##### 注意事项
- 两个状态必须尺寸相同、宽度合法、都恰有一个空格 `0`，且其余编号集合相同；函数本身不检查这些条件
- 这里只判可达性；八数码最短路常用反向 BFS，十五数码常用 IDA*
##### 常见用法
```cpp
if (puzzle_ok(a, b, w)) {
    // 可达
}
```
##### 复杂度
- 设格子总数为 $N$，当前逆序统计为 $O(N^2)$，额外空间 $O(1)$
#### 稳定婚姻 Gale--Shapley
---
**解决问题：** 两侧各有 $n$ 人，每人给出对另一侧的严格完整偏好序，求不存在阻塞对的稳定完美匹配
**思路：** A 方未匹配者按偏好顺序不断求婚；B 方只保留自己更喜欢的候选。每对组合最多被尝试一次，A 方主动时得到 A-optimal 稳定匹配
```cpp
vector<int> stable_match(const vector<vector<int>> &pa, const vector<vector<int>> &pb) {
    int n = pa.size();
    vector rk(n, vector<int>(n));
    for (int b = 0; b < n; ++ b) for (int i = 0; i < n; ++ i) {
        rk[b][pb[b][i]] = i;
    }
    vector<int> ma(n, -1), mb(n, -1), nxt(n);
    queue<int> q;
    for (int a = 0; a < n; ++ a) q.push(a);
    while (!q.empty()) {
        int a = q.front();
        q.pop();
        int b = pa[a][nxt[a] ++];
        if (mb[b] == -1) {
            ma[a] = b;
            mb[b] = a;
        } else if (rk[b][a] < rk[b][mb[b]]) {
            int old = mb[b];
            ma[old] = -1;
            q.push(old);
            ma[a] = b;
            mb[b] = a;
        } else {
            q.push(a);
        }
    }
    return ma;
}
```
##### 接口说明
- `stable_match(pa,pb)`：`pa[a]`、`pb[b]` 分别为两侧严格完整偏好排列，返回 `ma[a]=b`
##### 注意事项
- A 方主动求婚，因此得到 A-optimal 稳定匹配
- 不完整偏好、不可接受对象、容量大于 1 或并列偏好需要改成对应模型
##### 常见用法
```cpp
auto ma = stable_match(pa, pb);
for (int a = 0; a < n; ++ a) {
    int b = ma[a];
}
```
##### 复杂度
- 时间 $O(n^2)$，排名表与匹配数组共 $O(n^2)$ 空间
#### 最优二叉搜索树
---
**解决问题：** 已知有序关键字的成功搜索权 `p[0..n)` 和相邻空隙的失败搜索权 `q[0..n]`，构造期望搜索代价最小的二叉搜索树
**思路：** 区间 DP 枚举根，区间总权值作为本层新增代价；利用最优根的 Knuth 单调性，把根的枚举范围缩到相邻区间最优根之间
```cpp
pair<ld, vector<vector<int>>> opt_bst(const vector<ld> &p, const vector<ld> &q) {
    int n = p.size();
    vector dp(n + 1, vector<ld>(n + 1));
    vector sum(n + 1, vector<ld>(n + 1));
    vector rt(n + 1, vector<int>(n + 1));
    for (int i = 0; i <= n; ++ i) {
        dp[i][i] = sum[i][i] = q[i];
        rt[i][i] = i;
    }
    for (int len = 1; len <= n; ++ len) for (int l = 0, r = len; r <= n; ++ l, ++ r) {
        sum[l][r] = sum[l][r - 1] + p[r - 1] + q[r];
        int lo = len == 1 ? l : rt[l][r - 1];
        int hi = len == 1 ? r - 1 : min(r - 1, rt[l + 1][r]);
        dp[l][r] = numeric_limits<ld>::infinity();
        for (int k = lo; k <= hi; ++ k) {
            ld cur = dp[l][k] + dp[k + 1][r] + sum[l][r];
            if (cur < dp[l][r]) dp[l][r] = cur, rt[l][r] = k;
        }
    }
    return {dp[0][n], rt};
}
```
##### 接口说明
- `opt_bst(p,q)`：要求 `q.size()==p.size()+1`，返回 `{最小期望代价, 最优根表}`；`rt[l][r]` 表示区间 `[l,r)` 的根
##### 注意事项
- 权值必须非负；Knuth 单调性依赖该经典最优 BST 代价结构，其他区间 DP 不能直接套根区间优化
##### 常见用法
```cpp
auto [cost, rt] = opt_bst(p, q);
int root = rt[0][p.size()];
```
##### 复杂度
- 时间 $O(n^2)$，空间 $O(n^2)$
#### 最大 1 矩形
---
**解决问题：** 在 0/1 字符矩阵中求全部由指定字符组成的最大轴对齐子矩形，并返回面积与半开边界 `[t,b) * [l,r)`
**思路：** 逐行维护每列连续高度 `h`，同时维护当前高度能延伸到的左右边界，把每一行视为柱状图并在线更新最大矩形
```cpp
struct Rect {
    i64 area{0};
    int t{0}, l{0}, b{0}, r{0};
};
Rect max_rect(const vector<string> &a, char good = '1') {
    int n = a.size(), m = n ? (int)a[0].size() : 0;
    vector<int> h(m), l(m), r(m, m);
    Rect ans;
    for (int i = 0; i < n; ++ i) {
        int bd = 0;
        for (int j = 0; j < m; ++ j) {
            if (a[i][j] == good) {
                ++ h[j];
                l[j] = max(l[j], bd);
            } else {
                h[j] = 0;
                l[j] = 0;
                r[j] = m;
                bd = j + 1;
            }
        }
        bd = m;
        for (int j = m - 1; j >= 0; -- j) {
            if (a[i][j] == good) r[j] = min(r[j], bd);
            else bd = j;
            i64 s = (i64)h[j] * (r[j] - l[j]);
            if (s > ans.area) ans = {s, i - h[j] + 1, l[j], i + 1, r[j]};
        }
    }
    return ans;
}
```
##### 接口说明
- `max_rect(a,good)`：默认把字符 `'1'` 视为可用格，返回 `{area,t,l,b,r}`，边界为半开区间 `[t,b) * [l,r)`
##### 注意事项
- 若题目给的是平面障碍点、障碍矩形或允许旋转的矩形，与本 0/1 网格模型不同
##### 常见用法
```cpp
Rect ans = max_rect(a);
cout << ans.area << '\n';
```
##### 复杂度
- 对 $n\times m$ 矩阵，时间 $O(nm)$，额外空间 $O(m)$
#### 两机流水作业 Johnson 排序
---
**解决问题：** 每个任务都必须依次经过机器 1、机器 2，且两台机器一次只能处理一个任务，求使全部任务最早完成的一组任务顺序
**思路：** 若任务在机器 1 上更快，则放在前半并按机器 1 时间升序；否则放在后半并按机器 2 时间降序，这就是 Johnson 规则
```cpp
vector<int> johnson(const vector<pair<i64, i64>> &a) {
    vector<int> p(a.size());
    iota(p.begin(), p.end(), 0);
    sort(p.begin(), p.end(), [&](int i, int j) {
        bool x = a[i].first <= a[i].second;
        bool y = a[j].first <= a[j].second;
        if (x != y) return x > y;
        return x ? a[i].first < a[j].first : a[i].second > a[j].second;
    });
    return p;
}
```
##### 接口说明
- `johnson(a)`：`a[i]={t1,t2}` 为任务在机器 1、2 上的处理时间，返回一组最优任务编号顺序
##### 注意事项
- 只适用于所有任务都按“机器 1 → 机器 2”处理的经典两机 flow-shop；机器顺序不同、可并行、存在释放时间等变体不能直接套用
##### 常见用法
```cpp
auto ord = johnson(a);
for (int id : ord) {
    // 按该顺序加工
}
```
##### 复杂度
- 排序时间 $O(n\log n)$，额外空间 $O(n)$
#### 第 k 个元素
---
**解决问题：** 求无序序列按升序排列后的第 `k` 个元素，`k` 为 0base，但不需要完整排序
**思路：** 使用 `nth_element` 做选择，使目标位置左侧都不大于它、右侧都不小于它，避免完整排序
```cpp
template<class T>
T kth(vector<T> a, int k) {
    nth_element(a.begin(), a.begin() + k, a.end());
    return a[k];
}
```
##### 接口说明
- `kth(a,k)`：返回升序后的 0base 第 `k` 个元素，要求 `0 <= k < a.size()`；参数按值传入，不修改原数组
##### 注意事项
- `nth_element` 只保证第 `k` 个位置正确及两侧偏序，不会把整个数组排好序
##### 常见用法
```cpp
int x = kth(a, k);
```
##### 复杂度
- 标准库通常为平均 $O(n)$；本封装额外复制数组需要 $O(n)$ 时间与空间
#### 有界布尔母函数
---
**解决问题：** 第 $i$ 类物品重量为 `w[i]`、最多使用 `c[i]` 个，判断 `0..lim` 中哪些总和可达
**思路：** 把每类数量按二进制拆成若干个 0/1 物品，再用按位位移 OR 更新可达集合；每个 64 位整数同时处理 64 个状态
```cpp
void shift_or(vector<u64> &f, int d, int lim) {
    if (d <= 0 || d > lim) return;
    int q = d >> 6, r = d & 63;
    for (int i = (int)f.size() - 1; i >= q; -- i) {
        u64 x = f[i - q] << r;
        if (r && i > q) x |= f[i - q - 1] >> (64 - r);
        f[i] |= x;
    }
    int k = (lim + 1) & 63;
    if (k) f.back() &= (1ULL << k) - 1;
}
vector<u64> bounded_sum(const vector<int> &w, const vector<int> &c, int lim) {
    vector<u64> f((lim + 64) / 64);
    f[0] = 1;
    for (int i = 0; i < (int)w.size(); ++ i) {
        int rem = c[i];
        for (i64 b = 1; rem > 0; b <<= 1) {
            int take = min<i64>(b, rem);
            i64 d = (i64)w[i] * take;
            if (d <= lim) shift_or(f, (int)d, lim);
            rem -= take;
        }
    }
    return f;
}
```
##### 接口说明
- `bounded_sum(w,c,lim)`：第 `i` 类物品重量为 `w[i]`、最多选 `c[i]` 个；返回位集，第 `s` 位为 1 表示总和 `s` 可达
- `shift_or(f,d,lim)`：内部 0/1 位集转移，通常不单独调用
##### 注意事项
- 要求 `lim>=0`、`w[i]>=0`、`c[i]>=0` 且 `w.size()==c.size()`；`w[i]=0` 不改变可达集合
##### 常见用法
```cpp
auto f = bounded_sum(w, c, lim);
bool ok = f[x >> 6] >> (x & 63) & 1ULL;
```
##### 复杂度
- 设上界为 $L$，时间 $O\!\left(\frac{L}{64}\sum_i\log(c_i+1)\right)$，空间 $O(L/64)$
