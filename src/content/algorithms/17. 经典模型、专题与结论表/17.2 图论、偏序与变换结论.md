### 图论、偏序与变换结论
---
#### König、Gallai 与边覆盖
---
**解决问题：** 已知匹配、点覆盖、独立集或边覆盖中的一种量时，快速转化为另一种量，尤其用于二分图匹配后的答案换算
**思路：** König 把二分图最大匹配与最小点覆盖连接起来；Gallai 把任意图的最大独立集与最小点覆盖互补；无孤立点图的最小边覆盖可由最大匹配补齐
- König：二分图最小点覆盖大小 $\tau=\nu$，其中 $\nu$ 为最大匹配大小
- Gallai：任意图中最大独立集大小 $\alpha+\tau=n$
- 无孤立点图：最小边覆盖大小 $\rho=n-\nu$
##### 接口说明
- 二分图最大匹配、最小点覆盖使用 **6.1 二分图匹配与 KM**
- 若只需要大小，求出最大匹配数 `mat` 后直接代公式；若要恢复具体覆盖/独立集，使用匹配板子的恢复接口
##### 注意事项
- König 的 $\tau=\nu$ 只对二分图成立；Gallai 的 $\alpha+\tau=n$ 对任意图成立
- 图存在孤立点时，不存在覆盖全部顶点的普通边覆盖，不能直接使用 $\rho=n-\nu$
##### 常见用法
```cpp
int mvc = mat;
int mis = n - mat; // 二分图中也可由 König + Gallai 得到
int mec = n - mat;      // 仅当无孤立点
```
##### 复杂度
- 公式换算为 $O(1)$；总复杂度由最大匹配算法决定，Hopcroft--Karp 为 $O(E\sqrt V)$
#### Hall 定理与缺额
---
**解决问题：** 判断二分图是否存在覆盖左部所有点的匹配，或判断至少会有多少个左部点无法匹配
**思路：** 对任意左部子集 $S$，必须有足够多的右部邻点容纳它。定义缺额 $\operatorname{def}=\max_{S\subseteq L}(|S|-|N(S)|)$，则最大匹配能覆盖的左部点数为 $|L|-\operatorname{def}$。
$$
\text{存在覆盖 }L\text{ 的匹配}\iff \forall S\subseteq L,\ |N(S)|\ge|S|
$$
##### 接口说明
- 赛场上通常不枚举所有 $S$，而是直接求最大匹配：若 `mat == |L|`，Hall 条件成立
- 带权最优匹配不由 Hall 解决，应使用 KM 或费用流
##### 注意事项
- Hall 是存在性定理，不提供带权最优方案
- 完美匹配还要求两侧规模相同；“覆盖左部”本身不要求右部全部被匹配
##### 常见用法
```cpp
bool ok = mat == nl;
int def = nl - mat;
```
##### 复杂度
- 直接检查全部子集是指数级；实际使用最大匹配判断，复杂度由匹配算法决定
#### Dilworth 与 Mirsky
---
**解决问题：** 对偏序集求最少链覆盖、最大反链、最大链或最少反链分层
**思路：** Dilworth 给出“最少链数 = 最大反链大小”；Mirsky 给出对偶的“最少反链层数 = 最大链长度”。偏序链覆盖可把元素复制成左右两部，对所有可比关系 $x<y$ 连边，再做最大匹配
- Dilworth：最少链覆盖数 $=n-\nu=$ 最大反链大小
- Mirsky：最少反链分层数 $=$ 最大链长度
##### 接口说明
- 偏序链覆盖：对“可比关系”建二分图后调用 **6.1 二分图匹配与 KM**
- 若输入本身是 DAG 且题目求 DAG 顶点不相交最小路径覆盖，使用 DAG 路径覆盖模型，不必额外做传递闭包
##### 注意事项
- **偏序链覆盖与 DAG 路径覆盖不是同一建图。** 偏序需要连所有 $x<y$ 的可比关系；输入 DAG 的原始边未必已经是传递闭包
- 只有确认题意对象是偏序时，才能直接用 Dilworth 的“最大反链”解释
##### 常见用法
```cpp
int chains = n - mat;
int anti = chains;
```
##### 复杂度
- 传递闭包若用 bitset / Floyd 等另计；匹配复杂度取决于所用二分图匹配算法
#### Menger 与点边不相交路径
---
**解决问题：** 求 $s$ 到 $t$ 最多能同时走多少条互不共享边或内部点的路径，也可反向解释为最小割边数或最少删除点数
**思路：** Menger 把“不相交路径最大条数”与“最小分离集大小”对偶起来。边不相交直接把边容量设为 1；点不相交把中间点拆成 `in -> out`，容量设为 1
- 边版：边不相交的 $s\to t$ 路径最大条数 = 最小 $s-t$ 边割大小
- 点版：对不相邻的 $s,t$，内部点不相交路径最大条数 = 删除后能断开 $s,t$ 的最少内部点数
##### 接口说明
- 使用最大流板子；边不相交令原边容量为 1
- 点不相交令每个中间点拆点，`vin -> vout` 容量为 1，源汇容量设为足够大
##### 注意事项
- 若某个点允许被多条路径经过，把拆点容量改成对应上限
- 点版通常不限制源点和汇点本身的使用次数
- 有向图与无向图都可建模，但无向边转容量边时要按题意处理方向
##### 常见用法
```cpp
// 点不相交：v 拆成 vin, vout
flow.add_edge(vin, vout, v == s || v == t ? INF : 1);
```
##### 复杂度
- 建图为 $O(V+E)$ 级；求解复杂度由所用最大流算法决定
#### Erdős--Gallai 度序列判定
---
**解决问题：** 给定非负整数序列，判断它能否作为某个简单无向图的度数序列
**思路：** 先按非增排序并检查度数和为偶数，再验证所有前缀约束：
$$
\sum_{i=1}^k d_i\le k(k-1)+\sum_{i=k+1}^n\min(d_i,k)
$$
后半项可用前缀和加二分找到第一个小于 $k$ 的位置，从而整体做到 $O(n\log n)$；若还要构造图，可用 Havel--Hakimi
##### 接口说明
- 本节只保留判定结论；需要实现时建议写 `bool graphical(vector<int> d)`
- 只判存在性用 Erdős--Gallai；需要直接构造一张图时更适合 Havel--Hakimi
##### 注意事项
- 目标是**简单无向图**：不允许自环和重边
- 必须先排序；度数应满足 `0 <= d[i] < n`
##### 常见用法
```cpp
sort(d.rbegin(), d.rend());
// 前缀和 + 对每个 k 检查 Erdős--Gallai 不等式
```
##### 复杂度
- 排序、前缀和和二分实现为 $O(n\log n)$；朴素逐项计算为 $O(n^2)$
#### Landau 竞赛图度序列
---
**解决问题：** 判断一个整数序列能否作为竞赛图中各点的出度序列
**思路：** 将出度非降排序。任意前 $k$ 个点之间至少产生 $\binom{k}{2}$ 场内部胜利，全部点总胜场数恰为 $\binom n2$
$$
\sum_{i=1}^k s_i\ge\binom{k}{2}\quad(k<n),\quad \sum_{i=1}^n s_i=\binom n2
$$
##### 接口说明
- 判定时先非降排序，再扫前缀和
- 若题目还要求构造竞赛图，需要额外使用构造算法，Landau 本身只给存在性
##### 注意事项
- 每个出度都必须位于 `0..n-1`
- 这里是竞赛图：任意两点之间恰有一条定向边
##### 常见用法
```cpp
sort(s.begin(), s.end());
i64 pre = 0;
for (int k = 1; k <= n; ++ k) {
    pre += s[k - 1];
    // k < n 时检查 pre >= k * (k - 1) / 2
}
```
##### 复杂度
- 排序后 $O(n)$ 检查，总复杂度 $O(n\log n)$
#### Ramsey 小表
---
**解决问题：** 遇到很小的完全图染边 / 团与独立集保证存在问题时，直接查常见 Ramsey 数，避免临场误记
**思路：** $R(a,b)$ 是最小的 $n$，使任意 $K_n$ 的红蓝边染色必含红色 $K_a$ 或蓝色 $K_b$
- $R(3,3)=6$
- $R(3,4)=9$
- $R(3,5)=14$
- $R(4,4)=18$
##### 接口说明
- 本节仅作常数表，没有代码接口
##### 注意事项
- 大量 Ramsey 数的精确值未知，不能根据小表外推
- 注意区分 Ramsey 数与 Turán 极值数
##### 常见用法
- 看到“任意 6 人中必有 3 人两两认识或 3 人两两不认识”即使用 $R(3,3)=6$
#### 平面图与极值边数
---
**解决问题：** 快速判断某些图规模是否必不可能平面，或由面长、二分性推出边数和低度点上界
**思路：** 对平面嵌入使用 Euler 公式，再由所有面的边长和为 $2m$ 推出边数上界。设点数、边数、面数、连通块数分别为 $n,m,f,c$：
$$
n-m+f=1+c
$$
连通时为 $n-m+f=2$。进一步有：
- 简单平面图且 $n\ge3$：$m\le3n-6$
- 简单二分平面图且 $n\ge3$：$m\le2n-4$
- 连通简单平面图每个面长度至少为 $g\ge3$：$m\le\dfrac{g}{g-2}(n-2)$
- 简单平面图存在度数不超过 5 的点；简单二分平面图存在度数不超过 3 的点
- $K_5$ 与 $K_{3,3}$ 非平面
##### 接口说明
- 这些式子主要用于必要条件、计数和反证，不代替真正的平面性判定
##### 注意事项
- $m\le3n-6$ 不是平面性的充分条件
- 有自环、重边时不能直接套简单图边数上界
- Kuratowski 定理给出完整刻画，但竞赛中常先用 Euler 上界快速排除
##### 常见用法
```cpp
if (n >= 3 && m > 3LL * n - 6) {
    // 简单图一定不是平面图
}
```
#### Matrix--Tree 生成树计数
---
**解决问题：** 计算无向图生成树数量，或在统一 Laplacian 约定后计算有向根生成树数量。
**思路：** 构造 Laplacian 矩阵。无向图中 $L=D-A$，删除任意一行一列后的余子式行列式即生成树数
##### 接口说明
- 使用 **9.4 Prüfer、Matrix-Tree 与 De Bruijn** 的 `spanning_tree_count`
- 行列式消元依赖 **11.1 矩阵与线性方程组**
##### 注意事项
- 多重边在邻接矩阵中累加；自环不参与生成树
- 有向入树 / 出树的 Laplacian 定义和删行列方向必须与现有板子保持一致，不要凭记忆混用
- 模意义计数时，消元中的除法必须保证对应元素可逆；合数模通常不能直接套普通模高斯消元
##### 常见用法
```cpp
auto ans = spanning_tree_count(g);
```
##### 复杂度
- 构造矩阵 $O(n^2+m)$；朴素 $(n-1)\times(n-1)$ 行列式消元为 $O(n^3)$
#### BEST Euler 回路计数
---
**解决问题：** 计算强连通 Euler 有向图的 Euler 回路数量
**思路：** BEST 定理把 Euler 回路计数拆成“根向生成树数 × 各点出边排列的阶乘项”。核心结构为
$$
\text{Euler tours}\propto t_r(G)\prod_v(\operatorname{out}(v)-1)!
$$
具体系数取决于是否固定起点、首边、把循环旋转视为同一个方案、平行边是否有编号
##### 接口说明
- 根向生成树数使用 Matrix--Tree；阶乘项使用组合数学预处理
- 先按题目定义确定计数口径，再写最终系数
##### 注意事项
- BEST 最容易错在**计数口径**，不能只背一个裸公式
- 必须先满足 Euler 有向图的连通与入出度条件
- 建议用只有一个小环或两个平行环的手算样例核对系数
##### 常见用法
```cpp
// 伪代码：先明确题目是否固定起点/首边
ans = tree_cnt * fac_prod;
```
##### 复杂度
- 主要瓶颈是 Matrix--Tree 的 $O(n^3)$ 行列式；阶乘项为 $O(n)$
#### Euler、度数、树与割
---
**解决问题：** 快速处理 Euler 路存在性、度数奇偶、森林边数与桥/环之间的基本关系
**思路：** 这些结论都来自握手定理、树的无环连通性和割的度数计数
- 无向图：$\sum_v\deg(v)=2m$，奇度点个数为偶数
- 无向 Euler 回路：所有非零度点连通且全为偶度
- 无向 Euler 路：所有非零度点连通且奇度点恰为 0 或 2
- 有向 Euler 回路：忽略方向后非零度点连通，且每点入度 = 出度
- 有向 Euler 路：除起点 `out=in+1`、终点 `in=out+1` 外，其余点入度 = 出度；忽略方向后非零度点连通
- 树有 $n-1$ 条边；森林有 $m=n-c$
- 对任意顶点集 $S$，$\sum_{v\in S}\deg(v)$ 与割边数 $|\delta(S)|$ 同奇偶
- 无向图中一条边属于某个简单环，当且仅当它不是桥
##### 接口说明
- Euler 路构造使用图论章节的 Hierholzer
- 桥使用边双连通 / Tarjan 板子
##### 注意事项
- Euler 判定中的“连通”只要求考虑非零度点
- 有向 Euler 路的连通条件不要误写成所有点强连通；标准判定可用忽略方向后的连通性配合度数条件
##### 常见用法
```cpp
int odd = 0;
for (int d : deg) odd += d & 1;
bool ok = odd == 0 || odd == 2;
```
##### 复杂度
- 仅检查度数为 $O(V)$；若还需检查连通性则为 $O(V+E)$
#### Manhattan / Chebyshev 距离变换
---
**解决问题：** 把二维 Manhattan 距离转为 Chebyshev 距离，便于处理最远点、正方形范围、扫描和某些几何查询
**思路：** 令 $u=x+y,\ v=x-y$，则
$$
|x_1-x_2|+|y_1-y_2|=\max(|u_1-u_2|,|v_1-v_2|)
$$
反变换为 $x=(u+v)/2,\ y=(u-v)/2$，因此只有 `u,v` 同奇偶时才对应整数点
```cpp
pair<i128, i128> man2cheb(i64 x, i64 y) {
    return {(i128)x + y, (i128)x - y};
}
optional<pair<i64, i64>> cheb2man(i128 u, i128 v) {
    if ((u - v) % 2 != 0) return nullopt;
    i128 x = (u + v) / 2, y = (u - v) / 2;
    if (x < numeric_limits<i64>::min() || x > numeric_limits<i64>::max()) return nullopt;
    if (y < numeric_limits<i64>::min() || y > numeric_limits<i64>::max()) return nullopt;
    return pair{(i64)x, (i64)y};
}
```
##### 接口说明
- `man2cheb(x,y)`：返回变换坐标 `(u,v)`，使用 `i128` 防止 `x+y` 溢出
- `cheb2man(u,v)`：若能还原为 `i64` 整数点则返回坐标，否则返回 `nullopt`
##### 注意事项
- `cheb2man()` 默认 `u+v`、`u-v` 不超过 `i128`；由 `i64` 坐标经 `man2cheb()` 得到的值一定满足
- 二维 Manhattan 最远点也可直接枚举四种 `±x±y`；$d$ 维推广为枚举 $2^d$ 个符号掩码
##### 常见用法
```cpp
auto [u1, v1] = man2cheb(x1, y1);
auto [u2, v2] = man2cheb(x2, y2);
i128 du = u1 > u2 ? u1 - u2 : u2 - u1;
i128 dv = v1 > v2 ? v1 - v2 : v2 - v1;
i128 dis = max(du, dv);
```
##### 复杂度
- 正变换、反变换和单次距离计算均为 $O(1)$
#### 最小乘积与参数化凸壳
---
**解决问题：** 可行解同时产生两个非负代价 $X,T$，目标最小化乘积 $XT$；典型例子是每条边带两个权值的最小乘积生成树
**思路：** 把每个可行解映射为平面点 $(X,T)$。第一象限中最优乘积只可能出现在下凸壳；用参数 $\lambda$ 最小化 $\lambda X+T$ 得到支撑点，再递归寻找相邻支撑点之间是否存在新的凸壳点
##### 接口说明
- 最小乘积生成树每次把边权改为 `lambda * x + y` 后调用 MST
- 递归停止条件应比较端点与新点的叉积 / 是否落在同一支撑线，而不是对 `lambda` 做普通三分
##### 注意事项
- 前提是两个目标量处在适合该几何解释的非负区域
- 若 $X$ 或 $T$ 可为负，乘积等高线方向变化，不能直接套第一象限下凸壳结论
- 最终比较答案仍使用真实乘积 `X*T`，参数化线性权只负责找候选点
##### 常见用法
```cpp
// solve(lambda): 按 lambda * x + y 求一个最优对象，并返回其 (X, Y)
// 用两个端点递归寻找新的支撑点，再比较 X * Y
```
##### 复杂度
- 取决于产生的凸壳候选数和单次基础优化复杂度；最小乘积生成树中每个候选通常需要一次 MST
#### 最大 / 最小统计量求和
---
**解决问题：** 求所有大小为 $k$ 的子集中最大值之和、最小值之和，或进一步处理元素作为第若干大 / 小时的贡献
**思路：** 排序后固定某个元素作为最大值或最小值，剩余元素只需从它一侧选取，因此贡献次数直接是组合数。若 $a_0\le\cdots\le a_{n-1}$：
$$
\sum_{\lvert S\rvert=k}\max S=\sum_{i=k-1}^{n-1}a_i\binom{i}{k-1},
$$
$$
\sum_{\lvert S\rvert=k}\min S=\sum_{i=0}^{n-k}a_i\binom{n-i-1}{k-1}.
$$
##### 接口说明
- 先排序，再预处理组合数；按公式线性累加
- 更高阶第 `t` 大 / 小同样按“固定当前元素后，两侧分别选多少个”计组合数
##### 注意事项
- 先确认题目求的是“所有子集统计量之和”，还是随机子集的期望 / 分布；后者还要除以总方案数或保留计数分布
- 有模数时组合数和乘法都按模处理；精确整数计数注意溢出
##### 常见用法
```cpp
sort(a.begin(), a.end());
Z ans{};
for (int i = k - 1; i < n; ++ i) ans += a[i] * C(i, k - 1);
```
##### 复杂度
- 排序 $O(n\log n)$；组合数已预处理时统计为 $O(n)$
#### Sherman--Morrison、Woodbury 与行列式引理
---
**解决问题：** 已知 $A^{-1}$ 时，矩阵只发生低秩更新，希望避免重新做一次 $O(n^3)$ 求逆或行列式。
**思路：** 把更新写成秩一或低秩乘积，在较低维的中间矩阵上求逆：
- Sherman--Morrison：
$$
(A+uv^T)^{-1}=A^{-1}-\frac{A^{-1}uv^TA^{-1}}{1+v^TA^{-1}u}
$$
- Woodbury：
$$
(A+UCV^T)^{-1}=A^{-1}-A^{-1}U(C^{-1}+V^TA^{-1}U)^{-1}V^TA^{-1}
$$
- Matrix determinant lemma：
$$
\det(A+UV^T)=\det(I+V^TA^{-1}U)\det(A)
$$
##### 接口说明
- 本节只保留公式；矩阵乘法、求逆和行列式使用 **11.1 矩阵与线性方程组**
- 秩一更新优先使用 Sherman--Morrison；秩 $k$ 更新使用 Woodbury，把主要新求逆降到 $k\times k$
##### 注意事项
- 所有公式都要求相应逆存在；Sherman--Morrison 需 `1 + v^T A^{-1} u != 0`
- 上述 Woodbury 形式还要求 `C` 与中间矩阵可逆
- 有限域中“非零”和“可逆”都按模意义判断
##### 常见用法
```cpp
// 已知 invA，更新 A <- A + u v^T
// 先算 den = 1 + v^T invA u，再按 Sherman--Morrison 更新
```
##### 复杂度
- 秩一更新在已有 $A^{-1}$ 时通常为 $O(n^2)$
- 秩 $k$ Woodbury 主要为矩阵乘法加 $k\times k$ 求逆，常见量级约 $O(n^2k+k^3)$
